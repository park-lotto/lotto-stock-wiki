# 2회차 대본 — 종목 추적 시연 (현대모비스)

> **핵심 메시지 (4회 박기)**: 종목 찾기 < **타이밍**. 좋은 종목은 다들 안다, 진짜 차별화는 **수급 빈집이 뜬 그날** 들어가는 것.
>
> **포맷**: 16:9 / 1920×1080 / 30fps / 약 6분 50초 (13씬)
> **녹음 방식**: 한 번에 쭉. 자연스러운 호흡으로. 키워드(`**굵게**`)는 살짝 강조해서 발음.
> **Whisper segments.json**: 음성 분석 후 씬 경계 마커(`---씬N---`)로 자동 매핑.
> **자막 강조 규칙**: `**키워드**` 표시한 단어만 민트색(#00FFD0)으로 자동 변환.
