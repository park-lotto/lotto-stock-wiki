⑥ Buffer

SNS 예약 발행 3채널까지 무료 내 키만 됩니다
❗ 이 키는 숏템메이커가 대신해 드릴 수 없습니다. 내 인스타·유튜브 계정에 올리는 일이라 반드시 내 Buffer 키가 있어야 합니다. 다른 키들과 다른 점입니다.
1

buffer.com
무료로 가입

무료로 시작하시면 됩니다. 인스타·유튜브·틱톡 3개까지 공짜입니다.
채널을 더 붙이시려면 그때 월 $5짜리로 올리시면 됩니다.

2

내 SNS 계정을
Buffer에 연결

Buffer 안에서 ＋ Connect a channel 을 눌러 올리고 싶은 SNS를 연결하세요.
이때 인스타·유튜브 로그인은 Buffer가 안내해 줍니다. 우리는 관여하지 않습니다.

💡여기서 연결한 채널이 그대로 숏템메이커 10단계 「SNS 예약」에 목록으로 뜹니다.
3

API 키
만들기

Buffer 설정의 API 로 가서 Generate API Key 를 누르세요 (publish.buffer.com/settings/api).
이름은 숏템메이커 처럼 아무거나 적으시면 됩니다.

❗키는 만들 때 딱 한 번 전부 보입니다. 그 뒤에는 뒷 4자리만 보이니 그 자리에서 바로 복사해 두세요.
💡키를 만들려면 그 Buffer 조직의 소유자여야 합니다. 남이 만든 팀에 초대만 받으신 상태면 안 됩니다.
4

숏템메이커에

그러면 10단계 「SNS 예약」에 내 채널 목록이 뜹니다.
