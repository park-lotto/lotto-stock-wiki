# 트랙: 내보내기캡컷 (최종렌더 다운로드 + 캡컷 내보내기)

## 2026-07-20 — 설계 확정 (Fable), 구현은 오푸스가 이어서

- **설계문서 먼저 읽기**: `docs/superpowers/specs/2026-07-20-내보내기캡컷-design.md`
- 요지: 웹앱이라 "누르면 캡컷 자동실행"(레퍼런스=데스크톱 앱)은 원천 불가 →
  **3단 사다리**: T1 에셋 ZIP+다운로드(견고, 먼저 배포) → T2 캡컷 draft 자동생성(와우, 역공학 필요)
  → T3 ZIP 내 `캡컷에서열기.bat`(설치 없이 자동실행 근접).
- 재료는 전부 실재 확인됨(2026-07-20 코드 실측):
  - SRT ← `video_assemble._beat_timeline` (beat_idx·t0·dur·narration·cap_durs — 콘폼·여운 반영된 단일 출처)
  - 비트별 소스 컷 ← `_plan_beat_clips` 결과 재사용 (새 타임라인 계산 금지)
  - TTS ← `work/<job>/tts/beat_N.mp3` 이미 존재
  - SEO ← `store` `seo_json`
  - 최종영상 서빙 ← `/api/mix/video/{job_id}` (여기에 `?dl=1` attachment만 추가)

## ⏭ 착수 절차 (오푸스)

1. `py tools/track.py start 내보내기캡컷` → `.tracks/내보내기캡컷`에서 작업
2. T1: `GET /api/mix/export/{job_id}` (zip: final.mp4·sources/·tts/·captions.srt·script.txt·seo.txt·README)
   + `?part=sources|srt|script` 개별 + `/api/mix/video?dl=1` + 7단계 UI 버튼들 → finish(배포1)
3. T2: **로컬 캡컷으로 draft_content.json 역공학부터**(설계 §3 절차) — 실제 캡컷에서 열리는 것을
   육안 확인 전엔 ZIP에 넣지 말 것(기능 플래그)
4. T3: `캡컷에서열기.bat` (설계 §4) → finish(배포2)

  유료게이트 트랙 방식 확인 후 최종렌더와 같은 tier로.
