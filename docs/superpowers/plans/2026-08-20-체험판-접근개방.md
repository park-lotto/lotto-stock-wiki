# 체험판 접근개방 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 체험 사용자(`ranking_only` 등급)에게 레퍼런스랭킹·영상 즐겨찾기·렌즈(하루 10회)를 열고, 숏템제작소는 실제 화면 대신 소개 페이지를 보여준다.

**Architecture:** 접근 판정은 `_ranking_only_blocked()`의 **deny-by-default 화이트리스트** 한 곳에서만 한다. 여는 경로만 명시하고 나머지는 손대지 않는다. 제작소는 HTML 라우트만 등급으로 갈라 서빙하고 `/api/produce/*`는 그대로 막아둔다. 즐겨찾기는 담을 때 도는 **유료 부작용 2개(인스타 크롤·Gemini 예열)만 등급으로 끈다** — 담기 자체는 그대로 동작한다.

**Tech Stack:** Python 3 / FastAPI / pytest + fastapi.testclient / 정적 HTML

**설계 문서:** `docs/superpowers/specs/2026-08-20-체험판-접근개방-design.md`

## 사전 확인 (실측한 것 — 구현 중 재확인 불필요)

| 사실 | 근거 |
|---|---|
| `ranking_only` 등급이 이미 존재 | `app.py:7586` `access_level()` |
| 화이트리스트는 deny-by-default | `app.py:6185` `_ranking_only_blocked()` |
| 랭킹 조회는 이미 무료 | `_FREE_EXACT_GET`에 `/`, `/api/reference`, `/api/thumb`, `/api/video` 등 |
| 렌즈 하루 10회 상한이 이미 있음 | `_CREDIT_DEFAULTS={"lens":10}` (`app.py:7627`), DB 덮어쓰기 없음(실측) |
| SerpApi 월 용량 1,250회 | 서버 키 5개 × `_LENS_MONTH_LIMIT_PER_KEY=250` |
| 담기 엔드포인트 | `POST /api/mix/basket/toggle` (`app.py:1073`), 목록은 `GET /api/mix/basket` (`app.py:1143`) |
| 담을 때 도는 유료 부작용 | `_enrich_grab`(인스타 크롤) + `_enqueue_prewarm`(Gemini 추출) — 둘 다 `app.py:1101~1104` |
| 과금검사가 있는 렌즈 경로 | **`/api/lens/search`, `/api/lens/trace_url` 단 2개** (나머지 7개는 과금검사 0) |

★ **렌즈는 prefix로 열면 안 된다.** `/api/lens/kw/search`는 틱톡이 Apify 유료이고
`/api/lens/cn/search`도 Apify 폴백이 있는데 **둘 다 과금검사가 없다**. 그래서
**과금검사가 있는 2개만 정확 경로로 연다.**

from datetime import datetime, timezone
from fastapi.testclient import TestClient

def _cookie(cid):
    exp = int(datetime.now(timezone.utc).timestamp()) + 3600
    return appmod._sign_session(cid, exp)


def _setup(tmp_path, monkeypatch):
    monkeypatch.setattr(appmod, "DB_PATH", str(tmp_path / "t.db"))
    monkeypatch.setattr(appmod, "_AUTH_ON", True)
    monkeypatch.setattr(appmod, "DASH_SECRET", "test-secret-xyz")
    s = Store(str(tmp_path / "t.db"))
    s.ensure_paywall_schema()
    return s


def test_favorites_and_lens_open_for_ranking_only():
    """즐겨찾기 담기·목록과 과금검사 있는 렌즈 2개는 열린다."""
    assert appmod._ranking_only_blocked("/api/mix/basket", "GET") is False
    assert appmod._ranking_only_blocked("/api/mix/basket/toggle", "POST") is False
    assert appmod._ranking_only_blocked("/collection", "GET") is False
    assert appmod._ranking_only_blocked("/api/lens/search", "POST") is False
    assert appmod._ranking_only_blocked("/api/lens/trace_url", "POST") is False


def test_unmetered_lens_and_produce_api_still_blocked():
    """★과금검사 없는 렌즈는 계속 막는다 — prefix로 열면 Apify 유료가 샌다."""

    assert appmod._ranking_only_blocked("/api/lens/cn/search", "POST") is True
