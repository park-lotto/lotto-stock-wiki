# L3 — 한국 시장 구조

미국 시장 방향을 받아서 한국 시장이 어떻게 소화하는지.
외국인·기관의 실제 매매가 여기서 나타남.

## 수집 대상

| 소스 | 내용 | 수집 주기 |
|------|------|---------|
| 코스피·코스닥 | 지수 흐름, 이평선 상태 | 주 1회 |
| 원달러 환율 | 방향 및 외국인 이탈 신호 | 주 1회 |
| 외국인 동향 | 순매수/순매도 상위 종목·섹터 | 주 1~2회 |
| 기관 동향 | 기관 순매수 상위, 프로그램 매매 | 주 1~2회 |
| 국내 시황 뉴스 | 주요 이슈, 정책 발표 | 매일 |
| 반대매매 규모 | 레버리지 청산 지표 | 이슈 시 |

## 하위 폴더
- `index/` — 코스피·코스닥 지수, 이평선 상태
- `news/` — 국내 시황 뉴스, 정책 이슈
- `institution/` — 외국인·기관 매매 동향

## 파일 네이밍
`{날짜}_{소스}_{내용}.md`
예) `20260523_index_코스닥주간시황.md`
예) `20260523_institution_외국인순매수상위.md`
