# L1 — 글로벌 유동성

모든 시장의 가장 상위 레이어. 돈이 어디로 흐르는지를 결정함.

## 수집 대상

| 소스 | 내용 | 수집 주기 |
|------|------|---------|
| Fed 발표 | 금리 결정, FOMC 회의록, 파월 발언 | 회의 때마다 |
| M2 통화량 | 미국·글로벌 M2 증감 | 월 1회 |
| DXY (달러인덱스) | 달러 강약, 방향 | 주 1회 |
| VIX | 공포지수, 변동성 | 주 1회 |
| 미국채 금리 | 2년물·10년물·스프레드 | 주 1회 |
| 역레포 잔액 | 시중 유동성 지표 | 월 1회 |

## 하위 폴더
- `fed/` — Fed 발표문, 파월 발언 요약
- `liquidity/` — M2, DXY, VIX, 역레포
- `bonds/` — 미국채 수익률, 스프레드

## 파일 네이밍
`{날짜}_{소스}_{내용}.md`
예) `20260523_fed_파월발언요약.md`
예) `20260523_liquidity_DXY달러인덱스.md`
