# 썰쇼핑 히트작 200편 골격 실측 (2026-08-20)

> **용도**: ①대본 틀(스파인) 설계 근거 ②숏템하우스 3편 영상 소재
> **찾는 법**: `py tools/find_work.py 골격` / `py tools/find_work.py 히트작200`
> 보고 문서(사장님이 보신 것): https://claude.ai/code/artifact/2ac9ef2d-e20e-4b89-a6f4-050c37ec0aea

## 무엇을 쟀나

썰쇼핑 등록 채널 **107곳** → yt-dlp로 **2,428편** 수집 → 조회수 상위 **200편 자막 전량**
(확보율 100%) → 문구 규칙으로 골격 판정 → 상위 31편은 Gemini로 슬롯·장면까지 분해.

**YouTube API 쿼터 0** (yt-dlp가 조회수까지 준다 — 발굴 루프가 쿼터를 다 써서 403이 나던 상황을 우회).

| 은폐형(이븐쇼핑류) | 15편(7%) · 평균 27.0만 |

## 다시 돌리는 법

```bash
# 1. 수집(로컬, API 0원)
python collect_ytdlp.py 25            # 채널당 25편 → hits.json

# 2. 자막(로컬)
python pull_subs.py 200               # 상위 200편 → hits_subs.json

# 3. 골격 판정(로컬)

# 4. 슬롯 분해(★서버에서)
scp gemini_struct.py hits_subs.json ubuntu@43.200.48.69:/tmp/
ssh ... "cd /tmp && set -a && . /etc/shopping-shorts.env && set +a && python3 gemini_struct.py hits_subs.json 60"
```

## 함정 (다음에 또 밟지 마라)

- **Gemini 키는 하루 한도가 있다.** 31편에서 429로 끊겼다(60편 요청 중). 나머지는 다음날.
- **YouTube API는 발굴 루프가 다 쓴다.** `harvest_styles_forever.py`가 상시 돌아 403이 난다
  → yt-dlp를 써라(쿼터 무관, 조회수도 준다).
- **윈도 콘솔은 cp949**라 한글·유니코드 기호를 print하면 죽는다 → 결과는 파일로 써라.
- **문구 규칙으로 용도 개수를 못 센다.** 자동자막은 오탈자·경계가 흐리다. 의미 판단은 Gemini에게.
- **script_extracts(581건)는 대부분 인스타다.** 유튜브 은폐형 표본은 여기 거의 없다 —
  그래서 이번에 따로 모았다.

## ✅ 갱신 — 200편 전량 분해 완료 (2026-08-20 오후)

1차에 31편에서 429로 끊겼던 것을 **이어받기 판**(`gemini_struct_resume.py`)으로 채웠다.
198편 성공(실패 2). 집계는 `report_gemini200.txt`.

★**규칙판정과 크게 다르다** — '기타 39%'가 갈라지면서 그림이 바뀌었다:

| 골격 | Gemini 198편 | 규칙판정 200편 |
|---|---|---|
| 오용형 | **112편(56.6%)** | 92편(46%) |
| 권위자형 | **47편(23.7%)** | 4편(2%) |
| 은폐형 | 31편(15.7%) | 15편(7%) |
| 기타 | **4편(2.0%)** | 77편(39%) |

- **권위자형이 4편 → 47편**. 문구 규칙이 이 갈래를 거의 못 잡고 있었다.
- 오용형 용도 개수 **평균 3.34 / 2~5개가 96%** — 1차 31편(3.35)과 사실상 같다(표본을 6배로
  늘려도 안 흔들린다 = 믿을 만한 값).
- **클라이맥스가 마지막인 편 86/112(77%)** — `spine_fill`이 반전 몫을 따로 떼는 근거.
- 훅 장면자유 62%.

⚠️ 평균 조회수는 표본이 상위 31편 → 200편 전체로 넓어져 내려갔다(오용형 151.8만 → 88.7만).
   **갈래끼리 비교할 때만 쓰고 절대값으로 인용하지 마라.**
