## ✅ 완료·라이브 (origin/main 반영됨)
- **T1** sidebar.js: 🌙/☀️ 테마 토글(data-theme + localStorage `ssTheme`, 전 페이지 공유) + 선택색 민트 토큰화(폴백). `__ssPaintTheme`는 documentElement 가드 있음(테스트 하네스 대응).
- **T2** 노출 7페이지(index·produce·collection·library·discover·scene_library·outreach) `:root` 민트-블랙 + `[data-theme="light"]` 화이트-민트 블록 + `<head>` FOUC 스니펫. 토큰: `--accent`(민트) 하나로 퍼플·블루·틸 수렴. 신규 `--inset`·`--sel-bg`·`--sel-fg`·`--grad`·`--hover`.
- **T3** 하드코딩 치환: `#0d1420`/`#0d131c`→`var(--inset)`, 파란 선택 그라디언트→`var(--sel-bg)`, `#7db4ff`/`#9dc4ff`→`var(--sel-fg)`, 블루/퍼플 accent→민트. (canvas 색은 제외)
- **T4** 타이포: produce body 15px, panel h3 18, stub 15.
- **T5** 단계 헤더: dot 34→52px, 라벨 15px 굵게, 현재=민트 그라디언트+링+`stepBreathe` 숨쉬기, 완료=채운 민트+체크색(형태로도 구분). 잔존 퍼플 글로우 제거.
- **미리보기 UX(T8 일부)**: produce 좌측 미리보기 자리를 편집안 뜰 때 9:16 프레임으로 미리 확보(🪞), "미리보기 만들기" 누르면 그 자리에서 `SBLoader.spinner` 민트 로더. loader.js 스피너는 DOM 이탈 시 자동 정지.
- 공용 로더: **`/loader.js`** = `SBLoader.pipeline/spinner/skeleton`(민트 자체 토큰 `--sbl-*`). produce에 `<script src="/loader.js">` 이미 포함. 영상매칭(pollMix)도 단계바(`st._sblPipe`)로 이미 배선됨.

- **T6** 사이드바 작업목록을 **전 페이지**에 노출(현재 `mountWorks`가 `/produce`에서만). 단계 숫자 대신 7칸 미니 진행바. 항목 폰트 14px·터치영역 확대. → `sidebar.js`.
- **T7** produce: 안 눌리는(disabled/`display:none`) 컨트롤 **숨겼다 조건 충족 시 등장**. 단계 점프 게이트 일관화(미완 단계 잠금+안내, `canGoNext`/`refreshNextBtn`/`vpGateNext` 판정 수렴).

- **T10** 4단계(꾸미기) 밀도: 완성 스타일 카드 주경로 크게, `직접 다듬기` 4중 details→1겹, `내 프리셋` 중복 정리.
