## 1. 레퍼런스에서 가져올 것 / 버릴 것

**가져올 것 (40만 회가 증명한 뼈대)**
1. **첫 30초 = 완성 쇼츠 몽타주 + "이거 AI가 만든 겁니다"** — 결과를 먼저 보여주고 시작
2. **돈 구조 한 줄** — "조회수 수익 + 판매 수수료, 영상 하나로 두 번 번다" (0:30~1:00)
3. **반론 선제 차단** — "모델·촬영·제품 구매? 안 하셔도 됩니다"
4. **"딱 세 가지만 알고 가세요"** 프레임 — 시청자가 따라갈 지도
5. **"창 여러 개 안 띄웁니다. 클로드 하나"** — 우리 메시지와 똑같다
6. **준비물 카운트** — 레퍼런스는 "링크 하나 + 사진 몇 장". 우리는 **"한마디"** (더 적다 = 우리가 이기는 지점)
7. **단계마다 꿀팁 1개** — "이거 하나만 가져가셔도 영상값 합니다"
8. **아쉬운 점을 솔직하게** (13:30~14:00) — 신뢰를 산다. 3편 과장 구조와 가장 크게 달라지는 부분
9. **정리 → 쓰는 사람 2부류**(내 제품 사장님 / 부업) → CTA

**버릴 것 (우리와 안 맞거나 금지선)**
- 다른 도구 이름·가입 링크(레퍼런스는 협찬 툴 홍보) → 우리는 경쟁 이름 금지, 숏클만
- AI 모델 생성(가짜 인물) 시연 → 우리는 **해외 원본 영상 + 대본 + 성우 + 자막** 구조. "얼굴 바뀜 문제" 자체가 없다 → 5단계 대안 배제 근거로 씀
- 요금 설명 → 금액은 CTA 한 줄만(표준 §4)

## 2. 3편과 다르게 — 톤 원칙
| 3편(과장) | 4편(실연) |
|---|---|
| 선언·감탄 위주 | **화면이 증명** — 말보다 진행 줄·완성본이 먼저 |
| 장점만 | **아쉬운 점 2~3개를 먼저 말한다**(아래 6-⑥) |
| 결과 몽타주 | **한 편이 태어나는 과정을 처음부터 끝까지**(배속은 ×8 표시, 자르지 않음) |
| 관통 키워드 없음(확인 필요) | 관통 키워드 **"한마디"** — 1단계 등장 → 5단계 배제 근거 → 6단계 회수 |

## 3. 7단계 매핑 + 시간 배분 (목표 15분 ± 1분)

표시: 🎬 결과물(실제 녹화·완성본) · 🟦 모션그래픽(리모션) · ✏️ 손그림

| # | 단계 | 시간(가안) | 내용 | 주 화면 |
|---|---|---|---|---|
| 0 | 콜드오픈 | 0:00–0:35 | 숏클 완성 쇼츠 몽타주 → "이거 전부 사람이 편집 안 했습니다" → 클로드 창에 **"쇼핑쇼츠 만들어줘"** 타이핑 → 엔터 | 🎬 |
| 1 | 문제 인식 | 0:35–1:20 | 쇼핑쇼츠가 왜 많아졌나(돈 두 번 구조) → 그런데 **한 편 손편집에 몇 시간** | 🟦 돈 구조 / ✏️ |
| 2 | 일반 해결책 | 1:20–2:20 | 정석 손편집 과정을 **진짜로 다 알려준다**: 원본 찾기 → 자르기 → 박힌 자막 지우기 → 대본 → 성우 → 자막 → 꾸미기 → 썸네일 | ✏️ 손그림 (핵심 장면) |
| 3 | 한계 | 2:20–3:00 | 하루 2편이면 한 달 60편 → 칸마다 시계가 돈다 → "저장만 하고 못 올린다" | ✏️ → 🟦 시계 카운트 |
| 4 | 해결 방향 | 3:00–3:20 | "더 좋은 편집 앱이 아니라, **말로 시키는 비서**가 필요하다" | 🟦 저울 도식 |
| 5 | 대안 배제 | 3:20–4:10 | 유형으로만: ①AI 영상 생성 = 컷마다 얼굴·제품이 바뀜(레퍼런스도 인정한 문제) ②템플릿 앱 = 결국 손 ③웹 자동 서비스 = 버튼 여러 번. → **"한마디"로 끝나는 건 없었다** | ✏️ 표에 빨간 줄 |
| 6 | 숏클 실연 | 4:10–13:30 | 아래 6-① ~ 6-⑦ | 🎬 위주 + 🟦·✏️ 덧칠 |
| 7 | 정리 + CTA | 13:30–15:00 | 3줄 정리 → 쓰는 사람 2부류 → CTA 한 줄 | 🟦 |

→ 1~5단계 합계 **약 4분 10초**. 표준은 3분이라 2단계(손편집 정석)를 녹화하며 줄여 맞춘다.
→ 6단계 **약 9분 20초 = 전체의 62%** (표준: 절반 이상 ✔)

### 6단계 세부 — "한마디가 완성본이 되기까지" (레퍼런스의 "세 가지만 알고 가세요" 자리)

| # | 구간 | 시간 | 보여줄 것 | 꿀팁 한 줄(레퍼런스 장치) |
|---|---|---|---|---|
| 6-① | 준비물 | 0:30 | 클로드 + 숏클 연결 화면. 레퍼런스 "링크 하나 + 사진 몇 장" vs 우리 "**한마디**" 카운트 | "설정은 한 번만" |
| 6-② | 한마디 넣기 | 0:40 | 실제 한마디 3종 시연: "쇼핑쇼츠 만들어줘" / "○○ 스타일로" / 제품 링크 | 구체적으로 말할수록 결과가 좋다 |
| 6-③ | 진행 줄 따라가기 | 2:30 | "3/13 원본 영상 찾기 중" … 13단계가 넘어가는 장면, ×8 배속 표시. 단계마다 **손그림 아이콘이 화면 옆에 하나씩 체크**(2단계 손편집 칸과 같은 그림 → "이 칸을 클로드가 하고 있다") | 기다리는 동안 다른 일 해도 된다 📏 |
| 6-④ | 완성본 공개 | 1:30 | 완성 쇼츠 전체 재생(풀 화면) → 다시 한 번 **손그림 동그라미·화살표**로 자막·성우·썸네일 짚기 | — |
| 6-⑤ | 고치기 | 1:20 | "자막 색 바꿔줘" "이 줄 다시 써줘" — **한마디로 일부만 고친다**(레퍼런스 "전체 다시 만들 필요 없다") | 마음에 안 드는 부분만 말해라 |
| 6-⑥ | 솔직한 아쉬운 점 | 1:20 | ①PC가 느리면 한 편에 오래 걸린다 📏(관제 312 기록 확인) ②원본을 못 찾으면 그 편은 안 만든다(대신 다른 제품) ③클로드 구독이 필요하다 | ★3편과 가장 다른 장면 |
| 6-⑦ | 결과물 벽 | 1:30 | 숏클 완성편 여러 개(채널명 가림) 16분할 → 롱폼(지식롱폼)도 된다는 한 컷 | — |

## 4. 화면 3방식 — 무엇을 어디에 쓰나

### 🎬 결과물 (진짜 화면이 증명)
- 클로드 창 녹화: 한마디 입력 → 진행 줄 → 완성 알림 (원테이크, 로딩 ×8 표시, 자르지 않음)
- 완성 쇼츠 원본 재생: 바탕화면 완성본(썰템홈샷·잇템로그·숏클시험 등) — **채널명·로고는 전부 가림**(숏클엔진소개 금지 규칙과 같음), 연예인 편 제외
- 숏클 지식롱폼 완성본 한 컷(`숏클_GDP착시_v3_최종.mp4`) — "롱폼도 된다"

### 🟦 모션그래픽 (리모션 — 2편 엔진 재사용)
- 엔진: `remotion-stock/src/shottem2/fx.tsx`(키네틱 타이포·줌펀치·플래시·카운트업·Screen3D), 색은 `theme2.ts` 한 곳
- 쓰는 곳: 돈 두 번 구조 도식 / 한 달 60편 시계 카운트 / 저울 도식 / 녹화본을 3D 화면 틀에 얹기 / 정리 3줄
- 2편 규칙 그대로: 검정 배경 단독 금지 · 스크림 + 외곽선 · 녹화본 크게

### ✏️ 손그림 (이번 회차 새 무기 — 3편 과장 톤을 빼는 장치)
- **어디에**: 2단계 손편집 과정(8칸을 손으로 그리며 설명), 5단계 대안 배제 표, 6-③ 체크 표시, 6-④ 동그라미·화살표
- **왜**: 손그림은 "설명하는 사람"의 톤이라 과장으로 안 보인다. 그리고 **"손편집"의 '손'과 그림이 같이 간다** — 관통 키워드와 연결
- **어떻게(가안, 결정 필요)**:
  - A. 리모션에서 SVG 선이 그려지는 애니메이션(손글씨 폰트 + 획 그려지기). 자동·수정 쉬움
  - B. 사장님이 태블릿으로 직접 그리는 걸 녹화. 가장 진짜 같지만 손이 든다
  - C. AI 이미지로 손그림 일러스트 생성 후 리모션으로 획 등장. 중간
  - 추천: **A** (자동화 원칙 · 6-③에서 같은 그림을 재사용해야 해서 데이터로 갖고 있어야 함)
