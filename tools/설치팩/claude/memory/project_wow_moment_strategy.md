## 확정 컨셉 (2026-06-11)

**핵심 메시지**: "AI가 지어내는 게 아니라 원본에서 뽑아옵니다"

**Why:** 사람들이 AI 주식 분석을 불신하는 이유 = 할루시네이션. 이 시스템은 요약이 아닌 구조화 추출이라 원본 수치 그대로 나옴. 이게 와우 모먼트를 만듦.

**How to apply:** 영상 구조 = 불신 자극(오프닝) → 시스템 실행 화면 → 결과물 공개(와우) → "이게 매일 자동으로 됩니다"

---

## 비즈니스 모델 (확정)

```
유튜브 (무료) → 강의 (1회 30~50만원) → 구독 서비스 (월정액)
```

**강의 커리큘럼 (이미 모두 완성된 시스템):**
1. 텔레봇 뉴스 자동수집
2. 유튜브 채널 자동요약
3. 증권사 리포트 AI 추출
4. 태린이 파일 + AI 교차분석
5. 아침 브리핑 자동생성
6. 위키 복리 시스템

**구독 서비스**: 시스템 결과물 텔레그램 매일 배달

## 추출 vs 요약 기술 근거

- 요약: AI한테 "분석해줘" → 지어냄
- 추출: 원본 PDF에서 정해진 JSON 구조로 강제 추출 → 수치 원문 그대로

증거: 기존 MD 요약이 "2Q26 영업이익 313억원" 오기재 vs 추출은 정확히 분리
