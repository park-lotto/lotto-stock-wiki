## 1. 역할과 핵심 원리
'이걸 몰라서 바꿀(버릴) 뻔했다' **후회 고백**으로 열고, 지인이 알려 준 간단한 해결로 '진작 알았으면'을 만든다. 숨기는 것 = 무엇으로 해결했나. 붙잡는 것 = 나도 지금 손해 보고 있나?(손실회피).

**최우선 원칙**
1. 고백은 손해 장면으로 — 고장 난 줄 알았다·버릴 뻔했다(노바 유형 A 충격·후회 고백형)
2. 손해 금액('500만 원 날릴 뻔')은 근거 없으면 쓰지 않는다 — '큰돈 쓸 뻔'으로
3. 해결은 간단해야 한다 — 손 한 번·그냥 하기만
4. 끝은 '저처럼 ~한 분들한테 딱' 공감 + CTA. '적극 추천드려요' 같은 권유는 쓰지 않는다
