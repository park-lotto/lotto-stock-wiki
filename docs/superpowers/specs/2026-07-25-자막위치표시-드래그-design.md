# 자막 드래그 이동 + 지워진 자막 위치 표시 — 설계 (확정)

> 트랙: `자막위치표시` / 날짜: 2026-07-25 / 상태: **spec 확정, 구현 진행**

## 한 줄 정의
자막꾸미기(5단계)에서 (1) 나레이션 자막을 **마우스로 x·y 자유 드래그**해 위치를 옮기고,
(2) **자막제거(3단계) 때 지워진 원본 자막이 있던 자리를 미리보기에 표시**해 그 자리에 자동 정렬하거나 피할 수 있게 한다.

## 배경 / 기술 현실 (조사로 확정)
- 자막(`capPreviewText`)은 현재 `pointer-events:none` + 가로 중앙 고정, 세로만 `capY` 슬라이더.
  백엔드 `video_assemble.py:561`이 자막 x를 **50(중앙)으로 하드코딩** → 미리보기로 옮겨도 최종 렌더는 중앙(거짓).
- VMake 자막제거(`vmake_client.remove_subtitles`)는 **깨끗한 영상만** 반환, 지운 좌표는 안 준다.
  → 좌표 데이터가 세상에 없음. **우리가 원본 vs 클린을 diff해서 직접 구해 기억**해야 한다.
- 소스가 여러 개면 자막 위치가 소스마다 다름(불가피). **넓이 × 사용빈도로 가중해 1등 박스를 "1번"으로 지정**.

## 아키텍처

### A. 지워진 자막영역 감지·기억 (신규 모듈 `sub_region.py`)
- `detect_erased_region(original_path, clean_path, work, samples=8) -> box|None`
  - 두 영상에서 같은 시간비율로 `samples`장씩 프레임 추출(ffmpeg).
  - 프레임쌍마다 그레이스케일 절대차 → 임계값 이진화(PIL+numpy).
  - 이진마스크를 누적해 **빈도맵**(각 픽셀이 몇 %의 프레임에서 바뀌었나) 생성.
  - 빈도 ≥ 0.5(절반 이상 프레임에서 지속 변화 = 소각자막, 움직이는 배경은 걸러짐) 영역의 바운딩박스.
  - box = `{x_pct,y_pct,w_pct,h_pct, score}` (%단위, `score = 넓이비율 × 박스내 평균빈도`). 지속변화 없으면 None.
- 실패/None은 조용히 넘김(원본에 자막이 없었던 것) — 마커 안 그림, 자막은 기본 위치.

### B. 통합 (`mix_pipeline.py`)
- `_clean_one`: 청소 후 `detect_erased_region(src, out, work)` 호출 → `(vid, out, region)` 반환.
- `_ensure_clean_sources`: 소스별 region 취합 → **primary = score 최대 박스**.
  `clean_regions = {"sources": {vid: box}, "primary": box}` 를 DB 저장.
- 감지는 **best-effort** — 예외/None이어도 clean_status는 ready 유지(청소 자체는 성공).

### C. 저장·전달
- DB 신규 컬럼 `clean_regions_json TEXT` (`store.py` 마이그레이션 + 직렬화).
- 잡 GET 응답에 `clean_regions` 포함(`app.py`).

### D. 백엔드 자막 x 배선 (`video_assemble.py`)
- `_caption_drawtexts` line 561: `50` → `style.get("x_pct", 50)` (0~100 클램프).
- `caption_style`에 `x_pct` 필드 추가(프론트가 보냄, 미지정 시 50).

### E. 프론트 (`produce.html`)
- **자막 드래그**: `capPreviewText`의 `pointer-events` 켜고 `cursor:move`.
  헤드카피 드래그(1841~1848 참고) 방식으로 mousedown/move/up → `STATE.captionStyle.x_pct/y_pct` 갱신 →
  `capY` 슬라이더 값도 동기화, `updateCaption()` 재적용.
- **지워진 자리 마커**: 미리보기 위에 primary 박스를 **흰 점선 + "원본 자막이 있던 자리" 라벨**로 오버레이.
  후보(다른 소스) 박스가 있으면 옅은 마커로 같이(선택적).
- **자동 정렬(딸깍)**: step5 첫 진입 시 clean_regions.primary가 있으면 자막 기본 위치를 그 박스 중심으로.
- **"1번 자리로 되돌리기"** 버튼: 드래그로 옮긴 자막을 primary 박스로 리셋.

## 데이터 계약
```
box = {x_pct, y_pct, w_pct, h_pct, score}   # 모두 float, %; score는 정렬용
clean_regions = { "sources": {video_id: box}, "primary": box|null }
caption_style += { x_pct: float }            # 없으면 50(중앙)
```

## 테스트
- `sub_region.detect_erased_region`: 합성 프레임(하단 밴드만 다른 두 영상)으로 박스가 하단중앙에 잡히는지 / 변화 없으면 None / 움직이는 배경은 빈도 임계로 걸러지는지.
- 백엔드 x 배선: `_caption_drawtexts`가 x_pct를 `_segmented_drawtext`에 넘기는지(x_center 반영).
- 집계: 소스 3개 박스 중 score 최대가 primary인지.

## 범위 밖 (YAGNI)
- 자막 회전·크기 드래그(위치만). OCR 기반 텍스트 인식(diff로 충분). 후보 박스 다중선택 UI(1번 + 옵션 마커까지만).
