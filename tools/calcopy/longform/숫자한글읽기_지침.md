# 한국어 숫자 읽기 지침 (TTS·대본·낭독용)

## 0. 기본 원칙
- 출력할 문장의 모든 아라비아 숫자·기호·단위는 실제로 소리 내어 읽는 한글로 변환한다.
- 변환하기 전에 숫자 바로 뒤에 오는 단위(수량사)를 먼저 확인하고, 고유어로 읽을지 한자어로 읽을지 결정한다.
- 숫자와 단위는 띄어 쓴다. (예: 세 개, 십오 분)

## 1. 고유어 vs 한자어 선택 (가장 흔한 오류)
[고유어(하나·둘·셋…)로 읽는 단위]
개, 명, 사람, 마리, 살(나이), 시(시각), 시간, 번(횟수), 번째, 잔, 병, 권, 장, 대(차량·기계), 채, 벌, 켤레, 그루, 송이, 가지, 군데, 곳, 달, 배(배수), 척, 통, 줄, 쌍, 끼, 바퀴, 걸음, 방(총·주사), 판, 곡, 편, 알, 조각, 봉지, 상자, 그릇
 예) 3개→세 개 / 5명→다섯 명 / 2시간→두 시간 / 3배→세 배 / 4번 했다→네 번 했다

[한자어(일·이·삼…)로 읽는 단위]
분, 초, 년, 월, 일, 주, 개월, 원, 달러, 층, 호, 호선, 번(번호), 회, 차, 기, 학년, 세(나이), 위, 등, 점(점수), 쪽, 페이지, 인, 인분, 퍼센트, 도, 단계, 장(章), 조, 항, 권(권역), 대(연령대), 미터·킬로그램 등 모든 측정 단위
 예) 3분→삼 분 / 2층→이 층 / 3번 출구→삼 번 출구 / 20대→이십 대 / 3회→삼 회

## 2. 고유어 관형형 변화 (단위 앞에서는 반드시 변형)
- 1→한, 2→두, 3→세, 4→네, 20→스무
- 11→열한, 12→열두, 13→열세, 14→열네
- 21→스물한, 22→스물두 … 91→아흔한
 예) 1개→한 개(하나 개 ×) / 20명→스무 명(스물 명 ×) / 21명→스물한 명
- 단위 없이 셀 때는 원형을 쓴다: 하나, 둘, 셋, 넷, 스물

## 3. 고유어 수의 범위
- 1~99는 고유어로 읽는다: 열, 스물, 서른, 마흔, 쉰, 예순, 일흔, 여든, 아흔
- 100 이상은 백 단위 이상을 한자어로, 끝 두 자리를 고유어로 읽는다
 예) 125개→백스물다섯 개 / 101명→백한 명 / 300마리→삼백 마리
- 큰 수량은 전부 한자어로 읽어도 된다: 1,250명→천이백오십 명

## 4. 시각과 시간
- 시는 고유어, 분·초는 한자어로 읽는다: 3시 15분 20초→세 시 십오 분 이십 초
- 12시→열두 시 / 오전 11시→오전 열한 시
- 24시간제: 13시→열세 시, 22시→스물두 시 (또는 오후 열 시로 바꿈)
- 기간: 3시간 30분→세 시간 삼십 분 / 1시간 반→한 시간 반
- 14:30 같은 표기→열네 시 삼십 분 또는 오후 두 시 반

## 5. 날짜·연도·월
- 6월→유월, 10월→시월 (육월, 십월 ×)
- 나머지 월: 일월, 이월, 삼월, 사월, 오월, 칠월, 팔월, 구월, 십일월, 십이월
- 2026년→이천이십육 년 / '26년→이십육 년 / 1990년대→천구백구십 년대
- 2026.10.5 또는 2026-10-05→이천이십육 년 시월 오 일
- 1일→일 일 (날짜) / 하루, 이틀, 사흘, 나흘, 닷새, 엿새, 이레, 여드레, 아흐레, 열흘은 문맥상 일수일 때만 사용
- 3개월→삼 개월 / 3달→세 달 / 2주→이 주

## 6. 나이
- 살은 고유어, 세는 한자어: 25살→스물다섯 살 / 25세→이십오 세
- 만 3세→만 삼 세 / 100세→백 세

## 7. 큰 수 (콤마 3자리 → 한국어 4자리 단위로 다시 끊기)
- 콤마를 지우고 뒤에서부터 네 자리씩 끊어 만·억·조를 붙인다.
 예) 1,234,567→123|4567→백이십삼만 사천오백육십칠
 예) 3,200,000,000→32|0000|0000→삼십이억
- 맨 앞의 1은 생략: 10→십, 100→백, 1,000→천, 10,000→만 (일만 ×)
- 단, 억·조 앞의 1은 읽는다: 1억→일억, 1조→일조
- 110,000→십일만 / 10,500→만 오백 / 1,000,000→백만
- 혼합 표기: 1억 2천만 원→일억 이천만 원 / 3.5억→삼 점 오 억 또는 삼억 오천만

## 8. 소수·분수·비율
- 소수점은 "점", 소수부는 한 자리씩: 3.14→삼 점 일사 / 0.05→영 점 영오
- 0은 수학에서 "영", 번호에서는 "공"
- 분수: 1/3→삼분의 일 (분모를 먼저) / 2와 1/2→이와 이분의 일
- %→퍼센트, %p→퍼센트포인트: 3.5%→삼 점 오 퍼센트
- 비율: 3:1→삼 대 일 / 배율 x10→십 배

## 9. 번호·코드 (한 자리씩 읽기)
- 전화번호·계좌번호·우편번호·인증번호·종목코드는 한 자리씩, 0은 "공"
- 하이픈(-)은 "에" 또는 짧게 끊어 읽는다
 예) 010-1234-5678→공일공에 일이삼사에 오육칠팔
 예) 종목코드 005930→공공오구삼공
- 버스 번호·방 번호는 수로 읽는다: 7016번 버스→칠천십육 번 버스 / 302호→삼백이 호

## 10. 순서·순위
- 1번째→첫 번째 (한 번째 ×), 2번째→두 번째, 11번째→열한 번째, 21번째→스물한 번째
- 1위→일 위 / 1등→일 등 / 제1장→제일 장 / 제2차→제이 차 / 1기→일 기 / 3학년→삼 학년
- 1호선→일 호선 / 2단계→이 단계

## 11. 같은 단위, 다른 의미 (문맥으로 판단)
- 번: 순서·번호는 한자어(3번 출구→삼 번 출구, 3번 선수→삼 번 선수), 횟수는 고유어(3번 봤다→세 번 봤다)
- 대: 차량·기계는 고유어(차 2대→차 두 대), 연령·시대는 한자어(30대→삼십 대)
- 시: 시각은 고유어(3시→세 시), 행정명은 그대로
- 장: 종이는 고유어(3장→세 장), 책의 장(章)은 한자어(3장→삼 장)
- 권: 책 수는 고유어(2권→두 권), 시리즈 순번도 고유어(2권→두 권) / 수도권 등 지명은 그대로
- 인: 3인→삼 인 / 3인분→삼 인분 (단, "세 사람"으로 바꿔 읽는 것은 허용)

## 12. 범위·어림수
- 2~3개→두세 개 / 3~4명→서너 명 / 5~6명→대여섯 명 / 1~2개→한두 개
- 범위가 크면 "에서": 10~20명→열 명에서 스무 명
- 수십, 수백, 수천, 수만: 그대로 읽는다

## 13. 음수·온도·측정 단위
- -3→마이너스 삼 / -3℃→영하 삼 도 / 25℃→섭씨 이십오 도 또는 이십오 도
- km→킬로미터, m→미터, cm→센티미터, mm→밀리미터, kg→킬로그램, g→그램, mg→밀리그램
- L→리터, ml→밀리리터, ㎡→제곱미터, 평→평
- km/h→시속 ~ 킬로미터 (100km/h→시속 백 킬로미터)
- GB→기가바이트, MB→메가바이트, TB→테라바이트, GHz→기가헤르츠

## 14. 화폐
- 원, 달러, 엔, 위안은 한자어: 5,000원→오천 원 / $100→백 달러 / ₩10,000→만 원
- 기호가 앞에 붙어도 단위는 숫자 뒤에서 읽는다: $3.5B→삼십오억 달러, $1.2M→백이십만 달러
- 주식: 시총 3.2조→삼 점 이 조 또는 삼조 이천억 / 코스피 2,500→이천오백 포인트

## 15. 수식·기호
- + 더하기, - 빼기, × 곱하기, ÷ 나누기, = 는, 같다
- ± 플러스마이너스, ≥ 이상, ≤ 이하, > 초과, < 미만
- ~ (범위) 에서, / (분수) 분의, / (구분) 또는 생략
- # 샵 또는 번, & 앤드, @ 앳

## 16. 영문·고유명사와 결합된 숫자 (관용 독음 우선)
- 5G→파이브지, 3D→쓰리디, 4K→포케이, MP3→엠피쓰리, A4→에이포
- 24/7→이십사 시간 연중무휴 / 1:1→일 대 일
- COVID-19→코로나 일구 또는 코비드 나인틴
- 제품명은 공식 발음을 따른다: 아이폰 15→아이폰 십오, 갤럭시 S24→갤럭시 에스이십사
- 버전: v2.0→버전 이 점 영 / Windows 11→윈도우 일레븐(관용) 또는 윈도우 십일

## 17. 기타 주의
- 고어형(석·넉)은 일부 단위에만 쓴다: 석 달, 넉 달, 석 잔, 넉 장 (세 달, 네 잔도 허용되며, 낭독체는 현대형을 권장)
- 숫자가 문장 맨 앞에 오면 단위와 함께 자연스럽게 읽는다: 3명이 왔다→세 명이 왔다
- 숫자 뒤에 조사가 붙으면 조사를 읽은 수에 맞춘다: 1이→일이, 2를→이를, 3과→삼과, 10은→십은
- 판단이 애매하면 실제 한국인 아나운서가 뉴스에서 읽는 방식을 따른다.

## 18. 최종 점검
출력 전에 다음을 확인한다:
① 남아 있는 아라비아 숫자나 기호가 없는가
② 단위마다 고유어/한자어를 맞게 골랐는가
③ 한·두·세·네·스무 관형형으로 바꿨는가
④ 큰 수를 네 자리 단위로 다시 끊었는가
⑤ 유월·시월을 지켰는가
⑥ 번호는 한 자리씩, 0은 "공"으로 읽었는가
