라이브: https://shoppingshorts.duckdns.org → 랭킹 카드 **🔍 렌즈 유사영상**

## ✅ 이번에 한 것 (사용자 요청 6개, 전부 렌즈 결과 패널에 적용)
1. **샤오홍슈·도우인 자동 합류** — 렌즈(구글렌즈) 후 캡션 키워드로 Apify 병렬검색
   (`/api/lens/cn`)해 비동기로 결과에 덧붙임. 구글렌즈가 중국 플랫폼을 거의 못 잡던 것 보완.
2. **영상 메타 표시** — 채널명 · 조회수/좋아요 · 영상길이(카드에 표시).
3. **전체선택 · 일괄담기 · 일괄삭제** — 결과 카드 체크박스 + 컨트롤바.
4. **미리보기** — 유튜브 임베드 / 직접 mp4 `<video>` / 폴백 썸네일 오버레이.
5. **숏폼만 토글** — `is_short`(길이 ≤90초, 길이 불명은 유지) 필터.
   (요청 #5 "채널 저장"은 이번 범위에서 제외 — 사용자 지시)

## ⚠️ 미검증 / 후속 (라이브에서 확인 필요)
- **실제 검색 결과**: 구글렌즈+Apify 실호출은 유료라 미실행. 라이브에서 렌즈 눌러 확인.
  - 캡션이 한국어라 도우인(중국) 매칭률은 낮을 수 있음 — 샤오홍슈는 한국어 키워드로 실증 이력 있음.
- **Apify 메타 필드명**: 실제 액터 응답 필드명을 라이브로 못 봐서 `.get()` 방어 폴백으로 뽑음.
  라이브에서 채널/조회수/길이가 **빈칸이면** 실제 필드명 확인해 `xiaohongshu_search._first`/`douyin_search._first` 후보경로 보정.
- **비용**: 렌즈 누를 때마다 Apify 2회(샤오홍슈+도우인) 자동 실행 = 유료. 렌즈 자체 월 100회(SerpApi) 한도로 상한은 걸림.
