# 08 회원 지시서 형식 분기 + 잇템로그 제작 도구 저장소로 — `flow.py`·`runner_ops.py` (표준 §7·§3-3 C1·C2 · 04 뒤)

## 목표
"<프리셋> 스타일로 만들어줘"가 **어느 형식이든** 같은 서버 지시서(`flow.py`)로 돈다: 형식별 단계표 `FORMAT_STAGES`(연예인형 = 지금 것 / **해외원본형** = 한국 재편집 → 해외 원본 찾기 → 자막 지우기 → 대본 / 쇼핑형 / 레시피형). check 단계는 04 의 `quality_gate.gate` 1단 + 눈 2단(E1~E8). 잇템로그 v3 제작에 쓴 scratchpad 도구(`mk_v3_*.py`·`vmake.py`)를 **저장소 도구 + runner_ops do 명령**으로 옮긴다(회원 PC 가 같은 손을 갖게).

## 실측 배경(10-24)

- 잇템로그 실제 제작(handoff 10-22~24): 소재 = `channel/ititemlog/소재후보.json`(한국 재편집 조회 상위) → 해외 원본 = `tools/calcopy/origin_find.py`(렌즈·소넷 눈 판정, 장부 `channel/해외원본소재/원본찾기.json`) → 원본 2~3개 시간순 → 박힌 자막 구간은 **VMake Pro(서버 유료)** 로 지우고 `_orig` 보존·`_clean` 끼움(scratchpad `vmake.py`, 40분 제한 → 5400초) → 대본.json(결과 먼저 훅·전언 2줄+혼잣말 — 05 가 v2 로 갈라 적음) · 재료.json(cuts·blur·src_urls) → `render_bench` → `bench_check` 10/10 → 받아쓰기 대조 → 썸네일 카드 → 드라이브. `01b_영상수집_잇템로그_숏템로그.md` 가 1b 단계 문서.

## 설계
1. `FORMAT_STAGES = {"연예인형": [지금 STAGES], "해외원본형": [setup, bench(한국 재편집 쇼츠 확인·소재 쇼핑 여부), origin_foreign(렌즈→후보 썸네일 24칸 → 회원 Claude 눈 판정 `origin_find` 규칙: 해외 채널마다 가장 먼저·늦게 올린 건 퍼 간 쪽), product(쿠팡 같은 제품 → 비슷한 제품 허용 — 현장썰 규칙), research, material(원본 구간 받기·박힌 글자 상자 `shot_table` → clean 또는 blur), asr(원음 받아쓰기·번역 자막), script(판 brief + 결과 먼저 훅 등은 **판 v2 의 brief 가 정한다** — flow 는 판을 읽을 뿐), sign, plan, thumb, render, check, done], "쇼핑형": [setup, bench(제품·썰 소재), product, research(게시글·댓글 근거), material(제품 영상·짤), script, sign, plan, thumb, render, check, done], "레시피형": 연예인형 + 재료 스티커}`. `flow.start(url, version, sid, product, fmt=None)` — fmt 없으면 `channel/프리셋.json` 에서 version 의 slug → `member.flow_format`. 서버(09)는 fmt 를 넘기기만.
2. 질문문은 형식별 상수(`ORIGIN_READ_FOREIGN` 등) — 연예인형 문장을 해외원본형에 재사용 금지(사람 이름·'본인 채널' 전제가 틀린다).
3. `ph_check` → `runner check` = **`quality_gate.gate(판, doc, work)`**(04) → `ph_check_look` 질문 = 표준 §5-2 E1~E8 번호 그대로(눈 검수 묶음 `eye/` 그림 첨부) → 둘 다 ○ 아니면 `check_fix`(2회) → 멈춤(`stop`, 사유 = ×항목 번호).
4. runner do 새 명령: `origin_foreign`(origin_find run 1씨앗) · `clean_text`(vmake_clean — 회원 키 없으면 blur 로 자동 대체 + 로그) · `materials_draft`(ititemlog_make — 재료.json 초안: 원본 시간순·재사용 0·확대 1.0·blur 상자) · 전부 허용 목록에.
5. `flow_dev.py --version 잇템로그판 --fmt 해외원본형 --ref <한국 재편집 쇼츠> --cache <ep13 src>` 로 **유튜브 0회 완주** 가능하게(answer_key 에 잇템로그 정답지 추가 — 원본 id·제품).

## 합격 검사(사보타주 먼저)
1. 연예인형 회귀: 성시경 캐시 완주가 고치기 전과 같은 단계 수·같은 산출(자동 검사 ○, 정답지 합격) — `answer_key.py compare`.
2. 해외원본형: 잇템로그 ep13 캐시로 완주 → `render/final.mp4` + `quality_gate` 1단 ○ + 눈 2단 질문 8개가 회원 Claude(claude -p opus)에게 갔고 답 JSON 이 저장됨 · 정답지(원본 id 2개·제품) 일치.
3. 사보타주: `quality_gate` 를 강제로 `ok:false`(환경변수 `QG_FORCE_FAIL=1`) 로 돌리면 flow 가 `check_fix` 2회 뒤 `stop` 으로 끝나고 완성본을 `done` 으로 내지 않는다(고치기 전 코드는 bench_check 만 보고 done 으로 갔는지 확인).
4. VMake: 회원 키 없음 조건에서 `clean_text` 가 서버를 **호출하지 않고** blur 로 대체(호출 로그 0) — 키 있을 때 호출은 실측하지 않는다(돈).
5. 형식 이름이 프리셋.json 에 없는 version → `flow.start` 가 거절(조용한 기본값 금지).
