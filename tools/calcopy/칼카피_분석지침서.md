전문가의 기준: **① 줄마다 센다 ② 0.1초 띠와 원본 프레임까지 본다 ③ 픽셀·hex·자/초·초로 적는다 ④ 분모를 같이 적는다 ⑤ 없는 것(꾸밈 없는 줄·효과음 0)도 적는다 ⑥ 못 잰 것은 '미측정·왜'로 적는다 ⑦ 측정값마다 우리 엔진의 어느 설정에 들어가는지 안다 ⑧ 만든 뒤 벤치와 같은 자로 다시 잰다.**

## 1. 실행 대본 — 사장님이 "<채널> 칼카피하자" 라고 하면

```
1) py tools/track.py use 칼카피숏템엔진 · 탭 제목 set "칼카피 <채널>" · 이 문서와 시작 문서를 끝까지 읽는다
2) 시작할 때 한 번에 묻는다(그 뒤로는 안 묻는다): 우리 브랜드 이름 · 하이브리드 여부 · (과금은 이미 허락 — TTS·스피치매틱스)
3) PYTHONUTF8=1 py tools/calcopy/engine/kal.py <채널주소|@핸들> --slug <slug> --brand <브랜드> --hybrid 예|아니오 [--n 6]
   → 선정·수집·뜯기·프레임·뼈대까지 자동으로 돌고 readlines 에서 waiting_human 으로 멈춘다(상태 channel/<slug>/kal_state.json)
4) channel/<slug>/_kal/줄판독_브리프.md 의 '지금까지 본 것' 절을 내가 2편 프레임을 직접 보고 이 채널 것으로 고친다
5) _kal/워커묶음.json 대로 워커(오퍼스·편당 2편)에게 브리프+담당_공통규칙+이 문서 §6 을 주고 줄판독/<id>.json 을 채우게 한다
6) 워커 결과마다 py tools/calcopy/engine/kal_analyze.py check channel/<slug>/줄판독 --strict → 오류 0 이 될 때까지 되돌린다. 핵심 주장은 내가 프레임을 연다
7) 같은 kal.py 명령 다시 → rules 단계가 규칙빈도·대본언어·팔레트·스타일분석_초안을 만든다 → 내가 §3 축별 A 칸대로 스타일분석.md 를 쓴다(규칙 채택·신뢰도 표시)
8) 다시 kal.py → copy(to_frame 자동 설명서) → _hand 손질·preset_save(견본 spr_preset.py) → make(preset_make 시험편) → verify(재현일치도) → apply(원장·장부 할 일)

10) 끝: 시작 문서 §0-1 14-1 확정 채널 줄·브랜드.json·스타일.json 은 사람이(장부_할일.md), handoff·log.d·커밋·푸시·열린 세션 알림
```

## 2. 단계 파이프라인 (0 선정 → 1 수집 → 2 분석 → 3 카피 → 4 제작 → 5 검증 → 6 적용 → 7 하이브리드 → 8 운영)

각 단계 8칸: 들어가는 것 / 하는 일(명령) / 판단 주인 / 나오는 것 / 끝났다의 기준 / 자주 하는 실수 / 다음 단계 조건 / 사장님께 물을 것.

### 2-0. 선정 (kal.py `select`)
- 들어가는 것: 채널 주소·@핸들. 같은 결 후보는 `channel/스타일분석/현장썰/채널수집/같은결_채널.md`(확정 7) · 엔진 `engine/channel_find.py:judge_same_kind`.
- 하는 일: yt-dlp flat-playlist → 조회 순 정렬 → `C:/숏템_칼카피/<slug>/top.json` · 구독·편 수·조회 중앙/최대·구독 대비 중앙(실측 잇템로그 10-20: §9 시운전 표).
- 판단 주인: 숫자 = `kal.py:step_select` · 같은 결 판정 = `channel_find.judge_same_kind`(제목 규칙→썸네일 4장→표본 2편 소리). 최종 선정 = 사람.
- 나오는 것: `kal_state.json` channel 칸(name·subs·total·view_median·view_max·views_per_sub·top_ids).
- 끝났다의 기준: 구독 대비 조회 중앙 ≥ 1(미확인 — 기준 숫자는 사장님 결정 대기, 지금은 숫자만 적고 사람이 고른다) · 최근 30일 업로드 ≥ 주 2회(`yt_channel.channel_stats` 미확인 연결).
- 실수: 조회 큰 1편만 보고 고름(디데이쇼츠 535,000 vs 중앙 25,500) · 제품 없는 바이럴 채널(현장썰 요건 4가지 §0-1 0).
- 다음: top_ids ≥ n(기본 6, 숫자 층은 50 — `top50_run.py`).
- 물을 것: 우리 브랜드 이름 · 하이브리드 여부 — **이때 한 번만**.

### 2-1. 수집 (`collect`)
- 들어가는 것: top_ids. 하는 일: yt-dlp `-f "137+ba[ext=m4a]/bv*[height>=1080]+ba/b"` + info.json + ko 자동자막, 동시 2(무거운 프로세스 ≤4).
- 판단 주인: `kal.py:step_collect`(형식·동시 수). 나오는 것: `C:/숏템_칼카피/<slug>/src/<id>.{mp4,info.json,ko.vtt}`.
- 끝: 받은 편 ≥ 절반(2편 이상), 1080×1920. 실수: android 클라이언트·720p 미만(공통규칙) · C 여유 15GB 미만에서 50편 받기(10-18 0.7GB 사고). 지금 C 여유 **8.7GB(10-20 실측)** → 표본은 2~6편, 50편은 D 로.
- 표본 수: 칼분석 6~8편(규칙 분모 ≥5 가 나오게), 숫자 층 50편(기준표). 2~3편은 시운전만.

### 2-2. 분석 (`tteutgi` → `frames` → `skeleton` → `readlines` → `rules`) — 축별 A 칸은 §3
- 들어가는 것: src mp4·vtt. 하는 일: ① `analyze.analyze(llm=claude_cli.ask, materials=False)` → `channel/<slug>/뜯기/<id>/뜯기.json`(창·자막 띠·컷·글꼴 후보·LUFS; 제미나이 호출 0) ② `kal_analyze frames`(2fps 시트 + 10fps 글자 띠 변화 → `kal/frames_<id>/strips/` 0.1초 띠 80장·`판독목록_<id>.json`) ③ `kal_analyze skeleton`(줄판독 뼈대: t0·t1·text 기계값, 나머지 null + `_todo`) ④ 사람 줄판독(§6 칸) → `check --strict` ⑤ `rules`(규칙빈도·대본언어·팔레트·스타일분석_초안).
- 판단 주인: 뜯기 측정 = `engine/analyze.py:analyze`(bench 자) · 판독 프레임 고르기 = `kal_analyze.frames_cmd`(견본 `channel/starpickroom/_tools/sheets.py` text_mask 그대로) · 칸 검사 = `kal_analyze.check_doc` · 규칙+빈도 = `kal_analyze.rules_of` · 어미·말꼴 = `kal_analyze.script_of` · 팔레트 = `kal_analyze.palette_of` · 등장 어휘 정규화 = `kal_analyze.enter_key`.
- 나오는 것: `줄판독/<id>.json`(§6) · `_kal/{규칙빈도_초안.md, 규칙빈도.json, 대본언어.md, 스타일분석_초안.md, 워커묶음.json, 줄판독_브리프.md}` · `팔레트.json` · 사람이 쓰는 `스타일분석.md`(§3 꼴).
- 끝: 표본 전부 `check --strict` 오류 0 · 규칙 후보 등급(강/중/약/표본부족) 붙음 · 스타일분석.md 에 확인 범위·신뢰도 표시 · 축 11개 중 '미측정' 칸에 이유.
- 실수(실측 10-20): speaker 칸에 설명문(21Vo·ASqF 15건) · 원본박힘 층 줄에 꾸밈 칸 없음(dKcz 13줄) · enter 자유 서술 25가지(→ `enter_key` 가 접지만 새 줄판독은 §6 어휘로) · role 칸 0/193(역할별 빈도 불가) · 꿀템노트 줄판독 폴더 비어 있음(8편 0 — 1판 끝났다 기준 미달).
- 다음: check 통과 + 스타일분석.md 존재(kal.py rules 가 본다).
- 물을 것: 없음(판독은 우리 몫).

### 2-3. 카피 (`copy`) — 분석을 설정값으로 옮긴다 (축별 B 칸은 §3, 대응표 §4)
- 들어가는 것: 뜯기.json·스타일분석.md·팔레트.json. 하는 일: `engine/to_frame.py <뜯기.json> --out frame_<id>.json --no-ocr`(편마다 자동 설명서) → `preset/_hand/frame_<id>.json` 손질(실측 근거를 notes 에, 견본 `channel/starpickroom/preset/spr_preset.py` 머리말) → `engine/preset_save.py`(여러 편 공통값=프리셋·편마다 다른 값=variables) → manifest.
- 판단 주인: 뜯기→설명서 = `to_frame.build` · 공통/변수 가르기 = `preset_save.merge/variables` · 스키마 = `shopping_shorts/calcopy_frame/schema.py`(실측 칸: font·size·line_h·rgb·outline{px,rgb}·line_outline·shadow{dx,dy,blur,rgb}·glow{px,rgb}·box{rgb,pad,radius}·italic·letter_spacing·word_spacing·valign·enter{kind,ms}·emphasis{words,rgb,style}).
