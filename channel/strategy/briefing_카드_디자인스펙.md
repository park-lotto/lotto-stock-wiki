# 브리핑 카드 — 디자인 스펙 & 운영 가이드

> 텔레그램·카카오톡 단톡방 배포용 800px 고정폭 HTML 카드.
> 파일: `out/briefing_{섹터명}.html`

---

## 🎨 컬러 팔레트 규칙 (STOCK BRAIN 공식)

> **원칙: 민트 + 화이트 위주. 레드·옐로는 신호 전용 악센트.**

### 4색 확정 팔레트

| 역할 | 컬러명 | HEX | 용도 |
|------|--------|-----|------|
| **PRIMARY 1** | 민트 | `#00e5c6` | 브랜드 라인, 섹션 헤더, S급 배지, 강조 테두리, 상단 글로우라인 |
| **PRIMARY 2** | 화이트 | `#ffffff` / `#f0f8ff` | 종목명·제목·본문 — 전체 텍스트의 주요 색상 |
| **ACCENT RED** | 쨍한 레드 | `#ff2244` | 경고, 위험 신호, 긴급 이벤트, 강세 화살표(▲) |
| **ACCENT YELLOW** | 쨍한 옐로 | `#ffe500` | A급 배지, 주의 신호, 체크 경고(!) |

### 비율 원칙

```
민트   ─────────────── 40%  (브랜드 아이덴티티 — 라인, 태그, 하이라이트)
화이트 ─────────────── 40%  (텍스트 계층 전체 — 제목~본문~부제)
레드   ──────── 10%  (S급 시그널, 긴급 경고 전용)
옐로   ──────── 10%  (A급 시그널, 주의 표시 전용)
```

### 금지 사항

- 오렌지(`#ff9500`) 단독 사용 ❌ → 옐로로 통일
- 인디고/퍼플을 주요 강조색으로 사용 ❌ → 보조 칩 한정
- 배경에 흰색/회색 사용 ❌ → 다크 배경 고정 (`#07090f`)
- 시그널 색을 4색 외 색으로 추가 ❌

## 🙂 이모지 사용 규칙

> **원칙: 이모지는 구역 식별과 빠른 스캔을 위해 사용. 과하면 오히려 산만해진다.**

### 이모지 배치 기준

| 위치 | 이모지 | 규칙 |
|------|--------|------|
| **섹션 헤더 앞** (`sec-dia`) | 섹터/주제별 1개 | 텍스트 없이 이모지만. 14px. 섹터마다 고정 |
| **TODAY'S 라벨** | `⚡` | 1개 고정. 에너지·긴급 느낌 |
| **이슈 카드 이름** (`ic-name`) | 이슈 주제별 1개 | 이름 앞에 배치. 12px |
| **종목 이벤트** (`sk-evt`) | `📅` | "다음:" 앞 고정. 날짜 의미 |
| **TODAY'S 인사이트 본문** | 1~2개 허용 | 끝부분 배치. 감정 표현용 |
| **리포트/뉴스 라벨** | `📄` `📰` | 고정 (바꾸지 않음) |

### 이모지 ❌ 금지 구역

- 종목명 (`sk-name`) 앞 — 종목명은 텍스트만
- 불릿 마커 (`skpt-mk`) — `▲` `!` `—` 기호 고정
- 체크뱃지 (`cbadge`) — `✓` `!` `?` 기호 고정
- 섹션 카운트 (`sec-cnt`) — 이모지 이미 포함 (`🔴🟠🟡`)이면 추가 금지
- 풋터 — 텍스트만

### 섹터별 섹션 이모지 고정값

| 섹터 | 이슈현황 | 대표종목 | 체크리스트 |
|------|---------|---------|----------|
| 조선 | `⚓` | `🚢` | `✅` |
| 반도체 | `💾` | `📊` | `✅` |
| 전력기기 | `⚡` | `📊` | `✅` |
| 방산 | `🛡️` | `📊` | `✅` |
| 2차전지 | `🔋` | `📊` | `✅` |

### 이슈 카드 이름 (`ic-name`) 1행 규칙

```css
/* ic-name 은 반드시 1행 */
.ic-name { white-space:nowrap; overflow:hidden; text-overflow:ellipsis; font-size:11.5px; }
```

- **`<br>` 태그 사용 금지** — 이름은 줄바꿈 없이 한 줄
- 텍스트가 카드 너비를 넘으면 `...` 자동 처리
- 이모지 + 핵심 키워드만으로 압축 (예: `💎 삼성중공업 독과점` / `☢️ SMR 테라파워`)
- 긴 설명은 `ic-stage`(아래 줄)에 작성

```
포지션 꼭 챙기세요. 핵잠수함 건조사 선정도 언제든 터질 수 있는 타이밍이에요 👀"

❌ 잘못된 예시:
"조선 섹터는 2차 랠리 구간이며, 방산·에너지 복합 재평가라는 새 이유로
선반영 부담이 존재한다. CPSP D-30·FLNG 임박으로 카탈리스트가 지속 중이다."
```

**말투 원칙:**
- 존댓말(`~해요`, `~이에요`, `~세요`) 사용
- 이모지 1~2개 허용 (끝부분 배치)
- 딱딱한 보고서 문체 금지
- 오늘 가장 HOT한 이슈 1~2개 집중
- 3줄 이내

**디자인:**
- 민트 좌측 3px 라인
- 배경 `rgba(0,229,198,0.05)`
- 텍스트 `#ddeeff` · 12.5px · line-height 1.7

### ③ 오늘의 리포트 / 오늘의 뉴스

**2컬럼 구조 — 좌: 리포트 / 우: 뉴스**

| 컬럼 | 태그 색상 | 내용 기준 |
|------|---------|---------|
| 오늘의 리포트 | 민트 태그 (증권사명) | 오늘 또는 최근 3일 내 리포트. 증권사명 + 종목명 + 핵심 1줄 |
| 오늘의 뉴스 | 옐로 태그 (이슈명) | 오늘 주요 뉴스. 이슈 카테고리 + 내용 1줄 |

- 항목 수: 각 2~4개
- 1줄 요약 원칙: 25자 이내, 숫자·방향성 포함
- 매일 전체 교체

### ④ 조선섹터 주요 이슈현황 (4×2 그리드)

**이슈 카드 구조 (한 카드당):**
```
[번호]                    [등급 배지]
이슈명 (2줄)
현재 단계 (Stage)
┌─────────────────────┐
│ ▶ TRIGGER           │
│ 다음 트리거 이벤트    │
└─────────────────────┘
[종목칩] [종목칩]
```

**등급 배지 규칙:**

| 등급 | 의미 | 상단 바 색상 | 배지 색상 | 적용 기준 |
|------|------|------------|---------|---------|
| 🔴 S급 | 임박·핵심 촉매 | 민트 `#00e5c6` | 민트 | D-60 이내 or 섹터 직결 핵심 이슈 |
| 🟡 A급 | 중요·주목 | 옐로 `#ffe500` | 옐로 | 수혜 확정, 시기 미정 |
| ⚪ B급 | 모니터링 | 흰색 반투명 | 회색 | 가능성 있음, 불확실 |

**TRIGGER 박스 규칙:**
- "언제 어떤 뉴스/공시가 나오면 주가가 움직인다"를 1줄로
- 날짜 확정 시 D-XX 표기

**종목 칩 색상:**
- 민트 칩: 해당 이슈 직접 수혜 1~2순위
- 회색 칩: 간접 수혜 or 후순위

### ⑤ 조선섹터 대표종목 (4×1 그리드)

**종목 카드 구조:**
```
종목명              [점수/상태 배지]
코드 · 시장

▲ 불릿 1 (강점)
▲ 불릿 2 (강점)
! 불릿 3 (주의사항 가능)

다음: [다음 이벤트명] (민트 강조)
```

**불릿 작성 원칙:**
- 3개 고정
- ▲ = 상승 모멘텀 (민트)
- ! = 주의/리스크 (옐로)
- — = 중립 (회색)
- 각 불릿 15자 이내, 숫자/팩트 중심

**점수 배지:**
- 민트 배지: HOT (멀티 모멘텀, 탑픽 후보)
- 옐로 배지: 특정 이슈 특화 (방산, FLNG 등)

### ⑥ 주요 체크리스트

**2열 그리드, 5~6개 항목**

| 뱃지 | 색상 | 의미 | 사용 기준 |
|------|------|------|---------|
| ✓ | 민트 | 오늘 반드시 확인 | 공시·계약·협상 결과 등 임박 이벤트 |
| ! | 옐로 | 주의·체크 필요 | 수급·뉴스·발표 모니터링 |
| ? | 흰색 반투명 | 판단 필요 | 시나리오 판단, 대기 항목 |
