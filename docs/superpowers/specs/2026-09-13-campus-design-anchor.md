# 승인 외관 기준 복원과 내부 연결

사용자 재확인: 작은 원형 판/건물 3개로 바꾼 외관은 반려. 제공 이미지 GqkafwLrq1.jpg의 대규모 캠퍼스 스타일을 이어가야 한다. 내부 논의가 외관 폐기를 뜻하지 않는다.

## 이번 검토 산출물

`company_ops/static/campus-review/`: 원본 그대로의 외관 위에 본사/숏템메이커/스탁브레인/확장 구역을 표시한다. 실시간 관제가 아닌 설계 도면으로 명시한다. 내부 8석 및 3구역 구현은 별도 링크로 비교하며 반려된 기존 외관을 승인본으로 재사용하지 않는다.

정확한 연결 동과 층은 미확정이다. 특히 이미지의 B1 수집 안정화와 현재 기획/개발/검수 1F는 다른 공간이다. 기존 내부를 1F 후보로 연결하는 제안만 표시한다. 이미지의 프로젝트/워커 수를 실제 운영 수치로 가져오지 않는다.

## 유지할 외관

중앙 다층 원형 본사, 좌우 프로그램별 건물군, 여러 겹 원형 동선, 수공간, 연결 다리, 옥상 정원과 다층 테라스, 외곽 확장 부지. 부모 회사 메이커스랩 하나, 숏템메이커/스탁브레인 두 프로그램, HNL 후속.

## 다음 실제 3D 작업의 검토 순서

1. 원본 구도에 대응하는 지형/수로/원형 도로/건물 매스를 구성한다. 현재 작은 외관을 늘린 것으로 대체하지 않는다.
2. 동일한 정면 조감도에서 원본과 비교하고, 좌·후면 시점으로 공간 연속성을 확인한다.
3. 선택 건물의 진입점과 기존 내부 공간을 연결한다. 다른 동·층은 미구현으로 구분한다.
4. 건축 세부/조경/조명 품질을 단계별 비교한다. 이미지 수준 완성이나 수백 워커 성능을 검증 없이 약속하지 않는다.

이번 도면은 위 실제 3D 재구성 완료를 의미하지 않는다.
