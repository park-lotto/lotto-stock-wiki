# 휴지통띠제거 — 장면MIX 빨간 띠 먹통 + 끈 칸 컷 자물쇠

## 2026-09-16 (CH) — 완료 (라이브 배포됨)

### ① 빨간 띠 먹통 제거 (커밋 e59e24ba2 · 29d4d77e4)

**증상**: 장면MIX에 빨간 띠 "🗑 여기에 놓으면 이 장면이 빠집니다"가 뜨고 **먹통**.
같은 고객이 3번 제보. 고객 증언: *"드래그해서 위치 바꾸면서… 건드리다 보면 가끔씩"*.

**원인**(브라우저 실측): 휴지통 기능(2026-08-15 `3269cb001`에 도입, **처음부터 있던 버그**).
`dragStart`가 `dragFrom`과 `bin` 클래스 **둘을 켜는데**, `dragDrop`의 이른 반환이
**`dragFrom`만 비우고 `bin`은 안 걷어서** 띠가 남았다. → 제자리 드롭 때만 발생 = "가끔".

**조치**: 휴지통 기능 전체 제거(`binmsg`·CSS·`paneDrop`·패널 ondrop). 드래그 종료를
`itemDragEnd()` 하나로 통일. **빼기는 ✕ 버튼·두 번 클릭 그대로 유지.**
없앤 기능을 가리키던 **안내문구 3곳도 정정**(안 고쳤으면 고객이 시키는 대로 해도 안 됨).

**라이브 확인**: 서버 md5 = 로컬 md5 `be8229cd…` · binmsg 0건 · delx 4건 · 안내문구 교체됨.

### ② 끈 칸 컷 자물쇠 🔓/🔒 (커밋 14bd6cd9d)

사장님 요청: *"고정시킬 건 냅두고 다른 거 조작"* · 기본 풀림 · 풀린 것도 보이게.

**왜 필요했나**: 구절맞춤 **켠** 칸은 `FIXLEN`(✋)로 개별 고정이 되는데, **끈** 칸은
`CUTS`로 길이를 잡으면서 **잠금 개념이 아예 없었다** → 다른 컷을 만지면 맞춰둔 길이가 밀림.
(※ 처음엔 "끈 칸에서 ✋가 안 먹히는 버그"로 오판했으나, `scene_timeline.js:349` 주석대로
  **끈 칸은 ✋를 안 쓰는 게 설계**였다. 그래서 끈 칸 전용 잠금을 새로 만든 것.)

**설계**: 잠금은 **컷의 속성** `CUTS[i][k].lock`. 따로 창고를 만들면 컷이 빠지거나
자리를 옮길 때 짝이 어긋난다(0순위-B).

**길이가 바뀌는 4곳 전부에서 잠긴 컷을 건너뛴다**:
- `syncCuts` ③빼기(가장 가까운 **풀린** 컷이 시간 받음) ④담기(**풀린** 마지막 컷만 쪼갬)
  ⑤줄이기(잠긴 건 skip, 전부 잠겨 못 줄이면 **억지로 안 줄이고** 남긴다)
- `dragCut` 끌기(잠기면 막고 안내)

**저장·복원에 `lock` 실음** — 빼먹으면 새로고침에 사라진다(FIXLEN이 한 실수).

**검증**(Playwright 실제 페이지 함수): 기본풀림/토글 · 빼기 시 잠긴 b 2초 유지 ·
8→6초 줄일 때 잠긴 d 유지하고 합계 정확히 6 · 새 장면 담을 때 잠긴 d 안 쪼개짐 ·
잠긴 컷 끌기 늘리기/줄이기 둘 다 차단 · **풀린 컷은 정상 동작** · 저장→복원 lock 유지 ·
체크박스·✕ 소실 없음 · 콘솔오류 0.

### ③ 자물쇠를 카드 → **위쪽 필름(타임라인)**으로 이동 (커밋 0fec0f817)

사장님 캡처 지적 2건:
- **"왼쪽은 자물쇠, 오른쪽은 체크박스냐?"** → **내 CSS 실수**. 카드 자물쇠를
  `left:3px/bottom:6px`에 뒀는데 체크박스(`.pk`)가 `left:4px/bottom:6px`을 이미 쓰고 있었다.
  `z-index:4`가 덮어 **"여러 장 골라 빼기"가 통째로 막혔다.**
  (※ 오른쪽 칸에 자물쇠가 없던 건 정상 — 구절맞춤 **켠** 칸은 FIXLEN을 쓴다)
- **"자물쇠는 카드가 아니라 위쪽 필름 위에"** → 맞다. 길이를 끌어 조절하는 곳이 필름이다.

조치: 카드 `.lockbtn` 제거(체크박스 원복) → 필름 컷에 `.tl-lockbtn` 추가
(`scene_timeline.js`). 자리는 **아래 왼쪽 `left:11px`** — 윗줄은 `tl-len`(좌)·`tl-repbtn`(우)이
차 있고 양옆 `tl-edge`가 8px라 그걸 피한 값. 잠긴 컷은 `.tl-cut.locked` 테두리로도 표시.

⚠️ **카드 아래줄은 이미 꽉 찼다**: 체크박스(left:4) · 📦박스(left:22~right:26) · ✕(right:3).
여기에 무엇이든 끼우면 반드시 뭔가를 가린다.

검증: 실제 CSS 아래 렌더 좌표 실측 — 자물쇠 겹침 4곳 전부 false, 컷 안에 들어감,
카드 체크박스 클릭이 `elementFromPoint`로 체크박스에 닿음 확인, 잠금 동작 전부 유지, 콘솔오류 0.
