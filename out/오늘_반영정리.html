1. 성우 「유라」 추가

타입캐스트 젊은 여성 · 3가지 톤

2. 빠르게 맞추기 (강병주님)

박스로 길게 고른 장면이 잘리면 → [빠르게 맞추기] 누르면 영상만 빠르게 틀어 끝까지 보여줌
렌더 영상에서 끝 장면까지 나오는 것 확인함

3. 장면 띠 휠로 넘기기 (이윤정님)

맨 위 장면 띠에서 마우스 휠 → 옆으로 넘어감

⏳ 올리는 중 병합 끝, 서버 재시작 기다리는 중

4. 위 컷 띠가 늘 필름처럼

한 장짜리 카드 없이 처음부터 여러 장 그림으로 보임 · 카드 가운데 누르면 빨간 막대가 그 자리로 가서 재생

5. 카드에 「뒤에 더 있어요」 표시

고른 장면이 잘리면 카드에 +0.2초 ▶ → 누르면 끝까지 끝까지 ✓

7. 구절 맞춤에서 끝 잡아 줄이면 — 자막과 안 어긋나게

구절 맞춤 줄은 기본을 「그 카드만 느리게」로 → 장면 바뀌는 자리가 그대로라 자막과 계속 맞음
너무 느려지면 자동으로 「옆 장면 더 보여줌」

8. 안내 줄 하나로 합치기

지금 빨간 줄 여러 개·「전체 늘리기」 체크박스 → 줄마다 한 줄만:
1.4초 넘쳐요 ✓ 그냥 두기카드2 빠르게전부 같이 빠르게되돌리기
0.4초 비었어요 ✓ 옆 장면 더카드2 느리게전부 같이 느리게장면 붙이기되돌리기
「장면 붙이기」는 너무 느려질 때만 나옴

9. 위 컷에 주황 박스

아래 소스 필름처럼 · 양 끝 당기면 길이 · 가운데 잡고 밀면 원본의 어느 부분을 쓸지 바뀜
