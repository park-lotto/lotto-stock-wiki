## 2026-07-29 (집) — 상품 자동검색(크롤) 추가, 라이브 병합

### 결론부터
- **크롤은 되는데, 되는 IP가 정해져 있다.** 쿠팡(Akamai)은 **데이터센터 IP와 헤드리스를
  둘 다 막는다.** 실측 결과:

  | 경로 | 결과 |
  |---|---|
  | httpx / curl_cffi(chrome124 위장) | 403 (홈페이지조차) |
  | Playwright **헤드리스**, 로컬 | 403 |
  | Playwright **헤드풀 + channel="chrome"**, 로컬(주거용 IP) | **200 · 상품 58건** |
  | 서버(AWS) 직결, xvfb + 헤드풀 chrome | 403 |
  | 서버 + Webshare `YTDLP_PROXY`(데이터센터 플랜) | 403 |

  → 유튜브 쇼츠·Reddit과 같은 패턴(memory `reference_youtube_shorts_datacenter_block`).
