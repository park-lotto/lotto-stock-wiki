# 여행 숙소 인스타형 — 대본 스타일 카드 (관제 239, 2026-10-19)

> 양식 = 숏템메이커 업그레이드 정리(노바작가 대본 프롬프트 형식): 역할 → 원칙 → 재료 → 제목 틀 사전 → 후킹 유형 → 칸 → 가공 장치 → 연결어·말투 → 길이 → 시안 → 검수 → 참고 대본.
> 기계가 읽는 정본 = `shopping_shorts/travel_build.py` 의 `TRAVEL_CARD`(이 문서와 같은 값). 문서를 고치면 그 값도 같이 고친다.
> 근거 표기: **[창고 sc]** = 서버 대본창고 `script_extracts` 받아쓰기(조회수·댓글은 `channel_archive`) · **[강의]** = 여행쇼핑쇼츠 강의 6편 화면(`channel/strategy/여행쇼핑쇼츠_강의분석/`) · **[노바]** = 스타터킷 `_스타일/예시_인스타쇼핑형/대본_프롬프트.md` · **[HDN]** = 두유노홈디노 원본 49편(`대본설명서/labels`).

## 역할
인스타 릴스에서 **숙소 하나를 이야기로 소개하는 30~40대 화자**. 숙소가 주인공이고 화자는 "가족·연인·친구와 다녀온 사람"이다.
광고처럼 설명하지 않는다 — 친구에게 "나 거기 갔다가 진짜 놀랐잖아" 하고 수다 떨듯이 말한다. 목표 = 끝까지 보고 **댓글에 키워드**를 남기게 한다(→ 자동 DM으로 예약 링크).

## 최우선 원칙
1. **설명하지 말고 사건을 말한다.** 첫 3초에 인물(엄마·남편·친구)과 작은 사건이 나온다 — 숙소 칭찬이 아니라 **인물의 반응이 바뀌는 것**을 보여 준다(의심 → 놀람 → 백기/감동).
2. **화면에 보이는 것만 숙소 사실로 쓴다.** 인물·계기·감정·반응은 지어내도 된다(창작 허용선 [HDN 2판]). 시설·풍경·시간대·서비스는 그 줄의 사진에 보여야 한다.
3. **숙소 이름·지역·가격 숫자는 쓰지 않는다.** 궁금증이 댓글을 부른다(강의 6편 공통, 실측: 좋아요 595 / 댓글 5,268 [강의]).
4. **반전은 회수한다.** 첫 줄에서 던진 사건(의심·내기·몰래)을 끝에서 그 인물의 한마디로 닫는다.
5. **나열체 금지.** '~하고 ~하고', '~하더니 ~하더니'로 시설을 줄 세우지 않는다 — '~했는데 ~니까 ~어서'로 이유를 잇는다.

## 재료(입력)
- 숙소 상세: `travel_source.fetch` — 이름(쓰지 않음)·시설 목록·공식 사진(분류 꼬리표)·출처
- 사진 7장: `travel_build.pick7` → 원본 재설명(`describe_picks`: 보이는 것·시간대). **줄 i = 사진 i** (컷 = 줄)
- (선택) 사장님이 고른 후킹 유형

| ⑥ 반응·결과 | 객실 2 | 인물의 한마디·결과 과장(회수) | 15~30 | 결국 ~가 먼저 또 오자고 하더라고요 | 아니오(감상) |
| ⑦ 댓글 유도 | 물놀이 3·욕조 | 이야기 키워드 + 받는 것 | 15~30 | 궁금하면 댓글에 '{키워드}' 남겨 주세요 | 아니오 — 없는 할인·마감 금지 |

- **댓글 키워드는 그 이야기의 말**로 정한다(창고 실측: '대박'·'최고'·'촉촉'·'뽀송'·'완벽'). 예) 커플 반전 → '내가졌다' / 가족 → '효도' / 후회 → '진작' / 물멍 숙소 → '물멍'. 매 편 '정보'로 고정하지 않는다.
- 줄은 긴 문장의 마디다 — 조각 끝이 '~는데 / ~니까 / ~어서'로 다음 줄에 이어져도 된다. 문장이 끝나는 줄에만 마침표.

## 연결어·말투(실측 목표)
- 대본창고 인스타 상위 200편(조회수순, 문장부호 3개+) 실측 2026-10-19: 문장 5.7개·문장당 46자 · 끝 세요 18%·더라고요 13%·어요 10%·예요 8%·거든요 5%·거 있죠 4% · 이음 고 40%·는데 18%·니까 10%·더니 7%·어서 6%.
- 두유노홈디노 원본 49편: 끝 더라고요/구요 28%·어요 19%·대요 5%·잖아요 4% · 이음 고 36%·는데 20%·니까 11%·어서류 19%.
- **우리 목표**: 이음 '고·더니·며' 합 ≤ 50%, 끝 어미 3종 이상 섞기(더라고요·거든요·어요·예요·거 있죠·잖아요), 문장 3~4개(이 길이에서 문장당 40자 이상).
- 쓰지 않는 끝: ~네요·~는데요·~음/임/함(남의 어미 [HDN]), 썰쇼핑 고정 문형('이건 바로', '근데 진짜 충격적인 건' [노바]).
- 재는 자: `travel_build.speech_profile` / 관문 `speech_issues` / 비교 도구 `tools/travel/ending_profile.py`.

## 길이
- **140~175자(공백 포함) ≈ 20~25초** — 미나 1.35배 = 초당 6.87자(voice_presets 실측). 강의 완성본 18~20초(Fish 1.3배·190자), 창고 인스타 상위 중앙 256자(제품 소개라 김) 사이에서 숙소형은 짧게.
- 관문: `script_issues` 가 범위 ±10자 밖이면 지적.

## 시안
- 유형이 서로 다른 시안 **3개**(위 6유형 중) → 채점 → 【비교】+ 추천 1개. 같은 숙소를 다시 만들면 직전 유형은 피한다.
