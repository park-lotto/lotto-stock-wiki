- 오렌지 테두리 카드 = "Claude가 처리" 신호로 일관 사용

### 브랜딩
- **STOCKBRAIN** (all caps) — 채널명 모든 씬에 표기
- "로또의 주식인사이트" 절대 사용 금지
- 우하단 고정: `STOCKBRAIN · by 로또` 워터마크 (opacity 0.35)

## 씬별 재설계 지시

### S3 철학 (2404f) — "30분 AI의 환상파괴"
**감정**: 충격 → 깨달음 → 희망
- Phase1 (f0~900): "AI는 30분 후 멍청해진다" → 텍스트 임팩트
  - 화면 가득 **"30분"** 180px 레드 → 글리치 → 검은 사선 X 오버레이
  - 컨텍스트 창 시각화: 녹색 바→빨간 바 줄어드는 애니메이션 (화면 중앙 전체)
- Phase2 (f900~1948): AI 잘하는 것 4가지 → 카드 4장 2×2 격자, 한 번에 하나씩 폭발 등장
  - 각 카드: 120×120px 아이콘 + 40px 타이틀 + 회전 테두리 glow 효과
- Phase3 (f1948~2404): "그래서 무엇을?" 임팩트 → **"매일 리셋 = 매일 최강"** 56px 라임

### S4 로드맵 (322f) — "5단계 로드맵"
**감정**: "이거 진짜 쉽겠다"
- 배경: 짙은 그라디언트 + 은하수 파티클 (5개 별이 점→선→카드)
- 5개 카드: 지금 180px 너비 → **240px 너비** + 아이콘 60px
- 카드 등장: bounce-in 애니메이션 (spring, 탄성 높게)
- 카드 완료 시: 라임 체크 glow + 연결선 네온 점등
- 하단 배지 "10분 컷 · 코딩 0줄" → **72px** 임팩트 텍스트로 화면 중앙 배치

### S5 설치 (2545f) — "Claude 설치"
**감정**: 간단함, 따라할 수 있다
- STEP 배지: 코너 작은 거 → **화면 상단 1/4 전체 STEP 타이틀 바**
  - "STEP 1 · 구글에서 검색" 56px + 라임 밑줄 바 (좌→우 0.3s 슬라이드)
- 설치 중 구간 (f731~995): 중앙에 Claude 아이콘 120px + 원형 progress ring + "설치 중..." 타이핑
- 유료 플랜 구간 (f1510~): Free/Pro/Max 3카드 배치
  - Pro 카드: 오렌지 테두리 glow + **"필요"** 라벨 + 150% 스케일
  - Free/Max: dim(opacity 0.3), 회색 테두리
- 마지막 "$19/month" 카드: 레퍼런스처럼 검정 카드 중앙 + **180px 오렌지 $19** + "/ month" 흰색

### S6 MCP (1952f) — "USB-C 비유"
**감정**: "아 그거구나!" 유레카
- 5핀/8핀 파편화: 케이블 아이콘 3개 각각 다른 방향에서 등장, 충돌하며 ❌
- USB-C 등장: 가운데서 빛 폭발 → **"USB-C"** 180px 라임 텍스트 zoom-in
- PlayMCP: 4개 서비스 아이콘이 허브로 연결되는 선 애니메이션 (도미노 효과)
- 임팩트: **"딸깍 하나로"** 텍스트 120px 흰색 + 아래 **"전부 처리"** 라임 120px

### S7 PlayMCP 연동 (4295f) — 최장 씬
**감정**: 긴장감 → 성취감
- 단계 진행바: 상단 전체 너비 바 대신 → **5개 원형 노드 + 연결선** (미완료=회색 테두리, 완료=라임 채움)
  - 각 노드 60px, 레이블 24px, 완료 시 pulse glow 2초
- 액션 콜아웃: 코너 배지 대신 → 화면 오른쪽 1/3에 **큰 콜아웃 카드** (width 500px)
  - "🔑 우측 상단 로그인" → 56px 텍스트 + 레드 테두리 flash
- 연결 완료 배지: 전체 화면 LIME 플래시 → 중앙 **"✓ PlayMCP 연결 완료"** 90px
- 카톡 임팩트: shake + 💬 이모지 120px + "카톡, 바로 왔어요!" 80px → confetti 파티클

### S8 프롬프트 (1585f) — "업무 지시서"
**감정**: "이게 핵심이다"
- 프롬프트 카드: 지금 width 980px → **화면 전체(1760px)** 큰 카드
  - 타이핑 텍스트: 36px Roboto Mono (지금 26px에서 상향)
  - 커서: 라임 색 ▋ 깜박임
- 고정댓글 CTA: 작은 pill 대신 → **화면 하단 1/4 전체 CTA 바** (라임 배경 + 검정 텍스트)
- 결과 4개 칩: 좌→우 cascade 등장 + 각 항목 체크 시 라임 ✓ + chime

### S9 플러그인 (1412f) — "Before/After"
**감정**: 비교 충격, 전환
- Before 패널: 화면 왼쪽 절반, "매일 아침 수동 검색..." 타이핑, 지친 느낌 (dim, 레드 accent)
- After 패널: 화면 오른쪽 절반에서 슬라이드 인, `/브리핑` 명령어 강조 라임
  - 두 패널 사이: 번개 ⚡ 아이콘 중앙, 파티션 라인 라임
- 완료 배지: 화면 전체 fill → "완료" 대신 **카톡 대화창 mock-up** pop-up

### S10 스케줄 (1308f) — "예약 자동화"
**감정**: "진짜 매일 알아서 온다고?"
- 시계 비주얼: 중앙에 아날로그 시계 애니메이션, 오전 7:00 가리키며 멈춤
  - 시침 움직임 → 7시 도달 → 라임 flash + 카카오톡 알림음
- 스케줄 리스트: 위에서 아래로 타이핑되는 ToDo 리스트 (✓ 완료 시 라임)
- "전기 아껴요" 안심 카드: 오른쪽 고정 배지 대신 → **화면 하단 중앙 큰 안심 카드**

### S11 응용 (744f) — 마무리
**감정**: 가능성 확장, CTA
- 응용 4종 카드: 2×2 격자 (지금과 동일) → 카드 크기 **300×200px**으로 확대
- 마무리 텍스트: 페이드인 **"이 구조만 익히면"** 72px → **"응용은 무궁무진"** 80px 라임
- STOCKBRAIN 로고 + Claude 아이콘 나란히 큼직하게 중앙 배치
- 구독 CTA: 빨간 유튜브 버튼 mock-up 애니메이션

## 모든 씬 공통 규칙

### 절대 금지
- 40px 이하 텍스트 (자막 포함)
- 화면 5% 이하 코너 배지
- 3초 이상 그래픽 변화 없는 정적 구간
- "로또의 주식인사이트" 텍스트

### 필수 요소
- 모든 씬 우하단: `STOCKBRAIN` 16px 모노 워터마크 (opacity 0.4)
- Claude 오렌지 아이콘 최소 1회 이상 등장
- 자막 씬 전환마다 slide-up 애니메이션 (f=6 fade+translate)
- 씬 시작 0~10f: 흰 플래시 또는 zoom-punch 인트로

### 효과 강도
- spring damping: 6~10 (탄성 높게)
- 텍스트 등장: riseFade dist=40 (지금 18~30에서 상향)
- 임팩트 순간: shake amp=10~16 (지금 5~6에서 상향)
- glow 효과: box-shadow blur 40~60px (지금 20~30에서 상향)

## 기술 메모

- 기존 fx.tsx의 모션 함수 그대로 사용 (cl, pop, riseFade, shake, zoomPunch 등)
- SceneBase의 audio/video prop 구조 유지
- Whisper 자막 JSON 타이밍 그대로 유지 (변경 금지)
- 파일명/export명 변경 금지 (Root.tsx 연동 깨짐)
- 새 상수나 헬퍼 함수는 fx.tsx에 추가 가능
