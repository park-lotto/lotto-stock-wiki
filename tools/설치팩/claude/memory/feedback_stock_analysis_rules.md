## 규칙 0 — 가는 놈이 더 간다 (모멘텀 지속 확인)
"선반영 많음 = 제외"는 틀린 논리다. 선반영 이후에도 더 가는 케이스가 훨씬 많다.
LG이노텍: 6개사 TP 상향 후 "선반영 많음"으로 제외했지만 실제론 한 달 +110%, 외국인+기관 동시 순매수 지속.

**선반영 종목 판단 체크리스트:**
1. 현재가가 컨센서스 TP에 도달했는가? → 도달 안 했으면 추가 상승 여지
2. 기관·외국인 순매수가 끊겼는가? → 지속 중이면 모멘텀 살아있음
3. TP 상향이 계속 나오는가? → 나오면 선순환 (TP↑→주가↑→TP재상향)
4. 증권사들이 "여전히 저평가"라고 하는가? → 그러면 더 간다

**How to apply:** 후발주를 찾기 전에 먼저 "선도주가 계속 가는지" 확인. 둘 다 살아있으면 둘 다 봐야 한다.

## 규칙 1 — 이슈 먼저, 위키 나중
이슈 들어오면 위키 탐색 전에 WebSearch로 "왜"를 확인. [[feedback_issue_first]]

## 규칙 2 — 후발주 판단 시 갭 플레이 확인
후발주를 판단할 때 공급망 연결만 보면 안 된다.
대장주가 단기 급등했는지 → 밸류에이션 갭이 형성됐는지 → 동업종 저평가 종목 없는지 확인.
실적 나쁜 종목도 갭이 크면 더 강하게 반응. [[project_wiki_data_methodology]]

## 규칙 3 — 데이터 없는 종목은 "모른다"고 해야 한다
위키에 없는 종목을 "데이터 없어서 분석 불가"라고 명시하는 것이 틀린 분석보다 낫다.
삼화콘덴서 어닝쇼크만 보고 "후발주 아님"이라고 단정했다가 틀렸다. [[feedback_data_gap_analysis]]

## 규칙 4 — 섹터 리서치는 뉴스 반응 패턴까지
Q1~Q7 기존 구조에 Q8(뉴스 트리거)·Q9(주도 종목)·Q10(연쇄 구조) 없으면 불완전.
뉴스 반응 패턴 없으면 이슈 들어왔을 때 "어느 종목이 먼저 뜨는가"를 못 잡음.

## 규칙 5 — 연쇄 시차는 실제 데이터로
"A뜨면 B뜬다" 만으론 부족. 시차가 얼마인지, 실제 몇 % 움직였는지 데이터가 있어야 매매에 쓸 수 있다.
