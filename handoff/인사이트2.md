### 왜 API를 새로 팠나
기존 `/api/insights/*` 는 **"카테고리→소스→문서→상세" 드릴다운용**이라 화면 하나
그리는 데 4번 호출해야 한다. 인사이트2는 **전부 제자리에서 펼치는** 구조라
판세 3칸(시장·섹터·종목) + 문서별 발언을 **한 방에** 주는 모양이 필요했다.

`/api/insights2/daily?category=youtube` →
`{date, counts, market, sectors[], stocks[], videos[], atoms[]}`
- `atoms[].video` 인덱스로 발언↔문서를 연결한다(프론트에서 join)
- `sectors[]`/`stocks[]` = `{name, plus, minus, n}` ← 막대그래프 그대로 그림
- `asset` 은 `"삼성전자, SK하이닉스"` 처럼 한 칸에 여럿 → 쉼표로 쪼개서 집계

### 화면 원칙 (사장님 피드백으로 확정)
사장님 지적: **"내용·구성은 좋은데 난독이고 텍스트가 많아 읽기 힘들다."**
원인은 ①설명박스 11개 ②글자가 전부 같은 크기 ③정보를 문장으로 씀.
→ **"읽는 화면"이 아니라 "보는 화면"** 으로 재설계:
- 설명 텍스트 전부 제거. 위계는 **크기**로 준다(26px 헤드라인 → 29px 판세 → 13px 발언)
- 섹터·종목은 문장이 아니라 **막대 + 숫자**. 의견 갈리면 `2·1` 금색
- **페이지 이동 0** — 시장/섹터/종목/문서 전부 제자리 펼침, ESC로 닫힘, 한 번에 하나만
- 문서 카드 **아래에 결론 요약을 항상 노출**(클릭 없이 읽히게) ← 사장님이 명시 요청

### 날짜 처리
`오늘`을 고집하지 않고 **데이터가 있는 최근 날짜**를 쓴다(`_ins2_latest_date`).
크롤이 아직이면 화면이 통째로 비는 걸 막는다. 실측상 소스마다 최신일이 다르다.

### 접근제어 (★중요)
`/insights2` 와 `/api/insights2/` 를 `_USER_PAGES`·`_USER_API_PREFIX` 에 **일부러 안 넣었다**
→ 미들웨어 `_user_allowed`(server.py:501)가 일반 사용자를 자동 차단
  (페이지는 `/home` 리다이렉트, API는 403). `admin_page`(:707)와 같은 방식.
추가로 `_ins2_require_admin` 2중 잠금 — 나중에 누가 미들웨어를 고치다 초안이 새는 걸 막는다.

**검증 실측** (4케이스 전부 통과):
```
_is_admin(0)        = True    legacy admin
gate(쿠키 없음)      = True    차단됨
gate(위조 쿠키)      = True    차단됨
gate(정상 관리자)    = False   통과됨
```
⚠️ **로컬에선 이 테스트가 무의미하다** — `.env`에 `DASH_PASS`·`GOOGLE_CLIENT_ID`가 없으면
서버가 `인증 OFF(전원 관리자)`로 뜬다. 위 검증은 게이트 함수를 직접 호출해서 한 것.

### ① ⏱ 타임스탬프가 전 소스 0건 → 시각 링크 전부 비활성(`—`)
**수집 문제가 아니라 배선 문제다.**
- `raw/yt/*.md` 947개 중 **847개에 `[mm:ss] 화자: 발언`이 이미 있다 (총 11,105개)**
- 그런데 DB엔 72개뿐 → **원자화가 버린다**
- 원인: 유튜브 경로가 **두 벌**인데 타임스탬프를 채우는 쪽이 고아
  - **A(실제로 돎)**: `atom_pipeline.py` STEP3.7 → `post_ingest.py` → `POST_PROMPT`
    ← **텔레그램용 프롬프트를 재활용**. `ts`가 *메시지 시각*이라 `msg_ts`로 감
    (`telegram_questionnaire.py:112,153`). `db.py:69` `setdefault(...,None)`이 조용히 None
  - **B(아무도 안 부름)**: `pipeline/atoms/youtube_ingest.py` — `_YT_PROMPT`에
    `timestamp: mm:ss` 명시, 딥링크까지 만든다(`atomizer.py:207`, 순수 산수).
    2026-06-29 커밋 `b51969114`에서 컬럼 마이그레이션과 **같이 만들어졌는데
    파이프라인에 연결을 안 했다.** 게다가 `CRAWL_ROOT`가 집PC 경로 하드코딩(:18)
- **비용은 0** — API·재다운로드 불필요. 딥링크는 `_ts_to_seconds` 산수
- 화면은 `with_ts=0`이면 **안내 배너**를 띄우고 정상 동작한다(깨지지 않음)

### ② 📉 시장 칸이 0
`sector='시장'` 원자가 해당일에 없다. 판세 3칸 중 하나가 비어 보인다.

### ③ 🎯 종목명 자리에 문장이 들어온다
`asset`에 `"회사 내 주도적 위치 확대"`, `"성장을 커리어 확보"` 같은 값.
원자화 품질 문제 — 8월 원자는 `"야생 근육 배양"` 같은 **단어 조각**이고
같은 문장이 `"긍정: ..."` 로 **중복**되기도 한다. 6월(타임스탬프 있던 것)은
`speaker`도 살아있고 온전한 문장이었다.

## 설계 맥락 (합의된 큰 그림)

사장님 요구: **"두 축"**
- **축1 소스별** — 원본을 원본답게. 유튜브=썸네일+인사이트, 텔레=채널별 실시간,
  리포트=증권사별 정리. (지금 `/insights2`가 여기 1단계)
- **축2 주제별** — 유튭·텔레 등에서 나온 걸 **모아서** 섹터별/큰이슈 카드/주요종목.
  (미착수)

유튜브 화면의 목적: **"영상 안 보고 시간 줄여주는 것"**
→ 종합을 **위**에, 영상을 **아래**에. (영상 목록이 먼저면 결국 영상을 보게 된다)
→ 3분할: 시장 / 섹터별 / 종목별 + "결국 뭐라는 건가" 한 줄

레퍼런스 랭킹에서 빌려온 것:
- 정렬=하나 고름(밑줄) vs 필터=독립토글(둥근알약) — 축이 다르면 모양도 다르게
- 백분위 배지(절대기준 X) · 진단형 빈 상태 · `activity()` 🟢🔴 인디케이터
