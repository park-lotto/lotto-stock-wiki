이슈가 들어오면 위키 데이터만으로 추론하기 전에 반드시 실제 이유를 먼저 검색해야 한다.

**Why:** 젠슨황 방한 이슈 시 위키(반도체 HBM 중심)만 보고 "HBM 공급 스토리"로 분석했다가 완전히 틀렸다. 실제 이유는 "피지컬 AI 동맹 구축"이었고, 수혜 종목이 완전히 달라졌다. (반도체 소부장 → 현대오토에버·LG CNS·LG전자·현대모비스)

**How to apply:**
- 외부 이슈(방문·발표·협약 등) 들어오면 → WebSearch 먼저 → "왜 일어나는가" 확인 후 분석
- 위키 데이터는 배경 지식, 이슈의 실제 목적은 검색으로 확인
- "이슈 목적 모름 = 틀린 분석 확률 높음"
