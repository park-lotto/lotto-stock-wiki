### 원인 (실측으로 확정 — 첫 진단은 틀렸다)

유튜브 검색어를 **중국 커머스용 프롬프트에서 빌려 쓰고 있었다.**
`cn_search_keyword_vision`의 `_CN_VISION_PROMPT`는 샤오홍슈·도우인용이라
"넓은 카테고리 말고 제품 특정(색·형태·브랜드 포함)"을 지시한다. 중국 커머스엔 맞지만
유튜브엔 **너무 좁은 조합어**가 나와 아무것도 안 잡힌다.

⚠️ **처음엔 "후보 검색어(c.ko)를 쓰면 된다"고 진단했는데 실측에서 기각됐다.**
`다진마늘`(현행)도 9/10 same이 나왔다 — 제품=주제인 소재는 안 갈린다.
**제품과 주제가 갈리는 소재**에서만 무너진다. 표본 1개로 판단했으면 틀린 걸 고칠 뻔했다.

라이브 썸네일 4개 A/B 실측:

| 소재 | product(현행) | subject(교체) |
|---|---|---|
| 수납침대 | `'수납 침대'` → **2건** same 1 | `'수납침대'` → **5건** same 5 |
| 제모기 | `'크리스탈 제모기'` → same 5 **no 3** | `'제모기'` → **same 8 no 0** |
| 차량방향제 | same 8 | same 8 (차이 없음) |
| **강아지목욕** | `'강아지 목욕용 캠핑 침대'` → **same 0 no 5**(신혼여행 발리 영상) | `'강아지 목욕'` → **same 8** |

### 처방

`/api/lens/yt`가 `subject_tags_vision`(video_analysis.py:344)을 쓰게 교체.
이 함수는 프롬프트 목적 자체가 **"검색어로 이 영상이 잡히게 만드는 것"**이라 유튜브에 맞다.

- 검색어 우선순위: `subject` → `product`(기존 폴백 유지) → `_cn_keyword(caption)`
  → **새 경로가 죽어도 지금보다 나빠지지 않는다**
- `keywords` 첫 항목까지 2회 검색해 결과를 넓히고 **URL로 중복 제거**, 상한 12 유지
- `judge_same_product` 채점·정렬은 그대로. 비전 호출은 공통 경로에서 **1회**
  (subject가 비었을 때만 product를 추가 호출)
- 새 순수 헬퍼 `_yt_keywords(subject_result, cn_result, caption)`로 분리해 테스트 가능하게

**커밋** `373eb1023` — app.py 68줄 추가/20줄 삭제 + 테스트 179줄(11개).
로컬 전체 스위트 **3866 passed / 0 failed**.
