# 볼케이노 프리셋 전수 정리 (2026-11-01)

서버 커밋 `05ec118d`, 실행기 runner 128파일 기준. 도구 설명 목록에 없는 프리셋도 서버 setup 에 있어 총 43개다.

## 이 문서를 읽기 전에

- **실제로 한 편을 끝까지 만들어 본 프리셋은 0개다.** 서버 코드 실행이 자동 안전 검사에서 막혔다.
- 확인 깊이가 프리셋마다 다르다: 팩 읽음 14개 / 서버 응답·옛 기록 12개 / 작업 고정형 17개(코드 실행 없이는 내용을 못 봄).
- 팩도 전부 읽은 것이 아니라 안내 문서 위주로 읽고 코드는 검색했다. '없음'은 읽은 범위 기준이다.
- 인스타그램 쇼핑·인스타형 예능·예능픽·스케치코미디 등 숏클과 가까운 프리셋이 작업 고정형에 많다. 이쪽은 볼케이노 창에서 직접 돌려야 내용이 나온다.
- 옛 기록은 9월 자료이고 표본 1편인 것이 많다. 지금 서버와 다를 수 있다.
- 볼케이노 코드는 복사하지 않는다. 구조와 수치의 뜻만 참고한다(약관 판단은 사장님 몫).
