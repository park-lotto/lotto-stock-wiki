## 📋 해제 조건 공식 (Gemini 딥리서치 + 실증검증 확정 — 2026-06-02)

> **⚠️ 분류 기준: 코스피/코스닥 시장 구분 아님 → 지정 유형으로 구분**  
> 소스: KRX 시장감시규정 시행세칙 + Gemini 딥리서치 + SK하이닉스 실사례 교차검증

### 기본 원칙

```
지정 후 10영업일 경과 후부터 매일 체크 (롤링 기준).
아래 3가지 조건이 【모두(AND)】 해소되어야 다음 영업일 해제.
하나라도 살아있으면 이연(다음 영업일 재체크).
```

### KRX 급등 유형 (초단기급등 / 단기급등 / 중장기급등 / 투자주의반복)

| 조건 | 공식 | 해소 판정 |
|------|------|---------|
| ① T-5 조건 | 당일 종가 < T-5일 종가 × **160%** | < 기준가면 ✅ |
| ② T-15 조건 | 당일 종가 < T-15일 종가 × **200%** | < 기준가면 ✅ |
| ③ 최고가 조건 | 당일 종가 ≠ 최근 15영업일 최고가 | 오늘이 최고가 아니면 ✅ |
| **해제** | **① AND ② AND ③ 모두 ✅** | 다음 영업일 해제 |

### KRX 불건전수급 결합 유형 (단기상승&불건전 / 중장기상승&불건전 등)

| 조건 | 공식 | 해소 판정 |
|------|------|---------|
| ① T-5 조건 | 당일 종가 < T-5일 종가 × **145%** | < 기준가면 ✅ |
| ② T-15 조건 | 당일 종가 < T-15일 종가 × **175%** | < 기준가면 ✅ |
| ③ 최고가 조건 | 당일 종가 ≠ 최근 15영업일 최고가 | 오늘이 최고가 아니면 ✅ |
| **해제** | **① AND ② AND ③ 모두 ✅** | 다음 영업일 해제 |

> ★ T-5/T-15 = **Rolling** — 오늘 기준 5/15거래일 전 종가 (지정일 고정 아님)  
> ★ K-OTC 급등형: 170%/210% / 불건전형: 155%/185%  
> ★ 코넥스: 코스피 기준 준용

## 📋 재지정 메커니즘 (해제 후 10거래일 위험구간 — 2026-06-02 신규 확인)

> 해제 후 10거래일 이내, 아래 **4가지 동시 충족** 시 다음날 즉각 재지정

| 조건 | 내용 |
|------|------|
| ① 지정전일 초과 | 판단일 종가 > 최초 투경 **지정 전일** 종가 |
| ② 해제전일 초과 | 판단일 종가 > 투경 **해제 전일** 종가 |
| ③ 2일 급등 | 판단일 종가 ≥ 2일 전 종가 × **140%** (코넥스 120%) |
| ④ 시총 필터 | 전일 기준 코스피+코스닥 통합 시총 **100위 밖** 종목 |

> **실전 의미**: 해제 직후 10거래일이 "재지정 위험 구간"  
> → 해제 당일 무조건 추격 금지. 냉각장치(1일 투자주의) 통과 후 수급 확인 필수

## 투경 종목 주의 원칙

- 투경 지정 종목: 탑픽 스코어 -1 페널티 (수급 신뢰도 하락)
- 투경 해제 후 수급 재진입 확인 시 페널티 복구
- 투경 상태는 해당 stock/ 최신 이벤트 섹션에도 기록
- 해제 후 10거래일은 재지정 위험구간 — 수급 모니터링 강화
- `fetch_투경_kind.py` 스크립트로 매일 해제 조건 자동 분석 가능
