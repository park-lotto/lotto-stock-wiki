## 영상 기본 정보

| 항목 | 내용 |
|------|------|
| 제목 | **나는 자는 동안 직원 10명이 밤새 일한다** |
| 부제 | 잠드는 순간부터 깨는 순간까지 — 월급 0원 AI 팀 운영기 |
| 길이 | 8~9분 |
| 타입 | B타입 — 실제 화면 데모 중심 |
| 타겟 | 주식 중수 — "정보는 많은데 매일 정리가 안 되는 사람" |
| 핵심 감정 | "저거 나도 쓰고 싶다 / 어떻게 만든 거지?" |

### 핵심 개념 (v2 → v3 변경)
> "새벽 4시 한 번 실행" → **"잠드는 순간부터 깨는 순간까지 밤새 내내"**
>
> 미국 시장은 한국 밤 10시 30분부터 열린다.
> 텔레그램 뉴스, 미국 섹터 움직임, 증권사 리포트가 밤새 계속 들어온다.
> 직원들이 그걸 밤새 수집·분석·취합해서 아침에 브리핑을 올려놓는 구조.
> 이게 더 정확하고 더 강력하다.

```
[배경] 어두운 방 + 자는 사람 실루엣

[텍스트 작은 것] 내가 자는 8시간 동안
[포인트] 오른쪽 하단 — 쌓인 분석 로그 화면 (스크롤이 긴 터미널)
[색상] 다크 배경 + 민트/화이트 텍스트
```

### 씬 1 — 훅 (0:00~0:25)

**레퍼런스**: KR-01 "직원 5명 월급 빵원" 방식 + 밤새 개념으로 시작
**구조 결정**: 훅은 "자는 동안"으로 최강 대비 → 본론에서 24시간으로 확장

**대본**
```
"저 어젯밤 11시에 잠들었습니다.

그 순간부터 직원 10명이 일을 시작했어요.

밤새 미국 시장 보고
텔레그램 뉴스 읽고
리포트 분석하고
종목 스크리닝까지.

아침에 일어나니까 다 돼 있었어요.

월급은 0원입니다."
```

**화면**
```
[0:00~0:05] 밤 11시 — 잠자리 드는 모습 / 폰 내려놓는 장면
[0:05~0:15] 타임랩스 타임라인 (Remotion)
            밤 11:00 → 자는 사람
            밤 10:30 → 직원1 뉴스 수집 시작
            밤 11:30 → 미국 장 열림, 직원2 미국 시장 모니터링
            새벽 1:00 → 직원3 리포트 분석
            새벽 3:00 → 직원4 수급 스크리닝
            새벽 5:00 → 미국 장 마감, 직원5 취합 시작
            새벽 6:00 → 직원6 브리핑 생성
            아침 7:00 → 텔레그램 전송 완료
[0:15~0:25] 아침 — 폰 들고 텔레그램 확인하는 손
            "분석 완료. 오늘의 탑픽 🔴"
```

**왜 이 구조인가**
KR-01 분석 결과: 숫자(10명) + 충격 조건(월급 0원) + 내가 자고 있음.
여기에 **"밤새 내내"** 개념을 타임라인으로 시각화하면
"새벽 4시 한 번" 대비 임팩트가 3배.
미국 장, 텔레그램, 리포트가 밤새 들어온다는 사실 = 주식 하는 사람이면 바로 공감.

### 훅 → 24시간 확장 흐름 (핵심 설계 원리)
```
씬1  "자는 동안"      → 가장 강한 대비로 훅 (감정 자극)
씬4  "낮에도 즉시"    → "실제로는 24시간이었다" 점진적 공개
씬5  "24시간 내내"    → 클라이맥스에서 완전 확장 (진실 공개)
```
훅은 감정용(자는 동안), 클라이맥스에서 진짜 규모 공개.
이 순서가 극적 효과 최대화.
