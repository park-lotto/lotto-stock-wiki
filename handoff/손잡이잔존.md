## 2026-08-24 (회사PC) — 틀 삭제 후 띠 손잡이가 안 지워짐 ✅수정

사장님 제보: *"템플릿 했다가 삭제했는데 가운데 높이조절하는건 안지워짐"*
(스크린샷: 미리보기 한가운데 흰 막대가 남아 있음)

### 원인 — 숨기는 코드는 멀쩡했다. **삭제 경로에서 안 불렸다**

`syncFrameHandles()`는 틀이 없으면 손잡이 3개를 숨기도록 **이미 제대로 짜여 있었다**.
문제는 `renderTemplatePreview()`의 '틀 없음' 분기가 **그 함수를 부르기 전에 return**한 것:

```js
if(!t||(!t.id&&!t.frame)){ if(el) el.style.display='none'; return; }  // ← 여기서 나간다
...
syncFrameHandles();   // ← 그래서 여기까지 못 온다
```

틀 그림(`#tplPreview`)만 숨기고 손잡이는 손대지 않은 채 빠져나갔다. 손잡이는
`pv.appendChild`로 **미리보기에 직접 붙어 있어서** 틀 그림을 숨겨도 같이 안 사라진다.

★"고쳤는데 안 먹음"의 전형 — **고친 곳(syncFrameHandles)은 안 돌고, 도는 곳
(renderTemplatePreview)은 안 고쳤다.** 함수가 코드에 있다고 도는 게 아니다.

### 고친 것 — 한 줄

'틀 없음' 분기에서도 `syncFrameHandles()`를 부른다. 숨김 판단은 여전히
`syncFrameHandles` 한 곳에만 산다(0순위-B) — 여기선 부르기만 한다.

  "syncFrameHandles가 코드에 있다"는 검사로는 못 잡는다)
