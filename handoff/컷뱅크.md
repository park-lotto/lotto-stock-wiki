### B. 장면매칭 — 실측으로 방향이 바뀌었다

**① 검수판 가짜 빨간불 제거 (배포 완료)**
`visual_verb`("이 문장이 화면의 구체적 동작을 지목하는가")가 2026-07-20부터 **92% 채워져 있는데
검수판이 안 보고 있었다.** fit≤2인 칸 1,782개 중 **871개(49%)가 visual_verb=false** —
"친구네 집 갔다가 충격받았어요" 같은 이야기 문장에도 "영상이 부족합니다"가 떴다.
→ 실측 효과: 빨간불 **1,557 → 1,047개(33%↓)**, 빨간불 뜬 job **920 → 710개**.

**② 자동 재배치는 만들다가 폐기했다** ★중요
"안 쓴 구간 중 낱말이 더 겹치는 것으로 바꾸자"를 시뮬레이션까지 했으나(개선율 60%),
**사람이 실제로 바꾼 1,027건**을 대조하니 방향이 반대였다:
```
사장님이 버린 컷  낱말 겹침 0.82
사장님이 고른 컷  낱말 겹침 0.73   ← 오히려 낮다
겹침이 늘어난 교체 200건 · 줄어든 교체 270건
```
→ **낱말 겹침은 좋은 장면의 기준이 아니다.** 붙였으면 사장님 손이 더 늘었다.
3차(맞바꾸기·중복허용·인접구간)는 효과가 3%뿐이라 만들지 않았다.

**③ 1차 좁히기(`scene_match.narrow`) — 병합됨, 스위치는 꺼진 채**
장면 라이브러리가 예전에 꺼진 이유가 "컷 12개가 **모든 영상에 무조건** 붙어서"였다.
서버 실측으로 그 12개(튀김·삼겹살·서랍장·세탁기·감자튀김) 확인. 좁히기 검증:
```
캠핑 의자 대본 → []      (옛 사고가 막힌다)
감자튀김 대본  → [1, 5]  (맞는 것만)
```
⚠️`scene_library_auto_enabled`는 **아직 0**이다 — 컷이 14개뿐이라 켜면 예전과 같아진다.

**④ ★B1 프레임태깅 라이브 점화 (`frame_extract_enabled=1`)**
오늘 드러난 모든 문제의 **뿌리**였다:
```
태깅이 화면을 안 보고 배정 → 묘사가 한 칸 밀림
   → 그 어긋난 글자로 대본이 화면을 고름
      → 같은 모델이 자기 선택을 채점 → fit 5점
         → 사장님이 화면을 보고 절반을 갈아끼움(스왑 707/1343컷)
```
검증(0순위-A1 — 실제로 돌렸다):

  같은 4.5초 — 기존 "건물 실내에서 남녀가", B1 "핸들·발판 **근접 촬영**" ← 밀림 확인

## ⚠️ 이 트랙에서 밟은 함정

- **비로그인 curl로 라이브 화면을 판정하면 안 된다** — 랜딩 대문이 온다. 오늘 또 밟았다.
- **게이트가 실제 돈 버그를 잡았다** — 새 유료 라우트에 `check_and_count` + `_charge_or_402` +
  **환불 2줄(`refund_credit` · `_refund_points`)** 이 짝이다. 하나 빠지면 실패마다 잔액이 깎인다.
  `_PAID_SITES` 숫자도 함께 올려야 한다.
- **`except Exception: pass`는 예산이 있다**(`test_silent_except_budget`). 로그 한 줄로 바꿔라.
- **같은 함수 스코프에서 변수명 재사용 → TDZ**로 함수가 통째로 죽는다(`node --check`는 통과한다).
  `test_produce_tdz_scan`이 잡아준다.
- **추출 캐시 때문에 B1이 안 탄다** — 같은 소재를 재실행하면 캐시를 쓴다(구간 수가 같으면 의심).
  검증할 땐 `Store.get_extract`를 프로세스 안에서만 무력화(DB는 건드리지 말 것).
- **배포는 새벽 2~6시 시간창** — 낮에는 `touch /home/ubuntu/DEPLOY_NOW`. 다만 그건 pull만 풀고
  **웹 재시작 연기는 못 푼다**(고객 접속 중이면 최대 30분 대기, 그 뒤 강제).
- 정적 파일(html/js)은 **재시작 없이** 새로고침만 하면 반영된다(`_NoCacheStaticFiles`).
