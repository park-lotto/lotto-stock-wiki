## 함정
- 스토어판 Claude 데스크톱은 %APPDATA% 를 가상화(실제 LocalCache\Roaming) → 앱 밖 실행엔 실제 경로(core._real_path).
- mcp SDK·데스크톱은 MCP 서버를 KILL_ON_JOB_CLOSE 작업 개체에 넣는다 → 자식 프로세스 동반 사망.
- 엔진 단계표는 채널별 — reset_to 전에 registry.use(채널) 필수.
