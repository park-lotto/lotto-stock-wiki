## 자리·이름 (판 = 채널, 00_공통 표)
- 키치잇판(얜샷템): `G:\내 드라이브\칼카피영상\얜샷템 (연예인쇼핑) 재미썸홈스타일 대기중\kitchit\칼카피_얜샷템_kitchit_<인물><제품짧게>.mp4` (그 폴더 기존 이름 꼴을 따른다).
- 스타픽룸판: `…\칼카피영상\연예인레시피\starpickroom\` · 연예인레시피판: `…\연예인레시피\recipe\NN_<로마자>_<영어제품>.mp4`(예 `01_leehyejung_soybean_soup.mp4`).
- 번호 폴더(1번~7번) 꼴: `NN_제품영어.mp4`(두 자리 순번 = 폴더 마지막 번호 다음, 얜샷템은 연예인 로마자를 앞에).
- **mp4·md 만**(jpg 시트·썸네일은 안 올린다).

## 올리는 법 (PowerShell 만 — Git Bash `cp` 금지, 폴더가 파일로 덮인 사고)
```powershell
$src  = "C:\숏템_칼카피\yanshottem\하이브리드_<키>\<판>\render\final.mp4"
$stage = "$env:TEMP\claude\stage_<키>"; New-Item -ItemType Directory -Force $stage | Out-Null
Copy-Item $src "$stage\<드라이브 이름>.mp4" -Force
robocopy $stage "<드라이브 폴더>" "<드라이브 이름>.mp4" /NJH /NJS /NP     # /MIR 금지. 종료 코드 1 = 복사됨(정상)
(Get-Item $src).Length; (Get-Item "<드라이브 폴더>\<드라이브 이름>.mp4").Length   # 크기 같아야 한다
```
- 같은 편을 고친 새 판: 드라이브의 옛 파일을 `_이전판\<이름>_v2_<사유>.mp4` 로 **옮긴 뒤** 같은 이름으로 올린다. 드라이브 안에서 지우지 않는다.
- 다른 폴더로 옮길 때도 `Move-Item`(예 10-21 김나영 스타픽룸판 → 연예인레시피\starpickroom).
- 바탕화면 사본은 만들지 않아도 된다(만들었으면 13단계에서 같이 지운다).

## 서버 반영 확인
⚠ 구글 드라이브 앱(DriveFS)이 멈추면 G: 를 건드리는 명령이 전부 멈추고 로컬 `Copy-Item` 까지 멈춘다(10-21 — 앱 메모리 11.7GB, `Test-Path G:\` False). 납품용 사본은 Bash `cp`(C→C)로 `$env:TEMP\claude\stage_<키>` 에 만들어 두고, G: 가 살아나면 robocopy. 앱이 멈췄으면 `tasklist` 로 GoogleDriveFS PID 를 찾아 `taskkill /PID <번호> /F`(이름으로 끄기 금지) → `cmd //c start "" "C:\Program Files\Google\Drive File Stream\launch.bat"` 실행 → G: 는 10초쯤 뒤 잡힌다(10-21 사장님 "너가 직접 할 수 있잖아"). 로그 `Logs/drive_fs.txt` 마지막 기록 시각이 몇 시간 전이면 멈춘 것.

드라이브 앱 대기 작업 0 이어야 끝:
```
%LOCALAPPDATA%\Google\DriveFS\<계정번호>\metadata_sqlite_db  →  select count(*) from operations   (sqlite 읽기 전용 mode=ro 로 연다)
```
0 이 될 때까지 10초 간격으로 다시 잰다(보통 수십 초~2분). 느리면 드라이브 앱이 바탕화면 백업 중이라 그렇다(§0-2).

## 폐기된 옛 방식
- `run.py deliver` = 바탕화면 `칼카피영상/얜샷템/하이브리드/` 고정 → 지금 묶음에선 쓰지 않는다(드라이브가 정본).
- 바탕화면 정본·MD5 3자 대조 → 드라이브 크기 대조 + operations 0 으로 바뀜.
