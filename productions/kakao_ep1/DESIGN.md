## 1. 3가지 씬 모드 (가장 중요)

영상은 3가지 성격의 씬이 번갈아 나온다. **모드마다 디자인 규칙이 다르다.**

### 🟠 모드 A — AI 영상 (Veo 인트로/아웃트로, AI 호스트)
- 풀프레임 AI 호스트 영상 위에 **모서리 플로팅 카드**만 얹는다 (레퍼런스 114156, 130155, 157160)
- 카드 위치: 좌상단 / 우측 세로 리스트 / 하단 로어서드 — **얼굴 절대 가리지 않음**
- 영상은 어둡게 하지 않음. 카드 뒤에만 부분 그라디언트
- 하단 로어서드: 채널명 + 이탤릭 강조 태그라인 ("A space for motion to think" 스타일)

### 🔵 모드 B — 튜토리얼 (화면녹화 S2/S5/S7/S8/S9/S10)
- ⚠️ **화면녹화 위에 그래픽 절대 금지. 화면을 어둡게 하지 않는다.**
- 녹화 화면 = 주인공. **브라우저 창처럼 프레임에 담아 밝게** 보여준다
- 그래픽(STEP·콜아웃·브랜딩)은 **화면 바깥 여백(어두운 무대)에만** 배치
- 레이아웃: 어두운 무대 배경 → 상단 STEP 바 → 중앙에 밝은 녹화 프레임(테두리+그림자) → 하단 자막
- 강조가 필요하면 화면 위가 아니라 **여백의 화살표/콜아웃**으로 가리킴

### ⚫ 모드 C — 리모션 단독 (S3 철학, S6 MCP, S11 응용, 스팅)
- 순수 검정 무대. **큰 중앙 그래픽** (레퍼런스 187151 설치, 196152 $19, 159157 차트)
- Claude 오렌지 아이콘 중앙 + 거대 타이포 + 역동 애니메이션 자유롭게
- 여기서만 화면 전체를 그래픽이 채운다

## 2. 컬러 시스템

```
── 무대 ──
배경 베이스      #000000
배경 그라디언트   radial(circle, #0d1410 0%, #000 72%)
미세 그리드      rgba(170,255,0,0.04) 64px

── Claude CI (제품·신뢰) ──
오렌지          #D97757   ← Claude 아이콘·로고·설치·요금
오렌지 글로우    rgba(217,119,87,0.55)
오렌지 카드테두리 rgba(217,119,87,0.6)

── STOCKBRAIN (채널·데이터) ──
라임           #AAFF00   ← 수치·강조 키워드·완료·채널
라임 글로우     rgba(170,255,0,0.55)
NVIDIA 그린(차트) #7CFF00 (막대그래프 채움용 더 쨍한 톤)

── 보조 ──
화이트         #FFFFFF (메인 텍스트)
서브 그레이     rgba(255,255,255,0.6)
경고 레드       #FF4455 (BEFORE·부정 프레임·하단 베이스라인)
```

**규칙**: 한 화면에 오렌지+라임 동시 강조는 1:1 금지. 주인공 1색 + 보조 1색.
- Claude 제품 설명 씬 → 오렌지 주, 라임 보조
- 데이터·결과·채널 씬 → 라임 주, 오렌지 보조

## 6. 모드 B 튜토리얼 프레임 상세 스펙

```
┌─────────────────────────────────────────────┐ 1920×1080 어두운 무대
│ [CH·STEP 키커]      STEP 3 · 윈도우 버전      │ ← 상단 바 (h 120)
│                                               │
│   ╔═══════════════════════════════════════╗   │
│   ║                                       ║   │ ← 녹화 화면 (밝게)
│   ║      화면녹화 (1500×844, 밝게)         ║◄──┼── 라임/오렌지 테두리 2px
│   ║      어둡게 처리 안 함                  ║   │    + 그림자 + radius 14
│   ╚═══════════════════════════════════════╝   │
│   ▲ 여백에만 콜아웃: "여기 클릭 →"            │ ← 화면 밖에서 가리킴
│                                               │
│        [자막 바 48px]            STOCKBRAIN   │ ← 하단 자막 + 워터마크
```

- 화면은 원본 밝기 100% (dim 0)
- STEP 표시: 상단 바에 큰 글씨 + 진행 도트
- 콜아웃: 프레임 우측/하단 여백에 화살표로 화면 가장자리 지목
