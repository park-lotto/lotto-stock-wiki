브레인스토밍·설계 단계에서 섹션별로 "이대로 괜찮나요?" 매번 물어보지 말고, 방향이 이미 확인됐으면 바로 다음 단계로 진행할 것.

**Why**: 쇼핑쇼츠 꾸미기(단어별 강조) 기능 설계 중 데이터모델→렌더링로직→UI를 섹션별로 나눠 매번 승인 질문했는데, 사용자가 "묻지말고 고"라고 명시적으로 제지함. 이미 "고"로 여러 번 승인해온 흐름이면 추가 확인 없이 계속 진행하길 원함.

**How to apply**: [[feedback_keep_going_autonomous]]와 같은 맥락 — 방향이 정해졌으면 작은 판단은 바로 실행. superpowers:brainstorming 스킬의 "섹션마다 승인받기" 기본동작도 사용자가 명시적으로 빨리 가라고 하면 스킵하고 설계문서 작성까지 한번에 진행. 단, 설계를 다 건너뛰라는 뜻은 아니고 "질문 형태로 매번 멈추지 말라"는 것 — 결과물(설계문서, 코드)은 여전히 충실하게.
