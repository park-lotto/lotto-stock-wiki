# After Effects × Claude — 고퀄 영상 제작 계획

> 2026-07-25 수립 · 대상: 숏템박스 런칭 VSL(`out/숏템박스_1회차_VSL_대본.md`, S1~S10 / 10분)
> 배경: 코드(Three.js) 자체 렌더 데모가 퀄리티 기준 미달 판정 → **AE로 전환**

---

## 0. 핵심 아이디어 — "Claude가 이펙트를 발명하지 않는다"

앞선 실패의 원인은 **제가 이펙트를 0부터 만들려 한 것**입니다. 모션 디자이너가 몇 년에 걸쳐
다듬은 룩을 셰이더 몇 줄로 따라잡을 수 없습니다.

**이 계획의 구조는 반대입니다.**

```
프로가 만든 AE 템플릿(.aep)  ←  퀄리티는 여기서 온다 (사는 것)
        ↓
Claude가 ExtendScript(.jsx)로 조종  ←  자동화·반복·정확성은 여기서 온다 (짜는 것)
        ↓
aerender 헤드리스 렌더 → 프레임 읽고 검수 → 수정 → 재렌더
```

- **퀄리티 = 템플릿**(사거나 커스텀 제작)
- **속도·정확도 = Claude**(텍스트 치환·타이밍·대량 조립·검수 루프)
- 사장님은 **AE를 열지 않아도 됩니다.** 판단만 하시면 됩니다.

## 2. Claude ↔ AE 연결 방식 (기술 핵심)

### 2-0. ★조사 결과 — 브리지를 만들 필요가 없다 (2026-07-25 확인)

사장님 지적("이미 하는 사람 많을 것") 확인 결과 **맞았습니다.** 두 갈래가 이미 존재합니다.

**(A) 오픈소스 — `github.com/Dakkshin/after-effects-mcp`**
- ⭐506 · 포크 99 · **MIT 라이선스(무료)** · 최신 커밋 2026-03 (활발)
- 요구사항: After Effects **2022 이상**, Node.js 14+
- 구조: MCP 서버 ↔ **AE 안의 패널(`mcp-bridge-auto.jsx`)이 폴링**하며 명령 실행
  → **헤드리스가 아님.** 사장님은 AE를 켜고 패널만 열어두면 됨
- 이미 되는 것: 컴포지션 · 텍스트/도형/솔리드/**카메라**/널 레이어 · **키프레임** ·
  **익스프레션** · 마스크 · **2D/3D 전환** · 블렌드 모드 · 트랙 매트 · 복제/삭제 · 배치 속성
- ⚠️ **`run-script`는 임의 실행이 아니라 화이트리스트 20개 전용**(2026-07-25 실측 정정)
  → 우리가 브리지에 **`executeScript` 케이스를 추가**해 해결함
- ❌ **렌더 툴은 없음** → aerender는 별도로 붙여야 함

**(B) 상용 — Higgsfield MCP Bridge** (사장님이 보내주신 영상 `ZsS7ULEcMSI`)
- Higgsfield의 AI 생성 엔진을 AE·Premiere 안에서 Claude로 호출하는 상용 플러그인
- ⚠️ **주의**: 그 영상의 결과물이 좋은 건 **Higgsfield의 AI 영상 생성** 덕이지
  MCP가 퀄리티를 만든 게 아님. MCP는 조종 통로일 뿐 — 퀄리티는 여전히 소재·템플릿에서 온다.

→ **채택: (A) 오픈소스 먼저.** 무료이고 우리가 필요한 조종 범위를 이미 덮는다.
   (B)는 AI 생성 소재가 필요해지면 그때 별도 검토.

### 2-1. 조종 통로 (수정됨)
| 용도 | 수단 |
|---|---|
| 프로젝트 생성·수정 | **after-effects-mcp** (MCP 툴 호출) |
| 템플릿 .aep 치환 등 고급 조작 | **브리지에 추가한 `executeScript`** (파일 프로토콜로 .jsx 주입) |
| 렌더 | `aerender.exe -project X.aep -comp "Main" -output out.mov` (**직접 붙임**) |
| 검수 | 렌더 결과 → ffmpeg 프레임 추출 → Claude가 이미지로 읽음 |

### 2-2. 자동 루프 (이게 이 계획의 심장)
```
① Claude가 .jsx 작성/수정
② AfterFX -r 로 실행 → .aep 갱신
③ aerender 로 렌더 (검수용은 저해상도·짧은 구간)
④ ffmpeg로 프레임 추출 → Claude가 눈으로 확인
⑤ 문제 발견 → ①로
```
※ 이 루프는 **오늘 코드 데모에서 이미 성립을 증명했습니다**(렌더→육안→결함 4개 발견→수정→재렌더).
   바뀌는 건 렌더 엔진이 WebGL → AE라는 점뿐입니다.

### 2-3. 헤드리스 안정화 (필수 — 안 하면 멈춥니다)
| 위험 | 대비 |
|---|---|
| ExtendScript 오류가 **대화상자**로 떠서 프로세스 정지 | `app.beginSuppressDialogs()` + try/catch 전면 + 로그를 파일로 기록 |
| 렌더 무한 대기 | 프로세스 타임아웃 후 강제 종료 + 재시도 |
| 폰트 미해결로 조용히 다른 폰트 대체 | 렌더 후 **프레임 육안 확인 의무화**(4단계) |
| AE가 이전 프로젝트를 물고 있음 | 매 실행 `app.newProject()` 또는 전용 임시 .aep |
