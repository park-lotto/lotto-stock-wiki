- 대비("~와 달리") 칸은 **없다**. 공개 직후 바로 "이게 진짜 말도 안 되는 게".

- 고조1이 전체의 절반(8줄). 핵심 3줄(순간→지옥→없애버림) 뒤에 장면 풀이 4줄이 이어져 "작은 이야기"가 된다.
- 청자에게 말 거는 반말 0. 줄 끝은 ~는데 / ~거 / ~다고 / ~라 / ~고 / ~면.
- 346자 = 약 60초. 우리 이야기 작가 기본 목표 25초와 길이가 크게 다르다.
