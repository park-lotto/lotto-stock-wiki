# A안 본사 한 동 제작 계획

**Goal:** 승인 A안의 중앙 본사 한 동을 실제 Blender 모델로 제작하고 낮·밤·입구·로비 렌더로 검토한다.
**Architecture:** 기존 캠퍼스를 덮지 않는 `ML_HQ_A_v1` 장면. 석재 프레임, 높은 중앙 아트리움, 측면 업무동, 계단형 옥상 정원. 건물 주변 앞마당만 포함한다.
**Tech Stack:** 설치된 Blender 4.5.9, 실제 MCP SDK, Cycles/OptiX. 기존 회사운영플랫폼 트랙.

- [ ] `company_ops/blender/hq_verify.py`: 장면·필수 구조·카메라 검사를 먼저 만들고 아직 장면이 없어 실패하는지 실행.
- [ ] `company_ops/blender/hq_build.py`: 기존 장면을 보존하고 새 장면 생성. 베벨 석재, 얇은 금속 프레임, 유리, 실제 깊이의 로비, 층별 테라스/조경, 입구 계단과 수경시설 제작. 원본 이미지에서 읽을 수 없는 치수는 이번 가상 건축의 설계값이다.
- [ ] MCP로 생성 → `hq_verify.py` 재실행. 같은 이름 장면이 있으면 덮어쓰지 않고 거절.
- [ ] `company_ops/blender/hq_render.py`: 별도 백그라운드 프로세스에서 저장된 장면을 열어 주간/야간/입구/로비 PNG와 GLB 출력. 모든 경로는 절대경로.
- [ ] 렌더를 직접 열어 실루엣, 창의 깊이, 입구 가독성, 재질/노출/프레이밍 확인. 결함은 별도 수정본으로 보완.
- [ ] 별도 `/hq/` 검토 화면에서 결과를 표시. 기존 `/campus/` 및 실제 업무 시스템 미변경. 브라우저에서 직접 확인 후 handoff/트랙 커밋.

완료 범위는 건물 첫 제작본이다. 전체 회사, 실제 워커, 이동 충돌, 운영 데이터 연결을 완료했다고 하지 않는다. 디자인 최종 승인은 사용자 검토 후다.
