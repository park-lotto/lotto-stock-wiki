## 2026-11-03 (TheRose PC) 관제 311 — 일본어 윈도에서 설치 묶음 풀기 실패

**증상**: 일본 거주 회원(kyupa) 설치가 `tar.exe: Archive entry has empty or unreadable filename ... skipping` → `[숏클] 설치를 마치지 못했습니다: 풀기 실패(tar 1)`.

**뿌리**: 윈도 내장 tar.exe(bsdtar)는 zip 의 UTF-8 이름을 **시스템 ANSI 문자표**로 바꿔 쓰는데, 못 바꾸는 이름은 건너뛰고 rc=1.
묶음(1.0.0) 비ASCII 이름 309개(효과음 팩 147·엔진 147 등) — CP949 로는 전부 되고 CP932(일본)로는 309/309 불가(실측).

**수리(판단 주인 = .NET ZipFile 풀기, 두 길 같은 방법)**
- `installer/install.ps1` 풀기 → `[IO.Compression.ZipFile]::ExtractToDirectory` (시작.md 한 줄 설치 = 서버 `/api/claude/start.ps1` 가 이 파일을 그대로 내보냄 → 병합·배포 즉시 반영)
- `installer/mcpb/launcher.js` `unpack` → powershell 로 같은 .NET 풀기(경로는 환경변수로) — **다음 묶음/연결 파일 판부터** 반영

**결과물 검사**: `py -I installer/win/test_unzip_unicode.py --zip <shortem-win-x64-*.zip> [--script 옛ps1] [--launcher 옛js]`
- 묶음에 태국어 이름 파일(CP949·CP932 모두 불가)을 넣어 이 PC 에서 일본 PC 꼴을 재현
- 고치기 전: ps1·launcher 둘 다 `tar 1` 실패(회원 화면과 같은 문구) / 고친 뒤: 두 길 모두 11,208개·`packs/sfx/팩01`·태국어 파일 풀림, launcher 길은 설치 끝까지 ok(도구 10개)
- ps1 길은 1.0.0 묶음이 11-02 이전 판이라 `server/guide/MEMBER_GUIDE.md` 없음에서 멈춤(이번 수정과 무관, 그 뒤는 실제 바탕화면에 쓰므로 안 돌림)
- `shortem_client/test/noexe_install_check.js` leftover 판정: `Shortem*` 잔해만 본다(풀기용 파워쉘이 LOCALAPPDATA\Microsoft 캐시를 만든다)
