- 제목은 짧은 현상 제시형이에요("○○의 근황", "○○ 현황", "누가 돈을 버나", "이딴 게 선진국 교육?").

## 2. 소재를 얻는 방법 (관찰한 패턴)
| 단계 | 하는 일 | 근거 |

| ① 이번 주 뉴스 | 업로드(매주 토 11시) 전 1주 안에 크게 나온 국내 보도 1건을 출발점으로 삼는다 | R2(10/24 업로드): 10/23 헤럴드경제 '김정은 사망설' / R3(10/17): 9월 시작 프랑스 시위가 10월 전국 확산 / R1(10/31): 배달앱 결제액·라이더 기사 |
| ② 체감 현상 → 통념 | 사람들이 체감하는 현상과 흔한 해석(통념)을 찾는다 | R1 '콜이 말랐다' → '마운자로 때문?' / R3 '공부 싫어서 시위?' |
| ③ 통념 뒤집는 숫자 | 통념을 반박하는 공식 통계를 찾는다 | R1 배달앱 결제액 역대 최고(와이즈앱) |
| ④ 원인 3~5개 분해 | 챕터마다 `대주제 : 원인 n` 하나 | R1: 고용 불안 → 경제 양극화 → AI → 폐업 → 실질임금 → 고정지출 |
| ⑤ 출처 쌓기 | 화면에 정밀 수치와 출처를 띄운다 | 아래 3절 |

## 4. 매주 소재 찾기 루틴 (이 PC에서)
1. **월~화: 후보 모으기** — `jev_research`로 갈래별 검색 4번 (예: "이번 주 ○○ 국가 경제 위기", "실적 부진 폭락 기업", "한국 ○○ 역대 최다/최저", "이번 주 국제 정치 이슈 구조")
   - 키워드 힌트: `역대 최대`, `17년 만에`, `반토막`, `폭락`, `증발`, `처음으로`, `○○ 현황`, `근황`
2. **화: Jev 판정** — `jev-screen.ps1 -Channel "지식한입 롱폼(시사·경제 해설)"`, 종합 점수순 표 → 통과(≥60)만 진행, 보류는 사람 판단
3. **중복 확인** — 레퍼런스 채널이 최근 4주 안에 같은 소재를 다뤘는지 확인(프랑스 건처럼). 겹치면 각도를 바꾸거나 다른 소재로
4. **수: 사실기록** — 출처 붙은 사실 30~60개(`사실기록_○○.md`) → 헌법 보고서 → 대본
5. **목~금: 제작** — 프리셋 README 순서대로
6. **토 11시 업로드**

## 5. 좋은 소재의 조건 (점검표)
- [ ] 1주 안에 보도된 '이번 주' 이야기인가
- [ ] 흔한 통념이 있고, 그걸 뒤집는 숫자가 있는가
- [ ] 원인을 3개 이상의 챕터로 나눌 수 있는가
- [ ] 공식 통계·기관 자료가 3개 이상 있는가
- [ ] 한국 시청자에게 "남의 일이 아니다"로 이어지는가
- [ ] 특정인을 단정·비난하지 않고 제도·구조로 설명할 수 있는가(Jev 명예훼손 낮음)
