규칙 파일(CLAUDE.md 등)에 이미 명시한 절차를, 사용자에게 다시 "이렇게 입력하세요" 하고 외우게 시키지 마라.
사용자가 기억해야 할 형식을 만드는 순간 그 자동화는 실패한 것이다.

**Why**: 2026-07-15 트랙격리 작업에서 CLAUDE.md 세션시작 블록에 "트랙을 못 정했으면 사용자에게
어느 트랙인지 확인"까지 다 박아놓고도, 사용자에게 "각 창에서 `{트랙명} 트랙 이어서`라고 하세요"라고
안내했다. 사용자가 "이게 무슨 말이야?" → "클로드 md에 명시하고 읽고 시작하라 하면 안 되나"라고
지적. 사장님이 맞았다. 규칙은 이미 파일에 있었고, 사용자는 그냥 "이어서 하자"만 하면 세션이
알아서 목록 보고 묻게 돼 있었다. 내가 불필요한 주문을 발명해 혼란만 줬다.

**How to apply**:
- 규칙을 파일에 넣었으면 → 사용자에겐 "그냥 평소대로 말씀하시면 됩니다"라고 하라.
- 지름길(요령)을 알려줄 땐 "이렇게 하셔도 되고, 안 하셔도 알아서 됩니다"라고 선택임을 명시하라.
- 사용자에게 안내문을 쓰기 전에 자문: "이거 규칙 파일이 이미 처리하나?" 그렇다면 안내를 지워라.
- 줄임말·내부용어(창/트랙/N개씩) 금지. 사용자는 내 작업 맥락을 안 본다. [[feedback_묻지말고_진행]]
