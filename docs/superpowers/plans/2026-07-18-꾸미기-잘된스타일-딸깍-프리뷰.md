# 꾸미기 "잘된 스타일 딸깍" + 공용 장면 프리뷰 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 꾸미기 미리보기를 "장면(비트)마다 ◀▶로 넘겨가며 그 영상 프레임 위에 헤드카피·자막이 어떻게 나오는지" 보여주는 공용 프리뷰 스테이지로 확장한다. 스타일 딸깍 갤러리(FULL_PRESETS)·기본 자동적용(applyDefaultStyleOnEntry)은 **이미 구현돼 있어 재사용**한다.

**Architecture:** 서버에 비트별 프레임+자막을 주는 라우트 2개를 추가(기존 poster 라우트 로직을 전 비트로 일반화). 프론트는 기존 미리보기 DOM(`#hcPreviewBg` 배경 img + `#capPreviewText` 자막)을 그대로 쓰되, ◀▶ 스텝퍼가 배경 img.src와 자막 텍스트를 비트별로 교체한다. 새 렌더 경로는 만들지 않는다.

**Tech Stack:** FastAPI(app.py), ffmpeg(프레임 추출), 순수 JS(produce.html), pytest(서버), Node 문자열 파싱 테스트(JS).

## Global Constraints
- 대상 트랙 = 모션효과. 코드 편집은 전부 `.tracks/모션효과/...` 절대경로.
- **저장소 함정**: pytest에서 실 ffmpeg를 부르는 `subprocess.run`은 반드시 `stdin=subprocess.DEVNULL`(안 하면 Windows WinError 6). 기존 poster 라우트(app.py:2140)는 이게 없지만 프로덕션 전용이라 안 터졌다 — 새 코드는 테스트가 부르므로 DEVNULL 필수.
- **produce.html은 pytest가 없다** = JS는 Node 문자열 파싱 테스트로 잠그고, 최종 게이트는 **라이브 육안**. `node --check`로 문법만 봉인.
- **새 렌더 경로 금지**: 프리뷰의 헤드카피·자막 그리기는 기존 `updateHC`/`updateCaption`(DOM/CSS 근사)을 그대로 쓴다. 최종 영상 렌더(_segmented_drawtext)를 프리뷰가 다시 만들지 않는다.
- **produce.html 4트랙 동시편집**: 장면라이브러리(scene-cutaway)·자막싱크(음성프리뷰)와 겹치지 않게, **미리보기(#hcPreview) 블록과 그 아래 스텝퍼**에 국한해 편집. FULL_PRESETS/스타일카드 영역은 건드리지 않는다.
- 공용 프리뷰 스테이지는 이 트랙이 최초 구현·소유. 함수는 페이지 독립적으로(전역 헬퍼) 만들어 타 트랙이 재사용 가능하게 한다.

```python
def _extract_beat_frame(work, beat, out_path):
    """beat.primary 클립의 start 시각 프레임 1장을 9:16(1080x1920)로 out_path에 저장.
    소스 영상이 없으면 False(파일 안 만듦). 프로덕션 poster 로직을 비트 단위로 일반화."""
    import subprocess
    pr = beat.get("primary") or {}
    vid = pr.get("video_id")
    ss = float(pr.get("start") or 0)
    src = None
    if vid:
        src = next((work / vid).glob("*.mp4"), None)
    if src is None:
        src = next(work.glob("final.mp4"), None) or next(work.glob("mix_raw.mp4"), None)
    if src is None:
        return False
    out_path.parent.mkdir(parents=True, exist_ok=True)
    subprocess.run(
        ["ffmpeg", "-y", "-ss", str(ss), "-i", str(src),
         "-vf", "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920",
         "-frames:v", "1", str(out_path)],
        capture_output=True, stdin=subprocess.DEVNULL)
    return out_path.exists()


@app.get("/api/produce/mix/beats_preview/{job_id}")
def api_produce_mix_beats_preview(job_id: str):
    """꾸미기 프리뷰용 — 비트별 자막(narration)과 개수. 프레임은 beatframe 라우트가 따로 서빙.
    매칭(edit_plan) 전이면 빈 목록."""
    job = Store(DB_PATH).get_mix_job(job_id)
    beats = ((job or {}).get("edit_plan") or {}).get("beats") or []
    total = len(beats)
    out = [{"i": idx, "total": total, "caption": b.get("narration", "")}
           for idx, b in enumerate(beats)]
    return {"beats": out}


@app.get("/api/produce/mix/beatframe/{job_id}/{i}")
def api_produce_mix_beatframe(job_id: str, i: int):
    """i번째 비트의 영상 프레임 1장(캐시). 없으면 404 → 프론트는 흰 배경 폴백."""
    job = Store(DB_PATH).get_mix_job(job_id)
    beats = ((job or {}).get("edit_plan") or {}).get("beats") or []
    if i < 0 or i >= len(beats):
        return JSONResponse(status_code=404, content={"ok": False})
    work = _MIX_WORK_DIR / job_id
    out = work / "beatframes" / f"{i}.jpg"
    if not out.exists():
        _extract_beat_frame(work, beats[i], out)
    if not out.exists():
        return JSONResponse(status_code=404, content={"ok": False})
    return FileResponse(str(out), media_type="image/jpeg")
```

```javascript
// ── 🎞 공용 장면 프리뷰 스텝퍼 — 비트마다 프레임+자막 넘겨보기(TTS·검수판 트랙도 재사용) ──
let BEATS_PREVIEW=[];   // [{i,total,caption}]
let BEAT_IDX=0;
async function loadBeatsPreview(){
  const st=document.getElementById('beatStepper');
  if(typeof MIX_JOB==='undefined' || !MIX_JOB){ if(st) st.style.display='none'; return; }
  try{
    const r=await fetch('/api/produce/mix/beats_preview/'+MIX_JOB);
    const d=await r.json(); BEATS_PREVIEW=d.beats||[];
  }catch(e){ BEATS_PREVIEW=[]; }
  if(!BEATS_PREVIEW.length){ if(st) st.style.display='none'; return; }
  if(st) st.style.display='flex';
  BEAT_IDX=Math.min(BEAT_IDX, BEATS_PREVIEW.length-1);
  showBeat(BEAT_IDX);
}
function showBeat(i){
  if(!BEATS_PREVIEW.length) return;
  BEAT_IDX=(i+BEATS_PREVIEW.length)%BEATS_PREVIEW.length;
  const b=BEATS_PREVIEW[BEAT_IDX];
  // 배경 = 그 비트 프레임(실장면 배경 켜져 있을 때만; 로드 실패는 흰 배경 폴백)
  const bg=document.getElementById('hcPreviewBg');
  const sb=document.getElementById('sceneBg');
  if(bg && sb && sb.checked){
    bg.onerror=()=>{ bg.style.display='none'; };
    bg.src='/api/produce/mix/beatframe/'+MIX_JOB+'/'+BEAT_IDX;
    bg.style.display='block';
  }
  // 자막 = 그 비트 대본, 헤드카피는 비트 공통이라 그대로
  PREVIEW_CAP_TEXT=b.caption||'';
  if(typeof updateCaption==='function') updateCaption();
  const cnt=document.getElementById('beatCount');
  if(cnt) cnt.textContent=(BEAT_IDX+1)+' / '+BEATS_PREVIEW.length+' 장면';
}
function stepBeat(d){ if(BEATS_PREVIEW.length) showBeat(BEAT_IDX+d); }
```
