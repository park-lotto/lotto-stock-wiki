## 1. 반드시 받을 것 (검색어 그대로 쓰세요)

### A. 한글 되는 키네틱 타이포 팩 — **최우선**
- 검색어: `kinetic typography pack`, `title animation pack`, `text animation presets`
- **선정 기준(중요)**
  - [ ] **폰트 교체가 자유로운가** — 아웃라인(도형)으로 굳어 있으면 한글 못 넣음 ❌
  - [ ] 글자 단위 애니메이션(Text Animator) 기반인가 → 한글 자동 대응 ✅
  - [ ] "Editable text" / "Font can be changed" 표기 확인
- 쓰이는 곳: S1·S2·S3·S5·S8 자막 전체 (VSL의 뼈대)

### B. 형광펜 밑줄 / 강조 마커
- 검색어: `handwritten underline`, `marker highlight`, `scribble annotation`
- 쓰이는 곳: **S3 페인 짚기** — "템플릿 똑같음", "성우 티남" 지적할 때
- 기준: [ ] 색상 변경 가능 [ ] 길이 조절 가능

### C. 카운트업 숫자 + HUD 게이지
- 검색어: `number counter`, `data infographic`, `HUD circle loader`
- 쓰이는 곳:
  - **S1** "180분 → 8분" 광속 카운트다운
  - **S5 챕터7** 최종 렌더 진행 게이지
- 기준: [ ] 숫자를 텍스트로 바꿀 수 있는가(이미지로 굳은 것 ❌)

### D. 트랜지션 팩 (휩팬·줌)
- 검색어: `transitions pack after effects`, `whip pan transition`, `zoom transition`
- 쓰이는 곳: S1~S10 챕터 전환 전부
- 기준: [ ] 모션 블러 포함 [ ] 프리셋 방식(드래그로 얹기)

### E. 3D 카드 스택 / 리뷰 팝업
- 검색어: `testimonial cards`, `review popup`, `chat bubble animation`
- 쓰이는 곳: **S6 증거** — 베타테스터 카톡 후기 촤르륵
- 기준: [ ] 이미지 교체 슬롯이 3~5개 이상

### F. (선택) 로드맵 / 트리 확장 모션
- 검색어: `roadmap animation`, `timeline infographic`
- 쓰이는 곳: **S7 확장** — 짤쇼핑→연예인쇼핑→네이버클립→쓰레드

## 2. 음원·효과음도 같이 받으세요 (같은 구독에 포함)

- **BGM**: 검색어 `corporate tension`, `dark trailer`, `minimal tech` — S8 오퍼 구간용 긴장감
- **효과음**: `whoosh`, `click ui`, `impact hit`, `notification pop`
  → 대본이 "0.5~1.5초 빠른 컷"이라 **컷마다 whoosh가 들어가야 리듬이 삽니다**
- 이건 템플릿보다 체감 효과가 큽니다. 잊지 말고 받으세요.

---

## 3. 라이선스 확인 (사장님이 직접 확인하실 것)

Envato Elements 공식 표기 기준:
- ✅ 상업적 사용·유튜브 수익화 **가능**
- ✅ 구독 해지 후에도 **이미 라이선스한 프로젝트는 영구 사용 가능**
- ❌ 에셋 자체를 재판매·재배포하는 것은 불가 (우리 용도와 무관)
- ⚠️ 항목마다 개별 라이선스를 발급받는 구조 → **다운로드 시 프로젝트명 지정**할 것

---

## 4. 다운로드 후 Claude가 할 일

1. 각 `.aep` 구조 분석 → **어느 레이어를 무슨 이름으로 치환하는지 매핑표** 작성
2. 한글 폰트 주입 테스트 (PostScript명 `MalgunGothic` 기준)
3. 1컷 시험 렌더 → 프레임 육안 검수 → 사장님 확인
4. 통과한 것만 파이프라인에 편입

> 받으신 파일은 한 폴더에 모아만 주시면 됩니다. 경로 알려주시면 제가 전부 뜯어보겠습니다.
