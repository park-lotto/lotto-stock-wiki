# 자막꾸미기 ↔ 최종렌더 어긋남 (2026-08-31)

사장님 제보: **"자막꾸미기랑 렌더링이랑 검정으로 하니까 이상하게 나온다 / 화이트는 괜찮"**
→ 흰 자막에선 검은 테두리가 원래 그럴싸해 안 걸렸고, 검정 자막에서 글자가 뭉개져 발각.

## 고친 것 (5건 — 전부 미리보기 ≠ ffmpeg 렌더)

1. **두께 0인데 렌더는 검정 테두리 9px 강제** ★진짜 원인
   `borderw=max(1, _ui_px(outline_w, 9))` — `_ui_px`가 0을 "값 없음"으로 보고 기본값 9를 되살렸다.
   → `_outline_parts()` 하나로 뽑고 `zero_ok=True`. 0이면 테두리를 **아예 안 붙인다**.
   실측: 두께0 → `[]` / 미지정 → `borderw=9` / 두께5 → `borderw=8`(1080 환산).
2. **테두리 모양**: 자막 미리보기는 대각선 4방향 text-shadow였다 → 두꺼워지면 검은 사본이 글자 **위로**
   올라와 획을 메운다(헤드카피가 2026-08-20에 겪은 그 사고). `-webkit-text-stroke`+`paint-order`로 통일.
3. **박스 모서리**: 미리보기 `borderRadius:6px`(헤드카피는 30px) / 렌더 `drawbox`·`box=1`은 **각진 사각** → 0으로.
4. **강조 단어 박스가 설정 무시**: `@0.90`·`boxborderw=12` 하드코딩 → box_opacity·box_pad를 쓴다.
5. **그림자 질감**: 미리보기는 blur, ffmpeg `shadowx/y`는 blur 없음 → 딱딱한 오프셋으로.
