Remotion 씬을 새로 만들기 전에 반드시 사용자에게 레퍼런스를 물어본다.

**규칙:**
"이 씬 어떤 스타일 레퍼런스로 만들까요?" → 선택지 제시 → 확인 후 시작

**현재 등록 레퍼런스:**
- `국민성장펀드`: channel/strategy/remotion_레퍼런스_국민성장펀드.md
  - 이모지 100~140px, 메인텍스트 90~160px, 네온틸 #00FFD0, Phase전환, 자막바 16%, elastic 팝

**Why:** 스타일이 달라지면 영상 일관성이 깨짐. 먼저 확인하면 수정 반복이 줄어듦.

**How to apply:** 사용자가 새 Remotion 씬 제작 요청 시 → 레퍼런스 목록 제시 후 선택받고 시작.
새 좋은 씬 나오면 레퍼런스로 등록 제안.
