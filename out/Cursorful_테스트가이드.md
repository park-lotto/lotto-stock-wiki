# Cursorful 무료 테스트 가이드 (30초)

> 2026-07-25 · 목적: **"자동 줌이 숏템메이커 화면에서 실제로 예쁘게 걸리나"** 하나만 확인
> 비용 0원 · 회원가입 불필요

---

## ⚠️ 먼저 알아둘 것

| | |
|---|---|
| **무료판은 비상업용** | 지금은 **테스트만** 합니다. 실제 VSL 녹화는 Pro($79 일회) 결제 후 |
| **크롬 확장** | Chrome / Edge / Brave에서 동작 (Firefox ❌) |
| **브라우저 안에서만 자동 줌** | 숏템메이커가 웹앱이라 문제없음 |

---

## 1. 설치 (1분)

1. Chrome 웹스토어에서 **"Cursorful"** 검색
   - 직접 링크: https://chromewebstore.google.com/detail/cursorful/eihpmapodnppeemkhkbhikmggfojdkjd
2. **[Chrome에 추가]** 클릭
3. 주소창 오른쪽 퍼즐 아이콘 → Cursorful **고정(핀)** 해두면 편합니다

> 회원가입·결제정보 입력 없습니다.

---

## 2. ★가장 중요한 것 — 자동 줌이 걸리는 조건

공식 FAQ에 명시된 규칙입니다:

> **3초 안에 클릭이 2번 이상** 일어나야 자동 줌이 발동합니다.
> (클릭 한 번마다 줌하면 어지러워서 일부러 이렇게 만들었다고 합니다)

**→ 천천히 한 번씩 클릭하면 아무 일도 안 일어납니다.** "안 되네?" 하고 오해하기 딱 좋은 지점입니다.

**테스트할 때는 의도적으로 빠르게 두세 번 클릭하십시오.**

---

## 3. 무엇을 녹화할까 — S5 챕터1 흐름 (30초)

대본의 **"레퍼런스 랭킹 → 담기"** 구간이 제일 대표적입니다.

```
① 숏템메이커 로그인 → 레퍼런스 랭킹 페이지
② 카테고리 버튼 클릭 (여기서 빠르게 2번)
③ 마음에 드는 영상 카드 위로 이동
④ [담기] 버튼 빠르게 클릭 (2번 이상)
⑤ 담긴 것 확인
```

30초면 충분합니다. **길게 찍지 마십시오** — 우리가 볼 건 "줌이 예쁜가"지 내용이 아닙니다.

---

## 4. 녹화 절차

1. 숏템메이커 화면을 브라우저에 띄웁니다
2. Cursorful 아이콘 클릭 → **[Start Recording]**
3. 위 ①~⑤ 흐름을 30초 안에 (클릭은 빠르게 2번씩)
4. 정지 → **에디터가 자동으로 열립니다**
5. 에디터에서 확인·조정:
   - 타임라인에서 **줌 위치·깊이·타이밍 수정 가능**
   - **Background** — 배경 색/이미지 교체
   - **Hide browser frame** — 탭·북마크바 숨기기 (지저분한 거 정리)
6. **[Export]** → MP4 저장

---

## 5. 볼 것 (판단 기준)

| 확인 | 좋으면 |
|---|---|
| 클릭할 때 **그 자리로 부드럽게 줌**되는가 | ✅ ①②번 효과 해결 |
| 커서 움직임이 **매끄럽게 다듬어졌는가** | ✅ 손 떨림 제거됨 |
| 줌이 **과하거나 어지럽지 않은가** | 에디터에서 깊이 조절 가능 |
| 배경 얹으니 **화면이 살아나는가** | ✅ AE 목업 템플릿 불필요 |

**이 4개가 괜찮으면 → AE 템플릿에서 "앱 프로모/목업" 계열을 안 사도 됩니다.**

---

## 6. 끝나면

MP4를 **바탕화면에 저장**하시고 파일명만 알려주십시오.
제가 프레임을 뽑아 보고 **AE에서 뭘 더 얹어야 할지** 판단해서 알려드리겠습니다.

> 하나 안 맞는다고 방향이 틀린 건 아닙니다.
