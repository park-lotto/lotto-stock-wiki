## 확인 못 한 것
1. 쿠팡·네이버쇼핑 상품 페이지 **직접 열람 0건**(접속 차단). 가격·리뷰 수·재고·판매자는 전부 검색 결과 문구.
2. 5편 모두 '같은 제품의 국내 판매'는 **확인 못 함**. 1편만 같은 종류 상품 1건, 4편만 비슷한 종류 1건(11번가 카이엔).
3. 쿠팡 4L 보온 물병, 포르쉐 911 라이선스 유아 전동차, 고양이 엉덩이 빵클립 완제품 — 각각 검색어를 바꿔 해 봤으나 안 나옴. 없다는 증명은 아님(검색 도구 한계).
4. 알리익스프레스·11번가 직접 검색은 못 함(11번가는 검색 결과 문구로만 접함).
5. 영상 후보의 **제품 등장 구간(초)**, 같은 모델 여부, 다른 브랜드 혼입 여부는 영상을 안 봐서 모름(메타만).
6. 틱톡·릴스 후보는 조사 못 함(유튜브 검색만 사용).
7. 영상 재사용 허락/저작권, '써 보니 좋은 점'의 실제 리뷰 근거(리뷰 본문)는 확보 못 함.
8. 쿠팡 검색 결과 노출 순서·실제 국내 후기 수는 모름.
