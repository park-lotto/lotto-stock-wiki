## 엑셀 시트 구조 이해

모든 데이터 시트의 컬럼 구조는 동일하다:

| 컬럼 | 의미 |
|------|------|
| [1] | 년월 (예: 2026년05월) |
| [6] | 일평균 수출금액 (달러) |
| [7] | MoM (전월 대비) |

| [10] | **판가 YoY** ← 핵심 |

> 소수 표현: 0.22 = +22%, -0.05 = -5%

## 신호 판단 기준

### 🔴 즉시 sector/stock 업데이트 (강력 신호)
- **판가 YoY 부호 전환**: 음 → 양 (업사이클 시작), 양 → 음 (피크아웃 경고)
- **물량 YoY 절대값 변화 > ±30%p** (전월 대비): 방향 급변
- **물량 + 판가 동시 가속** (두 달 연속 상승폭 증가)

### 🟠 주의 (중간 신호, 메모만)
- 판가 YoY > +20% 신규 진입 또는 < -20% 하락
- 물량 YoY > +50% (수요 폭발 구간)
- 미국향(+미국 시트) ≠ 전체 (지역 분리 현상)

### 🟡 모니터링 (약한 신호)
- 물량↑ 판가↓ 지속: 공급 과잉 징조
- MoM 3달 연속 같은 방향

### ⚠️ 오독 주의
- **1일·11일 발표**: 부분 데이터. 일평균 기준으로만 해석
- **전체 ≠ 미국향**: 고용량변압기처럼 전체 -0.5%여도 미국향 +27% 가능
- **YoY ≠ 가격수준**: 변압기처럼 YoY -2%여도 절대 판가(21$/kg)가 역사적 고점일 수 있음

## 업데이트 절차

새 xlsx 파일이 `raw/export/`에 들어오면:

```
/ingest raw/export/{파일명}.xlsx
```

**Claude가 하는 일:**
1. 위 시트 목록에서 ★★★ 우선 → ★★ 순으로 최신 행 추출
2. `현재 신호 상태` 표를 새 값으로 전면 교체
3. **이전값 대비 변화 감지**:
   - 판가YoY 부호 전환 → 해당 sector/ + stock/ 즉시 업데이트
   - 물량YoY ±30%p 이상 변화 → 해당 sector/ + stock/ 업데이트
   - 변화 미미하면 이 파일만 업데이트, sector/stock 건드리지 않음
4. log.md에 "수출 데이터 업데이트 YYYY-MM-DD" 기록

**발표일별 처리 방침:**
- **1일 (전월 전체 잠정)**: sector/stock 업데이트 가능. 마켓이 반응하는 핵심 데이터
- **11일 (당월 1~10일)**: 방향성 확인만. 수치 불안정, 업데이트 보류
- **21일 (당월 1~20일)**: 방향성 확인 + 강한 신호(±30%p 이상)만 메모
- **15일 (전월 확정)**: 잠정치와 차이 확인 후 필요시 수정 반영
