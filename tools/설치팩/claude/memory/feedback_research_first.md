리서치 → 위키 참고 순서를 지킨다. 위키에서 이유를 찾으려 하지 않는다.

**Why:** "오르는 이유는 위키에서 찾는게 아니고 리서치를 해보고 위키와 참고를 해서 하는거야" — 위키는 섹터/종목 컨텍스트 보조 도구일 뿐, 시장 이유의 출처가 아님.

**How to apply:**
1. WebSearch/WebFetch로 실시간 뉴스·이슈 먼저 파악
2. 위키는 "이 종목/섹터가 우리 관심권인가", "수급·수출 데이터와 연결되는가" 확인 용도
3. 둘을 합쳐서 최종 분석 작성
