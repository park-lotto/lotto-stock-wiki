### 2-2. Hook 공식 해부 (9가지 변형)

모든 17개 영상이 동일한 구조를 쓰지만 Hook에 9가지 변형이 있음:

**패턴 A: "나도 그랬어요" (공감형)**
> "주식 투자의 정보가 중요하다고들 하니까 저도 새벽에 일어나서 유튜브 찾아보고 카톡 리딩방도 들어가 보고 카페 올라오는 글까지 싹 다 뒤져본 적이 있었거든요."

→ **청중의 과거 경험과 정확히 일치**하는 장면 묘사. 바로 "아, 나 얘기잖아" 반응 유발.

**패턴 B: 숫자 충격 (인식 전환형)**
> "하루 25,000개 뉴스 / 주식 공부 200시간 / AI 구독료 월 50만원"

→ **구체적 숫자**로 문제의 크기를 체감시킴. 추상적 어려움을 수치화.

**패턴 C: 질문 제시 (궁금증 유발형)**
> "여러분 이런 생각해 보신 적 있으세요? AI가 이렇게 발전했는데 이제 주식도 예측해 주는 거 아니야?"

→ 시청자가 이미 궁금했던 질문을 대신 던짐. 답이 궁금해서 계속 봄.

**패턴 D: 실패 고백 (신뢰 구축형)**
> "처음엔 그냥 재미나이한테 내일 중요한 뉴스 다섯 개를 요약해 줘 시켜봤어요. 얼핏 보면 그럴싸한데 막상 받아봤는데 며칠 전 기사를 가져오더라고요."

→ 실패도 공개하는 투명성 → **신뢰도 급상승**. "이 사람은 솔직하다" 인식.

**패턴 E: 긴급성 제시 (FOMO형)**
> "지금이 흐름을 놓치면 나중에 남들보다 뒤쳐질 수도 있겠죠"

→ 구독 안 하면 손해라는 심리 자극.

**패턴 F: 비교 반전 (기대 충족형)**
> "수십 페이지 증권 리포트를 다 읽느라 시간을 낭비하고 계신가요? → 퍼플렉시티로 핵심만 100배 빠르게"

→ 문제를 충분히 키운 후 극적으로 해결. 카타르시스 제공.

**패턴 G: 허탈감 공감 (감성형)**
> "주식 분석 제대로 하면 좋은 거 누가 몰라서 안 해. AI를 써봐도 자꾸 엉뚱한 답변만 하니까 믿을 수가 없고요."

→ AI 써봤는데 실망한 사람 타겟. "맞아, 나도 그랬는데 이 사람은 답을 알겠구나" 기대감 형성.

**패턴 H: 철학·거대 관점 (포지셔닝형)**
> "왜 아시아권 국가들이 서구 국가들에게 지배를 당했을까요? 기술 혁신에 참여하느냐 못하느냐가 나라의 주권을 송두리째 빼앗기게 만들 수 있다"

→ 개인 주식 분석을 산업혁명/AI혁명 레벨로 끌어올림. **빅픽처 프레임**.

**패턴 I: 입문자 공략 (확대형)**
> "주식을 시작하려고 하면 다들 이런 말을 하죠 코스피가 좋아요 아니면 코스닥이 좋아요"

→ 완전 초보까지 잡아 채널 상단 퍼널 확대.

### 2-3. 영상 내부 구조 (해부)

```
[00:00~00:30] ← HOOK (15초 내 핵심 Pain Point 발화)
     ↓
[00:30~01:30] ← 문제 확장 (충분히 공감 축적)
     ↓
[01:30~03:00] ← Solution 시연 (실제 화면 캡처 / 프롬프트 입력 장면)
     ↓
[03:00~03:30] ← 심화/팁 (무료 제공 예고: "프롬프트 설명란에")
     ↓
[03:30~04:00] ← 소프트 CTA (구독 요청 or 커뮤니티 링크)
```

**특징**: CTA가 매우 소프트함. "이 채널은 아직 작고 신생 채널입니다. 알고리즘이 쉽게 추천해 줄 확률이 솔직히 낮아요" → 구독 호소. **겸손함으로 공감 획득**.

## 5. 알고리즘 전략 분석

### 5-1. 영상 포맷 선택 이유 (4~5분)
- YouTube 완주율 기준: 4분 이하 = 높은 완주율 → **알고리즘에 강한 긍정 신호**
- 짧은 영상 = 낮은 진입 장벽 → 초보자도 "일단 한번 보자"
- 스크린 캡처 위주 → 제작 비용 거의 없음 → **대량 업로드 가능**

### 5-2. 제목/썸네일 전략 (추정)
- 숫자 강조: "200시간 → 10분", "25,000개 뉴스"
- Pain Point 직접 언급: "주식 공부가 버겁다" "재무제표 봐도 확신 못함"
- 도구 이름 노출: "ChatGPT", "Perplexity", "Gemini" → 검색 유입

### 5-3. 업로드 전략 (추정)
- 빠른 업로드 주기 (주 2~3회 추정)
- 주제 연속성: "AI 도구" 키워드로 카테고리 일관성 유지
- 초보자 입문 영상 + 심화 영상 교차 → 신규 유입 + 기존 구독자 유지

| **범용 AI 도구 의존** | ChatGPT/Perplexity/Gemini만 소개 | 독자적 시스템(빈집·수급오실레이터)과 차별화 명확 |
| **숫자 성과 없음** | 실제 수익률 공개 없음 | "내가 이 방법으로 얼마 벌었다" 결과가 없음 |
| **한계 자인** | "AI가 그럴듯한 추천을 하는 게 아니라 선성 기준과 판단을 논리적으로 함께 제공한다는 점" | 분석은 주지만 종목 발굴 엣지 없음 |

## 8. 벤치마킹 포인트 & 이기는 전략

### 8-1. 즉시 벤치마킹해야 할 것

**① 4~5분 짧은 how-to 포맷**
- 현재 우리 영상이 너무 길다면 분할 필요
- 1영상 = 1개의 문제 해결 = 1개의 도구 공개

**② 무료 가치 제공 전략**
- 프롬프트, 코드, 데이터 → 아낌없이 공개
- 우리: 태린이 파일 파싱 스크립트, 오실레이터 계산식 → 공개 가능한 것부터

**③ 1인칭 공감형 스토리텔링**
- "저도 이걸 모를 때 이랬어요" 로 시작
- 실패 과정 공개 → 신뢰도 폭발적 상승

**④ Hook에 구체적 숫자 삽입**
- "이 시스템으로 뭘 했는지" 수치 제시
- 매일 얼마나 시간을 절약하는지, 몇 개 종목을 필터링하는지

**⑤ 고정 댓글 리소스 제공**
- 프롬프트, 코드, 링크를 고정 댓글에 → 반복 방문 유인

### 8-2. 로보를 넘어서는 각도 (빈집·500만원 제외)

**각도 1: "AI 결과가 아니라 수급 신호"**
> 로보: "ChatGPT한테 이렇게 물어봐요"
> 우리: "아무도 갖고 있지 않은 수급 데이터가 이렇게 생겼어요"
- 로보는 공개 AI 도구 사용법 교육 → 누구나 할 수 있음
- 우리는 그 AI에 넣을 **원자재 데이터 자체**를 가지고 있음

**각도 2: "자동화 결과물 공개"**
- 매일 아침 시스템이 생성한 아웃풋(브리핑 카드, 텔레그램 알림) 직접 보여주기
- "이게 오늘 아침 내 시스템이 뱉어낸 거예요" → 완성된 산출물로 신뢰 획득
- 로보는 "이렇게 만들 수 있어요"만 보여줌 / 우리는 실제 완성된 결과물을 매일 보여줌

**각도 3: "섹터 + 종목 레이더 시스템 공개"**
- 주도업종 판단 과정 공개 (RS필터, 유동성 지표, 컨센상향 조합)
- 로보는 "종목 하나를 이렇게 분석해요" / 우리는 "전체 시장에서 이번 주 봐야 할 섹터는 여기고 그 안에서 빈집은 이거예요"

**각도 4: "크롤링 인프라 시스템 공개"**
- 자동화 파이프라인의 구조를 단계별로 영상화
  - "이 시스템이 하루 몇 개의 데이터를 수집하나"
  - "어디서 무엇을 가져오나"
  - "어떻게 필터링하나"
- 로보는 ChatGPT/Gemini/Perplexity = 누구나 쓸 수 있는 도구
- 우리는 **직접 구축한 인프라** = 로보가 절대 복제 불가능

**각도 5: "팩트 기반 투자 판단 시스템"**
- 로보: "AI한테 물어보면 답해줘요" (AI에 의존)
- 우리: "이 수급 데이터와 이 오실레이터가 이 조건을 충족하면 이 종목을 봐야 한다" (시스템에 근거)
- 감이 아닌 **조건부 시스템** 공개

**로보의 성공 공식**:
> 직장인 Pain Point(정보 과부하) + 즉시 따라할 수 있는 공개 AI 도구 활용법 + 프롬프트 무료 제공 → 구독자 신뢰 → 강의/커뮤니티 판매

3. 이 방법이 실제로 돈을 버는지 (실전 검증)
4. 실시간 데이터 반영 (AI 한계를 본인이 직접 인정)
