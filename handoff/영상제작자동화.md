# 영상제작자동화

## 목표

매번 문서와 파일을 주고받지 않고, 숏템메이커처럼 한 페이지에서 영상 프로젝트를 만들고 이어서 작업할 수 있는 제작소를 구현한다.

## 이번 작업

- `/yt`를 저장형 영상 프로젝트 화면으로 개편했다.
- 프로젝트 생성·목록·불러오기·자동저장 API를 추가했다.
- 기본설정 → AI 기획서 → 대본 → 장면 분리 흐름을 연결했다.
- 장면마다 영상·음성·이미지·문서를 등록하고 다시 받을 수 있게 했다.
- 최근 프로젝트를 페이지 진입 시 자동 복원한다.
- 아직 연결하지 않은 성우·자막, 디자인, 검수, 렌더 단계는 실제 기능처럼 보이지 않도록 명시했다.

## 검증

- `py -m pytest tests/test_yt_dashboard.py -q` → 5 passed
- `py -m py_compile dashboard/server.py` → 통과
- 브라우저에서 프로젝트 생성, 내용 입력, 대본 장면 분리, 새로고침 후 프로젝트·4단계·2개 장면 복원 확인
