### 순서
1. "오늘 이슈 모아줘" → 고른 번호의 **기사 원문**을 편 폴더 `articles.txt` 에(### 언론사 | … | 날짜 | 제목 / 주소 / 본문). 기사 날짜 확인
2. 대본 초안 → **사장님 컨펌**(화면 제목 2줄·오프닝·유튜브 제목·컷별 색·화면 줄 `/` 로). 줄 폭은 엔진 글꼴로 잰다(`measure.ink_width`, 822px 기준)
   - 두 줄 먼저. 두 줄이면 글자가 85% 아래로 줄어드는 컷은 세 줄
3. 확정본 = 편 폴더 `confirmed.json`: `title{h1,h2,card,youtube,slug}` · `region` · `card_img` · `groups[{color,role,text,lines,img|meme}]`
   - `slug` = 영어 소문자-하이픈(완성본 이름이 된다). 밈 칸은 `role:"PUNCH"`, `meme:"경악/충격"` 등(대본 감정 10가지)
4. 제작(트랙 폴더에서):
   ```
   PYTHONPATH=<트랙폴더> py -m shopping_shorts.channelkit.make --preset brainbulb_orange --text-file <편>/articles.txt --script-file <편>/confirmed.json --workdir <편> --sfx-dir <볼케이노>/효과음 --script-llm claude [--no-review]
   ```
   결과 = `<편>/out/sesangcham_<slug>.mp4` 하나(렌더가 바로 이 이름으로 저장. moacco_·final.mp4 는 옛 이름)
5. 컷마다 1장씩 시트로 뽑아 **15컷을 눈으로** 확인 → **밈 컷은 사장님께 보여 드리고 사장님이 정한다**
6. `out/sesangcham_<slug>.txt` 에 [제목]·[설명]·출처(언론사 주소)·태그
7. 확정되면 트랙 handoff 에 한 줄 + 커밋·푸시

## 대본·제목 취향 (볼케이노 때부터)

- 대본은 음슴체(~함·~음·~임). 짧은 구어와 현상 요약.
- '~셈'(보셈·가셈)으로 끝내지 않는다. 마무리 권유는 '~해야 함'·'~하는 게 맞음'(사장님 11-04).
- ★11-04부터 뇌전구는 볼케이노 서버가 아니라 **우리 프리셋 `brainbulb_orange`** 로 만든다(트랙 `track/뇌전구오렌지`, 만드는 법 = 그 트랙 `handoff/뇌전구오렌지.md`). 위 1~6 번의 볼케이노 단계는 옛 방식이다.
- 중복을 싫어한다. 줄일 때도 도입부 리듬은 남긴다.
- 흐름이 앞뒤로 이어져야 한다. 화제가 튀면 문장만 다듬지 말고 컷 순서를 바꾼다.
- 마무리 멘트는 임팩트 있게.
- 영어 약자는 읽기 쉽게 쓴다(GPT-4o → 챗지피티).
- 오프닝은 귀로 들어도 자연스러워야 한다.
- 유튜브에서 걸릴 수 있는 '죽인다' 류 표현을 피한다.
- 정치 소재는 한쪽 편을 들지 않게 양쪽 주장을 넣는다.
- 색: 흰색=일반 / 노랑·분홍=강조 / 오렌지·밈=펀치 / 빨강=마무리. 밈이 연달아 나오지 않게 한다.
