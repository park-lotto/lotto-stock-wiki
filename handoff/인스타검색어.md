### 사장님 요청
1. 인스타 키워드 검색 화면의 제목("Life hacks gadgets")을 **검색창**으로 — 한글로 치면 영어로 바꿔 주소창 검색
2. 제목 아래 **비슷한 검색어 5개** — 누르면 그 검색으로 이동
3. 게시물 팝업 오른쪽 버튼(레퍼런스 등록·렌즈·채널수집·담기) **아래 빈칸에 관련 검색어** — 누르면 이동
- 검색어는 **영어만**, 게시물 쪽은 **amazon** 포함

### 실측으로 정한 규칙
- 인스타 검색은 **4단어부터 결과 없음, 3단어까지 됨**(사장님 로그인 화면 확인) → 메모리 `reference_인스타키워드검색_3단어까지`
- 판단 주인: `shopping_shorts/video_analysis.py:english_search_terms` (+ `_clean_en_term`, `_EN_MAX_WORDS=3`)
  확장은 받은 걸 그리기만 한다(단어 수를 화면에서 또 자르지 않음).
- 라우트: `POST /api/lens/kw/en {text, kind: query|caption}` → `{ok, main, related}` (Gemini 텍스트 1회, 무료 키 풀)

### 화면 점검 도구 — `tools/ig_kw_ui_check.py`
- ① 진짜 인스타 릴스(로그아웃)에 로직 주입 → 설명글 읽기 → 관련 검색어 상자 → 칩 클릭 이동
- ② 검색 화면은 로그인 필요라 **흉내 페이지**(제목=검색어 글자)로 → 검색창·칩 5개·한글 입력→영어 주소
- 새 코드 PASS / main 옛 코드 FAIL(5개 항목) 확인 — 검사가 실제로 잡는다
- 서버 호출은 가짜 응답(서버 판단은 위 표로 따로 잼)
