1프리셋을 고르고 내 채널 옵션 저장

숏템메이커에 로그인해 '클로드형' 페이지를 엽니다. 프리셋 견본을 보고 하나를 고른 뒤 채널 이름·글꼴·목소리·효과음을 정하고 내 채널 저장을 누릅니다.

저장한 옵션이 내 채널 프로필이 됩니다. 나중에 Claude 에게 이 이름으로 만들어 달라고 하면 됩니다.

5설치가 끝나면 '연결하기'를 켠 채로 마침

렌더러·ffmpeg·파이썬 같은 실행 도구가 한 번에 깔립니다(몇 분). 인터넷에서 따로 받는 것은 없습니다.

마지막 화면에서 Claude Desktop 에 숏템 연결하기가 켜져 있는지 보고 마침을 누릅니다. 바탕화면에 숏템작업 폴더가 생깁니다.

8이 기기 등록 — 2대까지

처음 준비 점검을 할 때 이 컴퓨터가 자동으로 등록됩니다(2대 중 1). 집·사무실 두 대라면 두 번째 컴퓨터에도 설치팩을 깔고 같은 키를 넣습니다.

9"숏템 준비 점검해줘"

채팅에 숏템 준비 점검해줘라고 씁니다. 라이선스·기기·실행 도구·자막 굽기(ass)를 확인하고, 시험 렌더·시험 목소리·시험 다운로드 3가지를 실제로 만들어 봅니다.

결과는 숏템작업\자가점검_결과.md 에도 남습니다. 안 된 항목은 고칠 방법 한 줄이 같이 나옵니다.

10시작.md 를 끌어다 놓고 엔터

바탕화면 숏템작업 폴더의 시작.md 를 Claude Code 입력창에 끌어다 놓고 엔터를 한 번 누릅니다. 플러그인 등록 명령 두 줄을 실행해도 되는지 물으면 예.

Claude Code 를 껐다 켠 뒤 /plugin configure shortem@shortem 으로 키를 붙여 넣고 /shortem:setup 을 실행합니다.
