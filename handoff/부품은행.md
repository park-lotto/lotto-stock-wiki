**핵심 설계 반영**:
- **[R4]** 통계·perf·fit_categories는 `category_source IN ('user','gemini')`만 — keyword 추측(54%정확) 제외. T5·T7·T9에 배선.
- **[A1]** 스파인 승격 게이트 = `source_count>=3 AND status='approved'`. 야간배치는 **절대 자동승인 안 함**(pending만 생성). 부품 MIN_SAMPLES=1과 분리.
- **[A2]** perf_score = 플랫폼내 로그백분위 × 최근성감쇠 + views/followers 보정. 상수 모듈 상단 노출.
- **[R3]** perf 필드별 nullable. saves=전무·followers=인스타전용·댓글=도우인/샤오홍슈 없음. perf_from_item이 0 지어내지 않고 None.
- 모든 Gemini 콜은 `call=`/`ingest_fn=` 주입점 — 테스트는 실 Gemini 안 침.

**검증 근거**(이번 세션 tool 관측):
- 신규 테스트 전부 green(위 표). import 게이트 `import shopping_shorts.app` OK.
- edit_plan_build 2건 실패는 **기준선**(pristine HEAD에서도 동일 실패, plagiarism_flags — 내 변경 무관, 실측 확인).
- ⏳ 전체 회귀(1700+) 백그라운드 실행 중 — finish 전 신규 실패 0 확정 필요.

**아키텍처**: 새 배치 스텝은 전부 `daily_batch.run()` 순차호출(기존 관례). 크론 = `python -m shopping_shorts.daily_batch`(서버측 crontab, repo엔 스케줄러 없음).
