# 손그림 14장면 주인공 교체 — Opus 실행 지시 (10-29 저녁)

설계 = Fable `_hero_draft\SHOTLIST.md`(컷별 그림·남녀·팔레트) + `ART_GATE_1.md`(판정·수정 지시). 너는 실행자다. 장면을 처음부터 다시 만들지 말고 기존 scene.js 의 컷 순서·타이밍·문구를 지키며 아래만 바꾼다.

## 바꿀 것
1. 주인공 = 새 그림만. `py ..\_hero_draft\hero_install.py <장면>\template` 후 scene.js 의 인물 호출을 `INKHERO.put(레이어, "g_*", {x, y, sc, s, dur})` 로(README·보고: `_hero_draft` 의 hero_put.js 주석). 옛 _assets 주인공(face.*, bust.*) 호출은 전부 제거. 직급 로봇·소품 부품은 그대로.
2. ART_GATE_1.md 의 장면별 수정 지시(전환 겹침 0·끝맺음·소품 부품·크기·표정 방향)를 같이 반영.

## 사장님이 다른 장면을 보고 짚은 것 — 이 14장면에도 똑같이 적용(같은 지적이 두 번 나오면 안 된다)
- "밋밋하다" → 인물이 화면 높이 **60% 이상**, 빈 화면 40% 넘지 않게. 컷마다 카메라 밀기·당기기·패닝 중 하나.
- "자세도 똑같고 움직임 없다" → 한 장면 안에서 같은 그림 정지 금지: 컷마다 다른 그림(SHOTLIST 배정) 또는 표정 교체(win/stat), 작은 움직임(살짝 흔들림 없이 0.15초 교체).
- "처음 그려지는 게 느리다" → 첫 인물 펜 1.2초 이내(얼굴은 0.6초 안에 알아보이게).
- "같은 장면이 또 그려진다" → 같은 그림 이름 펜 호출 2회 금지(재등장은 stat:true).
- 모자이크 금지. 손글씨 결론 110px 이상.
