# 쇼츠 칼카피 기준표 — 외부 조사 (2026-09-27)

범위: 내려받은 mp4 + 공개 YouTube 메타데이터(Data API·페이지) + (내 채널만) YouTube Studio.
★ = YouTube Studio 필요(남의 채널은 못 잰다). 재는 법의 약어:
- **프레임 추출** = `ffmpeg -vf fps=N` 로 프레임 뽑아 OCR(PaddleOCR/EasyOCR)·픽셀 분석
- **ASR** = Whisper 등 음성 인식으로 단어·타임스탬프 뽑기
- **장면검출** = PySceneDetect / `ffmpeg scdet`
- **loudnorm** = `ffmpeg -af loudnorm=print_format=json` / `ebur128`
- **API** = YouTube Data API v3 (`videos.list` statistics·snippet·contentDetails, `channels.list`, `playlistItems`)

수치 출처 주의: 블로그 벤치마크(OpusClip·Aibrify·Retensis 등)는 자체 데이터 주장이며 YouTube 공식 수치가 아니다. 공식 문서(Netflix TTSG·libass·YouTube 고객센터·논문)만 규격으로 취급하고, 나머지는 "참고 기준선"으로 표기했다.
