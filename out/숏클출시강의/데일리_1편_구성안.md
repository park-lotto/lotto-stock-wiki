# 숏클 데일리 1편 구성안 — 롱폼 + 쇼츠 4편 (2026-10-29 · 사장님 승인 대기)
n> ⚠️ 10-29 오후 15분 30초판으로 변경 — 최신 구성은 `데일리_1편_구성안.html` (make_plan_html.py 가 원본). 아래 5분판은 옛 초안.

근거: `channel/strategy/영상제작_대본작업_표준.md`(설득 7단계·관통 키워드·1~5단계 3분 안·6단계 절반 이상) + 오늘 벤치마킹(`벤치마킹/` — 결말 먼저·질문 카드·쉬운→어려운 데모·결과물 등장).
사장님 기준: 진짜 Claude 가 만드는 과정 + 결과물 등장 / 최대한 다양하게 / 샘플을 다 쓰지 않는다 / 매일 스타일 교체 / 쇼츠는 자르지 않고 함께 기획.

## 0. 한 장 요약
- **관통 키워드 = "한 줄"** — ① 오프닝: "이 쇼츠들, 한 줄로 나왔습니다" ③ 한계: "AI에게 한 줄로 부탁하면 안 됩니다" ⑥ 본론: "프리셋 + 한 줄" 4번 ⑦ 끝: "오늘 한 줄 넣어 보세요". 세 번 이상 돌아온다.
- **이야기 구조**: 주인공 = 시청자(쇼츠 노가다에 지친 40·50·60대) / 적 = 시간 / 실패한 시도 = AI에게 말로 부탁하기 / 조력자 = 숏클 엔진 / 시험 4번 = 프리셋 4개(쉬운 것 → 어려운 것) / 결말 = 자는 동안 쌓인 결과물.
- **길이**: 롱폼 약 5분(1~5단계 2분 이내, 6단계 2분 40초 = 53%, 7단계 20초). 매일 12~15분판은 6단계 프리셋을 8~10개로 늘린다.
- **목소리**: 필재(1.25배속) 나레이션. 사장님 목소리 없음.

### 6단계 시험 4번 (쉬운 것 → 어려운 것, 한 번에 하나씩 새로운 능력)
| 순서 | 한 줄 명령 | 새로 보여 주는 능력(포인트 한 문장) | 결과 등장 방식 | 결과 3편(실제 완성본) |
|---|---|---|---|---|
| 1 | "해외+화장품 프리셋으로 만들어줘" | 해외 원본을 찾아 온다 | I1 카드 3장 솟음 | 코팩 · 연어크림 · 선크림 |
| 2 | "연예인+후기 프리셋으로 만들어줘" | 연예인 원음 + 같은 제품까지 찾아 붙인다 | I2 폰 알림 도착 | 함익병 도브 · 강민경 틴트 · 김가연 BB |
| 3 | "썰비하인드 프리셋으로 만들어줘" | 숨은 이야기 대본을 쓴다 | J2 번호·칩(가로판) | 아웃백 비밀 · 바나나우유 · 코스트코 가격코드 |
| 4 | "해외핫영상+나레원음 프리셋으로 만들어줘" | 원음을 살리고 나레를 섞는다 | J1 격자(가로판) | 아이언맨 헬멧 · 미니카 · 가짜 잠자리 |
터미널 장면은 **진짜 Claude Code 화면 녹화**를 쓴다(가짜 v1 은 99% 아님 — 사장님 핵심 '진짜 과정'과 어긋남).

### 이번 편에서 안 쓰는 샘플(다음 편 회전용)
C 가짜 터미널 v1 · F 웹 진행판(→2편 '보면서 고르는 화면') · G 채널 리포트(→2편 증거) · I1/J1/J2 의 다른 순서 조합.

## 2. 쇼츠 4편 — 롱폼과 같은 날, 따로 기획(자르지 않음, 세로 1080x1920, 35~45초)
| 쇼츠 | 0~3초 훅(큰 글자) | 3~10초 | 10~35초 | 끝 |
|---|---|---|---|---|
| ① | "클로드에 이 한 줄 넣었더니" | 세로 터미널: 해외+화장품 | **J2 번호·칩**(코팩·크림·선크림) | 결론 한 줄 + 로고 3초 |
| ② | "연예인 후기 쇼츠, 한 줄이면 됩니다" | 세로 터미널: 연예인+후기 | **J1 격자 쏟아짐** | 〃 |
| ③ | "이 썰 쇼츠, 사람이 안 썼습니다" | 세로 터미널: 썰비하인드 | **J2 번호·칩** | 〃 |
| ④ | "자는 동안 쇼츠 3편이 왔습니다" | 폰 알림(세로 I2) | 해외핫영상 3편 | 〃 |

## 4. 승인 뒤 제작 순서
① 필재 나레이션 대본 확정 → ② 진짜 Claude Code 화면 녹화(프리셋 4개 명령) → ③ 결과 등장 장면 3종을 프리셋별 실제 결과로 다시 렌더(Sonnet 병렬) → ④ 무음 가편집본(자막 1.25배속 가늠) → 사장님 승인 → ⑤ 필재 TTS → ⑥ 쇼츠 4편.
