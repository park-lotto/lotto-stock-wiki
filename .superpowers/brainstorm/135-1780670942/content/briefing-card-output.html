운영자 답변 후 — 카드 결과물은 어디로?

텔레그램으로 질문받고 답변했습니다.
완성된 브리핑 카드를 어디에 어떻게 전달할까요?

A

텔레그램 자동 전송

카드 완성 → PNG 캡처 → 텔레그램 채널/단톡방 자동 전송.

흐름: 답변 수신 → 카드 생성 → PNG 캡처 → 텔레그램 push
장점: 완전 자동화, 운영자가 아무것도 안 해도 됨
단점: PNG 자동 캡처 셋업 필요 (Playwright)

B

HTML 생성 + 수동 캡처·전송

카드 완성 → out/ 폴더에 HTML 저장 → 브라우저 자동 오픈.
운영자가 F12 캡처 → 텔레그램 수동 전송.

장점: 지금 바로 가능, 카드 검토 후 전송 가능
단점: 매일 손으로 캡처·전송 해야 함

C

텔레그램으로 HTML 링크 전송 (단계적)

1단계: HTML 생성 + 텔레그램으로 "카드 완성됐어요 + 요약 텍스트" 전송
2단계: 나중에 PNG 자동화 추가

장점: 지금 당장 텔레그램 연동 가능, 자동화 여지 남김
단점: HTML 링크는 외부 공유 불가, 텍스트 요약이 카드 대신

💡 추천: B안 → A안으로 확장
일단 HTML+수동 캡처로 카드 퀄리티를 잡고, Playwright PNG 자동화는 이후 추가하는 게 현실적입니다.
텔레그램 답변 자동화(A안 입력부)는 이미 셋업되어 있으니 출력부만 단계적으로 붙이면 됩니다.
