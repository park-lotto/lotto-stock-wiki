# 칼카피 제작 자동화 설계 — 시간부터 줄이고, 디테일은 그 위에 (2026-10-18, 관제 097, 초안 1판)

> 사장님(10-18): "직접 손으로 재는 게 아니라 자동화를 해야 한다. 자동화가 퀄리티를 떨어트려서는 안 되고, **시간을 먼저 세이브**시키고 나서 디테일이 들어간다."
> 이 문서 = 사람(클로드)이 손으로 하던 일 전부를 목록으로 놓고, 일마다 **자동화 방법 · 판단 주인 함수 한 곳 · 품질 게이트(B표·검수 매뉴얼 그대로) · 사람이 남는 지점 · 시간 자동 기록**을 정한다.
> 숫자는 전부 실측(날짜 표기). 추정은 "추정"이라고 쓴다. 1판 적용 결과는 §6.

## 0. 경계
- **앞단(링크 → 제품 확정 → 재료 모으기 → 판 고르기)은 옆 세션 "칼카피 링크→제품→다프리셋 영상 설계" 담당.** 여기서는 경계만 적는다 — 입력: 제품 링크/영상 링크, 출력: 확정 제품(이름·품번·분류)·재료 폴더·만들 판 목록(이븐쇼핑·두유노·썰쇼핑·인스타형 4판 기본 + 채널 추천). 그쪽은 렌더·검사를 아래 공용 도구로 부른다.
- **이 문서의 중심 = 공용 엔진의 시간 절감**(제미나이 서버 풀·병렬·받기 전 거르기·자동 검사 반려·단계 시간 자동 기록)과 **렌더·검사·저장 이후**(바탕화면·드라이브·결과물 등록·커밋·공지).
- 하이브리드(얜샷템)뿐 아니라 샥탬스토리(foreignshowshow)·썰템쇼(humorshowshow)·잇썸홈/재미썸홈 기본·도파민썰템·숏템리폿 등 모든 꼴이 같은 엔진을 쓴다는 전제.

## 3. 뿌리(공용 엔진)에 박은 것 — 1판 (10-18)
1. **제미나이 창구 하나** `tools/calcopy/engine/gemini_free.py`
   - `ask()` 그대로(모든 호출처가 이미 이걸 쓴다) + **서버 대체**: 로컬 풀이 `quota`/`no_key` 면 서버 풀(`engine/gemini_server.py`)로 같은 모델·같은 프롬프트를 보내 답을 받는다(`CALCOPY_GEMINI_BACKEND=auto|local|server`, 기본 auto). 답에 `_via` 표식.
   - `ask_many(jobs, workers≤8)` — 묶음 동시 호출의 주인. `analyze._batched` 가 쓴다.
   - `ask_cross(parts, prompt, models)` — 모델 교차(받아쓰기 검증용), 모델별 답을 그대로 돌려준다(조용히 한 모델로 줄이지 않는다).
2. **서버 창구 주인 이동** `hybrid/gemini_server.py` → `engine/gemini_server.py`(hybrid 는 재수출). 서버 스레드 상한 12 그대로(유료 고객과 같은 풀).
3. **이름 발음 사전 주인 이동** `hybrid/name_dict.json` → `engine/name_dict.json` + `engine/name_dict.py`(spelling/apply/apply_all). `hybrid/name_check` 는 이걸 읽고 쓴다. `preset_make.tts` 가 덩어리마다 `apply_all`.
4. **단계 시간 장부 주인** `engine/stage_log.py`(`Timer`·`timed`) — hybrid `common.Timer` 가 이걸 쓴다. `preset_make` 는 `run_log.json.steps_s` 를 이미 쓴다(같은 꼴로 `stage_log.json` 도 남긴다).
5. **analyze50 → gemini_free**(Vertex 경로 제거·404 모델 제거) · **top50_run 다운로드 동시 4**.
6. **screen 후보 실패 격리**(한 후보 실패가 단계를 멈추지 않는다).

## 4. 품질 게이트 원칙
- 기준은 새로 만들지 않는다 — `tools/calcopy/검수_매뉴얼.md`(A1~A13·B1~B18)·B표·T1 그대로. 자동 검사 미달 = 바탕화면 복사·결과물 등록 안 함(preset_make 이미 그렇다), 하이브리드 deliver 는 `ok_auto` 없으면 거절.
- "같거나 좋아야" 증명: 바꾼 도구마다 실제 편 1개 전·후 결과물 대조(§6).
- 조용한 축소 금지: 모델 교차 모자람·서버 대체·후보 실패는 결과 파일에 표식으로 남는다.
