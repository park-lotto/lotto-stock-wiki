# 쇼핑쇼츠 렌즈 유사영상 발굴 — 설계

**날짜**: 2026-07-14
**상태**: 설계 승인됨, 구현 대기
**관련**: [[project_틱톡_키워드발굴]] / product_identify.py(기존 SerpApi 렌즈 연동)

---

## 1. 배경·목적

레퍼런스 랭킹(인스타/유튜브/틱톡)에서 나온 영상이 부족할 때, **특정 장면을 구글 렌즈로 역검색해 유사한 동영상을 자동 발굴**한다. 사용자가 브라우저 우클릭 "구글 렌즈로 이 동영상 검색하기"로 수동으로 하던 걸 **앱 내장 렌즈탭**으로 원클릭 자동화.

**핵심 요구**: 렌즈 검색 결과에서 **동영상만 추려서** 깔끔하게 보여주는 것.

**이미 있는 것**: `product_identify.py`가 SerpApi `google_lens` 엔진을 연동해 `visual_matches`를 받아옴(지금은 제품명 추론에만 사용). 서버에 `SERPAPI_KEY` 존재. 프레임 추출(`frame_extract.py`)·외부 이미지 서빙(`/api/find/frame/*`) 인프라 존재.

**실증(2026-07-14)**: 서버에서 `google_lens` 1회 호출 → `visual_matches`에 유튜브 영상 URL+제목+썸네일 반환 확인. 응답 필드: `link, source, title, thumbnail, image`(video/duration 필드는 **없음** → 도메인으로 동영상 판별해야 함).

## 2. 아키텍처 (데이터 흐름)

```
[카드 미리보기] 우리 mp4 재생 → 멈춤
   ↓ 🔍 렌즈 버튼
[프론트] 멈춘 <video> → canvas 캡처 → JPEG blob
   ↓ POST /api/lens/search (이미지 업로드)
[서버] 캡처본 임시저장 → PUBLIC_BASE_URL로 외부 서빙 URL 생성
   ↓
[서버] SerpApi google_lens(url=캡처URL) 호출 (월 가드 통과 시)
   ↓ visual_matches
[서버] 5개 플랫폼 도메인 화이트리스트 필터 → 플랫폼 태깅
   ↓ {platform, url, title, thumbnail}[]
[프론트] 렌즈탭 아래: 토글 켠 플랫폼만 카드 그리드 표시
```

## 3. 컴포넌트

### 3.1 재생 통일 (embed → mp4) — `frontend` + `service`/`app`
현재 `playYoutube`/`playTiktok`는 iframe embed라 **크로스도메인으로 canvas 캡처 불가**. 인스타(`playInline`)만 우리 `/api/video` mp4라 same-origin 캡처 가능.

→ **유튜브·틱톡도 우리 mp4로 재생**하도록 교체:
- 서버에 `/api/media?platform=&id=` 엔드포인트: yt-dlp로 해당 영상 mp4 스트림 확보(다운로드→프록시 또는 direct URL 프록시). `tiktok_client.py`·`frame_extract.py`의 yt-dlp 사용 패턴 재사용.
- 프론트 `playYoutube`/`playTiktok`를 `<video src="/api/media?...">`로 변경.
- **경계**: mp4 확보 실패(비공개·지역차단) 시 기존 embed로 폴백(재생은 되게, 캡처만 불가 안내).

### 3.2 프레임 캡처 — `frontend`
- 멈춘 `<video>`를 `canvas.drawImage()` → `canvas.toBlob('image/jpeg', 0.85)`.
- same-origin(우리 프록시)이라 canvas untainted → `toBlob` 성공.
- **경계**: 영상이 아직 로드 안 됐거나(`readyState<2`) 캡처 실패 시 "재생 후 멈춰주세요" 안내.

### 3.3 캡처 이미지 서빙 — `app`
- SerpApi는 **공개 접근 가능한 이미지 URL**이 필요(localhost 불가 → 배포서버 `PUBLIC_BASE_URL`).
- 업로드된 JPEG를 `data/lens_frames/{uuid}.jpg`로 저장, `/api/lens/frame/{uuid}` GET으로 서빙(인증 예외 — `_AUTH_ALLOW`에 추가, SerpApi 크롤러가 쿠키 없이 fetch).
- **경계**: 오래된 캡처본 정리(간단: 저장 시 24h 초과 파일 best-effort 삭제).

### 3.4 렌즈 검색 + 동영상 필터 — `lens_discover.py` (신규)
- `search_similar_videos(image_url) -> [{platform, url, title, thumbnail}]`
- SerpApi `google_lens` 호출(기존 `product_identify._lens_matches` 패턴, 단 `link`도 보존).
- **5개 플랫폼 도메인 화이트리스트**로 필터 + 플랫폼 태깅:

| platform | 도메인 매칭 |
|----------|------------|
| youtube | `youtube.com`, `youtu.be` |
| tiktok | `tiktok.com` |
| instagram | `instagram.com` |
| xiaohongshu | `xiaohongshu.com`, `xhslink.com` |
| douyin | `douyin.com`, `iesdouyin.com` |

- 화이트리스트 밖(위키·핀터레스트·쇼핑몰 등)은 제외.
- **경계**: SERPAPI_KEY 없거나 호출 실패 시 `[]`(조용히).

### 3.5 월 호출 가드 — `store` + `app`
- SerpApi 무료 100회/월. 틱톡 가드 패턴 재사용:
  - `store`: `lens_month_count(month)` / `bump_lens(month)` (settings 네임스페이스 키 `lens_count:{YYYY-MM}`).
  - `app`: `/api/lens/search`에서 월 상한(설정 `lens_month_limit`, 기본 100) 초과 시 429 `lens_limit`. 성공 시 `bump_lens`.
- 향후 포인트=현금 차감으로 대체 예정(지금은 카운트 가드).

### 3.6 렌즈탭 UI — `frontend`
- 카드 썸네일 아래 **🔍 렌즈** 버튼(기존 대본추출/같은주제 버튼 옆).
- 클릭 → 카드 아래 렌즈탭 영역 펼침:
  - **플랫폼 토글 칩 5개**(▶️유튜브 🎵틱톡 📷인스타 📕샤오홍슈 🎶도우인) — 기본 전부 ON, 작은 칩으로 지저분하지 않게.
  - 결과 카드 그리드: 플랫폼 배지 + 썸네일 + 제목. 클릭 시 원본 새 탭.
  - 켠 토글의 플랫폼만 렌더(재검색 아니라 클라 필터).
  - 로딩/0건/한도초과 상태 표시.

## 4. API 계약

**POST `/api/lens/search`** (multipart 또는 base64 JSON)
- 입력: 캡처 이미지(JPEG)
- 처리: 저장→서빙URL→google_lens→필터→태깅. 월 가드.
- 출력: `{ok, items:[{platform,url,title,thumbnail}], count}` / 429 `{ok:false, error_code:"lens_limit"}`

**GET `/api/lens/frame/{uuid}`** — 캡처본 서빙(인증 예외).

**GET/POST `/api/lens/settings`** (선택) — 월 상한 조회/설정(관리자).

## 5. 테스트 (TDD)

- `lens_discover`: visual_matches 목→5플랫폼 필터·태깅(각 도메인 케이스 + 제외 케이스). SERPAPI_KEY 없으면 [].
- `store`: lens_month_count/bump(월경계 리셋).
- `app`: /api/lens/search 월가드 429 lens_limit, 성공 시 bump+필터결과 반환(google_lens 목킹). frame 서빙 인증예외.
- 프론트: 브라우저로 인스타 캡처→렌즈검색→토글 필터 육안검증(로컬 서버).

## 6. 범위 밖 (YAGNI)

- 유사도 점수·정렬(렌즈가 준 순서 그대로).
- 렌즈 결과를 랭킹/수집 대상으로 담기(향후).
- 중국 플랫폼 영상 실제 다운로드/재생(발굴=링크만, 재생은 원본 새 탭).
- 포인트=현금 과금(향후, 지금은 월 카운트 가드).

## 7. 정직한 제약

1. **중국 플랫폼(샤오홍슈/도우인)**: 렌즈가 잡아주는지는 실데이터 의존. 필터에 넣어두되 안 나와도 정상(요리·제품은 나올 가능성 높음).
2. **mp4 확보 실패**: 유튜브/틱톡 비공개·지역차단 시 embed 폴백(캡처 불가). 인스타는 기존대로 안정.
3. **샤오홍슈 사진/영상 혼재**: URL로 구분 어려워 일단 다 표시(사용자 승인).
4. **SerpApi 무료 100회/월**: 실사용 시 빠르게 소진 가능 → 향후 유료/포인트 필수.
