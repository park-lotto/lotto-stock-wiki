공통 규칙
- 나레이션은 **앞(상황·훅)과 끝(정리)**, 원음은 **가운데 핵심(본인이 하는 법·증언)**.
- 원음 = "그 사람이 말해야 믿기는 말". 나레이션이 대신 말하면 힘이 빠지는 부분.
- 뷰티·연예인 쪽에 몰림(사장님 체감과 일치). 해외 소재 14편 중 원음 분명한 건 1편 — 해외 소재여도 대부분은 전부 한국어 나레이션.

## 3. 우리 쇼핑쇼츠에서 지금 되나 — 코드 확인

- **지금은 안 된다.** 렌더(`video_assemble.py` 클립 `-an`)와 캡컷(`capcut_draft.py:628` volume 0)이 원본 소리를 전부 지운다.
- **재료는 이미 있다.** 원본 영상 받아쓰기를 시각과 함께 이미 한다
  (`frame_script._default_transcribe` → Whisper 단어 시각·언어 자동 / `script_extract.extract_script` → 구간 start·end·text·장면설명).
  → "원본에서 핵심 발언 구간 고르기"는 있는 데이터로 가능.
- 새로 필요한 것
  1. 원음 구간 고르기(주인 함수 1곳): 어느 구간을 몇 초 살릴지
  2. 대본 작가: 원음 앞뒤로 나레이션을 쓰기(상황 → 원음 → 정리)
  3. 렌더·캡컷·미리보기: 그 칸만 원본 소리를 살림 + 한국어 번역 자막
  4. 원본 배경음악 제거(목소리만 남기기) — 원음에 음악이 섞여 있으면 우리 BGM과 겹침
- 확인 안 된 것: 중국어(도우인) 원음이 한국 시청자에게 영어·한국어 원음만큼 먹히는지 — 표본에 중국어 원음 히트 없음.

## 4. 대화형 TTS 샘플(A 묻고답하기 / B 나레이션+언니 한마디)

- 대본은 준비됨. 일레븐랩스 합성은 서버 비밀키 접근이 자동 권한검사에 막혀 **아직 못 만듦**.
