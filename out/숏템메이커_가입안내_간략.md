# 숏템메이커 시작 안내 (간략판)

안녕하세요, 숏템메이커입니다. 아래 순서대로만 하시면 첫 영상까지 갑니다. 설치는 PC에서 두 개뿐입니다.

## 1. 사이트 가입
- 주소: **https://shoppingshorts.duckdns.org**
- 절차: 구글 계정으로 로그인 → 이름·전화번호·성별·연령대 입력 → **승인 대기** → 승인되면 바로 이용
- 승인은 관리자가 확인 후 열어 드립니다. 승인 전에는 화면이 "승인 대기중"으로 보입니다.

## 2. 숏템메이커 유튜브 채널 라이브 시청 (필수)
- 숏템메이커 유튜브 채널의 **최근 영상 몇 개는 반드시 시청**하고 시작하세요. 사용법과 업데이트 내용을 라이브로 계속 올립니다.
- 라이브 링크: https://www.youtube.com/live/B3brg_sG_PA?si=Ub3snEkLZfB7xmTj
- 라이브를 안 보시면 아래 설치·등록에서 막히는 경우가 대부분입니다.

## 3. 설치안내에서 API 키 등록
- 그림 매뉴얼: shoppingshorts.duckdns.org/api_manual.html
- 등록하는 곳: **마이페이지 → 🔑 내 키 등록**
- 아래 5가지는 **전부 필수**입니다
  - ① 구글 제미나이 (무료, 1개만) — 대본·영상 분석
  - ② 유튜브 (무료, 1개만) — 유튜브 영상 정보
  - ③ SerpApi (월 250회 무료) — 비슷한 영상 찾기
  - ④ VMake (본인 결제) — 자막 지우기. API Key·Secret Access Key **두 개를 두 칸에 각각** 넣습니다
  - ⑤ 일레븐랩스 **또는** 타입캐스트 (본인 결제) — 목소리. 일레븐랩스 키는 만들 때 **오른쪽 권한을 전부 허용**
    - 타입캐스트는 **API 요금제(typecast.ai/pricing/api)** 를 결제해야 합니다. 에디터 요금제는 안 됩니다.

## 4. 담기 프로그램 설치 (필수, PC 크롬·엣지)
- 주소: **shoppingshorts.duckdns.org/grab**
- ① 파일 받아 압축 풀기 → ② 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → 압축 푼 **폴더**를 끌어다 놓기
- zip이 아니라 **압축 푼 폴더**를 넣어야 합니다. 휴대폰·다른 브라우저에서는 안 됩니다.

## 5. 캡컷 연동 (원하시는 분만)
- 완성 영상을 캡컷에서 더 다듬고 싶은 분만 합니다. 바로 받거나 QR로 폰에 보내실 분은 건너뛰세요.
- 안내 한 장: **shoppingshorts.duckdns.org/capcut_easy.html** (3단계)

## 6. 첫 영상 만들기
- 유튜브·인스타에서 마음에 든 영상 **📥 담기** → 제작소에서 만들기
- 막히면 화면의 **신고하기** 버튼이나 카톡으로 알려 주세요.
