# 승인 캠퍼스 실제 3D 건설 · 1차

**승인 범위:** 대규모 원형 캠퍼스 건설 우선. 로로/음성/보고 작업 중단. 원본 외관 구도를 기준으로 중앙 본사, 좌우 프로그램 건물군, 다중 원형 수로·도로, 다리와 조경을 실제 메시로 구성한다.

**구조:** 기존 실험 화면 보존. `scene/campus-layout.js`는 고정 배치, `campus-art.js`는 3D 조형, `campus.js`는 카메라·비교·조명. `/campus/` 새 건설 검토 화면. 공유 패널 글자 도구 재사용, 반복 조경·기둥은 인스턴싱. 실데이터와 가상 건물 숫자를 혼동하지 않는다.

- [ ] 배치 테스트: 좌우 각 10동, 고유 ID, 중앙 본사와 수로를 침범하지 않는 반경, 전면 진입로 확보. 먼저 실패 확인.
- [ ] 3중 원형 수로·순환로, 중앙 다층 본사와 좌우 2열 건물군 구성. 옥상 정원·테라스·층별 창·기둥·가로수·진입 다리 추가.
- [ ] 정면 조감도, 좌측, 후면, 가까이 보기 버튼과 자유 회전/팬/줌. 원본 비교 패널, 주야간. 1인칭/실내 입장은 아직 미구현 표시.
- [ ] 실제 Chromium에서 정면·좌측·후면·야간 캡처 확인. 회전·카메라 버튼·원본 비교·모바일 검증. 빌드/배치 테스트. 트랙 저장, main 미배포.

**완료 기준:** 원본과 동일하다고 주장하지 않는다. 공간 골격과 건축 1차 조형이 실제 3D로 존재하고 모든 방향에서 연속적으로 관찰 가능해야 한다. 사용자 외관 피드백 전 내부/대화로 다시 넘어가지 않는다.
