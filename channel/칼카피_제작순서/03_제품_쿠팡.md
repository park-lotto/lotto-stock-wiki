# 03 제품 특정 · 쿠팡 (정확한 이름 → 같은 제품 → 없으면 비슷한 제품)

★**모든 칼카피 채널 같은 순서(사장님 10-22 "먼저 해당 제품의 정확한 제품명이 나오는지 검색 결과나 영상 속에서 보고, 그걸 쿠팡에서 본 다음 없으면 비슷한 제품을 검색해서 스토리를 만들면 되는 거잖아" / "얜샷템도 그렇게 하고 칼카피 세션들에서는 다 쿠팡 붙이는 거 비슷한 거야")**: ①영상 속(포장·로고·자막·말·설명란)과 검색 결과(구글 렌즈·포털·유튜브)에서 **정확한 제품명** → ②그 이름으로 **쿠팡**(렌즈 결과의 쿠팡 링크 + 파트너스 API) → 같은 제품이면 그것 ③**없으면 쿠팡에서 비슷한 제품**(파트너스 API 결과 안에서 같은 종류·색·형태가 가장 가까운 것 — 아래 '비슷한 제품(alt) 고르기·밝히기')을 찾아 그걸로 스토리(대본은 PRODUCT_TALK alt 꼴 + 비슷한 제품이라고 말하는 줄 필수). 얜샷템·연예인레시피·현장썰·샥탬 모두 같다. 이 순서의 주인 = 이 문서 + 회원 PC `tools/calcopy/hybrid/flow.py` 제품 단계(exact → name_find·named → best, 10-22 실측 같은 순서).
(옛 10-21 "제품 쿠팡에서 정확한 거 찾는 거야"는 ①②를 건너뛰지 말라는 뜻 — 같은 제품이 없을 때 멈추라는 뜻이 아니다.)
★**쿠팡 정지 조심(사장님 10-22)**: 쿠팡 사이트를 프로그램으로 열지 않는다. 확인은 렌즈 결과 링크 + 파트너스 API(검색어 꼭 필요한 것만, 호출 사이 60초 이상, 제한·오류면 재시도 말고 멈춤).
나오는 것: 정식 제품명(브랜드·모델·색) · 쿠팡 상품번호·상품명 · 같은 제품이라는 근거(사진 대조) → `조사.md` §제품 + `근거.md`.

## 순서
1. **제품 전체 모양이 보이는 장면을 여러 장 자른다**(원본·벤치에서). 너무 작게 부분만 자르지 않는다(사장님 10-18 "여러 개 전체 모양 나오게"). 포장 라벨·로고가 보이는 장면이 최고.
   ```
   ffmpeg -ss <초> -i src/<원본>.mp4 -frames:v 1 -vf "crop=<w>:<h>:<x>:<y>" look/p1.jpg
   ```
2. **구글 렌즈로 이름 찾기**(무료·로그인 불필요, 크롬 창이 뜬다):
   ```
   py channel/hottemreport/현장썰하이브리드/렌즈쿠팡.py <이름> look/p1.jpg look/p2.jpg look/p3.jpg
   ```
   → `렌즈_<이름>.json`: 여러 장에서 **겹쳐 나온 이름(hits)이 위로**(한 장만 보면 배경 소품을 잡는다) + 그 안의 coupang.com 상품.
   함께 쓰는 것: 원본 대사(본인이 브랜드를 말함 — 김나영 '베두먼(=벳우먼)'), 원본 화면 상품 카드, 원본 설명 챕터.
3. **쿠팡 확인 = 파트너스 오픈API 먼저**(서버 키, 이 PC 회선 차단과 무관):
   ```
   PYTHONUTF8=1 py tools/calcopy/coupang_api_search.py look/coupang.json "<브랜드 정식 이름>" "<영문 이름>"
   ```
   → 상품번호·상품명·대표 이미지·로켓 여부(한 번에 최대 10개, 호출 한도 있음 — 검색어는 꼭 필요한 것만).
   상품평 글·리뷰 수가 필요할 때만 크롬으로: `channel/hottemreport/현장썰하이브리드/쿠팡검색.py`(쿠팡은 데이터센터 IP·헤드리스를 막는다 — 이 PC 회선 + 화면 뜨는 크롬).
4. **같은 제품 판정 = Claude 눈**: 쿠팡 대표 이미지 ↔ 원본 장면을 나란히 놓고 포장·로고·모양·색이 같은지 본다. 이름만 같고 용량·색이 다르면 맞는 옵션을 고른다.
5. 결과를 적는다: 조사.md 와 근거.md 에 `쿠팡 상품번호 · 상품명 · 확인 시각 · 대조한 장면 파일`.

- 쿠팡 파트너스 API 에 **명품·백화점 화장품(시슬리 기초·키엘 등)과 단종 한정판(AHC 박세리 세이프온 2021)이 안 나온다**(10-21 박정수·박세리 — 파트너스 제외 브랜드인지 확인 안 함). 이런 제품은 `렌즈쿠팡.py` 결과의 coupang.com 상품을 먼저 보고, 그래도 없으면 멈춤.

## 원본에 상표가 안 보일 때 (사장님 10-21 — 바로 멈추지 않는다)
1. **포털·유튜브에 '연예인 + 제품 낱말'로 다시 검색**해 제품 이름을 찾는다(네이버 통합검색 글·블로그·기사·본인 채널 영상 제목).
   예(10-21 선우용여 눈 티슈): 네이버 '선우용여 눈 티슈' → 블로그 '순풍 선우용여 <눈청결 티슈> 냉장고에 들어있어…'(본인 채널 냉장고 영상).
   그 연예인이 쓴 바로 그 제품을 가리키는 글만 근거 — 남의 쇼츠 쇼핑 태그(키치잇 EYE ONE 등)는 근거가 아니다.
2. 찾은 이름으로 쿠팡을 다시 찾는다 → 같은 제품이면 그것(대본은 근거 글이 가리키는 만큼만).
3. 그래도 없으면 **쿠팡(파트너스 API 결과)에서 같은 종류·색·형태가 가장 가까운 제품**을 쓰고(아래 '비슷한 제품 고르기'), 대본에 그대로 말한다 —
   '영상 보고 쿠팡에서 찾아봤는데 똑같은 건 없어서 후기 제일 많은 걸로 써 봤는데 좋더라'. 그 제품을 연예인이 쓴다고 말하지 않는다.
   (회원 PC: 서버 지시서 hybrid/flow.py 제품 단계 mode exact·named·alt → 대본 질문에 rules.PRODUCT_TALK)

## 비슷한 제품(alt) 고르기·밝히기 (사장님 10-25 "쿠팡에 같은 제품이 없으면 비슷한 제품으로 가되, 영상에서 분명히 말해야 한다")
1. **고르는 곳 = 파트너스 API 결과 안에서만**(`coupang_api_search.py` — 쿠팡 사이트는 열지 않는다. 그래서 후기 수·별점은 고르는 근거로 쓰지 않는다 — API 에 없다).
   검색어는 원본 제품의 **종류 + 색 + 형태**(예: '여성 흑백 패턴 니트 롱 가디건'), 꼭 필요한 것만 · 호출 사이 60초.
2. **근거를 조사.md §제품에 표로 남긴다**: 후보마다 `상품번호 · 상품명 · 종류 ○/× · 색 ○/× · 형태(길이·목선·무늬 등) ○/× · 대표 이미지 파일` → 셋이 가장 많이 맞는 것 1개. 원본 장면 ↔ 대표 이미지 나란히 눈 대조(같은 제품 판정과 같은 방법, 단 '같다'가 아니라 '어디가 같고 어디가 다르다'를 적는다).
   API 결과에 종류부터 다른 것뿐이면 → 아래 '멈출 때'.
3. **대본.json 에 `"product_mode": "alt"`** 를 적는다(exact·named·alt·given — 이 문서 판정 결과. 회원 flow 는 서버가 st.product.mode 를 넣는다).
4. **대본에 '같은 제품이 아니라 비슷한 제품'이라고 목소리로 말하는 줄이 꼭 있다** — 예 '영상 보고 쿠팡에서 찾아봤는데 똑같은 건 없어서 비슷한 걸로 사 봤어요'. 연예인이 이 제품을 쓴다고 말하지 않는다(rules.PRODUCT_TALK alt).
   판정 주인 = `tools/calcopy/hybrid/script_audit.alt_disclosed`(product_mode alt 인데 그 줄이 없으면 audit 반려 `product:alt_say`) · 시험 `shopping_shorts/tests/test_script_alt_say.py`.

## 멈출 때 (조사.md 맨 위 '멈춤: 쿠팡에 비슷한 제품도 없음' → 보고 → 그 편은 만들지 않는다)
- **쿠팡에 같은 종류(비슷한) 제품조차 없을 때만** 멈춘다(10-21 정보석 낫또는 이 규칙 전 멈춤).
- 이름은 나왔는데 쿠팡에 그 제품이 없다(명품·해외 직구 전용·자사몰만 — 10-18 김나영 벳우먼, 10-21 박정수 시슬리·키엘)는 **멈춤이 아니다** → ③ 비슷한 제품으로 간다(10-22 사장님).
- 남의 채널 설명란의 파트너스 상품은 근거가 아니다 — 원본 화면과 대조해서 같을 때만.

## 같이 정하는 것
- **분류**: 의약품·의료기기·기능성화장품이면 4단계 금지 품목 판단으로(전문의약품이면 중단 — 10-17 함익병 멜라논).
- **검색 키워드**(5단계 재료 영상용): 정식 이름·영문 이름·모델명 5~8개 + 뺄 단어(모음·TOP·가성비·먹방).
- 가격은 조사에만 적는다(대본에 금액 금지).
