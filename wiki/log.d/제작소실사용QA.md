# 제작소실사용QA — 작업 로그

## 2026-09-02 (회사PC)
사장님 지시 "제작소 모든 기능을 실제로 눌러보고 설계의도대로 도는지 1단계부터 끝까지
사람처럼 테스트해라 / 작은거 하나까지 / 3번에서 바꾼 게 렌더에 반영 안 되는 디테일까지 /
근본해결책까지 다 만들어라".

라이브를 Playwright MCP(크롬 프로필 공유 → 관리자 세션)로 직접 조작해 1~10단계 전부 실행,
최종 렌더(유료·자막제거 ON)까지 완주. 발견 33건, **근본수정 7건 배포**(전부 사보타주 검증 가드 포함).

★최대 수확: 사장님이 지목한 "화면은 바뀌는데 렌더엔 안 나온다"의 정체가 **저장 미호출**이었다.
자막 11개·헤드카피 14개 컨트롤이 `updateCaption()`/`updateHC()`만 불러 미리보기만 갱신하고
`saveHeadcopy()`를 안 불렀다(템플릿·모션팩 경로는 18곳에서 부름 = 같은 화면인데 어떤 조작만 저장됨).
실측: 자막색 #ff00cc·헤드카피색 #00ff88 → 새로고침하면 전부 #ffffff.

그 외 수정: URL직접추가 영상이 영영 "분석 중"(프론트 빈 shortcode vs 서버 sha1 — 2단계 완전차단) /
"2안" 거짓안내 / 가로형 경고 미표시(None을 bool로 뭉갬 + autoload가 측정 안 함) /
"3.4초 안 나와요"와 "다 채웠어요" 동시표시 / 자막제거 가격 미표시(서버가 charged 판정 제공).

미결(사장님 판단 필요): 9단계 길이표시 41초 vs 실제 31초(SYLLABLES_PER_SEC 5.7 vs 실측 7.83,
