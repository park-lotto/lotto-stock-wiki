사장님: "노바작가 영상에서 장면과 대본이 어떻게 커트되는지 보고 / 이븐쇼핑도 봐라 / 지금 너무 짧게 커트되서 처음 배치된다"

**이븐쇼핑 1EJB 대사↔컷 정렬(자막 기준)**
```
0.0~2.0   훅 "세월을 되찾아주는 미국 천재의 발명품"            → 1컷 2.0초
2.0~7.8   미끼 "최근 딱 봤을 때는 … 논란이라는데"              → 5컷 0.6~1.5초 (빠른 몽타주)
7.8~10.8  "이게 말도 안 되는게 원래는 …"                      → 1컷 3.0초 홀드
10.8~12.9 "… 광택을 내버리는"                                  → 1컷 2.1초
12.9~19.0 "제품이었지만 … 새걸로 변신시켜 버렸다는 거"          → 1컷 6.1초 홀드 (시연·증거)
19.0~21.2 "근데 진짜 충격적인 포인트는 …"                     → 3컷 0.7~0.8초 (다시 빠르게)
21.2~23.0 "… 되찾아 준다고"                                    → 1컷 1.7초
```
→ 리듬 = **훅 2초 한 컷 → 미끼 빠른 몽타주 → 핵심(없애버림·시연) 3~6초 홀드 → 충격 포인트 빠르게 → 마무리**.
   빠른 컷과 긴 홀드를 **줄 역할에 따라** 섞는다. 균일하지 않다.

## 심플하게 갈 길(제안, 미구현)
1. 훅 첫 컷 2.0초: 인트로 정지화면 1.2초 → 훅 영상 컷을 2.0초 홀드(정지화면을 빼거나 훅 컷에 합쳐서).
2. 홀드는 **줄 역할로** 정한다(행위 사전 말고): 공개(이건 바로 X)·고조의 `erased`(없애 버렸다는 거)·풀코스 detail 줄은 라운드로빈 없이 한 컷 3초+.
   이야기 작가는 줄마다 role을 이미 남긴다(`beat_sources[].role`) — 사전 태깅이 필요 없다.
3. 구절 맞춤 조각 하한 0.5초(그보다 짧으면 앞 컷에 붙임).
측정 도구: 이 문서의 ffmpeg 검출을 `tools/seed_analyzer/cut_rhythm.py`로 저장 예정(고치기 전/후 같은 자로).

## 컷 경계가 오는 자리 (2026-09-23, `tools/seed_analyzer/cut_phrase.py`, 썰 10편·컷 108개, 자동자막 낱말 시각 대조)

| 자리 | 비율 | 뜻 |
|---|---|---|

| 낱말 한가운데 | 2% | 거의 없음 |

- 이븐쇼핑 3편은 낱말 사이 컷이 많고(9·10·12개), 상위 채널(살림킹왕짱·이거였네)은 문장 끝·신호어 앞 비중이 높다.
- 결론: 히트작은 **문장 단위로만 끊지 않는다**. 줄 경계(문장 끝·신호어 앞·연결어미 뒤 = 35%)에 컷이 오고, 나머지는 문장 안에서
  약 2초마다 낱말 경계에서 바뀐다. 낱말 한가운데는 2%뿐이다.
- 우리 라이브 규칙(줄=칸, 줄 안에서 2.5초마다 컷)은 이 모양과 같다. 남은 차이 하나: 줄 안 컷 자리를 **시간으로만** 정하므로
  낱말 한가운데에 걸릴 수 있다(히트작 2%). TTS 낱말 시각으로 가까운 낱말 경계에 붙이면 없앨 수 있다(미구현).
