# 유료게이트 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development 로 태스크 단위 구현.

**Goal:** 웹앱을 "레퍼런스 랭킹 맛보기(무료) → 체험(전기능) → 결제 시 pro(전기능 무기한)"로 계정별 게이팅.

**Architecture:** 기존 FastAPI + HMAC 쿠키 세션(`_verify_session`/`_set_session_cookie`, cid:expiry:sig) 위에 얹는다. 접근권한은 `customers.plan`+`customers.full_access_until` 두 필드로 판정(단일 함수 `access_level`). 게이트는 기존 인증 미들웨어에 deny-by-default로 확장. 체험기간·크레딧 상한은 `settings` 테이블로 관리자 조정.

**Tech Stack:** FastAPI, sqlite3(Store), 기존 텔레그램 알림 유틸, Google OAuth(authlib 또는 순수 httpx).

## Global Constraints

- **판정 규칙은 단 하나의 함수 `access_level(...)`만** 구현·사용. API 게이트·화면·크레딧 모두 이 함수만 본다. 규칙 중복 금지.
- **게이트는 deny-by-default**: 무료 허용 prefix(`FREE_ALLOWLIST`)만 명시, 나머지 전부 차단. denylist 금지.
- **판정은 서버 DB 기준**. `full_access_until`/`plan`을 쿠키에 넣지 않는다(현 HMAC 쿠키는 cid 식별용만).
- **사장님 = customer_id=0 = 영구 pro+admin**. 절대 만료·차단되지 않는다.
- **기존 동작 무해**: `_AUTH_ON=False`(로컬 DASH_PASS 없음)면 게이트 전체가 통과(개발 편의). 기존 테스트 기준선(실패 8건) 이상으로 실패 늘리지 않는다.
- 새 컬럼/테이블은 `CREATE TABLE IF NOT EXISTS` + 기존 DB에 `ALTER TABLE ADD COLUMN`(존재 체크) 마이그레이션으로 — 라이브 DB 파괴 금지.
- 크레딧/체험 기본값: `trial_days=7`, `limit_lens=5`, `limit_render=2`, `limit_script=10`. 전부 `settings`로 조정 가능.

```python
def test_access_level_rules(tmp_path, monkeypatch):
    monkeypatch.setattr(appmod, "DB_PATH", str(tmp_path/"t.db"))
    s = Store(str(tmp_path/"t.db")); s.ensure_paywall_schema()
    cid = s.create_customer("u1","pw12")

    assert appmod.access_level(cid, now=1000) == "full"
    s.set_plan(cid, "pro")
    assert appmod.access_level(cid, now=1000) == "full"
    assert appmod.access_level(0, now=1000) == "full"          # 사장님
    assert appmod.access_level(99999, now=1000) == "ranking_only"  # 없는 고객
```
