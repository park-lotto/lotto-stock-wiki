## 저장 경로 및 덮어쓰기 규칙

모든 파일 → `raw/매일 엑셀넣을것/`

### 파일 교체 규칙

```
전체 실행(python download_daily.py) 시:
  → 폴더 내 모든 파일 삭제 후 8개 새로 저장
  → 항상 오늘 날짜 파일만 유지

개별 실행(--ame / --cafe / --bingsu) 시:
  → 해당 파일 패턴만 삭제 후 저장
```

## 파일명 규칙

```
{기본파일명}(출처표기)MMDD.확장자

MMDD = 오늘 날짜 (예: 0528)
출처: (태린이아빠) / (카페) / (눈)
```

## 다운로드 방식

```
Playwright (Python) → headless Chrome
각 파일 개별 다운로드 (전체 zip 아님)

이유:
- 눈꽃빙수 폴더에 993.7MB 대용량 파일 있어
  전체 zip 불가
- 파일별 선택 다운로드로 필요한 것만 받음
```

## 파일 탐지 전략

```
1순위: 파일명 패턴 텍스트 매칭
   → 파일 목록에서 패턴 문자열 포함 아이템 찾기

2순위: 위치 인덱스
   → 1순위 실패 시 N번째 파일로 fallback

링크 갱신으로 막힐 경우:
   → 스크립트 상단 URL 변수만 교체
```
