# 1소스믹스 — 영상 1개짜리 믹스 전용 로직

## 2026-08-04 (회사PC) — 라이브 배포, 배선 절반 남음

### 문제 (실측으로 확정)

제작소에서 **영상 1개**로 믹스하면 매번 3~4비트짜리 토막 영상이 나왔다.

최근 45건 실측:

| | 소재/목표 배율 | 소재부족 비율 |
|---|---|---|
| **1소스** | 0.67배 (20초 원본 / 목표 30초) | **100%** (6/6) |
| 다소스 | 1.53배 (44초 / 30초) | 2% (1/37) |

5일치 게이트 위반 50건: 길이부족 76% · 비트부족 44% · 장면반복 22% · 무편집구간 10%.

**근본원인**: 1소스는 원본 길이가 물리적 천장이다(편집=원본에서 빼는 작업). 그런데 목표
30초가 그대로 내려와 **없는 10초를 채우라는 요구**가 됐다. 늘리려면 같은 장면 반복이나
컷 없이 이어붙이기밖에 없는데 그게 바로 게이트가 잡는 위반이라, 매번 반려되고 토막이 났다.
`plan_gate`는 소재량을 모른 채 목표치하고만 비교해서(`plan_gate.py:130`) 달성 불가능한
기준으로 판정하고 있었다.

### 사장님 확정 스펙

1. **길이**: 하한 18초 / 상한 원본 (원본의 90% 목표). "최소 18~20초는 돼야 스토리 기본이
   들어간다. 더 줄이지 않는 쪽으로."
2. **is_key(핵심 태깅) 구간은 반드시 살린다** — 잘라내기 후보에서 제외, 군더더기만 걷어낸다.
3. **순서 반드시 변경** (원본 시간순 그대로면 "원본 트는 느낌")
4. **중복 없음**
5. **대본 각색** — 원본 표현을 베끼지 말고 다른 말로
6. **컷 경계를 약간 넘는 건 허용** — "다음 장면에서 맞추면 되는 흐름으로"
   → 컷마다 한 문장이 아니라 **한 문장이 컷 2~3개를 덮는다**
   (컷마다 문장을 요구하면 총량이 2배로 튄다 — 실측: 17.8초 화면에 35.2초 나레이션)
7. **훅은 확정 10패턴만** — "은행에서 빼서 지금 나랑 정해"
   - ★"여러분 다이소 가면 이거 사오세요"는 **원본이 다이소(매장) 소재일 때만** 벤치마킹
     (아무 데나 붙이면 훅과 화면이 따로 논다 — 사장님 정정)
   - "여러분~" 계열은 3개 중 1개꼴로 우대(은행 approved 523개 중 '여러분' 47개,
     '가면 사오세요'류만 9회 중복 수확 = 여러 채널이 베낄 만큼 통한 훅)
