모션그래픽 엔진 설계노트

시작 2026-10-20 · 방식 C안(자동 생성 + 부품 팩) · 이 문서는 자료를 받을 때마다 갱신한다 · 기존 트랙 모션그래픽팩(관제 222) 이어서
결정접수 장부영상별 사용법 받은 자료공통 원리엔진 구조 라이선스페이블 검토깃허브 61유튜브 14결정할 것다음

0. 정해진 것

  • 최종 목표 = 숯템메이커 같은 서비스(2026-10-20 사장님): 내부 도구가 아니라 회원이 프리셋을 골라 단계별로 모션그래픽 영상을 만드는 서비스. 그래서 회원에게 팔 수 있는 자료만 엔진에 넣고, 100명이 같은 프리셋을 써도 결과가 갈라져야 한다.
  • C안: 대사·음성·이미지를 넣으면 Opus가 코드로 모션그래픽 영상을 만든다(생성). 쓸 만한 효과는 떼어 motion-graphics-pack.js 부품으로 쌓는다(팩).
  • 렌더 바탕 = HyperFrames: 받은 CHA 소스 전부가 HyperFrames 0.8.105 규격이고, 이 PC에 HyperFrames 스킬이 깔려 있다. Remotion은 엔진 몫에서 뺀다(같은 일을 하는 두 벌 금지).
  • 판단 주인: 효과 모양·시간표 = shopping_shorts/static/motion-graphics-pack.js 한 곳(기존). 생성 규칙(지침) = 엔진 지침 파일 한 곳(새로 만들 것).
  • 프리셋 + 단계별 제작 페이지(2026-10-20 사장님): 숯템메이커처럼 스타일을 정해 둔 모션 프리셋을 고르고, 그 프리셋대로 영상·작업물을 단계별로 만드는 엔진 페이지가 필요하다. 흐름·데이터 구조는 페이블 검토 뒤 확정.
  • 모션그래픽만으로 완결(2026-10-20 사장님): 실사 소스 없이도 모션그래픽만으로 완성 영상(쇼츠·설명·광고·자료)을 처음부터 끝까지 만들 수 있어야 한다. 기존 쇼츠에 얹는 보조 효과가 아니다 → 장면 유형 전부(훅·상품 화면·숫자·비교·리스트·전환·엔드카드·자막)와 소리까지 엔진이 책임진다.
  • 원칙 유지: 창작하지 말고 찾아서 쓴다 → 레퍼런스·공개 소스를 실측해 옮긴다. 출처에 없는 수치는 지어내지 않는다.

2. 영상별 사용법 (자막·설명란·고정댓글 실측)

① 오퍼스5.5로 모션그래픽 만들기 — PPT프로젝트 채널

설정claude.ai · Opus 5.5 · 노력 높음 또는 엑스트라. 한 편에 10분~1시간 30분.

  1. 대사+초만 주기: “(대사) / 11초 / 텍스트 없이 모션그래픽으로” → 대사 타이밍에 맞춰 화면 구성. 자막은 사람이 따로 얹음.
  2. 레퍼런스 영상 따라하기: JasonZhu 사이트 → Opus 5.5 → 모션그래픽 → 영상을 받아 파일째 올림 → “참고해서 만들어 줘, 주제는 물방울의 여행”. 핵심 주장: 높은 퀄리티 레퍼런스를 보여주는 게 최선.
  3. 음악에 맞추기: 음악 파일+가사 → 박자·단어에 맞춰 움직임. 가사를 화면에 보여주기 좋은 단어(키프레임·커브·픽셀)로 지음.
  4. 내레이션+이미지: 15초 대본 → AI 음성 → GPT 이미지 6장 첨부 → “종이 찢어지는 레퍼런스처럼” / “복스 스타일로”. 이미지·음성 무료 → 클로드 구독 외 비용 0.
  5. 광고: 내레이션+콘셉트 → 광고. “세로로” 한마디로 9:16 재조정.
  6. 웹사이트 링크→광고: “이 브랜드 15초 광고, 콘셉트는 PPT 편집 화면에서 커서가 기능만으로 광고를 완성하고 슬라이드쇼로 열리며 끝”.

② 무조건 작동하는 5가지 트랜지션 — 존코바 (34초)

트랜지션 이름: Shape Morphing · Push · Pull Back · Liquid Transition · Swipe(가장 많이 씀).

고정댓글노션 링크 → 사용법:

  1. Newtake 접속 → 새 프로젝트 → 캐릭터 이미지를 캔버스에 올림
  2. ‘텍스트’ 노드: 무조건 컷 전환에서 아래 트랜지션 활용, Shape Morphing, Push, Pull Back, Liquid Transition, Swipe

엔진 관점: 코드 렌더가 아니라 영상 생성 AI다. 쓸 것은 트랜지션 이름 5개(용어)뿐 — CHA 소스에 같은 전환(풀백·스와이프·매치컷)이 코드로 있다. 자료는 상업·2차 가공 금지.

④ Claude로 15초 모션그래픽 — GPT PARK (7분 34초)

준비물Claude 데스크탑 · Opus 5.5 유료 플랜 · 설정 → 기능 → 코드 실행 및 파일 생성 켜기.

  1. 프로젝트 생성 → 지침(+)에 8섹션 지침 전문을 붙여넣음 (블로그에 전문, 아래 5절에 요약)
  2. 첫 메시지: 이름 · 출처(공식 사이트·소개글) · 브랜드 색 · 분위기 · 사진·로고 사용 여부 · 비율
  3. Claude가 바로 만들지 않고 문구 표([인용]/[요약]/[창작] 표시)+팔레트·폰트·도형·모션 제안을 먼저 보여줌 → “알아서 해 줘”면 이후 확인 없이 제작
  4. 음악: 무료 상업 음원 찾기 → 못 받으면 직접 작곡·합성. 128BPM · 8마디 = 정확히 15초
  5. 렌더 뒤 자체 검수: 마디별 대표 프레임(겹침·잘림·오탈자·대비) + ffprobe(해상도·길이·오디오) → MP4+WAV 전달
  6. 수정은 장면 번호+바꿀 내용으로, 같은 대화에서. 예: “3번 장면 두 번째 키워드를 ‘실전 가이드’로, 나머지는 바꾸지 마”

핵심 문장: 고정 규칙은 지침에, 바뀌는 값은 메시지에. 신뢰도의 핵심은 1번(출처만)과 7번(자체 검수).
