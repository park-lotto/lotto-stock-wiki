# 03 제품 특정 · 쿠팡에서 정확히 같은 제품

사장님(10-21): "제품 쿠팡에서 정확한 거 찾는 거야." 얜샷템·연예인레시피는 **같은 제품**이어야 한다(비슷한 제품 대체 금지 — 현장썰 하이브리드만 예외로 '비슷한 제품을 찾았다'를 허용, 규칙 §14).
나오는 것: 정식 제품명(브랜드·모델·색) · 쿠팡 상품번호·상품명 · 같은 제품이라는 근거(사진 대조) → `조사.md` §제품 + `근거.md`.

## 순서
1. **제품 전체 모양이 보이는 장면을 여러 장 자른다**(원본·벤치에서). 너무 작게 부분만 자르지 않는다(사장님 10-18 "여러 개 전체 모양 나오게"). 포장 라벨·로고가 보이는 장면이 최고.
   ```
   ffmpeg -ss <초> -i src/<원본>.mp4 -frames:v 1 -vf "crop=<w>:<h>:<x>:<y>" look/p1.jpg
   ```
2. **구글 렌즈로 이름 찾기**(무료·로그인 불필요, 크롬 창이 뜬다):
   ```
   py channel/hottemreport/현장썰하이브리드/렌즈쿠팡.py <이름> look/p1.jpg look/p2.jpg look/p3.jpg
   ```
   → `렌즈_<이름>.json`: 여러 장에서 **겹쳐 나온 이름(hits)이 위로**(한 장만 보면 배경 소품을 잡는다) + 그 안의 coupang.com 상품.
   함께 쓰는 것: 원본 대사(본인이 브랜드를 말함 — 김나영 '베두먼(=벳우먼)'), 원본 화면 상품 카드, 원본 설명 챕터.
3. **쿠팡 확인 = 파트너스 오픈API 먼저**(서버 키, 이 PC 회선 차단과 무관):
   ```
   PYTHONUTF8=1 py tools/calcopy/coupang_api_search.py look/coupang.json "<브랜드 정식 이름>" "<영문 이름>"
   ```
   → 상품번호·상품명·대표 이미지·로켓 여부(한 번에 최대 10개, 호출 한도 있음 — 검색어는 꼭 필요한 것만).
   상품평 글·리뷰 수가 필요할 때만 크롬으로: `channel/hottemreport/현장썰하이브리드/쿠팡검색.py`(쿠팡은 데이터센터 IP·헤드리스를 막는다 — 이 PC 회선 + 화면 뜨는 크롬).
4. **같은 제품 판정 = Claude 눈**: 쿠팡 대표 이미지 ↔ 원본 장면을 나란히 놓고 포장·로고·모양·색이 같은지 본다. 이름만 같고 용량·색이 다르면 맞는 옵션을 고른다.
5. 결과를 적는다: 조사.md 와 근거.md 에 `쿠팡 상품번호 · 상품명 · 확인 시각 · 대조한 장면 파일`.

- 쿠팡 파트너스 API 에 **명품·백화점 화장품(시슬리 기초·키엘 등)과 단종 한정판(AHC 박세리 세이프온 2021)이 안 나온다**(10-21 박정수·박세리 — 파트너스 제외 브랜드인지 확인 안 함). 이런 제품은 `렌즈쿠팡.py` 결과의 coupang.com 상품을 먼저 보고, 그래도 없으면 멈춤.

## 원본에 상표가 안 보일 때 (사장님 10-21 — 바로 멈추지 않는다)
1. **포털·유튜브에 '연예인 + 제품 낱말'로 다시 검색**해 제품 이름을 찾는다(네이버 통합검색 글·블로그·기사·본인 채널 영상 제목).
   예(10-21 선우용여 눈 티슈): 네이버 '선우용여 눈 티슈' → 블로그 '순풍 선우용여 <눈청결 티슈> 냉장고에 들어있어…'(본인 채널 냉장고 영상).
   그 연예인이 쓴 바로 그 제품을 가리키는 글만 근거 — 남의 쇼츠 쇼핑 태그(키치잇 EYE ONE 등)는 근거가 아니다.
2. 찾은 이름으로 쿠팡을 다시 찾는다 → 같은 제품이면 그것(대본은 근거 글이 가리키는 만큼만).
3. 그래도 없으면 **쿠팡에서 같은 종류 중 후기 많고 별점 좋은 제품**을 쓰고, 대본에 그대로 말한다 —
   '영상 보고 쿠팡에서 찾아봤는데 똑같은 건 없어서 후기 제일 많은 걸로 써 봤는데 좋더라'. 그 제품을 연예인이 쓴다고 말하지 않는다.
   (회원 PC: 서버 지시서 hybrid/flow.py 제품 단계 mode exact·named·alt → 대본 질문에 rules.PRODUCT_TALK)

## 멈출 때 (조사.md 맨 위 '멈춤: 쿠팡에 같은 제품 없음' → 보고 → 그 편은 만들지 않는다)
- 원본에 포장·라벨이 안 보이고, 위 '상표가 안 보일 때' 1~3을 다 해도 같은 종류 제품조차 쿠팡에 없다(10-21 정보석 낫또는 이 규칙 전 멈춤).
- 렌즈·검색으로 이름은 나왔는데 쿠팡에 없다(명품·해외 직구 전용·브랜드 자사몰만 — 10-18 김나영 벳우먼은 29CM·자사몰뿐이었다, 쿠팡 규칙 전 편).
- 남의 채널 설명란의 파트너스 상품은 근거가 아니다 — 원본 화면과 대조해서 같을 때만.

## 같이 정하는 것
- **분류**: 의약품·의료기기·기능성화장품이면 4단계 금지 품목 판단으로(전문의약품이면 중단 — 10-17 함익병 멜라논).
- **검색 키워드**(5단계 재료 영상용): 정식 이름·영문 이름·모델명 5~8개 + 뺄 단어(모음·TOP·가성비·먹방).
- 가격은 조사에만 적는다(대본에 금액 금지).
