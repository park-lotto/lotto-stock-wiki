## 💡 전략 결론 (가장 중요 — 다음 세션 방향)
- **지금 = 잘 만들어짐 ≠ 잘 됨.** 외부 사용자 0명, 검증 안 됨.
- **차별화 해자 2개가 약함**: ① AI판단이 generic(로또 시각 아님) ② 백테스트 검증기록 없음
- **위키 = 차별화의 답**: 종목카드 AI판단이 **위키(종목·섹터 과거분석·내 판단)를 읽고** 생성하면 → "로또의 시각" = 복제불가 해자. 지금 대시보드↔위키 **완전히 따로 놂** = 위키가 죽어보이는 이유.
- **뉴스 히스토리 = "모든 종목" 아니라 "중요 종목(시그널 픽·관심종목)만"** 쌓기. 시그널 상위픽을 keyword_news 대상에 추가하면 됨.
- **검증**: 만들기 멈추고 **카드/브리핑을 본인 채널에 던져 반응 보기**가 유일한 답.
