## 2026-08-17 — 사용자 키 등록(BYOK) + 포인트 차감

사용자가 자기 API 키를 등록하면 무료, 안 하면 포인트 차감. 사장님 지시대로
"60대는 못하니 그냥 비용 내고 쓰게" — 포인트가 기본이고 키 등록은 아끼는 선택지다.
1P=100원·마진 0. 자막제거 5P(VMake 실비용 500원/편, 유일한 실측 근거).

**가장 큰 건: 자막제거 무과금 구멍을 막았다.** `/api/produce/mix/clean`에 크레딧
검사가 아예 없었고 소스 1편당 VMake 1콜이라 소스 3개면 1,500원이 무제한으로 샜다.

키 선택과 과금 판단을 `keyroute` 한 곳으로 묶었다(0순위-B) — 따로 적으면
"키 등록했는데 돈이 나가는" 상태가 조용히 생긴다.

리뷰가 잡은 실제 결함 6건 전부 수정. **최악은 포인트 이중차감** — 잔액 10P에
5P 5건을 동시에 던지니 3건이 성공하고 -5P가 됐다(실측 재현). `balance()` 읽고
`points_add()` 쓰는 두 문장 사이에 트랜잭션이 없어 워커들이 같은 잔액을 봤다.
SQL 한 문장(`INSERT...SELECT...WHERE`)으로 원자화했다.

⚠️ 서버에 `BYOK_MASTER_KEY` 넣어야 키 등록이 켜진다. 없으면 기능이 꺼진다
(평문 저장으로 폴백하지 않는다).
⚠️ 영상제작 3P·TTS 1P는 **임시값**이다. 마진 0이라 틀리면 그대로 손해 —
`usage_report.py`로 실측 후 admin에서 조정할 것.
⏭ 키 받는 방법 영상 촬영(버튼은 있고 URL만 비었다) · Gemini 실사용 전환(44곳이라 후속)
