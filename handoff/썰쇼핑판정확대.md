# 썰쇼핑 수집 넓히기 (2026-09-04 시작 · PC 재부팅으로 중단)

## 사장님 질문에서 시작
"최신순으로 정렬하면 왜 두번째가 7시간전이지" → "수집채널을 넓혀야하는데 어떻게 할까"

## 실측으로 밝힌 것 (전부 서버 DB에서 직접 확인)

### ① 정렬은 정상이다 — 데이터에 진짜 구멍이 있다
서버 `reference.db` → `settings` 테이블 → key `last_run::youtube` (★`last_run` 테이블 아님)
```
수집시각 2026-09-03T23:10:02Z (= KST 09-04 08:10) · 9,170편
썰쇼핑(제품정체형+오용형) = 267편뿐
  0.20h  깐깐대디숏핑  공사비 아깝다면? 그냥 붙이세요     ← #1
  7.40h  꿀팁꿀템     한국 천재가 만들어 떼돈 번 제품…   ← #2
  0.5~7시간 구간 = 0건  ← 화면의 "7시간 전"과 정확히 일치
```

### ② 카테고리 분포 — 썰쇼핑만 얇다
```
홈템 3,433 · 기타 3,280 · 레시피 1,153 · 뷰티 817
제품정체형 200 · 장비템 126 · 차량템 94 · 오용형 67
```

### ③ ★진짜 지렛대: 채널이 아니라 **판정기**다
문형(천재·떼돈·정체·발명품·돈방석·부자가 된·몰래·비밀·용도·활용법·사용법)으로 훑으니
```
문형 걸린 영상 780편
  → 썰쇼핑으로 분류된 것  193편 (25%)
  → 기타 265 · 홈템 228 · 뷰티 48 · 레시피 36 로 샌 것  587편 (75%)
```
샌 것 실물(명백한 제품정체형인데 '기타'):
```
 9.5h 기타 인생갓템  조용히 떼돈버는 사람들의 비밀
10.6h 기타 럭키박스  절대 부러지지 않는 연필의 정체
12.4h 기타 공가미   이케아도 감탄해버린 천재 디자이너의 발명품
 6.0h 홈템 집순이살림 거실 넓어보이는 천재적 공간 분리법   ← 7시간 구멍 안!
 0.7h 기타 사볼겨?  슥 닦았더니 새 폰 됐어요             ← 구멍 안!
```
→ **구멍 구간에 이미 후보가 들어와 있다. 판정기가 안 붙였을 뿐이다.**
코드에도 같은 기록이 있다 — `categorize.py`: 오용형 판정기를 후보 채널 8곳 54편에
돌리니 **26편(48%)만 통과**(2026-08-19 주석).

## 그래서 정한 순서
```
1  판정기 넓히기 (categorize.py 제품정체형·오용형 문형 보강)  ← 수집 0 추가, 재고 587편이 즉시 산다
2  썰쇼핑 채널 시드 추가 (platform_seeds, youtube/account 현재 1,973개)
3  발굴 자동화 — 썰쇼핑 결 채널만 픽업
```

## ⏭ 다음에 할 일 (여기서 멈췄다)
**사장님 답을 기다리는 중이었다**: 샌 587편 목록(제목+채널)을 뽑아 드리면
"이건 썰쇼핑 / 이건 아님"을 골라주시기로. 그 답으로 판정기를 맞춘다.

- [ ] 587편 목록을 HTML로 뽑아 바탕화면에 (사장님이 O/X만 찍게)
- [ ] 그 결과로 `categorize.py` 문형 보강
- [ ] 보강 전/후 분류 건수 대조(회귀 확인) — **교양·뉴스가 섞이지 않는지 반드시 본다**

## ⚠️ 함정 (먼저 읽어라)
- **어휘 하나로 붙이지 마라.** '천재·정체·비밀'은 교양·뉴스도 쓴다. `categorize.py`에
  이미 교양·뉴스 제외 로직이 있다(183~187줄 근처). 같은 사고가 '주방'(08-19)·
  '만들기'(08-21)로 두 번 났다 → 메모리 `reference_어휘축_단독신호_함정`
- **정확도를 자동카테고리로 재지 마라.** 사장님 눈이 정답이다.
- 채널 문턱 ≠ 영상 문턱.

## 같은 날 곁가지로 발견한 것 (아직 손 안 댐)
- 랭킹 카드의 "N분 전"이 **굳는다**: 항목에 발행시각(`posted_at`)이 없으면
  `fmtAgo`(index.html)가 수집 시점 스냅샷 `age_hours`를 그대로 쓴다.
  실측: 09:50에 보는데 #1이 "12분 전"(실제 약 1시간 50분 전).
- **틱톡·도우인·샤오홍슈는 2026-07-30 이후 실수집 0건** — 남은 8건이 전부 `demo:true` 가짜.
  네이버클립 08-31 / 핀터레스트 08-29 / 쓰레드 08-18로 지연. 유튜브만 정상.
