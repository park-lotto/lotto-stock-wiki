장단점

볼케이노

좋은 점

  • 로직이 서버에 있어 베끼기 어렵고, 고치면 바로 모든 회원에게 반영
  • 제작자 여러 명이 프리셋을 올리는 장터 구조(30여 채널)
  • 단계 지시가 서버에서 오니 Claude 모델이 약해도 흐름을 잃지 않음

아쉬운 점

  • 서버가 멈추거나 느리면 제작이 멈춤
  • 단계마다 서버 왕복
  • 수정은 지원 채널만

노바작가

좋은 점

  • 서버가 필요 없음
  • 시작이 쉬움(파일 하나 끌어다 놓기)
  • 회원 PC에 모든 과정이 파일로 남아 투명함

아쉬운 점

  • 파이썬 소스·지시문이 그대로 노출 — 복제·재배포에 무방비
  • BGM·글꼴·클립을 회원이 직접 준비
  • 결과물 HTML은 보기만 하고 고칠 수 없음
  • 키를 채팅창에 붙여 넣게 함(대화 기록에 남음)
  • 작업 폴더가 영상마다 수백 MB씩 쌓임

숏템

좋은 점

  • 드라이브 완본을 만든 그 엔진 그대로 — 품질 기준이 이미 있음
  • 처음 설치에 전부(도구·자산·모델) — 회원이 준비할 것 없음
  • 서버 부담 거의 0, 서버가 멈춰도 제작은 됨
  • 미리보기 = 완성본(같은 렌더러), PC 화면에서 고치고 Claude와 이어짐
  • 엔진 검사(근거·글자 폭)가 Claude 답도 걸러냄

아쉬운 점·숙제

  • 설치 파일이 큼(약 1GB 예상, 실측 전)
  • 엔진이 PC에 있어 완전한 보호는 안 됨(컴파일+라이선스로 문턱만)
  • 새 프리셋은 업데이트로만 — 켤 때 자동으로 받게
  • 배경음악 판별은 제미나이보다 약함(소리 분류 모델 필요)
  • 틱톡·인스타 채널 목록은 아직 못 엶(영상 주소는 됨)

숏템이 가져올 것 · 피할 것

  1. 가져올 것(노바): 시작을 '파일 하나 · 버튼 하나'로. 설치 exe가 끝나면 바로 로컬 설정 화면이 뜨게.
  2. 가져올 것(볼케이노): 단계마다 '다음 할 일 한 줄'을 Claude에게 주는 방식 — 숏템 MCP 응답에 이미 넣음(need·next). 하이쿠도 길을 잃지 않게.
  3. 피할 것(노바): 키를 채팅에 받지 않기 · 결과물을 보기만 하는 HTML로 끝내지 않기 · 작업 찌꺼기를 회원 폴더에 그대로 쌓지 않기.
  4. 피할 것(볼케이노): 제작 단계가 우리 서버에 매달리게 하지 않기 — 서버는 라이선스·업데이트만.
