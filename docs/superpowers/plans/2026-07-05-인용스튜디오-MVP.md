# 인용 스튜디오 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 검증된 인용 엔진(`quote_extractor.py`)을 웹에서 굴리는 화면 — URL 입력 → SSE 진행률 → 골든 후보 카드(tier순) → 체크로 인용 픽 → `quotes.json` 저장. (스펙 §4 "인용 스튜디오", 첫 컷=픽까지. 캡처 스트립·클립선택은 후속.)

**Architecture:** 엔진에 스트리밍 진입점 `extract_stream`(제너레이터, 진행이벤트+최종 doc)을 추가하고, `dashboard/server.py`에 기존 `/yt/refs`·`/yt/teardown`(SSE) 패턴 그대로 3개 엔드포인트를 얹는다. 화면은 독립 `dashboard/quote_studio.html`(`yt_refs.html` 룩 따름). 엔진의 기존 `extract()`/CLI는 손대지 않는다(테스트 보존).

**Tech Stack:** Python 3.14, FastAPI + StreamingResponse(SSE), pytest 9 + `fastapi.testclient.TestClient`, 바닐라 JS(EventSource 대신 fetch+ReadableStream, POST body 필요), 기존 `gemini_client`(18키 폴백).

## Global Constraints

- 엔진의 기존 `extract()`, `candidate_to_dict()`, `score_quotes()`, `chunk_segments()`, `to_mmss()` 등 **Task 1-7에서 만든 함수는 시그니처·동작 변경 금지**(23 테스트 보존). 추가만 한다.
- Gemini는 반드시 `scripts/yt_agents/gemini_client.py` 경유. yt-dlp는 `python -m yt_dlp`.
- SSE 이벤트는 기존 관례와 동일: `yield f"data: {json.dumps(ev, ensure_ascii=False)}\n\n"`, 타입 `running`/`progress`/`done`/`error`.
- 서버 모듈 import는 기존 패턴(server.py:218-236) 따라 `import quote_extractor as _qe` + try/except None 폴백.
- 후보 카드 정렬은 엔진이 이미 `(tier, -score, -heat)`로 정렬해 내려줌 — 화면은 그 순서 그대로 렌더.
- MVP는 **픽까지**. capture(프레임/비전)·클립선택은 이 플랜 범위 밖 → `extract_stream`은 capture 안 함.
- 저장 경로: `out/quote_studio/<video_id>.json`. video_id는 URL에서 파싱(watch?v=, youtu.be/, /live/).
- 테스트: `python -m pytest tests/yt_agents/test_quote_extractor.py tests/test_quote_studio_api.py -v`. 기존 `test_hot_clips.py` 2건 실패는 baseline(무관).
- 공유 워킹트리(feat/briefing-engine): 커밋 전 `git branch --show-current` 확인. server.py·yt_refs.html은 다른 세션도 만지므로 **추가 위주로, 최소 diff**.

```python
def extract_stream(url, topic, max_segments=None):
    """스트리밍 오케스트레이터 — 진행이벤트 + 최종 결과를 yield.
    capture는 하지 않음(MVP 픽전용). CLI용 extract()와 별개."""
    yield {"type": "progress", "phase": "메타"}
    info = fetch_info(url)
    source = f"{info['channel']} / {info['webpage_url']}"

    yield {"type": "progress", "phase": "자막"}
    segments = get_transcript(url)
    if max_segments:
        yield {"type": "progress", "phase": "bound",
               "used": max_segments, "total": len(segments)}
        segments = segments[:max_segments]

    chunks = chunk_segments(segments)
    cands = []
    for i, ch in enumerate(chunks):
        yield {"type": "progress", "phase": "채점", "done": i, "total": len(chunks)}
        try:
            reply = gemini_client.call_json(build_score_prompt(topic, ch))
            cands.extend(parse_score_reply(reply, source))
        except Exception as e:
            print(f"[extract_stream] 청크 {i} 실패: {e}", file=sys.stderr)
            yield {"type": "progress", "phase": "청크실패",
                   "done": i, "total": len(chunks)}

    apply_heatmap(cands, parse_heatmap(info))
    assign_tiers(cands)
    cands.sort(key=lambda c: (c.tier, -c.score, -c.heat))
    doc = {"topic": topic, "source": source,
           "quotes": [candidate_to_dict(c) for c in cands]}
    yield {"type": "result", "doc": doc}
```
(주: `score_quotes`는 함수 내부 `import gemini_client`를 그대로 둬도 됨 — extract_stream만 모듈-레벨 참조를 쓰면 테스트 monkeypatch가 걸린다. 상단에 `import gemini_client` 추가 시 순환/부작용 없음: gemini_client는 순수 래퍼.)

```python
@app.get("/yt/quote-studio", response_class=HTMLResponse)
def yt_quote_studio_page():
    p = os.path.join(HERE, "quote_studio.html")
    if not os.path.exists(p):
        return "<h1>quote_studio.html 준비중</h1>"
    with open(p, encoding="utf-8") as f:
        html = f.read()
    return HTMLResponse(content=html, headers={"Cache-Control": "no-cache, must-revalidate"})


@app.post("/yt/quote_extract")
async def api_yt_quote_extract(req: Request):
    """URL → 골든 발언 후보 추출(엔진 extract_stream) — SSE. 4.5h 영상은 수분 소요."""
    if _qe is None:
        return JSONResponse(content={"error": "quote_extractor 모듈 없음"}, status_code=503)
    body = await req.json()
    url = (body.get("url") or "").strip()
    topic = (body.get("topic") or "").strip()
    if not url:
        return JSONResponse(content={"error": "url 필요"}, status_code=400)
    ms = body.get("max_segments")
    max_segments = int(ms) if ms else None

    def _stream():
        yield f"data: {json.dumps({'type':'running'}, ensure_ascii=False)}\n\n"
        try:
            for ev in _qe.extract_stream(url, topic, max_segments=max_segments):
                yield f"data: {json.dumps(ev, ensure_ascii=False)}\n\n"
        except Exception as e:
            yield f"data: {json.dumps({'type':'error','message':str(e)[:200]}, ensure_ascii=False)}\n\n"

    return StreamingResponse(_stream(), media_type="text/event-stream")


@app.post("/yt/quote_save")
async def api_yt_quote_save(req: Request):
    """픽한 인용들을 quotes.json으로 저장 → out/quote_studio/<vid>.json."""
    if _qe is None:
        return JSONResponse(content={"error": "quote_extractor 모듈 없음"}, status_code=503)
    body = await req.json()
    url = (body.get("url") or "").strip()
    quotes = body.get("quotes") or []
    vid = _qe.parse_video_id(url) or "unknown"
    out_dir = os.path.join(ROOT, "out", "quote_studio")
    os.makedirs(out_dir, exist_ok=True)
    save_path = os.path.join(out_dir, f"{vid}.json")
    doc = {"topic": body.get("topic", ""), "source": url, "quotes": quotes}
    with open(save_path, "w", encoding="utf-8") as f:
        json.dump(doc, f, ensure_ascii=False, indent=2)
    return JSONResponse(content={"ok": True,
                                 "path": os.path.relpath(save_path, ROOT).replace("\\", "/"),
                                 "count": len(quotes)})
```

```html
<script>
const $=s=>document.querySelector(s);
let CANDS=[];
function esc(s){return (s||'').replace(/[&<>]/g,c=>({'&':'&amp;','<':'&lt;','>':'&gt;'}[c]));}
function render(){
  const box=$('#cards'); box.innerHTML='';
  CANDS.forEach((q,i)=>{
    const d=document.createElement('div'); d.className='card';
    d.innerHTML=`<input type="checkbox" data-i="${i}">
      <div class="ts">${esc(q.ts)}<div class="tier">T${q.tier}</div></div>
      <div class="txt"><span class="badge b-${esc(q.stance)}">${esc(q.stance)}</span>
        <span class="badge" style="background:#222;color:#aaa">${esc(q.evidence)}</span>
        ${esc(q.text)}
        <div class="meta">score ${q.score}${q.has_visual?' · 📄자료':''}${q.heat?' · 🔥'+q.heat.toFixed(2):''} · ${esc(q.source||'')}</div>
      </div>`;
    box.appendChild(d);
  });
  $('#save').disabled = CANDS.length===0;
}
async function run(){
  const url=$('#url').value.trim(), topic=$('#topic').value.trim();
  if(!url){$('#prog').textContent='URL을 입력하세요';return;}
  const bound=$('#bound').value.trim();
  CANDS=[]; render(); $('#run').disabled=true; $('#save').disabled=true;
  $('#prog').textContent='시작...';
  const body={url,topic}; if(bound) body.max_segments=parseInt(bound);
  const resp=await fetch('/yt/quote_extract',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify(body)});
  const reader=resp.body.getReader(); const dec=new TextDecoder(); let buf='';
  while(true){
    const {value,done}=await reader.read(); if(done)break;
    buf+=dec.decode(value,{stream:true});
    let idx; while((idx=buf.indexOf('\n\n'))>=0){
      const line=buf.slice(0,idx).trim(); buf=buf.slice(idx+2);
      if(!line.startsWith('data:'))continue;
      const ev=JSON.parse(line.slice(5).trim());
      if(ev.type==='progress'){
        if(ev.phase==='채점') $('#prog').textContent=`채점 ${ev.done+1}/${ev.total} 청크...`;
        else if(ev.phase==='bound') $('#prog').textContent=`${ev.used}/${ev.total} 세그먼트만 채점(제한)`;
        else if(ev.phase==='청크실패') $('#prog').textContent=`청크 ${ev.done+1} 실패(스킵)`;
        else $('#prog').textContent=ev.phase+'...';
      } else if(ev.type==='result'){
        CANDS=ev.doc.quotes; render();
        $('#prog').textContent=`완료 — 후보 ${CANDS.length}건 (T1 ${CANDS.filter(q=>q.tier===1).length}·T2 ${CANDS.filter(q=>q.tier===2).length}·T3 ${CANDS.filter(q=>q.tier===3).length})`;
      } else if(ev.type==='error'){ $('#prog').textContent='오류: '+ev.message; }
    }
  }
  $('#run').disabled=false;
}
async function save(){
  const picked=[...document.querySelectorAll('#cards input:checked')].map(c=>CANDS[+c.dataset.i]);
  if(!picked.length){$('#savemsg').textContent='선택된 인용이 없습니다';return;}
  const r=await fetch('/yt/quote_save',{method:'POST',headers:{'Content-Type':'application/json'},
    body:JSON.stringify({url:$('#url').value.trim(),topic:$('#topic').value.trim(),quotes:picked})}).then(r=>r.json());
  $('#savemsg').textContent = r.ok ? `저장됨 (${r.count}건) → ${r.path}` : ('저장 실패: '+(r.error||''));
}
$('#run').onclick=run; $('#save').onclick=save;
</script>
```
