# 인기상품 랭킹 — 화면 구조 설계 메모 (2026-10-20, 초안·사장님 승인 전)

## 근거
- 11곳 화면 조사(스크린샷 scratchpad/bench): 아이템스카우트·판다랭크·셀록홈즈(구 셀러라이프)·블랙키위·키워드마스터·데이터랩·FastMoss·Kalodata·Helium10·Exploding Topics·Google Trends
- 직접 눈으로 확인: 판다 황금키워드(기준시각·3일증가율·행 안 추이선·상세분석 버튼, 단 1~9위가 뉴스·인물 키워드), FastMoss 상품검색(왼쪽 필터·상품행·7일 추이선)
- 정답지 검증(레퍼런스랭킹 실제 터진 쇼츠): lecture/lead_check.py · novelty_check.py · follow_check.py · news/news_lead.py

## 여러 곳 공통 뼈대 (그대로 따른다 — 사용자가 이미 익숙한 문법)
1. 위: 기간·카테고리 토글 / 가운데: 정렬되는 순위 표 / 행 클릭 → 상세
2. 열 뼈대 = 수요(검색수·판매) · 공급(상품수) · 비율(경쟁강도)
3. "언제 기준" 표시
4. 상세 순서 = 핵심 숫자 → 추이 차트 → 연령·성별 → 연관 키워드 → 실제 상품·콘텐츠

## 한 곳을 베끼지 않는 우리 식 (국내 도구에 없는 것 위주)
| 우리 장치 | 빌려온 생각(여러 곳) | 우리 데이터 |
|---|---|---|
| 행 = **상품**(키워드 아님), 쇼츠 가능만 | FastMoss·Kalodata 상품행 | 6사이트 베스트 + 쇼츠 분류 |
| **이 상품으로 터진 쇼츠** 칸 | Kalodata 최고매출 영상 | 레퍼런스랭킹(국내 도구엔 없음) |
| **신호 배지**(색) — 근거 있는 것만 | 판다 등급배지 | 사전검색 +50%(터진 비율 2.2배), 전년비 2배(2.3배), 방금 터짐(2주 내 재히트 24/25) |
| 행 안 미니 추이선 | FastMoss·판다 | 데이터랩 주간 |
| **곧 뜰 시즌** 칸: 작년 이맘때+N주 배수·집중시기 | 블랙키위 시즌배수 | 데이터랩 3년 주간(강사: 피크 2달 전 제작) |
| **연령 쏠림** 배지(아이·10대 / 5060) | 데이터랩 연령 | 데이터랩 연령 필터 + 기준어 |
| **왜 뜨나** 한 줄(뉴스·화제) | 블랙키위 급상승+관련뉴스 | news_scan(품절·완판·유행) |
| 추세 단계(오르는 중/정점/꺼짐) | Exploding Topics | 데이터랩 |
| 리뷰 적은데 순위 높음(덜 알려진 신박템) | Helium10 기회 프리셋 | 쇼핑베스트 순위×리뷰수 |
