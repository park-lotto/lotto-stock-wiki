# 대본 경로 지도 (2026-09-16 실측 — 정리 작업의 0단계)

"이 스타일로 대본 만들기" 한 번 → 실제로 무엇이 도는가. 전부 코드에서 줄번호로 확인한 것.

## 2단계 — 대본 생성  (`POST /api/wiki/generate`, app.py 3438~3748)

화면(produce.html 17822 s2Generate)은 한 번 누르면 **요청을 둘로 나눠** 보낸다:
씨앗이 있으면 `auto_style`+seed_hook 요청 1개 + 고른 `style_ids` 요청 1개. 결과를 합친다.

| 분기 | 조건 | 생성기 | 검사·재시도 | 켜고 끄는 것 |
|---|---|---|---|---|
| A1 조립 | style_ids 있음 | `_assembled_drafts` → spine_fill.build_draft (모델 0회) | script_gate.check | `assemble_off` |
| A2 스타일 생성 | style_ids 있음, 조립 못 채운 스타일 | `generate_by_styles` → `generate_one_style` | check → 실패 시 재작성 최대 3회 → 치명이면 **버림(None)** | `script_grounded_enabled`(=admin만) · `script_claim_check` · `script_claim_fatal` · `ping_pong_enabled`/`bank_enabled`(은행) |
| B 픽업 생성 | style_ids 없음 | `generate_guarded_variations` → `generate_variations` | fatal_content_checks + semantic → 치명이면 버리고 재요청 → 0개면 `_grounded_fallback` | 위와 같은 스위치 + `pickup_script.filter_drafts` |

프롬프트에 실리는 것(A2 기준): style_block(남의 히트대본 3편) + 재료 + 은행(예산=재료×1.5) + facts_block + (grounded면) 장면 전부 + _GROUNDED_RULE + (claims면) _claim_prompt.

같은 목적("재료 밖으로 새지 마라")의 장치가 **5겹**: grounded / 은행 예산 / facts_block / claims 검사 / 소재 일치 치명.

## 3단계 — 장면 매칭  (`POST /api/produce/mix/start` → mix_pipeline._plan_and_tts)

| 분기 | 조건 | 무엇을 하나 | 모델 호출 |
|---|---|---|---|
| ① 상속 | 확정 대본 + script_structure.beat_sources | `build_inherit_plan` — 2단계가 줄마다 적은 src_seg를 **그대로** 붙임. 출처 없는 줄은 앞 컷의 다음 컷 / 역할표 / 낱말 겹침 | **0회** |
| ② 대본 매칭 | 확정 대본, beat_sources 없음 | `build_edit_plan(given_script)` | 있음 |
| ③ 장면 먼저 | 대본 **없음** | `build_scene_first_plan` — single_source / backbone / **ping_pong(장면↔대사 왕복 교정)** / judge | 있음 |

★ **제작소 흐름(2단계 확정 → 3단계)은 항상 ①이다.** 확정 대본이 오면 코드가 `scene_first`를 끈다(mix_pipeline "확정 대본이 있어 scene_first를 끈다").
→ `ping_pong_enabled=1`이어도 제작소에서는 **ping_pong이 한 번도 안 돈다.** ③에만 있다.
→ 장면↔대사 의미 일치를 보는 곳: **2단계 없음(형식만), 3단계 ① 없음(상속만).** 아무 데도 없다.

env 스위치(edit_plan.py): BLOCK_MIX · REWRITE_MIX · SCENE_BINDING · SCENE_GUIDE · SCRIPT_FACTSHEET · SCRIPT_FACT_GATE — 6개, 전부 ②③ 경로용.

| 사고 | 자리 | 원리 |
|---|---|---|
| 2안→1안 · 느림 (볼펜) | A2, 재시도 3회 뒤 치명(사실 근거)으로 버림 | 장면 0개라 근거 없음 → 반려 예정 |
| 팬케이크 대사↔장면 무관 5/10 | 2단계 A2가 10줄 전부 needs_scene=True·src_seg 채움 → 3단계 ①이 그대로 상속 | 의미 검사가 어디에도 없음 |
| 새송이(엉뚱한 제품) | A2/B 프롬프트에서 은행·스타일예시가 재료를 압도 | 은행 조립 출구 4개 중 1개 예산 누락(오늘 한 곳으로 합침) |

## 정리 방향 (1단계에서 확정)

남길 경로 = **A2(grounded 켜짐) → ①상속**. 이것이 사장님 말씀("씨앗 고정 → 있는 장면 보며 대본")과 같다.
- 2단계: A1 조립·B 픽업은 제작소 버튼에서 뗀다(다른 화면은 유지). grounded는 스위치 없이 항상.
- 검사: 치명 = 소재 일치 하나. 나머지는 재작성 1회, 그래도 안 되면 그대로 낸다(0안 없음).
- 의미 일치: 2단계에서 **장면을 먼저 고르고 그 장면에 대해 쓰게** 순서를 바꾼다(검사 추가가 아님).
- 스위치 5개 + env 6개 중 이 경로에 걸린 것은 없앤다.
