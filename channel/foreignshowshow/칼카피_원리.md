# 샥탬스토리 칼카피 원리서 — 벤치(해외쇼츠 샤크탱크)가 왜 터지나, 우리는 어떻게 똑같이 하나 (우리 자산, 살아 있는 문서)

> 사장님 2026-10-18: "대충하지 말고 칼카피 잘해서 **원리 다 적어놓고 계속 쌓으면서** 다음 편 만들 때도 동일하게 축적해서 **우리 자산으로** 만들면서 하는 거야."
> 규칙: ① 원리는 **실측 근거(편 id·시각·숫자)**와 같이 적는다 — 느낌 금지 ② 기계가 읽는 값은 `tools/calcopy/shark/rules.json`(렌더·검사가 읽는 주인)에, 이 문서는 "왜·어떻게"를 ③ 편을 만들 때마다 §9 '편마다 배운 것'에 쌓고, 확인된 것은 해당 절로 올린다(그 자리를 고친다, 덧붙이기만 하지 않는다) ④ 다음 편은 이 문서 + rules.json 으로 만든다(편마다 새로 정하지 않는다).
> 검사: `tools/calcopy/shark/compare_bench.py`(벤치 나란히 기준표) — 기준표 칸 = 아래 절 번호.
> 마지막 갱신: 2026-10-18 (뼈대 — 품질 칼카피 담당이 실측으로 채우는 중)

## 0. 한 줄 요약 (채워지는 중)
투자자의 놀란 얼굴(빨간 원+큰 반응 자막)로 0초에 결말을 던지고 → 핵심어만 색으로 터뜨린 큰 자막으로 시연·불편·숫자를 빠르게 → 원음 투자 경쟁 → 방송 후 결과로 닫는다.

## 1. 박자(대본 흐름) — 확인됨(8편 판독·1편 줄 표)
0~3초 결말 반응(원음, 빨간 원) → 시연(나레) → 기존 불편(나레+원음) → 숫자 → 지분 경쟁(원음 교대, 돈다발) → 방송 후 결과(나레, 확인된 사실만).
- 나레 = 반말 전언체(~는데/~다고), 원음 = 영어 + 한국어 번역 자막. 벤치 나레 사실은 그대로 믿지 않는다(STORMBAG 정정 3건, 인수인계 §3-6).

## 2. 시작 훅 (0~3초) — 실측 일부
- 빨간 실선 원 0~2초 6/8편, 반지름 178~217·선 12~15(프리셋 실측). 대상 = 놀란 투자자 얼굴.
- 반응 자막은 ×1.25 크게(6/8편 18칸). 색·번짐·등장 움직임: _채우는 중_
- 효과음: _미측정_

## 3. 자막 꼴 — 확인됨(프리셋 실측)
GmarketSansBold 68px, 1줄 잉크 929~988(창 가운데), 나레·번역 같은 꼴. 흰 글자 오른쪽 아래 옅은 그림자. 자막 바뀔 때 가로 흐림 약 2프레임.

## 4. 강조 낱말(와우 포인트) — _채우는 중_
- 7색: 노랑[252,226,61]·주황[245,155,72]·빨강[235,78,79]·초록[66,252,81]·민트[64,248,240]·파랑[67,165,246]·분홍[242,98,146] + 같은 색 번짐 빛.
- 어느 낱말을 고르나(숫자·핵심 명사·감탄…, 몇 %), 어느 색을 어디에: _8편 296칸 세는 중_
- 예(QMJ): "3분내로"=민트 · "15L 물을 빨아들이는"=초록 · "허리가 작살이 나죠"=초록 · "물만 부으면"=분홍 · "2억 7천만원"=노랑.

## 5. 효과 — _채우는 중_
실선 원 6/8 · 점선 원 4/8 · 화살표(분홍·빨간 곡선·초록) · 날개 돈다발 3/8(투자 제안 줄) · 색 번쩍(초록·빨강·노랑) 8/8 편당 2~10회 컷 넘김. 언제·무엇에·크기·움직임: _10fps 실측 중_

## 6. 효과음·배경음 — _미측정_

## 7. 장면 고르기
- 원음 줄 화면 = 같은 원본 시각에 말하는 본인(어긋남 0.1초 넘으면 고침) — 1편 확정.
- 벤치는 실제 현장(홍수 등) 장면으로 실감을 낸다 — 방송 클립에 없으면 현장 1080p 재료를 따로 찾는다.

## 8. 소리 — 확정
목표 −9.0 LUFS·최고점 ≤ −0.5 dBFS(벤치는 −7~−8·클리핑, 따라 깨뜨리지 않음). 성우 지훈(벤치 f0 116Hz 최근접).

## 9. 편마다 배운 것 (쌓는 곳 — 확인되면 위 절로 올린다)
- 1편 STORMBAG(10-18): 1차는 길이·소리·싱크만 맞추고 강조·효과·효과음을 빼서 "떨어진다"는 지적 → 판정을 기준표로 바꿈. 벤치 나레 사실 오류 3건 정정.
- 3편 DropStop: 원음 클립에 더빙 트랙이 섞임 → 영어 원음 트랙(140-7) 지정.
- 1편 프리셋판(10-18 새벽): 제목 노랑 214~304/흰 322~408(벤치 211~304/318~407)·자막 68px 잉크 936~994(벤치 929~988) 맞음. 제목이 길면 글자가 작아진다 — 4편 88.5·6편 79.5px vs 벤치 100~135 → **제목은 줄당 글자 수를 벤치 범위로 짧게**(규칙 수치는 rules.json 에 재는 중).
- 원음 창 받아쓰기 검사는 영어를 한글로 옮겨 적어(예 "댓츠 프리티 쿨") 판정 불가 → 원음은 영어 받아쓰기로 검사.
- 4편 Spikeball: 짧은 쉼(0.137초)에 말 꼬리가 섞이면 쉼 늘리기가 말소리를 반복 → 엔진 수리(75d27994d).
