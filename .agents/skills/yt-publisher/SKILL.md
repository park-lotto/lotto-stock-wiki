## When to use

사용자가 다음 중 하나를 요청할 때:
- `/publish [대본파일경로]`
- "제목 뽑아줘", "설명란 만들어줘", "업로드 준비해줘"
- "퍼블리셔 돌려줘"

---

## Step 1: 대본 읽기

`out/scripts/YYYYMMDD_script.md` 를 읽는다.
파일 경로를 사용자가 안 줬으면 가장 최근 날짜의 script 파일을 사용한다.

---

## Step 2: 메타데이터 생성 원칙

### 제목 (5개 후보)

**원칙:**
- 검색량 있는 키워드 포함 (종목명, 섹터명, 수급, 빈집, 탑픽)
- 클릭 욕구를 자극하는 패턴 사용:
  - 숫자형: "지금 수급 빈집 [종목] — 3가지 이유"
  - 반전형: "모두가 놓친 [종목] — 데이터는 이미 말했다"
  - 긴급형: "지금 당장 봐야 할 [섹터] 대장주"
  - 질문형: "[종목] 지금 사도 될까? 수급이 답했다"
  - 결과형: "[종목] 수급 빈집 확인 — 매수 조건 충족"
- 50자 이내
- 클릭베이트 금지 (실제 내용과 일치해야 함)

### 설명란 (1개)

**구조:**
```
[첫 줄 — 핵심 요약, 검색 노출용]
오늘 종목: [종목명] | 섹터: [섹터명] | 신호: [수출🔴 수급빈집 등]

[본문 — 영상 내용 요약 3~4줄]
...

[타임스탬프]
0:00 후킹
0:20 오늘 다룰 내용
0:40 수출/펀더멘털 데이터
2:30 수급 상태
4:00 이평선·차트
5:00 리스크
5:45 매매 포인트
7:15 마무리

[채널 소개 1줄]
로또의 주식 | 수급과 매물대 기반 실전 매매 인사이트

#주식 #[종목명] #수급분석 #탑픽 #[섹터명]
```

### 썸네일 문구 (3개 후보)

**원칙:**
- 3~6단어
- 임팩트 있는 숫자나 키워드
- 색상 대비가 강한 짧은 텍스트 기준으로 작성
- 예: "수급 빈집 포착", "+97% 폭등 중", "지금이 진입 타이밍"

### 키워드 (5개)

- 종목명, 섹터명, 매매기법 관련 검색 키워드
- 예: "수급분석", "빈집추적", "탑픽종목", "[종목명]주가", "[섹터명]전망"

---

## Step 3: 출력 형식

`out/publish/YYYYMMDD_metadata.md` 에 저장

```markdown
# 업로드 메타데이터 — YYYYMMDD

## 제목 후보 (5개)
1. [제목1]
2. [제목2]
3. [제목3]
4. [제목4]
5. [제목5]

> 추천: **[번호]번** — [이유 한 줄]

---

## 설명란
```
[설명란 전체 텍스트]
```

---

## 썸네일 문구 (3개)
1. [문구1]
2. [문구2]
3. [문구3]

---

## 키워드 (5개)
[키워드1], [키워드2], [키워드3], [키워드4], [키워드5]
```
