## ① ✏대본수정 — 기능은 있었는데 **고치는 도중 화면이 갈아엎여** 글자가 날아갔다

### 처음 의심했다가 실측으로 배제한 것 (짐작 금지)
| 의심 | 실측 결과 |
|---|---|
| 버튼이 배포 안 됐나 | **아니다.** 서버 md5 `0f93b580…` = 로컬과 **동일**, `대본수정` 5회 등장 |
| 옛 코드가 서비스 중인가 | 아니다. `d43491706`(✏대본수정 신설)이 `origin/main`에 있다 |
| 렌더 경로가 둘인가 | `renderBand()` 한 곳뿐. 세로목록(1266~)은 **다른 화면**(`SL.server`로 잠김) |
| iframe 캐시인가 | 아니다. `SCENE_LAB_BUST`로 `&t=`를 이미 붙이고 있다 |

### ★진짜 원인
`pollPhash()`가 페이지를 연 뒤 **4초마다 최대 20회(≈80초)** 돌면서 새 phash가 오면
`render()`를 부른다. `render()` → `renderBand()`는 칸 DOM을 **통째로 갈아끼운다**.

→ 사장님이 [✏ 대본수정]을 눌러 고치는 중이면 그 `contenteditable` 요소가 **사라진다**.
   커서와 입력 중이던 글자가 그대로 날아가고, 저장까지 못 가니 **"아까 고쳤는데 안 된다"**가 된다.
   조용히 일어나서(에러 0건) 기능이 없는 것처럼 보였다.

같은 입구가 하나 더 있었다 — `waitNarrRegen()`은 저장 후 **최대 40초** 배경으로 돈다.
그 사이 **다른 칸**을 고치면 똑같이 날아간다.

### 고친 방법 — 문 하나를 세웠다
```js
let _repaintPending = false;
function isNarrEditing(){ return Object.keys(NARR_EDIT).length > 0; }
function repaint(){ if (isNarrEditing()){ _repaintPending = true; return; } render(); }
function flushRepaint(){ if (!_repaintPending || isNarrEditing()) return;
                         _repaintPending = false; render(); }
```
- **배경 다시그리기는 전부 `repaint()`를 지난다** — `pollPhash`, `waitNarrRegen` 둘 다 교체.
- ⚠️**미루기만 하면 안 된다**: 편집 중 도착한 phash·자막이 영영 안 붙는다.
  → `closeNarrEdit`에서 `flushRepaint()`로 **정확히 한 번** 갚는다.
- 사람이 직접 부른 `render()`(칸 담기·비우기·정렬 등)는 **안 건드렸다** — 회귀 0.

### 실측
```
편집 중 repaint 3회 → render 0회 (종전 3회)   ← 글자가 안 날아간다
편집 닫은 뒤        → render 정확히 1회        ← 밀린 갱신이 붙는다
편집 안 열었을 때   → 평소처럼 2회             ← 회귀 없음
```

## ② 미리보기(장면 편집 iframe) 크기 — 같은 판단이 **두 곳에 다르게** 적혀 있었다

### ★진짜 원인 (CLAUDE.md 0순위-B 위반)
```
마크업        <iframe id="sceneLabFrame" style="…height:150vh;min-height:1100px…">
넓게보기 복귀  f.style.height='88vh';        ← min-height 는 아예 안 씀
```
[⛶ 넓게 보기]를 켰다 끄면 **원래 크기로 안 돌아온다**(150vh → 88vh로 쪼그라들고,
`min-height:1100px` 하한도 사라져 창이 짧으면 더 작아진다).
= 사장님이 말한 **"무슨 작업만 하면 크기가 변한다"**.

### 고친 방법 — 기준값을 한 곳으로
```js
const _SL_FRAME_H    = '150vh';      // ★크기 기준은 여기 두 줄뿐
const _SL_FRAME_MINH = '1100px';
function _applySceneLabFrameSize(f, wide){ … }   // 크기를 입히는 유일한 함수
```
- `toggleSceneLabWide()`는 이제 **높이를 손으로 안 적는다** — 이 함수만 부른다.
- **마크업에서 height/min-height를 뺐다** → 두 벌이 생길 수 없다(숫자가 한 군데뿐).
- `_syncSceneLab()`(iframe을 처음 띄우는 곳)도 이 함수를 탄다 → 첫 표시·복귀가 늘 같은 값.
- 전체화면일 땐 `minHeight:'0'` — 하한을 그대로 두면 오히려 스크롤이 생긴다.
