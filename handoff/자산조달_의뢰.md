## 왜 필요한가 (이게 지금 유일한 배포 차단 사유다)

`shopping_shorts/brainbulb/` 파이프라인은 링크 하나로 mp4 까지 실제로 나온다(2026-09-14 실측:
최민식 편 37.4초 완성). 그런데 **밈과 효과음이 볼케이노 팩에서 복사해 온 것**이라:

```
□ git 에 없다          → 회사 PC·서버에서 그대로 실행하면 밈 0장·효과음 0개로 나온다
□ 저작권 미확인        → 유튜브 업로드가 불가능하다
□ 로컬 한 대에만 있다   → 이 PC가 죽으면 끝이다
```

지금 읽는 자리(하드코딩된 기본값, `shopping_shorts/brainbulb/make.py`):

```
밈     ~/.volcano/jobs/20260911_뇌전구_박수홍/pepe/fm/     (PNG 57장)
효과음 ~/.volcano/jobs/20260911_뇌전구_박수홍/sfx_norm/    (MP3 79개)
```

**나머지(대본·자막·음성·렌더)는 전부 우리 코드라 문제가 없다. 이 두 가지만 바꾸면 배포가 열린다.**

---

## ★라이선스 기준 — 이게 제일 중요하다

유튜브에 많이 돌아다닌다는 것은 **허락받았다는 뜻이 아니다.** 지금 문제가 정확히 그거다.

```
□ 상업적 이용 가능 (유튜브 수익 창출 포함)
□ 재배포 가능 (git 저장소에 넣어 다른 PC로 간다)
□ 출처 표기 의무가 있으면 → 그 문구를 파일 옆에 적어 둘 것
□ 애매하면 받지 마라. 한 장이라도 섞이면 편 전체를 못 올린다
```

**안전한 출처 (추천 순)**
| 출처 | 무엇 | 주의 |
|---|---|---|
| **직접 제작** | 밈 그림을 그리거나 AI 로 생성 | 가장 안전. 생성물은 서비스 약관 확인 |
| freesound.org (CC0 필터) | 효과음 | ★필터를 **CC0** 로. CC-BY 는 표기 의무 |
| Pixabay / Mixkit | 효과음 | 자체 라이선스, 상업 이용 가능 |
| OpenGameArt (CC0) | 효과음·그림 | 라이선스가 항목마다 다르다 |
| Wikimedia Commons (PD/CC0) | 그림 | 항목마다 확인 |

**받지 말 것**: 페페(Pepe the Frog) — 지금 쓰는 것이 이것이고, **저작권자가 있다**(Matt Furie).
그래서 바꾸려는 것이다. 같은 캐릭터를 다시 받아오면 의미가 없다.

# ① 밈 (PNG)

## 규격

```
형식      PNG · 투명 배경 권장(불투명이면 흰 배경)
크기      정사각형 · 최소 512×512 · 최대 1024×1024
내용      감정이 **한눈에 읽히는** 얼굴/캐릭터 1개. 글자 없음
          ★글자가 박힌 그림은 피하라 — 자막과 겹쳐 읽힌다
```

## 감정 10종 — 이게 코드가 요구하는 목록이다 (`spec.EMOTIONS`)

| # | 감정 | 어떤 그림이 필요한가 | 현재 상태 |
|---|---|---|---|
| 1 | `경악/충격` | 눈 크게 뜨고 입 벌림 | 매핑 있음 |
| 2 | `당황` | 식은땀·시선 회피 | 매핑 있음 |
| 3 | `분노` | 얼굴 붉음·찡그림 | 매핑 있음 |
| 4 | `비웃음/조롱` | 실눈·비꼬는 웃음 | 매핑 있음 |
| 5 | `무표정/멍` | 초점 없는 눈 | 매핑 있음 |
| 6 | `의심/떨떠름` | 한쪽 눈썹 올림·입 삐죽 | 매핑 있음 |
| 7 | `슬픔/울음` | 눈물·처진 눈 | 매핑 있음 |
| 8 | **`만족/엄지척`** | 엄지 세움·흡족한 표정 | ⚠️ **매핑 없음** |
| 9 | **`피곤/지침`** | 다크서클·축 처짐 | ⚠️ **매핑 없음** |
| 10 | **`기타`** | 중립. 애매할 때 쓰는 자리 | ⚠️ **매핑 없음** |

> ⚠️ 표시 3종은 지금 **매핑이 없어서 팩의 첫 파일(`000.png` = 비웃음)이 대신 나온다**
> (실측 2026-09-14 `frames.meme_path` 폴백). 즉 「만족」 자막에 비웃는 얼굴이 붙는다.
> **10종을 다 채워야 이 버그가 사라진다.**

## 몇 장씩?

**감정당 3~5장.** 같은 감정이 한 편에 두 번 나올 때 같은 그림이 반복되면 티가 난다.
→ **총 30~50장**이면 충분하다.

★번호는 `_1` 부터 이어서. 코드 쪽 연결은 이 트랙에서 처리한다.

# ② 효과음 (MP3 또는 WAV)

## 규격

```
형식      MP3 44.1kHz 스테레오 (WAV 도 받는다 — 이쪽에서 변환한다)
길이      0.3~1.0초  (현재 팩 실측 평균 0.58초)
용도      컷이 넘어가는 순간 한 발씩 터진다. 꼬리가 길면 다음 컷을 덮는다
음량      정규화는 이쪽에서 한다 — 원본 그대로 주면 된다
```

## 계열 4종 — 코드가 컷 번호로 돌아가며 쓴다 (`spec.SFX_FAMILY`)

한 편(컷 32개 기준)에서 각 계열이 실제로 몇 번 쓰이는지 세어 봤다(`spec.SFX_SEQ32` 실측):

| 계열 | 느낌 | 언제 쓰이나 | 한 편에 | 필요 개수 |
|---|---|---|---|---|
| **pop** | 가볍게 톡 튀는 소리 | 평범한 전환 (가장 많다) | 8번 | **8개** |
| **click** | 딸깍·탁 | 사실을 짚을 때 | 8번 | **8개** |
| **hit / boing** | 둔탁하게 치는 소리 | 반전·충격 | 8번 | **8개** |
| **ding** | 맑게 띵 | 숫자·결론 | 8번 | **8개** |

**총 32개면 충분하다.** (현재 팩은 79개지만 한 편이 쓰는 자리는 32개다)
★한 편에서 같은 계열이 8번 돌아가므로, **계열당 8개를 채우면 한 편 안에서 소리가 안 겹친다.**

> 있으면 좋은 보조 3종: `swoosh`(휙 지나감) · `fail`(실패음) · `censor`(삐-) 각 2~3개.
> 없어도 돌아간다.

## 파일 이름 · 넣을 자리

```
out/assets/sfx/
  pop_1.mp3    pop_2.mp3   …  pop_8.mp3
  click_1.mp3  …  click_8.mp3
  hit_1.mp3    …  hit_8.mp3
  ding_1.mp3   …  ding_8.mp3
```
