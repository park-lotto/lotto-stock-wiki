## 확정된 것
- **썸네일 = 시안5**: 띠 "캡컷 노가다 전혀없음!!"(썰템홈샷 채널명 가림) / "클로드가 진짜 일냈다!" / "**쇼핑쇼츠** 만들어줘!!" 한마디면 끝 · 프리텐다드 Black · 가운데 클로드 코드 픽셀 캐릭터
- **대본 = B**(딸깍 시대). 대본 A(실연형)는 HTML 안에 보관
- **성우 = 타입캐스트 필재 1.1배**(2편과 같은 성우. 10-20 기록 "빠르면 발음 뭉개짐" 때문에 1.25 대신 1.1)
- **벤치마킹 = 베끼기 아님**(사장님 11-04): 같은 원본도, 비슷한 주제의 다른 원본도 가능. 가져오는 건 그 채널이 **후킹을 어떻게 잡고 이야기를 어떻게 끌고 가는지** → 장면 3에 '흔한 오해' 4문장 + 같은 주제·다른 원본 쇼츠 3개 나란히
- **화면 = 손그림 + 실제 제작 영상**(3편과 같은 결). 문장마다 화면이 바뀐다(문장 74개 → 비트 74개, Jev: 원인 0.91 · 해결 0.87)
- **오프닝 22.8초**: 클로드 창(실제 앱처럼 다시 그린 것)에 "외국인 + 한국 화장품 쇼츠 만들어줘" 타이핑(키보드 소리) → 숏클 13단계 체크(×8) → 완성 카드 → 완성 쇼츠 원음 재생

## 다시 만들기 (작업 폴더에서)
```
py make_open.py              # 오프닝(클로드 창) — playwright 필요
py build2.py seg             # 장면 13개(문장 비트) — 고친 장면만: py build2.py seg s05
py build2.py final           # 합본 + 자막 → yt4_draft_v3.mp4
py build.py voice s05        # 대사 고친 장면만 음성 재합성(먼저 voice/s05.mp3 지우기) — 저장소 로또의 주식 + 타입캐스트 키 필요
cd thumb && set THUMB_COPY=... && py make_thumb.py 출력.png   # 문구는 시안5_문구.json
```
- 대사 = `build.py` 의 `SCENES[].text` / 문장별 화면 = `build2.py` 의 `BEATS`(문장 수와 같아야 한다) / 손그림 = `build2.py` 의 `PAGES`
- 저장소 경로가 `바탕화면\로또의 주식` 이 아니면 환경변수 `LOTTO_REPO` 로 알려 준다(음성 합성 때만)
