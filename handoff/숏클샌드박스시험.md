## 수정 목록 (아직 아무것도 안 고침, 고쳐서 finish 한 번에)

설치
1. `installer/install.ps1:176` `process.argv[2]` → `node -e` 는 `argv[1]`. 권한 목록이 저장되지 않음(관제 298부터). 재현 완료.
2. 설치팩에 `msvcp140.dll` 없음 → 받아쓰기 실패, 제작 불가. 런타임 설치 후 통과로 **확정**. 설치 한 줄 재실행 안내는 틀린 안내.
3. `Paste code here` 에서 붙여넣기 불안정, 빈 엔터면 로그인이 끝나고 스크립트가 빠져나감. 왜 됐는지는 미확정.
4. `local_ui.js openBrowser` 는 창이 떴는지 모르고 성공 반환. 새로 깐 Chrome 의 '앱 선택' 창에 가려 안 뜬 것처럼 보였음 → 주소도 같이 보여 주기.
5. 점검 뒤 작업실·키 입력 화면 안내 없음. 회원이 있는 줄 모름.
6. 숏클과 무관하게 Claude 창만 켜도 저장된 회원 키로 자리를 잡음(60초 하트비트) → 다른 PC 가 막힘.
7. '앞 PC 창을 닫아라' 안내가 회원에게 불명확. 강제 해제는 동작 확인됨.
8. 작업 폴더 밖 읽기 승인 창이 영어로 뜸(1회).

화면
9. 채널명 판단이 세 벌: `hybrid/styles.py:229` 는 한 칸으로 합침, `shopping_shorts/calcopy_make.py:153`·`channel_profile.py:252` 는 칸마다. 글자가 나뉜 프리셋은 **미리보기만** 겹침(완성본 머리띠는 정상). 완성본은 오른쪽 위 흐린 워터마크로 채널명이 한 번 더 나옴.
10. `▶ 5초 재생` 은 소리 없음, 이름이 오해를 부름.
11. 작업실에 목소리·배경음악 미리듣기가 안 보임(`index.html:410,435` 는 sample_url 있을 때만). 숏템 샘플 주소가 넘어오는지부터 확인.
12. 사용법: 회원 Claude 는 "뭐라고 말하면 뭘 만들어줘?" 에 잘 답함. 지침 수정 불필요, 시작하기 탭·점검 끝 안내에 그 질문을 알려 주기만.

받기
13. 긴 영상 통째 받기가 남음: `hybrid/screen.py:246-252`(구간 실패·구간 없음), `runner_ops.py:437` 벤치. 길이 상한 없음. 이번 편 재료는 56~83초 4개라 안 걸림. 4K 상한은 77e0b4870 으로 반영 확인.

제작 흐름
14. **완성본 판정 요청 없이 완성 처리됨.** 파일 열기도 막혀 있었고 회원 Claude 가 시트를 못 찾음. 완성 뒤에야 봄. 1.5초 컷에 다른 브랜드 꿀병이 보이는데 통과.
15. 완성본 검사에서 걸렸는데 고치지 않고 그대로 재렌더 → 같은 곳에서 또 걸림. 변경 없는 재렌더는 막을 것.
16. `목소리·영상 만들기부터 다시` 문구. 목소리를 새로 만드는지 미확인(비용 문제). 타입캐스트 사용량으로 재기.
17. **쿠팡 제품이 화면에 0컷.** 판매 영상인데 풍경·양봉만.
18. **소재(사양벌꿀)와 제품(마누카꿀) 불일치.** '비슷한 제품' 경로.
19. 흐림 띠가 눈에 띔(14초·19초), 후반 풍경 반복, 아래 약 20% 빈 칸(프리셋 원래 모양인지 미확인).
