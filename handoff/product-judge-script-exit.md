# product-judge-script-exit

## 완료

- 제품 판정 API 장애가 대본 생성 전 422를 내던 경로를 선택 레퍼런스 제품군 폴백으로 변경.
- 외부 위키 카드의 URL/원문을 내부 job 영상 ID로 복원해 씨앗 재료가 중복 제거 후 사라지던 문제 수정.
- 추가 영상 다수결보다 사용자가 선택한 레퍼런스 제품군을 우선하고, 같은 제품군 추가 영상만 생성 재료로 사용.
- 서로 다른 제품군 동률이어도 선택 레퍼런스를 확인할 수 있으면 그 제품으로 계속 생성.
- 레퍼런스가 없는 혼합 요청과 고정 주제 불일치는 임의 제품을 고르지 않고 기존 오류 유지.
- 여러 제품을 의도적으로 다루는 리스트형은 단일제품 필터를 적용하지 않음.
- 대본 화면 씨앗 카드 위에 “대본 생성 시 씨앗 영상을 하나 고르세요. 대본의 소재를 확인할 때 사용됩니다.” 안내 추가.
- “담긴 영상을 전부 씁니다” 문구를 “모두 분석하고 씨앗 제품과 맞는 영상을 쓴다”는 실제 동작에 맞게 수정.

## 검증

- 안내문 추가 후 관련 회귀검사 71개 통과.
- 신규 회귀: 판정 API 503, 제품군 동률, 다른 제품 영상이 더 많은 경우에도 씨앗 제품 고정 및 같은 제품 추가 영상 포함.
