# 영상 제작소 작업파일 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 제작소 작업을 서버에 저장해 다른 페이지에 갔다 와도, 내일 다시 들어와도 그 단계에서 이어서 작업할 수 있게 한다.

**Architecture:** `produce_works` 신규 테이블에 클라이언트 작업상태(`state_json`)를 통째로 스냅샷한다. 기존 `saveWork()`(sessionStorage 저장)에 1초 디바운스 서버 POST를 얹어 저장 트리거를 새로 발명하지 않는다. 복원은 `/produce?work=<id>`로 들어와 서버 상태를 기존 복원 경로와 같은 모양으로 먹인다. `sessionStorage`는 그대로 둔다 — 서버는 **추가 계층**이다.

**Tech Stack:** FastAPI · sqlite3(`shopping_shorts/store.py`) · 바닐라 JS(`produce.html`, `sidebar.js`) · pytest · Node(JS 하네스 테스트)

**스펙:** `docs/superpowers/specs/2026-07-17-제작소-작업파일-design.md`

## Global Constraints

- **작업 폴더는 `.tracks/대본믹스통합/`뿐이다.** main 폴더의 코드 파일은 단 하나도 건드리지 않는다.
- **pytest 조건**: `pytest -q --tb=no -rf -p no:cacheprovider`. `-s`를 붙이지 마라 — 로컬에선 통과하고 병합 게이트에서 깨진다.
- **게이트 기준선 = `10 failed`**(test_apify_client×6, test_edit_plan_build×1, test_mix_pipeline×1, test_mix_render_flow×2). 판정은 "전부 green"이 아니라 **"병합 전보다 실패가 늘지 않았나"**.
- **태스크마다 뮤테이션을 돌린다.** 이 저장소는 "통과하는데 결함을 못 잡는 테스트"가 반복됐다.
- **뮤테이션 되돌릴 때 `git checkout --` 금지**(커밋 안 한 작업이 날아간다). 정확한 문자열 치환으로 되돌리고 `md5sum`으로 대조한다.
- **`state_json`은 `sessionStorage.produce_work`의 스키마 그대로** + `step`. 새 형식을 발명하지 않는다.
- **`deco`·`headcopy`·`voice`·`caption_style`은 `state_json`에 담지 않는다** — `mix_jobs`가 주인이다.
- **JS 테스트는 `produce.html`/`sidebar.js`의 실제 소스를 앵커로 잘라 Node로 실행한다.** 재구현 금지(`test_produce_preview_gate.py` 방식).
- **미리보기 게이트를 우회시키지 않는다** — 복원이 `cur`를 직접 대입하므로 `jump()`/`go()`의 검사를 안 거친다.

```python
    assert wid
    got = store.get_produce_work(wid)

    assert got["job_id"] is None

    assert same == wid
    assert store.get_produce_work(wid)["state"]["script"] == "고침"
    assert store.get_produce_work(wid)["step"] == 2

    assert store.get_produce_work(wid)["title"] == ""

    got = store.get_produce_work(wid)
    assert got["job_id"] == "job-9"
    assert got["step"] == 1


def test_list_is_recent_first_and_capped(store):

    # 같은 초에 만들어져도 순서가 서야 한다 — updated_at만으로는 동률이 생긴다

    assert store.get_produce_work(wid) is None

    store.upsert_produce_work(None, {"script": "고객7"}, customer_id=7)
    rows = store.list_produce_works(customer_id=LEGACY_CUSTOMER_ID)
    assert [r["work_id"] for r in rows] == [a]
```

```python
    # ── 제작소 작업파일(2026-07-17) ──────────────────────────
    def upsert_produce_work(self, work_id, state, job_id=None, step=0,
                            customer_id=LEGACY_CUSTOMER_ID):
        """작업 저장. work_id가 None이면 새로 만들어 반환한다.
        state: 클라이언트 작업상태 dict(sessionStorage.produce_work 스키마 + step).
        ★title은 서버가 state['script'] 앞 20자에서 뽑는다 — 클라이언트가 매번 보내면
        대본을 고쳤을 때 목록 이름과 어긋난다(스펙 §4.6)."""
        now = datetime.now(timezone.utc).isoformat()
        title = (state.get("script") or "")[:20] if isinstance(state, dict) else ""
        payload = json.dumps(state, ensure_ascii=False)
        with self._conn() as c:
            if work_id:
                n = c.execute(
                    "UPDATE produce_works SET title=?, state_json=?, job_id=?, step=?, "
                    "updated_at=? WHERE work_id=?",
                    (title, payload, job_id, step, now, work_id),
                ).rowcount
                if n:
                    return work_id
                # 서버 DB가 갈아엎였는데 브라우저가 옛 work_id를 들고 있는 경우 —
                # 조용히 버리지 말고 그 id로 되살린다(사장님 작업이 사라지는 것보다 낫다).
            wid = work_id or uuid.uuid4().hex[:12]
            c.execute(
                "INSERT INTO produce_works(work_id, customer_id, title, state_json, "
                "job_id, step, created_at, updated_at) VALUES(?,?,?,?,?,?,?,?)",
                (wid, customer_id, title, payload, job_id, step, now, now),
            )
            return wid

    def get_produce_work(self, work_id):
        """작업 1건 → dict(state는 파싱됨). 없으면 None."""
        with self._conn() as c:
            row = c.execute(
                "SELECT work_id, title, state_json, job_id, step, created_at, updated_at "
                "FROM produce_works WHERE work_id=?", (work_id,),
            ).fetchone()
        if not row:
            return None
        return {"work_id": row[0], "title": row[1], "state": json.loads(row[2]),
                "job_id": row[3], "step": row[4], "created_at": row[5], "updated_at": row[6]}

    def list_produce_works(self, customer_id=LEGACY_CUSTOMER_ID, limit=20):
        """최근 작업 목록(updated_at DESC). state_json은 싣지 않는다 — 목록은 가벼워야 한다."""
        with self._conn() as c:
            rows = c.execute(
                "SELECT work_id, title, step, job_id, updated_at FROM produce_works "
                "WHERE customer_id=? ORDER BY updated_at DESC, rowid DESC LIMIT ?",
                (customer_id, limit),
            ).fetchall()
        return [{"work_id": r[0], "title": r[1], "step": r[2], "job_id": r[3],
                 "updated_at": r[4]} for r in rows]

    def delete_produce_work(self, work_id):
        """지운다. 실제로 지워졌으면 True."""
        with self._conn() as c:
            return c.execute("DELETE FROM produce_works WHERE work_id=?",
                             (work_id,)).rowcount > 0
```

```javascript
  function mountWorks() {
    if (path !== "/produce") return;   // 다른 페이지에서 제작소 작업을 부를 이유가 없다

      var h = "";

        var name = (w.title || "(제목 없음)");

      });

      var box = document.createElement("div");
      box.innerHTML = h;
      nav.appendChild(box);
```
