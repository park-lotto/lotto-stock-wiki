## 하이브리드가 비트(timeline)에 싣는 꼴
```
beat.speaker        'narr'|'orig'
beat.variant        팩 variants 키(kitchit 'typing' / kkultemnote 'orig_pop'·'orig_red' / starpick 'cursor'·'heart')
beat.emph           ["낱말" | {"word","color"?:"#RRGGBB","grow"?:"pop"|"hold"}]   (어절 안에 들어 있으면 맞음, 여러 어절 낱말 = 한 색)
beat.caption_marks  caption_lines 순서대로 [{speaker?,variant?,emph?,sticker?}] — 비트 값보다 이긴다
beat.chars          [{"char","start"}] start = 비트 t0 부터 영상 초(배속 갚은 값). 없으면 어절 시각÷글자, 그것도 없으면 일정 간격
```
장면에 붙는 값: speaker·variant·sticker·emph=[{w,g,color?,grow?}]·chars. 자료 없는 고객 작업은 장면 dict 가 종전과 같다.
견본 변환: `tools/caption_pack/check_bench_packs.py rows_to_timeline`(자막표 줄 → 비트, 줄 하나=비트, cap_durs=다음 덩어리 시작까지).
스냅샷: presetId plain · mode story · **frameRule body_all**(첫 장면도 등장) · captionPack=<팩> · wordFx.style='mark' · motionPack 'off'.
