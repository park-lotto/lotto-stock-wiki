## ⑥ 원인 분석 — WHY (오늘 주요 이동의 원인)

> **규칙**: 전일 대비 DXY ±0.5% 이상, 10년물 ±5bp 이상, VIX ±2pt 이상 변동 시 반드시 원인 검색

### 원인 분류 체계 (에이전트 판단 기준)

| 지표 이동 | 원인 유형 | 한국 주식 실제 영향 |
|---------|---------|----------------|
| 10년물↑ + 2년물도 동반↑ (Bull/Bear Steepening) | **경기 강세 기대** | ⚪ 중립~긍정 — 실적주 유리 |
| 10년물↑ + 2년물→ (Bear Steepening) | **인플레·재정 불안** | 🔴 부정 — 멀티플 압축, 성장주↓ |
| 10년물↑ + 2년물↓ (스프레드 확대) | **경기침체 우려 해소** | 🟢 긍정 — 금융주·경기민감주↑ |
| DXY↑ | **미국 경제 강세** | 🟠 혼재 — 수출주↑ but 외국인↓ |
| DXY↑ | **Risk-Off (안전자산)** | 🔴 부정 — 전반적 위험자산 이탈 |
| DXY↓ | **유동성 공급 기대** | 🟢 긍정 — 신흥국·성장주↑ |
| DXY↓ | **미국 재정 불안** | ⚠️ 주의 — 달러 신뢰 흔들 |
| VIX↑ | **지정학/이벤트 공포** | 🔴 부정 — 방어주 제외 전반 부담 |
| VIX↑ | **옵션 헤지 수요** | 🟠 단기적 — 빠르게 해소 가능 |

## L1 → 한국 시황 판단 공식 (에이전트 내재 로직)

### 스텝 1: 유동성 모드 판정

| 조건 | 판정 | 한국 시장 |
|------|------|--------|
| FedWatch 인하↑ + VIX↓ + DXY↓ | 🟢 Risk-On 풀가동 | 코스피↑ 외국인 순매수 |
| FedWatch 인하↑ + VIX↓ + DXY→ | 🟢 Risk-On | 코스피↑ 반도체 유리 |
| FedWatch 동결 + VIX→ + DXY→ | 🟠 중립 | 개별 이슈·실적 장세 |
| FedWatch 인하↓ + VIX↑ + DXY↑ | 🔴 Risk-Off | 코스피↓ 방어주 |
| FedWatch 인하↓ + VIX↑ + DXY↑↑ | 🔴 Risk-Off 강화 | 코스피↓↓ 외국인 이탈 |

### 스텝 2: 섹터 매핑 적용

```
Risk-On 풀가동: 반도체·AI·성장주 → 조선·방산 → 내수소비
Risk-On:        반도체·AI → 조선·방산
중립:           실적 대장주 선별 (어닝서프 확인 종목)
Risk-Off:       방산·에너지·필수소비 → 금·달러 자산
Risk-Off 강화:  현금·달러·국채 방어
```

### 스텝 3: 추가 보정 (L4 지정학)

```
지정학 긴장↑ (중동·미중) → 방산 가중 / 에너지 가중
지정학 완화  →             방산 차감 / 성장주 복귀
```
