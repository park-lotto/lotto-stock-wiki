# 장면 확대 기본 범위 — 현재 장면만

## 확인한 현상

- 장면 꾸미기의 `모든 장면에 같은 배율`이 기본 체크라서, 사용자가 선택한 장면을 확대해도 모든 장면의 `scene_zoom`에 같은 값이 저장됐다.
- 과거에는 의도된 동작이었지만 실제 사용자는 선택한 장면만 바뀔 것으로 이해해 반복 문의가 발생했다.

## 수정

- `모든 장면에 같은 배율`의 기본 체크를 해제했다.
- 체크박스 DOM이 아직 없을 때도 전체 적용으로 판단하지 않게 `zoomAllOn()`의 기본값을 `false`로 바꿨다.
- 사용자가 직접 체크한 경우의 전 장면 적용 동작은 그대로 유지했다.

## 검증

- 기본 체크 없음·기본 판정 false·현재 장면 저장 분기를 고정하는 회귀 테스트 추가.
- `test_scene_style_save_barrier.py`: 6 passed.
- 확대·장면 꾸미기 관련 테스트: 99 passed, 1 skipped.
- 실제 Chromium DOM: 최초 `checked=false`·`zoomAllOn()=false`, 직접 체크 후 `zoomAllOn()=true` 확인.
