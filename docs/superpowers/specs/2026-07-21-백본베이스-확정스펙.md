# 백본-베이스 — 확정 스펙 (사장님 2026-07-21, 딴소리 금지·이걸로 고정)

## 이게 정답이다 (더 흔들지 말 것)
잘된 영상 1개(백본)의 **흐름**을 뼈대로, **완전히 우리 것인 새 대본**을 그 흐름 위에 얹고,
화면은 백본 조각 + 서브 조각 삽입/교체로 조립한다. **백본을 카피하지 않는다** — 흐름만 빌린다.

## 확정 규칙
1. **백본 = 흐름만** (편집 리듬·비트 구조·스토리 아크). 대사·화면을 그대로 베끼지 않는다.
   목적 = 맥락 없는(뒤죽박죽) 영상 제작을 막는 뼈대.
2. **대본 = 100% 우리 것.** 백본 흐름을 따르되 문장은 새로 생성(부품은행·말투·훅 우리 것).
   단 **실제 있는 장면(백본+서브 풀)을 알고 그에 맞춰 쓴다** → 없는 장면 요구 금지(그래서 천장 없음).
3. **길이 ≠ 백본.** 서브 조각 삽입/재구성으로 백본과 다른 길이가 되어야 한다(똑같으면 안 됨).
4. **중간중간 서브 영상 조각 삽입** (b-roll·전환·같은 제품 다른 컷).
5. **백본 1번 조각 → 같은 의미의 다른 조각으로 교체** (서브 또는 타 백본 클립, 같은 행위/의미).

## 흐름 (구현 순서)
1. `pick_backbone` = 잘된 영상(최다 세그/완결) 1개.
2. **흐름 추출** = 백본의 비트 구조(순서·역할·대략 길이). 대사 아님, 뼈대만.
3. **대본 생성(우리 것)** = 그 흐름 + 실제 장면 인벤토리(백본+서브)를 주고 새 대본 생성.
   "이 흐름을 따르되, 아래 실제 장면들로 말이 되는 우리 대본을 써라(없는 장면 지어내지 마라)."
4. **화면 조립** = 비트별로 백본 클립 배치 → 같은 의미 서브 클립으로 교체(가능시) + 중간 서브 삽입.
5. **핑퐁** = 대사↔장면 최종 정합(오늘 만든 행위매칭·길이·순서 조각 재사용).
6. **길이 검증** = 백본과 다른 길이인지 + 각 비트 대사↔장면 길이 맞는지.
