## 컨셉: "Claude Live"
내가 만든 AI 발표자가 따뜻한 클로드 세계 안에서 라이브로 안내하는 쇼.
어둠이 아니라 **따뜻한 코랄·크림**의 세계. 한 색에 머물지 않고
구간마다 액센트 색이 흐르며 31초 내내 시선을 끌고 간다.
발표자는 좌측 윈도우의 주인공, 우측 컬럼은 그가 가리키는 정보판.

## 3. 모션 (역동적)

| 항목 | 값 |
|------|-----|
| 기본 이징 | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 배경 blob | 6~10초 주기 sin·cos 부유, 끊김 없음 |
| 카드 부유 | 모든 카드 ±4px 상하 parallax (구간 내내) |
| 프레임 궤도 점 | 윈도우 모서리 4개 점이 천천히 공전 |
| 챕터 칩 | 좌→우 슬라이드인 + 액센트 언더라인 |
| 키네틱 자막 | 단어별 y:+14→0, opacity 0→1, 3프레임 stagger |
| 히어로 전환 | 우측 스크린샷 scale 0.92→1 + 크로스페이드 |
| 액센트 전환 | 구간 경계에서 색 18프레임 보간 |

## 4. 레이아웃 (충돌 0 — 픽셀 검증)

```
┌──────────────────────────────────────────────────┐
│ [진행 리본 5px]                                    │ top 0
│ [챕터 칩]                          [Claude 로고]    │ y 70
│ ┌────────────────────┐   ┌──────────────────────┐ │
│ │                    │   │                      │ │
│ │   발표자 윈도우      │   │   우측 정보 컬럼       │ │
│ │   1120 × 630       │   │   650 wide           │ │
│ │   (좌측)            │   │   (스샷/가격/비교)     │ │
│ └────────────────────┘   └──────────────────────┘ │
│ [─────────── 키네틱 자막 (하단 16%) ───────────]   │
└──────────────────────────────────────────────────┘
```

수치 (1920×1080):
- 발표자 윈도우: x 70, y 170, **1120 × 630** (오른쪽 끝 x=1190)
- 우측 컬럼: x 1230, width 650 (오른쪽 끝 x=1880) → 윈도우와 **40px 간격, 겹침 없음**
- 윈도우 하단 y=800 / 자막 상단 y=907 → **간격 107px (R4 통과)**
- 좌우 안전 여백: 40px / 진행 리본 top 5px
- 발표자 영상: objectFit cover (윈도우 16:9 = 비율 일치, 찌그러짐 0)
- 스크린샷: objectFit contain (UI 잘림 방지)
