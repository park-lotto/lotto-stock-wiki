- 서버(읽기 전용, 산출물 /tmp/claimv_<job>/): `set -a && . /etc/shopping-shorts.env && set +a && cd /home/ubuntu/lotto-stock-wiki && PYTHONPATH=/tmp:. python3 /tmp/claim_trial_video.py <job>`
  (스크립트는 scp로 /tmp 에 올린다. ★서버에서 `pkill -f claim_trial_video` 하면 같은 문자열이 든 내 ssh 명령까지 죽는다 — `ps aux | grep '[c]laim_trial_vide'`로 확인)
- 로컬 집계·시트: `py tools/claim_trial_report.py <받아온 claimv_* 부모 폴더>`
- 결과물: `tools/claim_trial_results/` (1단계 json·score, 2단계 json·비교 시트 jpg)
- 버텍스 인증은 서버에만 있다(로컬 .env 에 없음). 키풀 제미니는 503 수요과다가 잦다(재시도 6회·간격 늘림).
