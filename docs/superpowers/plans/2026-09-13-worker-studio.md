# 워커 스튜디오 8석 디자인 검토

사용자 승인: 밋밋한 atlas를 바로 200개 일괄 변경하지 않고, 한 팀의 8개 워커를 디테일 있게 구현해 전체/확대 두 시점을 검토한다.

## 범위

- 기존 `/atlas/`와 데이터 보존. 별도 `/studio/` 검토 화면과 진입 링크.
- 기존 예시 데이터 중 기획팀 8개 ID를 재사용. 집계·상태는 데이터에서 계산. 실제 가동을 가장하지 않는다.
- 둥근 로봇 외장/눈/안테나/관절/손/신발, 포즈 차이, 작업대/화면/키보드/작업등, 부서 장식/자료보드/식물.
- 따뜻한 회백색과 청회색, 민트/코랄 포인트의 밝은 주간. 야간 전환, 360도 회전, 확대, 워커 선택/복귀, 연출 동작 끄기.
- 실데이터·프로세스 연결/실제 명령/외부 배포 없음. 화면·동작 모두 디자인 예시.

## 실행 순서

1. `company_ops/tests/studio.cjs` 작성 → 로컬 /studio/ 부재로 실패 확인.
2. `scene/studio-art.js`에 재질/기하/텍스처 및 8석 장면 구현. 반복 형상과 재질 캐시, 키보드 인스턴스.
3. `scene/studio.js`, `static/studio/index.html`, `studio.css`에 카메라/선택/주야간/연출 토글/상태 목록 구현.
4. 별도 `build:studio` 명령, atlas 진입 링크. 기존 빌드/데이터 보존.
5. 실제 Chromium: 8석 집계, 선택/복귀, 회전/줌, 주야간, 동작 끄기, 모바일/키보드, 외부 쓰기 없음. 전체/확대/야간 캡처 직접 보고 재질·구도 보완.
6. 트랙 핸드오프와 루트 위키 로그 갱신. 트랙 커밋/푸시만 수행.

최종 아트 승인과 200석 적용은 사용자 검토 후 후속 작업이다.
