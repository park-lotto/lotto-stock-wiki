## 무엇을·왜

1기 멤버 100명이 **하루 2영상 업로드 챌린지**를 시작(08-24 오픈). 멤버가 올린 영상을
링크로 제출받고, 사장님이 달성현황과 영상을 한 화면에서 확인한다.

**사장님 결정**: 멤버가 링크 직접 제출(자동 채널 크롤 아님) / 영상 정보는 자동 수집 /
관리 화면은 달성현황+영상 탭 2개 / 참가 자격은 1기 멤버만 / 인스타·유튜브·틱톡 /
기간은 admin 설정 / 하루 기준은 **제출한 날짜**(KST).

## 주소

```
멤버   shoppingshorts.duckdns.org/challenge        ← 단톡방에 이 링크를 공유
관리   shoppingshorts.duckdns.org/challenge/admin  ← 관리자만
```

## 설계의 핵심 — 저장 먼저, 수집 나중

링크가 들어온 순간 `challenge_submission` 행이 생기고 **달성 카운트가 확정**된다.
썸네일·조회수는 백그라운드(`BackgroundTasks`)로 나중에 채운다.

**수집 결과에 카운트를 묶지 않는 이유**: 인스타 수집은 수십 초 걸리고 간헐적으로
실패한다. 거기에 카운트를 묶으면 **"멤버는 올렸는데 미달성으로 찍히는"** 사고가 난다.
수집은 장식이고, 카운트의 진실은 `submit_day` 한 곳이다.

`fetch_status`: `pending`(수집 전) · `ok` · `failed`(실패—링크는 남음) · `skipped`(틱톡)

## ★다음 세션이 알아야 할 함정 (전부 이번에 실측으로 밟은 것)

| 함정 | 진실 |
|---|---|
| 세션 쿠키 이름 | `ss_session`이 아니라 **`dash_auth`**(app.py:8029) |
| DB 파일 | `app.db`가 아니라 **`reference.db`**(config.py:23) |
| 썸네일 프록시 | `?u=`가 아니라 **`?url=`**(app.py:5579) |
| `probe_grab_meta` 키 | `view_count`가 아니라 **`views`**(media_download.py:141) — 틀리면 조용히 항상 None |
| `_media_code` 재사용 | **쓰지 마라.** 인스타 전용이고 실패 시 URL을 통째로 반환 → `challenge.video_code` 사용 |
| 색상 토큰 | `theme.css`엔 `--bg`/`--txt`/`--panel`이 **없다**(`--mint`/`--aurora`만). 페이지가 인라인 `:root`로 선언 |
| 유료게이트 | ★**챌린지 참가자격과 결제등급은 별개 테이블.** 참가자여도 pro가 아니면 402 → `_FREE_EXACT_ANY`/`_FREE_EXACT_GET`에 등록 필수. 보안은 핸들러의 `is_challenge_member` 403이 지킨다 |
| 사이드바 경로 | `/static/sidebar.js`가 아니라 **`/sidebar.js`**(app.py:6528 전용 라우트) |
| ★정적파일 경로 | **`/static/` 접두사를 붙이면 404다.** 정적파일은 **루트**에 마운트돼 있다(app.py:13753 `app.mount("/")`) → `/theme.css`가 맞다. 실측: `/static/theme.css`=404, `/theme.css`=200. 스타일시트는 404여도 **화면이 뜨긴 해서** 조용히 넘어간다 — 반드시 상태코드로 확인. (2026-08-24 전수조사: `href="/static/"`을 쓰는 페이지는 이제 0개. `produce.html`류는 상대경로 `theme.css?v=1`로 정상) |
| `_is_admin(0)` | **True**(사장님). 테스트에서 '비관리자' 역할에 cid 0을 쓰면 거짓 green |

| `git stash` | **쓰지 마라.** 다른 세션 stash 2개가 있어 pop이 남의 작업을 꺼낸다 → worktree로 기준선 측정 |
| ★`.env`가 테스트를 깨뜨린다 | `test_assembled_drafts.py` 2건은 **`.env`(AI 키)가 있으면 깨진다**. 키가 있으면 실제 생성 경로를 타서 문구가 달라지기 때문. 실측(2026-08-24): 기준선 worktree에 `.env`를 복사하자 **내 코드 없이도 똑같이 2건 실패** → 회귀 아님. `track.py start`가 `.env`를 자동 복사하므로 **모든 트랙 폴더에서 이 2건이 실패한다**. 전체 pytest 회귀 판정 시 반드시 `.env` 유무를 맞추고 비교할 것 |

## 2026-08-24 후속 — 사장님 제보 2건 수정(라이브)

1. **오늘 카운트 박스 겹침** — `.today b` 자손 선택자가 오른쪽 '달성한 날 N일'의
   `<b>`까지 38px로 키워 13px 줄에서 튀어나오고 `line-height:1`이라 겹쳤다.
   → 큰 숫자를 `.big` 하나로 좁히고 `.done`에 `line-height:1.6`.
2. **"관리페이지가 주소창 없이 따로 뜬다"** — 사이드바 계정패널 링크가
   `target="_blank"`라 새 탭이 뜨고, `admin.html`엔 **사이드바가 아예 없어**
   앱과 끊겨 보였다. → `target` 제거 + `.main` 래퍼 + `/sidebar.js?v=2`
   (`archive.html` 패턴). 표 14열이 좁아진 폭에 눌려 머리글이 세로로 쪼개져서
   (`이름`→`이/름`) `.card{overflow-x:auto}` + `nowrap`으로 카드 안 스크롤.

★병합 주의: 이 작업 중 main이 `admin.html`을 크게 고쳤다(바로가기 4개·요약
5칸·오류신고함). 충돌 2곳을 **양쪽 다 살려서** 해결했다 — main의 새 기능과
내 사이드바가 공존한다(브라우저 실측: `setChallenge`·`loadBugs` 둘 다 살아있음,

## 2026-08-25 — 오류신고 알림 + 가입 자동체험 (라이브)

### 1. 오류 신고 접수 팝업 + 해결여부 표시
- 문구를 사장님 지시대로: "…숏템메이커 관리자에게 전송됩니다. 확인 후 쪽지로 답변이 전송됩니다."
  (URL은 원래도 `context()`가 `page_url`로 자동 전송한다 — 고객이 따로 적을 필요 없다)
- `/api/admin/pending`에 `bug_newest_id`·`bug_newest`·`bug_open` 추가.
  **기존 폴러(25초)에 얹었다** — 새 폴러를 만들지 않는다(0순위-B).
- `_ssBugToast`(주황) — 가입 토스트와 같은 자리·같은 소리. 클릭 → `/admin`.
  첫 방문엔 기준선만 잡고 조용히 있는다(가입 알림과 동일).
- ★admin이 `?status=open`만 부르던 것을 **전체 조회**로 바꿨다 —
  처리한 신고가 목록에서 통째로 사라져 "해결됐는지" 볼 수 없었다.
  미해결 위로 정렬 + 🕓미해결/✅해결됨 배지 + 답장 미리보기 + [다시 열기].
  머리글 숫자는 **미해결 건수**를 유지한다(처리할 일의 개수).
- 쪽지(답장) 기능은 **이미 있었다**(만들 필요 없었음). 실측으로 왕복 확인:
  접수 → 답장 → 고객이 받음 → 읽으면 사라짐.

### 2. 가입 즉시 체험 3일 + [확인] 한 번
사장님: "가입되면 승인대기중 쪽에 체험3일 자동, 확인 누르면 고객관리로. 일일이 버튼 누르니 안 좋아."

- `create_customer`의 `trial_event_hours` 기본값 **0 → 72시간**.
  서버 `settings`가 미설정이라 **배포만으로 켜진다**. 0으로 되돌리면 옛 동작.
- `ack_customer` 신설 + `POST /api/admin/ack` — **클릭 한 번**.
  `approve_customer`(프롬프트 3번·결제 기록)와 **분리**했다.
- ★★**가장 중요한 함정**: `access_level`은 체험창(`trial_ends_at`)을
  **`approved_at`이 비어 있을 때만** 본다. `ack`가 `approved_at`만 채우면
  **확인을 누르는 순간 체험이 끊긴다**(사장님 지시와 정반대).
  → 남은 시간을 `full_access_until`로 **이관**한다. 줄이지 않는다(`max`).
- admin 대기 행: `[✅확인]`(체험유지) · `[💳결제승인]`(기간부여) 두 버튼.

실측: 가입 3.0일 → 확인 → 대기실서 사라지고 **3.0일 유지** → 만료 시
`ranking_only`로 잠김 → 중복 클릭 안전. 구글 가입 경로도 동일(게이트가 잡아줌).
