# 체험판개방 — 작업 로그

## 2026-08-20
체험판(ranking_only)에 레퍼런스랭킹·즐겨찾기·렌즈(하루10회)를 열고, 제작소는
**진짜 화면을 얼린 미리보기**(9단계 이동·클릭 무효·API 0)로 대체. 라이브 반영 확인.

절반은 이미 있었다 — `ranking_only` 등급과 렌즈 10회 상한은 기존 것 재사용(신규 개발 0).
★렌즈 9개 중 과금검사는 2개뿐이라 prefix로 열면 Apify 유료가 샌다(정확경로만 개방).
★담기 부작용은 인스타 크롤 + **Gemini 예열** 둘 다였다(설계 땐 크롤만 봤다).
★미리보기는 버튼(onclick 221개)을 잠그지 않고 **script를 통째로 걷어냈다** — 하나만
빠뜨려도 과금이라서. 생성기가 매번 자가검증(script 1개·fetch/onclick/api 0건).
★판정 기준을 문자열(mixScriptPick)로 두면 복사본 페이지에서 깨진다 → 성질로 교체.
finish는 exit 0이어도 병합 안 될 수 있다(이번에 실제로 게이트가 막았고 라이브는 무사).

⏭ 체험 계정 실브라우저 검증은 아직 안 했다. 사용자별 보관함은 2단계.
