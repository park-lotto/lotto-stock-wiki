## ✅ P1 완료·라이브 (origin/main 병합)
- **모션레벨**: `scene_cut.py` — `frame_motion`(ffmpeg YDIF, ss/to 윈도우), `motion_thresholds`·`level_of`·`cut_motion`(LOW/MED/PEAK), `peak_time_in_window`(윈도우 내 피크 시각, 클램프·실패시 무변경).
- **훅 자동 In-Point**: `video_assemble.py` — `_render_mix` 진입서 `_apply_hook_inpoint` 호출 → 훅 비트(beats[0]) primary.start를 **모션 피크 + delta**로 이동. 순수함수 `pick_hook_start`, `_hook_delta`. 옵션(ii) 지연계산(훅 소스만 ffmpeg 1패스). **훅 세그먼트 내에서만·유출0·실패시 원위치.**
- **프리뷰 0.2초 미세조정 UI**: `static/produce.html` — 믹스 미리보기에 `🎯 훅 시작점 [◀0.2초][0.2초▶]` → `hook_inpoint_delta` 누적 → `saveWork`(POST /api/produce/works) → 재프리뷰. `_workState`·복원 2곳에 필드 반영. ⚠️라벨은 인라인 계산(리프레시 JS테스트가 함수 부분집합만 node평가 → `_fmtHookDelta` 외부의존 금지).
- **테스트**: `tests/test_motion_level.py`(순수 8). 게이트 통과(기준선13 신규0). 1차 finish는 JS ReferenceError로 막혔다가 인라인화로 재통과.
- **실영상 그라운딩**: 37d67b0e6015.mp4(17.2s) 훅[0~4s] 피크=1.03s → 앞1초 스킵. 사장님 육안 "바꾼 게 더 낫다".

## ⚠️ 함정(다시 밟지 말 것)
- `_apply_hook_inpoint`는 반드시 try/except·유출0(소스 밖 금지)·실패시 원위치 — 렌더 안 죽인다.
- produce.html의 `_renderMixReviewBody`는 리프레시 회귀테스트(node로 함수 부분집합 평가)를 타므로 **외부 함수 의존 금지**(인라인).
- 추출 파이프라인은 인스타수집·AI픽자동적재 세션이 동시 수정 → **트랙 격리 + 어댑터 최소침습** 필수.
