# 장면꾸미기 서버 렌더

- 2026-09-16 실제 서버 LAB 렌더에서 `puppeteer` 미설치와 Ubuntu AppArmor의 Chrome sandbox 차단을 확인했다.
- 서버에는 `npm ci`와 Puppeteer 브라우저 설치를 실행했다.
- Linux 장면 레이어 자식 프로세스에 `SCENE_STYLE_NO_SANDBOX=1`을 기본 주입하고, package 잠금파일 변경 시 자동배포가 `npm ci`를 재시도하도록 수정했다.
- 실제 MP4 렌더·랜딩·SHA 영수증은 통과했다. CapCut 초안 검증에서 30fps 경계의 `round(end-start)`와 생성기의 `round(end)-round(start)` 차이(1μs)를 잡아 공용 `_us` 판정으로 통일했다.
