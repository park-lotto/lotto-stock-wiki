## 테마 발동 → 소멸 판단 기준

```
발동 조건:
  - 뉴스 첫 보도 + 거래대금 급증 = 테마 점화
  - 이틀 연속 상승 + 거래대금 유지 = 테마 지속

소멸 조건:
  - 주도주 거래대금 급감 = 매도 신호
  - 촉매 이벤트 해소 (시추 결과 발표 완료 등)
  - 주도주 3일 연속 음봉
```

## 업데이트 기준

- 활성 기준: 해당 이벤트 뉴스 첫 보도 OR 관련 종목 상한가
- 이 섹터는 고정 종목이 아니므로 발동 시 즉시 해당 서브섹터 행에 종목 추가
- 소멸 후에도 기록은 유지 (히스토리)
- **자동반영 규칙**: 뉴스 ingest 시 해당 테마 서브섹터에 관련 종목 즉시 추가, 소멸 시 ~~취소선~~
