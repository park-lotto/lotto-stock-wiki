# 06 원음 받아쓰기 — 연예인 본인 말 구간을 정확히

들어가는 것: 원본(또는 구간 파일) + 조사의 원음 후보 초. 나오는 것: 원음 조각마다 정확한 시작·끝(파일 초)과 들린 말 → 대본 `kind:"orig"` 줄의 `spans`·`caps_rel`.

## 순서
1. **자동자막으로 후보 찾기**: 원본 `.ko.vtt` 에서 제품·브랜드·"진짜 좋다" 류 본인 말 시각을 뽑는다(`tools/calcopy/yanshot/common.py vtt_words`, 또는 vtt 를 직접 읽기).
2. **구간을 잘라 두 모델로 받아쓴다** (제미나이 안 씀):
   ```
   ffmpeg -ss <a> -to <b> -i src/<원본>.mp4 -ac 1 -ar 16000 asr/O1.wav
   "C:\Users\CH\Desktop\로또의 주식\.venv\Scripts\python.exe" tools/hotpeople/measure/asr_speechmatics.py asr/O1.wav   # 스피치매틱스(enhanced·단어 시각) — 그 폴더 asr/<이름>.json
   ```
   위스퍼(로컬 faster-whisper small, 무료): 오디오를 numpy 배열로 넘긴다(파일 경로로 넘기면 av 버전 문제로 죽는다).
   ```python
   import wave, numpy as np; from faster_whisper import WhisperModel
   w = wave.open("asr/O1.wav"); a = np.frombuffer(w.readframes(w.getnframes()), np.int16).astype("float32") / 32768
   for s in WhisperModel("small", device="cpu", compute_type="int8").transcribe(a, language="ko")[0]: print(s.start, s.end, s.text)
   ```
   스피치매틱스 결과 글 = `results[].alternatives[0].content` 를 이어 붙인다(json 에 words 칸 없음).
   스피치매틱스는 main 폴더 `.venv` 파이썬에만 깔려 있다(`py` 에는 없다).
3. **말 경계 정하기**: `silencedetect`(−26/−30/−32/−38dB, d=0.07) + 짧은 RMS 표로 말 시작·끝을 잡는다(경계가 모델마다 다르다).
4. **화자 확인**: 그 구간 화면에서 입이 맞는 사람이 연예인 본인인지(이름표). 남의 말이 섞이면 자른다.

## ⚠ `run.py asr` 단계는 쓰지 않는다
`run.py asr` 은 아직 서버 제미나이 2모델(`gemini_server.asr`)을 부른다 — 사장님 10-18 "제미나이 쓰지 말고" 뒤로 **폐기**. 위 2번(스피치매틱스+위스퍼)으로 하고 결과를 `asr/` 에 남긴다.
(창구 한 곳 `server_ai.asr_clips` 를 스피치매틱스로 바꾸는 일은 남은 일.)

## 판단
- 원음 조각 = **본인 말만, 알아들리는 것만**. 두 모델이 다 못 알아들으면 뺀다(B17). −35dB 이하로 작게 웅얼거린 말은 쓰지 않는다(올리면 배경까지 커져 뭉개진다 — 아이템홈 '타겟에서 샀어요' −40dB → 완성본 "백오십만 원"으로 들림).
- 자막과 받아쓰기가 다르면 둘 다 조사.md 에 적는다.
- 이름은 화면 글자로 확인된 것만. 받아쓰기의 ㅐ/ㅔ 차이(이혜정 ↔ '이해정')는 같은 소리(△).
