## 0. 결론 3줄

1. **판정 단위는 채널이 아니라 훅 문형(축)이 맞다** — 채널 안 훅 일치율은 7~42%뿐인데, 같은 훅은 채널을 넘나든다("여러분 다이소 가면 이거" 25편/12채널).
2. **본문도 패턴화된다** — 축마다 도입→마무리 5구간 역할 분포가 뚜렷이 갈린다(지인증언은 도입 상황 41%, 금지경고는 도입 문제 27%+사용법 22%).
3. **축을 넘는 상수 3개를 찾았다** — 길이 22~25초 · 밀도 297~327자/30초 · 마무리 CTA 76~92%. 현재 spine의 밀도값(226~300자)은 **실측보다 낮다 → 고쳐야 한다**.

## 2. 왜 채널 단위 판정이 틀렸나 (핸드오프 원안 기각 근거)

**채널 안에서는 안 뭉친다** — 전사 5편 이상 보유 채널의 훅 첫 2어절 최다 일치율:

| 채널 | 전사 | 첫 2어절 최다 | 비율 |
|---|---|---|---|
| chae2home | 42 | 저 이거 | 23% |
| maison_homedino | 39 | 여러분 다이소 | 7% |
| homterior_pick | 38 | 와 이거 | 21% |
| home._.standard | 33 | 여러분 다이소 | 15% |
| homeditor_insta | 29 | 여러분 애들 | 13% |
| gomson.salim | 27 | 여러분 다이소 | 11% |

→ 유튜브 기준("볼드 어구가 글자 그대로 동일")을 채널에 적용하면 **20채널이 거의 다 '패턴 없음'**으로 떨어진다.

**반대로 문형으로 모으면 뭉친다** — 채널을 가로지르는 고정 어구:

```
25편/12채널   여러분 다이소 가면 이거
18편/10채널   다이소 가면 이거 무조건
15편/ 9채널   다이소 가면 이거 꼭
 9편/ 6채널   가면 이거 무조건 사오세요
 5편/ 5채널   저 이거 보고 진짜
 5편/ 4채널   여러분 감자는 무조건 이렇게
 3편/ 3채널   저 이거 보고 진짜 / 감자는 무조건 이렇게 드세요
```

→ 위 기준으로 **6개 축**이 통과한다.

### ⚠️ 가짜 축 2개를 걸러냈다 (정직한 감점)

처음 분류에서 `대상호출`(여러분 32편)·`감탄개시`(와 32편)가 축으로 잡혔는데, **접두어를 지우고
다시 판정하니 64편 중 61편이 여전히 미분류**였다. 즉 이 둘은 내용 축이 아니라 **훅 수식어**다.

```
대상호출 32편 → (여전히 미분류) 32
감탄개시 32편 → (여전히 미분류) 29, 무조건지시 2, 가격경악 1
```

→ 축에서 제외했다. **따라서 실질 축 커버리지는 77%가 아니라 65%다.**
접두어 자체는 별개 사실로 쓸모가 있다(templates의 수식어 슬롯):

```
"여러분" 124편 23%  ·  "와/우와" 68편 13%  ·  "저 이거" 45편 8%
```

## 4. 본문 패턴 — 축별 5구간 역할 프로필

역할 태거는 대본 전문 6편을 읽고 만든 12개 규칙(cta·가격·불신·반응·지적·상황·후회·문제·실증·사용법·효과·정체).

### 지인증언 (79편/20채널)
```
도입    상황 41%  문제 14%  지적 12%
전개    사용법 30%  실증 24%  문제 12%
중반    실증 31%  사용법 22%  문제 20%
후반    효과 24%  문제 18%  사용법 13%
마무리  cta 85%
밀도 307자/30s · 길이 24초 · 컷 13 · CTA 74%
```
→ **beat_roles 후보: 훅→상황→지적→정체→불신→실증→효과→반응→cta**
(전문 실측 예: 시댁 갔다 → 어머님이 화냄 → 5,000원짜리라 해명 → 안 믿음 → 직접 발라 보임 → 펄감 살아남 → 어디서 샀냐 → 남겨주세요)

### 다이소지목 (62편/22채널)
```
도입    문제 40%  상황 28%
전개    문제 32%  실증 20%  지적 16%
중반    실증 37%  문제 14%  사용법 14%
후반    효과 20%  실증 16%  문제 16%
마무리  cta 76%
밀도 297자/30s · 길이 24초 · 컷 14 · CTA 82%
```
고정 어구가 가장 강한 축(25편/12채널). 기존 spine 57(다이소 내부인형)이 이 축인데
**밀도가 226자로 박혀 있어 실측 297자와 71자 차이**가 난다.

### 금지경고 (51편/19채널)
```

전개    문제 36%  실증 28%
중반    실증 35%  문제 22%
후반    실증 38%  문제 27%  효과 16%
```

→ 컷이 9개로 가장 적다(다른 축 13~15). **틀린 방법을 먼저 보여주고 → 바른 방법 실증**의 2단 구조.

## 6. 측정의 한계 (믿으면 안 되는 것)

```
□ full_text에 구두점이 거의 없어 "첫 문장" 절단이 실패한다
   (첫 문장 길이 75%가 95자, 최대 756자) → 훅 길이는 **첫 컷 기준**만 신뢰할 것
   첫 컷 기준: 중앙 18자, 30자 이하 87%
□ 훅 종결형 통계는 폐기했다 — 첫 컷이 문장 중간에서 잘린다("여러분 타코는" 7자)
□ 역할 태거는 규칙 기반이라 한 컷이 여러 역할일 때 위쪽 규칙이 이긴다
□ 미분류 23%는 아직 안 풀렸다 (한국어 124편)
□ 축 커버리지 65%는 가짜 축 2개를 뺀 값이다
```
