## 6. 문체 규칙 (전문 12편, `script_text_stats.py`)

제목·댓글 한 줄을 뺀 본문 81문장의 끝 꼴:

| 끝 꼴 | 수 | 구실 |
|---|---|---|
| ~는데 / ~한데 | 25 | 문장을 닫지 않고 다음으로 넘긴다 |
| ~다고 · ~라고 · ~다고 함 | 20 | 전해 듣는 말투로 닫는다 |
| 명사로 끝 | 9 | 소개(I) 전용 |
| ~음 · ~됨 | 8 | 해답을 못 박는다("있었음") |
| ~는 거 | 8 | 의문의 정체·핵심 찍기 |
| ~고 · ~라 · ~더니 등 이어짐 | 11 | 구절 잇기 |
| **~다 · ~요 · ~습니다** | **0** | **평서 종결이 한 번도 없다** |

- **전해 듣는 말투 표지**(~다는 · ~라는 · ~다고 · ~라며) 87문장에 50회. 화자가 직접 써 봤다고 말하는 문장 0.
- **2인칭 0 · 1인칭 0** (12편 전부). 움직이는 주체는 "사람들이"와 **별명 붙은 무리** — 빵돌이들 · 러너들 · 한국인 · 맛잘알 코난들 · 장거리 커플들 · (앞 시기) 집순이들.
- **권하는 말·구매 유도 0**: "사세요/추천/링크/구독" 없음. 값은 정보로만 지나간다(500원 · 900원 · 30엔 · "월등히 저렴").
- 숫자는 편당 0~3개. 숫자가 훅이 아니다.
- **ㄷㄷ = 감탄 지점**(원리·성능 뒤), **ㅋㅋ = 웃음 지점**(사람 이야기 뒤). 화면 글자에 붙는다. 받아쓰기에 "크크"로 잡힌 것은 댓글 한 줄의 ㅋㅋ뿐이다.
- 낱말: 커뮤니티 말 — 노맛 · 빵돌이 · 인간사료급 · 맛잘알 · 꽂힌 · 쟁여놓고 · 시전 · 개시원해 · 따땃한.
- **제품 이름을 말하지 않는 편이 많다**: 아웃백(파는 곳 "인터넷") · 붓 · 볼펜("해당 볼펜") · 블랙헤드("이 두 제품") · 비요뜨("2가지 초코링") — 그림에는 나온다. 이름을 말한 편: 티라미수 · 이어폰 · 젤리 · 초코바 · 텀블러 · 홈캠 · 인공눈물.

### 12-4. 대본과 그림을 짝짓는 법 (6편 시트를 눈으로 대조 — 아웃백·초코바·비요뜨·티라미수·이어폰·볼펜)

**단위**: 자막 구절이 바뀌는 순간에 그림이 바뀐다(컷=자막 일치 중앙 100%). 11편 합계 자막 구절 218개 / 본문 118컷 = **구절 1.85개에 그림 1장** — 대략 자막 카드(2줄) 하나에 그림 하나.

**규칙**: 그 구절의 **명사·동사를 글자 그대로** 보여 준다. 분위기 그림(B롤)이 없다.

| 짝짓는 방식 | 대본 구절 → 그림 |
|---|---|
| ① 말한 물건 그대로 | "특이하게도 플라스틱이 아닌 / 유리컵에 담겨있고" → 컵을 든 손 클로즈업 · "문제는 바로 이 컵에 있었음" → 빈 유리컵만 |
| ② 말한 행동 그대로 | "고작 서비스 유리컵이면서 / 식세기도 견뎌내는" → 수돗물에 컵 씻는 손 · "온 집안 물컵을" → 쌓아 올린 유리컵 · "물 한 컵을 같이 넣으면" → 전자레인지 안 빵+물컵 · "40시간이라는 긴 사용시간과 방수" → 물방울 맺힌 이어폰 |
| ③ 증거 글자(라벨·로고·간판) | "가장 열광한다는 부쉬맨브레드" → OUTBACK 포장 라벨 · "독일 수입 제품이라는" → MADE IN GERMANY 배지 · "의리 초콜릿!" → 일본어 광고판 · "최근 이솝 매장에 방문한 사람들이" → 매장 사진 |
| ④ 원리 그림 | "귀를 압박해 고정되는 방식" → 귀 모형에 끼운 이어폰 · "휘어지는 본체 설계" → 두 손으로 벌리는 이어폰 |
| ⑤ 감정 짤 | "퍽퍽한 노맛에 / 사람들이 놀라곤" → 애니 장면 2컷 · "구할 방법이 없게 되었음" → 얼굴 감싼 남자 · 댓글 한 줄 "신의 아들이었네 ㅋㅋ" → 웃는 남자 사진 2컷 |
| ⑥ 사람(누가) | "낙하산이었던 사장 아들은" → 정장 남자 인터뷰 컷 · "맛과 만족감 둘 다 잡은 제품이라며" → 제품 앞에서 말하는 리뷰어 |
| ⑦ 비교 | "두 초코룹스 모두 / 육안으로는 거의 동일하고" → 제품 2개 나란히 → 두 줄로 놓은 초코링 |

- **말로 안 한 이름을 그림이 알려 준다**: 볼펜 편은 나레이션에서 이름을 안 말하지만 그림에 "KACO gel pen 0.5mm" 글씨와 "PURE" 상자가 나온다. 이어폰 편은 케이스의 baseus 로고, 비요뜨 편은 대체품 통 2개의 상표가 보인다.
- **훅 카드 뒤 그림 = 제품이 가장 잘 보이는 클로즈업**(티라미수 단면 · 이어폰 케이스 열기 · 볼펜 촉 · 오븐 속 빵).
- **마지막 컷 = 제품**(쌓인 볼펜 · 이어폰 케이스 · 비요뜨 포장 · 빵 — 티라미수 편은 리뷰어). 초코바 편은 댓글 한 줄에 감정 짤.
- 한 구절("직접 볼펜 정보를 물어봤다는데")에 택배 뜯는 조각을 0.6~1.0초로 4번 잘라 붙인 곳도 있다(볼펜 8.9~12.2초).
- 짝짓기 유형별 편수·비율은 세지 않았다(6편을 눈으로 본 것).

### 13-2. 뼈대 초안 A — 대체형 (7편)

글자 그대로 되풀이된 것:

| 칸 | 되풀이된 문장 | 나온 편 |
|---|---|---|
| 제목 | "영업기밀을 빼앗겨버린 {원조}" · "영업비밀 유출되어버린 {원조}" · "결국 해킹당해버린 {원조}" · "매출하락이 걱정되는 {원조}" | 아웃백·LG / 이삭 / 비요뜨 / 애플펜슬 |
| 소개 | "{곳}에서 사람들이 가장 열광한다는 {원조}" · "{특징}에 뚜렷한 매니아층이 있었던 {원조}" (명사로 끝) | 아웃백·LG / 에어셀 |
| 막힘 | 구할 길이 막힘: "{회사}가 {공식 답}~자 … 구할 방법이 없게 되었음" · 값·품질이 아쉬움: "의외로 {아쉬운 점}~는데" | 비요뜨·이삭·에어셀(단종) / 아웃백·LG·애플펜슬 |
| 무리 | "{감정} 못 한 **{별명 붙은 무리}**은(는) {노력} 끝에" — 빵돌이들 · 맛잘알 코난들 · 돼지런한 맛잘알들 · 공기식감 매니아들 · 오버스펙에 지친 유저들 · 집순이들 | 6/7편 |

| 근거 | 같다는 근거 한 문장 — "맛에도 거의 차이가 없다고 함" · "엄청난 싱크로율을 자랑한다고 함" · "가장 근접한 대체품이라고" · "인식률도 상당히 좋다고 함" | 비요뜨 / 이삭 / 에어셀 / 애플펜슬 |

새로 뽑아야 할 재료: `원조`(누구나 아는 비교 대상) · `아쉬운점`(값·단종·못 구함) · `별명무리` · `같은점`(대체 근거) · `값이득`.
★쿠팡 상품이 '대체품' 자리에 들어간다. **원조가 없는 상품엔 못 쓴다** — 재료에 원조가 없으면 이 갈래를 건너뛰어야 한다(오용형이 '딴 용도 없으면 안 쓴다'는 것과 같은 규칙).
★위험: 원조 상표를 깎아내리는 문장("퍽퍽한 노맛", "살 이유가 없어져버렸다")과 '똑같다'는 주장은 사실 근거가 있어야 한다. 근거 없는 '똑같다'를 모델이 지어내면 사고다.
