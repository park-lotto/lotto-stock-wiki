💡여기서 연결한 채널이 그대로 숏템메이커 10단계 「SNS 예약」에 목록으로 뜹니다.
3

API 키
만들기

왼쪽 메뉴 맨 아래 설정 → API 로 가서 ＋ 새 키 를 누르세요 (publish.buffer.com/settings/api). 「개인 접근」 탭입니다.
이름은 숏템 처럼 아무거나 적으시면 됩니다.

❗키는 만들 때 딱 한 번 전부 보입니다. 그 뒤에는 뒷 4자리만 보이니(••••ay4F) 그 자리에서 바로 복사해 두세요.
🚨 Buffer 키는 30일이면 만료됩니다. 키 옆에 만료일이 적혀 있으니 확인해 두세요. 만료되면 예약 발행이 조용히 멈춥니다 — 그때는 ＋ 새 키로 다시 만들어 숏템메이커에 새로 붙여넣으시면 됩니다. (다른 4가지 키는 만료가 없습니다)
💡키를 만들려면 그 Buffer 조직의 소유자여야 합니다. 남이 만든 팀에 초대만 받으신 상태면 안 됩니다.
4

숏템메이커에
붙여넣기

숏템메이커 마이페이지 → 🔑 내 키 등록 → 📅 SNS 예약 발행 (Buffer) 칸에 붙여넣고 저장을 누르세요.
그러면 10단계 「SNS 예약」에 내 채널 목록이 뜹니다.

안 될 때

?저장했더니 “키가 틀렸습니다”
→앞뒤에 빈칸이나 줄바꿈이 딸려온 경우가 가장 많습니다. 다시 복사해서 넣어보세요. Vmake는 앱키:시크릿 모양이 맞는지 확인하세요.
?유튜브 키가 계속 틀렸다고 나옵니다
→YouTube Data API v3 「사용」을 안 누르신 경우입니다. ⑥-2단계로 돌아가 켜 주세요.
?“이번 달 무료분을 다 썼습니다”
→SerpApi 무료 250회를 다 쓰신 것입니다. 키는 멀쩡하니 다음 달이 되거나, 유료로 올리시면 다시 됩니다.
?대본 만들다 키가 소진됐다고 뜹니다
→제미나이 하루치를 다 쓰신 것입니다. 다른 구글 계정으로 키를 하나 더 받아 줄을 바꿔 추가하시면 이어서 됩니다.
?Buffer 키를 넣었는데 채널이 안 뜹니다
→둘 중 하나입니다. ① Buffer 안에서 SNS 계정을 아직 연결하지 않으신 경우 — ⑦-2단계의 ＋ 커넥트 채널로 연결해 주세요. ② 키를 만든 계정과 채널을 연결한 계정이 다른 경우 — 같은 계정으로 맞춰 주세요.
?잘 되던 예약 발행이 갑자기 멈췄습니다
→Buffer 키가 만료됐을 가능성이 큽니다 — 키 수명이 30일입니다. publish.buffer.com/settings/api에서 키 옆 만료일을 확인하시고, 지났으면 ＋ 새 키로 다시 만들어 숏템메이커에 새로 붙여넣으세요.
?Buffer 가입이 안 됩니다 (hCAPTCHA 오류 · "뭔가 잘못됐어요")
→가입 화면의 사람 확인(캡차)이 막혀서 생깁니다. 회원가입 버튼이 회색이면 아직 통과가 안 된 것입니다. ① 시크릿 창(Ctrl+Shift+N)에서 다시 해보세요(광고차단 확장이 꺼집니다) ② 그래도 안 되면 다른 브라우저 ③ 그래도 안 되면 휴대폰 데이터로(VPN은 끄세요).
?Buffer에서 키 만들기 버튼이 없습니다
→그 Buffer 조직의 소유자가 아니신 경우입니다. 내 계정으로 새로 가입하시거나 소유자에게 권한을 받으세요.
?Buffer 키도 회사 키로 대신 안 되나요
→안 됩니다. 내 SNS 계정에 올리는 일이라 반드시 내 Buffer 키가 있어야 합니다. 다른 키들과 다른 점입니다.
?Buffer 키를 안 넣고 쓸 수는 없나요
→안 됩니다. 내 SNS 계정에 올리는 일이라 Buffer 키는 반드시 내 것이 있어야 합니다.
?키가 새어나가지 않나요
→암호로 잠가 보관하고 화면에도 가려서 보여드립니다. 언제든 지우기를 누르시면 바로 삭제됩니다.
이 중 안 쓰는 기능의 키는 안 받으셔도 됩니다.
대본만 쓰실 거면 제미나이 하나로 충분합니다.
