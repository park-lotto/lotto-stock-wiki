2026-08-26 사장님 확정으로 제작소 단계바를 **도크형**으로 교체(라이브, 병합 `3c93618c8`).
동그라미+선은 결제·회원가입 위저드의 기본 관용구라 "레퍼런스 채널과 똑같다"는 지적이 나왔다.

**모양**: 무지개 진행띠 + 단계별 고유색 SVG 아이콘 + 완료 체크 배지 + 지금 단계만 크게 뜨며 링.
이모지가 아니라 직접 그린 SVG다(이모지는 OS마다 그림이 다르고 키우면 뭉툭해진다).

**이름 변경**: `SEO해시테크`→`제목·태그` / `최종렌더`→`완성본`(서비스에서 이미 쓰던 말로 통일).

## 다음에 손댈 때 반드시

- **되돌리기는 `produce.html`의 `renderSteps()` 한 곳**이면 된다 — 옛 `.orbbar` CSS를
  `theme.css`에 일부러 남겨 뒀다.
- **단계를 늘리면 `STEP_LABELS`·`STEP_COLORS`·`STEP_ICONS`·`STEP_SHORT` 넷을 다** 늘려야 한다.
  하나만 빠지면 그 단계가 **조용히 회색**이 된다(에러가 안 난다). 개수 정합 테스트를 넣어 뒀다.
- 반응형은 옛 `.orbbar` 규칙과 **짝**으로 `produce.html` @media 두 군데에 적혀 있다.
- 폰에서 진행띠를 살릴 수 있는 이유: `.dockflow`가 `.dockbar` **바깥 형제**라 스크롤해도
  안 어긋난다(오브바는 `.orbline`이 스크롤 컨테이너 안이라 모바일에서 숨겨야 했다).

## ★ 목업 정본이 썩어 있었다

(영상/대본·매칭·음성…)에 멈춰 라이브 9단계와 이미 어긋나 있었다. 구조는 안 건드리고
단계바 정본이 옮겨간 곳만 파일 맨 위에 명시했다.
