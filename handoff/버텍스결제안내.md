# 버텍스결제안내 — 「권한이 없습니다」 오진(결제 미연결) 수리 + 안내 보강 (관제 053, 2026-10-01 사장님 PC)

## 왜
회원 153(프로젝트 shorts-510215)이 역할 「Agent Platform 사용자」를 맞게 넣고도 「권한이 없습니다 — Vertex AI 사용자 추가」에 막힘(10-01 08:26·10:34 거절 2회).
뿌리: `vertex_route._explain`이 **모든 HTTP 403을 "역할 추가"로 번역**. 결제 미연결(BILLING_DISABLED)도 403이라 결제 검사 줄에 영영 안 닿았다.
로그엔 번역문만 남아 서버에서 실제 사유를 못 가렸다(회원 631도 같은 거절 7회 뒤 새 프로젝트로 통과).

## 한 것
- `vertex_route._explain`: BILLING 검사를 403 검사 앞으로. 403 문구에 "방금 넣었으면 5분 뒤 / 역할 맞으면 결제 확인" 추가. 주인 = `_explain` 한 곳.
- `verify_sa`: 구글 원문 앞 300자를 `[vertex_verify] project=… 구글원문:` 으로 stderr에 남김(키 내용 없음). 라이브 `journalctl -u shopping-shorts | grep vertex_verify`.
- 설명서 ⑧: 5단계 뒤 「권한이 없습니다」가 뜨면 — 결제 연결 확인 카드(결제 화면 버튼) + 안 될 때 FAQ 1건.
- `tools/vertex_guide/check_pages.py`: 새 문구 2개 검사 추가. ★영상 주소가 `?v=2`로 바뀐 뒤 셀렉터가 안 맞아 **검사가 깨져 있었다** → `src^=`로 수정. 전부 통과(10-01).
- 테스트 3건 추가(`test_vertex_register_reason_log.py`): 결제 403 → 결제 문구 / 진짜 403 → 역할+5분+결제 / 원문 로그.
