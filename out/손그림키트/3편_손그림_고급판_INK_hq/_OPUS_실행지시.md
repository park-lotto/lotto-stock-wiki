# 손그림 장면 개선 — Opus 실행 지시 (공통)

설계는 Fable 이 끝냈다. 너는 실행자다. **처음부터 다시 만들지 마라** — 기존 장면 코드(scene.js·dur.txt·컷 순서·타이밍·손글씨 문구·장면 길이)를 열어 그대로 두고, 아래만 고친다.

## 읽을 것 (먼저)
1. `INK_hq\ART_REVIEW.md` — Fable 판정서. 공용 규칙 R1~R8 + **네 장면의 장면별 지시** + 자가 검사 5항목
2. `INK_hq\_assets\README.md` + `assets.js` — Fable 이 그린 부품 35개(주인공 표정 6×각도 3·포즈 4·손 4·소품 6·직급 로봇 3). `draw(L, …)` 로 hq.js Layer 에 얹힌다
3. `INK_hq\_lib_p\hq.js`, `build.py` — 엔진(이걸로 통일)

## 고칠 것
- **그림 교체**: 장면 속 사람·손·소품을 전부 `_assets` 부품으로 바꾼다(직접 그린 타원·사각 사람 금지). 표정은 그 컷 감정에 맞는 것(기대·지침·좌절·놀람·안도·설렘), 컷당 표정 전환 1회.
- **판정서 R1~R8 적용**: 무대(바닥·벽·탁자)는 0.6초 안에 깔고 시작(컷 첫머리 백지 금지) · 끝 −2.0초에 그림 완성 · 동시에 두 곳 쓰기 금지 · 소품 최소 크기 · 3분할 배치 · 선 2단·접지 그림자·종이결.
- **결론 손글씨는 크게**: 마지막 문구 110px 이상, 화면 아래 작은 글씨 금지.
- 엔진 통일: P1~P5 는 옛 엔진(_lib, hero.js)이다 → `_lib_p` 엔진 + `_assets` 로 옮긴다(컷·타이밍·문구는 그대로 옮겨 적는다).

## 금지
- `_assets`, `_lib`, `_lib_p` 공용 파일 수정 금지(다른 작업자와 같이 쓴다). 필요한 보조 함수는 네 장면 폴더 안에.
- 숫자·문구 새로 지어내기 금지. 장면 길이(dur.txt) 바꾸지 마라(나레이션에 맞춰져 있다).

## 검수 (보고 전 필수)
- 장면마다 0.5초 간격 시트(긴 변 1000px 이하)를 직접 보고 판정서 자가 검사 5항목 + "잉크 5% 미만 프레임 수"를 잰다(전: 판정서 수치 / 후: 너의 수치).
- 얼굴 클로즈업 프레임 1장(960px) 직접 확인.
- 문제 보이면 고쳐서 다시 렌더 → 다시 본다. 통과해야 보고.
- 결과: 각 장면 폴더에 `out.mp4` 덮어쓰기 전 기존 것은 `out_v1.mp4` 로 보관.
