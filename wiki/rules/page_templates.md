## 종목 페이지 신규 생성 규칙

> 뉴스·리포트·수급 자료에 등장하는 모든 종목은 반드시 stock/ 페이지를 갖는다.

```
탐지 → stock_종목명.md 있음 → 해당 섹션에 행 추가
탐지 → stock_종목명.md 없음 → 신규 생성
```

### 신규 생성 절차
```
□ 1. wiki/L5_섹터/{섹터}/stock/stock_{종목명}.md 생성
□ 2. 종목 기본 정보 (종목명·코드·섹터·서브섹터·미국 페어)
□ 3. 탑픽 콜아웃 초기값 (모든 항목 ❌, 총점 0점)
□ 4. 들어온 데이터를 해당 섹션에 첫 행 추가
□ 5. 종합 스토리 1줄 작성
□ 6. 관련 페이지 링크
```

### 종목명 탐지 기준
- 한글 종목명 완전일치: SK하이닉스, 삼성전자
- 종목코드 6자리: (000660)
- 미국 종목(NVDA·TSLA) → stock/ 생성 대상 아님 (한국 종목만)
- 동일 종목 여러 이름 → 동일 파일로 통합
