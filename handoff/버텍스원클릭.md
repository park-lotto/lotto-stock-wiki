Express 모드는 구글 문서상 $300 무료 체험과 별개·문서 모델표에 3.6-flash·Veo 없음 → 보류.

## 주인·검사
- 주인: `shopping_shorts/static/landing/vertex_setup.sh` (API·서비스계정·역할·키차단풀기·키). 명령 글자는 스크립트 머리말 한 곳, 설명서·마이페이지가 보여주기만(test_pages_show_same_command_as_script로 짝 검사).
- 검사: `tools/vertex_guide/check_pages.py` ⑧(명령 = 스크립트, 복사 버튼 → 클립보드, 셸 주소, 스크립트 비로그인 200·파일 동일, 옛 5단계 접힘). 옛 화면에선 ⑧ 실패 확인.

## 한 것
- 스크립트: 결제계정 확인(없으면 freetrial 안내 후 멈춤) → 라벨 shortsmaker=1 전용 프로젝트(재실행 시 재사용) → 결제 연결 → API → SA shortsmaker + roles/aiplatform.user → 키. 키 차단(iam.disableServiceAccountKeyCreation·managed) 걸리면 조직 정책 관리자 부여 + **이 프로젝트만** enforce:false → 재시도. 끝에 한 줄 JSON 출력.
- 설명서 ⑧: 2 자동 설정 / 3 붙여넣기 카드, 옛 2~5단계는 <details>「직접 하기」(가~라).
- 마이페이지 버텍스 칸: 자동 설정 4줄(가입·셸 열기·명령 복사·붙여넣기) + copyText 공용(copyAcct가 씀).
- 셸 주소: `?show=terminal`만은 사장님 PC에서 안 열림 → `?show=ide%2Cterminal`(실측 열림).
