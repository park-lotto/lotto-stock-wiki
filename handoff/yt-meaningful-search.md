# yt-meaningful-search

## 구현

- 기존 `order=viewCount` 검색을 YouTube `order=relevance` + 최근 기간 제한으로 교체했다.
- 검색 결과에 관련성, 하루 조회수, 채널 최근 영상 중앙값 대비 배수, 참여율, 최신성 종합 점수를 추가했다.
- 게시 기간(7/30/90/365일), 영상 형식(전체/쇼츠/롱폼), 정렬 기준을 UI에서 선택할 수 있다.
- 관련성 20점 미만 후보는 API 단계에서 제거한다.
- 상위 3개만 자동 선택하고 각 후보에 선발 근거를 표시한다.

## 실데이터 검증

- `쇼핑쇼츠`, 최근 90일, 전체 형식, 종합 추천으로 브라우저 검색했다.
- 과거 정글북·Netflix Kids·MrBeast 결과가 사라졌다.
- 상위 결과는 쇼핑쇼츠 수익·제작법·자동화 영상으로 바뀌었고 종합 90~94점이었다.
- 브라우저 카드에서 하루 조회수, 채널 중앙값 배수, 관련성, 참여율, 종합점수를 확인했다.
