### 1. 자동추천문구 훅 강화 — `shopping_shorts/thumb_title.py`

**문제**: 프롬프트가 그 영상의 대본만 보고 지었다. 수집해 쌓아둔 히트 대본은 **한 줄도 안 봤다.**
그래서 "자취생 필수템 / 미니 세탁기" 같은 **요약형**이 나왔다(스크롤이 안 멈춘다).

**한 것**:
- `docs/script_bank/bank.json`의 **훅 60개 · 놀람 24개**를 프롬프트에 참고로 싣는다.
  → **생성기(`script_engine`)와 같은 은행·같은 로더를 재사용**한다. 은행 파일을 여기서 따로 열지
    않는다(0순위-B: 같은 판단을 두 곳에 적지 않기 위해).
- **훅 장치 5종**을 명시하고 후보마다 다른 장치를 쓰게 했다:
  타깃호출 / 손해·경고 / 반전·의외 / 발견·후회 / 숫자·구체.
- `seed`로 참고 조각을 회전 → **다시 누르면 다른 각도**가 나온다(같은 5개 반복 방지).
  버튼 누른 횟수를 프런트가 보낸다(`produce.html` `THUMB_TITLE_SEED`).

**실측 전/후** (같은 미니세탁기 대본):
| 전 | 후 |
|---|---|
| 자취생 필수템 / 미니 세탁기 | 자취생인데 / 빨래가 두 배로 줄었어요 |
| 삶의 질 수직상승 / 이거 진짜 요물 | 속옷이랑 수건 / 그냥 같이 빨았나요? |
| | 왜 이제 샀지 / 건조까지 다 되는데 |

⚠️ **참고 훅을 주면 바로 생기는 사고 2개** — 실측하고 프롬프트로 막았다(재발 시 여기부터 의심):
- **베끼기**: 세탁기 제목에 은행의 `"그냥 버리지 마세요"`가 **그대로** 나왔다(소재가 달라 말이 안 됨).
- **숫자 창작**: 대본에 없는 `"3분 만에"`를 지어냈다. → "대본에 있는 숫자만, 없으면 이 장치를 버려라".

### 2. ✨강조 효과 — `shopping_shorts/static/produce.html`

썸네일 최종 PNG는 **브라우저 캔버스가 그린다**(서버 합성 없음 — `api_thumb_save`는 받아서 저장만).
그래서 효과는 전부 `drawThumb`에 넣었다 = 미리보기와 결과가 같은 코드를 탄다.

`L.fx = {underline:'none'|'line'|'brush', underline_color, marker:{color}, glow:{color}}`
- **밑줄 / 붓 밑줄**(손으로 그은 곡선) / **형광펜** / **네온**(발광) — 6단계 편집창에서 딸깍 토글.
- `fx`가 없으면 아무것도 안 그린다 = **구 저장본 회귀 0**.
- 색 프리셋을 바꿔도 `fx`는 유지된다(`applyThumbPreset`).

⚠️ **실측으로 잡은 버그**: 형광펜+밑줄을 같이 켜면 **밑줄이 안 보였다.** 형광펜 띠가
`y+0.06~+0.58`을 덮는데 밑줄이 `+0.46`이라 **띠 안**에 그어졌다. 색을 바꾸는 걸로는 못 고친다 —
형광펜이 켜지면 밑줄을 `+0.66`으로 **내린다**. (실브라우저 렌더로 눈으로 확인함)

### 3. 😀 이모지 스티커 레이어 (2차 지시 "이모지 이모티콘 해줘 효과들")

**먼저 확인한 사실**: 이모지를 **기존 글자 입력칸에 타이핑하면 망가진다.** 실측 —
`🔥 대박 😱`을 넣으면 `thumbAutoLines`가 **공백에서 줄을 쪼개** 🔥·대박·😱이 3줄로 흩어지고,
grow-to-fill이 폭을 맞추느라 글자가 통째로 작아진다. 그래서 **별도 레이어**로 만들었다.

- `L = {kind:'sticker', emoji, size, x, y, rot}` — 자동줄나눔·폭맞춤을 **안 탄다**.
- `size`는 **캔버스 폭 대비 %** → 프리뷰(270)든 결과(1080)든 같은 비율(기존 비율 계약 유지).
- 이모지 24종(🔥😱👀💥✅💯👉…)을 6단계에 딸깍 배치 → **드래그로 이동, 슬라이더로 크기·회전**.
- 컬러 이모지는 `fillStyle`·`strokeText`가 **안 먹는다**(실측) → 폰트·색·외곽선 UI를 아예 안 보여준다.

⚠️ **스티커를 붙이자 드러난 기존 경로 버그 2건**(스티커 없인 안 나던 것):
- 스티커를 고른 채 **색 프리셋** → `thumbPresetToLayer`가 빈 글자 레이어로 갈아치워 **스티커 증발**
- 스티커를 고른 채 **추천 제목 클릭** → 스티커에 문구가 박혀 그림이 사라짐
→ 둘 다 막고 테스트로 잠갔다(제목은 글자 레이어를 찾아 얹는다. 없으면 만든다).

### 4. 직접 입력칸 (지시 "직접칸도")

목록 24개는 자주 쓰는 것일 뿐 제한이 아니어야 한다. 붙여넣고 Enter(또는 `[얹기]`) → 얹히고
입력칸은 비워진다(연속 입력 대비).

⚠️ **한 글자만 잘라 쓰면 안 된다** — 이모지는 서로게이트 쌍(2칸)이고 `👨‍👩‍👧`처럼 ZWJ로 이어붙은
것은 7칸이 넘는다. `charAt`/`slice`로 자르면 쪼개져 □가 된다. `Intl.Segmenter`로 **grapheme**
(사람이 보는 한 글자)을 뽑고, 없는 구형 브라우저는 `Array.from` 폴백. 실브라우저 렌더로
`👨‍👩‍👧`이 **가족 한 덩어리**로 나오는 것까지 확인했다(`firstGrapheme`).

### 5. 🎨 고급 벡터 도형 9종 (지시 "화살표도 곡선이나 이쁜것들 / 이모티콘은 아예 기본인데 고급버젼")

이모지는 OS 글리프라 **어느 채널이나 똑같이 생겼다.** 그래서 **벡터로 직접 그린다**(`THUMB_SHAPES`).
곡선/굵은/도는 화살표 · 강조 획 · 동그라미 · 번쩍 · 말풍선 · 체크 · 엑스.
그라데이션(`_shapeGrad`)·그림자·둥근 끝단으로 입체감을 준다. 래스터가 아니라 **키워도 안 깨진다**.
이모지와 달리 **색이 먹는다** → 편집창에 색 고르개 + 팔레트 8색.

- 버튼마다 **작은 캔버스에 실제 도형을 그려** 보여준다(같은 `THUMB_SHAPES`를 쓰므로 목록 그림과
  결과가 어긋날 수 없다). ⚠️`querySelectorAll`·`getContext` 가드 필수 — 테스트 하네스엔 DOM이 없다.
- ⚠️ **곡선 화살표**: 몸통과 촉을 **따로 좌표로 찍으면 반드시 어긋난다**(실측: 촉이 떨어져 엉뚱한
  곳을 가리켰다). 곡선을 stroke로 긋고 촉은 **끝점의 접선**(제어점→끝점 각도)에 맞춰 붙인다.
- **이모지판 중복 제거**: 위(새로 얹기)와 편집창(바꾸기)에 같은 24종이 두 번 떠 헷갈렸다
  → 편집창 목록을 없애고 "선택한 스티커 😱 — 바꾸려면 위 목록에서" 안내만 남겼다.
