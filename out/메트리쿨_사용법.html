메트리쿨 사용법

영상 1개를 유튜브 쇼츠·틱톡·인스타 릴스·스레드·페이스북·핀터레스트에 한 번에 올리는 도구입니다. PC에서 쓰는 게 가장 편합니다. 아래 순서대로 한 번만 연결해 두면, 그다음부터는 영상 올리기 5단계만 반복하면 됩니다.

처음 한 번만: 가입하고 계정 연결

연결 전에 휴대폰에서 각 앱 가입을 먼저 끝내 두세요. 인스타는 프로페셔널 계정(크리에이터)으로 바꿔 둬야 연결됩니다.

  1. 가입·로그인

    "How do you want to log in?" 화면에서 Google을 누르면 가장 빠릅니다. 유튜브에 쓰는 구글 계정으로 들어가면 됩니다.

    메트리쿨 열기

  2. 계정 연결

    브랜드 설정의 연결(Connections) 화면(처음 가입하면 바로 나옵니다)에서 플랫폼마다 연결을 누르고, 뜨는 창에서 로그인·허용합니다.

    • 유튜브: 구글 계정 선택 → 채널 선택 → 허용
    • 틱톡: 틱톡 로그인 → 허용
    • 인스타그램: 인스타 아이디·비밀번호로 연결하면 예약·게시만 됩니다(페이스북 없이). 통계까지 다 보려면 인스타와 연결된 페이스북 페이지로 연결합니다
    • 스레드·페이스북·핀터레스트: 각각 로그인 → 허용

매번: 영상 1개를 한 번에 올리기

  1. 계획(Planning) 열기

    왼쪽 메뉴 계획 Planning → 오른쪽 위 게시물 만들기 Create post.

  2. 올릴 곳 고르기

    위쪽 동그란 아이콘 중 올릴 플랫폼을 모두 켭니다(유튜브·틱톡·인스타·스레드·페북·핀터레스트).

  3. 영상·글 넣기

    세로 영상 파일을 끌어다 놓고, 설명 글을 씁니다. 상품 링크·"수수료를 받습니다" 문구도 여기 넣습니다.

  4. 플랫폼별로 다듬기

    네트워크별 편집 Edit by network을 켜면 곳마다 글을 다르게 쓸 수 있습니다. 유튜브는 제목을 따로 넣고, 인스타는 릴스, 페이스북도 릴스로 고릅니다.

  5. 예약 또는 바로 올리기

    날짜·시간을 정하고 예약 Schedule, 지금 올리려면 지금 게시 Publish now. 틱톡은 자동 게시(Auto publish)를 켜 두세요. 꺼져 있으면 휴대폰으로 알림이 오고, 틱톡 앱에서 마무리해야 합니다.

무료와 유료 차이

구분무료유료
브랜드 수1개여러 개(요금제마다 다름)
예약 게시물월 20개요금제마다 더 많음
통계 기록최근 30일더 길게
안 되는 곳링크드인·X(트위터)링크드인 가능, X는 추가 결제

브랜드 1개 = 계정 묶음 1세트입니다. 휴대폰마다 다른 계정을 쓰면(예: 8대 = 8세트) 무료로는 1세트만 연결되니, 나머지는 유료 요금제나 각 앱에서 직접 올려야 합니다.

알아 둘 것

  • 네이버 클립·카카오·당근 같은 한국 플랫폼은 메트리쿨이 지원하지 않습니다. 같은 영상 파일을 각 앱에서 직접 올리세요.
  • 무료 한도 20개가 플랫폼마다 1개씩 세는지, 한 번 올리기를 1개로 세는지는 공식 안내로 확인하지 못했습니다. 처음 며칠은 남은 개수를 보면서 쓰세요.
  • 같은 영상을 여러 계정에 똑같이 올리면 중복 콘텐츠로 노출이 줄 수 있습니다. 계정마다 글·영상을 조금씩 다르게 하세요.
