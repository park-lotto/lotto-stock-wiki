## 📊 미국 종목별 한국 반응 매핑

### NVDA (엔비디아) — 반도체 섹터 최상위 트리거

**연결 이유**: 엔비디아 GPU에 SK하이닉스 HBM이 직접 탑재. NVDA 실적·수요·가이던스가 HBM 수요를 직결 결정.

| 이벤트 | 1차 수혜 (직접) | 2차 수혜 (공급망) | 무관 |
|--------|--------------|---------------|------|
| 어닝 서프라이즈 / 가이던스 상향 | SK하이닉스 🔴, 삼성전자 🔴 | 한미반도체 🔴, HPSP 🔴, 심텍 🟠, 이수페타시스 🟠 | 삼성전기 MLCC ❌ |
| 신규 GPU 아키텍처 발표 (Vera Rubin 등) | SK하이닉스 🔴 (HBM 탑재 확정 시) | 한미반도체 🔴, 피에스케이홀딩스 🟠 | 파운드리 소부장 ❌ |
| 어닝 쇼크 / 수요 둔화 | SK하이닉스 🔴 하락, 삼성전자 🟠 하락 | 소부장 전체 🟠 하락 | — |
| 중국 수출 규제 강화 우려 | SK하이닉스 단기 변동성 | 섹터 전체 불확실성 | — |

**브리핑 로직 예시**:
> "NVDA +8% (어닝 서프) → SK하이닉스 HBM3E 독점 공급 = 수요 직결. 한미반도체(TC본더 독점) 동반. 삼성전기 MLCC는 무관."

**반응 강도 (역사적 평균)**:
- NVDA +5% 어닝 → SK하이닉스 +2~4% (다음날)
- NVDA +10% 서프 → SK하이닉스 +4~7%, 한미반도체 +5~8%

### MU (마이크론) — DRAM 업황 선행지표

**연결 이유**: 마이크론은 삼성·SK하이닉스와 DRAM·HBM 시장 직접 경쟁사. 마이크론 실적/가이던스 = 시장 전체 DRAM 수급 방향 신호.

| 이벤트 | 의미 | 한국 반응 |
|--------|------|---------|
| 어닝 서프 + 가이던스 상향 | DRAM/HBM 시장 수요 강세 확인 | SK하이닉스 🔴, 삼성전자 🔴 (경쟁사 동조) |
| ASP 상승 언급 | 전체 DRAM 판가 방향 확인 | SK하이닉스·삼성 메모리 재평가 |
| HBM 수율/공급 문제 언급 | 마이크론 HBM 후발주자 → 한국 독점 구조 강화 | SK하이닉스 🔴 강하게 상승 |
| PC/서버 수요 부진 언급 | 범용 DRAM 수요 우려 | 삼성·SK 🟠 중간 영향 (HBM이 버퍼) |

**브리핑 로직 예시**:
> "MU +12% (어닝 서프, DRAM ASP 가이던스 상향) → DRAM 업황 강세 재확인. 삼성전자·SK하이닉스 동반 상승 예상. 단, 마이크론 HBM 경쟁력 약화 언급 있으면 SK하이닉스 추가 수혜."

**주의**: MU 상승이 HBM 때문인지, 범용 DRAM 때문인지 구분 필요.
- HBM 이유 → 소부장(한미반도체) 동반
- 범용 DRAM 이유 → 소부장 연동 약함

---

### ASML — 장비 수요 선행지표

**연결 이유**: ASML은 EUV 장비 독점 공급자. ASML 수주·실적 = 전세계 반도체 Capex 방향 선행 신호. 특히 한국 반도체 장비주 직결.

| 이벤트 | 한국 반응 | 비고 |
|--------|---------|------|
| 어닝 서프 + 수주 강세 | 원익IPS 🔴, 주성엔지니어링 🔴, HPSP 🔴 | 한국 장비주 = 후공정 포지션, ASML과 다른 영역이지만 Capex 방향 동조 |
| 한국향 EUV 납품 증가 | SK하이닉스·삼성전자 투자 가속 신호 → 소부장 전체 🔴 | |
| 수주 부진 / Capex 우려 | 장비주 전체 🟠 하락 | |

**브리핑 로직 예시**:
> "ASML +6% (수주 강세, 2026년 한국향 EUV 납품 확대) → 한국 반도체 Capex 가속 신호. 원익IPS·주성엔지니어링·HPSP 장비주 동반. 소재주(솔브레인·코미코) 간접 수혜."

---

### AMD — AI GPU 경쟁 지표 (NVDA 대안)

**연결 이유**: AMD는 엔비디아의 AI GPU 직접 경쟁사. AMD AI 칩에도 HBM이 탑재되지만 SK하이닉스 HBM 독점 비중이 엔비디아보다 낮음.

| 이벤트 | 한국 반응 | 비고 |
|--------|---------|------|
| AI 가속기 수요 강세 | SK하이닉스 🟠 (엔비디아만큼 강하지 않음), 삼성전자 🟠 | AMD HBM 공급사 분산 |
| 인텔 x86 시장 점유율 확대 | PC DRAM 수요 약간 긍정적 | 미미한 영향 |
| MI300 수요 급증 | HBM 수요 전반 증가 신호 | NVDA 어닝과 동일 효과 |

---

### TSMC — 파운드리 경쟁·기술 선행

**연결 이유**: TSMC는 삼성전자 파운드리의 직접 경쟁사. TSMC 수율·수주·기술은 삼성 파운드리 포지션을 역으로 결정.

| 이벤트 | 한국 반응 |
|--------|---------|
| TSMC 3nm/2nm 수율 개선 | 삼성전자 파운드리 🟠 부정적 (경쟁 심화) |
| TSMC 가동률 저하 / 가격 인상 | 삼성전자 파운드리 🟠 긍정적 (고객 이탈 기회) |
| TSMC CoWoS 패키징 부족 | 삼성전자 첨단 패키징 🔴 수혜 가능성 |
| AI 칩 수요로 풀가동 발표 | 파운드리 업황 강세 → 삼성전자 파운드리 리레이팅 기대 🟠 |

**주의**: TSMC 상승 = 삼성 파운드리 동반 상승이 아님. 경쟁 구도 파악 필수.

---

### Intel — 서버 수요 간접 지표

**연결 이유**: 인텔 서버 CPU(Xeon)가 많이 팔릴수록 서버 DRAM 수요 증가. 단, AI 시대에는 인텔보다 엔비디아 GPU 서버가 주도.

| 이벤트 | 한국 반응 | 비고 |
|--------|---------|------|
| 데이터센터 서버 수요 강세 | 삼성전자·SK하이닉스 DDR5 수요 🟡 소폭 긍정 | HBM과 무관, 범용 DRAM 영향 |
| PC CPU 부진 | 삼성·SK LPDDR 수요 🟡 소폭 부정 | |
| 파운드리 외주 확대 | 삼성 파운드리 🟠 간접 수혜 가능성 | |

---

### Broadcom — AI 네트워크·ASIC 지표

**연결 이유**: Broadcom의 AI 네트워크 칩(이더넷 스위치)과 커스텀 AI ASIC 수요 = 데이터센터 확장 신호.

| 이벤트 | 한국 반응 |
|--------|---------|
| AI 커스텀 ASIC 수주 대규모 발표 | HBM 수요 확대 신호 → SK하이닉스 🟠 |
| 데이터센터 네트워크 강세 | AI 인프라 전반 강세 → 반도체 섹터 전반 🟠 |

---

### LRCX (램리서치) / AMAT (어플라이드머티리얼즈) — 장비 Capex 동향

**연결 이유**: 두 회사 모두 반도체 전공정 장비 세계 1~2위. 수주·실적 = 글로벌 반도체 Capex 방향.

| 이벤트 | 한국 반응 |
|--------|---------|
| 어닝 서프 + 한국향 납품 언급 | 원익IPS 🔴, 주성엔지니어링 🔴, 테스 🟠 |
| WFE(웨이퍼 장비 투자) 전망 상향 | 장비주 전체 🔴 |
| 중국 수출 제한 언급 | 한국 장비주는 영향 제한적 (다른 공급망) |

## 🚦 이벤트 유형별 브리핑 로직 가이드

### Case 1. 마이크론 폭등 (+10% 이상)

```
Step 1: 왜 올랐는가?
  → 어닝 서프 + DRAM ASP 상향: 삼성·SK하이닉스 동반 (업황 강세 확인)
  → HBM 수율 문제 언급: SK하이닉스 추가 수혜 (독점 강화)
  → PC DRAM 강세: 삼성·SK 소폭 수혜, 소부장 무관

Step 2: 소부장까지 가나?
  → 수요(HBM) 이슈면 YES: 한미반도체·HPSP 동반
  → 가격(ASP) 이슈면 NO: 대형주만 움직임

Step 3: 쓰면 안 되는 것
  ❌ "마이크론이 올라서 반도체 장비주도 오른다"
  ❌ "마이크론 강세 = 삼성전기 MLCC 수혜"
```

### Case 2. NVDA 어닝 서프라이즈

```
Step 1: HBM 언급 확인
  → HBM 공급 부족, 다음 세대 수요 언급: SK하이닉스 🔴🔴🔴
  → 데이터센터 성장 일반: SK하이닉스 🔴, 삼성전자 🟠

Step 2: 연결 체인
  SK하이닉스 → 한미반도체(TC본더) → HPSP → 심텍 → 피에스케이홀딩스
  삼성전자 메모리 → 소부장 일반 상승
  삼성전자 파운드리 → 별도 이슈 (NVDA와 직접 연결 없음)

Step 3: 쓰면 안 되는 것
  ❌ "NVDA 덕분에 삼성전기도 오른다" (MLCC 수요와 무관)
  ❌ "NVDA 강세 = 모든 반도체 소부장 수혜" (공급망 연결 확인 필수)
```

### Case 3. TSMC 가동률 하락

```
연결 로직:
  → 고객사 주문 감소(AI 수요 둔화): HBM 수요도 같이 감소 우려 → 닉스·삼성 🟠 하락
  → TSMC 가격 인상: 삼성 파운드리 고객 이탈 가능성 → 삼성 파운드리 🟠 긍정
  → 공급 부족으로 고객 이탈: 삼성 파운드리 수혜 🔴

TSMC 가동률 = 항상 같은 방향이 아님. 이유 파악이 핵심.
```

### Case 4. 미국 빅테크 AI Capex 상향 발표 (Meta·Google·Microsoft)

```
연결 체인:
  빅테크 AI Capex ↑ → 데이터센터 서버 ↑ → GPU ↑ → HBM ↑
  → SK하이닉스 🔴 (HBM 독점)
  → 삼성전자 🟠 (HBM 후발 + DRAM 동반)
  → 한미반도체 🔴 (TC본더 발주)
  → 이수페타시스 🟠 (AI 서버용 MLB)
  → 삼성전기 🟡 (AI 서버 MLCC는 간접, 시간 차 있음)
```
