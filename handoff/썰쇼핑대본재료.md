## 썰 대본 템플릿 (라이브 spine id=55·56)

### A. 은폐형 — 이븐쇼핑류 (`제품정체형` 카테고리)
```
title → bait → authority → reveal → benefit → twist
"{X} 망하게 한 {나라} 천재의 발명품"
"최근 딱 봤을 때는 [용도를 알기 힘든/평범한] 이 {제품군}이"
"이걸 개발한 {나라}의 천재가 돈방석에 앉았다는데"
★"이건 바로 {제품}"                      ← 5~7초에 정체 공개
"이게 말도 안 되는 게 {효능}"
★"근데 진짜 충격적인 포인트는 {효능2}"     ← CTA 없이 닫는다
```

### B. 오용형 — 살림킹왕짱류 (`오용형` 카테고리)
```
title → origin → notice → cases → twist
"[권위자]도 [부정어] 미친 사용법"
"이게 원래는 {본래용도} 개발된 제품이었음"

"{용도}로 쓰는가 하면 …"
★"근데 미친 사용법은 따로 있었는데 {용도}"  ← CTA 없이 닫는다
```
말끝이 **`~었음`·`~다는 거`** — 인스타의 `~했어요`와 다르다.


| "개발된 **펀칭기**였습니다"(제품군을 말한다) | "개발된 **제품**이었음" |
| cases가 **초보 vs 고수 대비** | 명사 나열 |
| "**심지어** 물티슈까지 걸어두고"(고조) | 없음 |

### ④ 길이가 짧던 진짜 원인은 구조가 아니라 **재료**였다

칸을 다 채워도 145자였다(히트작 234~284자). `sul_facts`가 misuses를 **짧은 명사구**로
뽑게 지시하고 있었다("환기", "주방 벽 설치"). **서술구**로 바꾸니 그대로 늘었다.

### 결과 (게이트 전부 OK · 295자 ≈ 27초 = 히트작과 같은 범위)

```
[title ] 제조사도 예상 못 한 실링팬 활용법
[bait  ] 요새 이 실링팬 하나로 난리가 났는데
[origin] 이게 원래는 캠핑 텐트에 거는 용도로 개발된 실링팬이었음
[notice] 그런데 사람들은 어디든 달 수 있는 간편한 설치 방식을 눈치채고 이걸 엉뚱한 용도로 쓰기 시작하는데
[cases ] 초보들은 기껏해야 습하고 더운 화장실에서 땀을 식히거나 환기하기 정도가 전부였는데
         고수들은 주방 벽에 설치해서 시원하게 요리하기까지 하더라고요 심지어 …까지 한다는 거
[twist ] 근데 미친 사용법은 따로 있었는데 …
```

### ⚠️ 남은 한계 — **같은 제품**의 영상이어야 한다

서로 다른 제품 6편을 합치면 게이트는 통과하는데 **내용이 섞인다**:
실링팬 대본에 "안경 닦기"(초음파 세정기)가 들어갔다. 즉 사장님 말씀의 "여러 영상"은
**같은 제품을 다룬 여러 편**이어야 한다. 아무거나 합치면 안 된다.
한 편만 써도 **진짜 오용형 재료면 6/6칸이 찬다**(부실한 인스타 재료는 3/5였다).

### ⏭ 다음

1. **같은 제품 영상 묶기** — 합칠 대상을 제품 단위로 고르는 기준이 필요하다.
   (지금은 호출부가 job에 담긴 영상을 넘긴다는 전제에만 기대고 있다)
2. **조립 경로를 화면에 붙이기** — 지금은 `spine_fill`이 모듈로만 있고 제작소 생성
   버튼은 여전히 모델 생성 경로다. 슬롯이 다 차면 조립본을, 모자라면 모델 생성을
   쓰는 식으로 가르면 된다(커버리지 `spine_fill.coverage`가 그 판단값이다).
3. **재료 담기 자동화** — 지금은 로컬에서 손으로 yt-dlp를 돌렸다. 유튜브 자막은
   서버에서 못 받으므로 PC 릴레이가 필요하다(쿠팡 선수집과 같은 구조).
4. 은폐형(spine 55)은 아직 2/6칸 — product_facts(쿠팡 재료)가 있어야 채워진다.

## 📌 같은 제품의 한국+해외 영상을 담으면 (2026-08-19 코드 확인)

사장님 질문: "살림킹왕짱 제품을 렌즈에서 같은 한국영상 해외영상을 가져오면 어떤일이
일어나나? 대본과 장면매칭부분"

### 확인된 것 (코드를 읽어 확인 — 추측 아님)

**대본**
- `_sources_for_generate(limit=3)` — 담긴 영상 **최대 3편**의 자막을 함께 재료로 쓴다.
- `_sul_block_for_sources`도 3편을 합쳐 한 번에 슬롯을 뽑는다 → 같은 제품이면
  '엉뚱한 사용처'가 한국편+해외편으로 늘어 `cases`(초보vs고수)와 `심지어` 고조가
  다 채워진다. **오늘 안경 얘기가 섞인 사고는 '제품이 달라서'였고 같은 제품이면 없다.**

**장면매칭** (`edit_plan._build_inventory`)
- 담긴 영상 **전부의 세그먼트를 한 통(seg_map)** 에 모은다.
- `seg_id = "{video_id}-{n}"` 이라 모델이 **어느 영상 장면인지 안다**.
- `_SCRIPTED_PROMPT`에 명시: **"서로 다른 소스 영상에 걸쳐도 좋다(관련성 우선)"**
  → 한 대사에 한국편 장면 → 해외편 장면을 **이어붙인다**(교차 편집).
- 각 영상의 **첫·마지막 세그먼트는 제외**된다(상대 채널 CTA·썸네일 박제 차단).
- `_FACE_TOKENS`에 중국어(`脸`·`人物`·`正面`·`自拍`)가 이미 있고 렌즈 CN 경로가
  라이브다 → 중국어 소스는 이미 실무에서 돈다.

→ **같은 제품의 한국+해외 조합이 이 구조에선 가장 좋은 조합이다.** 말은 합쳐져
   풍부해지고, 화면은 두 채널 앵글이 섞여 '한 영상 베낀 티'가 줄어든다.

### ⚠️ 아직 확인 못 한 것

- **자막이 영어/중국어일 때 `sul_facts`가 슬롯을 제대로 뽑는지 실측하지 못했다.**
  유튜브 영어 자막이 429(요청 제한)로 막혔다. 다음에 반드시 확인할 것
  (프롬프트는 한국어 지시 + 자막 본문 전달 구조라 Gemini가 번역해 뽑을 것으로
   **예상**되지만, 예상은 사실이 아니다).
- 참고: 오늘 받은 살림킹왕짱의 '해외용' 영상(영어 제목)도 **나레이션은 한국어**였다
  (`ko-orig` 자막 존재). 렌즈에서 가져오는 게 진짜 외국어 영상인지, 한국 채널의
  해외향 영상인지에 따라 갈린다.

## ✅ 조립본을 제작소 생성 경로에 붙였다 (2026-08-19, 커밋 46b3ac5ae · 라이브)

그전까지 `spine_fill`은 **모듈로만** 있었다 — 사장님이 생성 버튼을 누르면 여전히
옛 경로(모델이 문장을 쓰는)로 갔다. 그게 어미를 새로 쓰고 CTA를 붙인 그 경로다.

### 어떻게 갈리나 — `app._assembled_drafts()`

```
고른 스파인 중 썰(오용형·제품정체형)이고 슬롯이 **전부** 차는 것 → 🧩 조립본
                                    슬롯이 하나라도 비는 것 → 기존 생성기
```
- 반쪽 조립본은 내놓지 않는다(`build_draft`가 `missing`이 있으면 None).
  `generate_one_style`이 쓰는 원칙과 같다 — 성공인 척 반쪽을 주는 게 제일 나쁘다.
- 반환 모양을 **생성기와 동일**하게 맞췄다(beats/script/hook/checks/passed/style_*).
  새 모양을 만들면 화면 코드가 두 갈래가 되고, 두 갈래는 언젠가 어긋난다(0순위-B).
- 슬롯은 재료에서 **한 번만** 뽑아 스파인들이 공유한다(같은 재료를 두 번 안 때린다).

### ★화면이 어느 경로인지 말한다

조용한 폴백이 쳇바퉈의 뿌리였다(memory: reference_silent_fallback_pipeline_undo).
- 재료줄: `틀 조립 N안`
- 안 탭: `A안 · 유튜브 오용형 🧩`
- 응답: `materials.assembled = [스타일명…]`

### 라이브 실측 (서버 36cb0900d, 재료=살림킹왕짱 실링팬 자막 1편)

```
오용형(56) → 🧩 조립본  passed=True · 262자 · 게이트 전부 OK · CTA·빈칸 없음
은폐형(55) → 기존 생성기 (쿠팡 재료가 없어 슬롯 부족 → 정상 폴백)
```
설계대로 갈렸다. 262자는 실측 히트작(234~284자) 범위 안이다.

### ⏭ 남은 것

1. **초보/고수 대비가 약할 때가 있다** — 위 실측에서 "화장실에 달아서 땀 식히기"와
   "화장실 공기 순환 및 환기하기"가 사실상 같은 말이었다. `sul_facts`가 뽑은
   `misuses` **순서를 그대로** 쓰기 때문이다. 초보용(흔한 것) / 고수용(의외인 것)을
   가려 뽑게 하거나, 비슷한 것끼리 묶어 거르는 게 필요하다.
2. **은폐형(55)은 쿠팡 재료(product_facts)가 있어야 조립된다** — 지금은 영상만으로
   `{제품}`·`{효능}`·`{나라}`를 못 채운다. 1단계 선수집분을 슬롯으로 넘기면 된다
   (`_prefetched_facts_for_job`이 이미 그 값을 꺼내온다 — 조립에 안 넘기고 있을 뿐).
3. **외국어 재료 실측 완료** — 중국어(샤오홍슈·도우인) 6/6칸 정상. 영어는 슬롯 값이
   영어로 나오던 것을 프롬프트 지시로 고쳤다("mobile device support"→"휴대폰 거치").
   ⚠️ 영어 자막 영상들은 대부분 제품 소개라 `misuses`가 없다 → 4/6칸에서 멈춘다.
   이건 코드 문제가 아니라 **그 영상이 오용형이 아니어서**다.
