### 🎬 S1. 훅 — 결과 선공개 (40초)

**씬 유형**: 임팩트형 → 카카오톡 실화면 캡처
**스윕 효과**: ⑤ 대각선 스윕 (속도감)

**[화면]**
카카오톡 나채팅방 화면. 오전 7시 4분, 아침 브리핑 메시지가 와 있는 장면.
```
📊 오늘 아침 주식 브리핑 (7:04)

[시장 동향]
코스피 전일 +0.8% / 나스닥 +1.2% 마감
외인 코스피 순매수 +2,300억

[주목 섹터]
반도체: TSMC 실적 호조 → 국내 공급사 수혜 기대
조선: LNG선 수주 소식, 현대중공업 긍정적

[관심 종목]
삼성전자: 외인 3일 연속 순매수
SK하이닉스: HBM 공급 계약 관련 뉴스
```

**[나레이션]**
오늘 아침 7시에 카카오톡에 이게 왔습니다.

시장 동향, 주목 섹터, 관심 종목 뉴스.

제가 한 건 없어요.

어제 저녁 30분 세팅했을 뿐입니다.

**[자막 바]** 매일 아침 7시, 자동으로 옵니다

증권사 앱 켜고, 네이버 증권 들어가고, 오늘 섹터 동향 찾고, 관심 종목 뉴스 하나씩 뒤지고...

이거 다 하면 최소 20분입니다.

그리고 빠뜨린 게 있으면 또 찾아야 해요.

**라벨**: STEP 1 / CLAUDE 코워크 설치

2. 💳 Pro 플랜 필요 (월 $20)
3. 🤖 코워크 탭 확인

**[화면]** Claude.ai 화면 → 앱 다운로드 → 설치 후 코워크 탭

**[나레이션]**
먼저 Claude 데스크톱 앱이 필요합니다.

claude.ai 들어가서 앱 다운로드 눌러서 설치하시면 됩니다.

한 가지 — Pro 플랜 이상 구독이 필요합니다. 월 20달러예요.

무료 플랜은 코워크 기능이 없습니다.

설치하고 실행하면 왼쪽에 코워크 탭이 보입니다.

여기 들어가면 오늘 우리가 쓸 공간이에요.

**[자막 바]** Claude Pro ($20/월) + 데스크톱 앱 필요

### 🎬 S6. STEP 2 — PlayMCP 카카오 연결 (1분 50초)

**씬 유형**: 리스트형 → 실화면 전환
**라벨**: STEP 2 / 카카오톡 연결
**카드 4개 (순차 등장)**:
1. 🔍 PlayMCP 사이트 접속
2. 🔑 카카오 계정 로그인
3. 💬 카카오톡 나채팅방 MCP 추가
4. 🔌 Claude 코워크에 연결

**[화면]** PlayMCP 사이트 → 카카오 로그인 → MCP 추가 → Claude 커넥터 설정

**[나레이션]**
이제 카카오톡을 연결해야 합니다.

PlayMCP라는 서비스를 씁니다. 구글에서 PlayMCP 검색하시면 바로 나와요.

여기서 카카오 계정으로 로그인하시고...

도구 목록에서 카카오톡 나채팅방 MCP를 추가합니다.

이게 뭐냐면 — Claude가 카카오톡에 메시지를 보낼 수 있는 연결 통로라고 보시면 됩니다.

추가하고 나서 Claude 코워크로 돌아와서...

설정 → 커넥터 → 플러스 버튼 → PlayMCP 검색 → 스위치 ON.

이제 Claude가 내 카카오톡으로 메시지를 보낼 수 있습니다.

테스트로 "카카오톡 나에게 안녕이라고 보내줘" 해보시면 바로 확인됩니다.

**[자막 바]** PlayMCP → 카카오톡 나채팅방 연결 완료

### 🎬 S7. STEP 3 — 브리핑 프롬프트 + 실시간 시연 (2분 30초)

**씬 유형**: 클라이맥스형 → 실화면 전환
**라벨**: STEP 3 / 브리핑 프롬프트
**아이콘**: 🧠 (핵심 씬)

**[나레이션 — 도입]**
이제 핵심입니다.

뭘 보내달라고 할지 프롬프트를 써야 합니다.

여기서 어떻게 쓰느냐에 따라 받는 정보가 완전히 달라지거든요.

제가 쓰는 프롬프트 보여드릴게요.

**[화면 — 프롬프트 텍스트 천천히 타이핑]**

```
매일 아침 웹에서 아래 정보를 찾아서 카카오톡 나에게 보내줘.

1. 코스피·나스닥 전일 마감 동향 1줄 (숫자 포함)
2. 오늘 주목할 섹터 뉴스 2~3개 (이유 포함)
3. 내 관심 종목: 삼성전자, SK하이닉스 — 오늘 기준 최신 뉴스 각 1개

형식: 이모지로 구분해서 읽기 쉽게
```

**[나레이션 — 프롬프트 설명]**
이게 전부입니다.

1번 — 시장 전체 흐름 파악.
2번 — 오늘 어디에 돈이 움직이는지.
3번 — 내 종목 챙기기.

관심 종목은 본인 거로 바꿔 넣으시면 됩니다.

**[화면 — 실시간 실행]**
자, 지금 실행해볼게요.

Claude가 웹에서 정보를 찾기 시작합니다...

**[화면 — 카카오톡 수신 화면]**
카톡에 왔네요.

이렇게 됩니다.

**[나레이션]**
웹 리서치로 공개된 정보를 모아서, 요약해서, 카카오톡으로 보내줍니다.

관심 섹터나 종목 더 추가하고 싶으면 3번에 이름 추가하면 됩니다.

**[자막 바]** 웹 리서치 → 요약 → 카카오톡 자동 전송
