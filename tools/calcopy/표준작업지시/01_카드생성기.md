# 01 카드 생성기·합격선 판정기 — `tools/calcopy/preset_card.py` (표준 §2·§6)

## 목표
23 프리셋 카드를 **주인 장부들을 읽어** 생성하고(`build`), 표준 §6 L0~L4 를 **자동 판정**한다(`check`). 사람이 문서만 읽고 채운 임시 카드(scratchpad preset_cards·`out/숏템프리셋_카드_2026-10-24.html`)를 대체한다. 이 도구가 관제 263 '됐다'(미측정 0·L4 23/23)를 재는 자다.

## 실측 배경(10-24)
- 주인 지도 = 표준 §2-1 표. 형식·엔진·회원 연결은 `channel/프리셋.json`(10-24 신설, 23 slug), 측정값은 `channel/<slug>/_kal/규칙빈도.json`(있는 곳 5: ititemlog·sinbak·starpickroom·uljimatrot·goodletter — 꼴 `{n_docs, episodes, by_speaker, by_pos, by_role, first_chunk, plain, base_rate, rules:[{cond,effect,k,n,rate,base,grade}], min_n}`), 판 설정 `hybrid/styles/<판>.json`(`styles.py load` 가 `_common` 깊게 합침), 완성편 `channel/결과물.json items[{channel,judge,…}]`.
- 자막팩 키 존재 = `shopping_shorts/static/caption-motions.js` `/*PACKS*/{` 뒤 `"<key>": {`(정규식 `^\s*"?key"?\s*:\s*\{` 로 kitchit·kkultemnote·starpick·recipe·goodletter·ititemlog 6개 실측).
- 감사 임시본 생성기(페이블 scratchpad `audit_gen.py`)의 열 정의를 그대로 가져와도 된다 — 단 **요소 15종 ○/△/× 는 손 판정이었다**. 생성기는 규칙빈도.json 의 `rules` 를 요소로 매핑해 **기계로** 센다(아래 매핑).

## 만질 파일(독점)
- `tools/calcopy/preset_card.py`(새) · `shopping_shorts/tests/test_preset_card.py`(새) · `channel/프리셋.json`(값 보정만 — 키 구조는 표준 §2 그대로, 새 키가 필요하면 페이블에 쪽지)
- 출력: `channel/<slug>/_kal/카드.json`(생성물, 표식 `made_by·built_at·inputs{파일:sha}`) · `out/숏템프리셋_카드.html`(생성물)
## 안 만질 파일
`규칙빈도.json`·`styles/*.json`·`브랜드.json`·`스타일.json`·`결과물.json`(읽기만) · `kal_analyze.py` · 다른 지시서 파일.

## 설계(판단 주인)
- `preset_card.load_owners(slug) -> dict` — 주인 장부들을 읽는다(없으면 `None`, 조용히 기본값 금지).
- `preset_card.rules_of(slug, style) -> list[RuleRecord]` — 규칙빈도 `rules[]` → 표준 §2-3 레코드. 매핑: `effect` `enter=*`→`cap_enter` · `emph`→`cap_emph` · `sticker`→`sticker`(what 에 원·화살표 글자면 `pointer`, 짤이면 `meme`) · `sfx`→`sfx` · `enter_fx`→`cap_enter`(효과 붙은 등장) · `plain`→`cap_enter cond=없음`. `engine_cell` = 판 칸 경로(`placement.rules.<…>`·`caption.pack_default.<slot>`·`sfx_files`) — 판에 그 칸이 없으면 `engine_support:"×"` + 표준 §3-3 결손 번호. 규칙빈도에 없는 요소(`transition`·`scene_fit`·`bgm`·`cap_exit`·`thumb`·`speech`·`cut_rhythm`)는 줄판독 칸(`transition`·`fit`·`exit`·`frame0`)·뜯기(`cuts.bench`·`audio.bench`)·`대본언어.json`(cps) 에서 세고, 없으면 `confidence:"미측정"` + **`measure_task:"06-<slug>"`**(이게 없으면 build 거절).
- `preset_card.level(card) -> (L, missing[])` — 표준 §6 표 그대로. L2 는 `<판>/품질관문.json`·`재현일치도.json`(지시서 04 산출) 존재+ok, L3 는 `업그레이드_측정.json`(05), L4 는 프리셋.json `member` 3칸 + 숏템MCP 실측 기록 파일(`channel/<slug>/_kal/회원실측.json`, 09 가 쓴다).
- `build --all` 은 slug 마다 카드 json + HTML 한 장(표: slug·형식·브랜드·엔진·L·요소 15종 ○△×·빈 칸·measure_task). HTML 은 `out/` 에만.

## 명령
```
PYTHONUTF8=1 py tools/calcopy/preset_card.py build <slug>|--all
PYTHONUTF8=1 py tools/calcopy/preset_card.py check <slug>|--all      # L 판정표 + 미측정 수 + exit 0/1(--all: 전부 L4 면 0)
PYTHONUTF8=1 py -m pytest shopping_shorts/tests/test_preset_card.py -q
```

## 합격 검사(사보타주 먼저)
1. `check --all` 결과가 `표준감사_2026-10-24.json` 의 L0/L1 사실 칸(줄판독 수·규칙빈도 유무·판 파일·자막팩·손 스크립트 수)과 **23개 전부 일치** — 다르면 어느 쪽이 틀렸는지 파일을 열어 적는다(감사가 틀렸으면 그 줄을 보고에).
2. 사보타주: `channel/ititemlog/_kal/규칙빈도.json` 의 `rules[0].k` 를 임시로 바꾸면 카드 `rules[0].rate` 가 따라 바뀌어야 하고, `styles/잇템로그판.json` `caption.pack` 을 없는 키로 바꾸면 `check` 가 L1 '자막팩' 미달을 내야 한다(둘 다 되돌린다).
3. `measure_task` 없는 미측정 레코드가 하나라도 있으면 build 가 exit 1 — 시험 픽스처로 확인.
4. 생성한 `카드.json` 23개에 `made_by`·`inputs` sha 가 있고, 같은 입력으로 두 번 build 하면 `built_at` 외 diff 0.
5. `out/숏템프리셋_카드.html` 을 브라우저로 열어 23행·요소 15열이 보인다(스크린샷 1장 보고에).
