# 칼카피 엔진 — 어떤 채널이든 넣으면 똑같이 만드는 기계 (설계, 2026-10-15 밤, 사장님 확정 방향)

## 0. 한 줄

**채널 주소(또는 영상 1편)를 넣으면 뜯고 → 똑같이 만들고 → 원본과 대조하고 → 통과하면 프리셋으로 남는** 엔진 하나.
프리셋은 목적이 아니라 결과다. 기초(사전·뜯기·그리기·대조)가 탄탄하면 "이 영상 칼카피해보자"가 바로 되고, 채널을 하나 복사할 때마다 엔진이 알아보고 만들 수 있는 범위가 넓어진다.
첫 채널은 사람이 붙어 **완벽하게** 한 편을 끝내고, 그때 생긴 절차·도구로 그 뒤는 대기열에 쌓아 24시간 돌린다.

## 1. 왜 우리만 계속 못했나 (2026-10-15 이 세션에서 코드·기록으로 확인)

볼케이노 방식 엔진은 이미 있다 — `shopping_shorts/channelkit/`(pipeline = `next_step` 상태기계) + `channel_presets/{brainbulb,hotpeople,banggu}` (9-25 설계, 트랙에만, main 미병합). 그런데 채널 4개를 4가지 방법으로 했다:

| 채널 | 방법 | 그린 코드 |
|---|---|---|
| 뇌전구·뜨거운사람들 (9-12~25) | channelkit 프리셋 — 측정값을 `spec.py`에 **손으로** 적음 | channelkit ASS/ffmpeg |
| 방구석 (10-05~06) | `spec.py` 상수 + seedflow | (대본만) |
| 픽션 썰 (10-08) | 라이브 숏템메이커에 확정 대본 | 라이브 HTML/크롬 |
| 썰풀다 (10-15) | `rules.json` + `style_writer` + `copy_render` | copy_render ASS/ffmpeg (세 번째) |

뿌리 셋:
1. **그리는 코드가 세 벌** → 한 채널의 틀을 다음 채널·숏템메이커 프리셋으로 못 넘긴다(0순위-B 위반이 구조에 박힘).
2. **역분석 → 프리셋이 수작업** → 측정은 자동(bench)인데 숫자를 사람이 옮겨 적어 채널마다 며칠, 세션마다 다르게.
3. **표준 절차 문서 없음, main에도 없음** → 다음 세션이 처음부터 다시 조사(실제로 이 세션도 channelkit 존재를 조사 뒤에야 알았다).

볼케이노가 12개 프리셋까지 간 이유 = 엔진 하나 + 프리셋은 **데이터**. 우리는 프리셋이 코드라 늘지 않았다.

## 2. 결정 (사장님 10-15 밤)

- **그리기는 라이브 숏템메이커 렌더러(HTML/크롬 촬영, `tools/render_scene_style.js`) 한 벌.** channelkit ASS·`copy_render`는 버린다. 이유: 어떤 채널이든 복사하려면 그리는 기계가 하나여야 하고, 그 하나가 편집 화면·렌더·캡컷까지 이미 돈다. channelkit은 절차·린터·프리셋 담당으로만 남긴다.
- **합격 = (다)** 원본과 나란히 놓고 같은 채널 영상으로 보이는 것을 기본으로, 숫자 차이표로 자동 검사.
- **합격 기준은 두 층(사장님 10-16)**: ① 픽셀 수준(틀·자막 모양·등장 효과·컷 박자) = 똑같이. ② 규칙 수준(효과음·배경음악·짤·TTS 목소리) = **같은 파일일 필요 없음**, 자리·빈도·종류 규칙만 같으면 통과("스타일을 파악하면 된다"). 곡 식별·짤 파일 대조·목소리 복제는 하지 않는다.
- **해외 원본 찾기**는 라이브에 있는 렌즈·키워드 검색·숏템파워를 통로로 쓴다(제작법 사전 '남의 영상 재편집'의 통로).
- **폰트는 전부 무료**(우리 폰트팩 + 눈누). 숏츠 제작자들이 쓰는 건 다 무료 폰트다.
- 외관만이 아니라 **소스를 얻는 방법·제작법도 채널마다 다르다** → 제작법 사전을 세 번째 사전으로.
- 첫 채널(썰풀다)을 완벽하게 → 그 뒤 24시간 대기열 운전.

## 3. 엔진의 모습 (사장님 쪽에서 보이는 것)

```
채널 주소(또는 영상 1편) 넣기
  → ① 뜯기   틀·폰트·글자효과·등장효과·컷박자·대본결·목소리·배경음·효과음·장면종류·제작법 → 숫자 + 사전 항목
  → ② 만들기 뜯은 그대로 대본 쓰고, 재료를 그 채널의 제작법 통로로 가져와 장면 채우고, 라이브 렌더러로 그려 렌더·캡컷
  → ③ 대조   원본 옆에 나란히 + 차이표(좌표·색·글꼴 점수·효과·제작법 비율). 기준 밖이면 설명서 고쳐 다시(자동 보정)
  → ④ 저장   통과하면 그 채널이 프리셋(데이터 한 묶음)으로 남는다 — 다음부턴 버튼 하나
```

못 알아보는 폰트·효과·제작법이 나오면 사전에 추가한다 → 두 번째·세 번째 채널부터 빨라진다.

## 4. 세 사전 — 항목마다 "알아보는 법 + 만드는 법"이 한 쌍

판별용과 구현용을 따로 두면 어긋난다(0순위-B). 사전 항목 하나에 둘이 같이 붙어 있어, 판별되는 순간 바로 그릴 수 있다.

### 4-1. 외관 사전
| 항목 | 알아보는 법 | 만드는 법 |
|---|---|---|
| 폰트 | 원본 글자 오려 후보 폰트로 같은 글자·크기 렌더 → 모양 상관(획 두께·받침·모서리). AI에 원본/후보 나란히 보여 보조 판정. 1~3위 + 점수 | 웹폰트 파일 + 렌더 이름(woff2 추가 경로 `reference_폰트추가_woff2_렌더3경로`) |
| 글자 꾸밈 | 채움색·그라데이션 / 외곽선(두께·색·겹수) / 그림자(방향·거리·흐림) / 글자 상자(색·모서리·여백) / 형광펜 / 기울임 / 자간·줄간 — 글자 안쪽·테두리 띠·바깥 번짐을 층별 픽셀 측정 | 그 꾸밈을 내는 CSS 설정 |
| 등장·퇴장 효과 | 글자 등장 앞뒤 프레임을 뜯어 위치·크기·투명도·흐림 **곡선** → 우리 효과 후보를 같은 방식으로 렌더해 곡선 대조. 종류·길이·속도감 | 같은 곡선을 내는 애니메이션(captionPack·motionPack·wordFx 확장) |
| 낱말 강조 | 자막 안 낱말 단위 색·크기·그려짐(밑줄·동그라미) 변화, 받아쓰기 시각과 대조. 어느 낱말을 강조하나(숫자·제품명·감정어) | wordFx 확장 |
| 자막 흐름 | 누적형/교체형, 줄 나누기 규칙, 자막당 노출 초(글자수 공식) | 자막 배치 규칙 |
| 화면 효과 | 컷 경계 ±8프레임 밝기·스케일·좌우분산 → 줌펀치·흔들림·플래시·페이드·분할 | scene_style zoom/shock/fxPreset 확장. CSS로 안 되는 것(입자·빛·3D)은 투명 영상 자산(에펙 견본 112)으로 |
| 얹는 그림 | 배경과 독립적으로 나타났다 사라지는 덩어리(프레임 차분) → 짤/스티커/이모지/화살표/말풍선, 언제·어디·얼마나 | 짤 팩·스티커·masks |
| 틀 | 캔버스·영상 창(x,y,w,h,모서리)·배경(단색/사진/흐림)·띠·박스·구분선·로고·광고표시 | **틀 설명서**(§5) |

### 4-2. 대본 사전 (있음 — `channel/<slug>/*.rules.json`, `style_writer.py`, `seedflow`)
구조(박자·전환 위치) · 말투(어미·반말·감탄사) · 첫 줄 훅 꼴 · 길이·말속도 · 소재 5기준(아는·몰랐던·재미·이야기·얻는 것 + 보여줄 수 있나) · 사실 조사·검증. 재현 검사 = 같은 자(`script_text_stats`·`script_structure`·cps)로 우리 대본 5편을 재서 범위 안/밖.

### 4-3. 제작법 사전 (새로)
| 제작법 | 알아보는 법 | 재료 통로 | 우리 |
|---|---|---|---|
| 남의 영상 재편집 | 컷마다 화질·화면비·워터마크 다름, 역검색으로 출처 | 유튜브·인스타 검색·다운로드(있음) | 가능 |
| 스톡 영상 | 균일 화질·로고 없음·흔한 구도 | 무료 스톡 API(Pexels·Pixabay) | 통로 추가 |
| 사진 + 움직임 | 정지 그림 확대·이동 | 사진 검색·스톡·기사 사진 | 장면 경로 추가(§6-4) |
| 기사·화면 캡처 | 브라우저·앱 화면, 글자 많음 | `article_shot.py`(있음) + 강조(빨간 원) | 가능 |
| AI 그림 | 실사 아닌 질감 | EvoLink(있음, 숏템 미연결) | 연결 |
| AI 영상 | 생성 클립 특유 움직임 | Veo `ai_scene.py`(라이브, 관리자) | 가능 |
| 짤·밈 조합 | 짤 팩에서 본 것 | 짤 팩 1,283개 | 가능 |
| 역할극·인물 컷 | 같은 얼굴 컷 반복 + 대사 자막 | 담긴 영상 얼굴 컷(픽션 썰 선례) | 가능 |
| 화면 녹화(앱·게임·지도) | UI 요소·커서 | 녹화/캡처 | 일부 |
| 글자만(텍스트·댓글 카드) | 장면 재료 없음 | 렌더러 | 가능 |
| 직접 촬영(손·시연) | 한 사람 손·같은 장소 반복 | 못 가져옴 | **대체**로 표시(스톡·AI·제품 영상) |

뜯기 = 컷마다 제작법 판별 → 채널 비율(예: 실사 70%·캡처 20%·짤 10%) + "어떤 줄에 어떤 종류" 규칙(핫템·방구석 판독 "영상 73~95%, 사진은 증거 캡처만"이 첫 사례). 만들기 = 줄마다 그 규칙대로 통로 선택, 없는 통로는 "대체"로 표시(숨기지 않음). 대조 = 제작법 비율 차이도 차이표에.

## 5. 프리셋 = 데이터 한 묶음 (`channel/<slug>/preset/`)

```
preset/
  frame.json        틀 설명서 — 층 목록: 배경·영상창·띠/도형·글자상자(폰트·크기·색·외곽선·그림자·등장효과 = 사전 번호)·이미지·자막 자리
  caption.json      자막 모양·흐름·강조 규칙
  motion.json       컷 박자·화면 효과·전환
  script.rules.json 대본 규칙(4-2)
  audio.json        목소리(닮은 TTS 후보·말속도·쉼)·BGM(분위기·음량·덕킹)·효과음(종류·자리·빈도)
  material.json     제작법 비율·줄→종류 규칙·통로
  overlays.json     짤·스티커 규칙
  manifest.json     어느 원본 몇 편에서 쟀나, 판별 점수, 미확인 항목, 생성 규칙 표식
```
**세 층: 채널 → 갈래 → 틀.** 같은 채널 안에서도 틀이 다르다(썰풀다 50편 = 5갈래·화면 틀 21종. 1위 '닿으면 스피커'는 흰 바탕·검정 제목·3초 자막, 3위 '하키 퍽'은 검정 띠·흰/노랑 제목·1초 자막 — 10-16 눈 실측). 그래서 뜯기는 **편 단위**, 프리셋은 `channel/<slug>/preset/<갈래>/<틀>/`로 두고 채널 평균을 내지 않는다. 영상 1편 칼카피 = 그 편의 틀 그대로, 채널 칼카피 = 조회 상위 갈래의 틀만 남긴다(갈래 묶기 `group_styles.py` 있음).

`spec.py`(코드)는 이 데이터에서 **생성**한다(`rules_to_spec` 꼴, 머리에 "생성됨" 표식). 손으로 적는 상수는 없앤다. 기존 3채널(뜨거운사람들·방구석·썰풀다)을 이 형식으로 변환하고, 변환본으로 다시 만들면 전과 같은 결과가 나와야 한다(회귀).

## 7. 24시간 운전 모델

- **대기열**: 보관함에 채널을 쌓으면 서버 큐가 다음 일을 내주고 PC 실행기(TheRose, 유튜브 다운로드는 서버 IP에서 막힘)가 받아 단계마다 결과를 돌려준다(진행판 §5, heartbeat·11분 끊김).
- **사람 결정 자리 = 멈춤이 아니라 쌓임**: 갈래 확정·시험 3편 판정은 보드 "결정할 것"에 올리고 엔진은 다음 채널로. 아침에 한 번에 결정.
- **클로드 자리**: 판독·대본·장면 고르기 같은 판단 단계는 큐 작업. 클로드는 예약(크론)으로 주기마다 **새 세션**이 들어와 큐에서 집어 간다(한 세션 24시간 금지 — 기억 잘림).
- **비용 상한**: 유료 호출(스피치매틱스·EvoLink·타입캐스트) 하루 상한, 넘으면 그 단계만 멈추고 보드에. 분석·제작=오푸스, 단순=무료 제미나이, 버텍스 금지.
- **조용한 실패 금지**: 어느 채널 어느 단계에서 왜 멈췄는지 보드에. `except: pass` 없음.
- **미확인**: 클로드 코드 예약 실행이 권한 확인 없이 밤새 도는가 — 첫 채널 뒤 하룻밤 시험 운전으로 확인.

## 10. 리스크·미확인 (솔직하게)
1. 판별 정확도 — 만들어 재 봐야 안다(조각 2 시험이 관문).
2. 라이브 렌더러 설명서 모드 공사 크기 — 가장 큰 일일 가능성. `validate_snapshot` 화이트리스트·`precision20-ui.js` 프리셋 id 하드코딩이 걸림돌(조사 실측).
3. 100% 동일은 아니다 — 캡컷 전용 폰트·애니, 모션그래픽은 가장 닮은 것 + 점수. 사전에 추가하며 채운다.
4. 캡컷은 멈춘 그림(PNG)만 받는다(`render_scene_style.js` 주석 실측) — 움직이는 글자효과는 완성본엔 그대로, 캡컷에선 대표 프레임.
5. 예약 실행 무인 운전 가능 여부(§7).
6. 시간 — 조각 1 회귀가 끝나야 근거 있게 말할 수 있다. 2·3이 가장 크다.
