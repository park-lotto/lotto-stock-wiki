숏템메이커 1기 · 8월 24일 시작

설치와 준비

승인이 끝나면 여기서부터 하시면 됩니다. 설치는 두 개뿐이고 둘 다 PC에서 합니다. 캡컷은 원하는 분만 하시면 됩니다.

미리 해두셔야 하는 것

숏템메이커는 제작 프로그램이라, 채널 자체는 미리 준비돼 있어야 합니다.

  • ✓유튜브 또는 인스타그램 채널 개설 — 개설 방법은 제공되지 않습니다
  • ✓채널 기본 운영 준비 — 프로필·채널명 등 기본 세팅
  • ✓구글 계정 — 로그인과 제미나이 키 발급에 함께 씁니다

1단계 · 설치할 것

설치는 사실상 두 개뿐이고, 둘 다 PC에서 합니다.

1

PC 크롬 또는 엣지반드시

담기 확장프로그램과 캡컷 보내기가 크롬·엣지에서만 동작합니다. 휴대폰이나 다른 브라우저로는 설치가 안 됩니다.

2

📥 담기 확장프로그램반드시

유튜브·틱톡·인스타·샤오홍슈·도우인에서 마음에 든 영상을 클릭 한 번으로 담는 기능입니다. 이게 있어야 소재를 모읍니다.

설치는 shoppingshorts.duckdns.org/grab 에서 2단계입니다. ① 설치 파일을 받아 압축을 풀고 → ② 크롬 주소창에 chrome://extensions 를 넣고 오른쪽 위 개발자 모드를 켠 뒤 압축 푼 폴더를 끌어다 놓기.

텀퍼몽키 같은 다른 프로그램은 필요 없습니다. zip 파일이 아니라 압축을 푼 폴더를 끌어다 놓아야 합니다.

2단계 · 캡컷 연동선택

완성본을 캡컷에서 더 다듬고 싶은 분만 하시면 됩니다. 숏템메이커에서 완성 영상을 바로 받거나 QR로 폰에 보내실 거면 이 단계는 건너뛰세요.

1

캡컷 PC 버전을 깔고 — 한 번 켜서 로그인

로그인을 안 하면 캡컷이 설정 파일을 만들지 않습니다. 그러면 다음 단계에서 "설정 파일을 찾지 못했습니다"가 뜹니다. 깔고 나서 꼭 한 번 실행해 로그인까지 해두세요.

2

자동 설정 파일을 한 번만 더블클릭

파일은 두 곳에서 받을 수 있습니다.

① 제작소에서 영상 매칭이 끝나면 아래쪽 📤 내보내기 줄에 ⚙ 캡컷 자동설정(최초 1회) 버튼이 생깁니다.
② 또는 shoppingshorts.duckdns.org/capcut_manual.html(그림 안내) 안의 ⚙ 자동설정 파일 받기 버튼.

이 버튼들은 크롬·엣지에서만 보입니다. 다른 브라우저면 안내문만 뜹니다.

받은 파일을 더블클릭하면 됩니다. 이 파일이 하는 일은 두 가지뿐입니다.

① C:\capcutproject\CapCut Drafts 폴더를 만들고   ② 캡컷의 프로젝트 저장 위치를 그 폴더로 바꿉니다. 기존 설정은 .bak으로 백업해 두므로 되돌릴 수 있습니다.

캡컷을 완전히 끈 상태에서 실행하세요. 켜져 있으면 파일이 "캡컷이 켜져 있습니다"라고 멈춥니다 — 캡컷이 종료할 때 설정을 도로 되돌려버리기 때문입니다.

3

숏템메이커에서 보내기 → 폴더 한 번 허용

크롬이나 엣지로 숏템메이커를 열고 완성 단계에서 캡컷으로 보내기를 누릅니다. 브라우저가 폴더 접근을 물어보면 위에서 만든 CapCut Drafts 폴더를 고르고 허용을 누르세요. 이 허용은 처음 한 번만 하면 됩니다.

4

캡컷을 껐다 켜면 프로젝트가 보입니다

보낸 직후 캡컷이 켜져 있었다면 목록에 바로 안 보일 수 있습니다. 껐다가 다시 켜면 나타납니다.

안 될 때
  • "Chrome 또는 Edge에서만 됩니다" → 크롬·엣지로 여시거나, 대신 캡컷용 ZIP을 받으세요.
  • "설정 파일을 찾지 못했습니다" → 캡컷을 한 번 켜서 로그인부터 해주세요(1번).
  • "캡컷이 켜져 있습니다" → 캡컷을 완전히 끄고 다시 더블클릭하세요(2번).
  • 보냈다는데 캡컷에 안 보여요 → 캡컷을 껐다가 다시 켜세요(4번).

3단계 · API 키 발급

숏템메이커 이용료와는 별도로, 각 서비스에 직접 가입해 키를 받는 부분입니다.

등록하시면 그 작업은 포인트가 안 깎입니다. 5개 다 하실 필요는 없고, 쓰실 기능만 하셔도 됩니다. 다만 아래 두 갈래로 성격이 다릅니다.

① 내 키로 직접 쓰는 것 — VMake · ElevenLabs · SerpApi

등록하신 키로 작업이 돌아가고, 요금은 본인 계정에서 나갑니다. 대신 숏템메이커 포인트는 안 깎입니다.

② 키 1개만 내면 무료로 쓰는 것 — 구글 제미나이 · 유튜브

이 둘은 1개만 등록해 주시면 됩니다. 등록하신 키는 공용 키 묶음에 함께 들어가고, 대신 묶음 전체를 포인트 없이 쓰시게 됩니다. 키를 여러 개 만드실 필요가 없고, 용량이 모자라면 운영자가 채웁니다.

서비스어디에 쓰나비용방식
구글 제미나이 대본 뽑기 · 영상 분석 · 썸네일 무료 1개만 · 공용
유튜브 유튜브 영상 정보 가져오기 무료 1개만 · 공용
VMake 원본 영상의 자막 지우기 월 14,000원 수준 내 키
ElevenLabs 영상에 넣을 AI 목소리(TTS) 월 22달러 수준 내 키
SerpApi 비슷한 영상 찾기(파워검색) 월 250회 무료 내 키

실제로 돈이 나가는 것은 ElevenLabs와 VMake 둘뿐이고, 둘 다 쓰신다고 가정하면 월 4만원 안팎입니다. 결제는 각 서비스에 직접 하십니다. 자막 제거를 안 쓰시면 VMake 비용은 나가지 않습니다.

VMake 키는 값이 두 개입니다. 앱키와 시크릿을 앱키:시크릿 형태로 가운데 콜론을 넣어 한 줄로 붙여넣으셔야 합니다. 띄어쓰기가 들어가면 "키가 틀렸습니다"가 뜹니다.

API 발급이 어려우시면 안 받으셔도 됩니다.

키를 등록하지 않으셔도 포인트가 차감되는 방식으로 그대로 이용하실 수 있습니다. 직접 키를 등록하시면 그만큼 포인트를 아끼는 것이고, 발급이 번거로우시면 포인트로 쓰시면 됩니다.

키 등록은 👤 마이페이지 → 🔑 내 키 등록 탭에서 하시고, 발급 방법은 그림으로 된 단계별 매뉴얼이 준비돼 있습니다 — shoppingshorts.duckdns.org/api_manual.html

SerpApi는 검색 1번에 3회가 소모됩니다. 한국어·영어·중국어로 각각 찾기 때문입니다. 무료 250회는 실제 검색으로 치면 한 달에 약 83번입니다. 키를 등록하셔도 서버 보호를 위한 하루 10번 제한은 그대로 적용됩니다.

포인트 — 무엇에 얼마가 드나

키를 등록하지 않은 작업은 포인트로 차감됩니다. 1P = 100원이고 마진 없이 원가 그대로입니다.

작업차감
🎬 자막 지우기5P
🎞️ 영상 제작 (1편 완성)3P
🔊 목소리 만들기1P
🔎 렌즈로 찾기0.1P
📝 대본 뽑기0.1P

영상 찾기 · 즐겨찾기 · 내보내기는 무료입니다. 작업이 실패하면 포인트는 자동으로 돌려드립니다.

첫날 포인트 충전은 운영자에게 말씀해 주세요.

사이트의 ＋ 충전 버튼은 아직 "준비 중"으로 뜹니다. 신규 계정은 0P로 시작하기 때문에, 키를 등록하지 않으셨다면 첫 작업에서 "포인트가 부족합니다"가 나옵니다. 승인과 함께 포인트를 넣어드릴 예정이니, 부족하면 단톡방이나 카톡으로 알려주세요.

수익화에 필요한 계정

영상을 만든 뒤 실제로 수익을 붙이려면 아래 두 가지가 필요합니다.

1

쿠팡파트너스수익화 시

8단계에서 파트너스 추적 링크를 넣는 칸이 있습니다. 이걸 넣어야 수수료가 붙습니다.

반드시 본인 계정에서 직접 만든 링크를 쓰세요. 남의 링크를 그대로 쓰면 수수료가 그쪽으로 갑니다.

2

인포크링크수익화 시

프로필에 거는 링크인비오 서비스입니다. 9단계에서 인포크에 붙여넣을 문구를 만들어 드리는데, 등록은 직접 하셔야 합니다.

알아두실 하루 사용량

1기(pro) 기준 계정별 하루 상한입니다. 넉넉하지만 무제한은 아닙니다.

제공되지 않는 것

숏템메이커는 제작 프로그램이지 입문 강의가 아닙니다.

  • ✕유튜브·인스타그램 채널 개설 방법
  • ✕각 플랫폼의 기본 사용법·운영 방법
  • ✕쇼핑 채널 세팅을 처음부터 대신해드리는 서비스
  • ✕쇼핑쇼츠 수익화 전반에 대한 기초 강의

프로그램 사용방법 교육영상과 제작 노하우는 별도로 제공됩니다.
