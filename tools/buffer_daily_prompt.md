## 영상 하나 준비 (prepare 의 각 영상)
드라이브 폴더 = {drive}\<folder>\<영상>
1. 장면 모음: 파이썬 subprocess 로 ffmpeg — 길이/12 간격 12장, 가로 200, 6x2 타일 한 장(jpg)을 {report}.d\ 에 만들고 Read 로 본다.
   - 오른쪽 위 '광고' 표시가 없으면 그 영상은 건너뛰고 보고에 적는다(배지 없는 영상은 올리지 않는다).
   - 화면 글자·자막으로 제품을 알아낸다. 확신이 없으면 건너뛴다.
2. 쿠팡 후보: `cd "{shoplink}" && py tools/shoplink/run.py find "<검색어>"` (아무것도 안 만든다)
   - 영상 속 제품과 **같은 물건**인 후보가 있을 때만 다음으로. 비슷한 다른 물건뿐이면 건너뛴다.
3. 링크·인포크: `cd "{shoplink}" && py tools/shoplink/run.py make "<검색어>" --channel <계정 번호> --match "<그 후보 이름 일부(유일하게)>" --name "<짧은 상품 이름>"`
   - 계정 번호 = 폴더 이름 앞 숫자(21·950·987·994·995·998·999). 출력의 `인포크: <계정> <블록 제목>` 과 `공개 페이지 실측: 있음` 을 확인한다. '없음'이면 건너뛴다.
4. 같은 이름 .txt 를 영상 옆에 UTF-8 로 쓴다:
   ```
   <제목 — 한국어, 숫자로 시작 금지, 영상 상단 문구를 살린 한 줄>

   <설명 2~3문장 — 영상에서 실제로 나온 내용만. 지어낸 사실·과장된 수치 금지>

   #쇼츠 #<태그> #<태그> #<태그> #<태그>
   인포크: <3번 출력의 블록 제목 그대로, 예: [14] 손 안 쓰는 외다리 목발 / 14. 먹는 숟가락>
   ```
   - 쿠팡 링크는 .txt 에 쓰지 않는다(쿠팡은 인포크에만). '프로필 링크 N번' 문장도 쓰지 않는다(buffer_post 가 채널 말투로 넣는다).

## 예약
- 준비가 끝난 계정마다: `py tools/buffer_post.py post --folder "<folder>"`  → 유튜브+틱톡이 오늘 빈 칸에 들어간다.
  관문(인포크 블록 실측·중복·칸 겹침)이 막으면 억지로 넘기지 말고 보고에 적는다.
