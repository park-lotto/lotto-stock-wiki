# 썰쇼핑 — 한 편 만드는 순서 (이 PC 의 클로드가 그대로 한다)

간식·제품 하나의 «썰»(탄생 비화·짝퉁·대란·몰락·역전)을 약 45초 세로 쇼츠로 만든다.
화면 틀·자막·컷 움직임·쉼은 `tools/render.py`·`tools/tts.py` 상수에 이미 박혀 있다(참고 채널 실측 · `docs/MEASURE.md`).
**그 숫자를 다시 재거나 찾지 않는다.** 한 편 = 음성 1번 · 렌더 1번. 같은 검사를 되풀이하지 않는다.

명령은 이 폴더(작업 루트)에서 `python preset.py …` 로 돈다(사전 점검이 만든 전용 가상환경의 python).
프로젝트 폴더는 `작업/<영문이름>/` 로 만든다(예: `작업/honey/`). 아래 `<P>` 가 그 폴더다.

## 0. 시작 전 (처음 한 번)
- `python preset.py status` — ffmpeg·agy·열쇠(typecast·speechmatics)가 `found`/`true` 인지. 아니면 회원에게 알린다.
  열쇠는 `~/.volcano/keys/typecast`, `~/.volcano/keys/speechmatics` 파일(값만)에 둔다. 열쇠 값을 어디에도 적지 않는다.
- `config.json` 의 `channel_name`(헤더에 두 글자면 아이콘 양옆에 한 글자씩) · `header_icon_path`(내 로고 PNG, 비우면 기본 그림)를 회원에게 묻고 적는다.
  목소리는 타입캐스트 제롬(`voice`). 바꾸면 회원이 정한 대로.

## 1. 소재와 사실
- 회원이 준 제품·주제, 없으면 «개발 비화·짝퉁·대란·몰락·역전» 이 있는 간식·제품을 고른다.
- 사실은 **기사·공식 자료 2곳 이상**으로 확인한 것만 쓴다. 출처를 `<P>/SOURCES.md` 에 적는다(예시 `examples/honey/SOURCES.md`).

## 2. 대본 `<P>/script.json` (예시 `examples/honey/script.json`)
- `title` 14~17자 도발형 · `hook` = 제목을 두 줄로 나눈 것(둘째 줄이 하늘색).
- `cards[].lines` 1~2줄, 한 줄 4~12자 말 덩어리. 약 330~360음절(40~50초).
- 말투 음슴체 반말: «~함 · ~해버림 · ~였음 · ~인데 · ~는데», 끝은 «~있다고 / ~가더라». 흐름: 배경(연도·숫자) → 갈등 → «근데/이때 … 진짜 레전드인데» 반전 → 대비 → 결말 → 현재.
- ★**문장이 끝나는 줄(~함·~음·~됨 등) 끝에 마침표 `.` 를 찍는다** — 그래야 끊어 읽힌다(자막에선 지워짐). 받침으로 자동 판단하지 않는다(«여름» 같은 명사가 틀린다).

## 3. 실제 영상 소재
- `python preset.py media yt <P> g1 "<검색어>" 3` — 검색어 3~4개(제품 뉴스·공장·먹방·주가 등). 긴 검색어는 결과가 0개일 수 있다 — 짧게.
- 고르기는 `python preset.py scenes <P>` → `<P>/scenes.json` — **후보 영상마다 작은 사본 한 파일**을 agy 가 한 번 본다(영상끼리 동시에 ·
  한 대화에 영상 하나 · 긴 영상은 조각). 카드마다 고른 구간·다른 후보·못 찾은 카드를 적고 `media clip` 명령 줄을 찍는다(뉴스 띠면 crop 도).
  시작 초 범위·같은 구간 두 번 금지·점수 순 배정은 코드가 한다. `agy` 를 직접 불러 후보 폴더를 통째로 보이지 않는다(한 대화에 수백 MB → 답 없이 끝난다).
  못 찾은 카드가 있으면 검색어를 바꿔 `media yt` 로 더 받고 `scenes` 를 다시 — 이미 답한 영상은 다시 묻지 않는다(답 없던 조각은 한 번만 더).
- 효과음은 영상을 볼 필요가 없다 — 6번대로 «결정적인 줄(놀람·충돌·폭락·반전) 약 4줄에 1개»(이름은 assets/sfx 중)를 카드에 직접 적는다.
- 카드마다 컷 **1개가 기본**(둘째 줄은 렌더가 «툭» 확대로 처리). 몽타주·같은 인물 그림 연속만 `media` 를 목록으로.
- 뉴스·자막이 박힌 영상은 `"crop": [0, 0.12, 1, 0.75]`(자막 띠를 자름).

## 4. 실사풍 재연 그림 (화면 시간 약 20~30%)
- 실제 영상이 있을 수 없는 사건 장면(결정·반대·설득·도망·허탈 등)에만 쓴다. 검색 사진은 쓰지 않는다.
- `python preset.py aiimg <P> ai01 "<영문 장면 설명>"` · 같은 인물은 같은 외모 문구 + 앞 그림을 참고로: `... ai02 "<설명>" <P>/media/ai/ai01.jpg`
- 만든 뒤 agy 가 그림을 보고 «글자·로고 · 손·얼굴 이상 · 앞 그림과 다른 사람» 을 본다. 걸린 그림만 다시 만든다.

## 5. 피사체 가운데
- agy 에게 컷마다(영상은 그 시작 초부터 1초) 주 피사체 중심을 원래 화면 기준 가로·세로 %로 받는다(한 번에).
- `focus: [가로, 세로]` = crop 뒤 기준 0~1 — crop `[x0,y0,x1,y1]` 이면 `((x/100-x0)/(x1-x0), (y/100-y0)/(y1-y0))`.

## 6. 효과음
- 카드에 `"sfx": [{"name": "hit_2", "line": 1}]` — `line` 은 그 줄(0부터)이 나올 때 울림. 이름은 `assets/sfx/*.mp3`.

## 7. 음성 → 굽기 전 판정 → 렌더 → 확인
- `python preset.py tts <P>` — 타입캐스트 1회(유료 · 글자 수를 먼저 회원에게 알린다) + Speechmatics 정렬. 일치율 90% 미만이면 대본·읽기를 점검.
  다시 처리만 할 때는 `--reuse`(타입캐스트를 다시 부르지 않음).
- `python preset.py review <P>` → `<P>/review.json` — **굽기 전에** 완성본과 같은 그림·시각의 작은 미리보기(소리 없음)를 만들어
  agy 가 **한 번** 본다: 컷마다 «영상 칸에 원래 영상의 자막·띠·로고 · 자막과 안 맞는 장면 · 검은/멈춘 화면». 판정은 코드가 한다(하나라도 걸리면 실패).
  «빈 화면(한 색) 컷» · «소재 시작 초가 영상 길이를 넘음» 은 미리보기를 만드는 코드가 먼저 잡는다(그때는 agy 를 부르지 않는다).
  실패면 **걸린 컷만** 고치고(소재·구간·자막) review 를 다시 — agy 는 **바뀐 컷만** 묻는다(컷마다 지문을 review.json 에 남긴다 ·
  통과한 컷은 다시 묻지 않는다 · 고친 것이 없으면 아무것도 묻지 않는다 · 답이 없던 컷은 한 번만 더 묻는다). 그림 이상은 4번에서 이미 봤다.
  소리 크기·움직임처럼 agy 가 틀리기 쉬운 것은 이미 렌더 상수로 정해져 있다 — agy 말로 바꾸지 않는다.
- `python preset.py render <P>` → `<P>/out.mp4` + `render_receipt.json`. 굽기 전 판정이 없거나·실패거나·판정 뒤 대본·타이밍·소재가 바뀌었으면 굽지 않는다.
- **완성본은 agy 에 보이지 않는다**(렌더 뒤 agy 금지). `python preset.py check <P>` → `<P>/sseol_check.json`(규격·길이·굽기 전 판정·영수증 — 프로그램 측정만).
  통과하면 `<P>` 경로를 서버에 넘긴다.

## 지킬 것
- 검색으로 가져온 영상은 남의 저작물이다 — 업로드 전 회원이 권리를 확인한다.
- 참고 채널의 대본·이름·로고를 쓰지 않는다. 대본은 이 편 소재로 새로 쓴다.
- 열쇠 값은 어디에도 적지 않는다.
