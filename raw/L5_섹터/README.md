# L5 — 섹터

국제정세와 시장 구조가 실제 산업·기업에 미치는 영향.
수급 분석 전 섹터 방향성 파악의 핵심 레이어.

## 수집 대상

| 소스 | 내용 | 수집 주기 |
|------|------|---------|
| 섹터 리포트 | 증권사 섹터 분석 보고서 | 발행 시 |
| 종목 리포트 | 개별 종목 TP·투자의견 | 발행 시 |

| 유튜브 섹터 분석 | 주요 채널 섹터 영상 요약 | 주 1~2회 |
| 텔레그램 섹터 | 섹터 관련 주요 채널 | 매일 |
| 산업 뉴스 | 섹터별 핵심 이슈 | 이슈 시 |
