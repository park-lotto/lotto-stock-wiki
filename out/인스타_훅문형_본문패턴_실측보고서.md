## 0. 결론 3줄

1. **판정 단위는 채널이 아니라 훅 문형(축)이 맞다** — 채널 안 훅 일치율은 7~42%뿐인데, 같은 훅은 채널을 넘나든다("여러분 다이소 가면 이거" 25편/12채널).
2. **본문도 패턴화된다** — 축마다 도입→마무리 5구간 역할 분포가 뚜렷이 갈린다(지인증언은 도입 상황 41%, 금지경고는 도입 문제 27%+사용법 22%).
3. **축을 넘는 상수 3개를 찾았다** — 길이 22~25초 · 밀도 297~327자/30초 · 마무리 CTA 76~92%. 현재 spine의 밀도값(226~300자)은 **실측보다 낮다 → 고쳐야 한다**.

## 8. 축 발굴 3차 — 커버리지 65% → 71%

미분류 훅을 전량 눈으로 읽어 새 축 5개를 찾았다(전세공포·정체의문·잘못인지·리스트형·지목호명).
동시에 **가짜 축 3개를 검정으로 걸러냈다.**

### 접두어 검정 — 축인가 수식어인가

축으로 잡힌 것에서 접두어를 지우고 **다시 판정**한다. 다른 축으로 안 옮겨가면 그건 축이 아니다.

| 의심 축 | 편수 | 접두어 제거 후 | 판정 |
|---|---|---|---|
| 대상호출("여러분") | 32 | 32편 전부 여전히 미분류 | ✗ 수식어 |
| 감탄개시("와") | 32 | 29편 여전히 미분류 | ✗ 수식어 |
| 본인경험("저 이거") | 16 | 14편 여전히 미분류 | ✗ 수식어 |

수식어 자체는 templates에 쓸모가 있다: **여러분 23% · 와/우와 13% · 저 이거 8%**.

`권위출처`(11편)는 다른 이유로 내렸다 — 11편 중 3편이 실제로는 금지경고 문장이었고
("의사 선생님이 ~ 흰쌀밥 절대 먹이지 마세요"), 유튜브 spine 55·56이 이미 `authority`를
**본문 칸**으로 둔다. 같은 판단을 훅과 본문 두 군데에 두면 어긋난다(0순위-B).

문장은 **전부 전사 원문에서 가져왔다.** 슬롯은 기존 7종만 썼다 —
`insta_facts.py`는 인스타대본스파인 트랙과 공용이라 이쪽에서 고치지 않는다.

### 조립 실측으로 잡은 것 3가지 (정적 검토로는 안 보였다)

```
① {차별점}이라  → fix_josa가 받침을 보고 "구조가라 되는 거였어요"로 망가뜨림
                  → 슬롯 바로 뒤에 '이라/이더라'를 붙이지 않는다
② {불편함}이 mistake·reason 두 칸에 들어가 같은 문구가 한 대본에 2회 등장
                  → reason에서 슬롯을 뺐다
③ 조립 결과가 196자인데 실측 밀도로는 24초에 258자 필요(76%)
                  → 5구간 프로필에 실제로 있던 problem 칸(전개 22%)을 넣어 225자(87%)
```

### ★심어도 안 도는 상태였다 — 조립 경로 배선

```
INSTA_CATEGORIES = ("다이소형",)      ← 이거 하나뿐이었다
```
스파인의 `fit_categories`에 이 이름이 없으면 `_assembled_drafts`가 **조립 대상으로 보지도
않고 조용히 생성기로 폴백한다**(오류 안 남). 그래서 기계용 이름을 추가했다:
`("다이소형", "금지경고형", "사회증거형")`. 검증: `_is_insta_context`가 둘 다 True.

### 같은 이유로 spine 52·53·54는 지금도 조립이 안 된다 (실측)

## 10. 장면 규격 — "어느 구간에 어떤 장면"

`scene_desc` 7,047컷 전량. 규칙은 실제 어휘를 뽑아 만들었다
(보여주는 561 · 손으로 509 · 완성된 248 · 넣는 149 · 올리는 149 · 붓는 133 …).

### 전체 분포 (7,047컷)
```
투입도포 15% · 제품클로즈업 8% · 결과제시 8% · 손시연 7% · 기기조작 6%
제거청소 6% · 공간전경 4% · 보여주기 4% · 인물 2% · 문제상태 2% · 기타 32%
```

### 축별 구간 특성 (실제로 갈린다)

| 축 | 화면의 정체 |
|---|---|
| **다이소지목** | **제거청소 15~20%가 전 구간** — 다른 축엔 거의 없다. 청소용품 축이다. 마무리 결과제시 21% |
| **금지경고** | 투입도포가 전개 22%로 최고 → 마무리 결과제시 17%. 틀린 방법/바른 방법 대조가 화면에도 있다 |
| **사회증거** | 도입 손시연 19%+기기조작 15%(손이 먼저 나온다) → 후반 결과제시 22% |
| **충격선언** | 마무리가 제품클로즈업 19%·공간전경 18% — **물건 자랑으로 끝난다** |
| **지인증언** | 전 구간 투입도포 중심, 마무리 공간전경 9% |

### ★인물 2% — 기존 실측이 재확인됐다

메모리 `reference_인스타_음성스토리_화면시연_분리`("대사에 사람 나오는 컷 49개 중 화면에도
나온 건 1개 = 2%")가 **7,047컷 전량에서도 2%**로 같다. 음성=스토리 / 화면=시연 분리는 확정이다.

### 공통 규칙 (축 무관)
```
결과제시는 뒤로 갈수록 오른다 — 전 축이 마무리에서 최고치(13~21%)
투입도포는 전 구간 1위 — 화면의 주력 동사는 "넣고 바르고 뿌리는" 것
```
