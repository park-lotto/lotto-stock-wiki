# 🔊 썰쇼핑 채널 효과음 실측 2차 + 자동매칭 진단 (2026-08-31, 회사PC)

## 한 줄
사장님: "이븐쇼핑 외 비슷한 채널들 효과음 뭘 어느 구간에 쓰는지 조사, 3·5단계 자동매칭 구현"
→ **8채널 12편 실측 완료. 3단계 자동매칭은 이미 라이브인데 재료가 0개고, 매칭축이 실측과 어긋난다.**

## ✅ 오늘 한 것

### 1. 실측 2차 — 3편 → 8채널 12편으로 확장
이븐쇼핑3 · 살림킹왕짱3 · 치트키요정 · 긍정템 · 순찌홈 · 살림장착 · 인생갓템 · 공가미.
서버 `source_enrichment`에서 채널별 조회수 상위로 뽑아 실제 다운로드·오디오 분석.

### 2. ★1차(08-29) 결론을 정정했다 — 대조군을 붙였더니 과장이었다
1차 "컷 55개중 52개(95%)에 효과음"은 **배경음악 하이햇을 효과음으로 센 값**이었다.
이벤트를 통째로 2초 밀어 컷과 관계를 끊고 재도 커버율 73%가 나온다 = 밀도가 높으면
아무 신호나 컷에 맞는다.

```
느슨한 임계   실제 84% / 랜덤 73% → 순수신호 +11p
시간이동 대조 ±100ms: 41.1% vs 27.8% → +13.4p
임계를 어떻게 잡아도 순수신호는 +9~13p를 못 넘는다
```

- ✅ 컷 경계에 몰리는 경향은 **진짜**(Δ중앙 0ms, 먼저 38/나중 38 정확히 반반)
- ❌ "95%"는 과장 → 실제 정렬은 **49%(±150ms)**
- ✅ 타점 기본값 `transition`은 **그대로 유지**(결론 방향은 안 바뀜, 코드 변경 없음)

### 3. 재료 스펙 확정 (441건 분류)
```
반짝/whoosh  80%   ← 컷마다 돌려쓰는 주력
붐/임팩트    17%   ← 강조 칸만
둘 동시       3%
길이 중앙값 80ms · 93%가 200ms 이하
```
→ **"효과음이 비트보다 길어 넘친다"는 스펙 §4.3 한계는 실질적으로 무의미**(0.08초가 0.8초 칸을 못 넘음).
→ 필요한 자산은 **전환음 3~5개 + 임팩트 1~2개**. 역할 7종을 다 채울 필요가 없다.

### 4. 검출기를 영구 스크립트로 (`tools/sfx_probe.py`)
1차 검출기는 스크래치패드에 있다 사라졌다. `--selftest`(합성 정답파일) 내장 — 통과 확인
(3/3, 30ms 이내, 음성만 파일 오탐 0).

## 🔎 진단 — "3·5단계 자동매칭 구현"에 대한 답

**5단계는 TTS음성이다**(`produce.html` data-steptitle). 효과음이 붙을 자리는 **3단계 영상대본MIX**이고,
거기 자동매칭은 **2026-07-22부터 이미 라이브**다(`match_sfx` · `transition` 타점 · 칸 도구줄 · 미리듣기).
즉 새로 만들 게 아니라 **막힌 두 곳을 뚫는 일**이다.

### 막힌 것 ① 재료가 0개 (선행조건)
서버 `reference.db` `scene_assets` 실측: `asset_type='sfx'`가 **2건뿐**(훅1·본문1),
둘 다 08-21에 만든 검증용 톤. **자산 0개면 UI가 효과음 줄을 아예 안 그린다**(`scene_lab.html:2251`)
→ 타점을 아무리 고쳐도 화면엔 변화가 없다.

### 막힌 것 ② 매칭축이 실측과 어긋난다 (실행해서 확인)
전환음 4 + 붐 1을 등록했다 치고 9칸 대본에 `match_sfx`를 실제로 돌려봤다:

```
칸0 hook        (없음)   ← '훅' 역할 자산이 없으면 통째로 빈다(fallback에 '전환' 없음)
칸4 result_wow  (없음)
칸5 benefit     (없음)
칸6 cta         (없음)
배치 5/9칸 · 서로 다른 소리 2개 (id 큰 것 고정 = 로테이션 아님)
```

두 가지가 실측과 다르다:
1. **`_ROLE_FALLBACK`이 역할 7종을 요구** — 실측 영상은 역할과 무관하게 같은 계열을 컷마다 돌려 쓴다.
   전환음만 등록하면 hook·result_wow·benefit·cta가 전부 빈다.
2. **`_pick_role_asset`이 결정적**(overlap 동점이면 id 큰 것 고정) — 같은 소리만 반복된다.
   실측은 3~5개를 **로테이션**한다.
