## 🎬 제작 방식: 3레이어 하이브리드

```
레이어 A — Remotion 그래픽    : 훅·개념·비유·로드맵·클로징
레이어 B — 실화면 녹화 (OBS)  : STEP별 실제 클릭·설치·시연
레이어 C — 하이브리드 합성    : 실화면 위에 DocHighlightScene 오버레이
                               (형광펜·줌인·화살표·설명 박스)
```

**테크피드 스타일 적용 포인트**:
- 실화면을 전체 보여주지 않음 → **DocHighlightScene으로 중요 영역만 크롭+줌인**
- 클릭 순간마다 → 해당 영역 팡! 확대 + 민트 형광펜 하이라이트
- 나레이션 100% + 실화면 + Remotion 자막 바 오버레이
