# A형 확장 캠퍼스 3D 전환

사용자 기준은 B에서 A로 변경됐다. 주간/야간 대표 시안 exec-d18f0325-b1e0-4e0f-b310-5dd44f2910b7.png를 비교 기준으로 사용한다. 외관만 진행하며 로로/실내/음성은 이번 범위 밖이다.

- `campus-a-layout.js`: 본사 뒤 중앙, 프로그램 좌우, 앞 중앙 프로젝트관과 확장 정원. 건물 ID/배치를 외형과 분리.
- `campus-a-art.js`: 석재 프레임·투명 유리·안쪽 층/조명/사무실 단서, 테라스 정원, 정문, 물길/보행교, 조경. 낮·밤 건축 위치 불변.
- 기존 `/campus/` 렌더러를 A로 연결하고 비교 이미지/카메라/조명을 갱신. B 소스는 보존하되 사용하지 않는다.
- 배치 테스트 먼저 실패 확인, 브라우저 정면/측면/후면/확대/낮밤/비교/모바일 검사 및 실제 캡처 확인. 디자인 기준 이미지 수준 달성했다고 주장하지 않는다.
