# 숏템박스 런칭 VSL — 1회차 촬영 대본 (10분 임팩트판)

- **목적:** 1기 모집 · "무료 공략법" 포지션으로 신뢰 → 비밀·한정으로 회수
- **포맷:** 실루엣/음성변조 **인터뷰(서사)** + **화면녹화 데모(증거)** 교차편집
- **톤:** 처음부터 끝까지 [페인 자극 → 강점 → "우와 진짜 편하다"] 밀어붙이기. 언더그라운드("쉿, 아는 사람만")
- **정직선:** 가짜 수익창 ❌ / 인터뷰는 사장님 **본인 실제 서사**("제가 그 수강생") / 증거=테스트 채널 **실조회수**
- **길이:** ~10:00 (600초) · 컷 10개

> 표기: `[화면]`=촬영/화면 지시 · `[대사]`=읽는 내레이션 전문 · `[자막]`=번인 자막(큰 글씨)

## S1 · 콜드오픈 훅 (0:00–0:35)
[화면] 완성 쇼츠 3개가 촤르륵 빠른 컷 재생 → 검은 배경 흰 글씨 타이핑
[대사]
> "**진짜 미쳤습니다. 세상에 없던 프로그램이 나왔어요.** 저 이거 처음 보고, 소름 돋아서 한참을 멍하니 봤습니다.
> 드디어 나왔습니다. 소문나기 전에, 딱 한 번만 보여드릴게요.
> 지금 보시는 이 쇼츠 세 개… 제가 만든 거 아닙니다. 정확히는, **제 손이** 만든 게 아니에요.
> URL 하나 붙여넣고, **4분**. 편집은 단 한 번도 누르지 않았습니다. **정말 놀랍지 않아요?**
> 현존하는 쇼츠 자동화 프로그램, 제가 **다 써봤고**, 결국 **제가 직접 만들었습니다.**"

[자막] **진짜 미쳤습니다** / 세상에 없던 프로그램 / 소문나기 전에 / **현존 최고 쇼츠 자동화** / URL 1개 → 4분

## S2 · 동일시 + 페인 [인터뷰·실루엣] (0:35–1:40)
[화면] 실루엣 인터뷰, 하단자막 "쇼핑쇼츠 3년차 · 前 유료강의 수강생"
[대사]
> "솔직히 말할게요. 저, **300만원짜리 쇼핑쇼츠 강의** 결제했던 사람이에요.
> 근데 강의를 다 들어도… 결국 **편집은 제가 다** 하더라고요.
> 제품 찾고, 대본 쓰고, 자막 달고, 성우 입히고, 썸네일 만들고… 영상 하나에 **세 시간**.
> 강의는 '이렇게 하면 됩니다'까지만 알려주지, 그 **'이렇게'를 대신 해주진 않잖아요**."

[자막] 강의 300만원 / 근데 편집은 내가 다 함 / 영상 1개 = 3시간

## S3 · "5개 다 써봤다" (1:40–2:40)
[화면] 5개 프로그램 UI 로고 가리고 빠르게 스치듯(저격 아님, 구조만)
[대사]
> "그래서 유료 자동화 프로그램을 찾았죠. 시중에 나와 있는 거, **다섯 개 전부** 결제했습니다.
> 강의에, 프로그램에… 이것만으로 **수천만원** 썼어요.
> 결론부터요? **다 똑같이 답답했어요.**
> 결과물이 다 비슷하게 생겼어요. 딱 봐도 '아, 저거 그 프로그램이네' **티가 나요**.
> 트렌드는 못 따라가고, 매달 구독료는 나가는데 **업데이트는 안 되고**.
> 지금 터지는 영상이 눈앞에 있는데, 그걸 **못 베껴요**."

[자막] 5개 전부 결제함 / 결과물이 다 똑같음 / 지금 터지는 걸 못 베낌

## S4 · 탄생 + 핵심 철학 (2:40–3:30)
[화면] 숏템박스 로고/대시보드 첫 등장
[대사]
> "그래서 그냥, **제가 만들기로 했어요.** 개발? 한 번도 안 해봤습니다.
> **클로드한테 물어가면서**, 밤마다 붙잡고, 그 다섯 개의 답답한 지점을 하나씩 다 뜯어고쳤어요.
> 그렇게 나온 게 이겁니다. **숏템박스.**
> 핵심은 이거예요 — 쇼핑쇼츠는 퀄리티가 **극상일 필요가 없어요.**
> 진짜 핵심은, **지금 터지는 영상을 얼마나 더 트렌디하게, 더 독창적으로 벤치마킹하느냐.**
> 숏템박스는 그걸 **자동으로** 합니다."

[자막] 개발 0 → 클로드로 직접 / 5개 페인 다 뜯어고침 / **핵심 = 트렌드 벤치마킹**

## S5 · 라이브 데모 [화면녹화, 3분] (3:30–6:30)

**챕터1 — 찾기**
> "영상 URL 하나 붙여넣으면, 알아서 제품을 찾고 분석해요. 유튜브·인스타·틱톡 다 됩니다. 붙여넣고… 끝."
[자막] URL 붙여넣기 → 끝 / **우와 편하다**

**챕터2 — 트렌드 기획**
> "지금 터지고 있는 레퍼런스를 넣으면, AI가 그 구조를 분석해서 **내 제품에 맞게 대본을 새로** 짜요. 베끼는 게 아니라, **트렌드만** 가져오는 거죠."
[자막] 터지는 구조만 → 내 걸로

**챕터3 — 편집(차별점)**
> "여기가 다른 프로그램이랑 **갈리는 지점**이에요. 성우 목소리도 프리셋으로 클릭, 자막 스타일도 클릭, 장면도 알아서 배치, 효과음까지. 제가 지금 뭐 했죠? **클릭 몇 번**밖에 안 했어요."
[자막] 여기가 남들과 다름 / 클릭 몇 번

**챕터4 — 완성**
> "속도감까지 자동으로 다듬고… 자, **완성.** 링크인바이오 쇼핑몰까지 같이 만들어져요. 이걸 **올리기만** 하면 됩니다."
[자막] 완성 / 업로드만 하면 끝

[대사 마무리]
