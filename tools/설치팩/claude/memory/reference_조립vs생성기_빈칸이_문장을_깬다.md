숏템메이커 대본에는 경로가 둘인데 **품질 차이의 뿌리가 여기 있다**(2026-08-21 실측).

| | 문장틀을 어떻게 쓰나 | 구조 강제 | 문장 품질 |
|---|---|---|---|
| 조립 `spine_fill.build_draft` | **글자 그대로** + 빈칸 치환 | 틀이 곧 구조 | 나쁨 |
| 생성기 `bank_assemble.style_block` | **참고만** 하고 모델이 새로 씀 | role 이름을 돌려받아 `script_gate`가 대조 | 좋음 |

**둘 다 구조는 강제된다.** 조립의 실제 이점은 `모델 호출 0회`(비용·속도)뿐이다.

## 왜 조립이 깨지나 — 빈칸 값의 형태에 계약이 없다

같은 슬롯인데 영상마다 명사·관형형·완결문장이 뒤섞여 들어온다. 템플릿 뒷말은 하나로 고정이라
서로 안 맞물린다.

```
"저도 해보니까 진짜 {효과} 거 있죠"
  효과="불꽃이 올라오는"(관형형) → "…진짜 불꽃이 올라오는 거 있죠"   OK
  효과="정리할 수 있다"(문장)    → "…진짜 정리할 수 있다 거 있죠"    깨짐
```
`{수치} 만에` + 값 `"5분 만에"` = `"5분 만에 만에"` 도 같은 뿌리.

**템플릿을 고쳐도 어미를 통일해도 다른 영상에서 또 깨진다.** 하나 막으면 옆에서 난다(두더지잡기).
실제로 하루에 반창고 4개(다듬기·중복어절 제거·인접칸 도입부 충돌·수치검사 완화)를 붙였고
전부 조립이 만든 문제였다.

## 끄는 법 — 코드 배포 없이

```
settings.assemble_off = "1"   → _assembled_drafts가 첫 줄에서 반환, 전 스파인이 생성기로
```
`_ADMIN_SETTING_KEYS`에 등록돼 `/api/admin/settings`로도 토글. 기본은 꺼져 있지 않음(회귀 0).
⚠️`_assembled_drafts`의 반환값은 **(out, left, why) 3개**다(docstring은 2개처럼 적혀 있다).

## 아직 안 쓰는 자산

`pattern_source` 512건에 히트 영상 전사가 있고 `structure_json`에 **역할별 실제 대사가 이미
분해**돼 있다(`{"hook": ["여러분 감자 찌지 말고 꼭 이렇게 드세요", …]}`), `spine_id`로 축과 연결됨.
축의 **구조**는 히트영상 3편+에서 오는데(`daily_batch.cluster_and_gate_spines`) **문장 틀은
근거 없이 별도 작성**돼 있다 — "구조는 맞는데 문장이 헛소리"의 뿌리. 조립을 다시 쓸 거면
문장을 여기서 뽑아야 한다.
