# 유튜브 레퍼런스 랭킹 — 채널 정예화 설계

- 날짜: 2026-07-29
- 트랙: `유튜브채널정예화`
- 상태: 설계 승인됨(사장님 "고")

## 1. 문제

유튜브 레퍼런스 랭킹이 숏템쇼츠(해외 짜깁기 쇼핑영상) 제작에 쓸 소재를 못 보여준다.
사장님 표현: "정말 짜깁기 쇼핑쇼츠를 할 만한 게 안 보이고 뒤죽박죽".

### 실측 근거 (2026-07-29, 서버 `reference.db` / `settings.last_run::youtube`)

| 사실 | 값 |
|---|---|
| 수집 총건 | 6,062건 (매일 08:10 정상 수집 중) |
| 카테고리 '기타' | **3,009건 = 절반** |
| delta 상위 12 중 연예·아이돌 클립 | **10개** (KREAM/즐거운타임/덕칼럼/셀럽이냥 등) |
| 채널 수 | 715개 |
| 적합도 100%(홈템·레시피·가전만) | **285개** |
| 적합도 0%(전부 '기타') | **164개** (작가의 연예노트, 요오즘이슈 …) |

### 근본 원인 — 두 가지

1. **채널이 큐레이션된 적이 없다.** `platform_seeds`의 유튜브 시드 464개는 사장님이 고른 게
   아니라 키워드 검색 결과에서 자동 축적된 raw 채널 ID(`UC...`)다. 연예 클립 채널이 그대로 섞였다.
   → 인스타가 잘 나오는 이유는 알고리즘이 아니라 **사람이 채널을 골랐기 때문**이다.

2. **키워드 검색이 채널 수집과 섞여 들어온다.**

   ⚠️ 2026-07-29 코드 정정: 처음엔 "등록 채널이 수집에 안 쓰인다"고 판단했으나 **틀렸다.**
   `service._collect_youtube()`(`service.py:150-166`)는 세 경로를 **전부 합친다**:

   ```
   preset 키워드 검색(preset_keywords(categories), lang="ko")
   + 수동 키워드 시드(by_lang)
   + 계정 시드(yt_fetch_channel — 464개, 전부 kind='account')
   → video_id 중복제거 → build_youtube_items
   ```

   유튜브 시드는 464개 전부 `kind='account'`라 `by_lang`은 비어 있다. 따라서
   **잡음의 유일한 출처는 `preset` 키워드 검색 경로**다. 채널 수집은 이미 정상 작동 중이다.

   이 정정으로 T4가 "경로 전환"에서 **"키워드 경로 차단"** 으로 축소된다(아래 참조).

부수 문제: 키워드 검색은 `videoDuration="short"`(YouTube 정의 = **4분 미만**)를 쓰고,
통계 조회가 `part=statistics`뿐이라 **길이 정보가 없어 60초 필터가 불가능**하다.
(상위 50개 실측: ≤60초 48개 / 61~180초 2개 / 그 이상 0개 — 오염은 작지만 필터가 없는 건 사실)

## 2. 목표 / 비목표

**목표**: 유튜브 랭킹에 살림·제품 소재만 남긴다. 연예·이슈 클립을 구조적으로 차단한다.

**비목표(이번 범위 밖 — 별건으로 분리)**
- **얼굴 실촬영 판별**: 카테고리로는 불가능. 채널 정예화 후 남는 잡음을 보고 판단한다.
- **해외 원본 확보**: 현재 수집은 `regionCode=KR` + `relevanceLanguage=ko` + 제목 한국어 필터라
  해외 영상이 구조적으로 못 들어온다. 언어 설정 문제로 별도 과제.
- 랭킹 점수식 변경: 이미 별건으로 처리됨(`'전체'` 탭 → delta 정렬, 커밋 `d05fbf9c8`).

## 3. 설계

기존 자산을 최대한 쓴다. **새 테이블·새 컬럼·새 승인 상태를 만들지 않는다.**

이미 있는 것:
- `/api/seeds` GET/POST/DELETE (`app.py`) — 시드 추가·삭제
- `store.add_seed / remove_seed / list_seeds` (`store.py:1251-1265`)
- 채널 지표·관리 보드 `openChannelBoard()` (`index.html:750-780`) — 삭제 버튼 포함
- `/api/seeds/from_youtube_videos` — 영상 목록에서 채널을 시드로 등록
- `youtube_client.fetch_channel_shorts(seed, ...)` — 채널의 쇼츠 수집. **`≤60초` 필터 내장**
  (`youtube_client.py:246` duration 파싱) → "쇼츠만" 요구가 여기서 자동 해결된다

### T1. 채널 적합도 지표

채널별로 지금 쌓인 items에서 계산한다. 새 크롤 없이 캐시 데이터만 쓴다.

```
적합도 = (홈템 + 레시피 + 가전) / 전체
```

채널 지표·관리 보드에 **'쇼핑 적합도'** 컬럼과 정렬을 추가한다. 기본 정렬은 적합도 오름차순
(= 버릴 채널이 위로). 영상 수가 적은 채널은 표본이 작아 신뢰도가 낮으므로 건수를 함께 보여준다.

### T2. 정예화 (사장님 1회 작업)

보드에서 적합도 낮은 채널을 지운다. 285개가 이미 100%라 실제 판단은 중간 구간뿐이다.
**일괄 삭제**(체크박스 또는 "적합도 0%인 164개 모두 삭제" 버튼)를 제공해 클릭 수를 줄인다.

### T3. 누락된 좋은 채널 등록

715개 중 시드에 등록된 건 464개뿐이다. **적합도 높은 미등록 채널이 빠지면 정예화가 손해**가 된다.
전환 전에 적합도 100%인 채널 중 미등록분을 시드에 자동 등록한다
(`/api/seeds/from_youtube_videos` 재사용).

⚠️ T3는 T4보다 **반드시 먼저** 수행한다. 순서가 바뀌면 수집량이 급감한다.

### T4. 키워드 경로 차단 (계정 시드만 남긴다)

계정 시드 수집은 **이미 돌고 있다**. 새로 만들 게 없고, 키워드 경로만 건너뛰면 된다.

`service._collect_youtube()`(`service.py:152-158`)에서 `YOUTUBE_SEED_ONLY`가 켜져 있으면
`preset` 검색과 `by_lang` 검색을 **건너뛰고** 계정 시드 루프만 실행한다.

```
YOUTUBE_SEED_ONLY=off (현재): preset 검색 + by_lang 검색 + 계정 시드   ← 잡음 유입
YOUTUBE_SEED_ONLY=on  (목표):                            계정 시드만
```

- 14일 창(`YOUTUBE_WINDOW_HOURS = 336`), 중복제거, 랭킹 계산(`build_youtube_items`)은 그대로 둔다.
- `fetch_channel_shorts`는 `≤60초` 필터가 내장돼 있어(`youtube_client.py:246`)
  키워드 경로를 끄는 순간 **"쇼츠만" 요구가 자동 충족된다.**
- 쿼터는 오히려 **줄어든다**(검색 API 호출이 사라짐). 채널 해석은 `youtube_channel_cache`가 캐시한다.
- **플래그 기본값 off → 검증 후 on.** 라이브가 깨지면 즉시 되돌린다.

### T5. 키워드 검색은 신규 채널 발굴 용도로 남긴다

T4의 플래그는 **자동 수집(매일 08:10 타이머)에만** 적용한다. 화면의 `지금 수집` 버튼으로
사장님이 직접 돌릴 때는 키워드 경로를 그대로 쓴다 — 새 채널을 찾는 수단이 필요하기 때문이다.

발굴한 채널을 시드로 넣는 건 **이미 있는 `/api/seeds/from_youtube_videos`** 를 그대로 쓴다.
"발굴 결과를 후보로 쌓아두는 저장소"는 만들지 않는다(YAGNI).

구현상 이는 `_collect_youtube()`에 `seed_only` 인자를 두고, 타이머 진입점
(`scripts/daily_youtube_collect.py`)만 `seed_only=True`로 부르는 것으로 끝난다.

## 4. 데이터 흐름

```
[화면 '지금 수집' 버튼 (수동, seed_only=False)]
      preset 키워드 검색 → 새 채널 발견 → /api/seeds/from_youtube_videos → platform_seeds
                                                                                │
[매일 08:10 타이머 (자동, seed_only=True)] ─────────────────────────────────────┘
      fetch_channel_shorts(시드마다, ≤60초 필터 내장) → video_id 중복제거 → 14일 창 →
      build_youtube_items(delta/speed/accel/density) → apply_grades →
      settings.last_run::youtube (캐시) → /api/reference → 화면
```

## 5. 검증 (완료 기준)

정적 통과가 아니라 **실제 결과로** 판정한다.

1. T1: 보드에 적합도 컬럼이 뜨고, 적합도 0% 채널이 위로 정렬된다 (실브라우저 확인)
2. T3: 시드 수가 464 → 적합도 100% 미등록분만큼 늘어난다 (DB 카운트 전후 비교)
3. T4: 플래그 on으로 1회 수집 후 **카테고리 '기타' 비율이 절반(49.6%)에서 유의미하게 떨어진다.**
   목표: 기타 비율 20% 미만. 이 수치가 이 작업의 성공 판정선이다.
4. T4: 수집 건수가 0이 되지 않는다(경로 전환 실패 감지). 최소 1,000건 이상.
5. 랭킹 화면 상위 12개에 연예·아이돌 클립이 없다 (육안, 현재는 10/12)

## 6. 위험

| 위험 | 완화 |
|---|---|
| 전환 후 수집량 급감 | T3를 먼저 수행 + 검증 4번(최소 건수)으로 감지 + 플래그 즉시 롤백 |
| API 쿼터 초과 | `youtube_channel_cache` 활용, 첫 실행만 비쌈. 실패 시 키 로테이션 기존 로직 사용 |
| 카테고리 자동분류(`ai_categorize`) 오분류로 좋은 채널이 버려짐 | 삭제는 사람이 최종 확인. 적합도는 정렬 힌트일 뿐 자동 삭제하지 않는다 |
| 얼굴 실촬영이 여전히 남음 | 비목표로 명시. T4 결과를 보고 다음 단계에서 판단 |
