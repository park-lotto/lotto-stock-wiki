# L6 — 수급

섹터·종목 분석의 최종 실행 레이어.
"좋은 섹터 안에서 수급이 빈 종목 = 탑픽"

## 수집 대상

| 소스 | 내용 | 수집 주기 |
|------|------|---------|
| 수급 오실레이터 | 외인·기관 수급 오실레이터 xlsm | 매일 (장 마감 후) |
| 외국인 순매수 | 코스피·코스닥 외국인 상위 | 매일 |
| 기관 순매수 | 기관 매수 상위 종목 | 매일 |
| 종목 리포트 | TP·투자의견·컨센서스 변화 | 발행 시 |
| 컨센서스 변화 | 추정치 상향·하향 종목 | 주 1~2회 |
| 공매도 | 공매도 상위 종목·증감 | 주 1회 |

## 하위 폴더
- `oscillator/` — 수급 오실레이터 xlsm 파일 (기존 raw/supply/ 연동)
- `foreign/` — 외국인 순매수 상위 일별
- `institution/` — 기관 순매수 상위 일별
- `report/` — 종목별 리포트·컨센서스 (기존 raw/report/ 연동)

## 파일 네이밍
`{날짜}_{소스}_{내용}.md`
예) `20260523_foreign_외국인순매수상위10.md`
예) `20260523_report_덕산하이메탈_삼성증권.md`
예) `20260523_oscillator_수급오실레이터.xlsm`

## 기존 폴더 연동
- `raw/supply/` → oscillator/ 와 동일 데이터 (크롤러 전환 시 통합)
- `raw/report/` → report/ 와 동일 데이터 (크롤러 전환 시 통합)
- `raw/consensus/` → report/ 와 동일 데이터

## 크롤링 연결 (예정)
- KRX 매매동향
- 수급 오실레이터 자동 다운로드
- 증권사 리포트 자동 수집
