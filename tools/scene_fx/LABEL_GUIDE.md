# 장면 효과 눈 분류 기준 (관제 124)

레퍼런스 쇼츠에서 **편집으로 넣은** 장면 효과를 그대로 옮기기 위한 분류다. 창조하지 않는다 — 보이는 것만 적는다.

## 시트

- `<id>_<n>.jpg` : 장면이 바뀌는 후보 지점 10줄씩. 줄 맨 앞 숫자 = 후보 번호. 같은 이름 `.json` 에 번호별 시각(t)·후보 종류(cand).
  - 전환 후보(cut/soft/zoom_cut): 그 시각 -0.32~+0.32초, 0.08초 간격 8칸.
  - 장면 안 후보(push): 0~0.84초, 0.12초 간격 / (punch·shake·whip): 0~0.42초, 0.06초 간격.
- `<id>_hook.jpg` : 첫 3.2초, 0.1초 간격 16칸 × 2줄(윗줄 0~1.5초, 아랫줄 1.6~3.1초).

## 라벨 (후보 줄마다 하나)

| 라벨 | 보이는 모습 |
|---|---|
| hard_cut | 한 칸 사이에 다른 장면으로 뚝 바뀜 |
| jump_zoom_cut | 같은 장면이 한 칸 사이에 더 크게/작게 잘려 이어짐 |
| jump_cut | 같은 구도·같은 크기에서 시간만 건너뜀(물건 위치·손만 바뀜) |
| dissolve | 두 장면이 반투명하게 겹친 칸이 있음 (겹친 칸 수를 frames 에) |
| zoom_blur | 바뀌면서 방사형으로 흐려지며 확대 |
| whip_pan | 한쪽으로 쓸리며 흐려지고 다음 장면 |
| slide_push | 다음 장면이 경계선을 보이며 밀고 들어옴 |
| spin / flash_white / glitch / fade_black | 이름 그대로 |
| edit_punch_zoom | 같은 장면이 1~2칸 만에 기계적으로 확 커짐(화면 전체가 똑같이) |
| edit_slow_zoom | 같은 장면이 칸마다 매끈하게 조금씩 커짐/작아짐 |
| edit_shake | 화면 전체가 기계적으로 떨림 |
| camera_motion | 손으로 찍은 흔들림·카메라 이동·물건 움직임 — **편집 효과 아님** |
| no_change | 별 변화 없음(후보 오탐) |
| unclear | 판단 못 함 — 지어내지 말고 이걸 쓴다 |

편집 효과 vs 촬영 움직임: 편집 확대는 화면 **전체**가 중심 기준으로 기계적으로 커지고 원근이 안 바뀐다.
손으로 다가가면 원근(가까운 물체가 더 빨리 커짐)·흔들림·회전이 섞인다.

같은 컷이 이웃 후보 두 줄에 함께 보이면(후보 시각 0.3초 안), 그 컷이 5번째 칸 경계에 있는 줄만 컷으로 적고 다른 줄은 no_change.

## 훅 시트 (영상마다 하나)

- hook_style: 첫 3초에 무엇을 하나 — 예: "맨 컷 3개", "같은 제품 jump_zoom_cut 2번(멀리→가까이)", "edit_punch_zoom 1번 약 1.15배", "효과 없음 한 장면".
- hook_cuts: 첫 3초 장면 전환 수(칸으로 센다)
- hook_zoom: 보이면 대략 배율(시작 크기 대비, 예 1.2)과 걸린 칸 수. 없으면 null.

## 출력 (영상마다)

```json
{"id": "...", "items": [{"n": 0, "label": "dissolve", "frames": 3}, ...],
 "hook": {"hook_style": "...", "hook_cuts": 3, "hook_zoom": null}}
```
