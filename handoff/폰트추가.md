### ★함정 (다음에 폰트 넣을 때 그대로 밟는다)

1. **아네모네의 영문명은 `Ohsquare`다.** 이름으로 URL을 못 만든다.
   카페24 다운로드 URL 패턴(실측 200 OK):
   `https://img.cafe24.com/csdstatic/freefonts/download/kr/Cafe24{영문명}-v2.0.zip`
   확인된 것: Ohsquare / Danjunghae / Simplehae / Dangdanghae / Ssurround /
   Syongsyong / Shiningstar / Oneprettynight. (Ssukssuk·Meongi·Decobox는 404)

2. **★간판체·분필은 배포본이 woff2뿐이다 → 그대로 넣으면 조용히 죽는다.**
   `video_assemble._font_ref`가 폰트 파일을 그대로 ffmpeg에 넘기는데
   **ffmpeg·PIL은 woff2를 못 읽는다**. 오류가 안 나고 기본폰트로 나온다.
   → `fontTools`로 변환해야 한다(이 프로젝트 .venv에 이미 있다):
   ```python
   from fontTools.ttLib import TTFont
   f = TTFont('X.woff2'); f.flavor = None; f.save('X.ttf')   # CFF면 .otf
   ```

3. **noonnu CDN 경로는 추측하지 마라.** jsdelivr 경로를 손으로 지으면 전부 404.
   noonnu 페이지를 받아서 실제 @font-face URL을 뽑아라:
   `curl -sL -A "Mozilla/5.0" https://noonnu.cc/font_page/{번호} | grep -oE "https://[^\"')]*\.(woff2|woff|ttf|otf)"`

4. **콘솔이 cp949라 한글 결과가 깨져 읽힌다.** 검증 스크립트는 `PYTHONIOENCODING=utf-8`.
   (깨진 출력을 "실패"로 오독하기 쉽다 — 실제론 통과였다)
