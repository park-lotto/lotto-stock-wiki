## 한 것
- `merge_gate.snapshot`: pytest 인자에 `tools/test_*.py`·`tools/*/test_*.py`(`_tools_test_paths`) + `--continue-on-collection-errors`(tools 파일 하나 수집 실패로 전체가 안 도는 것 방지) + `-rfE`(수집 오류도 실패 목록에).
- **교착 방지**: tools 시험 중 finish 시험이 게이트가 쥔 전역 락을 다시 기다리면 영원히 멈춘다(10-02 실제로 내 시험이 멈춤).
  - `track._lock_path`: 환경변수 `TRACK_FINISH_LOCK`/`TRACK_VIDEO_LOCK` 가 있으면 그것, pytest 안이면(`PYTEST_CURRENT_TEST`) 프로세스별 개별 락.
  - `merge_gate._run` 이 띄우는 자식 pytest 에 개별 락 경로를 넣는다.
- **영상 관문 락 분리**: `track._FileLock`(놓고 다시 잡기) · `_run_video_gate_unlocked`: 관문이 **실제로 돌 때만**(`video_gate.gate_decision` — 판정 한 곳) 전역 finish 락을 놓고 영상 락(`stockbrain_video_gate.lock`)으로만 줄 선다. 끝나면 finish 락을 다시 잡고 커밋·push.
  건너뛰는 병합은 락을 안 놓는다(놓았다 다시 잡는 사이 남의 pytest 를 통째로 기다리는 손해 방지).
- **살아 있는 stage 보호**: 락을 놓은 사이 다른 finish 가 `_clean_dead_stages` 로 내 `_merge-*` 를 지우지 않게 `.tracks/_merge-<이름>.owner`(pid) — 살아 있는 프로세스 것이면 건너뛴다(윈도는 ctypes OpenProcess, os.kill(pid,0) 금지 — 윈도에서 0 은 CTRL_C_EVENT).
- `video_gate.gate_decision`: run_video_gate 와 track 이 같이 쓰는 '관문이 도나' 판정(0순위-B).
- 테스트 `test_gate_holes.py` 5건(tools 경로·개별 락·자식 환경·락 놓는 동안 다른 finish 진행·살아 있는 stage 보존). 고치기 전 코드에서 실패/멈춤 확인.
