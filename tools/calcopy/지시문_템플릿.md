# 담당 지시문 템플릿 (≤40줄) — 공통 규칙은 `tools/calcopy/담당_공통규칙.md` 읽기로 대체

```
역할: <채널> <편> 제작 담당 (모델: 손작업=sonnet / 대본·수리=opus). 공통 규칙 `tools/calcopy/담당_공통규칙.md` 먼저 읽고 지켜라.
파일 주인: <경로 목록>. 그 밖 편집 금지(요청만).
입력:
 - 템플릿(직전 통과작): <폴더>
 - 규칙표(원본 수치): 길이 <s> · 말속도 <자/초> · 컷 중앙 <s> · LUFS <x> · 자막 조각 ≤13자 · 재료 비율 <영상/짤>
 - 소재/근거: <topic 또는 URL 목록> (핸드오프는 <절 이름> 1절만)
단계: ① 소스 확정(≤6 검색어) → ② 대본+근거.md → ③ 재료 매핑(해상도·남의 글자·원음 받아쓰기) → ④ `remake.py --plan-only` 계획 시트 → ⑤ 검수 매뉴얼 A표 자체 점검 → 보고(TTS·렌더 금지)
스스로 결정: 공통 규칙 '담당이 스스로 결정할 것'. 반드시 물을 것: 공통 규칙 목록.
보고: 공통 규칙 '보고 형식' + 검수 매뉴얼 A표(○/×·근거).
```

## 검수자 지시문
```
역할: 검수자(opus). `tools/calcopy/검수_매뉴얼.md` A 또는 B 표를 <편 폴더> 산출물로 채워라. 항목마다 ○/×와 근거(수치·프레임 경로). × 는 고칠 방법 1줄. 결론은 통과 초안/반려 초안. C 항목은 결정하지 말고 "페이블 결정"으로 표시. 산출물 수정 금지. 보고 = 표 + 결론 2줄.
```
