# 자막제거잔액바로가기 트랙 핸드오프

_최종 갱신: 2026-09-04_

## ✅ 2026-09-04 — 내 키 잔액을 제작소에서 (사장님 "v메이크 포인트 연동" → "바로가기탭" / "tts에도 api연동")

**조사 결과가 먼저다**
| 업체 | 잔액 API | 그래서 |
|---|---|---|
| 자막제거(VMake) | **없음** — 번들 SDK 경로는 `/skill/config.json`·`/skill/consume.json` 둘뿐, 공개 문서에도 없음. 잔액은 로그인한 개발자 대시보드(우상단 Credit·Usage Details)에만 | 새 탭 바로가기만 |
| 일레븐랩스 | `GET /v1/user/subscription` (xi-api-key) → character_count/limit/next reset/tier | 숫자 표시 |
| 타입캐스트 | `GET /v1/users/me/subscription` (X-API-KEY) → credits.plan_credits/used_credits/plan (리셋시각 없음) | 숫자 표시 |

**바뀐 것**
| 자리 | 내용 |
|---|---|
| `app.py` `/go/subclean-credits` | 302 → 업체 대시보드. 주소는 `_SUBCLEAN_CREDITS_URL` 한 곳(produce.html은 업체명 금지 — test_subclean_ui) |
| `produce.html` 4단계 자막제거 패널 | 시작 버튼 아래 "💳 내 자막제거 키 잔액·사용내역 확인 ↗"(새 탭) |
| `produce.html` `cleanFailHtml` no_credit | "💳 잔액 확인·충전하러 가기 ↗" 추가(실패한 자리에서 바로) |
| `app.py` `/api/produce/tts/credits` | 내가 등록한 키만(`_own_keys_plain`) 업체에 물어 used/limit/remaining/reset/plan. 고객당 60초 캐시(`?refresh=1`로 강제). 평문 키는 안 내보냄(끝 4자) |
| `produce.html` 5단계 `#ttsCredits` | `loadTtsCredits()`가 `loadTtsBeats` 진입 때 채움. ★일레븐랩스 제한키는 user_read 없어 401 → `no_permission`으로 갈라 "키가 틀린 게 아님" 안내 |

테스트: `test_subclean_credits_link.py` 4건 · `test_tts_credits.py` 5건.
실측: 잘못된 키로 두 업체 실호출 → 둘 다 `bad_key`(네트워크·상태코드 경로 확인). 로컬엔 실키가 0개라 **200 응답 파싱은 문서 기준** — 아래 ⏭.


## ✅ 2026-09-04 (2차) — 아이콘 버튼·노출 판정 (사장님 "토글 위 아이폰 아이콘형 / 관리자는 운영자 키 / 빌려 쓰는 고객은 비노출")

| 자리 | 내용 |
|---|---|
| `produce.html` 4단계 카드 우상단 | `.hbar-row` = `label.hbar[for=subToggle]` + `.hright`(💳 아이콘 `#cleanCreditBtn` 위 / 토글 아래). 버튼은 label **밖**(안에 두면 클릭 시 토글이 뒤집힘). `.sw-input`(absolute)은 `.sw-wrap`(relative) 안. CTA 아래 옛 링크 삭제 |
| `app.py _credit_mode()` | own(내 키) / owner(**관리자만** 운영자 키: env·전역 vmake 설정) / none(면제 고객 — 남의 잔액 비노출). 판정 한 곳 |
| `/api/produce/tts/credits` | `services[].mode`, `subclean.show`(아이콘 노출), `need_own_key`(면제면 "키 등록하세요"도 안 띄움). 페이지 로드 때 1회 + 5단계 진입 때 |

⚠️ 로컬 `http.server`로 렌더 확인하려 했더니 **크롬만 404**(curl 200) — 원인 미상, 접었다. 렌더 확인은 라이브에서.

## ⏭ 남은 것
- **라이브에서 실키 200 응답 확인**: 키 등록한 회원(예: cid 134 일레븐랩스·타입캐스트 둘 다 있음)이 5단계 열면 숫자가 뜨는지. 안 뜨면 `/api/produce/tts/credits?refresh=1` 응답의 error_kind부터.
- 사장님 계정(cid 0)은 등록 키가 없어 "등록한 내 음성 키가 없어요"가 정상.
- 자막제거 쪽 호출 자체는 여전히 api_events에 안 남는다(누가 몇 번 썼나는 작업별 clean_status뿐). 별건.
