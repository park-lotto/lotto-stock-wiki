카드 인사이트는 **판단 + 수치 + 조건부 전략**이어야 한다. 양면론(좋은 것도 있고 나쁜 것도 있다)은 인사이트가 아니다.

**Why:** v1(뉴스 요약형)과 v2(판단배지+SIGNAL BAR 구조형) 모두 "와닿지 않는다" 피드백. 구조가 아무리 좋아도 내용이 뻔하면 무의미하다.

**How to apply:**

인사이트 작성 전 체크:
- ❌ "좋은 것도 있고 나쁜 것도 있다" → 양면론. 쓰지 마라.
- ❌ "지켜봐야 한다" → 판단 없음. 쓰지 마라.
- ❌ "펀더멘탈은 나쁘지 않다" → 두루뭉술. 구체적으로.
- ✅ 수치 포함: "고점 대비 -43%, PBR 1.1배 역사적 저점"
- ✅ 명확한 방향: "지금은 관망 / 36만 지지 확인 시 진입"
- ✅ 조건부 전략: "X 되면 Y 한다"
- ✅ 주가 실제 반응: "이 뉴스 나왔을 때 +X% 움직였다"

**핵심 차이:**
- 뉴스 보고 쓴 글 → 텔레그램 채널 요약 수준
- 뉴스 너머를 보는 글 → 유저 본인의 수급데이터+경험이 들어간 글

유저가 갖고 있는 오실레이터 수치, 빈집강도, 20년 매매 경험 — 이게 없으면 차별화 안 된다.
