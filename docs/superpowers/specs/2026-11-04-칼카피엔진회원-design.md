## 5. 소재마다 바뀌는 값 가르기

집 PC 7단계의 '컨셉 프리셋'은 사람이 판 칸을 고른다. 회원 PC에는 사람이 없으므로 `bm_split`이 이 일을 한다.
- **판에 고정**: 3편 이상 모두 같은 값(틀 자리·글꼴·색·자막 꼴·목소리 결·속도·채도처럼 편 사이 차이가 측정 오차 안).
- **소재마다**: 편마다 다른 값(확대 배율·영상 놓을 자리·밝기). 판에는 범위만 적고 `bm_make`가 소재마다 정한다.
- 판에 없는 규칙은 지어내지 않는다. 모르는 칸은 벤치를 다시 잰다.
- 가르기 기준(측정 오차 폭)은 `kal_analyze.MATCH_RULES`의 칸별 허용폭을 쓴다(새 문턱 금지).

## 6. 제미니 (agy)

| **소넷** | 받기·360p 줄이기·시트 뽑기·도구 실행·결과 모으기·`프리셋.md` 그리기 호출·zip 묶기·정리 | **결과물 판단 금지.** 자리마다 `model_ab.py`로 소넷 답 = 오푸스 답 실측 뒤에만 옮김. 기록 `channel/production_guide/model_ab_bench.md` |
| 프로그램 | 숫자 전부 | |
| agy | 영상 통째 판독·좌우 대조 판독 | §6 |

- 회원 구독에서 페이블 사용 가능 여부는 **실측 전**. 못 쓰면 두 자리는 오푸스, 결과 보고에 「페이블 대신 오푸스」.
- 하이쿠는 쓰지 않는다(사장님 10-19).

## 8. Jev

- 서버 `flow.py`에서만: `bm_split`(고정/소재마다), `bm_panbokki`(어느 칸을 어떻게), `bm_confirm`(확정해도 되나). 회원 PC가 올린 판독표·숫자·후보를 `problem/facts/fixes`로.
- 신뢰도 0.5 근처·낮음 → `flow.py`가 「다시 잴 칸」 단계를 내려준다. 확신 없이 넘어가지 않는다(전역 0원칙).
- 그림 속 브랜드·디졸브는 Jev에 묻지 않는다(11-04 실측으로 못 함).
- 키는 서버 환경에만. `benchmark_pack.check` 금지 글자에 Jev 키 이름 추가.

## 9. 됐다의 기준 (관제 319 카드와 같은 문장)

회원 PC 설치본(`shortem_client/test/live_episode.js`, 라이브 서버·진짜 키)으로 **서로 다른 3채널**을 2판으로 끝까지 돌려, 각 채널 첫 편이 넷 다 통과:
1. `quality_gate` 1단
2. `kal_analyze match` 재현일치도 `MATCH_RULES` 합격
3. `bench_compare_script_scene` 대본·장면 칸이 벤치 상위 10편 중앙값 이상
4. 사장님이 벤치와 좌우로 보고 통과

4 전에는 「자동 검사만」이라고 보고한다.

## 10. 그대로 지킬 우리 규칙

- 필재 금지(남 = 박창수·지훈 / 여 = 문정·유라), 회원 PC는 타입캐스트
- 연예인 장면은 찾은 원본에서만 — `rules.source_rule_static`
- 모든 렌더 오른쪽 위 '광고' · 맨 앞 썸네일 2프레임 — 기존 렌더 함수
- 틀·스타일만 배운다. 남의 영상·대본·이름은 옮기지 않는다 — `rules.bench_copy_problems`
- 권한 확인을 끄는 실행 옵션은 쓰지 않는다
- 고객에게 영상 제작 요구 금지 — 엔진이 스스로 해결
- 기본반에는 열지 않는다 — `claude_portal.member_tier`·`benchmark_rent`
