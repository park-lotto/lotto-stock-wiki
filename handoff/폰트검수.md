# 폰트검수 트랙

## 2026-08-26 — "최종렌더하니 네모에 x로 나온다" 해결

### 무엇이 문제였나

사장님 제보: 폰트를 골라 최종렌더했더니 글자가 전부 **네모X(두부)**로 나왔다.

**진짜 원인 — 파일이 깨진 게 아니라, 애초에 한글이 없는 폰트였다.**

`OkMallangW.ttf`(목록 이름 '옥 말랑')는 OKFont가 낸 **영문 전용** 폰트다.
- 글리프 81개 = 영문·숫자·기호뿐, **한글 0자** (실측)
- 파일 크기 25KB (다른 한글 폰트는 1~12MB)
- 출처: <https://noonnu.cc/font_page/1796> — 눈누 표기 "형태: 영문"

파일 자체는 **정상 TTF**라 브라우저도 ffmpeg도 아무 오류 없이 로드한다.
그래서 경고 한 줄 없이 조용히 두부로 나갔다.

> ⚠️ 첫 진단을 "파일이 깨졌다"로 잘못 냈다. 크기가 이상하다고 파일 손상으로 단정했는데,
> 실제로는 **정상 파일 + 잘못된 분류**였다. 조치가 통째로 달라진다(교체 → 표시+폴백).
> 폰트를 만나면 **파일이 아니라 글리프를 봐라.**

### 왜 종전 검사로는 못 잡았나

`tools/sync_fonts.py`와 `test_fonts_manifest.py`는 **"static/fonts에 파일이 있는가"**만 봤다.
파일은 있었다. 렌더(`video_assemble`)도 마찬가지로 존재만 확인하고 그대로 썼다.
→ 세 층 전부 통과하고 고객 영상에서 처음 드러났다.

### 무엇을 고쳤나 (4파일)

| 파일 | 변경 |
|---|---|
| `static/fonts.json` | '옥 말랑' → **'옥 말랑 (영문전용)'**, `group:latin`, `"latin": true` |
| `static/produce.html` | 위 이름이 `sync_fonts.py`로 자동 반영(손으로 안 고침) |
| `video_assemble.py` | `_missing_glyphs()` 신설 + **폰트 해석 단일 출구 `_font_ref()`** |
| `tools/sync_fonts.py` | `_check_hangul()` — 한글 없는 폰트를 목록에 넣으면 **거기서 막는다** |

**두 겹 방어**
1. **넣을 때** — `sync_fonts.py`가 한글 글리프 없는 폰트를 거부한다.
   영문 전용인 걸 알고 넣으려면 `"latin": true`를 명시해야 통과.
2. **렌더 직전** — `_font_ref()`가 그 폰트로 **그 문구를** 못 그리면 기본 자막폰트로
   되돌리고 stderr에 남긴다. 두부 대신 다른 글꼴로 나간다.

**0순위-B 정리**: 폰트 해석 규칙이 `_resolve_seg_font`(자막)와 `_fixed_drawtext`(헤드카피)에
각각 적혀 있었다 → `_font_ref()` 하나로 뽑았다. 한쪽만 고쳐 어긋나는 일이 없다.

### 판정 원리 (이름·크기로 판정하지 마라)

폰트에 없는 글자는 전부 같은 `.notdef` 글리프로 그려진다. 사적사용영역 문자
(`U+F8FF`·`U+E05C`, 어떤 한글 폰트에도 없다) 두 개의 마스크가 서로 같으면 그게 이 폰트의
`.notdef`이고, 어떤 글자의 마스크가 그것과 같으면 그 글자는 **없는 것**이다.

- **Pillow만 쓴다.** fontTools는 `requirements.txt`에 없다 — 서버 의존성을 늘리지 않으려고
  일부러 PIL 방식을 골랐다(실측으로 정확도 확인).
- 공백(U+0020)은 검사에서 **제외**한다. 빙그레·리디바탕은 공백 글리프가 없지만
  `_lacks_space_glyph` 우회가 이미 처리하므로, 여기서 폴백시키면 사장님이 고른 글꼴이
  통째로 바뀌는 회귀가 난다.

### 검증한 것 (실측)

```
_missing_glyphs   옥말랑+'한글 자막입니다' → '한글자막입니다' (전부 없음)
                  옥말랑+'SALE 2026'      → ''  (영문은 정상)
                  주아+'한글 자막입니다'   → ''
                  빙그레+'공백 있는 문장'  → ''  (공백은 안 센다)
_font_ref         옥말랑+한글 → font.ttf(폴백) / 옥말랑+영문 → font_k.ttf(그대로)
                  주아+한글 → font_k.ttf / 없는파일·None → font.ttf
_resolve_seg_font (자막)     옥말랑+한글 → font.ttf
_fixed_drawtext   (헤드카피) 옥말랑+한글 → fontfile=font.ttf
sync_fonts 가드   latin 떼고 넣으면 SystemExit로 막힘 / latin:true는 통과
pytest            신규 6건 포함 폰트·자막 23건 통과
                  -k "caption or font or drawtext or assemble or headcopy or thumb or deco"
                  → 606 passed, 2 failed
```

**남은 실패 2건은 기준선이다** — `test_assembled_drafts.py`의 대본 조립 어미 문제
(`'쓴다' vs '쓴다는'`, `'제품이었어' vs '제품이었어요'`). `app._assembled_drafts`만 쓰는
테스트고 이번 변경 4파일에 `app.py`는 없다. 폰트와 무관.

### 새 폰트를 넣을 때 (사장님·다음 세션)

```
1) shopping_shorts/static/fonts/ 에 파일을 넣는다
2) shopping_shorts/static/fonts.json 에 한 줄 추가
      영문 전용이면 반드시  "latin": true  + 이름에 '영문' 표기
3) py tools/sync_fonts.py        ← 화면 3벌에 반영. 한글 없으면 여기서 막힌다
4) py -m pytest shopping_shorts/tests/test_font_glyph_fallback.py -q
```
