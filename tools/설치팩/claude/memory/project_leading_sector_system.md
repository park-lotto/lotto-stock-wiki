# 태린이아빠 주도업종 판단 시스템

**Why:** 어떤 섹터가 지금 가장 강한지 판단 → 탑픽 선정의 1단계

## 3개 데이터 조합 → 주도업종 결론

```
① 유동성 컨셉 시트        → 기관(사모/투신/연금) 시총·금액 대비 매수 순위
    파일: 유동성체크...xlsm   시트: '유동성 컨셉 YYYYMMDD'

② Normalized RS ≥ 70     → RS 강한 ETF/종목 필터
    파일: 한국상대강도.xlsx    기준: Norm_RS_avg ≥ 70
    ETF 소르티노 → 별도 파일 (소라티노 파일, 아직 미입수)

③ 소라티노 파일           → ETF 소르티노 비율 (하방리스크 대비 수익률)
    현재 raw 폴더에 없음 → 태린이아빠에게 별도 요청 필요
```

## 소르티노 원리 (핵심)

> "수익은 얼마나 냈는데, 하락할 때만 얼마나 흔들렸냐"

```
소르티노 = 연환산 수익률 / 하방 표준편차
         (하락한 날만의 편차 — 상승은 페널티 없음)
```

**일반 모멘텀 vs 소르티노 차이:**
- 일반 모멘텀: 전체 변동성(상승+하락) 페널티
- 소르티노: 하락 변동만 페널티 → 우상향 ETF가 높은 점수

**계산 방식:**
1. 일별 수익률 계산
2. 하락한 날만 골라 표준편차 (하방편차)
3. 3M(63일)/6M(126일)/12M(252일) 각각 계산 → 평균
4. 50일선(10주선) 이상 필터 (하락추세 제외)
5. 점수 높은 순 Top 20 랭킹

**결론:** 소르티노 높음 = 수익 대비 하락 적음 = 꾸준히 우상향 = 주도업종 후보
