종목을 영상에서 언급할 때 반드시 2단계로 나눠서 제시한다.

**1군 (안전주) — 먼저 제시**
- 조건 1: 여론에서 가장 많이 언급되는 종목
- 조건 2: 재료 발표 후 실제로 주가가 반응한 종목
- 역할: 시청자 신뢰 확보. 이미 증명된 연결고리.

**2군 (기대주) — 나중에 제시**
- 조건: 아직 크게 반응 안 했지만 기대 가능한 종목
- 반드시 "아직 반응 전", "기대 가능" 표현으로 조건부 제시
- 역할: 빠져나갈 구멍. 틀려도 "기대했던 것"으로 방어 가능.

**Why:** 모험적 추천은 신뢰를 깎는다. 안전주로 신뢰 쌓고 → 기대주로 차별화.
실제 주가 반응이 있어야 영상 언급이 의미 있음. 움직이지 않은 종목을 확신으로 말하면 채널 신뢰도 손상.

**How to apply:** 종목 선정 시 항상 1군/2군 분류 먼저. 1군 없으면 영상에 종목 언급 자체를 보류.
