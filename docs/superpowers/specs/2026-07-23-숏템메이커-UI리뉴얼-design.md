# 숏템메이커 UI 전면 리뉴얼 — 설계 (진행 중)

날짜: 2026-07-23 · 상태: **브레인스토밍 진행 중 (회사 PC에서 이어서)** · 트랙: 부품은행(임시)
목업: `assets-숏템메이커목업/` (브라우저로 바로 열면 대략 보임 — 원래는 visual companion 프레임용)

## 모토

**원클릭.** "이거 하세요 → 다음은 이거"가 화면에 순서대로 내려온다. 텍스트·설명 최소.
사용자는 썸네일만 보고 영상을 가져온다(랭킹·렌즈) — **안의 대본을 읽어본 적이 없다.**
그러므로 선택을 떠넘기지 말고 **AI가 근거를 들고 미리 골라놓는다.** 사용자는 확인하고 딸깍만.
+ 시각적으로 "우와, 이 시스템 이렇게 하고 있구나"를 계속 보여주는 전시 연출(사용자가 결정할 건 없음).

## 확정된 결정

1. **이름**: 영상 제작소 → **🛠 숏템메이커** (탭·헤더·로고 전부).
2. **스타일**: 네온 글로우 — 딥다크(#070b14) + 민트(#3ee0bf)·퍼플 오로라 배경 애니메이션,
   **폰트 두껍고 크게**(가독 우선). 목업 `visual-style.html` A안.
3. **적용 범위**: 색 토큰·오브·카드·CTA·애니메이션을 **공통 디자인 시스템**(공통 CSS/JS)으로 빼고
   숏템메이커에 먼저 적용 → 이후 회원가입 등 다른 페이지가 같은 부품 재사용.
4. **페이지 뼈대**: **B 작업대형** (목업 `layout.html`)
   - 상단: **원형 오브 단계바 7개** — 현재 단계 파동(펄스 링) 애니메이션, 완료 단계 금색 ✓,
     호버 시 통통. 단계: 1 영상/대본 · 2 매칭 · 3 음성 · 4 꾸미기 · 5 썸네일 · 6 SEO · 7 완성.
   - 좌측: **재료 레일 고정**(접기 가능) + 미리보기 자리(결과물이 자라는 자리).
   - 우측: **스테이지** — 단계 전환 시 슬라이드 애니메이션. 현 produce.html의
     `.panel{display:none}` 위저드 골격 유지하고 연출만 얹는 게 아니라 1단계 내부 구조를 갈아엎음(아래).
5. **1단계 "영상/대본" 단순화** (목업 `final-mock-v6.html` 위쪽):
   - **"우리 시스템으로 믹스" 탭 통째 제거** (담긴 대본 목록·위키 전체 영상대본·선택 1개/2개+ 조합 생성).
     대본 조합·강점 섞기는 매칭 단계의 ✨스마트 믹스가 전담 — 역할 중복 해소.
   - **넘어온 영상은 전부 자동 담김.** 뺄 것만 좌측 카드 클릭으로 끔(✓ 뱃지 토글).
     카드마다 붙던 버튼 5개(뽑기·담기·메인·정보채우기·✕) 제거.
   - **대본 = 🤖 AI PICK 자동**: "선택 영상 중 완성도 1위 대본"을 미리 골라놓음.
     근거를 **수치 타일**로 크게: 조회수(팔로워의 N배 🔥)·댓글(평균의 N배)·참여밀도(담긴 것 중 1위)·길이.
     + 구조 배지(훅 유형·설득 장치). 대안은 "🔁 다른 대본 보기(후보마다 같은 분석)·✍️ 직접 쓰기"로 접힘.
   - 강조줄: **"✨ 이 뼈대로 완전 새로운 대본을 만듭니다"** ("복사가 아니에요"·"100%" 문구 쓰지 말 것).
   - 고급 ▾ (접힘): ⭐메인 바꾸기 · 스마트믹스 끄기 · 위키에 원본 담기 · URL 직접 추가.
   - CTA: **⚡ 이대로 만들기 시작** (반짝 shine 애니메이션).
   - 좌우 균형: 레일 25% · 카드 컴팩트(v6에서 조정 완료).
6. **2단계 "매칭" — 위→아래 한 방향 고정** (목업 `final-mock-v6.html` 아래쪽):
   - ① **새 대본 고르기** — 후보 3개 가로 카드(A안 👍추천 미리 선택, 훅 첫 줄만).
   - ② **장면 확인** — 고른 안 기준 문장↔화면 짝이 세로로. "장면 바꾸기·전체 보기 ▾" 접힘.
   - ③ **미리보기** — 좌측 레일 자리에서 재생(재료 목록은 접힘) → "다음 (3 · 음성)".
   - 매칭 완료 시 스피너는 done 처리(2026-07-22 커밋 7d156f09c 반영됨).
7. **원본 대본+분석 전시 연출** (목업 `analysis-show.html`) — ⚠️ **사용자 선택 대기**:
   - A안 구조 스트립: AI PICK 카드에 훅/문제제기/주변인물/결과/CTA 구간 색 바 한 줄(항상 보임).
   - B안 분석 극장: ⚡시작 후 대기시간에 원본 대본이 실시간 해부되는 연출(스캔라인·문장별 태그 팝).
   - 추천: **둘 다.** 클릭·결정 요소 없음 — 순수 전시.
8. **자막제거(현 2단계)**: 다른 세션에서 작업 중 — **이번 설계에서 건드리지 않고**, 완료되면 보완해서 새 구조에 끼움.

## 기술 메모 (구현 시)

- 백엔드 API는 그대로(`/api/produce/*`) — 프론트 produce.html 재구성이 본체.
- AI PICK 채점: 기존 `backbone.score_backbones`(참여도 배선됨) + 구조분석 재사용. 새 모델 호출 설계 전에 기존 것 먼저.
- 도착 시 백그라운드 사전 분석(추출 캐시는 기존 뽑기 경로와 동일) — 영상당 추출 1회 비용, 상한 고려.
- 수치 타일·차트 구현 전 `dataviz` 스킬 참조.
- 믹스 탭 제거 시 관련 테스트(test_produce_*) 마커 문자열 주의 — 주석 마커는 유지돼야 함.
