## ⚛️ HD현대 원전 파운드리 이슈 심층 분석 (2026-05-28)

> **조선소가 원전 공장이 된다. HD현대중공업이 테라파워(빌 게이츠) SMR의 핵심 기자재 독점 공급자로 선정 — 조선 제조 역량의 원전 전환점.**

### 왜 "원전 파운드리"인가?

반도체 팹리스-파운드리 구조처럼, SMR 설계는 테라파워가 하고 **핵심 부품 대량 생산은 HD현대**가 맡는 구조. 조선소의 중후장대 제조 역량 (대형 금속 구조물 정밀 가공·용접) = SMR 원자로 기자재 제작과 100% 겹친다.

| 조선 제조 역량 | SMR 파운드리 적용 |
|-------------|---------------|
| 대형 원통형 구조물 정밀 용접 | 원자로 용기(원통형) 제작 |
| 극한 내압 설계 (선박 수압 수천m) | 고압 원자로 격납 설계 |
| 대규모 부품 공급망 관리 | SMR 모듈 대량 생산 |
| 선박 1척당 수만 부품 통합 | 원전 기자재 계통 통합 |

### 테라파워 나트륨 원자로 — 왜 게임체인저인가?

| 항목 | 기존 원전(PWR) | 나트륨 원자로(4세대 SFR) |
|------|-------------|---------------------|
| 냉각재 | 물(고압) | **액체 나트륨** (저압) |
| 연료 | 우라늄 | 우라늄 + **사용후 핵연료 재활용** 가능 |
| 출력 | 1,000MW↑ | **345MW** (소형·모듈화) |

| 에너지저장 | 없음 | **나트륨 열저장 — 출력 조절 가능** |
| 안전 | 냉각재 손실 시 위험 | 수동 안전계통 (사고 시 자동 정지) |
| 데이터센터 적합성 | ❌ 과대 규모 | ✅ DC 전용 소규모 발전 최적 |

> **핵심**: 나트륨 원자로 = 데이터센터 전력 + 수소 생산 + 열 공급까지 동시 가능. 빅테크들이 주목하는 이유.
