수출데이터는 보조 지표다. RS + 변동성모멘텀 + 기관유동성 + 거래대금이 주력.

**Why:** 태린이아빠 직접 언급 (2026-06-02) — "수출데이터를 주력 지표로 보고 있진 않습니다"

**How to apply:**
- 수출데이터만 보고 탑픽 판단하지 말 것
- 이미 RS↑ + 변동성모멘텀↑인 강한 섹터에서 수출데이터가 좋으면 확률 보완재로 활용
- 약한 섹터(RS↓)에서는 수출데이터 급변 아닌 이상 무시

## 수출데이터 발표 일정

| 발표일 | 내용 |
|--------|------|
| 매월 1일 | 전월 잠정 수출 (1차) |
| 매월 11일 | 수출 중간 집계 |
| 매월 21일 | 수출 중간 집계 |
| 매월 15일 | **확정 수출데이터** (전전월 확정치) |

## 태린이아빠 분석 우선순위

```
1순위 (주력): RS + 변동성모멘텀 + 기관유동성 + 주요거래대금
2순위 (보조): 수출데이터 (강한 섹터에서만 확률 높이는 용도)
```

## 수출데이터 활용 기준
- ✅ 의미있는 경우: RS↑ + 모멘텀↑ 섹터에서 수출도 좋을 때 → 확신 강화
- ❌ 무시하는 경우: 약한 섹터, RS↓ → 수출이 좋아도 시장 관심 없음
- ⚠️ 예외: 약한 섹터에서 수출이 크게 급변하면 체크 필요
