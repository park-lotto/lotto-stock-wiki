**70% 구간에서 해야 할 것:**
- 오늘 이슈에 대한 명확한 분석과 데이터

- 숫자, 근거, 사례로 신뢰 구축
- "이 사람 진짜 알고 있다"는 확신을 주는 것

**20% 구간에서 해야 할 것:**
- "저는 이런 흐름을 보고 있습니다" 방식
- 내 분석 과정의 일부만 보여주기 (전부 X)

**10% 구간에서 해야 할 것:**
- S8 CTA에만 집중
- "이게 궁금하신 분들은" 방식으로 자연스럽게
- 구독·알림·프로그램 안내 한 번만

## 타겟별 문제와 해결

**주식을 하는 모든 사람 — 단계별로 막히는 지점이 다르다**

| 단계 | 막히는 지점 | 속마음 | STOCK BRAIN 해결 |
|------|-----------|--------|----------------|
| **1단계** | 정보를 어디서 봐야 하는지조차 모른다 | "텔레방이 맞나? 유튜브? 증권사 앱?" | 크롤링된 정보 한 곳에서 |
| **2단계** | 정보는 찾았는데 뭐가 중요한지 모른다 | "다 중요해 보이는데 어디를 봐야 하지?" | 신호 등급 자동 분류 |
| **3단계** | 중요한 건 골랐는데 정리가 안 된다 | "머릿속에 있는데 흩어져 있다" | 위키 자동 누적·교차분석 |
| **4단계** | 정리까지 했는데 인사이트·종목 연결이 안 된다 | "그래서 뭘 사야 하는 거지?" | 탑픽 자동 선정·매매 판단 |

**Stock Brain은 이 4단계를 모두 해결한다**
정보 수집 → 선별 → 정리 → 인사이트 + 종목 매칭, 딸깍 한 번으로.

## 서비스 구조 (데이터 파이프라인)

```
텔레그램 / 뉴스 / 리포트 / 수급 / 유튜버
                ↓ 크롤링
        Obsidian 폴더 (md 파일)
                ↓ 1시간마다 동기화
        Claude Code (파일 읽기·파싱)
                ↓
        Supabase DB (클라우드 저장)
           ↙              ↘
  STOCK BRAIN            구독자 웹앱
  (본인 풀버전)          (단계별 오픈)
```

### 자동 브리핑 — 새벽 4시 cron 1회 실행
```
매일 새벽 4시 Claude 1회 실행 → DB 저장 → 시청자는 꺼내보기만 (토큰 거의 0)
  - 오늘 브리핑 요약
  - 섹터별 핵심 인사이트
  - 종목별 수급 요약
  - 자주 묻는 질문 50개 미리 답변 생성
  - 오늘의 시그널 (BULL/BEAR/WATCH)
```

### 토큰 비용 구조
| 방식 | 시청자 1,000명 기준 | 월 비용 |
|------|---------------------|---------|
| 챗봇 (매번 API) | 하루 10회씩 | 월 30만원+ |
| **미리 생성 방식** | 하루 1회만 | **월 3,000원** |
| 혼합 (무료+유료) | 유료 100명만 API | 월 3만원 |

## 서비스 3티어 (가격 포함)

| 티어 | 대상 | 형태 | 가격 |
|------|------|------|------|
| **1번** | 정보 수집만 필요한 사람 | 크롤러 프로그램 일회성 판매 | 별도 책정 |
| **2번** | 분석까지 받고 싶은 사람 | STOCK BRAIN 대시보드 구독 ← **핵심 수익** | 월 9,900~29,900원 |
| **3번** | 직접 구축하고 싶은 사람 | 영상 강의 + 커뮤니티 | 별도 책정 |

### 구독 가격 티어 (2번 상세)
| 티어 | 가격 | 제공 기능 |
|------|------|-----------|
| 무료 | 0원 | 오늘 브리핑 열람 + 키워드 검색 |
| 베이직 | 월 9,900원 | 전체 DB 열람 + 검색 + Q&A 50개 |
| 프리미엄 | 월 29,900원 | AI 질문 무제한 + 영상 연동 |

### 무료/유료 차등 — 타임랩 방식
- **무료**: 어제 데이터 (결과는 보임, 하루 늦음)
- **유료**: 오늘 실시간

→ 영상에서 "이게 어제 나왔어요, 오늘 이렇게 됐죠" 보여주면
다 공개하면서도 **"어제 알았으면 나도 했겠다" 감정 → 결제**로 이어짐

### 3번 고객 전략 — 다 공개하기로 결정
시스템 만드는 과정 전부 공개. 숨기지 않음.
**단, 혼자 하면 3개월 / 서비스 쓰면 오늘부터.**
다 공개 → 신뢰 축적 → 현실적으로 못 만드는 사람이 2번으로 넘어옴.

## 4단계 서비스 오픈 로드맵

```
1단계: 나만 쓰는 도구 (현재)
  → Obsidian + Claude Code 연동
  → 유튜브 퍼포먼스 콘텐츠 촬영

  → 채널 트래픽 유입
  → 구독자 대상 베타 선공개 ("같이 만들어가는" 초기 충성 구독자 확보)

3단계: Q&A 서비스 (부분 유료)
  → 내 DB 기반으로 시청자 AI 질문
  → 무료 티어 + 월정액

4단계: 각자 쓰는 SaaS
  → 시청자가 자기 정보 연결해서 사용
  → 구독 플랫폼 완성
```

### 주간 운영 계획 (주 2~3회)

```
월·수  →  시황 or 섹터 (데이터 → 오늘의 판단)
금     →  종목선정 or 팩트체크 (탑픽 도출 과정)
수시   →  쇼츠 (탑픽 한 줄 요약, Remotion 자동생성)
```

### 쇼츠 전략
- **자동화**: Remotion 파이프라인 → 리포트 내용 → 쇼츠 자동 생성
- 매일 "오늘 수급 빈집 상위 섹터" 한 줄 요약 형태
- 채널 생존 신호 + 대시보드 유입 동시 해결

### 전환 흐름
```
시황·섹터 (공감·유입) → 종목선정·팩트체크 (데모·신뢰) → 무료 대시보드 → 유료 전환
```
