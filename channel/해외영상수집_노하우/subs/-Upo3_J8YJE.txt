# Google Chrome의 Google 렌즈 기능을 사용하여 검색 이미지를 탐색하는 방법
# OnlineComputerTips · 조회 9589 · 160초 · .ko-orig

안녕하세요. 이번 영상
에서는 최근 구글이 크롬에
도입 한 'Google Lens로 이미지
검색' 기능을 우회 하는 몇
가지 방법을 보여
드리겠습니다. 보통 이미지가
있으면 우클릭을 해서 구글
이미지에서 검색 할 수
있었죠. 그런데 이제 그 기능
이 사라 졌습니다. 이제
우클릭 하면 'Google Lens로
이미지 검색' 옵션만 나타
납니다. 그러면 여기 새로운
인터페이스로 연결 되는데,
여기서 이리저리 움직 이며
특정 기능을 검색 하는 식
이죠. 이 기능이 어떻게 작동
하는지에 관한 영상을 이미
올린 적이 있습니다. 그리고
이 기능을 비활성화 하는
방법, 아니 사실 같은 영상
에서 그 방법도 다뤘 었죠.
하지만 이제는 그 방법이
통하지 않는 것 같습니다.
브라우저 설정의 해당 플래그
를 '사용 안 함' 으로 설정해
도 아무런 변화가 없고,
여전히 이미지를 클릭 하면
구글 렌즈 옵션만 나오
거든요. 그래서 우회 할 수
있는 몇 가지 방법이
있습니다. 첫 번째 방법은,
우선 이걸 닫아 보겠습니다.
같은 방식으로 'Google Lens로
이미지 검색' 을 실행 한 뒤,
맨 아래로 스크롤을 내리면 '
찾으시는 결과가 없나요?
Google 이미지로 다시 검색해
보세요' 라는 문구가
나옵니다. 물론이 기능이
언제까지 유지 될지는
모르겠습니다. 여기서 '시도
하기' 를 클릭 하면, 다시
구글 이미지 검색 화면으로
돌아 오게 됩니다. 이게 한
가지 방법 입니다. 다른 방법
으로는, 이것을 닫고 구글
이미지 페이지를 별도의 탭에
하나 더 열어 두는 것 입니다.
아주 좋은 방법은 아니지만,
우회 할 수 있는 또 다른 방법
이죠. 그다음 이미지를
끌어다가 해당 탭에 놓으면,
똑같이 구글 이미지 검색
결과를 얻을 수 있습니다.
이것도 하나의 방법 입니다.
마지막으로는 'Google image search
' 라는 크롬 용 애드온 이나
확장 프로그램을 사용 하는
방법 입니다. 우리가 익숙
하게 사용 하던 기능을 다시
불러와 주는 셈 이죠. 'Chrome에
추가' 를 클릭 하고, '확장
프로그램 추가' 를 누르면,
이제 확장 프로그램 목록에
추가 될 것 입니다. 이제
이미지에 우클릭을 하면 '
Search Google using this image' 옵션
이 생기고, 기존의 구글 렌즈
옵션도 그대로 남아 있습니다
. 이제 둘 다 사용할 수 있게
된 거죠. 그걸 클릭 하면 구글
이미지 검색 결과를 볼 수
있습니다. 괜찮은 우회 방법
이죠. 이 확장 프로그램을
추가 할 수 있는 링크를
설명란에 남겨 두겠습니다.
직접 시도해 보시고, 구글이
다시 뭔가를 바꾸기 전까지
예전처럼 구글 이미지 검색
기능을 활용 해 보세요. 네,
시청 해 주셔서 감사 합니다.
구독도 잊지 마세요.
