# 무료체험 이벤트(24h 맛보기) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 신규 가입자가 사장님 승인 전에도 24시간 동안 전기능을 맛보되 완성 렌더는 1회만 되게 하고, 24h 후 미승인이면 대기실로 복귀시킨다.

**Architecture:** 등급 판정 단일 진실원 `access_level`에 "미승인+체험창 안이면 full" 분기를 넣고, 렌더 과금 단일 초크포인트 `check_and_count("render")`에 "체험 중이면 영구 trial 버킷 1회 상한"을 얹는다. 체험 창은 customers의 새 `trial_ends_at`(epoch) 컬럼으로 표현한다. 실패 환불은 `render_charge_day="trial"` 센티넬로 계정 trial 버킷을 되돌린다.

**Tech Stack:** Python, SQLite(store.py), FastAPI(app.py), 정적 HTML(admin.html), pytest.

## Global Constraints
- 체험 기간 = **24시간**(설정 `trial_event_hours` 기본 24). 범위 = 담기·렌즈·레퍼런스·제작소 전부 + 완성 렌더 **1회**.
- 체험 만료(미승인) → **pending 전면차단**(기존 `_PENDING_HTML` 재사용, 신규 화면 없음).
- 화이트리스트 유지: 체험은 가입당 1회·시간제한 창일 뿐. 승인되면(approved_at 값) 체험 분기를 안 탄다.
- 하위호환: 기존 고객은 `trial_ends_at NULL` → 만료 취급 → 동작 불변. 백필 금지.
- 모든 편집은 `.tracks/회원승인/` 절대경로. 커밋은 `track/회원승인` 브랜치.
- 테스트 실행: `cd .tracks/회원승인 && py -m pytest ...`.

```python
def _refund_render_charge(store, customer_id, charge_day):
    """렌더 실패 환불. charge_day=None이면 과금 안 한 job(오환불 방지) → no-op.
    "trial"(🎁 무료체험 이벤트)이면 계정은 영구 trial 버킷을, 전역은 오늘 버킷을 되돌린다
    (전역은 항상 today로 집계됐다). 그 외(날짜)면 계정·전역 둘 다 그 날짜로."""
    if not charge_day:
        return
    try:
        if charge_day == "trial":
            store.usage_decr(customer_id, "render", "trial")
            today = datetime.now(timezone.utc).strftime("%Y-%m-%d")
            store.usage_decr(-1, "render", today)
        else:
            store.usage_decr(customer_id, "render", charge_day)
            store.usage_decr(-1, "render", charge_day)
    except Exception:
        traceback.print_exc(file=sys.stderr)
```
