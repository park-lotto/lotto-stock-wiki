## 지정유형 확인법 (공식)

1. **KIND 공시에서 직접 확인** (가장 정확)
   - 종목 → `[투자주의]투자경고종목 지정` 공시 클릭
   - 공시 내 **3. 지정사유** 항목 확인
   - 급등형: "단기급등", "중장기급등" 등 순수 가격 요건만
   - 불건전형: "단기상승·불건전요건" + **특정계좌 관여율 수치** 함께 명시

2. **공시번호 탐색법** (KIND 직접 접근이 막힐 때)
   - 지정일 전날(공시일) 날짜로 연번 탐색: `20260514001600` ~ `20260514001650`
   - iframe URL 패턴: `kind.krx.co.kr/external/{연}/{월}/{일}/{6자리}/{전체}/{docno}/70804.htm`
   - 프레임 텍스트에서 "60%" = 급등형, "45%" = 불건전형
