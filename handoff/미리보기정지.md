# 미리보기정지 — "분명 영상인데 사진처럼 멈춰 있다"

## 2026-09-02 고객(이유준) 제보

- 미리보기 영상이 **돌아가다 다음 클립에서 멈추고, 또 돌아가다 멈추고** 반복
- "분명 영상인데 사진처럼 멈춰서 확인이 불가"
- **"어제는 안 그랬는데 지금은 매번 그래요"** ← 회귀 신호
- (별건) 전체 재생 시 아예 검게 안 보일 때도 가끔 / 소스 추가가 즉시 반영 안 됨

## 원인 — 어제 커밋 02afe3fa9(09-01 15:28)이 낸 회귀

그 커밋은 "짧은 컷에서 검은 화면"을 고치며 **되감는 동안 썸네일을 까는**
`holdShot`을 넣었다. 그런데 **걷는 길이 이벤트뿐**이었다:

```js
if (v.readyState >= 2) holdShot(null, false);
else {
  const late = () => { v.oncanplay=null; v.onseeked=null; holdShot(null,false); };
  v.oncanplay = late; v.onseeked = late;      // ★이게 안 오면 영영 안 걷힌다
}
```

`canplay`·`seeked`는 **이 줄에 닿기 전에 이미 지나갔을 수 있다.** 그러면 다시 오지
않아 썸네일이 화면에 남는다 → 소리와 컷 번호는 흐르는데 **그림만 정지**한다.
컷마다 이벤트를 놓치냐 마냐로 갈리니 "돌아가다 멈추고 또 돌아가다 멈추고"가 된다.
걷는 다른 길은 `stopPlay` 하나뿐이라, 재생 도중에는 회복할 방법이 없었다.

## 고친 것

`late`에 **안전핀**을 걸었다 — 이벤트를 하나도 못 받아도 **그 컷 안에서** 걷는다.
- `timeupdate`도 해제 신호에 추가(실제로 흐르기 시작했으면 정지 그림은 불필요)
- `setTimeout(late, 컷 길이의 50%, 120~600ms)` — 컷보다 짧게(전 사고의 교훈 유지)
