- **자막 층이 셋이다 — 줄마다 어느 층인지 가른다**:
  ① **나레 자막(스냅봤니가 얹음)**: 흰 굵은 고딕 + 검정 두꺼운 외곽선, 한 줄, 창 안 아래쪽(d-jFF 실측 띠 y≈1300~1400). 전언·설명 말투('~했다는', '무려 6년 전인 2019년부터..', '와 스텝 지린다 ㄷㄷㄷ').
  ② **대사 자막(원음 받아쓰기)**: 노랑 채움 + 검정 외곽선, 둥근 손글씨풍 굵은 글꼴, 창 위쪽(UMaw '나는 조금 작거든'·'양보해 줘서 뭐 하게'). 
  ③ **해설 이름표**: 어두운 반투명 둥근 상자 + 흰 글자 '동생 : 팩트 기반 주장중ㅋㅋㅋ'·'언니 : 실질적 목적과 효용성 검증' — 화자 이름 + 콜론 + 짐짓 진지한 논문체 해설 + ㅋㅋㅋ. 대사 자막이 바뀌어도 이름표는 남아 있다(UMaw 2.5~3.4초 실측). 언니 쪽 강조는 핫핑크 상자(UMaw #4·#7). 왼쪽 위 작은 어두운 상자 글('ㅇㄴ 스텝 뭐임;;', '가방 메고 문워크 찢어버림 ㄷㄷ')도 이 층인지 따로인지 가른다.
- **등장 움직임(자막 움직임 핵심)**: 타이핑 아님. **팝 등장** — 첫 1프레임(0.1초 띠 기준)에 작고(약 55~70%) 글자 간격이 벌어지고 어둡게 보이다가 다음 프레임에 100%로 또렷. 나레(d-jFF 2.1→2.2초)와 대사(UMaw 2.7→2.8초) 둘 다 같은 꼴. 퇴장은 다음 줄로 바로 바뀜(페이드 없음 — 확인해 적는다). ★30fps 프레임으로 등장 곡선을 enter_curve[[t,scale%,alpha%,dy]] 로 잰다(0.1초 띠는 너무 성기다 — 등장 전후 0.2초를 프레임 단위로 뽑아라).
- **강조·스티커**: 문장 끝 이모지·그림(d-jFF '빨간 책가방' 뒤 빨간 가방 그림), 'ㅋㅋㅋ'·'ㄷㄷㄷ' 꼬리. 단어 색 강조가 있나 줄마다 본다.
- **끝**: UMaw 끝 = 흐릿한 화면 위 '여러분은 누구 편이신가요?ㅋㅋㅋ'(흰 글 + 검정 상자) — 시청자 질문으로 닫는다. 다른 편 끝도 확인.
- **원본에 박힌 층**: 원 촬영자 화면에 이미 글자가 있으면(스냅봤니 글꼴·자리와 다르면) layer='원본박힘'으로 근거를 적는다. 3편 중 3AqK 는 컷 2개뿐(0~3.3초 소녀 얼굴, 3.3~20.5초 육교 아래 트럭) — 나레만으로 끌고 가는 꼴.
