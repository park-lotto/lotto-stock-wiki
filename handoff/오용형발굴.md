# 오용형(제품 오용·재발견) 축 신설 + 채널 발굴 (2026-08-19)

사장님 방향: **"유튜브는 이런 썰+쇼핑이 되는 트렌드라 이런 채널을 많이 찾아야해"**
/ **"인스타랑 결이 완전 다르다"**

## 한 줄

이븐쇼핑형(정체 은폐)과 **결이 반대인 살림킹왕짱형(용도 뒤집기)** 을 별도 축으로 갈랐다.
같은 칸에 두면 대본 스파인이 정반대라 스타일이 오염된다.

## 왜 — 전사 실측으로 갈린 두 장르 (2026-08-19)

| | **제품정체형**(이븐쇼핑) | **오용형**(살림킹왕짱) |
|---|---|---|
| 파는 것 | 제품의 **정체**(what) | 제품의 **다른 용도**(how) |
| 훅 | 최근 딱 봤을 때는 용도를 알기 힘든 이 제품이 | 이게 원래는 {본래용도}로 개발된 제품이었음 |
| 중반 | 전 세계 SNS 바이럴 → 천재가 돈방석에 | 근데 사람들은 {숨은속성}을 눈치채고 |
| 공개 | **이건 바로 {제품}** (5~7초) | 정체는 처음부터 공개 |
| 반전 | 근데 진짜 충격적인 포인트는 | **근데 미친 사용법은 따로 있었는데** |
| 실적 | 78.2만(최고) | **1,047만**(최고). 구독 1.46만·84편·총 5,789만 |

★살림킹왕짱은 **제품을 팔지 않는다 — 이미 가진 물건의 다른 쓰임을 판다.** 그래서 10배 터진다.

## ✅ 완료 (커밋 2개, `track/오용형발굴`)

### 1. 오용형 카테고리 신설 (`80abac3fc`)
`categorize.py` — 제목 공식 **[권위자]도 [부정어] [귀결어]** 세 조각을 통째로 요구.
판정은 `_is_misuse` 한 곳에서만(0순위-B). `_HOOK_BLOCK`은 제품정체형과 공유.

★**제품정체형과 승격 조건이 다르다.** 제품정체형은 "기타일 때만 승격"인데, 오용형은
**'기타'가 아니라 '홈템'으로 샌다** — 해시태그에 `#살림템 #주방꿀템`을 그대로 달기 때문
(살림킹왕짱 상위 12편 **12/12 홈템**). 기타 제한을 걸면 한 건도 못 건진다.

### 2. 라이브 발굴 중 잡은 실사고 2건 (`e541ebb82`)
둘 다 **오류가 안 나고 조용히 홈템으로 새는** 종류라 테스트로 못박았다.

1. **★채널명의 차단어가 그 채널 영상을 통째로 죽였다.** `살림치트키`(구독 9,770·정상
   쇼핑채널)가 전부 걸러졌다. `치트키`는 지식북('구구단 치트키') 오탐용으로 `_HOOK_BLOCK`에
   넣은 말인데, 차단 검사를 `name_t`까지 묶은 blob에 걸어서 **채널명에 두 글자가 있다는
   이유로** 죽었다 → 차단은 **영상 제목(cap_t)으로만**.
   실측 효과: 살림치트키 0→5편, 살림도사 0→16편, 활용정점 6→13편.
2. **귀결어가 '사용법/활용법'뿐이라 놓쳤다.** `아이디어·꿀팁·방법·신박한` 추가.
   권위자+부정어 공식은 그대로라 단독 통과는 불가.
