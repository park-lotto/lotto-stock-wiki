05 · Usage Scenes

▶
유튜브 썸네일
표정 2종 조합 — 기본(설명 중) + 탑픽(발견). 텍스트 없이도 감정 전달.
✦
Remotion 영상 내 자막바
말풍선 + 얼굴 아이콘 콤보. 씬 전환마다 표정 바꿔 내레이터 역할.
📲
텔레그램 브리핑 카드
카드 하단 우측 고정 배치. 탑픽 🔴 = 탑픽 발견 표정 / 경고 = 빨간 안경 표정.
🧠
STOCK BRAIN 대시보드
신호 등급별 표정 자동 매핑. 섹터 온도 🔴 = 탑픽 표정, 🟡 = 설명 표정.
🖼
채널 아트 / 프로필
기본 표정 + STOCK BRAIN 로고 조합. 배경 다크 네이비 고정.
📌
굿즈 / 스티커팩
4종 표정 기본. 추후 확장 — 커피 들기 / 차트 가리키기 / 어깨 으쓱.
