# 장면꾸미기 → 최종 렌더 전체 저장 보강

- 아스트라 감사로 확대·강조의 지연 저장이 장면 전환 후 다른 비트에 저장되는 문제와 서버 edit_plan read-modify-write 경합을 재현했다.
- 확대·강조는 조작 순간 대상/값을 캡처하고 공용 직렬 큐로 저장한다. flattened 컷은 실제 beat_idx별 1회만 보낸다.
- scenezoom/scenehl API도 `_plan_lock` 안에서 edit_plan을 다시 읽고 쓴다.
- 최종 렌더는 자막·확대·강조·장면실험실 저장이 끝날 때까지 기다리며 실패 시 옛 설정으로 렌더하지 않는다.
- headcopy/caption_style/deco 전체 저장도 호출 순서대로 직렬화했다.
- `scene_hl`을 완성본 청소 캐시 서명에 포함해 강조 변경 뒤 옛 캐시가 재사용되지 않게 했다.
- 관련 테스트 50개 통과(문법·TDZ·자막 위치·최종 청소·강조 포함).
- 라이브 박세현 job `24831d78958d`는 과거 잘못 저장된 장면별 좌표를 화면 근거와 대조해 복구한 뒤 최종 렌더·13초 프레임을 확인해야 한다.
