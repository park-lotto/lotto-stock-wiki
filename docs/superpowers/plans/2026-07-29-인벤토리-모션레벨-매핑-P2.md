**Goal:** 대본 세그먼트마다 시각컷 기준 모션레벨(LOW/MED/PEAK)을 붙여 대본 생성 프롬프트(scene_desc와 별개 필드)가 "이 구간이 화면상 얼마나 격한 동작인가"를 알게 한다.

**Architecture:** 설계서(`docs/superpowers/specs/2026-07-28-하이브리드-장면인벤토리-design.md`) §3 P2를 재조정한 버전. 원 설계는 "whisper 세그먼트를 시각 컷으로 재베이스"였으나, 코드 실측 결과 대본 생성 단계(`edit_plan.py:_build_inventory`)에는 영상 파일 경로가 없어 그 자리에서 `scene_cut`(ffmpeg)을 호출할 수 없다. 대신 **추출 단계(`script_extract.py:extract_script`, 이미 video_path 보유)에서 컷+모션을 계산해 각 세그먼트에 `motion_level` 필드를 미리 박아 DB(`segments_json`)에 저장**한다. 인벤토리 재베이스(seg 단위를 컷 단위로 바꾸는 것)는 하지 않는다 — seg_id 체계·인터페이스 완전 불변, 회귀 위험 최소화.

**핵심 안전장치**: `scene_desc`(자유 텍스트) 필드 자체는 절대 건드리지 않는다. `_claim_key`(edit_plan.py:125)가 `scene_desc`의 모든 토큰을 앵커 dedup 키로 쓰기 때문에, 여기에 `[Motion]LOW` 같은 접미어를 섞으면 서로 무관한 앵커들이 "Motion"/"LOW" 공통 토큰 때문에 오탐 dedup될 위험이 있다(실측 확인, 설계서에 없던 리스크). `motion_level`은 seg dict의 별도 키로만 추가하고, 프롬프트 조립 시(`_build_inventory`의 인벤토리 라인)에만 텍스트로 노출한다.

**Tech Stack:** Python, ffmpeg(scene_cut 기존 함수 재사용), SQLite(segments_json blob — 스키마 변경 없음)

```python
def map_segments_to_motion_levels(segments, cuts_labeled, fps):
    """세그먼트 리스트 + cut_motion() 출력(컷별 {start,end,level,...} 프레임단위) + fps
    → {seg_id: level|None}. 교집합(프레임 겹침) 최대인 컷의 level을 채택.
    겹치는 컷이 없으면(seg가 컷 범위 밖) None. 순수 함수(테스트 대상)."""
    out = {}
    for seg in segments:
        sid = seg.get("seg_id")
        s_a = seg.get("start", 0.0) * fps
        s_b = seg.get("end", 0.0) * fps
        best_level, best_overlap = None, 0.0
        for cut in cuts_labeled:
            c_a, c_b = cut.get("start", 0), cut.get("end", 0)
            overlap = min(s_b, c_b) - max(s_a, c_a)
            if overlap > best_overlap:
                best_overlap = overlap
                best_level = cut.get("level")
        out[sid] = best_level
    return out
```

```python
def _compute_motion_map(video_path, cuts, fps, raw_segments, video_id):
    """detect_cuts 결과(cuts,fps 재사용) + 추출된 세그먼트(아직 seg_id 없음) + video_path
    → {seg_id: level|None}. ffmpeg로 프레임모션을 재고 seg별 교집합 최대 컷의 레벨을 매핑.
    cuts가 비었거나 어떤 예외든 fail-open(빈 dict, 전부 motion_level=None)."""
    try:
        if not cuts or not fps:
            return {}
        motion = scene_cut.frame_motion(video_path)
        if not motion:
            return {}
        cuts_labeled = scene_cut.cut_motion(cuts, motion)
        tmp_segs = [{"seg_id": f"{video_id}-{n}", "start": s.get("start", 0.0), "end": s.get("end", 0.0)}
                    for n, s in enumerate(raw_segments)]
        return scene_cut.map_segments_to_motion_levels(tmp_segs, cuts_labeled, fps)
    except Exception:
```

```python
def _build_inventory(source_scripts):
    """소스 대본들 → (seg_map, prompt_block).

    seg_map: {seg_id: {video_id, seg_id, start, end, text, scene_desc, motion_level}}
    prompt_block: 모델 프롬프트에 넣을 세그먼트 인벤토리 텍스트(seg_id로만 지목하게)."""
    seg_map = {}
    lines = []
    for script in source_scripts:
        vid = script.get("video_id", "")
        segs = script.get("segments", [])
        usable = segs[1:-1] if len(segs) >= 3 else segs
        for seg in usable:
            sid = seg["seg_id"]
            length = round(seg["end"] - seg["start"], 2)
            seg_map[sid] = {
                "video_id": vid, "seg_id": sid,
                "start": seg["start"], "end": seg["end"],
                "text": seg.get("text", ""), "scene_desc": seg.get("scene_desc", ""),
                "action": seg.get("action"),
                "is_key": bool(seg.get("is_key")),
                "shot_role": seg.get("shot_role") or "기타",
                "product_benefits": _seg_benefits(seg),
                "motion_level": seg.get("motion_level"),
            }
            _act = seg.get("action")
            _act_s = f" | 행위:{_act}" if _act else ""
            _ben = _seg_benefits(seg)
            _ben_s = f" | 특장점:{' / '.join(_ben[:2])}" if _ben else ""
            _ml = seg.get("motion_level")
            _ml_s = f" | 모션:{_ml}" if _ml else ""
            lines.append(
                f"[{sid}] ({length}s) 화면:{seg.get('scene_desc','')} | 말:{seg.get('text','')}"
                f"{_act_s}{_ben_s}{_ml_s}"
            )
    return seg_map, "\n".join(lines)
```

⚠️ `scene_desc` 값 자체는 한 글자도 안 바뀐다 — `_ml_s`는 별도 접미어로 `_ben_s` 뒤에만 붙는다. `_claim_key`/`_is_face_seg`는 여전히 `seg_map[sid]["scene_desc"]`만 읽으므로 영향 없음(다음 Task에서 회귀테스트로 확정).
