# 유튜브 영상 제작 규칙 — STOCK BRAIN 채널

> 모든 영상 기획 시 이 규칙을 따른다.
> 작성일: 2026-05-30

---

## 1. 프로덕션 문서 필수 구성

모든 영상은 아래 4개 컬럼이 씬마다 채워져야 제작 시작 가능하다.

| 컬럼 | 내용 |
|------|------|
| **대본** | 실제 읽을 대사 전체. 쉼·강조·속도 표시 포함 |
| **화면** | 이 순간 화면에 뭐가 보이는지 구체적 묘사 |
| **연출** | 어떻게 보여줄지 — 카메라·편집·Remotion 지시 |
| **목적** | 이 씬이 시청자에게 만들어야 할 감정/상태 |

---

## 2. 씬 구조 표준

```
[씬 번호] 씬명 | 시작~종료 시각 | 길이
─────────────────────────────────────
대본:
  (실제 읽을 대사. 쉼/강조 표시 포함)

화면:
  (이 순간 화면에 뭐가 보이는지)

연출:
  (어떻게 촬영/편집/제작할지)

목적:
  (이 씬이 시청자에게 만들어야 할 감정)
─────────────────────────────────────
```

---

## 3. 대본 표기 규칙

| 표기 | 의미 |
|------|------|
| `[쉼]` | 1~2초 멈춤 |
| `[긴쉼]` | 2~3초 멈춤 |
| `**강조**` | 천천히, 힘 줘서 |
| `(작게)` | 낮은 목소리 |
| `→` | 화면 전환 시점 |

---

## 4. 화면 표기 규칙

```
[화면 유형]
  Remotion    — Remotion 컴포넌트로 제작하는 그래픽
  실화면      — 실제 화면 녹화 (터미널·브라우저·앱)
  캡처        — 미리 캡처한 스크린샷 이미지
  실촬영      — 카메라로 직접 찍는 장면
  자막        — 텍스트 오버레이만
```

---

## 5. 연출 표기 규칙

```
컷 전환:
  페이드인 / 페이드아웃 / 컷 / 슬라이드 / 줌인

속도:
  슬로우 / 일반 / 빠른 / 타임랩스

강조:
  하이라이트 박스 / 화살표 / 확대 / 텍스트 오버레이

Remotion 씬:
  컴포넌트명(AG01, AG02 등) + 파라미터
```

## 6. 훅 설계 원칙 (레퍼런스 7개 분석 기반)

```
① 첫 문장에 반드시: 숫자 + 충격 조건 + 대비 상황
② 공감 없이는 해결책이 안 먹힘 — 씬2 공감 필수
③ 실제 화면 데모 없으면 신뢰 0 — 가짜 같으면 즉사
④ 오프닝 결과를 클라이맥스에서 다시 보여줌
⑤ 클라이맥스에 개념 전환 문장 1개
⑥ 마지막은 다음 편 예고 — 여운이 클릭을 만듦
```

## 7. 씬 흐름 표준 (8분 영상 기준)

```
씬1  0:00~0:30  훅           첫 문장에 모든 것 박기
씬2  0:30~1:10  공감         시청자 일상 고통 짚기
씬3  1:10~1:45  선언/개요    해결책 한 줄 선언
씬4  1:45~5:30  데모         실제 화면 보여주기 (핵심)
씬5  5:30~6:30  클라이맥스   오프닝 재등장 + 개념 전환 문장
씬6  6:30~7:10  자각         시청자가 얻는 것
씬7  7:10~7:45  여운         다음 편 예고
씬8  7:45~8:20  CTA          댓글 키워드 + 서비스 티저
```
