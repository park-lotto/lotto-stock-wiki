## 자동반영 프로토콜

> 뉴스·리포트 ingest 시 아래 순서로 처리:

```
1. 종목명·코드 탐지 → 해당 섹터 테이블.md의 서브섹터 확인
2. 신규 종목이면 → 해당 서브섹터 행의 "대표 종목" 컬럼에 즉시 추가
3. 기술 드라이버 변화 → "기술 드라이버 × 서브섹터 연계" 표 업데이트
4. 활성 서브섹터 확인 → "일별 활성 로그"에 날짜·이유 추가
5. 섹터 온도 현황 표 (이 페이지) 온도·업데이트 날짜 갱신
```
