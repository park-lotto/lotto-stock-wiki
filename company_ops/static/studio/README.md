# 8석 워커 디자인 스튜디오

`http://127.0.0.1:8931/studio/` — static 폴더에서 `py -m http.server 8931 --bind 127.0.0.1`로 제공.

- 기존 atlas 데이터에서 W-001/002/003/004/007/015/016/020을 재사용. 실행 5, 대기 2, 막힘 1 모두 고정 예시.
- 8개 워커의 외형/작업대/작업 화면과 기획팀 한 구역의 주간·야간 디자인 검토용. 실제 AI 가동·명령·산출물 없음.
- 로봇을 직접 누르거나 하단 목록에서 선택. 드래그 회전, 우클릭 이동, 휠 확대. Esc/전체 보기로 복귀.
- 연출 동작은 머리/손의 디자인용 미세 동작이며 실제 작업 이벤트가 아니다. 버튼으로 정지 가능. reduced-motion 환경에서는 기본 정지.
- `scene`에서 `npm run build:studio`. 트랙 루트에서 `node company_ops/tests/studio.cjs`.
- 200개 atlas는 변경하지 않고, 디자인 승인 후 최적화/적용할 범위. 기존 API·DB는 사용하지 않는다.
- Three.js MIT 고지: `../hq/THIRD_PARTY_LICENSES.txt`, 생성 번들 라이선스도 유지.
