# 낱말 색 ↔ 템플릿 충돌 (2026-09-02, 사장님 제보)

**제보**: "헤드카피 설정 후, 템플릿 적용하고, 다시 헤드카피로 돌아가 기존에 적용되어 있던
글자별 색을 클릭하여 색 바꿈을 시도하면 기존 색이 바뀌지 않음."

## 뿌리 (라이브 재현 완료)
템플릿을 고르면 `applyHeadcopySet`이 **2줄째 통째**를 키워드로 규칙을 하나 넣는다:
`{keyword:"바닥 세정제 추천", color:색2, _fromFrame:true}`
그런데 색칠 로직이 **긴 키워드 먼저** 정렬하고 `marks[i]==null`일 때만 칠한다
→ 9자짜리 틀 규칙이 2자짜리 사람 낱말을 통째로 덮어, 나중 규칙이 들어갈 자리가 없다.

★**데이터는 정상이었다**: 내 규칙 color가 #2EE6C5로 정확히 바뀌는데
세그먼트는 `"바닥 세정제 추천:#000000"` 한 덩어리 → **화면·렌더만** 안 바뀐다.
그래서 "색이 안 먹는다"로 보인다.

## 고침 (커밋 `3dc4dca99`)
정렬을 **(사람 규칙 먼저, 그 안에서 긴 것 먼저)** 로 바꿨다.
- 수정 전: `바닥 세정제 추천` 전부 #000000
- 수정 후: `바닥`=#2EE6C5 / ` 세정제 추천`=#000000
- 길이 우선은 같은 등급 안에서만 유지 → 짧은 규칙이 긴 규칙을 조각내던 원래 문제는 그대로 막힌다.
