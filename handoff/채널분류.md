# 채널분류 — 폰 공유 채널 담기에 분류 버튼 (관제 261)

> **소유 트랙**: 채널분류 — 이 파일은 이 트랙 세션만 수정한다.

## 2026-10-24 (PC: CH)

사장님: "폰 보다가 채널 등록할 때 자동 분류보다 쉽게 / 기타도 만들고 기타에서 분류로 이동 / 내가 직접 추가 / 지금은 나만 보는거야".

- **주인**: 분류 이름·기타 판단 = `store.py` `fav_cat_*`(기본 9개 `FAV_CAT_DEFAULTS`, `FAV_CAT_ETC`) / 누가 쓰나 = `app.py:_fav_cat_on`(지금 관리자만 — 회원에게 열 땐 여기만).
- **표**: `fav_channel`(회원 표)은 안 건드리고 옆 표 2개 — `fav_channel_cat_def`(분류 이름) · `fav_channel_cat`(채널↔분류, 행 없음 = 기타). 채널 빼면 분류 행도 같이 지움.
- **입구**: 폰 공유 `/share` → ⭐채널 담기 → 응답에 `cats`(최근 쓴 순) → 분류 버튼 한 번 탭(`POST /api/fav_channel/set_cat`) · ＋새 분류(없는 이름이면 만들어짐) / `/fav_channels` 위 분류 탭(순서 고정 `cats_fixed`) + 카드마다 '분류로 옮기기' 선택칸 · ＋분류 추가(`POST /api/fav_channel/cats/add`).
- **검사**: `shopping_shorts/tests/test_fav_channel_category.py`(6개, 회원 화면 변화 0 포함). 로컬 서버(:8873, 인증 끔) + 폰 크기(390px) 브라우저로 공유→분류 탭→기타에서 옮기기까지 눌러 확인, 가로 넘침 0·페이지 오류 0.
