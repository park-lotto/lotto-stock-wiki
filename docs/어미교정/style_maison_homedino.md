사장님 지정 1순위 스타일 (2026-08-05 "메종홈디노가 제일 내 스타일이야").
근거 대본 13개 (조회수 158만~1.6만, `maison_scripts.json`) 직접 분석.

## 구조 템플릿 (13개 중 11개가 이 뼈대)

```
① 훅: 사건/발견 선언 (1문장, 아래 3패턴)
② 배경+불편: "원래는 ~해서 진짜 귀찮았거든요?" — 기존 방식의 짜증을 내 경험으로
③ 반전: "근데 이건/이게" + 원리 한 줄 (구체 스펙 하나 콕: 0.02mm·24시간·75인치)
④ 장점 몰기: 장점 2~3개를 한 문장에 — "~는데 ~니까 ~더라고요" 리듬
⑤ 확장: "심지어/더 대박인 건" + 보너스 장점 1개
⑥ 사회적 증거: "없어서 못 산다고 하더라고요" / "바로 주문하더라고요"
⑦ CTA: "댓글에 '키워드' 남겨주세요" 단문 (없는 대본도 있음 — 캡션 유도형)
```

## 훅 3패턴 (실측 분포)

| 패턴 | 예 (실제 대본) | 빈도 |
|---|---|---|
| **감탄+목격** | "와, 저 이거 보고 소리 질렀어요" / "친구 차 타고 깜짝 놀랐어요" | 5 |
| **출처 권위** | "천재가 만들어서 캠핑족들 사이에서 난리 났다는 불멸의 얼음이 있어요" | 4 |
| **인물 사건** | "와이프가 생일 선물로 게임방을 만들어줬는데" / "와이프한테 혼났어요" | 4 |

## 스타일 자산 (벤치마킹 6축)

1. **서사**: 반드시 **인물 관계**를 통과한다 — 와이프·친구·엄마·인플루언서 형·개발자.
   "내가 좋다"가 아니라 "그 사람이 이렇게 쓰더라/사더라"로 신뢰를 만든다.
2. **불편 묘사가 앞에 온다**: 제품 소개 전에 기존 방식의 짜증을 1~2문장 ("얼음이
   녹으면서 물이 생기고 주변까지 다 젖으니까 진짜 짜증나잖아요").
3. **원리+스펙 1개**: 왜 되는지 한 줄 + 숫자 하나만 (여러 스펙 나열 금지).
4. **장점 몰기 리듬**: "공간 차지도 없는데 + 서랍 열면 본체가 나오니까 + 업그레이드도
   진짜 쉽더라고요" — 접속으로 잇고 끝에 감탄/전달 어미 하나.
5. **강조 어휘**: 진짜 / 미쳤는데 / 대박 / 난리 났다는. 상투어(꿀템·갓성비)는 0회.
6. **어미 분포**: ~거든요?(의문 억양) · ~더라고요(전달) · ~는 거예요 · ~잖아요.
   같은 어미 연속 없음 — 문장이 길게 이어지다 어미 하나로 닫힌다.

## ⚠️ 우리 규칙과의 충돌 확인

- 사장님 확정 구조(강훅→문제→해결→해결심화→보상형CTA)와 **호환** — 이 채널 구조가
  사실상 같은 뼈대(훅→불편→반전→장점몰기→CTA)다.
- CTA: 이 채널은 "댓글에 '나도'" 단문형. 우리 보상형("남기면 뭘 받는지 명시")이
  더 강하므로 **CTA는 우리 규칙 유지**, 훅~장점몰기까지만 이 스타일을 입힌다.
- 과장 가드 유지: "미쳤다/대박" 같은 감정 과장은 OK, 없는 성능·가격 창작은 계속 금지.
