# [인계] 유튜브 전용 대본 스파인 2종 신설

사장님 지시(2026-08-19): "1번2번 시작하고 **3번은 다른 트랙에 주게 정리남겨봐** 전달할게"

## 왜 이게 별도 작업인가

지금 라이브 스파인은 **인스타에서 뽑은 것뿐**이다(`spine` id=52 '시월드형', 채이홈 기반).
그런데 실측해보니 **유튜브 썰쇼핑은 인스타와 대본 문법이 정반대**다. 인스타 스타일을
유튜브에 그대로 쓰면 안 된다 — 아래 표의 모든 축이 어긋난다.

**소재**: 이븐쇼핑 2편·살림킹왕짱 2편 = yt-dlp 자막 전문 + 프레임 육안

|---|---|---|

| 훅 엔진 | **관계 갈등**(시댁·와이프·아빠·친구) | **미스터리**(정체 은폐) / **오용**(용도 배신) |
| 권위 출처 | 제3자 지인 "영양사 하는 친구가" | 익명의 천재·개발자·제조사 |

★**댓글률 400배 차이** = 게임이 다르다. 인스타는 관계 장사(댓글·저장), 유튜브는
완시청 장사(21초를 끝까지). 살림킹왕짱은 **구독 1.46만인데 1,047만 조회** — 구독자와
조회수가 무관하게 돈다. 그래서 유튜브 스파인에 **CTA를 넣으면 안 된다.**

## 만들 것 — 스파인 2종

### A. 은폐형 (이븐쇼핑, `UClecY6IhcjwmCBJHiZ2-cTg`)
```
1 제목반복    "{X} 망하게 한 {나라} 천재의 발명품"
2 미끼        "최근 딱 봤을 때는 [용도를 알기 힘든 / 평범한] 이 제품이"
3 증폭        "한국은 물론 전 세계 SNS에서 바이럴이 폭발하며"
4 권위        "이걸 개발한 {나라}의 천재가 돈방석에 앉았다는데"
5 ★공개       "이건 바로 {제품명}"                      ← 5~7초
6 효능1       "이게 말도 안 되는 게 {효능}"
7 ★2차반전    "근데 진짜 충격적인 포인트는 {효능2}"      ← 여기서 끝. CTA 없음
```
실측 전문 2편(78.2만·31.6만)에서 **볼드 어구가 글자 그대로 동일**. 소재만 갈아끼운다.

### B. 오용형 (살림킹왕짱, `UCBFu04us6bv9OFcwrJDXdMg`)
```
1 제목반복    "[권위자]도 [부정어] 미친 사용법"
2 본래용도    "이게 원래는 {본래용도}로 개발된 제품이었음"
3 눈치챔      "그런데 사람들은 {숨은속성}을 눈치채고 엉뚱한 용도로 쓰기 시작하는데"
4 사례나열    "{용도A}로 쓰는가 하면 {용도B}로 사용했다는 거"
5 ★최종반전   "근데 미친 사용법은 따로 있었는데 {용도C}"  ← 여기서 끝. CTA 없음
```
실측 2편(1,047만·904만). **말끝이 `~었음`·`~다는 거`** — 인스타의 `~했어요` 존댓말과 다르다.

## 구현 메모 (기존 자산 재사용 — 새로 짓지 마라)

- **`spine` 테이블에 행 2개 추가**가 전부다. 새 테이블 만들지 마라(0순위-B).
  컬럼: `beat_roles_json`(기계 대조용)·`templates_json`(문장틀)·`chars_per_30s`.
- 시드 스크립트 본보기: `tools/seed_style_siworld.py` (id=52 시월드형). 이걸 복사해 고쳐라.
- `chars_per_30s`는 **270**(실측 262~283의 중앙). 시월드형은 300이다.
- **게이트 주의**: `script_gate.py`의 CTA 검사는 **스타일과 무관하게 무조건 돈다**
  (memory: 스타일추출_전사재고먼저). 유튜브 스파인은 CTA가 없는 게 정답이므로
  **CTA 검사를 스타일별로 끌 수 있게** 하지 않으면 이 스파인은 항상 FAIL한다. ★이게 최대 함정.
- **문장틀 판정은 통짜 일치를 요구하지 마라** — "고정 어구가 순서대로 절반 이상 +
  최장 어구 필수"가 기존 규칙이다(handoff/채널전략분석.md 참고).
- 카테고리 잠금: A는 `제품정체형`, B는 `오용형`(2026-08-19 신설, main 병합 대기).
