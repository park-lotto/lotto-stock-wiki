# 속도감 모드 (무음 컷 + 타이트 이음) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 각 문장 TTS의 앞뒤 숨소리·문장 안 쉼을 합성 직후 다듬어, 문장이 무음 없이 타이트하게 이어지는 "속도감 모드"를 한 스위치로 추가한다.

**Architecture:** 전부 `audio_post.post_process`의 필터 체인 확장으로 처리한다. mp3가 짧아지면 하류(자막 싱크·영상 슬라이스·타임라인)가 읽는 `tts_dur`이 자동으로 그 값이 되므로 `video_assemble.py`·타임라인 코드는 손대지 않는다. 스위치는 보이스 스냅샷(job의 `voice` dict)의 `pace_mode` 키 하나로 흐른다.

**Tech Stack:** Python, ffmpeg(silenceremove/apad/afade), FastAPI(app.py), 순수 JS(produce.html), pytest.

**작업 폴더:** 모든 경로는 트랙 폴더 `.tracks/속도감모드/` 기준. git은 `git -C .tracks/속도감모드 ...`.

**참고 스펙:** `docs/superpowers/specs/2026-07-22-속도감모드-무음컷-타이트이음-design.md`

_PACE_FADE = 0.012       # 가장자리 페이드(초)

```python
def post_process(in_path, out_path, tempo=1.0, silence_trim="off", pace_mode=False):
    """in_path mp3에 속도(tempo)·무음삭제·속도감모드를 적용해 out_path로.
    둘 다/셋 다 no-op이면 in_path 그대로 반환.

    tempo: atempo 배율(1.0=변화없음). silence_trim: off/weak/mid/strong.
    pace_mode: True면 앞뒤 숨소리까지 잘라 문장을 타이트하게 붙임(무음 컷+타이트 이음).
    pace_mode가 켜지면 silence_trim 레벨 대신 _pace_filters를 쓴다(둘을 한 스위치로 묶는 지점)."""
    filters = []
    if tempo and abs(tempo - 1.0) > 1e-3:
        filters.append(f"atempo={tempo:.3f}".rstrip("0").rstrip("."))
    if pace_mode:
        filters.extend(_pace_filters())
    else:
        sf = _silence_filter(silence_trim)
        if sf:
            filters.append(sf)
    if not filters:
        return in_path
```

`shopping_shorts/tests/test_pace_real_ffmpeg.py` 생성:

```python
import shutil, subprocess, tempfile
from pathlib import Path
import pytest
from shopping_shorts import audio_post

pytestmark = pytest.mark.skipif(shutil.which("ffmpeg") is None, reason="ffmpeg 없음")


def _dur(p):
    out = subprocess.run(["ffprobe", "-v", "error", "-show_entries",
                          "format=duration", "-of", "csv=p=0", str(p)],
                         capture_output=True, text=True).stdout.strip()
    return float(out)


def test_pace_shrinks_leading_and_trailing_silence():
    """앞 0.5s 무음 + 0.4s 톤 + 뒤 0.5s 무음(총 ≈1.4s)에 pace_mode 적용 →
    앞뒤 무음이 잘려 (톤 0.4s + 끝여백 0.08s) 수준으로 짧아진다."""
    d = Path(tempfile.mkdtemp())
    src = d / "in.mp3"
    # lavfi로 [무음0.5][440Hz 0.4][무음0.5] 생성
    subprocess.run(["ffmpeg", "-y",
        "-f", "lavfi", "-t", "0.5", "-i", "anullsrc=r=44100:cl=mono",
        "-f", "lavfi", "-t", "0.4", "-i", "sine=frequency=440:r=44100",
        "-f", "lavfi", "-t", "0.5", "-i", "anullsrc=r=44100:cl=mono",
        "-filter_complex", "[0][1][2]concat=n=3:v=0:a=1[a]",
        "-map", "[a]", str(src)], check=True, capture_output=True)
    before = _dur(src)
    out = d / "out.mp3"
    audio_post.post_process(str(src), str(out), pace_mode=True)
    after = _dur(out)
    assert after < before - 0.5      # 최소 앞뒤 무음 1초 중 상당분이 잘림
    assert after < 0.8               # 톤(0.4)+여백(0.08) 수준
```
