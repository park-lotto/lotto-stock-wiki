## Ingest 처리 규칙

```
정책 이슈 관련 뉴스 감지 시:

1. 이 파일(policy_watch.md) 먼저 확인
   → 기존 정책이면: 편입 종목 업데이트
   → 신규 정책이면: 새 섹션 추가

2. 편입 확정 종목 → stock/ 파일 정책이슈 ✅ 변경 + 탑픽 점수 +1

3. 수혜 섹터 → 해당 L5_섹터/index.md 🌏 지속영향이벤트 추가

4. 코스닥 전반 수급 유입 뉴스 → L3_한국시장/index.md 수급흐름 업데이트
```
