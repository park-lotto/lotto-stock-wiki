## ✅ 2026-08-10 — 렌즈 결과 썸네일 검정 해결 (라이브)

**증상**: 역대 히트작 → 카드의 `🔍 숏템파워검색` → 모달은 뜨는데 **카드 썸네일이 검게 비어 있음**.
일부(틱톡)만 보이고 유튜브·인스타는 전부 검정.

**원인**: 렌즈 결과(SerpApi `visual_matches`)의 `thumbnail`은 플랫폼 CDN이 아니라
**구글이 재호스팅한 `encrypted-tbnN.gstatic.com`** 주소다. `_ALLOWED_THUMB_HOSTS`
(app.py:4099 부근)에 gstatic이 없어 `/api/thumb`가 **400 invalid host**를 뱉었고,
프런트 `onerror`가 이미지를 숨겨(`visibility:hidden`) 검은 칸만 남았다.
틱톡만 보였던 건 렌즈가 그쪽은 원본 `tiktokcdn` 주소를 준 경우가 있어 우연히 통과한 것.

**서버로그 실측(2026-08-09 3시간)**: `/api/thumb ... 400 Bad Request` **40건**,
거부된 호스트는 `encrypted-tbn0/2/3.gstatic.com` **뿐**(다른 호스트 0건).

**고친 것**: `shopping_shorts/app.py` `_ALLOWED_THUMB_HOSTS`에 `"gstatic.com"` 추가.
커밋 `32cf200d1` → main 병합 `9684d94c7` → 서버 배포·재시작 확인(00:06).

**검증**
- `_reject_cdn_proxy` 8케이스 PASS — gstatic 통과 / `evil-gstatic.com` ·
  `gstatic.com.evil.com` · `169.254.169.254` · `127.0.0.1` 전부 차단 유지
- TestClient 실호출: gstatic → **200 image/jpeg 9024B**(수정 전 400), AWS메타 → 400
- 서버에서 `__file__` 찍어 실제 배포본 확인: `허용목록에 gstatic 있나: True`
- Referer는 **안 건드림** — 서버에서 instagram/google referer 둘 다 200 확인(불필요)

## ⚠️ 다시 밟지 말 것

1. **`/api/thumb`는 비로그인이면 401**이다(`_AUTH_ALLOW`에 없음). curl로 밖에서
   찔러보면 호스트와 무관하게 401이라 **수정 여부를 판별할 수 없다**. 서버에서
   `python3 -c "import shopping_shorts.app"`로 `_ALLOWED_THUMB_HOSTS`를 직접 찍어 확인해라.
2. **이 유형은 반복된다** — xhscdn(07-19) · douyinpic(07-26) · gstatic(08-10) 전부
   같은 원인(화이트리스트 누락 → 카드 검정). **새 플랫폼/새 검색경로가 붙으면
   썸네일 호스트가 뭔지부터 확인**할 것.
3. 화이트리스트에 넣을 땐 반드시 **파싱한 hostname 정확일치/서브도메인 일치**여야 한다
   (`_reject_cdn_proxy`가 이미 그렇게 돼 있다). 부분문자열 검사로 바꾸면 SSRF가 뚫린다.
