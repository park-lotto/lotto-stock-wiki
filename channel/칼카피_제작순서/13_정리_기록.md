# 13 정리 · 기록 · 커밋 · 공유

## 로컬 정리 (사장님 10-20 "납품한 편은 지운다" → 10-24 "구글에 올리면 로컬은 다 지워 / 이 규칙 계속 적용, 수정 시 필요하면 구글 드라이브에서 받아서")
드라이브에 올린 편은 로컬의 **영상·이미지만** 지운다. 조건: ① 드라이브 크기 = 로컬 크기 ② DriveFS `operations` = 0.
- **지우는 것**: 그 편 작업 폴더의 영상(mp4·mov·webm…)·이미지(png·jpg) — 렌더 중간물·완성본·프레임 + 바탕화면 사본.
- **남기는 것**: 나레·원음 소리(wav·mp3 — git 에 없다, 지우면 고칠 때 타입캐스트를 다시 해야 한다) · json·txt · 받은 원본·재료 폴더(`src`·`screen`·`bench`·`raw`·`dl` — 원본이 비공개·삭제되면 다시 못 받는다, 10-18 주걱 쇼츠) · git 의 `channel/<채널>/<편>/` · 드라이브 `_이전판`.
- **고칠 때**: 완성본은 드라이브 정본에서 받아 쓴다(robocopy/Copy-Item 으로 C 작업 폴더에). 중간물은 남은 소리·json·src 로 다시 렌더.
- 지우는 도구: 편 목록을 만들고 영상·이미지만 지우는 스크립트(10-24 묶음 정리 = 드라이브 mp4 196개와 크기 대조 → 편 폴더 → 위 규칙). 최근 3시간 안에 손댄 폴더·다른 세션이 지금 쓰는 편은 건너뛴다.
- 사장님 판정 전에 다시 손볼 수 있는 편(사실 확인 대기 등)은 판정 뒤에 지운다. 멈춘 편(만들지 않은 편)의 받은 원본은 묶음이 끝나면 지운다.
- 권한 판정이 삭제를 막으면 우회하지 말고 사장님께 `! <명령>` 을 드린다.

## 커밋
```
git -C <워크트리> diff --cached --stat                  # 남의 staged 파일이 섞였나(있으면 git restore --staged <그 파일>)
git -C <워크트리> add channel/yanshottem/하이브리드_<키>/ <내가 고친 도구 경로>      # 새 파일을 알리기
git -C <워크트리> commit -m "<무엇> (관제 097)" -m "Co-Authored-By: …" -- channel/yanshottem/하이브리드_<키>/ <내가 고친 도구 경로>   # ★경로를 붙여 그 경로만
git -C <워크트리> push origin HEAD:track/칼카피숏템엔진
```
- `git add -A` 금지(같은 워크트리를 여러 세션·워커가 쓴다). `track.py finish 칼카피숏템엔진` 금지(고객 영상 라인까지 라이브로 간다).
- 장부·근거 문서의 라이브 반영은 `tools/calcopy/preset_publish.py` 한 곳(사장님 요청 때 또는 매일 02:00).
