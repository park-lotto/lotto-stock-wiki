판(키치잇판·꿀템노트판·스타픽룸판)을 칼카피할 때 자막팩을 모든 줄에 똑같이 바르면 벤치와 다르다. 벤치는 **어느 덩어리에** 팝·타이핑·강조색·스티커·효과음이 붙는지가 편·장면·말 역할마다 다르고, **꾸밈 없는 덩어리도 많다**(없는 것도 스타일). 이 판독에서 그 빈도를 세어 판 설정의 배치 규칙(`tools/calcopy/hybrid/styles/<판>.json` placement)을 만든다.

## 할 일 — 편마다 `channel/<채널>/줄판독/<id>.json` (스타픽룸 `channel/starpickroom/줄판독/*.json` 과 같은 꼴 + 아래 칸)
```
{"id","dur","title_lines":[{"text","colors":[{"word","hex"}]}],"source_label",
 "lines":[  ← 화면 자막 덩어리 하나 = 한 행(바뀔 때마다 새 행, 이어 붙이기면 붙은 덩어리를 새 행으로)
   {"t0","t1","speaker":"나레|원음:<이름>|원음|제3자|불명","text":"화면 글 그대로","layer":"채널|원본박힘",
    "enter":"pop|cut|fade|typing|append|기타(설명)",   ← pop=작게→크게 넘쳤다 돌아옴 / cut=첫 프레임부터 완성 / fade=반투명 1~2프레임 / typing=글자씩 / append=앞 글 두고 붙임
    "enter_ms":등장 끝까지 걸린 ms(30fps 띠로, cut 이면 0),
    "variant":"기본|빨강|크게 튀어나옴|기울임|기타(설명)",   ← 그 채널 기본 자막 모양과 다른 변형이면 적는다
    "emph":[{"word","hex"}],                            ← 기본 채움색과 다른 색의 낱말(없으면 [])
    "sticker":[{"what":"💎|♥|강조선|빨간원+화살표|ㅋㅋㅋ|댓글카드|제품누끼|기타","t_in","t_out","x","y","w","anim"}],
    "sfx":{"kind":"휙|띵|뽁|탄성|기타","t":초,"basis":"뜯기 후보|파형 솟음|둘다"} 또는 null,
    "cut_at":[이 덩어리 안 컷 시각], "scene":"얼굴|손·제품 근접|화보|기타", "y":[y0,y1], "fill_hex", "notes"}],
 "no_caption":[[t0,t1],…],   ← 채널 자막이 없는 구간(0.3초 이상)
 "beats":"훅(0~?초 무엇) → … → 끝(무엇)", "narr_share":"나레 덩어리/전체, 나레 초/전체", "notes":["확인 못 한 것"]}
```
- 덩어리가 바뀌는 지점마다 원본 프레임을 본다(0.5초 시트만 보지 마라 — 0.1초 띠로 확인). 등장 모양은 30fps 띠로 첫 3~10프레임.
- 색은 확대 크롭에서 픽셀로(cv2 채움 중앙값) hex.
- 나레/원음 = 입 모양·말투(전언 '~다는데요/~라는데')·vtt `>>` 화자 표식·목소리.
- 효과음은 들을 수 없다 → 뜯기 후보 시각 + 파형 솟음(`ffmpeg … astats` 또는 numpy RMS 10ms)이 같이 있으면 '둘다', 하나면 그 근거만. 없으면 null.
- 원본 채널이 박아 둔 자막·스티커는 layer '원본박힘'(글꼴·자리·외곽선이 채널 자막과 다르면).
