# 서버 리모션(고급효과) 설치 — 부트스트랩 절차

고급효과 렌더(`remotion_render.render`)는 서버에 **node + Remotion(node_modules) + 헤드리스 크롬**이
있어야 돈다. 없으면 `_motion_ready()`가 False를 반환하고 `RemotionUnavailable` 예외 →
`/api/produce/fx/render`의 백그라운드 잡이 즉시 실패하며 **포인트를 환불**한다(그레이스풀).
즉 미설치 서버에서도 기본 꾸미기·믹스는 정상이고, 고급효과만 "사용 불가"로 안전 실패한다.

## 1회 부트스트랩 (shopping-shorts 서버, `ubuntu@3.39.179.148`)

```bash
cd /home/ubuntu/lotto-stock-wiki/shopping_shorts/motion
node -v            # 없으면 nodesource로 node 20+ 설치
npm ci             # package-lock.json 기준 정확 설치(수백 MB)
```

- **최초 렌더 시** `@remotion/renderer`가 chrome-headless-shell을 자동 다운로드한다(수백 MB).
  `/home` 용량을 미리 확인(`df -h /home`). 헤드리스 크롬 실행에 필요한 시스템 라이브러리가
  없으면(예: libnss3, libatk 등) 첫 렌더가 죽으니 `npx remotion browser ensure`로 미리
  받아두고 부족 라이브러리를 apt로 채운다.

## 그레이스풀 확인 (설치 전/후 공통)

- 미설치 상태에서 `/api/produce/fx/render` 호출 → `remotion_render._motion_ready()`가 False →
  백그라운드 잡이 `RemotionUnavailable`로 실패 → `points.refund` 실행 → `fx_status=failed`.
  **500이 아니라 안전 실패 + 환불**인지 확인(라우트는 큐잉만 하고 렌더는 백그라운드).
- 설치 후엔 `_motion_ready()`가 True(테스트 `test_motion_ready_true_in_env`가 이 환경 검증).

## 리모션 프로젝트 위치

`shopping_shorts/motion/` (FullReel 컴포지션 + `src/render-scene.mjs`). `node_modules`는 gitignore라
서버에서 `npm ci`로 각자 설치한다(로컬 트랙 폴더도 마찬가지).

## 배포 주의

- `deploy/auto_deploy.sh`는 `git pull --ff-only`만 한다 — node_modules는 git에 없으므로
  **코드 배포와 별개로 위 부트스트랩을 1회 수동 실행**해야 고급효과가 켜진다.
- 부트스트랩 전까지는 고급효과가 그레이스풀하게 꺼져 있으므로 배포 자체는 막지 않는다.
