A

풀스크린 스텝 위저드 — 한 화면 = 한 단계

단계 전환 시 슬라이드/페이드 애니메이션. 지금처럼 세로로 다 쌓지 않고, 화면 전체를 현재 단계가 씁니다. 상단에 빛나는 진행바 상시 고정.

B

작업대형 — 좌측 재료 레일 고정 + 우측 스테이지 전환

좌측에 재료(영상풀)와 미리보기가 항상 떠 있고(접기 가능), 우측 큰 영역만 단계별로 슬라이드 전환. "재료를 보며 만든다"는 지금 구조의 진화형.

C

세로 스크롤 유지 + 완료 단계 접힘
