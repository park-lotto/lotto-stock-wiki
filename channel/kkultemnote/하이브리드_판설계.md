# 얜샷템 하이브리드 「꿀템노트판」 설계 (2026-10-18, 관제 097)

잇썸홈판·재미썸홈판 옆의 세 번째 판. 정본 구조(`tools/calcopy/hybrid/` README · 정본 `channel/yanshottem/하이브리드_성시경/`)는 **원음 훅 → 우리 나레 제품 이야기**였다.
꿀템노트판은 그 둘을 **한 틀 안에서 번갈아** 놓는다 — 벤치 꿀템노트의 '나레가 묻고 연예인이 답하는 가짜 대화'(스타일분석 §3). 1편 = 성시경 신라면(세 채널 공통 소재).

## 한눈에 — 다른 두 판과 비교
| 축 | 잇썸홈판 | 재미썸홈판 | **꿀템노트판** |
|---|---|---|---|
| 짜임 | H 나레 훅 → 원음 3조각 → 우리 나레 6줄(B1~B6) | 원음 → F1 한마디 → 재미썸홈 틀 | **원음 훅 → (나레 ↔ 원음) ×4 → 원음 끝** |
| 화면 틀 | 앞 얜샷템 틀 / 뒤 전체화면(틀이 바뀜) | 앞 원음 / 뒤 t11 | **처음부터 끝까지 한 틀**(검정 + 2줄 제목 + 1080² 창 + 출처 + 댓글 카드) |
| 나레 결 | 체험담 '~더라고요', 와우 3줄·권위·비유·사회반응 | 이븐쇼핑 결 | **전언·질문 해요체 '~다는데요?'·'~다네요?'·'~가요?'** — 1인칭 체험 없음, 한 줄 1~3초 |
| 길이 | 34초 | ~30초 | **15~22초**(벤치 중앙 16.8, 1편 21.6) |
| 자막 | 얜샷템 Cafe24Ohsquare 노랑 | 이븐쇼핑 | **화자별 2벌**(원음 꾸불림 / 나레 굵은 고딕+노랑) — 자막팩 보강안 |
| 목소리 | 박창수 | 박창수 | **박창수**(벤치 최근 나레 남 f0 119~166Hz — 10-19 신호 재측정: znH 나레 = tc-changsu-stable 1위, 653b·_dz 는 tc-piljae-expressive 1위·changsu 7~8위 → 유지) |
| 소리 | −8.6 LUFS(주인 styles `잇썸홈판.json`, 옛 판 그대로) | −14 | 벤치 실측 −15.3 LUFS(1위 BpU, 8편 중앙 −15.7) / **우리 판 −14 LUFS(주인 styles `꿀템노트판.json` loudness)** · BGM 경쾌 처음~끝(곡·템포 식별 불가) · **효과음 0이 기본**(고립 후보 8편 합쳐 3개, 있어도 자막교체·나레→원음 전환 순간 한 발) |

## 대본 결
- 줄 = 원음 줄(연예인 본인 말, 원본 구간 그대로)과 나레 줄이 번갈아. 나레 4줄 내외·한 줄 10~22자·전체 70~90자, 나레 비중 33~45%.
- 박자: ①원음 훅 0.8~2초(반응·반문 한 마디, 첫 프레임 연예인 얼굴) ②나레 전언 '[인물]도 [행동]한 [제품] [정체]가 있다는데요?' ③원음 증언 ④나레 질문 '대체 ~가요?'/'뭐 때문에 ~가요?' ⑤원음 답(쓰는 법·이유) ⑥나레 정보 '~다네요?' ⑦원음 감탄 ⑧나레 반전·가격·권위 '~지만 ~라는데요?'(숫자 1개 근거 필수) ⑨원음 반전 ⑩원음 끝.
- 어미: '~다는데요?'·'~라는데요?'·'~다네요?'(물음 올림) · 질문 '~가요?' · 끝 정리가 필요하면 '결국 ~했네요'. 반말·1인칭·CTA 없음.
- 권위·숫자는 나레 반전 줄에 한 번(전언). 효능 단정·질병 말 금지(브리프 공통 규칙 그대로).
- 정직 선: 연예인이 말하지 않은 평가를 연예인 입에 넣지 않는다 — 원음에 반대 말이 있으면 반전 박자로 그대로 쓴다(성시경 '1등 할 레시피는 아닌 것 같다·짜파게티를 이길 수 없어').
- ★`script_audit.py` 는 잇썸·재미썸 결 기준이라 이 판엔 맞지 않는다(1편 실측: 79자·4줄로 '줄 수 5~8·150~246자·와우 3줄' 전부 미달 판정). 꿀템노트판 기준(원음/나레 교대·전언 어미·첫 원음 ≤2초·나레 33~45%)은 엔진 요청.

## 틀
- 바탕 검정 · 창 [0,420,1080,1080] · 제목 2줄 SBAggroB 98/112px, y176·287 — 1줄 분홍 #FCB9CE+흰, 2줄 파랑 #0091FD+흰(강조 어절만 색, 사람 이름·결과어 흰) · 출처 '출처 : <원본 채널명>' Pretendard Regular 40px #FAFAFA y1615.
- 제목 문형 = '[원음 반응/가격 훅] + 인물도' / '[행동] + 제품' (1편: '뭐가 맛있겠어? 성시경도 / 따라 한 신라면 레시피').
- 로고: **벤치에 로고 자리가 없다(8/8)** — 규칙 9(바꾸는 건 로고 자리뿐)대로 1편엔 '얜샷템' 을 넣지 않았다. 브랜드 표시가 꼭 필요하면 자리(예: 출처 줄 아래 y1700)를 지휘자가 정한다.
- 댓글 카드(벤치 5/8편): 원본 영상 실제 댓글 1장, 반전 줄부터 끝까지, 아래변 y1505.
- 프리셋 기록: `channel/kkultemnote/preset/검정2줄_분홍파랑_출처/`(8편).

## 자막
`자막팩_보강안.json` 팩 `kkultemnote`: 원음 = speakers.orig(꾸불림 90·흰·검정 테·컷인), 원음 감탄 = orig_pop(popOvershoot), 원음 펀치 = orig_red, 나레 = speakers.narr(굵은 고딕 83·흰+노랑 강조·flashIn). 1편 줄별 표 = `하이브리드_성시경/자막표.json`(초·글·강조·변형).

## 장면
- 원음 줄 = 그 말을 하는 연예인 화면(입 맞춤, ss = 원음 구간 시작). 나레 줄 = 그 말의 장면(제품·조리 과정) 또는 연예인 얼굴.
- 컷 0.8~2.0초(벤치 중앙 1.2) · 하드컷 · 제품 그릇 컷은 느린 확대 1.0→1.08~1.10.
- 원본 편집 자막은 크롭 밖(성시경 원본: 대개 y≥840, '계란 2개'·'짜파게티' 큰 자막 y≈740~).

## 소리
- 원음 그대로(고역통과 90Hz), 나레 구간엔 원음 없음. BGM honwaka_puppu −17dB 처음~끝(끝 0.4초 페이드). 효과음 기본 없음(벤치 1위 0발, 10-19 신호 재측정으로 고립 후보 3개 — 있다면 자막교체·전환 순간 한 발; 제미나이가 들은 휙·띵은 신호로 안 잡혀 근거 아님).
- 마스터: 벤치 실측 −15.3 LUFS / **우리 판 −14 LUFS·TP −1.5(주인 styles `tools/calcopy/hybrid/styles/꿀템노트판.json` loudness)** · 이 문서 작성 때 1편 실측 −15.1 LUFS·최고 −1.6dBFS(판 값과 별개 기록).
