## 여러 편을 한 번에 (우리 PC 방식)
- 편마다 워커 1명(에이전트, 백그라운드)이 1~12단계를 끝까지. 지시문 = `briefs/worker_full_piece.md` + 이 폴더 + 편 정보(인물 키·벤치 URL·판·드라이브 이름·주의).
- 같은 워크트리를 여러 워커가 같이 쓴다 → 커밋은 **경로를 붙인 커밋**으로: `git commit -m "…" -- channel/yanshottem/하이브리드_<키>` (그 경로만 커밋된다 — 남이 staged 해 둔 파일이 섞이지 않는다). `git add` 뒤 그냥 `git commit` 하면 그 사이 다른 워커가 staged 한 파일까지 담긴다(10-21 안문숙 커밋에 고현정 11파일이 섞임 → soft reset 으로 풀었다).
- 부모 세션은 워커 보고를 받으면 드라이브 크기·자동 검사를 **직접** 다시 보고, 멈춘 편은 예비 소재로 채우고, 끝나면 13단계(정리)를 한다.
