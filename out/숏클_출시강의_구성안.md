## 한 줄 주제
**"버튼 8번 누르던 숏템에서, 말 한 줄이면 되는 숏클로."**

## 장치: 오프닝에 한 줄 걸어 두고, 끝날 때 결과를 연다
강의 시작 1분 안에 라이브로 Claude에 한 줄을 넣는다 → 강의가 진행되는 동안 영상이 만들어지고 → 마지막에 완성본을 같이 본다.
처음과 끝이 이어져서 이야기가 닫힌다.

## 0막 · 오프닝 (5분)
| 화면 | 말 | 형식 |
|---|---|---|
| 검은 화면에 커서 깜빡 → 「키치잇 스타일로 하나 만들어줘」 타이핑 | "오늘 강의는 이 한 줄에서 시작합니다" | 모션 |
| (라이브) 실제로 숏클에 한 줄 넣기. 진행 한 줄이 뜬다 | "끝날 때 결과 같이 봅시다" | 시연 ① 시작 |
| 로고 등장: 숏템메이커 → 숏클메이커 | "숏템메이커 후속작, 숏클입니다" | 모션 |

## 1막 · 문제 — 왜 쇼츠는 저장만 하고 못 올리나 (7분)
- 하루 2편이면 한 달 60편. 한 편마다: 소재 찾기 → 원본 찾기 → 자르기 → 자막 → 목소리 → 꾸미기 → 썸네일.
- 모션: 할 일 카드 7장이 쌓이며 시계가 돈다.
- 질문 던지기: "저장해 둔 영상 몇 개, 실제로 올린 건 몇 개입니까?"

## 2막 · 이미 아는 해결책 — 진짜로 다 알려준다 (8분)
제품 이름·화면은 쓰지 않는다. **유형**으로만 설명하고 장점을 먼저 인정한다.
| 유형 | 장점 (인정) |
|---|---|
| 직접 편집 앱 | 내 마음대로, 무료 |
| AI 영상 생성기(글→영상) | 원본 없이 그림이 나온다 |
| 템플릿 자동 편집 | 빠르다, 쉽다 |
| 웹 자동 쇼츠 서비스 (숏템메이커도 여기) | 단계만 따라가면 완성 |
| 외주 편집자 | 손 안 댄다 |

## 3막 · 그 해결책의 한계 (7분)
같은 표에 빨간 줄이 그어지는 모션.
| 유형 | 한계 |
|---|---|
| 직접 편집 | 시간. 하루 2편이 안 된다 |
| AI 생성기 | 실제 제품·연예인 원본이 아니라 신뢰가 안 생긴다 |
| 템플릿 | 100명이 쓰면 100개가 똑같다 |
| 웹 자동 서비스 | 정해진 틀 + 클릭 단계가 많다 + 서버에서 순서를 기다린다 |
| 외주 | 비용, 터진 채널 공식을 모른다 |
→ 정리 한 줄: **"터진 채널의 '틀'은 모르고, 결과물은 다 비슷하다."**

## 4막 · 방향 (4분)
- "터진 채널 하나를 골라 **그 틀 그대로**, 소재만 내 것으로" = 벤치마킹(칼카피).
- 그런데 사람이 하면 매번 판단이 필요하다: 원본이 진짜 그 장면인가, 자막이 목소리와 맞나, 남의 편집본을 쓰진 않았나.
- 모션: 터진 쇼츠 한 편이 해부되는 그림(자막 위치·컷 길이·소리 방식이 표시선으로 분리).

## 5막 · 숏템메이커 1기, 그리고 다음 (6분)
- 숏템메이커: 웹에서 8단계(영상·대본 → 화면 붙이기 → 자막 제거 → 음성 → 꾸미기 → 썸네일 → SEO → 완성).
- 1기 회원 덕분에 배운 것 (숏템을 깎지 않는다 — 1기는 숏템을 그대로 써도 된다).
- 전환 질문: "집 PC에서는 한마디면 영상이 나오는데, 회원님 PC에서도 똑같이 될 수 없을까?" → 숏클의 출발점.

### 숏템 vs 숏클 (비교 슬라이드)
| | 숏템메이커 | 숏클메이커 |
|---|---|---|
| 어디서 만드나 | 우리 서버 | **내 PC** |
| 어떻게 시키나 | 버튼 8단계 | **말 한 줄** ("○○ 스타일로 만들어줘") |
| 누가 판단하나 | 정해진 틀 | **내 Claude가 매 단계 보고 판정** + 서버가 규칙 검사 |
| 틀 | 공용 템플릿 | **터진 채널 벤치마킹 프리셋 24종** |
| 결과 받기 | 웹 | **텔레그램·구글 드라이브로 자동** |
| 준비물 | 로그인 | Claude Max 구독 + 설치 프로그램 |

## 6막 · 숏클메이커 — 강의의 절반 (30분)

### 6-1. 구조 한 장 (모션 핵심, 4분)
세 칸이 고리로 돈다:
**서버 = 노하우(지시서)** → **내 PC = 손(실행기)** → **내 Claude = 눈(판정)** → 다시 서버가 검사, 틀리면 그 단계 다시.
- 노하우는 서버 한 곳에 있어 매일 좋아진다 → 회원은 자동 업데이트로 받는다.
- 화면에는 지금 단계 한 줄만 뜬다 ("장면 맞추기 완료 → 목소리·영상 만들기 중").

### 6-2. 프리셋 = 형식 6가지 (6분, 카드가 펼쳐지는 모션)
| 형식 | 한 줄 |
|---|---|
| 쇼핑형 | 제품 썰을 게시글·스토리 틀로 (인스타스토리·썰쇼핑·썰커뮤니티) |
| 해외원본 | 해외에서 터진 원본 재편집 (나레+원음 / 나레 / 자막+배경음) |
| 연예인쇼핑형 | 연예인 본인 원본 원음 + 나레 + 같은 제품 (후기·대화·체험·가격공개) |
| 연예인레시피형 | 연예인 레시피 원음 + 재료 |
| 여행쇼츠형 | 숙소 쇼츠 한 편 틀 그대로 |
| 인물형 | 인물 썰 (나레 없이 배경음) |
- 신청서에 넣은 이름: 연예인쇼핑 · 해외영상 · 썰쇼핑 · 인스타쇼핑 · 시니어쇼핑 · 여행숙박 · 랭킹형.

### 6-3. 기능 특징 — 이야기 순서대로 (10분)
1. **원본을 찾는다** — 연예인 장면은 본인 채널 원본에서만. 남의 쇼츠를 그대로 쓰지 않는다(출처 규칙).
2. **제품을 맞춘다** — 원본에 상표가 안 보이면 이름을 찾고, 없으면 같은 종류 중 후기 많은 것 + 대본에 그대로 밝힌다.
3. **대본은 내가 사인한다** — 대본이 나오면 회원이 확인·사인해야 다음으로 간다.
4. **장면 맞추기·목소리·렌더** — 주인공은 화면 가운데, 자막과 목소리를 대조.
5. **자동 검사 + 눈 검수** — 검사 6항목과 Claude 눈 검수를 통과해야 완성.
6. **완성본이 폰으로 온다** — 텔레그램(내 봇)·구글 드라이브 '숏템완성본' 폴더.
7. **내 설정 화면** — 프리셋·화면·자막·소리·완성본 탭. 바꾸면 미리보기가 실제 렌더와 같은 그림.
8. **광고 표시** — 모든 영상 오른쪽 위에 '광고'.

### 6-4. 장점 정리 (3분) — 세 단어
- **한 줄**: 버튼 대신 말.
- **내 것**: 내 PC·내 키·내 Claude — 기다리는 줄이 없다.
- **터진 틀**: 실제로 터진 채널 공식 그대로, 그런데 원본·출처는 깨끗하게.

### 6-5. 시연 ②·③ (7분)
- ② 설치 (녹화본): 빈 PC에 설치 → 준비 점검 → 프리셋 고르기. (실측 기록: 가짜 새 PC 설치 132초, 10-20)
- ③ 설정 화면 (라이브): 자막 글꼴·색을 바꾸고 미리보기가 바로 바뀌는 것.

## 7막 · 결과 열기 + 출시 안내 (8분)
1. 오프닝에 걸어 둔 시연 ① 완성본 재생 → 텔레그램에 도착한 화면까지. "한 줄의 결과입니다."
2. 출시: **11월 1일** 서비스 시작 예정.
3. 등급: 기본형 · 고급형 · 프리미엄 (금액은 사장님이 직접 말로 — 슬라이드에 적지 않는다).
4. 1기 회원 특권: 숏템메이커 그대로 / 숏클 기본형 업그레이드 선택, 위 등급은 차액만.
5. 베타 체험단: 우선 10명 · 30일 · 하루 2편, 고급형까지 무료, 조교·인터뷰 가능자 우선 → 신청서 QR.
