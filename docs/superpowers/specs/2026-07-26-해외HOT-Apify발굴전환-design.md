# 해외HOT 발굴 Apify 전환 — 설계 (2026-07-26)

> 선행 설계 `2026-07-24-해외HOT발굴-design.md`(레딧 기반)를 **소스 전환**으로 대체.
> 브레인스토밍 원장: handoff/해외HOT.md 의 "🧠 CN 발굴 설계" 절(2026-07-25 커밋 2f8dff4c7).

## 1. 배경 / 문제

- **현행(라이브)**: 레딧 서브레딧 `rising`+`top` 수집. 실측 저장 80건 중 **76건(95%)이 일반 바이럴 잡탕**
  (만족감/제품 30·신기템/바이럴 46), 정작 꿀템 카테고리(주방·살림·가전)는 **0건**.
- **근본 불일치**: 목표는 "틱톡에서 터지는 영상의 원본 / 터지기 전 선점"인데, 레딧 틈새 서브의
  hot은 그 커뮤니티 최근 잡글일 뿐 — **바이럴 신호(가속)가 없어** 의미없는 영상만 수집됨.
- **무료 probe 결과(2026-07-25 실측)**: 틱톡/CN 해시태그·트렌드 무료 발굴 경로 전부 벽.
  `tiktok:tag` broken · Creative Center `no permission` · douyin/xhs 검색 추출기 없음.
  유일 무료경로 = 시드계정(yt-dlp `tiktok:user`, 조회수·날짜 확인됨)뿐 → 넓은 발굴 불가.
- **결정**: Apify 유료 발굴로 전환. **틱톡 + CN(샤오홍슈·도우인) 함께**. 레딧 접음. 카테고리당 40건.

## 2. 목표

**"안 터졌는데 빨리 오르는" 해외 꿀템 숏폼을 한국 재편집 전에 선점.** 원본(자막없는 깔끔본) 우대.
= **미선점 × 급상승 × 신선도**. (선점=인기가 아니라 가속 문제. 초기 라이징일수록 리포스트·자막이
덜 붙어 자연히 깔끔한 원본 확률↑.)

## 3. 재활용 자산 (90% 이미 존재)

| 부품 | 상태 |
|---|---|
| `apify_client.py` — 토큰 로테이션(최대 30) | ✅ |
| `tiktok_search.search_full()` — 조회수·좋아요·댓글·게시시각·작성자 | ✅ `build_tiktok_items`로 바로 흐름 |
| `douyin_search.search()` · `xiaohongshu_search.search()` | ✅ (단 리치추출 `search_full` 추가 필요) |

| `gap_check.gap_badge()` — 한국 유튜브 검색 선점판정 | ✅ 라이브 |
| `store` 피드/이력(prev_base/prev_delta)·job·폴링·🌍탭 | ✅ |

## 4. 필터 깔때기 (돈 드는 순서 — 과금은 STAGE 0 딱 한 곳)

```
[STAGE 0] 쿼리 (유료) — 카테고리별 플랫폼별 키워드 → maxItems=40
   · 여기서 긁는 40건만 과금. 아래는 전부 무료.
   · ★리스크#1: 액터 날짜/정렬 파라미터로 "최근+라이징"만 긁어야 옛날 대박이 안 섞임.
        ▼
[STAGE 1] 형식 하드컷 (무료) — 재생가능 영상만 · 숏폼만(≤90초) · 죽은링크 제외
        ▼
[STAGE 2] 관련성 게이트 (무료) — 허용어(카테고리 관련어 ≥1) / 차단어(dance·prank·립싱크·경품·계정홍보)
        ▼
[STAGE 3] "안터진+급상승" 랭킹 (무료) — 선택 심장. §5
        ▼
[STAGE 4] 중복제거 (무료) — video_id 단위 (플랫폼내 + 이전 배치와)
        ▼
[STAGE 5] 미선점 게이트 (무료, 쿼터보호) — 랭킹 상위 생존자만 gap_check. §6
        ▼
[STAGE 6] 다운로드·자막제거 (유료/비용) — 사장님이 고른 생존자만. ← Phase 3
```

추정 생존율(미실측): 720 raw → 형식·관련성 20~40% → 안터진·급상승 → 미선점 → 실사용 50~150건.

## 5. "안 터진 + 급상승" 선택 공식 (깔때기 심장)

**정직한 제약**: 진짜 가속(Δ의 Δ)은 같은 영상 2회+ 스냅샷부터 성립. 그래서 첫 스크랩에도 되는
대체 신호를 1차로 쓰고, 배치가 쌓이면 진짜 가속으로 보정한다.

| 신호 | 계산 | 첫 스크랩 | 역할 |
|---|---|---|---|
| **급상승 속도** | 조회수 ÷ 게시후 경과시간(h) | ✅ | 1차 랭킹 |
| **진짜 가속** | 이번 배치 Δ − 직전 배치 Δ (store 이력) | ❌(누적) | 가점, 꺾이면 강등 |
| **안터짐(글로벌)** | 절대조회수 상한 + 신선도(7~14일) | ✅ | 이미 터진 것 제외 |
| **참여율** | 좋아요÷조회수 (계정빨 vs 진짜반응 구분) | ✅ | 품질 가점 |
| **미선점(한국)** | gap_check | ✅ | 국내 선점🔥 |

**좁히는 식** = `급상승 속도 높음` × `게시 7~14일 이내` × `절대조회수 상한 이하` × `한국 미선점`.
이미 조회수 폭발한 "터진 것"은 속도가 꺾였거나 한국 유입돼 자연히 밀려남.

## 6. 검토 보완점 (6건 — 전부 반영)

1. **[🔴치명] 액터 날짜/정렬 제어** — 현 payload는 `searchQueries`만 → 옛날 대박이 40건에 섞임.
   → 액터 날짜필터 지원여부 **소규모 실런으로 확인**, 없으면 과수집 후 클라이언트 날짜컷. (Task 1)
2. **[🔴핵심] "안터진" 상한** — views/hour만으론 이미 터진 대박도 상위. → 절대조회수 상한 +
   2회차 가속 꺾이면 강등. (§5)
3. **[🟠정확] CN 미선점 오작동** — gap_check가 중국어 제목으로 한국 유튜브 검색 → 한글 재편집본
   못 찾아 오판정. → CN은 **제목 한국어 번역**(기존 한중번역 자산) 후 검색. (Task 4)
4. **[🟠쿼터] gap_check 순서** — 720건 다 검색하면 유튜브 무료쿼터 초과. → 깔때기로 좁힌
   **상위 생존자만**(캡 유지) gap_check. (STAGE 5 = STAGE 3 이후)
5. **[🟡품질] 참여율** — views/hour는 대형계정 기본조회수를 급상승으로 오인. → 참여율 가점. (§5)
6. **[🟡언어] 키워드 플랫폼별 언어** — 틱톡=영어, CN=중국어. 시드구조 분리. (Task 2)

## 7. 신규/변경 컴포넌트

- **Task 1 — 실런 검증(선행)**: 틱톡 1카테고리 실 Apify 수집으로 (a)액터 날짜/정렬 파라미터
  (b)반환 필드 (c)관련성·생존율 실측. 결과로 STAGE 0 payload 확정.
- **Task 2 — 시드 재구조화** `overseas_seeds.json`:
  `{카테고리: {"tiktok": [영어kw...], "cn": [중국어kw...]}}`. 레딧 시드 제거(비활성).
- **Task 3 — CN 리치추출** `douyin_search.search_full` / `xiaohongshu_search.search_full`:
  조회수·좋아요·게시시각·숏폼여부 매핑 → `build_tiktok_items` 스키마(도우인은 clockworks 동일).
- **Task 4 — CN 미선점 번역** `gap_check`: CN 항목은 제목 한국어 번역 후 검색(한중번역 자산 재사용).
- **Task 5 — `overseas_hot_jobs` 재작성**: 레딧 대신 3플랫폼 search_full 호출 → 깔때기(STAGE 1~5)
  → store. maxItems=40/카테고리/플랫폼. gap_check는 생존자 캡만.
- **Task 6 — UI 카드 재설계** `index.html`: 제목 없는 표 → 카드 그리드.
  카드 = 큰 썸네일 + **제목** + 조회수 + 플랫폼뱃지 + 🔥선점뱃지 + 속도등급. 클릭→원본재생.
  카테고리 필터 탭 유지. [재편집] 버튼은 Phase 3 훅.

## 8. 비용

- 카테고리당 40 × 6카테고리 × 3플랫폼 ≈ **720 raw/배치** ≈ **$1.2/배치**(틱톡 ~$1.7/1000 기준, 실단가 확인 필요).
- 하루 1회 자동 ≈ $37/월. 무료계정 크레딧($5/월) 내에선 ~주1회.
- **계정/과금 전략(무료1개 vs 유료 Starter vs 로테이션)은 검증 후 별도 결정** — 멀티계정 돌려막기는
  약관위반·취약이라 기본전략에서 제외.

## 9. 단계

- **Phase 1(이 문서)**: 틱톡+CN 수집 → 깔때기 → 안터진+급상승 랭킹 → 미선점 → 카드 UI.
- **Phase 2**: 자막검출 뱃지(소프트), CN 번역 gap_check 고도화, 가속 스냅샷 누적 정착.
- **Phase 3**: 생존자 다운로드 → [재편집] → mix 파이프라인 연결.

## 10. 오픈 리스크 (Task 1 실런으로 검증)

- 틱톡/CN 액터의 날짜·정렬 파라미터 지원 여부 (미지원 시 과수집 비용↑).
- douyin/xhs 반환 필드 실제 스키마(문서 vs 실측 차이 가능).
- CN 관련성·생존율(중국어 키워드가 꿀템을 잘 잡는지).
- gap_check CN 번역 검색의 정확도.
