**볼채널등록** = 회원 개인 채널 즐겨찾기. 2026-09-02 라이브(main `fc0469ae7`).
사이드바가 **⭐볼채널등록 / ⭐볼영상등록** 2칸으로 갈렸다(영상 쪽은 기존 `mix_basket`).

**설계의 핵심은 "전역 수집과 분리"다.** 기존 📌채널수집(`/api/discover/add_by_url`)은
관리자 전용 + 전역 시드라 회원에게 열 수 없다 — 회원 등록 채널이 주기크롤 대상이 되면
채널 수만큼 API 쿼터·Apify 비용·mp4 캐시가 늘어난다(100명×20채널 = 2,000채널 크롤).
그래서 회원용은 **순수 북마크**(`fav_channel` 테이블)로 따로 냈다. **담아도 수집량은
1건도 안 는다.** 용량은 행당 300~500B이라 100명×50채널 = 약 2MB — 디스크는 논외다.

- 인당 상한 **50** / 지표 갱신은 **열 때 1회 + 6시간 캐시**(사장님 확정)
- `_fav_channel_probe`는 유료 API를 안 부른다 — `channel_archive`·`channel_names`만 본다
- 유저스크립트 ⭐볼채널등록 버튼은 `/api/me`의 `is_admin`으로 갈라 띄운다
  (회원에겐 관리자 전용 📌채널수집·⭐레퍼런스등록을 **붙이지 않는다** — 붙였다 지우면 깜빡인다)

**남은 것**: 라이브에서 유저스크립트 버튼 실동작 확인(로컬은 BASE가 운영 도메인 고정이라
못 했다) · 팔로워 수는 아직 안 채워진다(메타 소스 미연결).
