# 볼채널등록 — 개인 채널 즐겨찾기

**2026-09-02 · 라이브 반영 완료** (main `fc0469ae7`)

## 무엇을 / 왜

사장님 요청: 사이드바에 **볼채널등록 / 볼영상등록** 2칸. 개인당 즐겨찾기.
"인스타 화면의 채널수집·레퍼런스등록을 누르면 내 즐겨찾기에 들어가게."

핵심 판단 — **전역 수집과 철저히 분리**한다.
기존 📌채널수집(`/api/discover/add_by_url`)은 `_require_admin` 관리자 전용 +
전역 시드(platform_seeds·discovered_channels)다. 회원에게 그대로 열면
회원이 등록한 채널이 주기크롤 대상이 되어 채널 수만큼 API 쿼터·Apify 비용·
mp4 캐시가 늘어난다(회원 100명×20채널 = 2,000채널 크롤).
→ 회원용 **북마크 갈래를 새로 만들었다**. 담아도 수집량은 1건도 안 는다.

용량: 행당 300~500바이트. 100명×50채널 = 5,000행 ≈ 2MB. 디스크 논외.

## ★실측으로 잡은 함정 (재발 방지)

1. **로그인 판정을 `not cid`로 하면 관리자(cid==0)가 막힌다.**
   `_cid()`는 비로그인도 0을 폴백으로 준다 — 로그인 여부가 아니다.
   정본은 `_verify_session(request.cookies.get("dash_auth"))`의 **None 여부**(`/api/grab`).
   브라우저에서 직접 눌러보고서야 발견했다(TestClient·문법검사로는 안 잡힌다).
2. **`_FREE_EXACT_GET`은 `method=="GET"`일 때만 본다**(app.py:8618).
   POST API를 거기 넣으면 무효 → `_FREE_EXACT_ANY`로 가야 한다.
3. **카드 폭 210px에 버튼 3개면 글자가 줄바꿈으로 깨진다**("원본 열 기").
   `white-space:nowrap` + 라벨 축약.
4. **`channel_archive`에 `taken_at`·`name` 컬럼은 없다**(실측 store.py:655).
   채널 표시명은 `channel_names` 별도 표. 짐작으로 쿼리 쓰면 런타임에 터진다.
5. **두 트랙이 같은 날 LOGIC_VER 20260905를 각각 달아 병합에서 부딪혔다.**
   합친 파일이니 20260906으로 올렸다.
6. **로컬 서버 재시작 시 포트가 안 비면 옛 코드가 계속 돈다** — "고쳤는데 그대로"의
   전형. `grep -c "Started server process"`로 새로 떴는지 확인하고, 안 되면 포트를 바꿔라.

- 메뉴 이름: **나만의 채널등록**(`/fav_channels`) · **영상 즐겨찾기**(`/collection`)
  ★경로·테이블(`fav_channel`)·API·id는 안 바꿨다 — 이름 따라 바꾸면 담긴 데이터와
  유저스크립트가 끊긴다.
- 카드 버튼: [채널 보기] 삭제 → **[채널이동][빼기]** 둘만.
  채널이동 주소는 서버가 정한다(`_fav_channel_home_url`) — 저장된 `url`은
  "담을 때 보던 화면"이라 영상 페이지일 수 있어 채널 홈을 다시 만든다.
- 썸네일: **프로필(avatar) 우선**, 없으면 최근 영상 썸네일, 그것도 없으면 안내문구.

### ★프로필 이미지는 유튜브만 된다 (실측 2026-09-02)

```
yt-dlp -J --no-warnings --playlist-items 0 <채널 홈 URL>
  유튜브   → channel(채널명) · channel_follower_count(구독자) · thumbnails(아바타) 전부 옴. 무료
  인스타   → ERROR: Unable to extract data
  틱톡     → ERROR: Unable to extract secondary user ID
```

그래서 인스타·틱톡은 **종전대로 최근 영상 썸네일**을 쓴다. 프로필을 넣겠다고 유료
크롤(Apify 등)을 붙이지 않는다 — 카드 그림 하나에 과금이 붙는 건 남는 장사가 아니다.
유튜브 조회는 채널당 수십 초라 `refresh` 한 번에 **3개까지만** 갱신한다(나머지는 다음에
열 때 이어서. 6시간 캐시라 몇 번 열면 다 채워진다).

**아바타 고르는 법**: `thumbnails`에는 배너(가로로 긴 것)가 섞여 있다 → **정사각 중
가장 큰 것**만 고른다. 안 그러면 카드에 배너가 들어가 흉해진다.

실측: 유튜브 `@shorts_house` → 채널명·팔로워 6·아바타 표시 / 인스타는 안내문구 폴백.
