## 볼케이노 장단점과 우리가 흡수할 부분

우리 쪽 항목은 메모리 기록 기준이며 현재 코드와 대조한 것이 아니다. 예능픽 1편 기준이고 다른 프리셋에서는 확인하지 못했다.

### 장점
- 작업 고정: 편 폴더마다 팩 sha256 영수증(`.ta-job-receipt.json`) → 어떤 코드로 만든 편인지 증명.

- 재개: 사람 차례에 멈춰 `next_payload.json`을 남기고 `--step <단계>`로 이어감.
- 역할 분리: 소재·장면·자막·보조자막은 Claude, 렌더·검수는 고정 코드.
- 합격 증명: `검증결과.json`에 항목별 참/거짓·사유·실측값. 서버가 다시 판정.
- 합격과 영상의 결합: 재렌더는 새 출력 폴더, 이전 PASS 이관 금지.
- 유료 호출 표시: 나레이션 전 글자 수 고지, 실패 시 자동 재호출 금지.
- 실행 기록: `runtime-report.json`에 단계별 실행 시간·외부 호출·청구 칸.

### 단점
- 소재 검사가 늦음: `start`가 금지 출처(MBC 공식)를 통과시킴. 출처 판단은 Claude 몫이고 렌더 직전 검사 범위는 코드 확인 필요.

- 첫 모델 부담: large-v3 준비 1046초(약 17분).
