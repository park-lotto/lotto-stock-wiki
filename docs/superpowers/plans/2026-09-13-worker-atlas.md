# 워커 관제 탐색 프로토타입 실행 계획

> 실행: executing-plans, 격리된 회사운영플랫폼 트랙. 사용자 2026-09-13 대화 승인 범위.

**목표:** 숏템메이커 내부에서 예시 워커 200개와 프로젝트 30개를 검색·확대·선택하는 작동 검토본.
**구조:** 데이터/고정 배치 모듈, Three.js 인스턴스 장면, DOM 검색·상세 패널을 분리한다. 기존 /hq/와 운영 API는 변경하지 않는다.
**기술:** 기존 Three.js 0.180.0 + esbuild, Node 테스트, 실제 Chromium 검증.

## 설계 기준

- 원본 TzI7KabS8zw의 5/15/27초와 q-PtyF3Rqiw의 5/15/30/45/60초 캡처를 직접 확인했다. 자체 생성 이미지를 원본으로 대체하지 않는다.
- 주요 부서별 경계와 인원 비례 면적, 작은 개별 워커의 일정한 간격, 전체/확대 탐색을 유지한다.
- 기본은 넓은 3D 작업 지도. 벽·지붕으로 가리지 않는다. 단면 층 세계와 외부 B형 캠퍼스는 후속 단계.
- 검색/필터는 위치를 변경하지 않는다. 선택 워커와 참여 프로젝트 관계만 강조한다.
- 200/30은 검토용 고정 예시. 실제 모델·프로세스·크론 연결 없음. 터미널은 예시 로그이며 실행/중단 버튼으로 가동을 가장하지 않는다.
- 3D 자산 최종 품질 승인이 아닌 탐색 검토. 라이브 배포 및 main 병합 제외.
