# 영상 제작소 UI/UX 재설계 — 민트 투톤 · 사용성 정비 (설계서)

- 날짜: 2026-07-19
- 작성: 페이블(설계) / 집행: 오푸스
- 입력: 페이블 UI 리뷰 + 현재 UI 전체 인벤토리(사이드바·전 페이지·produce 7단계 기능지도)
- 사장님 확정: (1) 제작소 재정비 깊이 = **A + 부분 B** (2) 고아 페이지 3개 **숨김 유지** (3) 대본 만들기 **하나로 통합**

---

## 0. 목표 · 원칙

**목표**: 전체 UI를 스탁브레인 **민트 메인 + 화이트/블랙 토글 투톤**으로 통일하고, 60대 사용자가 헤매지 않게 사이드바·제작소의 **정보구조·크기·폰트·사용성**을 정비한다.

**설계 원칙**
1. **민트 하나로 수렴** — 지금 accent 3계열(퍼플·블루·틸)을 `--accent`(민트) 하나로. CTA=민트, 나머지=중립.
2. **토큰만 바꾼다, 마크업은 최소로** — `produce.html`(3,562줄·인라인 style ≈432회)은 여러 세션이 동시 편집하는 hot 파일. 요소를 건드릴수록 머지 충돌이 폭증한다. **재테마는 토큰 정의 교체 + 기계 치환**으로, 구조 개편은 별도 저위험 태스크로 분리.
3. **색이 아니라 형태로도 구분** — 민트≈초록이라 완료(초록)와 accent(민트)가 가까움. 완료=채운 민트+체크, 현재=링+글로우로 **형태 차이**를 준다.
4. **시니어 우선** — 본문 폰트 상향, 잔글씨 정리, "안 눌리는 버튼"은 숨기고 조건 충족 시 등장, "지금 무슨 단계/저장됨" 어포던스 상시 노출.
5. **각 태스크 독립 커밋·게이트·라이브 검증** — 저위험(재테마)부터, 고위험(제작소 구조 정비)은 맨 뒤.

**하지 않을 것 (YAGNI · 사고 방지)**
- 인라인 style 432회 전면 리팩터링(대량 diff = 흡수 사고 재료). 신규/수정 요소만 클래스화.
- 7단계 흐름 자체를 갈아엎기(순서 변경·단계 삭제). 골격은 유지(A).
- 고아 페이지(`find`·`voice_tune`·`mix`)를 사이드바에 노출(숨김 유지, 직접 링크로만 도달).

## 1. 색 시스템 — 민트-블랙 / 화이트-민트 투톤

### 1-1. 토큰 재정의 (다크 = 기본, 민트-블랙)
`produce.html`·`index.html`·기타 페이지의 `:root` 블록을 아래로 교체. **토큰 이름은 유지**하고 값만 바꾸면 `var(--)` 참조 ~211건이 자동으로 따라온다.

```
:root{
  --bg:#0a0f0d;        /* 민트 기 도는 블랙 */
  --panel:#101815;
  --line:#1e2b26;
  --txt:#eaf3f0;
  --sub:#8fa1a0;
  --accent:#37e0bd;    /* 민트 — 퍼플·블루·틸을 전부 이걸로 수렴 */
  --accent2:#1f9e7a;   /* 딥민트 — CTA 그라디언트 짝 */
  --ok:#37e0bd;        /* 완료도 민트(형태로 구분, §1-4) */
  --fire:#ff6b6b;      /* 위험/삭제만 */
  --gold:#f0c453;      /* 뽑기 draft 제목 강조(유지) */
  /* 신규 토큰 (§1-3) */
  --inset:#0c1412;     /* 인풋·textarea·인셋 카드 배경 */
  --sel-bg:linear-gradient(90deg,#123a30,#0c221c);  /* 선택/활성 표면 */
  --sel-fg:#6ff0d6;    /* 선택/활성 텍스트 */
  --grad:linear-gradient(135deg,#6ff0d6,#1f9e7a);   /* CTA·진행 그라디언트 */
  --hover:#131d19;
}
```

### 1-2. 라이트(화이트-민트) — **순수 추가 블록** (기존 규칙 안 건드림)
```
:root[data-theme="light"]{
  --bg:#f4faf7; --panel:#ffffff; --line:#d5e6df;
  --txt:#0f1a16; --sub:#5c726d;
  --accent:#12b886; --accent2:#0ca678; --ok:#12b886;
  --inset:#eef7f3; --sel-bg:linear-gradient(90deg,#d8f2ea,#eafaf5); --sel-fg:#0a7d66;
  --grad:linear-gradient(135deg,#19c9ab,#0a8f79); --hover:#eef7f3;
}
```
- 최초값은 `prefers-color-scheme`로 잡되, 사용자가 토글하면 `data-theme` 명시값이 이긴다.
- `color-scheme` 프로퍼티도 다크/라이트에 맞춰 선언(폼 컨트롤 네이티브 색).

### 1-3. 하드코딩 치환 (기계적 · 우선순위순)
동일 문자열 검색-치환이라 diff가 얇다. `produce.html` + `sidebar.js` + `index.html` 전부 적용.

| 순위 | 리터럴 | 대략 횟수 | → |
|---|---|---|---|
| 🥇 | `#0d1420`, `#0d131c` | 44 | `var(--inset)` |
| 🥈 | `linear-gradient(90deg,#153a6b,#0d2340)` | 4+ | `var(--sel-bg)` |
| 🥈 | 텍스트 `#7db4ff` / `#9dc4ff` | 다수 | `var(--sel-fg)` |
| 🥉 | `.btn-next` 그라디언트 `linear-gradient(90deg,var(--accent2),#8b5cf6)` | 1(클래스) | `var(--grad)` |
| 4 | 고급효과 박스 퍼플(`#1c1436→#0d1420`, 테두리 `#6b4fa0`) | 다수 | `var(--accent2)` 계열 / `var(--inset)` |
| 5 | `#2E7D8A`(fxRender 틸) | 1 | `var(--accent)` |
| 6 | `#0a0e14`·`#0a1017`·`#161d2b` | 5+ | `--bg` / `--hover` |

> `#0d1420`(44회)와 파란 선택 그라디언트가 안 바뀌면 라이트 모드에서 인풋·활성항목만 시커멓게 남아 UI가 깨져 보인다 — **최우선 변환 대상**.

### 1-4. 완료/현재 단계 = 형태로 구분
- 완료 dot: 채운 민트 배경 + 체크(✓).
- 현재 dot: 민트 그라디언트 + **링(box-shadow glow) + 은은한 숨쉬기 애니메이션**.
- 미래 dot: 중립(테두리 `--line`, 숫자 `--sub`).
- `prefers-reduced-motion`에서 애니메이션 정지.

## 2. 타이포 — 시니어 스케일

현재 font-size가 8~22px 애드혹(최다 12px·13px·11px)이라 60대에 잔글씨가 지배적. **타입 스케일을 `:root`에 토큰으로 정의**하고 신규/수정 요소부터 적용, 전역 body 기준을 올린다.

```
--fs-caption:12px; --fs-label:13px; --fs-body:15px; --fs-lead:16px;
--fs-h3:18px; --fs-h2:22px; --fs-step:15px;   /* 단계 라벨 */
body{font-size:var(--fs-body);}   /* 12~13 지배 → 15 상향 */
```
- 단계 라벨 15px + 현재 단계 볼드.
- 폰트 패밀리 유지(`'Malgun Gothic',system-ui,sans-serif`).
- ⚠️ 전면 강제 아님 — body 기준 상향 + 신규/수정 지점부터. 잔글씨(11px) 남발 지점만 정리.

## 3. 사이드바 (`sidebar.js`) — 정보구조 · 크기 · 사용성

골격(3그룹 7항목)은 유지. **토글의 집**이자 전 페이지 공유라 여기에 핵심을 얹는다.

### 3-1. 테마 토글 + FOUC 방지 (전 페이지 획득)
- 사이드바 최하단에 🌙/☀️ 토글 항목 1개. 클릭 시 `data-theme` 토글 + `localStorage('ssTheme')` 저장.
- **FOUC 방지**: 각 페이지 `<head>` 최상단 인라인 스크립트(렌더 전 실행) — `localStorage`값을 `documentElement`에 즉시 반영. (sidebar.js는 body 주입이라 늦으므로, 이 초기화 스니펫만 각 HTML `<head>`에 넣는다. 6페이지 × 3줄.)
- 활성 항목 색: 파랑 `#153a6b→#0d2340` → `var(--sel-bg)`/`var(--sel-fg)`(§1-3).

### 3-2. 크기 · 폰트
- 항목 폰트 13→**14px**, 항목 높이·패딩 키워 터치영역 확대(`padding:10px 12px`).
- 그룹 라벨 11px 유지(민트 tint).
- 브랜드 헤더 14px → 16px, 민트 그라디언트 텍스트.

### 3-3. 작업 연속성 — "내 진행 중 작업"을 전 페이지에
- 현재 `mountWorks()`가 `/produce`에서만 작업목록을 붙임 → **모든 페이지 사이드바에 노출**(같은 `/api/produce/works`).
- 각 작업 행: 제목 + **단계 미니 진행바**(숫자 "3단계" 대신 7칸 중 3칸 채운 민트 바) + 현재 작업 하이라이트(`--sel-bg`).
- `+ 새 작업` 유지.

### 3-4. 고아 페이지
- `find`·`voice_tune`·`mix` = **사이드바 미노출 유지**(사장님 결정). 직접 링크로만 도달. 나중에 필요하면 이 스펙 재개해 "내 도구" 그룹 신설.

## 4. 제작소 (`produce.html`) 기능 재정비 — A + 부분 B

7단계 골격 유지. 인벤토리·페이블이 짚은 **명백한 꼬임만** 정비. 각 항목은 독립 태스크.

### 4-1. ★대본 만들기 3갈래 → 하나의 흐름으로 통합 (핵심)
현재 "확정 대본"을 만드는 경로가 ① 카드 📝뽑기(모달) ② `✍️직접작성` 탭 ③ `🧬믹스` 탭(담긴대본/위키전체 × 1개생성/2개조합 = 2×2)로 **세 군데·네 조합**에 흩어져 있고, `useDraft`가 탭을 자동 전환해 방금 위치를 잃는다.

**통합 설계 — 단일 "대본 만들기" 패널, 3스텝 세로 흐름:**
1. **소스 고르기** (라디오/세그먼트): `내가 직접 쓰기` · `담은 영상에서 뽑기` · `담은 대본으로 믹스`.
   (기존 뽑기 모달·직접 탭·믹스 탭의 진입을 하나의 소스 선택으로 흡수)
2. **방식 고르기** (소스가 뽑기/믹스일 때만 노출): 1개로 새로 쓰기(♻️) / 2개+ 조합(🧬) — 라벨을 **글자로 명확히**("영상 1개로 새 대본" / "영상 2개 조합"). 이모지는 보조.
3. **초안 확정**: 초안 카드(요소 토글 8개 + 업그레이드 유지) → `이 대본 사용` 누르면 **탭 이동 없이** 상단 "확정 대본"에 박히고 그 자리 유지.

- 구현 주의: 기존 함수(`openScriptModal`·`switchMixSource`·`genMix`·`openGenFromWiki`·`mixUpgrade`·`useDraft`) **재사용**하되 진입점을 단일 패널로 재배치. 렌더 경로·저장 키(`STATE.script`·draft_id) 단일 유지, 새 렌더 경로 만들지 말 것.
- 모달 속 모달 제거: 📝뽑기 전면 모달(`#pmModal`)을 이 패널 안 인라인 스텝으로 흡수 → 오버레이 3중 → 1중.

### 4-2. 쓸 수 없는 컨트롤 = 숨김(비활성 노출 금지)
- 2단계 `자막제거 미리보기`(disabled 노출) → 조건(자막제거 ON) 충족 시 **등장**.
- 3단계 `#voiceControls`는 이미 프리셋 선택 후 등장(유지·확장): SEO/썸네일도 "대본 확정 전"엔 stub 대신 **잠금 카드 + 다음 행동 1줄 안내**("① 제작소에서 대본을 확정하면 열립니다").

### 4-3. 단계 점프 게이트 일관화
- dot 자유 점프 유지하되, **미완 단계는 잠금(회색+자물쇠)** — 클릭 시 "먼저 N단계를 마치세요". 게이트 로직(`canGoNext`/`refreshNextBtn`/`vpGateNext`)을 **하나의 판정 함수로 수렴**해 stub 헛걸음 제거.

### 4-4. 4단계(꾸미기) 밀도 정리
- **주경로 = 🎯 완성 스타일 카드**를 크게·위로. `+ 더보기`로 확장.
- `✏️ 직접 다듬기`(4중 중첩 details)는 **한 단계로 평탄화**(details 1겹) + 시각적으로 확실히 낮춤(색·크기). `⭐ 내 프리셋` 중복 언급 정리(한 곳).
- 고급효과(리모션)는 접힘 유지.

### 4-5. 미리보기 위치 통일
- "미리보기"는 **항상 좌측 고정 미러**(9:16). 0단계 `#mixPreview`·4단계 `#hcPreview`가 같은 좌측 슬롯을 쓰도록 위치 규약 통일(마크업 이동 최소, 컨테이너 클래스 공유).

### 4-6. 저장/되돌리기 어포던스
- 상단(단계바 옆)에 **"저장됨 ✓"** 상시 표시(암묵 `saveWork()` 결과를 사용자에게 보임) + **되돌리기** 1버튼(직전 저장 스냅샷 복원). 60대 신뢰감.

## 5. 컴포넌트 원칙

- 전면 리팩터링 금지. **신규/수정 요소만** `.btn`(민트 CTA)·`.btn-ghost`(중립)·`.field`(인풋)·`.card`·`.panel` 클래스로.
- 기존 `.btn-prev/.btn-next/.tab` 유지하되 색만 토큰화(§1-3).
- 인라인 style 위 클래스 덧씌우기 패턴은 신규 지점에서 지양.

## 6. 오푸스 집행 순서 (SDD 태스크 · 저위험 → 고위험)

각 태스크 = 독립 커밋 + finish 게이트 + 라이브 육안. produce.html은 hot이라 **태스크마다 finish 직전 origin/main 재병합** 습관.

| # | 태스크 | 파일 | 위험 | 수용 기준 |
|---|---|---|---|---|
| **T1** | 테마 토글 + FOUC + 사이드바 선택색 토큰화 | `sidebar.js` + 각 HTML `<head>` 3줄 | 낮음 | 아무 페이지서 토글→민트/화이트 즉시 전환·새로고침 유지·깜빡임 없음 |
| **T2** | `:root` 민트 수렴 + `[data-theme=light]` 블록 추가 | 각 페이지 `:root` | 낮음(순수 교체/추가) | 다크=민트블랙, 라이트=화이트민트, 퍼플/블루/틸 사라짐 |
| **T3** | 하드코딩 기계 치환(`#0d1420`→`--inset` 등) | produce/index/sidebar | 낮음(문자 치환) | 라이트 모드서 인풋·활성항목 안 깨짐 |
| **T4** | 타이포 스케일 토큰 + body 상향 | `:root` + 잔글씨 지점 | 낮음 | 본문 15px, 단계 라벨 15px 볼드 |
| **T5** | 단계 헤더 확대(dot 34→52·라벨 볼드·글로우) + 완료/현재 형태 구분 | produce `.step/.steps` CSS | 낮음(CSS 값) | 헤더 커지고 현재 단계 숨쉼, 색약도 형태로 구분 |
| **T6** | 사이드바 크기/폰트 + 작업목록 전 페이지 + 미니 진행바 | `sidebar.js` | 중간 | 모든 페이지서 진행중 작업+미니바 노출 |

## 7. 검증 · 리스크

- **게이트는 HTML/JS 문법·로직을 못 잡는다**(실측 교훈). 각 태스크는 ① node 문법 검사(HTML script 슬라이스) ② node mock-DOM 동작 검사 ③ 라이브 브라우저 육안 3단으로 grounding.
- **produce.html·sidebar.js는 다세션 hot 파일** — 태스크당 diff 최소화, finish 직전 origin/main 재병합, 충돌 시 수동 병합 후 재검증.
- **T9(대본 통합)은 렌더/저장 경로를 새로 만들지 말 것** — 기존 `STATE.script`·draft_id·`synthesize` 단일 경로 유지. 배선 seam(저장위치≠읽기위치) 주의.
- 라이트/다크 **양쪽 다** 각 태스크에서 육안 확인(한쪽만 보면 나머지가 깨짐).
- 되돌릴 수 없는 것 없음 — 각 태스크 독립 커밋이라 문제 시 그 커밋만 되돌림.
