## 애니메이션 패턴 요약

```
카드 입장: spr(f, delay, 22) — 스프링 바운스 (1.25배 오버슈트)
슬라이드인: translateX -50→0px + spr 조합
타이틀: spry(f, 8, 26, 60) — 아래서 위로 스프링 슬라이드
글로우: osc(f, .04, 기준, 진폭) — sin 맥동
텍스트 글로우: filter: drop-shadow(0 0 12px 색상88)
카운터 팝: spr scale 1.25 → 1.0 안착
KGraph 플로팅: sin/cos 진폭 0.030/0.024 (강한 부유)
```
