# 에보링크연결

## 목표

- 영상 제작소 4단계에서 장면별 제작 방식을 정하고, AI 생성 장면만 EvoLink API로 생성한다.
- 유료 호출은 사용자 확인 뒤 시작하며 완료 파일은 만료 전에 프로젝트 폴더에 저장한다.

## 구현

- `dashboard/evolink_api.py`: Bearer 인증, 영상 작업 생성, 상태 조회, 오류 정리, 결과 파일 원자 저장.
- `dashboard/server.py`: 연결 상태, 장면별 생성·조회 API와 완료 영상 자동 자산 등록.
- `dashboard/yt.html`: 직접 촬영/화면 녹화/자료 화면/AI 영상 생성 분류, 모델·길이·화질 선택, 진행률 표시.
- 키는 `EVOLINK_API_KEY` 환경변수 또는 `.env`에서 서버만 읽고 프론트엔드에는 보내지 않는다.

## 검증

- `py -m pytest tests/test_evolink_api.py tests/test_yt_dashboard.py -q` → 15 passed.
- Chrome `http://127.0.0.1:8097/yt`에서 프로젝트 생성 → 대본 장면 분리 → AI 영상 생성 선택 → 모델/길이/화질 UI와 키 대기 상태를 확인했다.
- 실제 유료 생성은 API 키가 아직 없어 실행하지 않았다.
