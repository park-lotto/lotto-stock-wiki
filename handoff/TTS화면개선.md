### 고친 방식 — 순서·폭만. **id는 하나도 안 지웠다**

전 id가 JS에서 실제로 쓰인다(사전에 grep으로 전수 확인: voiceUI·voiceHint·
voiceControls·presetCards·ttsBeats·noVoice·openVoiceTune·speedBtns·silenceBtns·
paceMode·voicePreview 등 11개 + 고급 슬라이더 4개). **하나라도 지우면 기능이 죽는다.**

```
① #ttsBeats(완성본 듣기)  → 맨 위 주인공으로 이동
② 🎙 목소리 바꾸기        → 접힌 채 그 아래 + summary에 지금 성우 표시
③ ⚙ 그 밖 설정            → 자막없이·발음교정을 묶어 첫 화면에서 뺌
④ voiceUI 순서 뒤집기     → [성우카드 | 설정]  (먼저 할 일이 왼쪽)
⑤ ★안내문을 두 칸 위 한 줄로 빼냄
⑥ 대기 화면을 [프레임 | 안내] 2단으로 → 빈 86% 제거
⑦ 44px 터치타깃          → paceMode 19→44, advBoost 20→44, 고급 요약 18→44
```

**★⑤가 핵심 교훈**: ④(좌우 뒤집기)만으로는 **367px 어긋남이 그대로 남았다**(실측).
안내문이 오른쪽 칸 안에 있는 한, 그 칸이 폭 1226px을 잡은 채 높이는 47px뿐이라
420px짜리 성우카드와 계속 어긋난다. **한 줄짜리 안내를 큰 칸에 넣지 마라** —
칸 밖 한 줄로 빼야 두 칸이 각자 내용만큼만 자리를 먹는다.

**★⑥에서 두 벌 방지**: `renderTtsBeats`의 `if(!MIX_JOB)` 분기도 HTML 초기값과
**같은 틀**로 맞췄다. 여기만 옛 모양으로 두면 "처음 열었을 때"와 "함수가 다시 그린 뒤"가
다르게 보인다(0순위-B: 같은 판단 두 벌 금지).

### 신설한 것 — `#curVoiceName` / `syncCurVoiceName()`

접힌 `🎙 목소리 바꾸기` 줄에 **"— 지금: 지민 · 안정"** 을 띄운다. 펼치지 않고도
무슨 성우로 만들어졌는지 알 수 있어야 "뭐부터 할지 모름"이 준다.
이름을 정하는 곳은 **함수 하나**뿐이고 `pickPreset`(고를 때)·`loadTtsBeats`(처음 뜰 때)가
같이 부른다 — 두 군데서 각자 문자열을 만들면 반드시 어긋난다.

## 2026-08-18 (이어서) — 자막제거·TTS 추가 지적 4건

### ★"같은 자막제거 화면"이 사실 **두 개**다 — 혼동 주의

| 요소 | 언제 보이나 | 클래스 |
|---|---|---|
| **LIVE DEMO** | 자막제거를 **돌리기 전** (데모 애니메이션) | `#cleanShowcase .show .dframe` |
| **실제 미리보기** | **돌린 뒤** (진행중/완료) | `.cp-scan` / `.cp-frame` |

처음에 실제 미리보기만 키웠더니 사장님 화면(=데모)은 그대로여서 "이 크기가 맞냐"는
지적이 다시 나왔다. **둘 다 키워야 한다.** 화면 제보를 받으면 어느 쪽인지 먼저 갈라라
— 돌리기 전이면 `.dframe`, 돌린 뒤면 `.cp-frame`.

### 고친 것

| # | 대상 | 전 → 후 |
|---|---|---|
| ① | `.cp-scan`(진행중) | 170×302 고정 → `.cp-frame`과 같은 2칸 틀 |
| ② | `.cp-frame`(완료) | 260px → `min(340px,34vw,34vh)` |
| ③ | `.dframe`(LIVE DEMO) | 124×220(22%) → 240×427(42%), 가운데 빈 폭 456→80px |
| ④ | TTS 완성본 | 220px 검은 썸네일 제거, ▶ 재생버튼 맨 위, 중복 '다음' 제거 |

**★크기를 키울 땐 세로 상한(vh)을 같이 걸어라.** 9:16이라 폭을 키우면 높이가 1.78배로
뛴다 — 폭만 늘리면 화면 밖으로 넘친다. `min(px, vw, vh)` 세 값 중 가장 작은 걸 쓴다.

**★`.demo{flex:1}` 함정**: 칸이 화면을 반씩 나눠 갖는데 프레임엔 `max-width`가 걸려
있으면, 프레임이 **양 끝으로 밀리고 가운데가 텅 빈다**. 칸을 `flex:0 1 auto`로 바꾸고
부모에 `justify-content:center`를 줘야 한다(실측: 가운데 456px 빔 → 80px).

### ⚠️ 남의 stash 2개 (건드리지 않음)

기준선 대조하려고 `git stash`를 썼는데, 변경이 없어 아무것도 저장 안 됐고
`stash pop`이 **다른 세션의 오래된 stash**를 꺼내 `mix_pipeline.py`에 충돌이 났다.
파일은 HEAD로 원상복구했고 stash는 **지우지 않고 그대로 뒀다** — 누구 작업인지 모른다.

```
stash@{0}: 매칭견고화 미커밋 복구본(2026-07-20 raw충돌로 드롭됐던 것)
stash@{1}: raw 크롤데이터 임시보관 (git풀 전)
```

→ **커밋된 상태에서 기준선을 잴 땐 `git stash`를 쓰지 마라.** 저장할 게 없으면
`pop`이 남의 stash를 꺼낸다. 대신 별도 폴더에서 재거나 `git worktree`를 써라.
