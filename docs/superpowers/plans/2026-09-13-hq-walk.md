# 본사 실제 3D 회전·보행 구현 계획

사용자 지시: 만든 건물 공간을 3D로 걸어다니고 둘러볼 수 있게 한다. 기존 A 외관/소재 승인 유지.

**Goal:** v3 Blender 건물을 새 `/hq-walk/`에서 실제 메시로 로드하고 외관 회전과 1인칭 보행을 제공한다.
**Architecture:** `hq_export_walk.py`가 원본을 보존하고 보행용 출입구/슬라이딩 문을 보정해 GLB와 충돌/바닥 JSON을 같은 기하에서 추출한다. 순수 navigation 함수와 WebGL 화면 코드를 분리한다. 기존 렌더 검토 페이지 보존, 진입 링크 추가.
**Tech Stack:** 설치된 Blender4.5.9 glTF exporter, Three0.180 GLTFLoader/OrbitControls, esbuild, Node tests/Puppeteer.

- [ ] 바닥·계단·벽/문 충돌 단위테스트 RED 작성. `hq-navigation.js` 구현 후 GREEN.
- [ ] v3에서 보행용 모델과 콜라이더 내보내기. 숨긴 구모델 제외, 원본 .blend 덮어쓰지 않음. 출입문과 로비-업무실 통로 보정. 나머지 지붕/형태 유지.
- [ ] `/hq-walk/`: 실제 메시, 회전/줌, WASD/화살표/드래그시점 또는 포인터잠금, ESC해제, 터치이동 버튼, 위치바로가기, 주야간, 로딩/오류표시.
- [ ] 렌더 비용을 줄이도록 정적 메시를 재질별 병합. 출입문은 별도 이동. 실시간 광원/재질은 오프라인 렌더와 차이가 있음을 표시.
- [ ] 브라우저 실제 GLB로딩·회전변화·전진·문열림·실내진입·계단·벽차단·위치바로가기·야간·모바일·오류 검증. 화면 직접 확인 후 보정.
- [ ] 기존 렌더 페이지 회귀검사, 읽기전용 코드리뷰, 기록·트랙저장. main 배포 없음.

범위: 정문→로비→1층 양측 공간→중층 계단 보행. 높은 층은 위치바로가기로 방문; 연속된 전층 계단/엘리베이터·워커/업무 실행은 미구현으로 명시한다.
