# 07 손 스크립트 → 판 설정 이관 — 채널마다 `styles/<판>.json` 신설 (표준 §3-1·§3-3 B1 · 02 뒤)

## 목표
판 설정이 없는 프리셋 15개(감사 L1 '판파일' 미달)에 `tools/calcopy/hybrid/styles/<판>.json` 을 만들고, 손 스크립트(33벌) 안의 상수·규칙을 판 칸으로 옮긴다. 공용 렌더러로 **같은 소재 시험편 1편**을 그려 옛 손 스크립트 결과와 프레임 대조. 손 스크립트는 지우지 않고 `_deprecated_2026-10-xx` 표식만.

## 순서(채널 하나)
1. 손 스크립트·설명서·defaults.json·manifest `channel_rules` 를 읽어 **상수 표**를 만든다(값·어디서·근거 편). 근거 없는 값은 `why:"손 스크립트 상수 — 벤치 근거 없음(06 측정 뒤 교체)"` 로 표시.
2. `frame_import.py <frame.json> --kind post|full|window` → 판 `frame` 칸 초안(픽셀 그대로).
3. 판 파일: `name·renderer:bench·bench{ko,channel,analysis,line_reads,src_dir,sfx_events}·voice(판 주인 — 00_공통 표)·cps_target·bgm·loudness(−14/−1.5)·length·timing·frame·caption{pack(없으면 관제 235 에 팩 요청 — 그동안 가장 가까운 팩 + `_pending`)}·cuts·sfx_files·placement{rules,counted(06 뒤 `placement.py count`)}·script{brief,audit,example}` — 숫자 칸마다 `why`/`_from`.
4. 같은 소재 시험편 1편(그 채널 완성편 중 하나의 대본·재료를 render_bench 대본.json 꼴로 옮김 — 머리말 꼴 `title_lines·lines[{kind:tts|orig…}]`) → `run.py <키> render --version <판>` → 옛 완성본과 `kal_analyze framecmp`(0초·중간·끝 3프레임, 자막 띠) + `bench_check`.
5. 손 스크립트 머리말 표식 · README 표 줄 · 커밋(경로 지정).

## 합격 검사(채널마다)
1. `styles.py list` 에 새 판이 뜬다 · `styles.load` 가 `_common` 합쳐 오류 0 · 숫자 칸 why 없는 것 0(`preset_card check` L1 '근거 없음' 0).
2. 시험편 1편 `framecmp` 좌표 ±4px·ΔE<5(틀·자막 띠) — 미달 칸은 판 칸 어디를 고쳐야 하는지 적는다(렌더러가 못 그리는 것이면 02 에 쪽지, 손으로 덧대지 마라).
3. `bench_check`(또는 04 의 gate) 전부 ○.
4. 옛 손 스크립트가 그대로 돌아간다(지운 것 없음 — 머리말 표식만 diff).
5. 사보타주: 판 `frame.title[0].px` 를 2배로 바꾸면 framecmp 가 높이 미달을 낸다(되돌림).
