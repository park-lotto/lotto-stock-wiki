## 전체 흐름

```
① Playwright → 네이버 금융 크롤링
   거래대금 상위 + 상승률 상위 (ETF 전량 제외)
        ↓
② Gemini 2.5 Flash → 테마 4개 자동 분류
   "왜 같이 움직이는가" 기준. 반드시 4개.
        ↓
③ Gemini 2.5 Flash → 테마별 병렬 웹리서치 (4개 동시)
   오늘 오르는 이유 + 주목 종목 2개
        ↓
④ Playwright → 네이버 이미지 검색 (4테마 × 1장)
   테마 관련 실사 이미지 자동 다운로드
        ↓
⑤ HTML 대기보드 생성 → 자동 브라우저 오픈
```

## 내용 규칙

### 테마 분류
- Gemini가 Google 검색으로 오늘 뉴스 확인 후 분류
- 단순 업종(반도체, 조선) X → "젠슨황 방한", "HBM소부장" 같이 구체적 테마명
- 무조건 4개 (종목이 1개뿐이어도 테마로 묶음)
- 정보 없거나 "(정보 없음)" 뜨는 테마 자동 제외

### 이유 텍스트
- **15자 이내**, 한 줄 (넘으면 `...` 처리)
- 날짜·주가·퍼센트 쓰지 않음
- 핵심 키워드만 (인물 + 사건 + 기대감)

### 종목 설명 (키워드 2줄)
- **주가/퍼센트 절대 금지**
- **오늘 뉴스와 직접 연관된 키워드만**
- **10자 이내** 2줄
- 이모지는 변경 가능 (✅ 고정 아님)

### 이미지 규칙
- 네이버 이미지 검색으로 테마 관련 실사 자동 다운로드
- **4장 모두 다른 이미지 (중복 금지)**
- 사람 얼굴/초상권 이미지 제외 → 건물·공장·장치·제품 위주
- 실패 시 picsum 폴백 (테마별 다른 seed)
- 이미지는 `out/images/` 폴더에 캐시 저장 → 재실행 시 재사용

## 폴더 구조

```
out/
├── 장중_섹터흐름_YYYYMMDD_HHMM.html  ← 결과물 (매 실행마다 새 파일)
└── images/
    ├── 테마명1.jpg  ← 네이버 이미지 캐시
    ├── 테마명2.jpg
    ├── 테마명3.jpg
    └── 테마명4.jpg
```

> 이미지 캐시는 같은 날 재실행 시 재사용됩니다.  
> 다음날 새 이미지를 받으려면 `out/images/*.jpg` 삭제 후 실행.

## 자주 쓰는 명령

```bash
# 기본 실행
python 장중섹터흐름.py

# 이미지 캐시 초기화 후 실행 (새 이미지로 새로 받기)
python -c "import pathlib; [f.unlink() for f in pathlib.Path('out/images').glob('*.jpg')]"
python 장중섹터흐름.py

# 이전 결과물 정리 (최신 1개 남기고 삭제)
python -c "
files = sorted(__import__('pathlib').Path('out').glob('장중_섹터흐름_*.html'))
[f.unlink() for f in files[:-1]]
print(f'정리 완료, 유지: {files[-1].name}')
"
```
