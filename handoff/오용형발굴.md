### ★진짜 버그 — 나열과 반전이 같은 사용처를 두 번 말했다

`용도끝 = _last(misuses)`인데 `cases`도 앞에서 3개까지 쓴다. 사용처가 2~3개면 겹친다:

```
misuses 3개 → cases "…고수들은 슬라이딩 신발장까지 심지어 2층 수납함까지 한다는 거"
              twist "근데 미친 사용법은 따로 있었는데 2층 수납함"      ← 같은 말
```

"twist는 cases가 이미 말한 것을 또 말하면 안 된다"는 규칙은 **주석에 적혀 있었는데**
뽑는 방식이 그걸 못 지켰다. 적어두는 것만으로는 안 지켜진다는 사례가 하나 더 늘었다.
실측 분포로 **20편 중 11편(55%)**이 이 구간이었다.

**수리**: `spine_fill._cases_and_last()` — 반전 몫(마지막 1개)을 먼저 떼고 나머지만 나열에 준다.
사용처가 1개뿐이면 반전 몫을 비워 twist를 `missing`으로 넘긴다(겹친 문장보다 낫다).

### 부작용을 같이 처리했다 (이게 더 중요하다)

cases가 쓰는 사례가 하나씩 줄어 **사용처 3개 구간에서 '심지어'가 사라진다.**
`script_gate`의 「고조 심화(1회)」는 대본 전체에서 고조어 **정확히 1회**를 요구하므로
그대로 두면 실측 30% 구간이 통째로 FAIL이었다. 기존 테스트가 이걸 잡아줬다.

→ `tools/spine_add_escalator_variant.py` (멱등): cases에 **2슬롯 고조 변형**을
3슬롯 변형 바로 뒤에 끼운다. `pick_template`은 "슬롯이 다 차는 첫 번째"를 고르니 순서가 우선순위다.

```
사용처 4~5개 → 3슬롯 변형(심지어 1회)      종전 그대로
사용처 3개   → 2슬롯 고조 변형(심지어 1회)  ★이번에 살린 구간
사용처 2개   → 1슬롯 변형(고조어 0회)       종전 그대로
```

**실측 확인**: 3·4·5개 전부 심지어 1회 / 겹침 0 / 두 번 돌려도 멱등. 관련 테스트 456건 통과.
