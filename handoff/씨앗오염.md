### 2. 영상 1건 실패 — 구글 500을 영상 탓으로 래치한다 (미수정)

**로그 실측**:

```
23:37:36  POST .../gemini-3.5-flash:generateContent  HTTP/1.1 500 Internal Server Error
          script_extract: 빈 결과 반환 — ServerError("500 INTERNAL")
23:37:38  WARNING worker prewarm lens_youtube_1h722so: failed_empty
```

다운로드·업로드는 정상이었고 **구글 쪽 일시 장애**였다. 그런데 코드가 이걸
`failed_empty`(= 재료가 안 나옴 = 영상 탓)로 처리해 **래치를 걸었다.**

`KeyPoolExhausted`는 "서버 사정"이라 `autoload_rollback_attempt`로 되돌려주는데
(`prewarm.py:143`), **구글 5xx는 그 분기에 없다.** 같은 성격의 일시 장애인데 한쪽만 구제된다.

**고칠 곳**: `prewarm.py` / `app.py`의 `has_usable_result(result)` 실패 분기 —
`ServerError` 5xx면 `failed_empty`가 아니라 롤백(재시도 기회 보존)해야 한다.

**당장 푸는 법**: 그 영상을 **다시 담으면** `autoload_reset`이 래치를 푼다
(`store.py:2056` 주석 — "다시 담는 행위 = 다시 해보라는 뜻"). SSH 불필요.

**origin/main에 실제로 들어갔는지 직접 대조**해야 한다 — exit 0도 병합 성공을 뜻하지 않는다
(메모리 `reference_슬라이스하네스_window금지`에 이미 있던 함정인데 이날 또 밟았다).
