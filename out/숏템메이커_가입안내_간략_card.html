숏템메이커 시작 안내

아래 순서대로만 하시면 됩니다. 설치는 PC에서 합니다.

1
숏템메이커 가입
구글 계정으로 로그인 → 이름·전화·성별·연령대 입력 → 승인 대기 → 승인되면 이용
2
숏템메이커 유튜브 채널 라이브 시청반드시
채널의 최근 영상 몇 개는 반드시 보고 시작하세요. 사용법과 업데이트 내용을 라이브로 계속 올립니다. 안 보시면 아래 단계에서 막힙니다.
3
API 키 5가지 등록전부 필수
① 제미나이② 유튜브③ SerpApi④ VMake⑤ 일레븐랩스 또는 타입캐스트
각 사이트에서 발급받아 마이페이지 → 🔑 내 키 등록에 저장. 타입캐스트는 API 요금제를 결제해야 됩니다.
4
담기 프로그램 설치반드시
PC 크롬·엣지에서 파일 받아 압축 풀기 → 확장프로그램 화면에서 개발자 모드 켜기 → 압축 푼 폴더를 끌어다 놓기
5
캡컷 연동원하시는 분만
완성본을 캡컷에서 더 다듬을 분만. 바로 받거나 QR로 폰에 보낼 분은 건너뛰세요.
미리 준비: 유튜브 또는 인스타 채널 · 구글 계정 · PC 크롬(또는 엣지)
