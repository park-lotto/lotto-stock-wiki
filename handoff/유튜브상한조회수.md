### ① 신설 3축은 수집 자체가 불가능 (★미해결 — 다음 할 일)

| 층 | 상태 |
|---|---|
| 판정 `categorize.py` | ✅ 8축 정상 |
| 화면 탭 `TOPIC_CTYPE` | ✅ 8축 → 7버튼 매핑 정상 |
| **수집 드롭다운** `index.html:467-470` | ❌ **4개뿐**(홈템·비법형·혼합형·기타) |
| **프리셋 키워드** `youtube_category_presets.py:8-14` | ❌ **3축 키 없음** + 유령 키 `제품형` |

`preset_keywords`는 모르는 키를 조용히 무시한다(`.get(key, [])`). 실행 확인:
```
preset_keywords(['썰쇼핑']) -> []      # 빈 리스트 = 검색어 0개 = 수집 0건, 오류도 안 남
preset_keywords(['장비템']) -> []
preset_keywords(['차량템']) -> []
preset_keywords(['제품형']) -> ['다이소추천','쿠팡추천','주방용품','살림추천템']  # 화면엔 없는 유령 키
```
→ 이 3축은 전용 수집 경로가 없고 시드 채널 훑을 때 우연히 딸려온 것만 들어온다.

**⏭ 다음 할 일**: `CATEGORY_KEYWORDS`에 썰쇼핑·장비템·차량템 키워드 추가 + 드롭다운 4→7개.
⚠️ **키워드를 임의로 정하지 마라** — 사장님이 정하거나, 기존 발굴 데이터(`platform_seeds`
1,974채널 + 각 축 통과 채널의 실제 제목)에서 뽑아 확인받아야 한다.
오용형은 차단어를 채널명에 걸어 정상 채널이 전멸한 전례가 있다(`reference_오용형_판정함정`).
