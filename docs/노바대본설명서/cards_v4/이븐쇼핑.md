# 재미썸홈 (이븐쇼핑 결 · 썰쇼핑)

> 2차 판(cards_v2) · '바이럴이 터지며 논란인' → '난리 난' · 3차: 공통 두 덩어리 공식·'집 안 훤히' 예문 제거, 스타일 틀 고정 낱말 유지, 첫 줄 맨 앞 불편 원인
