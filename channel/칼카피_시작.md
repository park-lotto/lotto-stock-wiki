## 0. 시작 순서 (매번)
1. `py tools/track.py use 칼카피숏템엔진` → 작업은 전부 `.tracks/칼카피숏템엔진` 안에서(관제 카드 **097**, 브랜치 `track/칼카피숏템엔진`).
2. 이 문서 → 아래 '지금 할 일' → 필요한 절만 `handoff/칼카피숏템엔진.md` 에서 찾아 읽기(`py tools/find_work.py <주제>`).
3. `git -C .tracks/칼카피숏템엔진 status --short` — **다른 세션이 같은 폴더에서 작업 중일 수 있다**(10-17 얜샷템 하이브리드). 내 파일만 경로 지정해서 add, `git add -A` 금지.
4. 탭 제목 `py tools/session_title.py set "<하는 일>"`.
5. 끝날 때: 이 문서 고치기(바뀐 사실만) → handoff 일지 몇 줄 → `wiki/log.d/칼카피숏템엔진.md` 1줄 → 커밋 → `git push origin HEAD:track/칼카피숏템엔진`.
   ⚠ **`track.py finish` 금지**(통째 병합하면 `shopping_shorts/` 68파일 — 고객 영상 라인까지 라이브로 간다). 라이브가 필요하면 그 부분만 떼어 새 트랙으로.

## 0-1. ★새 규칙 (사장님 2026-10-18 — 세션 켜면 여기부터, 바뀌면 이 자리를 고친다)
1. **현장썰 진행 방식**: 현장썰 영상(핫템리포트·썰풀다 제품 편 등) 하나하나를 **구글 렌즈(한국)·키워드로 조회** → 같은 결의 **한국 채널을 최대한 많이 수집**(조회 상위 채널) → 같은 원본을 쓴 **해외 원본 찾기** → **다르게 각색**해 우리 영상으로. 수집하면 현장썰·나레썰 등 여러 스타일이 섞여 나온다 — 스타일별로 갈라 스타일.json 에 강점 보강.
2. **대량 수집은 가벼운 에이전트(소넷 등)를 여러 개 병렬로** — 씨앗을 나눠 맡기고, 결과는 `channel/스타일분석/현장썰/채널수집/`(seeds.json·lens.json·kw_1~3.json)에 모아 합친다.
3. **구글 렌즈 = 숏템메이커 렌즈 기능(SerpApi 키)을 쓴다** — `shopping_shorts/lens_discover.py:search_similar_videos`(이미지는 유튜브 썸네일 `i.ytimg.com/vi/<id>/hq720.jpg` 그대로, 로컬은 `upload_frame`). 키는 **서버 `/etc/shopping-shorts.env` 에만** 있어 서버에서 읽기 전용으로 돌린다(서버 저장소 파일 수정·git add 금지). 유료 — 편당 1회·한국 로케일만, 호출 수 기록.
4. **제미나이 키 = 공용 풀** — `py tools/calcopy/pull_pool_keys.py`(서버 사장님 키+회원 공용 풀을 .env 로, 10-18 실측 161개). 키가 적게 보이면(42개 등) 이것부터 돌린다. 버텍스는 여전히 금지.
5. **샤크탱크(해외쇼츠 @foreignshowshow, 브랜드 샥탬스토리)는 다른 세션이 독자적으로 한다** — 이 세션의 수집·분석 씨앗에서 뺀다. 그쪽이 낸 강점은 스타일.json 에 있으면 그대로 둔다.
6. 관리 페이지 이름은 **숏템프리셋**('칼카피'라고 부르지 않음). 장부 바꾸면 §10 반영 규칙.
7. **같이 일하는 세션끼리 공유·피드백을 계속한다** — 칼카피 일을 하는 세션은 시작할 때 ListAgents 로 칼카피 세션들을 확인하고, 이 문서·장부(브랜드·스타일·결과물)를 바꾸거나 새 사실(강점·결함·결정)을 알면 관련 세션에 SendMessage 로 바로 알린다. 받은 피드백은 이 문서의 해당 자리에 반영(덧붙이기 말고 고치기)하고 보낸 쪽에 반영했다고 회신한다. 같은 파일을 동시에 고치지 않게: 장부 json 은 다시 읽고 자기 항목만 더하고, 남의 트랙 문서는 직접 고치지 말고 그 세션에 요청한다.
8. **뿌리는 하나 = 썰쇼츠**(비하인드·재밌는·흥미로운 이야기). 새 채널을 봐도 새 스타일을 만들지 않는다 — 그 채널의 장점은 `스타일.json` 의 **options**(축: 화면·대본·자막·소리, 근거 편·숫자·출처 채널)로 쌓고, 브랜드엔 `options` 목록으로 단다(§3).
9. **먼저 벤치를 그대로 칼카피 → 그다음 하이브리드**("칼카피를 할 수 있어야 하이브리드로 응용된다"). 그대로 = 조회수 줄·반응 짤 같은 것도 우리 식으로 바꾸지 않는다. 바꾸는 건 로고 자리의 우리 브랜드뿐(벤치 로고와 같은 꼴·자리·크기). 다른 점이 생기면 전부 보고.
10. **프리셋은 기존 방식 그대로**(새 방식 만들지 마라 — `channel/mantem/preset/mt_preset.py`·`annapick/preset/ap_preset.py`·`homedesignnote/preset/hdn_preset.py`): 벤치 6~8편 뜯기 → 자동 설명서(to_frame / 훅+본문은 to_frame_multi) → `_hand/` 손질(실측 근거 notes) → preset_save → CHANNEL_RULES → 하나 빼고 실제 렌더 대조(loo).
11. **판독은 클로드 눈으로**(제미나이 판독 금지, 받아쓰기만 무료 키). 대충 금지 — 장면 시트(0.5초 칸)만 보면 2줄째 덧붙음·짧은 줄을 놓친다(재밌쇼 실측) → **10fps 로 자막 칸·그림 칸 변화를 0.1초 단위로 찾고 바뀌는 지점마다 원본 프레임을 본다**. 인포그래픽·애니메이션은 시작·중간·끝 3프레임 이상.
12. **사람 이름은 화면 글자(자막·이름표·명패)로 확인된 것만** 적는다. 얼굴만 보고 짐작한 이름은 '불명'.
13. **새 채널 분석은 워커(에이전트) 여러 개 병렬** — 채널당 4조 × 5편, 지시문에 `tools/calcopy/담당_공통규칙.md` 읽기·편마다 `channel/<slug>/줄판독/<id>.json`·내 파일 경로만 커밋을 넣는다. 결과를 받으면 핵심 주장(예: 강주은 장면·연예인 결합)은 **내가 프레임을 직접 열어 확인**하고 보고한다.

## 3. 스타일 (주인 `channel/스타일.json` — 채널을 가로지름)
