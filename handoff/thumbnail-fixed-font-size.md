# thumbnail-fixed-font-size

## 완료

- 썸네일 제목 `size`를 문구 길이와 무관한 고정 크기로 변경했다.
- 1080 캔버스 기준 실제 크기는 `1080 × size / 500`이며 미리보기와 저장 PNG 비율은 같다.
- 제목 끝의 불필요한 줄바꿈은 빈 줄로 계산하지 않는다.
- UI에 같은 숫자는 같은 크기라는 안내를 표시한다.
- 관련 테스트 35개 통과 및 로컬 브라우저에서 size 85의 짧은/긴 제목을 직접 확인했다.

## 주의

- 긴 제목은 더 이상 자동 축소되지 않는다. 필요하면 사용자가 줄바꿈 또는 크기 슬라이더로 조절한다.
