## 1. 메모리 반도체 (HBM · SOCAMM · 범용)

### 핵심 구조
- **패러다임 전환**: 범용(Commodity) → 맞춤형(Custom) 메모리 = "메모리의 파운드리화"
- **병목 이동**: GPU 품귀 → HBM 수요 → SOCAMM → 레거시 턴어라운드 순서로 확산

### HBM4 베이스 다이 전쟁 (핵심 기술 포인트)

| 플레이어 | 전략 | 속도 목표 | 리스크 |
|---------|------|---------|--------|
| **SK하이닉스** | TSMC 12nm FinFET 위탁 + 1b D램 코어 | 10Gbps+ 달성 | 원가↑ but 마진 협상력 우위 |
| **삼성전자** | 자체 4nm FinFET + 1c D램 (6세대) | 11.7Gbps 목표 | 오버스펙 원가 부담, 루빈 진입이 목표 |
| **마이크론** | 자체 2D Planar 공정 고수 | 9.2Gbps 한계 | 파운드리 경험 없음 → 공급 지연 |

> **투자 시사점**: HBM4 공급난 = 가격 프리미엄 40~50%. SK하이닉스 공급자 우위 유지

### SOCAMM (차세대 메모리 — 추론 특화)
- 엔비디아 '베라(Vera)' CPU 탑재 예정. LPDDR 수직 적층으로 대역폭 극대화
- 삼성 100억비트 / SK하이닉스 100억비트 / 마이크론 70억비트 분담 예정
- **수혜 밸류체인**: 기판 → 심텍, TLB, 이수페타시스

### 레거시 + eSSD 턴어라운드
- HBM 캐파 쏠림 → 범용 D램 구조적 공급 부족
- 중국 '이구환신' + AI KV Cache 수요 → DDR5·eSSD 폭등
- SK하이닉스 솔리다임(인텔 낸드 인수) → eSSD 점유율 31.3%

## 🔗 꼬리에 꼬리를 물고 — 연쇄 흐름 + 실제 시차 (2026-05-29 업데이트)
> 출처: Q10 Gemini 딥리서치 | 실제 사례 기반 검증

### ① HBM 체인

```
엔비디아 HBM 수요 확정
  → SK하이닉스 (HBM 독점)          [당일]    실사례: NVDA 어닝 당일 +5.0%
      → 한미반도체 (TC본더 독점)     [0~1일]   실사례: 다음날 +8.2%
      → HPSP (고압수소어닐링)        [1~2일]   실사례: 3월 한 달 +15%
      → 심텍 (HBM 기판)             [1~2일]   실사례: 4월 한 달 +10%
      → 피에스케이홀딩스 (PR Strip)  [2~3일]   실사례: 3월 한 달 +12%
      → 코미코 (부품 세정)           [3~5일]   실사례: 4월 한 달 +8%
```

### ② MLCC·기판 체인

```
삼성전기 MLCC 판가 양전환
  → 삼성전기                         [당일]    실사례: 판가전환 당일 +4.5%
      → 심텍 (서버용 고층기판)        [1~2일]   실사례: 다음날 +3.8%
      → 대덕전자 (FC-BGA)            [1~2일]   실사례: 다음날 +4.1%
      → 이수페타시스 (AI서버 PCB)     [1~2일]   실사례: 다음날 +5.2%
      → 코리아써키트                   [2~3일]   실사례: 2월 한 달 +7%

삼성전기 단기 급등 (PBR 부담 구간)
  → 삼화콘덴서 (밸류에이션 갭 플레이)  [수일]   실사례: 5/22 상한가 → 수일 만에 2배
     ※ 공급망 연결이 아닌 "상대 저평가" 플레이. 실적 무관.
```

### ③ 파운드리 체인

```
삼성전자 파운드리 수주 확정
  → 삼성전자                          [당일]   실사례: 테슬라수주 당일 +3.0%
      → 솔브레인 (식각액)             [1~2일]  실사례: 다음날 +4.2%
      → 코미코 (부품 세정)            [2~3일]  실사례: 1월 한 달 +6%
      → 피에스케이 (PR Strip)         [2~3일]  실사례: 1월 한 달 +5%
```

### ④ 소부장 리레이팅 체인 (대형주 TP 상향 이후)

```
대형주 TP 상향 보고서
  → 1차 (핵심 소부장): 한미반도체, 이수페타시스    [당일]   실사례: 5/10 +7.5%
      → 2차 (밸류체인 확장): ISC, 프로텍, 대덕전자 [1~2일]  실사례: 5/11 +5.0%
          → 3차 (소재·전공정): 솔브레인, 주성, 유진테크 [3~5일]
```

### ⑤ 연결이 안 되는 것 — 오해 케이스

| 뉴스 | 반응 없는 종목 | 이유 |
|------|-------------|------|
| HBM 수요 폭증 | 범용 D램 모듈사·레거시 낸드 | HBM ≠ 범용 메모리 시장 |
| 삼성 파운드리 2nm 수주 | 한미반도체·ISC (HBM 후공정) | 파운드리 ≠ 메모리 공정 |
| 삼성전기 MLCC 판가전환 | D램 증착장비사·식각장비사 | MLCC ≠ 웨이퍼 전공정 |

### ⑥ 지금 활성 체인 → 다음 체인

| 체인 | 현재 상태 | 이유 |
|------|---------|------|

## 4. 유리기판 (Glass Substrate)

### 기술 구조

```
유리기판 제조 공정:
원판 유리
  → TGV 레이저 가공 (홀 뚫기)
  → 습식 식각 (홀 정밀화)
  → 메탈라이제이션 (Cu 밀착층)
  → 도금 (컨포멀 or 풀필)
  → CMP (표면 평탄화)
  → AOI/X-ray 검사
  → 회로 형성
```

### 플레이어별 전략

| 기업 | 도금 방식 | 현황 | 문제점 |
|------|---------|------|--------|
| **SKC 앱솔릭스** | 컨포멀(벽면 코팅) | 미국 조지아 공장 | Void 불량 + 세와리 |
| **삼성전기** | 풀필(꽉 채움) | 부산 원패스 라인 | CMP 공정 추가 비용 |

> **세와리 불량**: TGV 레이저 공정의 마이크로 크랙 → 싱귤레이션 시 균열. 핵심 수율 이슈.
> **풀필 방식** 대세화 → CMP 장비 수혜 (케이씨텍 vs 에바라)

### 소부장 밸류체인 전체 매핑

| 공정 | 기업 | 강점 |
|------|------|------|
| TGV 레이저 | 필옵틱스, 아바코, LPKF(독일) | 홀 가공 정밀도 |
| 유리 식각 | 켐트로닉스 (싱글래스 기술) | TGV+식각 턴키 |
| 메탈라이제이션(건식) | 씨엔지하이테크 | 아르곤 개질+스퍼터, 7N 밀착력 |
| 메탈라이제이션(습식) | 와이엠티 YMT | 화학동 기술, 삼성전기 협력 |
| CMP 평탄화 | [[stock_케이씨텍|케이씨텍 (064820)]], 에바라(일본) | 풀필 도금 후 필수 |
| AOI 검사 | HB테크놀로지, 야스(YAS) | SKC 앱솔릭스 레퍼런스 |
| X-ray 검사 | 이노메트리, 세크(SEC) | TGV 홀 내부 투시 |

## 5. 전공정 소재·부품·장비

### 낸드 300단+ 시대 핵심 기술

**극저온 식각(Cryo Etching)**
- 채널 홀 고도화로 기존 식각 한계 → 챔버 -60°C 유지
- 글로벌: 램리서치(미국) vs TEL(일본)
- 수혜 부품사: 에프에스티·유니쌤 (칠러), 티씨케이·하나머티리얼즈 (SiC 링)

**몰리브덴(Mo) 전구체 — 텅스텐 대체**
- 삼성 9세대 낸드(300단+)부터 배선 소재 교체
- **동진쎄미켐** — 미국 m4사와 제휴, 캐니스터 패키징 사업 진출
- 고온(400°C+) 기화 공정, 국산화 초기

**High-K 소재 — 하프늄 특허 만료**
- 2025년 11월 하프늄 전구체 특허 만료 → 진입 장벽 해소
- 기존: 아데카(일본)·SK트리켐 독점
- 진입 후보: **한솔케미칼** (지르코늄 이관 이력), 솔브레인
