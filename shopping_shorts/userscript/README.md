# 인스타 소통 · 댓글 자동채우기 유저스크립트

소통큐(`/outreach.html`)의 **`🔗 열기+댓글채우기`** 버튼과 짝을 이루는 브라우저 유저스크립트.
버튼을 누르면 인스타 게시물이 새 탭으로 열리고, 이 스크립트가 **댓글칸에 미리 만든 댓글을 자동으로 채운다.**
**전송(게시)과 팔로우는 사용자가 직접 클릭한다.**

## 왜 전송·팔로우는 수동인가 (안전 설계)

- 전송·팔로우를 사용자가 진짜로 클릭하면 그 이벤트는 `isTrusted=true`(진짜 사람) → 봇 탐지 회피.
- 댓글칸 자동채우기는 **Ctrl+V 붙여넣기와 행동적으로 동일**(사람도 늘 하는 정상 행동) → 봇 신호 아님.
- 자동화되는 부분이 "텍스트 채우기" 하나뿐이라, **위험이 수동 소통과 사실상 같다.**
- ⚠️ 남는 위험은 수동으로 해도 존재하는 기본 위험뿐: **모르는 계정에 댓글·팔로우를 과다·고속으로** 하면 그 볼륨·패턴이 잡힌다. 하루 소통량은 사람답게 유지할 것.

## 설치

1. 크롬에 **Tampermonkey** 확장 설치 (크롬 웹스토어).
2. Tampermonkey 대시보드 → **Utilities → Import from file**(또는 새 스크립트 만들고 붙여넣기)로
   `insta_fill_comment.user.js` 등록.
   - 또는 파일을 크롬으로 드래그하면 설치 프롬프트가 뜬다(`*.user.js`).
3. 스크립트가 **활성화(ON)** 상태인지 확인.

## 사용

1. 소통큐(`/outreach.html`)에서 카드의 댓글 후보 중 하나를 골라 **복사** 버튼으로 선택.
2. **`🔗 열기+댓글채우기`** 클릭 → 인스타 게시물이 새 탭으로 열림.
3. 잠시 후 하단에 **"✅ 댓글 채워둠 — 확인 후 직접 전송·팔로우 하세요"** 토스트가 뜨고 댓글칸이 채워짐.
4. 내용 확인 후 **직접 전송**, 필요하면 **직접 팔로우**.
5. 소통큐로 돌아가 **`✓ 완료`** 클릭.

## 문제 해결

- **댓글칸이 안 채워짐 / "댓글창을 못 찾음" 토스트**: 인스타가 DOM을 바꿨을 가능성.
  스크립트 상단 `CONFIG.COMMENT_SELECTORS`에 현재 댓글 `textarea`/`contenteditable` 셀렉터를 추가.
  (클립보드에는 이미 복사돼 있으니 그동안은 **Ctrl+V 수동 붙여넣기**로 폴백 가능.)
- **아무 반응 없음**: 게시물/릴스 페이지(`/p/…`, `/reel/…`)에서만 동작. 프로필·피드에선 무동작(정상).
- **새로고침해도 다시 안 채워짐**: 의도된 동작(중복 발사 가드). 다시 채우려면 소통큐 버튼을 다시 누른다.

## 옵션

스크립트 상단 `CONFIG`:

- `HUMANLIKE_TYPING`(기본 `false`): `true`면 한 글자씩 랜덤 딜레이로 타이핑. 사용자가 직접 전송하므로
  기본은 즉시 채우기(붙여넣기와 동일)로 충분하다.
- `WAIT_TIMEOUT_MS`: 댓글창이 늦게 뜰 때 대기 시간.
