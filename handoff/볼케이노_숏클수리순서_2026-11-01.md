## 수리 순서

고친 2건을 회원 길 1편으로 확인한 뒤 진행한다.

1. **숫자 원문 대조(7):** 대본 숫자가 조사 원문에 없으면 반려. 주인 후보 `audit_script`, `SCRIPT_MUST`.
2. **줄어들 때만 고침(8):** 문제 수가 안 줄면 멈춤. 주인 후보 `_tries`.
3. **관리자 멈춤 목록(10):** 저장되는 멈춤 기록을 화면에 표시. 자동 신고 전 단계.
4. **컷 지문(4):** 바뀐 컷만 다시 묻기.
5. **렌더 전 저화질 검수(3), 편별 판 버전 고정(9):** 효과는 크지만 작업도 크다. 3은 완성본과 같은 렌더 코드로 구워야 성립한다.

주인 후보는 넣기 전에 코드에서 다시 확정한다.

**예능픽 완주 뒤 판단:** 순서는 유지한다. 렌더 3회 중 2회가 구운 뒤 실패해 4·3번 근거가 늘었지만, 표본이 1편이고 다른 팩의 기록이다. 1~3번이 작아 먼저 끝내도 뒤로 밀리는 비용이 작다. 4·3번은 함께 설계한다.

## 완주 기록에서 나온 추가 후보

전부 숏클 코드와 대조하지 않았다. 넣기 전에 있는지부터 본다.

| 후보 | 근거 |
|---|---|
| 필수 외부 도구를 시작 때 확인 | AGY 없음을 팩을 받은 뒤 `_make`에서 알려 3개 프리셋이 멈춤 |
| 한글 경로를 시작 때 경고 | 한글 포함 절대경로의 글꼴에서 ffmpeg 비정상 종료. 원인은 기록상 '보인다' 수준 |
| 금지 출처를 소재 시작 때 판정 | 서버 `start`가 금지 출처를 통과시킴 |
| 검사 위반을 한 번에 전부 출력 | 인스타형 `final_check.py` |
| 표지 얼굴·전환을 렌더 전에 판정 | 예능픽 재렌더 2회 |

| 자막 싱크를 실제 음성과 대조 | 볼케이노 `subtitle_sync`는 제출 파일만 보는 자기 비교. 숏클도 같은지 확인 |

## 볼케이노에서도 못 푼 것

- 멈춤은 많다. 예능픽 1편에 멈춤 8회, 렌더 3회.
- 사람 개입이 있었다. 사장님 `!` 입력 또는 권한 모드 변경이 필요했다. 이 차단은 Claude Code 자동 권한 검사이므로 일반 사용자에게 같은 일이 생기는지는 확인 못 했다.
- 읽은 범위에서 소재 중복 방지, 금액 상한, 비하인드 소재 창고를 못 찾았다. 우리가 직접 설계한다.
- 완주는 예능픽 1편뿐이다. 스케치코미디·썰쇼핑·인스타형은 AGY 설치 뒤 사전 점검만 통과했고 실제 제작은 없다. 인스타그램 쇼핑은 소스 영상이 없어 안 만들었다.

## 지킬 것

- 볼케이노 코드는 복사하지 않고 구조만 참고한다. 약관 판단은 사장님 몫이다.
- 개발 폴더에서 볼케이노를 부르지 않는다. `step=feedback` 금지.
- 토큰, 서명값, 계정 이메일을 파일에 옮기지 않는다.
- 트랙 수정은 finish 전까지 고객에게 안 간다. 고객 라이브 배포 규칙은 그대로다.
