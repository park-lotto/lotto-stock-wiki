# 칼카피 영상 제작 순서 — 목차 (2026-10-21, 관제 097)

사장님(10-21): "회사 PC 에서 MCP 로 회원들이 그대로 쓸 수 있게 프로그램을 만들었는데, 영상을 어떤 단계부터 하는지 매우 구체적으로 —
소재 찾고 원본 찾고 그런 것부터. 아주 사소한 것까지." / "지금까지 전 과정이 다 나와 있어서 MCP 를 만드는 과정에 빠지지 않고
단계별로 내가 영상 만드는 것과 똑같이 나오는 거다."

**이 폴더 = 우리가 실제로 영상 한 편을 만드는 순서 그대로.** 세션·워커·숏템MCP(회원 PC 엔진)가 이 순서를 따른다.
- 단계 파일마다: 들어가는 것 → 하는 일(명령 그대로) → 판단 기준 → **멈출 때** → 나오는 것 → 실제로 있었던 사고.
- **규칙 원문(금지선·사장님 결정)은 `channel/칼카피_시작.md` 한 곳**에 있다. 여기서는 그 규칙을 '어느 단계에서 어떻게 지키나'로 적고 절 번호를 단다.
  규칙이 바뀌면 칼카피_시작.md 를 먼저 고치고, 그 규칙이 걸린 단계 파일을 같이 고친다(§7 실시간 공유 — 열린 칼카피 세션에 쪽지).
- 이 순서를 바꾸는 사람(세션)은 **같은 커밋에** 이 폴더를 고친다. 순서가 코드와 어긋나면 문서가 틀린 것 — 코드를 읽고 고친다.
