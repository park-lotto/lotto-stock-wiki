# 캡컷 자막 제거 작업에 전체 원본 동봉

## 문제

- 이윤정 고객의 `1556910737b6` 작업을 실측했다.
- 자막 제거 완성본을 비트별로 나눈 2.6~5.4초 조각만 캡컷에 들어가서 클립 앞뒤를 늘릴 수 없었다.
- 서버에는 20~184초 길이 원본 8개가 그대로 남아 있었다.

## 변경

- 자막 제거 작업은 기존처럼 자막 없는 조각을 타임라인에 사용한다.
- 편집안에서 실제 사용한 긴 원본을 `original_full_<video_id>.mp4` 이름으로 캡컷 미디어 보관함에 추가한다.
- 긴 원본은 타임라인 material에 연결하지 않아 기존 자막 제거 결과와 음성이 바뀌지 않는다.
- 원본 사용 ID 판정은 `capcut_draft.used_video_ids()` 한 곳으로 공용화했다.

## 검증

- `test_capcut_recovers_clean_final_when_path_cleared`에서 API 산출물의 assets/meta에 전체 원본이 있고, draft 타임라인에는 없음을 확인했다.
- 캡컷 관련 회귀 테스트: 88 passed.

## 운영 참고

- 전체 원본에는 원래 박혀 있던 자막이 남아 있을 수 있다. 사용자가 교체 편집할 수 있도록 보관함에만 제공한다.
- 과거에 이미 내려받은 캡컷 프로젝트는 자동 갱신되지 않으므로 다시 `캡컷으로 보내기` 해야 한다.
