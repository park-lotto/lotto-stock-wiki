# 키등록포인트 — handoff

> **소유 트랙**: 키등록포인트 — 이 파일은 이 트랙 세션만 수정한다.
> 트리거: **"키등록포인트 이어서"**

**2026-08-17 (회사PC)** · 트랙 `키등록포인트` / 폴더 `.tracks/키등록포인트`

---

## 목적 (사장님 원문)

> "사용자들 개인페이지만들껀데 필요한 키들 직접받아서 등록하게 하면
>  사용자 아이디에 매칭해서 사용시 우리꺼안쓰게 설정좀 만들어보자"
> "60대 이상은 그런거 못하고 그냥 비용내고 하게 / 알려줘도 못하는사람많음"
> "키등록없으면 포인트 차감방식을 해야해. 어짜피 자막제거 api때문에"

**두 갈래를 다 연다.** 포인트가 기본 통화이고, 키 등록은 포인트를 아끼는 선택지다.
등록을 강요하지 않는다 — 못 하는 사람은 그냥 충전해서 쓴다.

---

## ⚠️ 사장님이 서버에서 해야 할 일 (이거 없으면 키 등록이 안 켜진다)

`/etc/shopping-shorts.env`에 **마스터키 한 줄**을 추가해야 한다:

```
BYOK_MASTER_KEY=<44자 Fernet 키>
```

생성 방법:
```bash
python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

그리고 `sudo systemctl restart shopping-shorts`.

- ⚠️ **이 값을 잃으면 등록된 키를 전부 복호할 수 없다.** 따로 보관할 것
- ⚠️ **git에 커밋하지 마라**
- ⚠️ `cryptography` 패키지가 서버에 필요하다(`pip install cryptography`)
- 키가 없으면 **기능이 꺼진다**(평문 저장으로 폴백하지 않는다). 화면에
  "키 저장이 설정되지 않았습니다"가 뜨고 포인트 탭은 정상 동작한다

| **기존 회원** | **없음**(회원 0명 상태에서 시작) → 처음부터 차감 켜고 출시 |

## ✅ 완료 (Task 1~10)

| # | 내용 | 핵심 |
|---|---|---|
| 1 | `keycrypt.py` | Fernet 암복호·마스킹·지문. **마스터키 없으면 기능 off** |
| 2 | `customer_keys` 테이블 | 사용자별 키를 암호문으로만. 평문 경로는 store 안에만 |
| 3 | `pricing.py` | 단가표. admin 설정 우선. `OP_*` 상수 |
| 4 | `keyroute.py` | **키 선택과 과금 판단을 한 곳에서.** `SVC_*` 상수, 폴백 없음 |
| 5 | `points.py` 확장 | reason 기록(어디에 얼마 썼나), `points_history` |
| 6 | **자막제거 구멍 차단** | 소스 개수만큼 선차감·실패 시 환불 |
| 7 | TTS·유튜브 배선 | `keyroute` 경유로 (호출부에 cid 전파는 후속) |
| 8 | 설정 API 5개 | 평문은 GET으로 절대 안 나감 |
| 9 | `/settings` 화면 | 탭 2개(포인트·키 등록), 민트색, 시니어 타이포 15px |
| 10 | 나머지 차감 배선 | 대본·렌즈·영상제작 8곳 + 일일 상한 10회 |

### 리뷰가 잡아낸 실제 결함 (전부 수정·실측 검증)

| 문제 | 심각도 |
|---|---|
| **포인트 이중차감** — 잔액 10P에 5P 5건 동시 → 3건 성공, **-5P** | **상** |
| 키 검증 상태가 **엉뚱한 키에 박힘** (복호 실패 행이 zip을 밀어냄) | 중 |
| `IntegrityError`를 통째로 "중복"으로 삼킴 (NOT NULL 위반이 둔갑) | 중 |
| 서비스명 오타가 **과금 여부까지 뒤집음** | 중 |
| 복호 실패를 로그 없이 건너뜀 | 중 |
| 단가 설정 오류가 조용히 기본값으로 | 하 |

전부 "조용히 삼켜서 나중에 원인을 못 찾는" 패턴이었다.

## ⏭ 다음 (우선순위 순)

### 1. **키 받는 방법 영상 촬영** (사장님)
화면의 `[▶ 받는 방법 영상]` 버튼이 지금 "영상 준비 중입니다"만 띄운다.
`settings.html`의 `GUIDE_VIDEO` 상수에 URL만 채우면 바로 살아난다.
**서비스별로 하나씩** 필요하다(구글·VMake·ElevenLabs·유튜브).
★이게 "알려줘도 못하는 사람"을 위한 핵심 장치다.

### 2. **영상제작·TTS 실단가 확정**
지금 3P·1P는 **추측값**이다. 마진 0으로 가므로 틀리면 그대로 손해다.
```bash
py tools/usage_report.py            # 영상 1편당 평균
```
실측 후 admin에서 `point_cost_mix`·`point_cost_tts`만 고치면 된다(배포 불필요).

### 3. **초기 지급 포인트 결정**
가입 시 몇 P를 줄지. 지금은 0이라 충전 전엔 아무것도 못 한다.
체험 성격으로 얼마를 줄지 사장님 판단.

### 4. **충전 수단**
지금은 admin 수동 지급만 된다(화면의 [＋ 충전]은 안내만 띄움).
기존 `payments` 테이블은 기간제 구독용이라 포인트 충전용 컬럼이 필요하다.

### 5. **Gemini 키 실사용 전환** (범위에서 뺀 것)
지금은 **저장만 되고 실제 호출엔 안 쓰인다.**
- 이유: `_current_key_and_idx`/`_mark_key_exhausted` 호출부가 **44곳 15개 파일**
- 대부분 크론·배치라 회사 부담 — 사용자 키가 필요 없다
- 소진표시 상태파일이 공유 자산이라 쪼개면 로테이션이 흔들린다
- **선행 필요**: 소진표시를 인덱스 → `key_hash` 기반으로 전환
- 포인트가 이미 비용을 회수하므로 급하지 않다

### 6. **TTS·유튜브 cid 전파**
Task 7은 **키 조달 경로만** keyroute로 모았다. 아무도 `customer_id`를 안 넘겨
기본값 0으로만 불린다 = **아직 사용자 키가 실제로 안 쓰인다.**
`synthesize_line`·`search_shorts` 호출부에 cid를 뚫어야 한다.

⚠️ **그때 반드시 함께 고칠 것**: `mix_pipeline.py:240`
```python
loudnorm=bool(config.ELEVENLABS_API_KEY)
```
이 줄은 "지금 나온 mp3가 진짜 음성이냐 무음 mock이냐"를 판정한다. cid를 뚫는
순간 **틀린다**(사장님 키가 비고 사용자 키만 있으면 진짜 음성인데 False).
`tts._api_key(customer_id)`로 바꿔야 한다. 같은 판단이 두 곳에 적히는 0순위-B 모양.

### 7. 쿠팡 파트너스·Buffer 연동
둘 다 **코드가 아예 없다**(`coupang_partners.py`는 `NotImplementedError`,
Buffer는 전 리포 검색 0건). 연동을 먼저 만든 뒤 3번째 탭을 추가한다.

## 함정 기록

| 함정 | 실제 |
|---|---|
| **포인트 차감은 원자적이어야 한다** | `balance()` 읽고 `points_add()` 쓰면 워커 3개가 같은 잔액을 보고 전부 통과한다. `store.points_try_deduct`가 SQL 한 문장으로 처리한다 |
| **평문 목록과 화면 목록을 zip으로 짝짓지 마라** | 복호 실패 행이 평문 쪽에서만 빠져 밀린다 → 엉뚱한 키에 상태가 박힌다. `get_customer_keys_with_id` 사용 |
| **`BYOK_MASTER_KEY`를 잃으면 끝** | 등록된 키를 전부 복호 불가. 화면엔 보이는데 안 쓰이고 경고 로그만 남는다 |
| **자막제거는 소스 1편당 1콜** | 소스 3개면 1,500원. job당 1회로 계산하면 손해 |
| **부분 실패는 전액 환불이 맞다** | 성공분도 캐시가 안 되므로 재시도해야 한다. 못 쓰는 작업에 청구하는 게 더 나쁘다. 주석에 근거 박아둠 |
| **`prewarm.py`는 과금 대상이 아니다** | 사장님 배치다. `check_and_count`는 있어도 포인트는 안 깎는다 |
| **테스트 DB 격리에 `SHORTS_DB`는 없다** | `monkeypatch.setattr(appmod, "DB_PATH", ...)` 를 써라(`test_paywall_gate.py` 관례) |
| **키 생존 확인에 SDK `models.list` 금지** | 살아있는 키도 전부 실패로 나온다(`comment_gen.py:95` 실측). REST로 확인 |
| **라우트는 클린 URL 루프에 추가** | 수동 `@app.get`을 만들면 `_NOCACHE` 헤더가 빠져 "고쳤는데 캐시로 안 바뀜" 재발 |
