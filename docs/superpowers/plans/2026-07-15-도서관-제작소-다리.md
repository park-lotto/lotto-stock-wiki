# 도서관 → 영상제작소 다리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 도서관(`library.html`)에서 만든 대본을 클릭 한 번으로 영상제작소에 확정 대본으로 꽂아 보내고(구조분석 동반), 원본 영상과 여러 영상 믹스도 같은 경로로 넘긴다.

**Architecture:** 즐겨찾기(`collection.html`)가 이미 쓰는 `sessionStorage` + `location.href='/produce'` 방식을 도서관에 그대로 적용한다. 백엔드는 초안 구조분석 라우트 1개 신설 + `mix_jobs`에 구조 보관 컬럼 1개 추가. 나머지는 전부 기존 것 재사용.

**Tech Stack:** FastAPI(Python), 순수 HTML/JS(단일 파일), SQLite(reference.db), pytest

**설계 근거:** `docs/superpowers/specs/2026-07-15-도서관-제작소-다리-design.md`

## Global Constraints

- **`structure`라는 이름을 재사용하지 마라.** 기존 `structure`(= `edit_plan.build_edit_plan(structure=)` 파라미터, `mix_jobs.structure` 컬럼, `create_mix_job(structure)` 인자)는 **구조분석 dict가 아니라 template/free 모드 플래그(문자열)**다. `edit_plan.py:352`가 `_TEMPLATE_INSTR if structure == "template" else _FREE_INSTR`로 분기한다. 여기 dict를 넣으면 그 분기가 조용히 깨진다. **새 이름만 쓴다: `script_structure`(프론트·sessionStorage·API body), `script_structure_json`(DB 컬럼).**
- **구조분석 실패가 이동을 막으면 안 된다.** `analyze_structure`는 실패·무키 시 `{}`를 반환한다(`structure_analyze.py:90-93`). 그래도 대본은 넘어가야 한다. (2026-07-15 C-1 교훈: 대본을 잃는 게 최악.)
- **`git add -A` 금지.** 동시세션 6개가 같은 워킹트리·같은 `.git` 인덱스를 공유한다. 자기 파일만 stage. 커밋 전 `git status --short`로 남의 hunk 확인. `produce.html`은 모션효과 트랙과 동시편집 중.
- **`.git/hooks/post-commit`이 무조건 `git push`** → 커밋 = 즉시 라이브 배포. **테스트 통과 전 커밋 금지.**
- 브랜치는 항상 `main`(`git branch --show-current`로 확인).
- 테스트 경로는 `shopping_shorts/tests/` (`tests/shopping_shorts/`는 **존재하지 않는 경로**).
- 중복 id 금지(단일파일 HTML). 추가 후 `grep -o 'id="[^"]*"' <파일> | sort | uniq -d`로 스캔.

    def create_mix_job(self, job_id, urls, target_seconds, structure,
                       subtitle_removal=False, given_script=None, script_structure=None):
        """새 믹스 job 생성. 초기 status='downloading'.
        given_script: 영상제작 2단계 — 확정 대본을 그대로 쓸 때(나레이션 자동생성 대신).
        script_structure: 도서관에서 딸려온 대본 구조분석 dict(2026-07-15). 뒷단계가 꺼내 쓸
            스냅샷으로 보관만 한다. ⚠️ 인자 structure(template/free 모드 플래그)와 다른 것."""
        now = datetime.now(timezone.utc).isoformat()
        with self._conn() as c:
            c.execute(
                "INSERT INTO mix_jobs(job_id, urls_json, target_seconds, structure, "
                "status, created_at, updated_at, subtitle_removal, given_script, "
                "script_structure_json) "
                "VALUES(?,?,?,?,?,?,?,?,?,?)",
                (job_id, json.dumps(urls, ensure_ascii=False), target_seconds,
                 structure, "downloading", now, now, 1 if subtitle_removal else 0,
                 given_script or None,
                 json.dumps(script_structure, ensure_ascii=False) if script_structure else None),
            )
```

@app.post("/api/wiki/draft/analyze")
def api_wiki_draft_analyze(body: dict):
    """초안 텍스트 → 구조분석(도서관→제작소 다리, 2026-07-15). body: {script_text}.

    도서관 초안은 요소별 유지/변형으로 만들어져 원본 영상의 구조와 다르다(주변인물을
    '요리 고수 언니'로 바꿔 생성했다면 원본 구조의 주변인물과 어긋남). 그래서 원본
    구조를 재사용하지 않고 초안을 다시 분석한다(사용자 결정).

    구조분석 실패({})해도 200으로 응답한다 — 구조는 있으면 좋은 것이고, 여기서
    막으면 대본 이동 자체가 죽는다."""
    text = (body.get("script_text") or "").strip()
    if not text:
        return JSONResponse(status_code=422, content={"ok": False, "error": "script_text 필요"})
    try:
        structure = analyze_structure(text) or None
    except Exception:  # noqa: BLE001 — 구조분석 실패는 무해(대본은 넘어가야 함)
        structure = None
    return {"ok": True, "structure": structure}
```

```javascript
// 도서관 → 영상제작소 다리(2026-07-15). 즐겨찾기(collection.html)와 같은
// sessionStorage 방식. 구조분석 실패해도 대본은 넘긴다(대본을 잃는 게 최악).
async function goProduce(scriptText, srcItems){
  const payload = (srcItems||[]).map(it=>({
    url: it.url||'', shortcode: it.shortcode||'', name: it.name||'',
    thumbnail: it.thumbnail||'', caption: it.caption||'', useFootage: true
  })).filter(x=>x.url);
  let structure = null;
  if(scriptText && scriptText.trim()){
    try{
      const d = await (await fetch('/api/wiki/draft/analyze',{method:'POST',
        headers:{'Content-Type':'application/json'},
        body: JSON.stringify({script_text: scriptText})})).json();
      structure = d && d.ok ? (d.structure||null) : null;
    }catch(e){ structure = null; }   // 실패해도 이동은 계속
  }
  sessionStorage.setItem('produce_handoff', JSON.stringify(payload));
  if(scriptText) sessionStorage.setItem('produce_script', scriptText);
  if(structure) sessionStorage.setItem('produce_script_struct', JSON.stringify(structure));
  location.href='/produce';
}
```

async function draftToProduce(btn){
  const wrap = btn.closest('.draft');
  const text = (wrap.querySelector('.dtext')||{}).value || '';
  if(!text.trim()){ alert('초안이 비어 있습니다'); return; }
  const withSrc = (wrap.querySelector('.withSrc')||{}).checked;
  const o = btn.textContent; btn.disabled = true; btn.textContent = '⏳ 구조 분석 중…';
  try{
    await goProduce(text, withSrc ? [srcItemOf(wrap)] : []);
  }finally{ btn.disabled = false; btn.textContent = o; }
}
