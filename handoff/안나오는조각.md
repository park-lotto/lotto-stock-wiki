### 1) 담겼는데 화면에 안 나오는 조각 (커밋 `bb0b77971`)
사장님: "아래 조각에서 위쪽으로 이동시키면 저 초가 이상하게 올라간다 / **안보이지만 계속 쌓이는거같은데**"

**원인 — 머리글 초와 썸네일이 서로 다른 것을 세고 있었다**
- 머리글 `have` = `lists[i]` **전부**의 합
- 썸네일 `clips` = `planClips` 결과 → **자막 길이를 채우면 거기서 멈춘다**

→ 자막 길이를 넘겨 담은 조각은 **초에만 더해지고 썸네일이 없어** 보이지도 빼지도 못했다.
   실측 재현: 조각 5개 담으면 보이는 컷 1개, 머리글 `14.5/2.9초`.

**고침(A안)**: 컷에 안 들어간 id를 **흐린 '안 나옴' 카드**로 이어 붙인다.
- 목록의 주인은 `lists[i]` 그대로 — 그리기만 한다(0순위-B)
- 두 번 클릭·체크박스 빼기·다른 칸으로 끌기 전부 **기존 함수 재사용**
- ★같이 고친 것: `.tbcut`을 그대로 세면 컷 수가 부풀어 총 초와 안 맞는다
  → `:not(.unused)`로 세고 안 나오는 개수는 따로 표시

### 2) ★미리보기 정확도 (커밋 `487f73db7`) — 사장님 "그게 핵심"
**부족분 처리가 화면과 서버가 서로 달랐다.**

| | 부족분(`0.7초 모자람`) 처리 |
|---|---|
| 미리보기(옛) | `clips[마지막].dur += 부족분` → **그 화면이 멈춘 듯** |
| 실제 렌더 | 소스 릴의 **남은 실프레임**을 1배속으로 이어 붙임 |

→ 미리보기만 어색하고 결과물은 멀쩡한 **거짓 경고**. 조립 판단 근거가 거짓이면 매번 헷갈린다.

**고침**: 서버의 1·2·3순위를 미리보기에 **그대로 옮겼다**(0순위-B).
1. 마지막 컷을 그 소스의 남은 뒷부분으로 연장(1배속)
2. 담긴 소스들의 '안 튼 뒷부분'을 **앞으로만** 밀며 새 컷(같은 창 되풀이 없음)
3. 실프레임이 아예 없을 때만 마지막 컷을 늘림(=정지)

★**서버가 이미 `src_duration`을 내려주고 있었는데 화면이 안 쓰고 있었다** — 배선만 이었다.

**실측 대조(같은 입력)**: v1[2~3]·v2[4~5], 자막 5초, 원본 각 30초
→ 서버 `v1 1.0 + v2 4.0` / 미리보기 `v1 1.0 + v2 4.0` **일치**
