# sfx_bench — 채널 효과음을 구간·자막 기준으로 재는 도구 (2026-09-22)

작업 폴더(영상 mp4를 둔 곳)에서 **순서대로** 돌린다. 결과: 이븐쇼핑 12편 → `이븐쇼핑_효과음_규칙_분석.md`(바탕화면).

| 순서 | 스크립트 | 하는 일 |
|---|---|---|
| 0 | (수동) | `yt-dlp`로 mp4 → `ffmpeg`로 wav/ → `py -m demucs -n htdemucs -o sep wav/*.wav` |
| 1 | prep.py, words.py | 컷(ffmpeg scene) + whisper 받아쓰기(단어 시각) → prep.json |
| 2 | nv.py | 목소리 뺀 소리 nv.wav 만들고 **배경음악 유무** 확인 |
| 3 | ev.py | 효과음 사건 검출 → events.json |
| 4 | cl.py | 소리 지문으로 군집 → labels.npy (군집→이름 표는 anchor/agg의 T 사전) |
| 5 | sec.py | 대사로 6구간 자르기(제목훅/떡밥/정체공개/시연/반전/마무리) |
| 6 | agg.py, anchor.py | 구간별 종류·밀도, 구간 경계에 붙는 소리 |
| 7 | cap.py | ★자막 줄 교체 시각 검출(흰 바 세로 70~96 / 180x320 기준) — **채널 바뀌면 칸 위치부터 다시 재라** |
| 8 | align2.py, rule.py, words_at.py | 컷 vs 자막교체 정렬(대조군 포함), 문구별 소리 |
| 9 | best2.py, synth.py, pack.py | 효과음 파일 대조(시간-주파수 지문), 합성, 바탕화면 패키징 |

★함정(실제로 걸린 것):
- cap.py 자막 칸을 처음에 잘못 잡아 영상 가장자리 변화를 셌다 → 반드시 잘라낸 칸을 이미지로 눈 확인
- 파형 상관(xcorr)은 "같은 파일"만 잡는다. 비슷한 소리 고르기엔 best2.py의 지문 점수를 써라
- 윈도우 ffmpeg엔 /c/... 경로가 안 먹는다(cygpath -m), 한글 목록 파일은 encoding="utf-8"

## 효과음팩 만들기 (2026-09-22 추가)
| 순서 | 스크립트 | 하는 일 |
|---|---|---|
| 10 | prof.py (feat.py) | 칸별 이븐쇼핑 기준 범위(타격·길이·음높이·타격수) → prof.json |
| 11 | synth2.py | 둥 합성 변형 |

| 13 | pick.py | 칸별 후보 선정 + 스펙트로그램 격자(★반드시 눈 검수 후 packs.py의 KEEP 수정) |
| 14 | packs.py N | 팩 N개 조합(서로 다른 칸 최대화·같은 원본 금지·이븐쇼핑 음량비) |
| 15 | verify_packs.py | ★최종 파일 재채점 — 자르면서 망가진 후보를 잡는다(실제로 틱D·딸깍F를 여기서 잡음) |

★**분리(demucs) 검출만 믿지 마라** — 2026-09-24 실사고: 완성본 24발 중 17발만 잡혀

demucs가 효과음 일부를 목소리 트랙으로 가져가고, 0.1초 간격 두 발을 하나로 묶은 것이다.
