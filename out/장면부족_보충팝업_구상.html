장면 보충 팝업 — 구상안

3단계에서 장면이 모자란 칸을 채우는 팝업 하나를 만들고, 그 안에 탭 두 개(🔎 키워드로 찾기 / ✨ AI로 만들기)를 둡니다. 어느 탭으로 채우든 결과는 같은 자리로 갑니다: 필름에 "영상 N" 추가 + 노란 구간 박스 자동 지정.
예시 칸: 4. feature “반죽 부어주고 / 뚜껑 닫아 가열만 해주면 / 노릇하게 구워진다는 거” — 와플 굽는 장면이 3.0초인데 실제로는 4.3초가 필요해서 1.3초가 모자랍니다.

1. 🔎 키워드로 찾기 탭

안 A · 숏템 파워 검색창을 그대로 띄우기

기능 많음무겁다
  • 렌즈·국가·플랫폼 토글까지 다 있음
  • 3단계 위에 큰 창이 하나 더 열려서 60대 회원은 어디서 돌아오는지 헷갈림
  • 결과를 “이 칸”으로 돌려보내는 길을 새로 만들어야 함

안 B · 경량판 (추천)

한 화면기존 API 재사용
  • 검색 엔진은 숏템 파워와 같은 것을 부름(두 벌 금지): /api/lens/kw/expand(비슷한 검색어) · /api/lens/kw/search(인스타·틱톡·유튜브) · /api/lens/cn/search(샤오홍슈·도우인)
  • 화면만 작게: 검색어 칩 → 결과 썸네일 → 고르면 끝
  • “더 자세히 찾기”를 누르면 숏템 파워 본창으로 넘어감(안 A를 탈출구로)
