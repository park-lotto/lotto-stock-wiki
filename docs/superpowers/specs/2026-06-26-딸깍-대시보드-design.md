# 딸깍 대시보드 — 설계 문서 (2026-06-26)

## 목적
내부 도구. 버튼 하나로 AI가 정리한 시장 결과물을 띄운다. 버튼 누르는 장면 자체가 영상 콘텐츠.
구독자용 아님(인증 없음). 나중에 검증되면 스탁브레인(구독자용)에 합칠 수 있음.

## 핵심 통찰
대시보드는 **새 수집기가 아니라 이미 도는 자동화 잡의 산출물을 한 화면에 모으는 표시 레이어**다.
→ 토큰 폭발 방지(수집은 Gemini/Haiku 잡이 분리 수행), 개발 단순화.

## 버튼 3개 (투자자 하루 흐름)
```
🌅 장 시작 전  "오늘 뭐 봐야 해?"     간밤 미국장 + 신호 + 주도섹터 + 주목종목
🔥 장 중       "지금 왜 이래?"        실시간 지수/선물/환율 + 한투 수급/프로그램
🌙 장 마감 후  "오늘 뭐였고 내일은?"   오늘 픽 결과 + 최종 수급 + 내일 일정
```

## 데이터 소스 매핑
| 버튼 | 산출물 | 상태 |
|------|--------|------|
| 🌅 장전 | `output/signal/signal_snapshot.json` (매크로 verdict + 주도섹터 + 종목 9점표 498개) | ✅ 매일 07:55 (수동 검증 완료) |
| | `output/signal/backtest_summary.json` (픽 승률) | ✅ |
| | `out/briefing_YYYYMMDD_미국증시.md` (@futuresnow 간밤 미국장) | ✅ |
| 🔥 장중 | `data/market_data.js` (지수·선물·환율, Yahoo) | ⚠️ 갱신 멈춤(5/24) |
| | 한투 API 실시간(업종등락·거래대금·프로그램·외인기관개인) | 🔴 연결 필요 |
| 🌙 마감 | signal_snapshot 픽 + 최종수급 + 내일일정 | 🟡 일정 파일화 필요 |

## signal_snapshot.json 구조 (장전 핵심)
```
date, generated_at
stage1: verdict(GO/CAUTION/NO), market(%), vix, vix_chg, reasons[], us_sectors, us_strong_sectors
stage2: sectors[], methods{A_교집합:[섹터], B_점수합산:[섹터]}, sortino{섹터:0~100}
stage3: stocks[498]{name, code, sector, vacancy(A/B), rs, flags{빈집,수출,컨센신고가,어닝서프,판가,미국커플링,정책,D30}, score}
```

## 발견된 문제 (별도 후속)
- P1. `signal_snapshot.json` 작업 스케줄러 Ready인데 6/22 이후 안 돌았음 → 잡 점검 필요(설계 외)
- P2. `market_data.js` 5/24 이후 죽음 → 장중 단계에서 한투로 대체
- P3. 09:30 배치가 태이버 아닌 @futuresnow 중복 호출 → 태이버 스크립트 별도 필요(장전 보강)
- P4. 태린이 3종(업종osc·투자자수급·소라Top20) 텔레그램 전용, 파일 안 남음 → JSON 출력 추가(마감 단계)

## MVP 범위 — 단계적 (과거 "한 번에 다 만들다 막힘" 회피)
```
1단계 ★ 🌅 장전 버튼만   데이터 이미 있음. UI(G4)만 필요. 새 수집 0.
2단계   🔥 장중          한투 API 연결(G1)
3단계   🌙 마감          태린이 JSON화(P4) + 일정 파일화
```

## 기술 스택
- 백엔드: FastAPI (로컬, 포트 8090 — 8080은 스탁브레인 점유)
- 프론트: 단일 HTML (검정+골드 테마, 기존 채널 톤)
- 동작: 버튼 클릭 → `/api/morning` 호출 → 백엔드가 파일 읽어 JSON 반환 → 화면 렌더
- 장중만 호출 시점에 한투 실시간 API 호출(2단계)
- 인증 없음(내부 도구)

## 디렉토리

```
dashboard/

```

## 1단계 완료 기준
- `python dashboard/server.py` → localhost:8090 접속
- 🌅 장전 버튼 클릭 → signal_snapshot(verdict·주도섹터·상위 종목 9점표) + 미국증시 브리핑 요약이 한 화면에 렌더
- 데이터 날짜 표시(stale 인지)
