## 1. 유튜브 썰과 갈리는 지점 (같은 표로 비교)

| | 유튜브 썰(노바·이븐쇼핑) | **인스타(메종·홈테리어픽)** |
|---|---|---|
| 화자 | 정체를 감춘 해설자 | **1인칭 나** — 내가 겪은 일 |
| 말투 | 반말 (`~는데`·`~다는 거`) | **존댓말** |
| 대표 어미 | `~다는데` · `~버렸다고` | **`~더라고요` 95~98%** |
| 인물 | 없음 | **지인이 나온다 37~52%** (와이프·엄마·친구·사장님) |
| 마무리 | 남의 말로 닫음(`난리라는데`) | **CTA** `댓글에 'OO' 남겨주세요` 33~42% |
| 권유 | 없음 (no_cta) | **`~세요` 45~47%** |
| 가격 | 떼돈·돈방석(성과로) | **거의 안 씀 2~7%** |
| 감탄 | 천재·미친 | **와·진짜·소리질렀어요 66~69%** |

★**`~더라고요`가 사실상 전부다**(40/42 · 52/53). 이 어미 하나가 인스타 결을 만든다.
 썰의 `~다는데`(남의 말로 돌리기)와 정반대로, **내가 직접 봤다**는 체험 화법이다.

## 4. 이야기 구조 — 썰과 다르다

썰: 훅 → 미끼 → 정체공개 → 고조 → 반전 → 마무리 (**정보 순서**)
인스타: **사건 순서**로 간다.

```
계기      전셋집 이사 왔는데 소파를 벽에 딱 댈 수가 없는 거예요
발견      어느 날 보니까 와이프가 이걸 하나씩 쌓고 있더라고요
정체      실리콘만 바르고 차곡차곡 올리면 끝인데
결과      햇살에 유리가 투명하게 빛나는데 와… 감성 미쳤습니다
반응      오는 사람마다 인테리어 어디서 했냐며 아주 난리예요
```

homterior_pick 1위(272만)는 **공포로 연다**:
```
경고   "나가실 때 원상 복구해 주세요." 전세 살면 이 소리 제일 무섭잖아요
내 일  저도 이번에 그 말 듣자마자 심장 철렁하더라고요
피해   문틀 긁히고 까지고 색도 다 벗겨졌더라고요
비용   이거 수리 맡기면 30만 원은 그냥 깨지죠
해결   우드 크레파스로 슥 문질러주면 끝이고
권유   전세 사시는 분들 이거 미리 챙겨두세요. 멘탈 지켜줍니다.
```

## 5. 그래서 인스타 대본에 넣을 규칙

```
말투      존댓말. 문장 끝은 ~더라고요 / ~거든요 / ~어요 로.
          (썰의 ~다는데·~버렸다고를 쓰면 안 된다)
화자      1인칭 나. 내가 보고 겪은 일로 말한다.
인물      지인(와이프·엄마·친구·사장님)이 있으면 쓴다. 재료에 없으면 억지로 넣지 마라.
여는 법   감탄+내 경험 / 지목 명령 / 인물 등장 / 제3자 소개 — 넷 중 하나.
          정체를 감추지 마라(썰과 반대).
순서      사건 순서: 계기 → 발견 → 정체 → 결과 → 반응
닫는 법   CTA(댓글에 'OO' 남겨주세요) 또는 사람의 반응으로.
가격      거의 쓰지 않는다(2~7%). 재료에 값이 있고 꼭 필요할 때만.
감탄      와 · 진짜 · 소리질렀어요 · 미쳤 — 자주 쓴다(66~69%).
```
