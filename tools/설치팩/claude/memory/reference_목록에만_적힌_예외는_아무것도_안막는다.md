2026-08-30 쇼핑쇼츠 제작소. 사장님 제보 "가림막 만들고 이동할때마다 장면 확대 계속되는데".

`_zoomOnText()`의 예외 셀렉터에 `[data-maskbox]`가 **적혀 있었는데**, 정작 가림막 상자를
만드는 `syncMaskBoxes()`가 그 속성을 **안 붙이고 있었다**. 목록만 있고 표식이 없으니
예외가 통째로 무력 — 상자를 끌고 손을 떼면 pointerup이 스테이지로 올라가 "누른 곳 확대"가
덤으로 돌았다.

**예외 목록과 표식은 짝이다.** 한쪽만 고치면 아무 에러 없이 조용히 안 막힌다.
새 손잡이(드래그 요소)를 만들 때는 표식을 붙였는지 **실제 DOM에서** 확인하라
(`document.querySelectorAll('[data-maskbox]').length`).

## 더 큰 교훈 — 증상 하나 ≠ 뿌리

같은 증상을 두 번 고쳤다:
1. 강조 원(`#hlCircle`)만 예외 목록에 추가 → 원에서는 안 나는데 **가림막에서 또 났다**
2. 진짜 뿌리는 **"미리보기 클릭 = 항상 확대"가 늘 켜져 있다**는 것 →
   [화면을 눌러서 확대] 체크박스로 **기본 꺼짐**으로 바꿔서야 끝났다

"이 요소에서만 막자"가 반복되면 **막는 방식 자체가 틀린 것**이다.
