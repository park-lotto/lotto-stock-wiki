# 브리핑 카드 — 디자인 스펙 & 운영 가이드

> 텔레그램·카카오톡 단톡방 배포용 800px 고정폭 HTML 카드.
> 파일: `out/briefing_{섹터명}.html`

---

## 배포 방법 (확정)

| 방법 | 사용 상황 | 절차 |
|------|---------|------|
| **PNG 캡처** ✅ (추천) | 텔레/카톡 이미지 공유 | 브라우저 F12 → 점 3개 → "전체 페이지 캡처" |
| **PDF 저장** | 문서로 보관 | 인쇄 → "설정 더보기" → **배경 그래픽 ✅ 체크** → 저장 |

## 디자인 토큰 (briefing 전용)

```css
/* 배경 */
--bg:   #070710          /* 카드 기본 — 파란빛 다크 */
--c1:   #0d0d1c          /* 카드 상단 그라데이션 시작 */
--c2:   #0a0a16          /* 중간 */
--c3:   #080810          /* 하단 */

/* body 배경 */
background: #03030c
background-image: 그리드선 (rgba(0,255,208,0.022), 48px × 48px)

/* 카드 글로우 */
box-shadow:
  0 0 60px rgba(0,255,208,0.10),   /* 민트 외부 글로우 */
  0 0 120px rgba(0,255,208,0.04),
  0 60px 120px rgba(0,0,0,0.8),    /* 깊은 드롭쉐도우 */
  inset 0 1px 0 rgba(0,255,208,0.08);  /* 내부 상단 하이라이트 */

/* 상단 글로우라인 (::before) */
background: linear-gradient(90deg, transparent 5%, rgba(0,255,208,0.5) 35%,
  rgba(0,255,208,1) 50%, rgba(0,255,208,0.5) 65%, transparent 95%)

/* 텍스트 계층 */
--t0: #ffffff   /* 종목명, 헤드라인 */
--t1: #cccccc   /* 인사이트 본문 */
--t2: #888888   /* 보조 설명 */
--t3: #444444   /* 날짜, 출처 */
--t4: #252535   /* 구분선, 비활성 */
```

## 섹션별 CSS 클래스 요약

### 헤더
```css
.hdr             — flex, 15px 26px 패딩
.brand           — 11px 900w 5px자간 민트색
.brand-dot       — 7px 원형 민트 도트 (글로우)
.sector-nm       — 16px 800w 흰색
.mood-badge.warn — 레드 배경/테두리, 레드 도트
.mood-badge.bull — 민트 배경/테두리, 민트 도트
```

### 시그널 스트립
```css
.sc.hot  — 민트 배경·테두리·텍스트
.sc.bad  — 레드 배경·테두리·텍스트
.sc.mid  — 옐로 배경·테두리·텍스트 (#FFD600)
.sc.off  — 투명 배경, 회색 텍스트 (미입력)
```

### 리포트 탑픽
```css
.pick-rank.r1  — 민트 원형 번호 (1위)
.pick-rank.r2  — 회색 원형 번호 (2~3위)
.pick-name     — 14px 900w 흰색
.pick-score-num.s1 — 18px 900w 민트 (탑픽)
.pick-score-num.s2 — 18px 900w 옐로 (후보)
.pick-fill.c1  — 민트 그라디언트 + 글로우 바
```

### 테마 카드
```css
.tc.up — 민트 배경·테두리 (강세)
.tc.dn — 레드 배경·테두리 (약세)
/* ::before — 코너 방사형 글로우 */
.tc-dir.up — "▲ 강세" 민트 희미
.tc-dir.dn — "▼ 조정" 레드 희미
```

## 대시보드 vs 브리핑 카드 차이

| 구분 | 대시보드 (`sector_dashboard_`) | 브리핑 카드 (`briefing_`) |
|------|-------------------------------|------------------------|
| 용도 | 내부 분석용, 풀스크린 | 배포용, 공유 이미지 |
| 크기 | 가변폭 (1560px max) | 고정 800px |
| 스크롤 | 있음 (긴 페이지) | 없음 (한 화면) |
| 배포 | 직접 열어서 확인 | PNG 캡처 → 텔레/카톡 |
| 정보량 | 매우 많음 (전체 섹터 분석) | 핵심만 (5~6 섹션) |
