# 장면꾸미기 카나리 전체화면

- 제작소 `6 · 장면꾸미기`의 관리자 카나리에서 LAB 검증표·복사 버튼을 노출하지 않고 40개 템플릿 편집기만 전체 폭/높이로 표시한다.
- `embedded=tab&job=<현재 작업>`일 때 정확한 작업의 격리 복사본을 자동으로 열며, 같은 탭의 새로고침에서는 `sessionStorage`의 LAB ID를 재검증해 재사용한다.
- 기억한 LAB이 없거나 만료됐으면 새 복사본을 만들고, 복사본의 `source_job_id`가 현재 작업과 다르면 편집기를 열지 않는다.
- 독립 관리자 LAB 페이지의 검증표·MP4·CapCut·랜딩 기능은 그대로 유지한다.
- `node --check` 및 카나리/LAB 관련 pytest 9개 통과. 운영 화면 육안 확인 후 완료한다.
