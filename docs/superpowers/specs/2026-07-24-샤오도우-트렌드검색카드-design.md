# 샤오홍슈·도우인 트렌드 검색카드 — 설계

- 날짜: 2026-07-24
- 트랙: 레퍼런스랭킹개편
- 상태: 설계 승인 대기

## 배경·목표

샤오홍슈·도우인은 크롤 자동수집이 불가하고(실측: yt-dlp extractor 없음 / 웹API 406 서명요구 /
익명 브라우저 noteId 0), 유료 크롤(Apify·SerpApi·쿠키)은 사장님 최종 결론으로 안 한다.

대신 **딥링크 우회**: 우리가 이미 무료로 수집한 인스타·틱톡·유튜브 랭킹 상위 영상에서 **소재 키워드**를
뽑아 **중국어로 번역**하고, [원본 대표 썸네일 + 소재 문구] **카드**로 만들어 랭킹 화면 샤오·도우 탭에
**강도순 랭킹**으로 띄운다. 카드 아래 **[🔴샤오홍슈][⚫도우인] 검색 딥링크 버튼**을 붙여 사장님이
직접 눌러 그 소재가 중국에서 어떻게 터졌는지 본다. 지금수집 돌 때마다 자동 갱신 = 실시간 트렌드.
**100% 무료** — 우리는 안 긁고, "뭘 검색하면 터진 게 나오는지"만 트렌드에서 뽑아 카드로 준다.

## 확정 사항 (브레인스토밍 2026-07-24)

| 항목 | 결정 |
|---|---|
| 검색어 소스 | **C) 비전소재(vision_subject) + 제목키워드 둘 다** — 카드마다 여러 버튼 |
| 카드 재료 | **인스·틱·유튜 상위 통합** 랭킹 (3플랫폼 마지막 수집 합침) |
| 강도 정렬 | **조회수 기본**, 없으면 좋아요 보정 (`views ?? likes*가중`) |
| 카드 단위 | **소재별 묶기(중복 제거)** + "N개 영상에서 터짐" 배지 |
| 번역·갱신 | **수집 직후 백그라운드** 번역, DB 캐시. 탭 열 때 대기 0 |
| 기존 렌즈 | **안 건드림** — 샤오·도우 탭에 별개 신규 카드 랭킹 |
| 접근안 | **A) 프론트 조립 + 번역 캐시 API 1개 + 수집직후 백그라운드 번역** |

## 재사용하는 기존 재료 (실존 확인 완료)

- **딥링크 빌더**: `static/index.html:_lensSearchUrl(platform, kw)` (xiaohongshu/douyin URL). JS 재사용.
  백엔드는 `search_links.py:_URL_BUILDERS`.
- **한→중 번역**: `video_analysis.translate_keyword(keyword)` → `{ko,en,zh,ja,ru}` dict, **zh 이미 반환**.
  Gemini 자체(Apify 아님). 키 없으면 ko만 채워 반환(안전).
- **비전 소재태그**: `store.save_vision_tags` / `store.vision_tags_map` (shortcode 캐시, 플랫폼 무관).
  `_attach_vision_tags`가 **랭킹 응답에 `vision_subject`·`vision_keywords`를 이미 실어줌**.
- **플랫폼별 마지막 수집**: `store.load_last_run_platform(platform)` + `GET /api/reference?platform=`.
- **수집 훅**: `api_collect`의 `background_tasks.add_task(_tag_new_items, items)` 옆에 번역 태스크를 붙인다.

## 데이터 흐름

```
[지금 수집] api_collect (기존)
  ├ background: _tag_new_items(items)        # 비전태그 (기존)
  └ background: _translate_new_subjects(items)  # ★신규 — 새 vision_subject/keywords 한→중 번역 → translations 캐시

[샤오·도우 탭 진입] (프론트 JS)
  1. GET /api/reference?platform=instagram|youtube|tiktok  (3회)
       → 각 item: vision_subject, vision_keywords, title, views, likes, thumbnail, platform, url, shortcode
  2. 소재 추출:  카드 검색어 후보 = { 비전소재(vision_subject), 제목키워드(title 정제) }
  3. 소재별 묶기:  정규화 소재키로 그룹핑 (vision_subject 우선, 없으면 제목키워드)
  4. 정렬:  소재 강도 = 그룹 내 max(views ?? likes*가중) → 내림차순
  5. 번역:  각 소재 → GET /api/translate?q= (수집직후 미리 채워져 캐시히트=즉시)
  6. 렌더:  [대표 썸네일 + 한글소재 + 중국어] + [🔴샤오홍슈][⚫도우인] 딥링크(중국어)
           + "N개 영상에서 터짐" 배지 + 대표 플랫폼 뱃지
```

## 컴포넌트

### 1. 백엔드 — 번역 캐시 (신규 최소)

**translations 테이블** (`store.py`):
```
translations(
  ko TEXT PRIMARY KEY,     -- 한국어 소재(정규화 전 원문)
  zh TEXT,                 -- 중국어(빈 문자열이면 번역 실패/키없음 → 재시도 대상)
  updated_at TEXT
)
```
- `store.get_translation(ko) -> zh|None`
- `store.save_translation(ko, zh)`
- `store.translations_map(kos) -> {ko: zh}` (배치 조회)

**GET /api/translate?q=<한국어>** (`app.py`):
- 캐시 히트 → `{ok, ko, zh}` 즉시.
- 미스 → `translate_keyword(q)` 호출 → zh 저장 → 반환. 키 없거나 실패면 `zh=""`로 저장(반복 호출 방지),
  응답 `{ok, ko, zh:""}`. 프론트는 zh 없으면 딥링크에 ko 폴백(중국 검색 정확도 낮지만 버튼은 뜸).
- **비용 가드**: q 길이 제한(예: 40자), 하루 번역 상한(설정값, 비전태그 CAP와 유사). 단순 GET이라 관리자 게이트는 불필요(랭킹 페이지 내부 호출).

**_translate_new_subjects(items)** (`app.py`, 백그라운드):
- items의 vision_subject + (제목키워드 대신 vision_keywords 상위 몇 개)에서 **번역 안 된 것만** 골라
  `_TRANSLATE_CAP`(예: 40)까지 `translate_keyword` 호출 → `save_translation`. 초과분 다음 수집으로 미룸.
- `_tag_new_items` 패턴 그대로. 비전태그가 먼저 채워져야 subject가 생기므로 **번역은 비전태그 다음 수집분부터**
  자연히 따라잡음(1수집 지연 허용 — 트렌드는 회차 누적이라 무방).

### 2. 프론트 — 트렌드 카드 조립·렌더 (`static/index.html`)

- `switchPlatform('xiaohongshu'|'douyin')` 진입 시 `renderTrendCards(platform)` 호출.
- **소재 추출 `_extractSubject(item)`**: vision_subject 우선, 없으면 `_titleKeyword(title)`
  (검색개편 불용어 제거·이모지/해시태그/광고문구 정리 재사용).
- **묶기 `_groupBySubject(items)`**: 정규화키(공백·조사 제거, 소문자) → {subjectKo, items[], platforms:Set, maxScore}.
- **정렬**: maxScore 내림차순. score = `item.views ?? (item.likes*가중)`.
- **번역 조회**: 보이는 카드 소재만 `/api/translate` (캐시히트 즉시). 미번역은 렌더 후 lazy 채움.
- **카드 렌더**: 대표 썸네일(그룹 내 maxScore 아이템) + 한글소재 + 중국어 + 딥링크 버튼
  (`_lensSearchUrl('xiaohongshu'|'douyin', zh||ko)`) + "🔥 N개 영상에서 터짐" + 플랫폼 뱃지들.
- 소재가 하나도 안 나온 초기 상태/빈 결과 → "수집을 돌리면 트렌드 소재가 채워집니다" 안내.

### 3. 딥링크

- `_lensSearchUrl('xiaohongshu', zh)` = `https://www.xiaohongshu.com/search_result?keyword=<중국어>`
- `_lensSearchUrl('douyin', zh)` = `https://www.douyin.com/search/<중국어>`
- `target="_blank" rel="noopener"`.

## 에러 처리

- 번역 실패/키 없음 → zh="" 저장, 딥링크는 ko 폴백. 배너로 "번역 대기 중" 표기(선택).
- 3플랫폼 중 일부 수집 없음 → 있는 것만 합침(빈 배열 무시).
- vision_subject·title 둘 다 없는 아이템 → 소재 추출 불가, 카드에서 제외(조용히 skip).
- `/api/translate` q 과다/상한 초과 → `{ok:false, error}` → 프론트는 ko 폴백 딥링크만.

## YAGNI로 제외

- 백엔드 집계 엔드포인트(접근 B) — 데이터가 이미 프론트로 옴.
- upload_ts 기반 최신성 가중 — 신뢰도 미확정(refs 활동여부에서도 미사용). 조회수 정렬로 충분.
- 샤오·도우 지표 역수집 — CN extractor 없음. 딥링크로만.
- 렌즈 딥링크 한→중 번역 — 이번 범위 밖(사장님 "별개"). 원하면 후속.
