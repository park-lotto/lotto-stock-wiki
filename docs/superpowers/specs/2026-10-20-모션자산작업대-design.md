## 0. 한 줄 정의

**작업대 = 자산이 자라는 곳.** 레퍼런스를 들여오고(수집) → 재고(실측) → 부품으로 만들고(부품화) → 대사 위에 놓아 보고(조립) → 렌더해 보고(렌더) → 사장님이 좋음/별로를 찍는다(판정). 판정·사용 실적이 장부에 쌓여 다음 선택 순위와 검사 기준을 바꾼다. **모델이 배우는 게 아니라 장부·예문·임계값이 자란다.**

## 1. 화면 구성 (`/mograph_bench`, 사이드바 '숏템팩' 묶음 안 '🛠 모션 자산 작업대', 관리자 전용)

```
┌ 필터 띠 ──────────────────────────────────────────────────────────────┐
│ 종류[overlay·scene·transition·caption·preset] 장면유형[훅·상품·숫자·비교·리스트·전환·엔드카드·배경] │

├ 갤러리 ──────────────────────────┬ 상세 ────────────────────────────┤
│ 카드 = 움직이는 미리보기          │ 이름·출처·라이선스·크기·길이         │
│  overlay → 팩 캔버스(poster→clock) │ 변수 표(meta vars) → 바꾸면 미리보기 즉시 │
│  scene   → 같은 출처 iframe,       │ 시간 슬라이더(seek, 결정적 렌더 확인)  │
│            화면에 보일 때만 재생    │ 판정 [좋음][별로] + 이유 태그 + 메모     │
│  preset  → 4초 색·글꼴·대표 부품    │ [렌더] → mp4 · 프레임 시트 · 시간 실측  │
│ 카드 아래 배지: 판정·사용 60일·버전  │ 판정 이력(verdicts[])                   │
├ 조립대(2차) ─────────────────────────────────────────────────────────┤
│ 대사 줄(TTS 타이밍 t0·dur) 가로 띠 ← 부품을 끌어다 놓음 → 1080×1920 미리보기 → 렌더 → 시트 │
└──────────────────────────────────────────────────────────────────────┘
```

- **갤러리의 미리보기는 반드시 움직인다.** 정지 썸네일로 판정하면 모션을 판정한 게 아니다. overlay 는 `MOTION_GRAPHICS.poster/clock`(팩 주인) 그대로, scene 은 원본 HTML 을 같은 출처 iframe 으로 열고 작업대가 `contentWindow.__timelines[slug]` 를 `time((now)%duration)` 으로 돌린다(CHA 런타임이 타임라인을 `paused:true` 로 등록하는 규격 — `brand/cha-motion.js` `CHA.timeline`). 동시에 도는 iframe 이 무거우니 **화면에 보이는 카드만** 돈다(IntersectionObserver).
- **CHA 원본은 회원 노출 금지**: 라이선스 `ref_only`. 서빙 길 `/api/admin/mograph/ref/...` 는 `_require_admin` 뒤이고, 저장소 밖 폴더(`MOGRAPH_REF_DIR`, 기본 `C:\Users\TheRose\숏템자료\모션그래픽엔진\CHA`)에서만 읽는다. 저장소에는 **장부 레코드(메타)만** 들어간다(코드·글꼴 미포함).
- **판 vs 세로 비교(결정 ③)**: scene 상세에 '세로 보기' 토글 — 같은 조각을 1080×1920 판(가로 1080×830 을 세로 가운데 배치, 위아래 배경색)으로 보여 준다. 세로 재작성본(`rewritten`)이 생기면 두 벌이 나란히 뜬다 → 사장님이 고른다. 작업대는 그림만 보여 주고 결정은 장부에 `verdicts[]` 로 남긴다.
- **자막 효과(coordinator 추가)**: 부품 kind 에 `caption` 을 둔다(예능 자막 등장·강조). 작업대에서 만들고 판정하되, **실제 사용처의 주인은 기존 자막 스타일/등장 효과팩**(`caption-motions.js` 등)이다 — 작업대는 참고·실측·판정까지, 합격한 것은 그 팩 파일에 한 칸으로 들어가고 장부는 `impl` 로 그 파일을 가리킨다(두 벌 금지).

## 2. 데이터 — 장부 세 개, 주인 함수 하나씩

| 장부 | 파일 | 주인 함수 | 레코드 |

부품 레코드(7절 검토의 필드 그대로, 새 항목 `impl`·`ratio_variants` 추가):
```
slug · kind(overlay|scene|transition|caption|preset) · label · group(장면 유형) ·
src{url,span,measure} · license{origin,status: ours|rewritten|ref_only} ·
impl{file,key}      ← 코드가 사는 곳(overlay: motion-graphics-pack.js ITEMS 키 / scene: 폴더 / caption: caption-motions.js 키)
geometry{w,h} · duration_ms · min_scene_ms · ratio('16:10'|'9:16') · ratio_variants[] ·
vars[] · beats[] · sfx_cues[] · timing_policy · fonts[] ·
check{tool,last_pass} · verdicts[{at,by,verdict,tags[],note}] · usage{jobs_60d,members_60d} · version
```
- **ITEMS(팩 JS)는 여전히 overlay 모양·시간표의 주인**이다. 장부는 그것을 가리키고(impl) 판정·출처·분류·실적을 더한다. 같은 값을 두 곳에 적지 않는다: 장부엔 `duration_ms` 같은 메타를 두되 작업대 화면은 그림을 팩 JS 로 그린다.
- CHA scene 레코드는 `sources.py:scan_sources` 가 `meta.json` 에서 뽑아 장부에 넣는다(`upsert_part`, 없는 것만). 폴더가 없어도 장부는 읽히고, 미리보기만 "원본 폴더 없음" 으로 뜬다.
- 판정은 **검사 결과와 같은 레코드**에 쌓인다 → "검사 통과인데 사장님은 별로" 건수 = 검사 기준을 고칠 신호(7절).

- 레퍼런스 대조: 중심 ±4px · 각도 ±9° · 겹침 ≥0.6(카운트다운 실측 기준 공용화).
- 세로 안전영역: iart tiktok short-form 규칙 **가운데 900×1400** 을 후보값으로 두고, 우리 자막 위치 실측으로 확정한 뒤 적는다(지어낸 값 금지). 첫 프레임에 훅 자막·자막 4~7단어.
- 자동 검사 후보(claude-remotion-skill 필수 규칙 10): linear 이징 금지·페이드 단독 금지·3~6프레임 순차 등장·90프레임 넘게 새 요소 없음 금지… → `check_render.py` 항목으로 하나씩, 각 항목은 **고치기 전 코드에서 실패하는지** 먼저 본다(0순위-A1c).
- 가격·숫자 장면 규칙(iart ecommerce): 가격·할인율은 **계산으로만**(같은 숫자를 두 번 타이핑하지 않는다), 취소선 + 가격 카운트다운, 가짜 타이머 금지 → 숫자 부품 vars 는 `price·discount_pct` 만 받고 할인가는 부품이 계산.
- 결정성: 같은 입력 2회 렌더 프레임 동일.

## 4. 별도 서비스로 떼어 갈 경계

```
shopping_shorts/mograph/            ← 통째로 들고 간다
  ledger.py   장부(부품·레퍼런스·프리셋)      sources.py  원본 폴더 스캔
  render.py   HyperFrames 렌더·시트·시간 기록   plan.py     대사→장면표(2차)
  data/*.jsonl                                    engine.md   생성 지침(2차, 한 파일)
shopping_shorts/static/mograph_bench.html        ← 작업대 화면(관리자)
app.py 는 길목만: _mograph_* 라우트 ~60줄(권한·파일 서빙·JSON)
```
- 재사용(숏템메이커 것): 회원·로그인·크레딧·작업 대기열·TTS 줄 타이밍·소리 팩·단계 패널 꼴·관리자 스위치. 분리 시 이 부분만 어댑터 한 벌.
- **렌더 엔진 층 교체 가능하게**(coordinator GSAP 경고): GSAP 표준 라이선스는 "회원이 코드 없이 애니메이션을 만드는 비주얼 편집기"가 금지 조항(Webflow 경쟁)에 걸릴 수 있다. 관리자 작업대는 GSAP 그대로(사장님 OK) / 회원용 서비스에서 회원이 직접 애니메이션을 편집하는 화면이 생기면 그 층은 WAAPI·anime.js(MIT)로 바꿀 수 있게 `impl.runtime` 필드로 구분하고 부품은 "시간 t → 그림" 함수 계약만 지킨다. Remotion 은 직원 3명 초과 유료 → HyperFrames 결정 유지.
- 렌더 부하: 모션 렌더는 별도 대기열(동시 1)로 쇼츠 렌더와 안 밀리게. PC 렌더는 서비스 부적합 → 서버 렌더 시간 실측 뒤 결정.
