숏템메이커 시작 안내 (상세)

가입 → 라이브 시청 → 키 등록 → 담기 설치 → (선택) 캡컷 → 첫 영상. 한 단계씩 따라 하시면 됩니다. 설치는 PC에서 하고, 휴대폰으로는 설치가 안 됩니다.

1사이트 가입

숏템메이커 열기 →
  1. https://shoppingshorts.duckdns.org 접속
  2. 구글로 로그인 (새 비밀번호를 만들지 않습니다. 쓰시던 구글 계정으로 들어갑니다)
  3. 처음 로그인하면 이름 · 전화번호 · 성별 · 연령대 입력 화면이 뜹니다. 승인 안내에 필요하니 정확히 적어 주세요.
  4. 입력 후 "승인 대기중" 화면이 보입니다. 관리자가 확인하고 열어 드립니다.
  5. 승인되면 같은 주소로 다시 로그인하면 바로 제작 화면이 열립니다.
구글 계정이 두 개인 분은 한 계정으로만 가입하세요. 다른 계정으로 로그인하면 담아둔 영상·키가 안 보입니다.

2숏템메이커 유튜브 채널 라이브 시청 반드시

숏템메이커 유튜브 채널의 최근 영상 몇 개는 반드시 시청하고 시작하세요. 사용법(담기 → 대본 → 장면 → 완성)과 업데이트되는 내용을 라이브로 계속 올립니다.

타입캐스트에서 가장 많이 틀리는 것
  • 타입캐스트는 요금제가 두 가지입니다. 홈페이지의 Pro($29) 같은 것은 에디터 요금제라 결제해도 숏템메이커에서는 안 됩니다.
  • 반드시 typecast.ai/pricing/api 에서 API 요금제(Lite $15/월)를 결제하세요.
  • 결제 안 된 무료 계정으로 키를 넣으면 "비정상 활동이 감지되었습니다(UNUSUAL_ACTIVITY_DETECTED)"가 뜹니다. API 요금제 결제 후 다시 확인을 누르면 풀립니다.
  • 타입캐스트 성우(필재·김건·박창수·용식 등)는 본인 타입캐스트 키가 있어야만 쓸 수 있습니다. 키 없이 고르면 안내문과 함께 막힙니다. 등록 전까지는 일레븐랩스 성우를 골라 주세요.

등록하는 법

  1. 화면 오른쪽 위 사람 아이콘 → 마이페이지 → 🔑 내 키 등록 (바로 가기)
  2. 해당 서비스 칸에 붙여넣고 저장. 앞뒤 공백·줄바꿈이 끼면 "키가 틀렸습니다"가 뜹니다.
  3. VMake는 칸이 두 개입니다. 윗칸에 API Key, 아랫칸에 Secret Access Key를 따로 넣고 저장하세요. 한 칸에 둘을 합쳐 넣으면 안 됩니다.
  4. 일레븐랩스 키를 만들 때 오른쪽 권한을 전부 허용하지 않으면 등록은 돼도 목소리 생성에서 막힙니다.
  5. 저장하면 그 자리에서 키가 맞는지 확인해 ● 정상으로 표시됩니다. 틀리면 이유를 알려줍니다.
  6. 제미나이는 예비로 2~3개 넣어 두시면 하나가 멈춰도 이어집니다(서로 다른 프로젝트에서 만든 키).
키는 본인 요금이 나가는 열쇠입니다. 단톡방·화면공유에 노출하지 마세요. 노출됐으면 그 사이트에서 폐기하고 새로 받으세요.

4담기 프로그램 설치 반드시

유튜브·틱톡·인스타·샤오홍슈·도우인에서 마음에 든 영상을 클릭 한 번으로 담는 크롬 확장프로그램입니다. 이게 있어야 소재를 모읍니다.

📥 담기 설치 페이지
  1. PC 크롬(또는 엣지)에서 shoppingshorts.duckdns.org/grab 접속
  2. 설치 파일을 받아 압축을 풉니다
  3. 크롬 주소창에 chrome://extensions 입력
  4. 오른쪽 위 개발자 모드 켜기
  5. 압축 푼 폴더를 그 화면에 끌어다 놓기
  • zip 파일이 아니라 압축을 푼 폴더를 넣어야 합니다.
  • 텀퍼몽키 같은 다른 프로그램은 필요 없습니다.
  • 설치 후 유튜브·인스타 영상 화면에 📥 담기 버튼이 보이면 성공입니다.

5캡컷 연동 원하시는 분만

완성 영상을 캡컷에서 더 다듬고 싶은 분만 합니다. 숏템메이커에서 바로 받거나 QR로 폰에 보내실 분은 이 단계를 건너뛰세요.

⚡ 캡컷 연결하기 (3단계)
  • 처음 두 번만 따라 하시면 그 뒤로는 보내기 한 번으로 캡컷에 들어갑니다.
  • 캡컷 보내기도 크롬·엣지에서만 됩니다.

6첫 영상 만들기

  1. 유튜브·인스타에서 마음에 든 영상에서 📥 담기
  2. 제작소에서 담긴 영상으로 대본 → 장면 → 목소리 → 완성
  3. 완성본은 바로 받거나 QR로 폰에 보내거나, 캡컷으로 보냅니다

7이용 한도와 무료 범위

  • 렌즈로 찾기 하루 10번 · 영상 만들기 하루 10편. 남은 횟수는 마이페이지 → 내 계정에서 보입니다.
  • 영상 찾기 · 즐겨찾기 · 내보내기는 무료입니다.
  • SerpApi 키를 등록하면 렌즈 횟수가 키 1개당 10번씩 늘어납니다.

8수익화에 필요한 계정 (나중에)

  • 쿠팡파트너스: 8단계에서 본인 계정의 추적 링크를 넣어야 수수료가 붙습니다.
