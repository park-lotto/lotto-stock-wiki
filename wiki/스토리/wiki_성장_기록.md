# STOCK BRAIN 위키 성장 기록
> 유튜브 콘텐츠 소재용. AI 지식 시스템이 시행착오를 거쳐 진화하는 과정.
> **핵심 스토리**: 빈 위키 → 규칙 추가 → 실수 발견 → 시스템 개선 → 답변 밀도 상승

---

## 기록 방법

각 세션 또는 중요한 순간마다 아래 형식으로 기록:
- **날짜**
- **무슨 일이 있었나** (시행착오, 발견, 개선)
- **Before** (개선 전 상태)
- **After** (개선 후 상태)
- **유튜브 활용 포인트** (시청자에게 어떤 메시지를 줄 수 있는가)

## 2026-05-29 — 첫 번째 대규모 리서치 세션

### 에피소드 1: AI가 사실을 지어냈다

**무슨 일:**
로봇 섹터 Q10 리서치 완료 후 "엔비디아 Isaac 파트너십" 관련 주장 검증.
Gemini가 "레인보우로보틱스 GTC 2024 시연", "유진로봇 Isaac 협력" 등을 실제처럼 작성.

**Before (검증 전):**
```
"레인보우로보틱스 GTC 2024에서 Isaac 플랫폼 활용 언급" → 위키에 그대로 저장
"유진로봇 Isaac 플랫폼 기반 로봇 개발 협력" → 위키에 그대로 저장
```

**After (WebSearch 검증 후):**
```
레인보우로보틱스 GTC 2024 시연 → ❌ 파트너 명단에 없음
유진로봇 Isaac 협력 → ❌ 검색 근거 없음
두산로보틱스 → ✅ 실제 CES 2026 + 2026.04 공식 협력
```

**시스템 개선:** `analysis_rules.md §4` — Gemini 사후 WebSearch 검증 규칙 추가

**유튜브 포인트:**
> "AI한테 물어봤더니 그럴듯하게 답했는데, 전부 지어낸 거였습니다. 이게 AI를 주식에 쓸 때 가장 무서운 부분이에요."

### 에피소드 2: 규칙서가 1,352줄이 됐다

**무슨 일:**
CLAUDE.md가 시간이 지나면서 규칙이 계속 추가되어 1,352줄 / 섹션 70개가 됨.
실제로 읽히는지도 모르는 규칙들이 쌓임.

**Before:**
- CLAUDE.md: 1,352줄
- 규칙이 뒤죽박죽 섞여있어 충돌 발생
- 세션 시작할 때마다 전부 읽음 → 비효율

**After:**
- CLAUDE.md: **237줄** (-83%)
- 상세 규칙 3개 파일로 분리:
  - `analysis_rules.md` — 분석 행동 규칙
  - `ingest_rules.md` — 데이터 입력 규칙
  - `page_templates.md` — 페이지 형식
- 질문별로 필요한 파일만 읽음 → 토큰 절약

**유튜브 포인트:**
> "AI 시스템도 코드처럼 리팩토링이 필요합니다. 규칙이 많다고 좋은 게 아니에요."

### 에피소드 3: AI가 위키를 안 읽고 검색했다

**무슨 일:**
"현대 MASGA 미군함 관련 이벤트?" 질문 → 위키에 이미 MASGA 분석 다 있는데 WebSearch 먼저 함.

**Before (잘못된 패턴):**
```
질문 → 즉시 WebSearch → 답변
(위키 무시)
```

**After (수정된 패턴):**
```
질문 → 위키 먼저 (구조·논리) → WebSearch (현재 상태만) → 합쳐서 답변
```

**유튜브 포인트:**
> "위키를 쌓는 이유가 뭔지 잊었던 거예요. 매번 검색 안 하기 위해서 쌓는 건데."

---

### 에피소드 4: 전고체 대장주를 놓쳤다

**무슨 일:**
전고체 배터리 리서치 → 장비주(필에너지·씨아이에스)는 잡았는데 **이수스페셜티케미칼(황화리튬 원료 대장)** 누락.

**Before:**
```
검색: "전고체 관련주" → 장비주 위주로 노출
황화리튬(Li₂S) → 황화물 전해질 → 삼성SDI 체인을 역추적 안 함
```

**After:**
- 이수스페셜티케미칼 12개월 **+88.8%** — 테마 내 최대 상승 확인
- CNPC 230억 공급 계약 공시 → 당일 **+21.48%** 확인
- "완성품 → 소재 → 원료" 역추적 규칙 추가

**시스템 개선:** 리서치 완료 후 대장주 크로스체크 + 주가 검증 3단계 표준화

**유튜브 포인트:**
> "위키가 없을 때는 검색하면 항상 유명한 것만 나와요. 실제 돈이 된 건 유명하지 않은 원료 회사였는데."

---

### 에피소드 5: LS 오기 공시 발견

**무슨 일:**
전력기기 리서치에서 LS일렉트릭 수주잔고 수치 검증하다가 LS 지주가 수주잔고를 1.5조 부풀려 공시하고 12일 방치한 사건 발견.

**Before (Gemini 수치):** LS일렉트릭 수주잔고 8.7조
**After (검증 결과):** 실제 연결 7.2조 + LS 지주 오기 공시 사건 (5/27 발표) → 주가 이틀 -9%

**유튜브 포인트:**
> "AI가 틀린 게 아니라, 회사 자체가 틀린 수치를 공시했어요. 검증 안 했으면 그냥 썼겠죠."
