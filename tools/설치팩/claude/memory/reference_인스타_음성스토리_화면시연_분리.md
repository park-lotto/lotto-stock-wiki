인스타 릴스 전사 43편·654컷을 대사와 `scene_desc`로 갈라 대조한 실측(2026-08-19):

```
대사에 등장인물(시어머니·친구·사장님)이 나오는 컷    49개
그중 화면에도 사람이 나온 컷                         1개  ← 2%
```

**"시어머니가 화를 내시는 거예요"라고 말하는 순간에도 화면은 양말을 빨고 있다.**
스토리는 전부 목소리로 굴러가고, 화면은 처음부터 끝까지 제품 시연 루프다.
화면 서술 어휘 상위 35개(모습534·보여주는96·손으로62·붓는36·닦는18)에
**사람 얼굴 관련 단어가 하나도 없다.**

→ 필요한 화면은 4종뿐. **이 4종만 있으면 어떤 스토리든 위에 얹을 수 있다**:
① 문제 상태(더러운 대상) → ② 투입·도포(제품 쓰는 손) → ③ 작동(거품·문지름)
→ ④ **결과 대비**(반반 대비샷 = 클라이맥스, "반쪽은 누렇고 반쪽은 하얀 양말")

**유튜브와 정반대다.** 유튜브 은폐형은 "이건 바로 ○○" 공개 시점에 화면이 같이 꺾인다.
인스타는 화면이 스토리를 안 따라가므로 **대본 변형의 자유도가 훨씬 크다.**

## 단, 슬롯을 두 종류로 갈라야 한다

대본 슬롯이 화면에 근거가 있는지 재보니(한국 5편 68컷·중국 3편 58컷) 규칙이 있었다:

- **사물·동작 슬롯**(사용법·적용대상·불편함) → 화면에 있다
- **판단·추상 슬롯**(가격·효과·차별점) → **화면에 없다.** "단돈 몇 천 원"은 눈에 안 보이고
  "구멍을 뚫을 필요 없는"처럼 *없는 것*은 애초에 못 찍는다

그래서 장면 대조 게이트는 **사물 슬롯에만** 걸어야 한다. 전부에 걸면 정상 대본이 죽는다.

⚠️ 측정할 때 **어간(2글자)으로 매칭하라.** 완전일치로 재면 "뿌리고/뿌려주기"가
"뿌리는 모습"과 안 걸려 오탐이 난다(실제로 3건 중 2건이 오탐이었다).
