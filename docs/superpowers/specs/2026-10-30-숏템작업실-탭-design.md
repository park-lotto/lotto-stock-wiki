# 숏템 작업실 — 설정·진행현황·원본 찾기 한 화면 탭 (관제 291, 2026-10-30 사장님)

사장님: "원본 찾기 엔진 · 설정+수정 페이지 · 진행현황판 — 하나의 페이지에서 탭으로", "고객 PC 에서 작동".

## 실측한 바탕 (코드)
- 화면 파일 하나 `shortem_client/server/ui/index.html` 을 두 곳이 띄운다: 고객 PC `local_ui.js`(127.0.0.1, 토큰) · 서버 `/claude/studio/`(app.py → claude_studio.UI_FILE).
- `local_ui.js` 와 제작 고리 `flow_driver.js` 는 같은 프로그램(`index.js`) 안 — 상태를 함수로 바로 읽는다.
- 고객 제작 상태 = `<data>/flow/<sid>/flow.json`(stage·message·finding·status·fail·wait·asks) · `job/progress.json`.
  옛 `hybrid/flow_board.py` 는 `flow_dev` 의 `flow_log.jsonl` 을 읽어 고객 PC 에선 빈 화면 → 옮기지 않고, 완성 뒤 접는다.
- 원본 찾기 기록(고객 PC job 안): `origin_foreign/cands_{lens,peers,find}.json`(후보 n·platform·제목·조회·korean) · `thumb_<id>.jpg` · `judge_<k>.jpg` · `seed_*.jpg` · `look/verify_<id>.jpg`.
  AI 판정 = `<aiRoot>/flow_<sid>/<id>/request.json`(tag of_judge·of_peer·of_find·of_verify, 그림 p00..) + `answer.json`(same·picks).
- 24시간 워커(of_worker·channel_worker)는 설치 묶음에 없음 → 이번 범위 밖(탭 자리는 같다).

## 구성
| 탭 | 보여 줄 것 | 주인(읽기만) |
|---|---|---|
| ⚙ 설정·수정 | 지금 화면 그대로 | local_settings.js |
| ▶ 진행현황 | 편 목록 · 단계 n/전체 · 안내 한 줄 · AI 판정 대기 · 멈춤(이유·고칠 것) · 사인/다시 버튼 | flow_driver.shapeFlow · approveFlow · retryFlow |
| 🔍 원본 찾기 | 소재 장면 → 후보(썸네일·조회) → AI ○/✕ → 받기 → 실제 장면 확인 ✅/❌ · 경과 | 같은 편 job/origin_foreign + AI 판정 폴더 |

원칙: 탭은 판단 0(서버 flow.py 한 곳) · 서버판은 진행·원본 탭 숨김(로컬 API 없으면 숨김 — 따로 판정 안 적음) ·
화면에 모델 이름·키·경로·계정명 안 냄 · 디자인 = 기존 화면 토큰이 정본, 빈칸(탭 알약·간격)은 linear.app DESIGN.md(pill 9999px, ≥36px 높이), 움직임 ease-out 200ms.

## 순서 · 검사
1 탭 틀 → 두 곳에서 설정 화면 그대로(캡처) 2 진행현황 → 실제 한 편 단계 넘어감 3 원본 찾기 → 같은 편 후보·판정 4 고객 길(로컬 서버+묶음) 완주 캡처, flow_board 접기 5 기록·한 번 병합(배포·발행은 승인 뒤).
