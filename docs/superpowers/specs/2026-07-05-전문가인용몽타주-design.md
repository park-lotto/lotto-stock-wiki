# 전문가 인용 몽타주 — 설계 (Design Spec)

- 날짜: 2026-07-05
- 상태: 설계 확정 (렌더 엔진·창고합류·T2 heatmap 실측은 의도적 미확정)
- 브랜치: feat/briefing-engine (현재), 구현은 별도 브랜치 권장

## 1. 목적 (Why)

여러 신뢰 전문가의 관점을 크롤링·인용·**종합**해 "나는 이렇게 본다"를 보여주는 영상 포맷.
- 채널 70/20/10 중 **20%(간접 노출 = 방법론 데모)**가 본체. 파는 것은 리딩이 아니라 **관점 종합 능력**.
- 영상 자체가 "이 많은 전문가를 내가 정리해 이렇게 본다"를 증명 → 키컨텐츠(인사이트 채널/Stock Brain) **간접홍보**.
- 예시 주제: "반도체 고점인가?"

## 2. 최종 산출물의 성격 (What appears on screen)

**C안 = 하이브리드.**
- 기본: 전문가 영상/리포트의 **정지 캡처**를 배경으로 리모션 효과 + **내 나레이션**(전문가 발언은 인용카드+출처 자막).
- 결정적 순간만: **3~5초 원본 클립** 재생.
- 원본 음성은 대부분 안 쓰고, 핵심에서만 원본 파워를 빌린다.

## 3. 8단계 파이프라인

```
[기획]
1. 주제 선정        논점 1개 확정
2. 논지(thesis)     내 결론/각도 초안 = 가설 (잠그지 않음)
[수집]
3. 레퍼 영상 선정   창고(/yt/refs, 다른세션)에서 신뢰 전문가 영상 N개 + 출처 확정
4. 해체·인덱싱      각 영상 → 타임스탬프 대사 전문 + 프레임 스캔 → 발언 후보 카드 + 캡처 후보
[구성]
5. 인용 픽 & 매핑    후보 중 논지 기둥에 붙을 발언을 체크로 픽 → quotes.json
6. 스토리 확정       클러스터가 내러티브를 "발생"시킴 (부과 금지)
[제작]
7. 씬 빌드          quotes.json → 씬 데이터 → 렌더 어댑터(hyperframes/Remotion)
8. 렌더 & 검수      출처 표기·오인용 체크 → MP4
```

**순서의 함정(중요):** 2(논지)는 **가설**이고 6에서 **확정**된다. 어떤 발언이 실제로 존재하는지 모르고 스토리를 잠그지 않는다. 5(인용 픽)이 가설과 확정을 잇는 경첩.

## 4. 핵심 자산 A — 인용 스튜디오

- 위치: `/yt/quote-studio` (독립 페이지). 나중에 창고와 합류 가능하나 지금은 분리.
- 이유: 창고는 "배울 영상 찾기", 이건 "인용 뽑아 편성" — 목적이 달라 UI를 섞으면 둘 다 지저분.
- **엔진은 공유**: `hot_clips.py` · `clip_teardown.py` · `gemini_client.py`. 화면만 별도.

### 4.1 화면
```
[영상 URL 입력]  또는 창고에서 넘겨받기
─ 대사 타임라인 (자막 세그먼트, 클릭=점프, 스탠스 태그 표시)
─ 캡처 스트립 (프레임 썸네일, 리포트/차트 프레임 표시)
─ 인용 픽 (체크) → 각 픽: [정지캡처 ⟷ 3~5초 클립] 선택
─ 정렬/필터: tier · stance · has_visual · heat
```

### 4.2 엔진 흐름 (자동)
```
영상 URL
 → yt-dlp 다운로드 (+ heatmap 메타 수집)
 → 자막 / Whisper = 타임스탬프 대사 전문
 → 프레임 샘플링(2~3초 간격)
 → Gemini 2패스:
     (a) 대사 채점 → 발언 후보 카드 + stance/근거유형/신뢰도/score
     (b) 프레임 비전 스캔 → "리포트/차트/슬라이드 있음" 프레임 태깅(has_visual)
 → 타임라인·스트립에 뿌림 (tier 정렬)
```

## 5. 핵심 자산 B — 골든 루브릭 + 3계층 수집

### 5.1 골든 발언 루브릭 (점수제, 감이 아니라 통과선)

**필수 3개를 모두 넘어야 골든 후보:**
| 항목 | 통과 기준 | 통과 예 / 탈락 예 |
|------|-----------|-------------------|
| 주장 명확 (필수) | 판단이 있나? 인사말·물타기 탈락 | "고점 아니다" ✅ / "지켜봐야죠" ❌ |
| 근거 동반 (필수) | 왜? 근거유형 태깅(수급/실적/밸류/공급망) | "HBM 공급부족이라" ✅ / 근거없는 단정 ❌ |
| 입장 존재 (필수) | 강세/약세/전환 중 하나로 분류되나 | 관점 지도에 못 꽂으면 탈락 |

**가점(픽 우선순위):**
| 항목 | 가점 조건 |
|------|-----------|
| 구체성 | 숫자·날짜·종목·조건 있음 ("내년 상반기까지") |
| 화면 근거 | 말할 때 리포트/차트가 화면에 (캡처 붙음) |
| 화자 신뢰 | 창고 검증 통과한 전문가 |

→ 양비론·잡담·광고는 규칙상 자동 탈락 = 억지 원천 차단. Gemini가 이 루브릭으로 채점.

### 5.2 수집 우선순위 3계층 (Tier)

| 순위 | 무엇 | 왜 | 감지 |
|------|------|----|------|
| T1 자료 구동 발언 🥇 | 화면에 리포트·직접 슬라이드·차트 켜고 말하는 지점 | 데이터 기반 신뢰 최상 + 캡처가 곧 증거화면 | 프레임 비전이 문서/차트/슬라이드 감지 → 그 순간 발언 |
| T2 트래픽 스파이크 발언 🥈 | 시청자 몰리는(most-replayed) 구간 발언 | 대중이 검증한 먹히는 지점 | yt-dlp `heatmap` 피크 → 대사 매핑 |
| T3 루브릭 통과 발언 🥉 | 위 둘 아니어도 필수3 통과 | 놓친 인사이트 폭넓게 1차 확보 | 5.1 루브릭 |

- 정렬: T1 > T2 > T3, 겹치면 최상위.
- **T2 폴백:** heatmap은 조회수 충분한 영상만 제공. 없으면 T1+T3만 가동. (실측 필요)

## 6. 핵심 자산 C — quotes.json (유일 산출물, 뒷단 전부 구동)

```json
{
  "topic": "반도체 고점인가",
  "thesis_draft": "고점 아니다(가설)",
  "quotes": [
    {
      "source": "채널명/영상URL",
      "ts": "00:12",
      "text": "HBM 공급부족은 최소 내년까지",
      "tier": 1,
      "has_visual": true,
      "heat": 0.0,
      "stance": "강세",
      "evidence": "수급",
      "score": 5,
      "media": { "type": "capture", "path": "cap_0012.png" }
    }
  ]
}
```
- 이 JSON 하나가 **관점 지도(stance 집계)**와 **씬 빌드(media+text+source)** 둘 다를 먹인다.

## 7. 스토리 발생 & 억지 금지 3원칙

```
전영상 골든 발언 풀
 → 각 발언 {주장, stance, 근거유형}
 → 주장/근거로 자동 클러스터링
 → 클러스터 = 스토리 비트 (강세팀 근거 / 약세팀 근거 / 전환론)
 → 비트 순서 = 내러티브
```

**억지 금지:**
1. 내러티브는 발언이 뭉쳐 **발생**한다. 미리 짠 스토리에 발언을 끼워맞추지 않는다.
2. 골든이 **한쪽 쏠림** → "전문가 합의" 내러티브 / **팽팽** → "갈린다, 나는 이래서 이쪽"(양쪽+내 종합) / **부족** → "수집 더", 지어내기 금지.
3. 2(논지)는 클러스터가 확정하기 전까지 잠그지 않는다.

**표준 스토리 스파인(종합 모먼트 필수):**
```
훅 → [관점 지도: 강세팀 vs 약세팀 한눈에]
   → 기둥별 대표 인용 파고들기(캡처+클립+출처)
   → 반론 인용(균형)
   → 내 종합 "나는 이렇게 본다" (= 상품 데모)
   → S8 CTA 한 번
```

## 8. 씬 빌드 & 렌더 (어댑터로 개방)

- 확정 범위: **quotes.json → 씬 데이터**까지.
- 렌더 엔진은 **어댑터**로 두 구현을 꽂을 수 있게:
  - hyperframes (HTML 컴포지션, 이 세션 스킬 다수)
  - Remotion (`scripts/yt_agents/agent_remotion.py` + 효과 7종, 채널 룩 통일)
- 결정: 나중에 둘 다 써보고. 씬 데이터 스키마는 렌더 중립으로 설계.

## 9. 미확정 (의도적 개방)

- 렌더 엔진 (hyperframes vs Remotion) — 앞단 검증 후 둘 다 시험.
- 창고(/yt/refs)와 스튜디오 합류 시점 — 지금은 분리, 필요 시 나중.
- T2 heatmap 실제 제공률 — 실측 후 폴백 정책 확정.

## 10. 재활용 자산 (이미 있음)

- `watch` 스킬 = yt-dlp 다운로드 + ffmpeg 프레임 + 자막/Whisper.
- `scripts/yt_agents/`: hot_clips(검색·검증), clip_teardown(해체·mix), gemini_client(네이티브 시청, 18키 폴백).
- Remotion 효과 라이브러리 7종 / hyperframes 스킬군.
- stance_key 개념 (원자DB·사람브레인) — 스탠스 태깅에 재활용.

## 11. 열린 질문 (구현 플랜에서 해소)

- 프레임 샘플링 간격 vs 비전 호출 비용 트레이드오프.
- 정지캡처 해상도/워터마크 처리, 출처 표기 자동 삽입 위치.
- quotes.json 영구 저장(창고 DB 합류 시).
