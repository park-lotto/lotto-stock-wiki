## 1. 기획 검수 직원 체크리스트

### A. 측정 가능 항목 (각 1점, 자동 판단)
```
□ 제목에 숫자 포함 (100배 / 6월 / 5천만원 / 40% 등)
□ 제목에 시간 압박 단어 (6월 / 다음주 / 지금 / 오늘 / 임박)
□ 제목에 행동 촉구 단어 (사세요 / 모으세요 / 하세요 / 사모아라)
□ 제목에 과장 표현 (미친 / 역대급 / 폭등 / 완전 / 무조건)
□ 제목에 대형 브랜드/종목명 (삼성 / SK / LG / NVIDIA / 반도체)
□ 썸네일 텍스트가 제목의 핵심만 압축됐는가 (20자 이내)
```

### B. 구조 항목 (각 1점, AI 판단)
```
□ 씬1 훅이 공감으로 시작하는가 (나도 그래 유발)
□ 씬4 데모가 실제 화면 보여주는 구체적 장면인가
□ 서비스 소개가 뒤 1/3에만 나오는가 (앞에 광고 느낌 없는가)
□ CTA에 댓글 키워드 + 서비스 대기 2가지 모두 있는가
```

### 판정 기준
- **A 항목 4개 이상 + B 항목 3개 이상** → PASS (총 7/10)
- 미달 시: 실패한 항목 명시 후 기획 직원에게 재작업 지시

## 2. 대본 검수 직원 체크리스트

### A. 측정 가능 항목 (자동 판단)
```
□ 첫 문장이 질문이거나 공감 유발 문장인가
□ 첫 15초 안에 숫자 또는 충격 단어가 나오는가
□ "안녕하세요" / "오늘은" 으로 시작하지 않는가 (금지어 검사)
□ 씬별 예상 시간 합산이 6~10분 범위인가
□ CTA 씬에 "댓글에 [키워드]" 형태가 명시됐는가
```

### B. 레퍼런스 비교 항목
```
□ 5.4만뷰 영상 첫 문장 패턴과 유사한가:
  "사람들이 [걱정]을 했는데 → 오히려 [반전] → [행동] 하세요"
□ 데모 씬에 실제 보여줄 화면이 3개 이상 구체적으로 명시됐는가
□ 클라이맥스 씬에 개념 전환 문장 1개가 있는가
  예: "저는 이제 주식 분석을 합니다가 아니라 팀을 운영합니다"
□ 여운 씬에 다음 편 궁금증이 심어지는가
```

### 판정
- **A 5개 + B 3개 이상** → PASS (8/9 이상)

## 3. Remotion 영상 검수 직원 체크리스트

### A. 기술 검수 (자동 — 코드 분석)
```
□ TypeScript 에러 0개 (tsc --noEmit)
□ 모든 씬에 Html5Audio 태그 있는가
□ 모든 씬에 자막바 있는가 (SUBS + 하단 div)
□ 모든 씬에 fadeIn (f=0~18) 있는가
□ ip() 헬퍼 함수 사용하는가 (하드코딩 interpolate 금지)
```

### B. 연출 검수 (측정 가능 기준)
```
□ 씬당 Phase 전환 최소 2개 (Phase 1/2/3 구분 있는가)
□ 정적 구간 없는가 (5초 이상 아무 움직임 없는 구간)
□ 클라이맥스 씬에 elastic scale + dynGlow 있는가
□ 민트(#00FFD0) 포인트 컬러 사용됐는가
□ 이모지 사용됐는가 (최소 3개 이상)
□ 숫자/핵심단어에 color: C.main 강조 있는가
```

### C. BRAIN SIGNAL 스타일 체크
```
□ 배경색 #080c14 또는 유사 다크 계열인가
□ 씬 마지막에 +30프레임 여백 있는가
□ 우상단에 씬 번호/이름 라벨 있는가
```

### 판정
- **A 전부 + B 5개 이상 + C 2개 이상** → PASS
- A 하나라도 실패 → 자동 수정 후 재검

## 4. Whisper 싱크 검수 직원 체크리스트

### 측정 가능 기준만 (주관 없음)
```
□ 자막 시작 프레임 - 발화 시작 프레임 오차 ±5프레임 이내
□ 자막 끝 프레임 >= 발화 끝 프레임 (말 중간에 자막 사라지면 실패)
□ 침묵 구간(gap > 15프레임)에 자막 없는가
□ durationInFrames = 실제 녹음길이 × 30 + 30 이내인가
□ 씬 간 음성 겹침/공백 없는가
```

### 판정
- **전 항목 통과** → PASS (하나라도 실패 시 해당 씬 재싱크)
