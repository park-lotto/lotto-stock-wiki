70/20/10 규칙은 **채널 전체 영상 라이브러리의 타입 비율**이다. 1개 영상 안의 씬 비율이 아님.

- A형 (70%): 순수 정보만. 서비스·툴·프로그램 존재 자체 없음. "제가 쓰는 툴" 같은 간접 표현도 금지.
- B형 (20%): 정보 + 내 서비스 간접 노출. "저는 이렇게 합니다" 방법론만 보임.
- C형 (10%): 서비스/프로그램 직접 소개 영상.

**Why:** 영상 제작 단계에서 타입 확인 없이 씬을 짜면 A형에 서비스 흔적이 섞이는 실수 발생 (실제로 발생함).

**How to apply:** yt-planner / yt-gemini-pipeline 시작 시 반드시 첫 번째 질문으로 "이 영상 A/B/C형?" 확인 후 진행. 타입 확정 전 씬 구성 불가.
