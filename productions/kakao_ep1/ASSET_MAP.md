## 🚀 작업 순서

```
1. 오푸스  → design.md + design_prompt.txt 채우기 (Veo클립 + 전환컷)
2. 직접    → Veo 생성 → 해당 clip 폴더에 영상 넣기
3. 직접    → 화면녹화 → 해당 씬 폴더에 영상 넣기
4. 소넷    → Whisper → _audio/ + TSX SUBS 업데이트
5. 소넷    → S4·S7~S11 TSX 제작 (KK_S6_MCP.tsx 복제)
6. 소넷    → Remotion 렌더 → 각 씬 폴더에 render.mp4
7. 소넷    → ffmpeg concat → _final/
```
