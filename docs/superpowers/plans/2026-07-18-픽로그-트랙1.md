> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사장님이 제작소에서 무엇을 고르고(픽) 무엇을 버렸는지(반려)를 `pick_events` 테이블에 조용히 남겨, 훗날 LLM 심사(트랙 7)의 취향 예시·B전환 승인률 지표의 원천 데이터로 쓴다.

**Architecture:** 백엔드에 append-only `pick_events` 테이블 + `POST /api/pick_log` 라우트를 만들고, produce.html의 결정 지점 5곳(초안픽·믹스시작·꾸미기스타일·프레임픽·SEO생성)에 fire-and-forget JS 훅 `logPick()`을 심는다. 스펙 §7·§8(트랙1)·리스크 §9.4 근거.

**Tech Stack:** Python 3 / SQLite (`shopping_shorts/store.py`) / FastAPI (`shopping_shorts/app.py`) / 바닐라 JS (`shopping_shorts/static/produce.html`) / pytest + `fastapi.testclient.TestClient` + Node(함수 슬라이스 실행).

## Global Constraints

- **produce.html seam (스펙 §9.4)**: produce.html은 4개 트랙이 동시 편집 중. 이 트랙의 프론트 변경은 **`logPick` 헬퍼 1개 + 5개 호출 한 줄씩**으로만 제한한다. 새 화면·기존 렌더 함수 재작성 금지.
- **픽로그는 부가 기능 — 절대 흐름을 막지 않는다**: 클라이언트 `logPick`은 fire-and-forget(`.catch`로 실패 삼킴, try/catch로 감쌈). 기존 액션 로직 **뒤**에 호출한다. POST가 죽어도 사장님의 초안 확정·믹스·썸네일 픽은 그대로 진행돼야 한다.
- **멀티테넌시**: 모든 개인 행동 테이블 관례대로 `customer_id INTEGER NOT NULL DEFAULT 0` 포함, 라우트는 `_cid(request)`로 채운다 (`LEGACY_CUSTOMER_ID = 0`).
- **append-only**: pick_events는 수정·삭제 API 없음. 오직 append + 조회.
- **경로**: 모든 편집은 `.tracks/픽로그/...` 절대경로. main 폴더 코드 파일 무접촉.

- [ ] **Step 4: store 메서드 추가**

`store.py`의 `Store` 클래스에 메서드 추가(예: `create_mix_job` 근처, 1284행대). `_enc`/`_dec`는 str이면 그대로, 아니면 JSON:

```python
    @staticmethod
    def _pe_enc(v):
        """픽로그 값 저장 인코딩: str/None은 그대로, 그 외(dict·list·int)는 JSON."""
        if v is None or isinstance(v, str):
            return v
        return json.dumps(v, ensure_ascii=False)

    @staticmethod
    def _pe_dec(v):
        """저장 값 복원: JSON이면 파싱, 아니면(순수 문자열) 그대로."""
        if v is None:
            return None
        try:
            return json.loads(v)
        except (ValueError, TypeError):
            return v

    def log_pick_event(self, stage, *, picked=None, rejected=None, candidates=None,
                       edit_diff=None, job_id=None, customer_id=LEGACY_CUSTOMER_ID):
        """픽/반려 한 건 append. 새 row id 반환. 부가 기능이라 최대한 관대하게 저장한다."""
        ts = datetime.now(timezone.utc).isoformat()
        with self._conn() as c:
            cur = c.execute(
                "INSERT INTO pick_events(customer_id, job_id, stage, candidates_json, "
                "picked, rejected, edit_diff, ts) VALUES(?,?,?,?,?,?,?,?)",
                (customer_id, job_id or None, stage,
                 json.dumps(candidates, ensure_ascii=False) if candidates is not None else None,
                 self._pe_enc(picked), self._pe_enc(rejected), self._pe_enc(edit_diff), ts),
            )
            return cur.lastrowid

    def list_pick_events(self, *, customer_id=None, stage=None, limit=100):
        """최근(id 내림차순)부터. customer_id/stage 필터 선택. JSON 필드는 파싱해서 준다."""
        q = ("SELECT id, customer_id, job_id, stage, candidates_json, picked, "
             "rejected, edit_diff, ts FROM pick_events")
        conds, args = [], []
        if customer_id is not None:
            conds.append("customer_id=?"); args.append(customer_id)
        if stage is not None:
            conds.append("stage=?"); args.append(stage)
        if conds:
            q += " WHERE " + " AND ".join(conds)
        q += " ORDER BY id DESC LIMIT ?"; args.append(limit)
        with self._conn() as c:
            rows = c.execute(q, args).fetchall()
        return [
            {"id": r[0], "customer_id": r[1], "job_id": r[2], "stage": r[3],
             "candidates": self._pe_dec(r[4]), "picked": self._pe_dec(r[5]),
             "rejected": self._pe_dec(r[6]), "edit_diff": self._pe_dec(r[7]), "ts": r[8]}
            for r in rows
        ]
```

def _slice(src, start, end):
    i = src.index(start)
    j = src.index(end, i)
    return src[i:j]


def test_logpick_sends_merged_payload_and_swallows_failure():

    // fetch가 거절해도 logPick은 절대 던지지 않아야 한다(fire-and-forget)

    logPick('S2', {picked: '초안2', candidates: ['a','b','c']});

    console.log('OK');

    assert "OK" in out.stdout
