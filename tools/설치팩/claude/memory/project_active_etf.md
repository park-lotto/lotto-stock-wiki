# 액티브ETF관리 파일 활용법

**파일**: `raw/매일 엑셀넣을것/액티브ETF관리MMDD.xlsx`
**Why:** 액티브 ETF는 종목을 능동적으로 교체함 → 편입 직전 수급 유입, 편출 직전 수급 이탈 예측 가능

## 파일 구조

- **64개 시트** = 섹터별(코스닥액티브·반도체·로봇 등) + ETF별(KoAct·TIME·PLUS·TIGER 등)
- **컬럼 구조** (시트당 ETF 3개 병렬):
  ```
  | 종목명 | CPD[오늘] | 이전날짜 | 비중차이 | 증가율 |
  ```
- CPD = 현재 편입 비중(%)
- 비중차이 = 오늘 - 이전 (양수=편입증가, 음수=편출)

## 활용법 (태린이아빠 방식)

### 핵심 로직
```
수급빈집(하위25%) + ETF 비중 증가 = 🔴 최강 매수 시그널
수급과매수(상위25%) + ETF 비중 감소 = 🔴 매도/회피 시그널
```

### 실전 예시 (2026-06-02)
- 비나텍 → 서진시스템으로 교체 예고
- 비나텍: ETF 편출 예정 → 수급 이탈 시작
- 서진시스템: ETF 신규 편입 예정 → 수급 유입 예상
- 수급오실레이터 + ETF 비중 오버레이 차트로 시각화

### 교차 분석 조합 (나중에 구현 예정)
```
1. 수급빈집 목록 (오실레이터 하위 25%)
2. 액티브ETF 비중 증가 종목
3. 교집합 → 탑픽 후보
```
