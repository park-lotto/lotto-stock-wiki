## ★핵심 결론 — "스파인 쌓기"는 이미 실패한 방식이다

라이브 실측:
```
spine 34개  →  실제로 쓸 수 있는 것 3개
              31개는 beat_roles가 없어 목록에 아예 안 뜬다(죽은 재고)
```
살아남은 3개의 공통점은 **실제 전사로 공식을 뽑은 것**이다
(단정 명령형 12편·가족갈등 반전형 4편). 나머지 31개는 이름만 짓고 근거가 없어 죽었다.

→ **개수가 아니라 근거다.** 사장님 말씀대로 틀은 고정하고 내용물만 바꾸는 게 맞다.
   증거: 이븐쇼핑 2편 전사에서 볼드 어구가 **글자 그대로 동일**했다({제품}·{효능}만 다름).

## 썰 대본 템플릿 (라이브 spine id=55·56)

### A. 은폐형 — 이븐쇼핑류 (`제품정체형` 카테고리)
```
title → bait → authority → reveal → benefit → twist
"{X} 망하게 한 {나라} 천재의 발명품"
"최근 딱 봤을 때는 [용도를 알기 힘든/평범한] 이 {제품군}이"
"이걸 개발한 {나라}의 천재가 돈방석에 앉았다는데"
★"이건 바로 {제품}"                      ← 5~7초에 정체 공개
"이게 말도 안 되는 게 {효능}"
★"근데 진짜 충격적인 포인트는 {효능2}"     ← CTA 없이 닫는다
```

### B. 오용형 — 살림킹왕짱류 (`오용형` 카테고리)
```
title → origin → notice → cases → twist
"[권위자]도 [부정어] 미친 사용법"
"이게 원래는 {본래용도} 개발된 제품이었음"
"그런데 사람들은 {속성}을 눈치채고 엉뚱한 용도로 쓰기 시작하는데"
"{용도}로 쓰는가 하면 …"
★"근데 미친 사용법은 따로 있었는데 {용도}"  ← CTA 없이 닫는다
```
말끝이 **`~었음`·`~다는 거`** — 인스타의 `~했어요`와 다르다.
둘 다 `no_cta=True`·`chars_per_30s=270`(실측 262~283).

## ★영상에서 무엇을 뽑아야 하나 — 빈칸 8종

| 빈칸 | 어디서 | 상태 |
|---|---|---|
| `{제품}` | product_facts.title | ✅ 기존 |
| `{효능}` `{효능2}` | product_facts.why | ✅ 기존 |
| `{나라}` | product_facts.origin | ✅ 기존 |
| **`{본래용도}`** | **sul_facts.original_use** | ★신규 |
| **`{속성}`** | **sul_facts.hidden_property** | ★신규 |
| **`{용도}`** | **sul_facts.misuses** | ★신규 |
| **`{제품군}`** | **sul_facts.category_word** | ★신규 |

**빈칸이 안 채워지면 모델이 지어낸다 — 그게 "AI 티 나는 대본"의 정체다.**
`sul_facts.SLOT_SOURCE` 표가 빈칸↔추출을 못박고, 테스트가 짝을 강제한다
(템플릿에 새 빈칸이 생기면 추출도 같이 늘어야 통과).

### 왜 product_facts로는 안 되나 (0순위-B 위반 아님)
`product_facts`는 **쿠팡 상세·리뷰**를 읽는다("이 제품이 왜 좋은가").
오용형이 요구하는 건 **영상에만 있다** — 쿠팡은 '원래 용도'나 '엉뚱한 사용처'를 안 판다.
재료의 **출처가 달라서** 별도 모듈이다(같은 판단을 두 번 하는 게 아니다).

### 실측 검증 (살림킹왕짱 실제 자막 2편)
```
옷수선 1,047만   original_use=의류 태그 부착 / hidden=옷감 손상 제로·티 안 남
                misuses=바지 밑단·의류 임시수선·커튼 밑단·침대커버 고정 / category=수선도구
다이소후크 904만  original_use=압축봉 걸이 / hidden=봉 없이 고리 단독·테이프 분리
                misuses=벽면 정리·변기 뚜껑 손잡이·문 손잡이 / category=후크
```
스파인이 요구하는 칸이 **전부 실제 값으로** 채워졌다.
