# 브리프 — 조사 (소넷 워커용, 하이브리드 <연예인>)

**목표**: `channel/yanshottem/하이브리드_<연예인>/조사/조사.md` 한 파일. 원본 영상에서 연예인이 **본인 입으로 말한** 제품과 그 말의 시각, 제품의 사실(출처별), 금지 품목 여부.
**읽을 것**: `tools/calcopy/검수_매뉴얼.md` A1·A2·A6·A11·A13 · 정본 `channel/yanshottem/하이브리드_장윤정/조사/조사.md`(같은 꼴로 쓴다).
**받은 것**: 원본 URL(run.py init --source) · `C:/숏템_칼카피/yanshottem/하이브리드_<연예인>/src/<원본>.mp4 · .ko.vtt · .info.json`(없으면 `py tools/calcopy/hybrid/screen.py download <W> <id>`).

## 할 일
1. 자동자막(vtt)에서 제품 언급 시각을 전부 뽑는다(`tools/calcopy/yanshot/common.py vtt_words`). 제품명·브랜드·"이거 진짜 좋다" 류 본인 말 구간을 표로(원본 초 · 말).
2. 그 구간을 서버 받아쓰기로 확인한다(모델 2개 교차): `py tools/calcopy/engine/gemini_server.py asr <원본.mp4> --spans "a-b,a-b"`. 자막과 받아쓰기가 다르면 둘 다 적는다.
3. 제품 사실: 브랜드 공식/판매처 설명 · 리뷰 영상 2개 이상 · 연예인 본인 말 — 출처별 표. 시험 수치가 아닌 것은 '브랜드 문구'로 표시. 최상급·범위 숫자 단정 금지(A2).
4. 금지 품목(의약품·의료기기·기능성화장품 효능 주장)인지 결론 1줄. 멈출 이유가 있으면 맨 위에 **멈춤** 이라고 쓴다.
5. 검색어·키워드 제안: `run.py <연예인> init --keywords <제품명,영문> --queries "…" "…"` 에 쓸 것 5~8개 + 뺄 단어(모음집·가성비·TOP).
6. 받아쓰기 구간 파일 `C:/숏템_칼카피/yanshottem/하이브리드_<연예인>/asr/spans.json` 을 적는다: `[{"src":"src/<원본>.mp4","a":224.8,"b":231.0,"tag":"O1"}]`.
