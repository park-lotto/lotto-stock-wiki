# 스타일 2·3번 후보 — 5채널 분석 (2026-08-05)

## ✅ 확대 표본 재검증 (같은 날 저녁, 백필 후 채널당 27~35개·총 183개)

1차 판정(7~11개 표본)이 확대 표본에서도 유지·강화됨. 새로 확정된 시그니처:

- **chae2home (30개, 최고 631만)**: 시그니처 포맷이 기계처럼 반복된다 —
  훅 "저 이거 때문에 (시어머니/엄마/아빠)한테 욕 바가지 먹을 뻔했어요" (30개 중 ~15개)
  → 가족 방문 사건 → 관용구 **"표정이 싹 굳으시면서 왜 이런 게 있다고 말을 안 해줬냐
  하시더라고요"** → "하나 바로 주문해 드렸는데 ~ 좋아하시는 거 있죠? 그래서 (친정엄마/
  시어머니)것도 하나 더 주문했는데" → "나도 남겨주세요?". 숫자 소구(500만원 아낌·3만원
  vs 100만원)도 자산. **체급·차별성 모두 1순위 후보 확정 근거 강화.**
- **home._.standard (30개, 최고 292만)**: 1차의 "정보 전수형" 판정을 보정 — 본체는
  **남편 화자의 유머 목격담**("와이프한테 쫓겨날 뻔" "등짝 스매싱" "장모님이 혼내시는")
  + 실용 정보 + CTA 키워드 연동("품번은 '필름'"). 유머 코드가 메종·채이 어디에도 없는
  고유 자산이라 3번 유지.

→ 최종 추천 불변: **스타일1 메종(발견담) / 스타일2 chae2home(가족 갈등 드라마) /
스타일3 home._.standard(유머 목격담+실용)** — 서사 축 3각 유지.

근거: `other_channels_scripts.json` (채널당 대본 7~11개, 조회수 상위) 직접 분석.
1번은 메종홈디노 확정(`style_maison_homedino.md`). 아래에서 2·3번을 고른다.

## 채널별 스타일 요약

### chae2home (11개, 최고 273만) — "관계 드라마형"
- 훅: "저 이거 때문에 진짜 충격먹었어요" / 금지형 "절대 소금 참기름만 넣지 마세요"
- **본체 = 인물 티키타카**: 시어머니·숙모·남편·네일샵 친구의 **대사를 직접 인용**하며
  갈등→반전 드라마를 만든다 ("표정이 싹 굳으시면서 왜 이런 게 있다고 말을 안 해줬냐")
- 감각 묘사 최상급: "겉은 바삭 탱탱, 속은 폭신 촉촉 사르르" / 숫자 소구("3만원 케어를 6천원에")
- 어미: ~는 거 있죠 / ~다니까요 / CTA "나도 남겨주세요?" 의문형
- 화자: 주부 1인칭. 대본이 제일 길고 스토리텔링이 제일 진하다.

### home._.standard (10개, 최고 33만) — "생활정보 전수형"
- 훅: "여러분 다이소 가면 이거 바로 사세요!" 명령형 / "절대 ~하지 마세요" 금지형
- **출처 권위가 공식**: 다이소 5년차 이모, 양파농사 30년 삼촌, 정육점 삼촌, 한식조리사 이모
- 원리 설명이 붙는다("양파는 90%가 수분이라 열과 습기가 차서…") — 정보 밀도 최고
- ★CTA가 우리 규칙과 이미 동일: 제품 연관 키워드("필름"·"얼룩"·"양파") + **보상 명시**
  ("양파 남겨주시면 보관법 바로 보내드릴게요")
- 화자: 중성적. 감정 과장 적고 실용적.

### homterior_pick (8개, 최고 62만) — "남편 감탄형"
- 훅: "와 이거 보고 진짜 헛웃음부터 나오더라고요" — 전부 '와'로 시작
- 화자가 **남편/남성**: 아내 관찰담("아내가 너무 좋아합니다") + 합쇼체 섞임("~습니다")
- ⚠️메종홈디노와 결이 상당히 겹친다(남성 화자·감탄·발견담). CTA 느슨("아무 댓글 주세요")

### homeditor_insta (7개, 최고 410만) — "육아맘 특화형"
- 훅: "애들 아침에 쌀밥 절대 안 돼요" — 아이 건강 불안 소구
- 소재가 아이 중심(방학·간식·성취감·KC인증·밀가루 없이) — **육아 카테고리에선 최강**,
  일반 홈템·가전엔 안 맞는다(적용 범위 좁음)

### gomson.salim (7개, 최고 10만) — "빠른 티키타카 경량형"
- "아니 ~거든요 → 와 ~거 있죠" 구어 리듬, 시어머니 티키타카 — chae2home의 짧은 버전
- 조회수 체급이 낮고 chae2home과 겹침
