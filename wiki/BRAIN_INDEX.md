# STOCK BRAIN — 6레이어 분석 프레임워크

> 탑다운 분석. L1부터 순서대로 읽어야 맥락이 잡힘.
> 수동 수집 중 → 크롤링 전환 시 raw/ 폴더 구조 그대로 유지.

---

## 분석 순서 (탑다운)

```
L1 글로벌유동성  →  돈이 풀리는가, 조이는가
        ↓
L2 미국시장구조  →  어떤 섹터로 돈이 흐르는가
        ↓
L3 한국시장구조  →  외국인·기관이 한국에서 어떻게 움직이는가
        ↓
L4 국제정세      →  특정 섹터를 뒤바꾸는 이슈가 있는가
        ↓
L5 섹터          →  살아있는 섹터는 어디인가
        ↓
L6 수급          →  그 섹터 안에서 빈집 종목은 어디인가
                          ↓
                      🔴 탑픽
```

## 수동 수집 우선순위 (크롤링 전)

```
1순위 (매일): L6 수급 — 오실레이터, 외국인·기관 상위
2순위 (주2~3): L5 섹터 — 주력 섹터 리포트·뉴스
3순위 (주1):  L3 한국시장 — 코스닥·코스피 시황
4순위 (주1):  L2 미국시장 — 나스닥·섹터 ETF
5순위 (이슈): L4 국제정세 — 미중·지정학 이슈 시
6순위 (월1):  L1 글로벌유동성 — Fed·M2·DXY
```
