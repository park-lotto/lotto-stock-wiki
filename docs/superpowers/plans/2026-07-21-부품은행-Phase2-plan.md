# 부품은행 Phase 2 Implementation Plan — 생성이 은행에서 조립

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 스크립트 생성이 승인된 스파인(아크) + 승인된 부품(top-k 성과가중)에서 조립하고, 대화체 스코어러가 요약체/AI냄새를 재생성 상한 2회로 걸러 안 되면 사람에게 빨간불로 넘긴다.

**Architecture:** 위험도로 2겹 분리. **토대(신규·격리, 위험0)**: 스파인 선택자 store 리더 + 부품블록 조립기 — 기존 생성 무변경, 순수 신규. **배선(기존 생성경로 개조, 고위험)**: `_GEN_PROMPT`/`_MIX_PROMPT`/`_scene_first_candidates`에 부품·스파인 블록 주입(opt-in 플래그, 기본 off로 회귀0) + `_verify_and_fix`에 톤 축·cap-2·빨간불 + B4 표절가드 우회. 각 배선은 기본값 off라 켜기 전까지 라이브 생성이 안 바뀐다.

**Tech Stack:** 기존 `script_generate.py`(Gemini 직접, `.format()` 프롬프트) · `edit_plan.py`(scene-first) · `tone_score.py`(A3, Phase1.5 라이브) · `store.py` pattern/spine 테이블. 테스트는 `Store(tmp)` + 가짜 `call`.

## Global Constraints

- **[격리]** 전 편집 `.tracks/부품은행/...`. main 폴더 무편집. `git -C .tracks/부품은행`.

- **[회귀0 기본]** 모든 생성경로 개조는 `use_bank=False` 기본. 켜지 않으면 프롬프트가 지금과 바이트 동일. 이게 finish 게이트 안전선.

- **[R4]** 스파인 fit_categories·부품 통계는 `category_source IN ('user','gemini')` 소스 기반(Phase1에서 이미 보장).
- **[B3]** 부품은 버킷당 top-k(perf 상위 3~5)만 주입 — 은행 전체 붓기 금지(토큰·희석).
- **[B4]** 주입된 승인부품 리터럴은 표절가드(`_plagiarism_flags`, 임계0.5)에 오탐된다(원본 full_text에서 딴 것). 주입 시 그 소스 full_text를 가드 대상에서 제외하거나 beat에 bypass 태그.
- **[재생성 상한 2]** 톤 실패 시 최대 2회 재생성. 그래도 실패면 초안 그대로 두고 `tone_flag=True`(빨간불) — 무한루프 금지. fit≤2 UI 패턴 재사용.
- 모든 Gemini 콜 `call=` 주입점 유지 — 테스트는 실 API 안 침.

```python
    def pick_spine_for_category(self, category, status="approved", min_sources=3):
        """생성용 스파인 1건 — 승격게이트(status·source_count) 통과 + category가
        fit_categories에 포함되는 것 중 perf 최고. 없으면 None."""
        best = None
        for sp in self.list_spines(status=status):     # perf_score DESC 정렬됨
            if (sp.get("source_count") or 0) < min_sources:
                continue
            fits = sp.get("fit_categories") or []
            if category and fits and category not in fits:
                continue
            best = sp        # 첫 통과가 최고 perf(정렬 보장)
            break
        return best
```

```python
# shopping_shorts/bank_assemble.py
"""생성 프롬프트 주입용 은행 컨텍스트 조립(Phase2 토대). store 읽기만, Gemini 없음.
★중괄호 소독 필수 — script_generate 프롬프트가 .format()을 돌린다."""
from shopping_shorts.pattern_bank import STYLE_BUCKETS

_LABEL = {"hook":"훅","ending":"마무리","adverb":"담화부사","cta":"CTA","price":"가격표현"}


def _sanitize(text):
    return (text or "").replace("{", "(").replace("}", ")")


def spine_charter(spine):
    if not spine:
        return ""
    parts = []
    if spine.get("situation_type"):
        parts.append(f"상황={_sanitize(spine['situation_type'])}")
    if spine.get("emotion_arc"):
        parts.append(f"감정선={_sanitize(spine['emotion_arc'])}")
    bc = spine.get("beat_chain") or []
    chain = " → ".join(_sanitize(b) for b in bc) if bc else ""
    head = "★학습된 아크(이 이야기 골격을 따르라): " + " · ".join(parts) if parts else ""
    if chain:
        head += f"\n  비트: {chain}"
    return head


def parts_block(store, k=5):
    lines = []
    for b in STYLE_BUCKETS:
        items = store.list_pattern_items(bucket=b, status="approved", order_by="perf", limit=k)
        if not items:
            continue
        texts = ", ".join(_sanitize(it["text"]) for it in items)
        lines.append(f"· {_LABEL.get(b, b)}: {texts}")
    if not lines:
        return ""
    return "[승인된 부품 — 이 결을 따르거나 이 중에서 골라 써라(그대로 베끼지 말고 녹여라)]\n" + "\n".join(lines)


def assemble_bank_context(store, category, k=5):
    spine = store.pick_spine_for_category(category) if category else None
    blocks = [x for x in (spine_charter(spine), parts_block(store, k)) if x]
    return "\n\n".join(blocks)
```
