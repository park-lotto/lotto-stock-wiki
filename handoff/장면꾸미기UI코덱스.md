# 장면꾸미기 UI·정밀 템플릿 디자인 시스템

## 2026-09-09

- 목표: 장면꾸미기를 `훅+본문 페어 프리셋 선택 → AI 문구 확인 → 완료` 흐름으로 재설계한다.
- 실제 레퍼런스 프레임을 사용하는 고해상도 UI 시안 4종을 `out/scene-style-ui-showcase.html`에 제작했다.
  - A `3단 편집기`: 왼쪽 프리셋, 중앙 큰 미리보기, 오른쪽 최소 문구 편집.
  - B `페어 갤러리`: 훅·본문을 한 카드에 크게 보여주는 탐색 중심 UI.
  - C `검수 스튜디오`: 제작자가 원본/렌더/차이를 비교하는 검수 UI.
  - D `간편 완성`: 초보 사용자를 위한 3단계 UI.
- 권장 구조는 A를 사용자 기본 화면으로 사용하고, B의 갤러리를 탐색 화면으로, C를 내부 제작자 도구로 분리하는 것이다.
- `shopping_shorts/template_system/`에 템플릿 디자인 시스템 기반을 만들었다.
  - `preset.schema.json`: 원본 캡처, 폰트 에셋과 해시, 색/그라데이션 정지점, 외곽선, 그림자, 훅·본문 독립 레이어, 검증 상태를 강제한다.
  - `ui-tokens.css`: 편집기 UI 토큰. 영상 템플릿 색과 분리한다.
  - `examples/ebeunshopping-pair.draft.json`: 제공된 이븐쇼핑 훅·본문 캡처의 1차 측정 예시. 아직 폰트와 픽셀 검증 전이므로 `draft`다.
  - `README.md`: 제작·대조·게시 게이트와 사용자 UI 원칙.
- 원본 기준값은 잠그고 사용자 변경은 별도 override 층에 저장하도록 규칙화했다.
- JSON Schema 자체 검사와 예시 데이터 검증을 통과했다.
- 크롬에서 4개 시안 전환, 이미지 로드, 가로 넘침을 확인했다.
- A 시안을 정적 썸네일이 아닌 분리 레이어 미리보기로 교체했다. 우측 문구 입력은 즉시 훅/본문 레이어에 반영되고, 프리셋 선택 시 채널명·강조색·헤더색·영상 소스가 함께 바뀐다.
- 중앙의 빈 공간에는 현재 선택 프리셋과 자동 배치 상태를 표시하고, 하단 장면 스트립에서 훅/본문 전환이 가능하다.
- 제공된 이븐쇼핑 캡처 2장을 `out/template_refs/`에 원본 해시와 함께 고정하고 `out/even-pair-precision-lab.html` 정밀 복제 작업판을 추가했다.
- 정밀 작업판은 원본과 분리 레이어 렌더를 같은 캡처 해상도로 나란히 보여주며, 훅 3개 문구와 본문 2개 문구를 실시간 교체할 수 있다.
- 기존 설정의 Spoqa 단독 사용은 원본 제목과 형태가 달랐다. 실제 브라우저 대조 결과 굵은 제목은 `TmonMonsori.ttf`가 더 가까워 제목 후보로 변경했고, 헤더·영상·하단 영역은 원본 픽셀 소스를 분리해 사용한다.
- 훅/본문 전환, 실시간 문구 입력, 초기화, 두 폰트 로드를 크롬에서 확인했다. 아직 제목 배경 질감과 글자 외곽선의 최종 픽셀 검수가 남아 있으므로 상태는 `draft`다.
- A 시안의 `숏템 기본형`을 360×640 원본 기준 전용 템플릿으로 교체했다. 훅 배경 `rgb(43,39,29)`, 강조 `rgb(255,229,0)`, 본문 상단 `rgb(255,233,168)`과 띠 그라데이션·그림자·실측 Y 좌표를 CSS에 고정하고 `TmonMonsori.ttf`를 직접 로드한다.
- 기본 문구 상태에서는 원본 프레임을 그대로 표시해 서브픽셀까지 동일하게 보존하고, 사용자가 입력하는 순간 실측 편집 레이어로 전환한다. 크롬에서 문구 수정, 다른 프리셋 전환, 숏템 복귀, 훅/본문 전환을 실제 클릭해 확인했다.
- 문구 편집 패널을 프레임별 필드 구성으로 변경했다. 숏템 본문은 실제 구성대로 `채널명 · 훅 제목 · 현재 장면 자막` 3개만 표시하며, 훅에서는 `채널명 · 훅 제목 1 · 훅 제목 2 · 보조 제목`을 표시한다. 채널명은 상단과 프로필 옆 이름에 동시에 반영되고 글자 수 표시도 입력값을 따라간다.
