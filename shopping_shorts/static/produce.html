10 · SNS 예약 발행

완성한 영상을 인스타·유튜브·틱톡 등에 예약해 올립니다. 올리는 곳은 내 Buffer 계정입니다.
❓ 처음이신가요 — 이렇게 하시면 됩니다
1. buffer.com 에 무료로 가입합니다. 3채널까지 공짜입니다.
2. Buffer 안에서 내 인스타·유튜브·틱톡 계정을 연결합니다.
3. Buffer 설정의 API 에서 키를 만들어 마이페이지 → 🔑 내 키 등록 에 붙여넣습니다.
4. 여기로 돌아오시면 내 채널이 목록으로 뜹니다. 고르고 예약하시면 끝입니다.
📖 그림으로 보는 준비 방법  ·  키는 숏템메이커가 대신해 드릴 수 없습니다 — 내 SNS에 올리는 일이라 내 키가 있어야 합니다.
먼저 마이페이지 → 🔑 내 키 등록에서 Buffer 키를 넣어 주세요. 이 키는 숏템메이커가 대신해 드릴 수 없습니다 — 내 SNS 계정에 올리는 일이라 반드시 내 Buffer 키가 있어야 합니다.
📼 올라갈 영상
이 작업에서 완성한 영상 그대로 올라갑니다. 파일을 따로 받아 올리실 필요 없습니다 — 정한 시각이 되면 Buffer가 우리 서버에서 직접 가져갑니다.
