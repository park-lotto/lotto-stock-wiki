# 썰 흐름 유지 + 목소리 구성 4종 — 강아지 케이블 커버 (라이브 확정 대본 사실만)

썰 칸 순서는 4종 모두 같다: 훅 → 문제 → 이건 바로 → 이게 말도 안 되는 게 → 심지어 → 충격 포인트 → 마무리
성우: 나레이션 미나 · 언니 칸나 · 동생/독백 유라 (일레븐 대화 API, 말 사이 0.4초, 1.25배)

| 파일 | 길이 | 구성 |
|---|---|---|
| 썰1_나레이션후_대화전환 | 35.9초 | 훅~이건 바로 = 나레이션 썰 → 나머지 동생↔언니 대화(의심 커짐 → 충격 포인트) → 나레이션 한 줄 마무리 |
| 썰2_고조계단_대화 | 31.1초 | 처음부터 대화. 동생 의심이 칸마다 한 계단씩("거기서 거기지"→"장식 아니고?"→"그게 다야?"→"꺾이면 끝이잖아"), 언니가 썰 칸으로 답 |
| 썰3_대화로열고닫기 | 35.8초 | 대화로 문제 상황 → 나레이션 썰(이건 바로~충격 포인트) → 대화로 마무리 |
| 썰4_나레이션+독백 | 39.3초 | 나레이션 썰 + 주인공 혼잣말([한숨]·[속삭임]·[놀람]) |

받아쓰기(Whisper medium)로 대사 누락 없음 확인. "꽉 물어"가 "꽝 물어"로 잡힌 곳 귀로 확인.
