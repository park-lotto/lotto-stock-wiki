# 키당렌즈20 — SerpApi 키 낸 회원 렌즈 한도 키 1개당 10→20 (2026-09-04)

사장님 지시: 박복례·mihwa101305 두 회원이 SerpApi 키를 등록했는데 하루 10회에서 막힘.
"등록한 사람들은 10→20으로, 모든 사람에게 그렇게".

## 한 것
- `shopping_shorts/app.py` `_CREDIT_PER_KEY_DEFAULTS["lens"]` 10 → 20. 키 1개=20회·2개=40회.
  판정은 `_limit_tier`/`_lens_limit_for`/`_effective_limits_all` 셋 다 이 상수 하나를 읽으므로 한 곳만 고침.
- 테스트: 옛 계약(기본 10) 검사 1건을 20으로 갱신 + 기본값 20 검사 1건 추가. 33건 통과.

## 주의
- DB 설정 `limit_lens_per_key`가 서버에 값으로 박혀 있으면 코드 기본값을 덮는다. 관리자 화면엔 이 칸이 없어
  테스트에서만 세팅하므로 라이브는 기본값을 탈 것으로 봄 — ★단 SSH 타임아웃으로 서버 DB 미확인.
  배포 후 관리자 고객목록에서 키 낸 회원의 렌즈 한도가 20/40으로 보이는지 확인.
