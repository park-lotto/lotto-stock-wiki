# 입체 사옥 첫 조작 검토본

## 승인과 목적
2026-09-13 대화에서 사용자는 외부가 기본인 3D 사옥, 내부 진입, 귀여운 로봇, 늘어나는 브랜드와 프로젝트, 터미널과 연결된 명령·중단, 크론 워커와 상급자 보고, 정밀한 제품 내부 공장을 요청했다. 아스트라가 디자인하고 페이블이 기술 구조를 검토한다. 사용자는 작은 조작 검토본을 보여주며 확장하는 방식에 동의했다. 전체 디자인은 여전히 브레인스토밍 중이다.

## 이번 검토 범위
따뜻한 석재·짙은 금속·유리·층별 조명으로 만든 열린 3D 메이커스랩 사옥. 다섯 팀의 구역과 테라스, 여러 책상과 비인간형 로봇. 사옥 전체 → 부서 선택 → 로봇 선택 → 실제 저장 업무 조회 → 전체 복귀. 건물·팀·로봇은 제안된 공간 배치이며 실제 직원 수로 집계하지 않는다. 선택 구역 외 상층은 숨겨 내부 시야를 확보한다.

장면과 실무 패널을 분리한다. Three.js PerspectiveCamera와 OrbitControls 사용. 기본 드래그는 이동, 회전 모드 별도 제공. 휠/두 손가락 확대, 탭 선택, 드래그/멀티터치 후 오선택 방지. HTML 부서·워커 선택 버튼으로 키보드 대체 조작. reduced-motion에서 카메라 즉시 전환. 휴대폰은 상단 지도와 아래 상세 패널.

## 실제 자료 경계
GET /api/state의 companies/teams/roles/projects/assignments를 사용한다. 해당 팀·역할의 저장 배정만 보여주고 실제 모델 실행은 미연결로 표시한다. 새 업무/실제 중단/임의 셸 실행 API를 이번 시안에 추가하지 않는다. 기존 기록 화면으로 연결한다. 빈 시험 DB는 빈 상태, API 오류는 조회 실패와 마지막 조회 시각. 시연 로봇의 움직임을 실제 실행으로 표시하지 않는다. 공장은 기술 지도 검토 중 상태로 표시한다.

## 독립성과 전달
company_ops/scene 소스, company_ops/static/hq 전용 경로. 기존 페이지와 백엔드 보존. npm 고정 의존성과 번들 빌드로 브라우저 CDN 의존 제거. 127.0.0.1:8923 별도 시험 DB. 외부 배포/main 병합 없이 사용자 화면 검토 대기.

## 검증
실제 Chromium WebGL 실행·스크린샷 직접 검토. 사옥/팀/워커 전환, 전체 복귀, 마우스 이동/회전/휠, 터치 탭/드래그/핀치, 입력 취소·멀티터치 오선택 방지, reduced-motion, 390px/태블릿, API 실패/빈 상태/시험 업무 조회, 콘솔 오류 확인. 프레임 간격과 draw calls는 이 PC headless 환경 측정으로만 기록한다.
