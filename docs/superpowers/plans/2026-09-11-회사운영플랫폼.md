# 회사운영플랫폼 첫 실행판 — 실행 계획

> **실행 모델:** superpowers:subagent-driven-development 또는 superpowers:executing-plans로 체크 항목별 진행한다. 이번 인계는 실행 방식을 다시 대표에게 묻지 않는다.

**Goal:** 세 회사의 살아 있는 조직 지도와 실제 저장·업무 검증 흐름을 로컬에서 완성한다.
**Architecture:** 독립 FastAPI + SQLite + 정적 웹. 실제 고객 서비스와 분리. 기능·API 규격의 원본은 ../specs/2026-09-11-회사운영플랫폼-인수설계.md.
**Tech Stack:** 설치 확인된 Python/FastAPI/uvicorn/httpx, Node/puppeteer, HTML/CSS/SVG/JS. 아래 시험 코드는 실행 모델의 시작 기준이며 실제 구현에 맞춰 검증한다.

목표: 세 회사 → 팀 → 프로젝트 → 검증·운영기록을 탐색하고 실제로 저장하는 로컬 운영실.
범위: FastAPI + SQLite + 정적 웹. 기존 라이브 서비스에 영향 없음. AI/API/매출 연동은 미연결 표시.

1. 저장 동작 테스트: 생성, 단계 순서, 검증 근거, 반려/차단/재개, 버전 충돌, 재시작 후 유지.
2. 독립 company_ops 패키지에 API 구현. localhost 전용, 외부 Origin 쓰기 차단. 임의 명령 실행 없음.
3. 조직 지도, 회사 전환, 제품 목록, 프로젝트 입력/상세, 실제 이벤트 피드, 미연결 매출 구조 UI 구현.
4. 실제 서버 + 브라우저로 생성/전이/새로고침/반응형 화면 검증. 스크린샷 검토.
5. 독립 코드 검토와 핸드오프. Git 메타데이터 읽기 전용이므로 커밋/배포는 수행하지 않음.

API 계약: GET /api/state → companies, teams, roles, projects, events, stages, integrations.
POST /api/projects {company_id,title,team_id,owner,description}; POST /api/projects/{id}/actions {action,version,note,evidence,reviewer}.
action: advance, block, resume, reject. stages: intake, design, build, verify, done.
완료는 verify에서만, 근거와 담당자와 다른 검증자 기록 필수. 검증자 입력은 수동 기록이며 인증/실제 AI 검증이 아님.

## T1. API 행위 테스트부터 작성

파일: company_ops/tests/test_api.py. 표준 unittest + TemporaryDirectory + fastapi.testclient.TestClient 사용. create_app(db_path) 팩토리를 목표로 테스트를 먼저 쓴다. ROOT conftest 영향 없이 실행한다.

```python
import tempfile
import unittest
from pathlib import Path
from fastapi.testclient import TestClient
from company_ops.app import create_app

class WorkflowTest(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.addCleanup(self.tmp.cleanup)
        self.path = Path(self.tmp.name) / 'test.sqlite3'
        self.client = TestClient(create_app(self.path), base_url='http://localhost')
        self.addCleanup(self.client.close)

    def test_completion_requires_evidence(self):
        response = self.client.post('/api/projects', json=dict(
            company_id='makers', title='검증 업무', team_id='improve',
            owner='대표', description='실제 저장 시험'))
        self.assertEqual(response.status_code, 201)
        p = response.json()
        for stage in ['design', 'build', 'verify']:
            r = self.client.post(f"/api/projects/{p['id']}/actions",
                json={'action':'advance', 'version':p['version']})
            self.assertEqual(r.status_code, 200)
            p = r.json()
            self.assertEqual(p['stage'], stage)
        denied = self.client.post(f"/api/projects/{p['id']}/actions",
            json={'action':'advance', 'version':p['version']})
        self.assertEqual(denied.status_code, 422)
        self.assertEqual(self.client.get('/api/state').json()['projects'][0]['stage'], 'verify')

if __name__ == '__main__':
    unittest.main()
```
