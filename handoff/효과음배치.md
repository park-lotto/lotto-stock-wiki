# 🔊 효과음 배치·미리듣기 (2026-08-21, 회사PC)

## 한 줄
효과음을 **장면처럼** 3단계 장면편집에서 고르고·빼고·타점 옮기고 **미리 들어본다**. 전부 라이브.

## 왜 시작했나
사장님: "이븐쇼핑같은 채널들 보면 효과음이 다 들어가는데 우리는 어떻게 구현하지?"
→ 조사해보니 **시스템은 2026-07-22에 이미 완성·라이브**였는데(`장면라이브러리` 트랙,
   `match_sfx` 역할매칭·amix·업로드 UI) **sfx 자산이 0개**라 아무 영상에도 안 붙고 있었다.
   구현 문제가 아니라 등록 문제였다.
이어서 사장님: "믹스 3단계에서 장면 넘어갈 때 자동배치 되게. 빼거나 다른거 넣거나. 장면처럼"

## ✅ 오늘 한 것 (전부 main 병합·배포·브라우저 검증)

### 1. 전환 타점 신설 — `transition`
```
first      = 칸 시작
last       = 칸의 마지막 자막(종전 기본)
transition = 칸이 끝나는 순간 = 다음 칸이 시작하는 지점   ← 신설, 훅의 기본값
```
- 렌더는 `offset = b["dur"]` 한 줄(`video_assemble._burn_captions`)
- 이름은 `scene_match.SFX_POSITIONS`가 통제 — **한쪽만 늘리면 조용히 `last`로 떨어진다**

### 2. API 확장 (`POST /api/produce/mix/{job}/sfx`)
빼기만 되던 것을 교체·타점변경까지. `asset_id`는 소유권 확인(`get_scene_asset`),
`position`은 통제어휘만. 
```
{beat_idx}                        → 빼기
{beat_idx, asset_id}              → 교체·삽입
{beat_idx, position:"transition"} → 타점만 이동
```

### 3. ★재매칭이 수동 선택을 안 덮는다
`match_type="manual"` 표시. 재매칭은 **대본이 바뀔 때마다** 도는데(mix_pipeline) 무조건
덮으면 사장님이 바꾼 효과음이 조용히 되돌아간다 — 오늘 오전 장면편집 무음 사고와 같은 종류.

### 4. UI — 3단계 장면편집 칸 도구줄
```
✏ 대본수정 | 🔊 띠용 ▾ | ▶ | 다음 칸 넘어갈 때 ▾ | 비우기 | ✨ 채우기
```
- 효과음 자산이 0개면 **줄 자체를 안 낸다**(빈 드롭다운은 고장으로 보인다)
- `▶` = 그 소리만 즉시 미리듣기
- 칸·전체 재생 시 **타점에 맞춰 실제로 울린다**(`scene_play.armSfx`)
- 정지·일시정지에 예약 해제(안 하면 멈춘 뒤 울린다)

## ⏭ 남은 것

1. **★타이밍 미검증** — 자동화 브라우저 탭이 계속 `document.hidden`이라 setTimeout이
   클램프돼 0.7~0.8초 늦게 측정됐다(칸 2.04초 → 2.8초에 울림). **활성 탭 정확도는
   확인 못 했다.** 사장님이 눌러보고 늦게 들리면 → setTimeout 대신 **실제 재생 진행
   (seq/오디오 currentTime) 기준**으로 바꿔야 한다.
2. **실제 효과음 파일 없음** — 지금 등록된 건 검증용으로 ffmpeg로 만든 단순 톤 2개
   (id 13 `띠용(테스트)`/훅, id 14 `뿅(테스트)`/본문). 사장님 파일로 교체 대상.
3. **`sfx_volume` 기본 60은 추정치** — 실제 파일 넣고 렌더해서 귀로 튜닝(2026-07-22부터 미결).
4. **효과음이 비트보다 길면 다음 비트로 흘러넘침**(v1 알려진 한계, 스펙 §4.3).
5. **4단계 검수판은 아직 빼기만** — 교체 UI는 3단계에만 넣었다.
