# 보이스 속삭임 톤 — 설계

- **날짜**: 2026-07-16
- **트랙**: 보이스
- **상태**: 설계 확정(사장님 청취 판정 3건 반영), 구현 대기

---

## 1. 왜 만드나

사장님 요청: "ASMR처럼 약간 울림? 속삭임? 이런 느낌으로도 몇 개 만들면 좋을듯"

속삭임은 두 가지로 쓰인다. **둘 다 필요하다**(사장님 명시: "ㄱ의 기능도 꼭 필요함, 강조포인트 활용").

| 쓸모 | 뜻 |
|---|---|
| **ASMR 영상** | 영상 전체가 속삭임 |
| **강조 도구** | 일반 톤 영상에서 한 비트만 속삭여 귀를 끌어당김 |

두 번째가 값어치 있는 이유: 목소리를 낮추면 오히려 집중이 쏠린다.
사장님이 프로브를 직접 듣고 "목소리에 집중력이 확 쏠린다"고 한 것이 그 관측이다.

## 2. 실측으로 확정한 사실 (추측 아님)

프로브: `out/whisper_probe/` (성우 미나 · eleven_v3 · seed 42 고정 = take 편차 배제).
4케이스 전부 실합성 확인 — 크기가 47~52KB로 제각각이라 무음 mock이 아니다.

| 확인한 것 | 결과 |
|---|---|
| `[whispers]`가 한국어 성우에 먹히나 | **먹힌다** (사장님 청취) |
| `[curious][whispers]` 태그 2개가 되나 | **400 에러 없이 통과** |
| 태그 2개가 1개보다 나은가 | **낫다** — 사장님 판정 "4번이 좋다" |
| 울림(리버브)이 필요한가 | **아니다** — 사장님 판정 "에코는 빼자" |
| `max_tags_total=3`이 죽은 값인가 | **아니다.** 예산으로 살아있다 — 5비트 대본에서 훅·CTA만 태그를 받고 나머지 3비트는 0개 |

> ⚠️ 마지막 줄은 내 의심이 **반증된** 것이다. "이 캡은 무의미하니 그냥 올리자"고 적었으면
> 틀린 전제 위에 설계를 얹을 뻔했다. 캡을 2로 올려도 **태그가 붙는 건 훅·CTA 2비트뿐**이라
> 도배가 나지 않는다 — 이게 B안을 안전하게 만드는 근거다.

> ⚠️ 프로브를 짤 때 `synthesize_tts`가 **키가 없으면 조용히 무음 mp3를 쓴다**(`_write_silent_mp3`)는
> 걸 알고 가드를 먼저 걸었다. 실제로 첫 실행에서 키가 안 잡혀 가드가 중단시켰다. 없었으면
> 무음 4개를 받고 "속삭임이 한국어 성우엔 안 먹힌다"는 **틀린 결론**을 낼 뻔했다.
> (키는 `/etc/shopping-shorts.env`에 있고 systemd만 읽는다. 프로브는 그걸 `source` 해야 한다.)

## 3. 핵심 설계 — 노브 하나, 값 두 가지

ㄱ(강조)과 ㄴ(ASMR)은 **별개 기능이 아니다. 같은 노브의 두 설정값이다.**

```
whisper_roles = 속삭일 role 목록
```

| 프리셋 | `whisper_roles` | 나오는 것 |
|---|---|---|
| `kr-mina-whisper` | 전체 role | 5비트 다 속삭임 = **ASMR 영상** |
| `kr-mina-stable` 등 | `["반전"]` (기본값) | 그 비트만 속삭임 = **강조 도구** |

**새 개념을 두 개 만들지 않는다.** 값만 다르게 준다.
이 노브는 프로파일에 들어가므로 **작업대에서 튜닝**되고, **새 저장층이 필요 없다**.

### 3.1 whisper는 감정 예산과 별개 축이다

감정태그(`_ARC_BY_ROLE`)는 예산이 있다 — 강도에 비례해 훅·CTA부터 채운다.
**whisper는 그 예산에 얹지 않는다.** whisper 톤인데 예산이 모자라 중간 비트가 안 속삭이면
"ASMR 영상"이 깨지기 때문이다.

결과 예시 (whisper 톤, 5비트):

```
훅       [curious][whispers] …
페인포인트  [whispers] …          ← 감정태그는 예산 밖이라 없음
반전      [whispers] …
실용      [whispers] …
CTA      [excited][whispers] …
```

### 3.2 태그 순서는 `[감정][whispers]` 로 고정

프로브에서 사장님이 좋다고 한 4번이 `[curious][whispers]` 순서였다.
**순서를 바꿔 검증한 적이 없으므로** 관측된 순서를 그대로 고정한다.
(v3가 순서에 민감한지는 **미검증** — 바꿀 이유가 없으니 확인하지 않는다.)

### 3.3 캡을 1 → 2 로 올린다

`caps.max_tags_per_beat: 1 → 2`

올리는 근거는 §2의 실측이다: 태그가 붙는 건 훅·CTA 2비트뿐이라 "태그 도배 금지"라는
원래 설계 의도가 깨지지 않는다. **3 이상으로는 올리지 않는다** — 2가 필요한 최대치다.

## 4. 프리셋 — 성우 14명 × 4톤 = 56개

지금: 42개 = 14명 × `stable` / `natural` / `expressive`
추가: 14개 = 14명 × `whisper`

`whisper` variant는 기존 variant와 같은 모양이다(`preset_id` / `group_id` / `variant` /
`voice_settings` / `sample_file` …). 다른 건 `naturalize_profile.whisper_roles`가 전체라는 것뿐.

샘플 mp3 14개를 새로 뽑아야 한다(`build_voice_samples.py`, ElevenLabs 크레딧 소모).

## 5. 사장님이 실제로 하는 일

작업대는 **성우마다 한 번** 하는 세팅이지 영상마다 가는 곳이 아니다.

```
① 작업대(voice_tune.html)  → 조정 → ▶합성 → 귀로 확인 → 💾동결   ← 가끔
② 프리셋에 naturalize_profile 저장 (성우별)
③ 제작 페이지(produce.html) → 성우 카드에서 "미나 · whisper" 선택   ← 매번
④ 렌더가 mix_pipeline.synthesize_line() 으로 그 프로파일 사용
```

**사장님이 매번 하는 일은 카드 하나 더 고르는 것뿐이다.**
지금 카드가 stable/natural/expressive 3개인데 whisper가 4번째로 생긴다.

## 6. 안 만드는 것 (YAGNI)

| 항목 | 왜 안 만드나 |
|---|---|
| **울림·리버브·에코** | 사장님 판정 "에코는 빼자". `audio_post` 리버브도 울림 슬라이더도 만들지 않는다 |
| **영상별 비트 토글** | 지금 엔진은 성우별 프로파일로만 굴러간다. 넣으려면 "영상별 비트 설정"이라는 **새 저장층**이 필요하다. role 규칙으로 먼저 내보고 "이 영상만 다르게"가 실제로 생기면 그때 얹는다 (사장님 승인: "ㄱ으로 해보고 나중에 수정하자") |
| **속삭임 강도 슬라이더** | 태그는 켜지거나 꺼질 뿐 중간이 없다. 강도 개념이 성립하지 않는다 |

## 7. 검증 기준

이 트랙의 규약이 그대로 적용된다 — **"테스트 통과" ≠ "테스트가 결함을 잡음"**.

1. **뮤테이션 필수** — 모든 수정에 대해 일부러 깨뜨려 **정확히 그 지점에서** 실패하는지 확인.
   특히 `whisper_roles`를 빈 목록으로 바꾸는 뮤턴트가 죽어야 한다(안 죽으면 배선 테스트가 0개다).
2. **스테이지 뮤턴트는 `_STAGES` 튜플 자체를 교체할 것** — 모듈 속성 패치는 무효인데 테스트는 초록이 된다(거짓 안전).
3. **격리 프로파일 `_p`가 아니라 순정 `merge_profile({})`로 검증** — `_p`는 `emotion_arc`를 꺼서 태그 관련 결함을 통째로 가린다.
4. **최종 게이트는 사장님 귀** — 자동테스트로 대체 불가.
   ⚠️ **작업대 코퍼스 10줄로는 이 기능을 온전히 볼 수 없다.** 코퍼스에 강조어로 시작하는
   줄이 0개라 오늘 고친 T6 결함이 화면에 안 뜬 전례가 있다. 실제 대본으로 확인할 것(= T8이 필요한 이유).

## 8. 알려진 한계 (정직하게 남김)

- **role별 whisper는 성우별 설정이다.** 같은 성우로 만드는 모든 영상이 같은 규칙을 탄다.
  영상마다 다르게 하려면 §6의 새 저장층이 필요하다.
- **태그 순서 민감도 미검증** (§3.2).
- **`[whispers]`의 효과는 성우·문맥 의존**이라고 ElevenLabs 문서가 명시한다. 미나로는 확인했지만
  **나머지 13명은 확인 안 했다.** 샘플 14개를 뽑을 때 각 성우마다 실제로 속삭이는지 들어봐야 한다 —
  안 먹히는 성우가 있으면 그 성우는 whisper 톤을 빼는 게 맞다(억지로 붙이면 품질이 떨어진다).
