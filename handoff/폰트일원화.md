## 한 것 ① 폰트 목록 일원화 (커밋 `a4cb2284e`)

### 문제
폰트 목록이 **세 벌**이었다 — `produce.html`의 `@font-face`·`HC_FONTS`,
`produce_intro.html`의 `@font-face`(체험판 화면, HC_FONTS는 없음).
하나만 빠뜨려도 **오류 없이 조용히** 기본체로 나온다.

### ★백엔드는 이미 일원화돼 있었다 (실측 — 처음엔 내가 "4벌"이라고 잘못 말했다)
| | 상태 |
|---|---|
| `/fonts/*.ttf` URL | ✅ `static/` 루트 마운트(`app.py:15091`)라 **파일만 넣으면 열린다** |
| `video_assemble.py` | ✅ 파일명을 받아 `_FONT_DIR`에서 찾는다(목록 없음) |
| `deco_frame.py` | ✅ override로 파일명을 받는다(목록 없음) |

**손볼 곳은 프론트뿐이었다.**

### 해결 — 정본 하나 + 빌드 스크립트
```
정본: shopping_shorts/static/fonts.json
도구: py tools/sync_fonts.py          ← 세 곳을 여기서 다시 써 넣는다
      py tools/sync_fonts.py --check  ← 최신인지 검사만(테스트가 부른다)
```
표식 `@@FONTS:BEGIN` ~ `@@FONTS:END` 사이를 갈아끼운다. **표식을 지우지 마라.**

**폰트 추가 = ①파일 넣기 ②fonts.json 한 줄 ③도구 실행.** 서버는 무수정.

### ★왜 런타임 JS 주입이 아니라 빌드 스크립트인가 (사장님 선택)
`@font-face`를 브라우저에서 만들면 폰트 로드가 늦어 첫 화면에서 글꼴이 잠깐
기본체로 보인다(FOUT). 고객 화면이라 그 위험을 안 진다.

## 한 것 ③ 폰트 즐겨찾기 (커밋 `162ef2913`)

**계정마다 ★를 눌러 자주 쓰는 폰트를 맨 위로.** 기본값은 사장님이 정하고 각자 바꾼다.

### 저장 (사장님 선택: 서버 계정)
```
customer_prefs(customer_id, key, value JSON)   ← store.py, 범용 표
  get_pref / set_pref / clear_pref
API: GET·POST /api/fonts/favorites  ({files:[...]} 전체교체 / {reset:true} 되돌리기)
기본값: fonts.json의 star  ← app._font_fav_default(). ★파일명을 코드에 또 적지 않는다
```

### ★적용 = 폰트 고르는 곳 **6군데 전부**
메인 메뉴 · ⚡빠른 조절 · 자막 · 틀 글자 2곳 · 썸네일 레이어.
**정렬은 `fontList()` 한 곳만** 정한다(0순위-B). `test_font_favorites`의
"HC_FONTS.map이 남아 있으면 실패"가 강제 — **실제로 내가 놓친 ⚡빠른 메뉴를 잡았다.**

### ★설계에서 지킨 것
- **'안 고침' ≠ '별을 다 끔'**: 후자를 기본값으로 되돌리면 일부러 비운 걸 무시하는 셈.
  행이 없을 때만 default를 쓴다.
- **전체 목록 통째 저장**: 토글 한 건씩 보내면 빠르게 누를 때 순서가 뒤집혀 어긋난다.
- **별 클릭 ≠ 폰트 선택**: `stopPropagation`+`preventDefault`. 테스트가 강제한다.
- 별은 **왼쪽 별도 레이어** — 별에까지 폰트를 입히면 손글씨체에서 별이 뭉개진다.

### ★내가 낸 회귀 1건 (잡아서 고침) — 다음에도 밟을 자리
썸네일 테스트는 `produce.html`의 **6단계 구간만 잘라 Node로 단독 실행**한다.
그 안에서 바깥 함수 `fontList()`를 불러 **`ReferenceError`로 5건이 깨졌다.**
(메모리 `reference_슬라이스하네스_window금지`와 같은 함정 — 이 저장소가 **네 번째**)

→ `thumbFontOptions()`를 **슬라이스 안**에 두고 `typeof` 가드.
   **브라우저에선 안 걸린다**(페이지 전체가 로드되니 함수가 있다) — 전체 pytest만 잡는다.

> **교훈: 6단계 썸네일 구간을 편집할 땐 바깥 함수를 직접 부르지 마라.**

### 검증 (브라우저 실측 포함)
playwright로 실제 확인 — 즐겨찾기 8종 맨 위 · 별 37개 렌더 · 별 클릭 시 순서변경+서버저장 ·
**선택 폰트 안 바뀜** · 되돌리기 · 빈 목록 유지. **콘솔 오류 0건.**
