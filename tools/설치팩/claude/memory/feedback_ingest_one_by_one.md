인제스트는 파일 한 개씩, 깊게 처리한다. 대량으로 몰아서 하면 안 된다.

**Why:** 한 번에 많이 하면 중요한 내용이 넘어가거나 과도하게 요약된다. 태린이아빠 3,455줄 절반 미독, 수급 리스트 이미지 패스, 브로드컴 분석 1줄 요약 등 실제 매매 인사이트가 유실된다.

**How to apply:**
- 파일 1개 읽기 → wiki 업데이트 → 다음 파일 순서로 진행
- 텔레그램 긴 파일(1,000줄+)은 섹션별로 나눠서 읽고 반영
- "다음 파일 뭐야?" 확인 후 진행
- 한 세션에 2~3개 파일이면 충분. 많이 한다고 좋은 게 아님
- 이미지 기반 내용은 "이미지라 파악 불가" 명시하고 넘어가기
