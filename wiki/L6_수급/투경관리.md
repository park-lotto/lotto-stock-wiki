## 📋 해제 조건 공식 (raw/투경해제 공식.xlsx 실증 검증 완료 — 2026-05-27)

### 기본 원칙

```
지정 후 10영업일(≈14달력일) 경과 후부터 매일 체크.
아래 3가지 조건이 【모두(AND)】 해소되어야 다음 영업일 해제.
하나라도 살아있으면 이연(다음 영업일 재체크).
```

### 코스닥 기준

| 조건 | 공식 | 해소 판정 |
|------|------|---------|
| ① T-5 조건 | 당일 종가 < T-5일 종가 × **160%** | < 기준가면 ✅ |
| ② T-15 조건 | 당일 종가 < T-15일 종가 × **200%** | < 기준가면 ✅ |
| ③ 최고가 조건 | 당일 종가 ≠ 최근 15영업일 최고가 | 오늘이 최고가 아니면 ✅ |
| **해제** | **① AND ② AND ③ 모두 ✅** | 다음 영업일 해제 |

### 코스피 기준

| 조건 | 공식 | 해소 판정 |
|------|------|---------|
| ① T-5 조건 | 당일 종가 < T-5일 종가 × **145%** | < 기준가면 ✅ |
| ② T-15 조건 | 당일 종가 < T-15일 종가 × **175%** | < 기준가면 ✅ |
| ③ 최고가 조건 | 당일 종가 ≠ 최근 15영업일 최고가 | 오늘이 최고가 아니면 ✅ |
| **해제** | **① AND ② AND ③ 모두 ✅** | 다음 영업일 해제 |

> ★ 코넥스는 코스피 기준 준용  
> ★ 사유유형(급등형/불건전형)으로 구분하는 것이 아님 — 시장(코스피/코스닥)으로 구분

### 현재 투경 종목 해제 조건 현황 (2026-05-27 장마감 기준 — fetch_투경.py 자동 분석)

**🟢 제주반도체 (080220 / 코스닥) — 3조건 모두 해소, 5/28 해제 예상**
- 현재가: 108,200원 (전일 대비 하락)
- ① T-5 비율: 112.8% < 160% ✅
- ② T-15 비율: 190.8% < 200% ✅ (117,800 기준 미달로 해소)
- ③ 15일 최고가: 해소 ✅
- **판단**: 3조건 AND 모두 해소 → 5/28 해제 예상

**🔥 코리아써키트 (007810 / 코스피) — ③ 최고가 조건만 미해소**
- ① T-5 조건: ✅  ② T-15 조건: ✅
- ③ 15일 최고가 = 오늘 종가 ❌ → 내일 신고가 미경신시 해소
- **판단**: 5/28 신고가 미경신 → 즉시 해제. 경신 시 이연.

**🔴 파인텍 (131760 / 코스닥) — 해제 요원**
- T5/T15 비율 479.2% — 액면병합(5:1) 후 기준가 극히 낮아 조건 미충족
- 현재가: 4,965원
- **판단**: 장기 모니터링. 해제 후 재검토.

## 투경 종목 주의 원칙

- 투경 지정 종목: 탑픽 스코어 -1 페널티 (수급 신뢰도 하락)
- 투경 해제 후 수급 재진입 확인 시 페널티 복구
- 투경 상태는 해당 stock/ 최신 이벤트 섹션에도 기록
- `fetch_투경.py` 스크립트로 매일 해제 조건 자동 분석 가능
