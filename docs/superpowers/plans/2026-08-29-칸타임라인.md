# 칸 타임라인 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement
> this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 장면연구소 각 칸에 자막·TTS·컷이 한 시간축에 정렬된 타임라인을 만들고,
구절 경계 편집(재TTS 없이 초 재계산)·고정길이 박스 장면 교체·싱크 단계 표면화까지 잇는다.
AI 매칭(픽) 로직은 무변경.

**Architecture:** 프론트는 새 파일 `scene_timeline.js`(scene_lab.html이 로드, 페이지
전역 DATA/planClips/capsOf/curT/setBoxLen을 사용)에 타임라인 부품을 만들고, 선택된
칸(`sel`)의 `.h` 아래에만 삽입한다. 서버는 기존 narration POST(5040)를 본떠
caption_lines POST 하나를 추가하고, 재계산은 기존 `caption_sync.phrase_durs_from_words`
+ 사이드카 `<mp3>.align.json`을 재사용한다(재합성 없음). 좌표 규약: 층은 없음(칸 폭
고정 pps), 자식은 절대 t×pps — off 개념 자체를 두지 않는다(08-29 이중차감 사고 예방).

**Tech Stack:** vanilla JS(기존 방식), FastAPI(app.py), pytest.

**실측된 계약(2026-08-29 — 이 이름들만 쓴다):**
- `planClips(lists[i], beatDur(i), STRETCH[i], i)` → 렌더와 같은 컷 배치(scene_play.js)
- `capsOf(i)` → [{start,end,text}…] · `DATA.tts_dur[i]` · `capAt(i,t)`
- 재생 시계 = `curT()` 하나, 재생 중 칸 = `seqBeat`, `playKey==='beat:'+i`
- 필름 [+구간] 길이 주입 = `S.inst.setBoxLen(sec)` (scene_lab.html:3104 기존 배선)
- 워드 타임스탬프 = `tts_timestamps.words_from_mp3(mp3)` (사이드카 `<mp3>.align.json`)
- 구절 재계산 = `caption_sync.phrase_durs_from_words(narr, words, dur, preset=lines)`
- 서버 라우트 본보기 = `POST /api/mix/scene_lab/{job}/narration/{beat}` (app.py:5040)

- [ ] filmroll.js 모듈 스코프에 프레임 추출 헬퍼(전역 CACHE와 별도, 같은 원리):

```js
// ★타임라인 컷 펼침용 — 구간 [a,b]를 n장으로. 기존 fillVisible과 같은 시크·캡처.
const FRAME_CACHE = {};                    // "vid|a|b|n" → [dataURL…]
const _FVIDS = {};                         // vid → <video> 재사용
async function filmframes(vid, src, a, b, n){
  const key = `${vid}|${a.toFixed(2)}|${b.toFixed(2)}|${n}`;
  if (FRAME_CACHE[key]) return FRAME_CACHE[key];
  let v = _FVIDS[vid];
  if (!v){ v = document.createElement('video'); v.muted = true; v.preload = 'auto';
           v.src = src; _FVIDS[vid] = v; }
  await new Promise(r => { if (v.readyState >= 1) return r();
    v.addEventListener('loadedmetadata', r, {once:true}); setTimeout(r, 5000); });
  const cv = document.createElement('canvas'); cv.width = 96; cv.height = 170;
  const x = cv.getContext('2d'); const out = [];
  for (let k = 0; k < n; k++){
    const t = a + (b - a) * (k + 0.5) / n;
    await new Promise(r => { let done = false;
      const fin = () => { if (done) return; done = true; v.removeEventListener('seeked', fin); r(); };
      v.addEventListener('seeked', fin);
      try { v.currentTime = t; } catch(e){ fin(); } setTimeout(fin, 800); });
    try { x.drawImage(v, 0, 0, cv.width, cv.height); out.push(cv.toDataURL('image/jpeg', 0.6)); }
    catch(e){ out.push(''); }
  }
  FRAME_CACHE[key] = out; return out;
}
global.filmframes = filmframes;
```
