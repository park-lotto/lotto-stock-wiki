# 쿠팡검색근거

## 2026-09-05
- 랭킹 카드 쿠팡 버튼이 "벽선반"·"프라이팬" 같은 범주어를 뽑던 것 수정 — 프리워밍이
  **썸네일 이미지만** 보내고 캡션을 버리고 있었다(카드엔 이미 있는데 요청에 안 실림).
  캡션을 같은 호출에 얹어 해결 — **모델 호출 1회 그대로, 비용·지연 0**.
- 버튼 이름 `🛒 쿠팡에 있나?` → `🛒 쿠팡검색`(판독 시 `🛒 3단 조립식 벽선반 쿠팡검색`).
- ★쿠팡용 프롬프트·캐시(`shop_product`)를 묶기용(`product`)과 **분리** — 아카이브
  유사도가 같이 흔들리면 안 된다(0순위-B). 사보타주 5종으로 가드 확인.
- ⚠️ 한계: 실측 10건 중 캡션이 실제로 도움되는 건 2~3건. 맛집·방법영상은 애초에
  팔 물건이 없다. 커밋 `b7de8f8ab`.

## 2026-09-05 (2차)
- '살 물건 없음'(맛집·방법영상) 카드를 **회색 처리** — 판독은 이미 빈 문자열로 답하는데
  화면이 조용히 건너뛰어 헛클릭이 났다. 클릭해도 판독 재실행 없이 이유만 안내.
- ★같이 잡은 버그: 프리워밍 필터가 `it.thumbnail`을 요구해 **캡션만 있는 카드가
  브라우저에서 잘리고** 있었다(1차에서 서버·모델만 고쳐놨던 것). 배선은 층마다 확인.
- 사보타주 6종 전부 빨개짐 확인. 실브라우저 검증(opacity 0.45·grayscale(1)·pageerror 0).
  커밋 `2ad194c24`.
