# 담기유튜브검색 (관제 060)

## 2026-10-01 — 유튜브 검색 결과(렌즈 키워드 검색탭)에서 쇼츠 카드 📥

- 제보: 사장님 "유튜브 담기가 없다, 1.10인데 왜 안 되나" → 렌즈 키워드 검색탭 = youtube.com/results
- 뿌리: 09-02 '유튜브는 쇼츠에서만'(`_ytOff`)이 /results를 통째로 꺼 버렸고, 카드 담기(`addAnchorCardBtns`)는
  /shorts/ 링크를 원래 안 잡았다. 버전·설치 문제 아님.
- 수리(`shopping_shorts/userscript/grab_logic.js`): `_ytResults()` 판정 1곳 → `_ytOff` 예외 + tick에서 `_ytResultsTick`
  (플로팅·렌즈·채널등록·시크바 걷고 쇼츠 카드 📥만). 카드 셀렉터는 /results에서만 `a[href*="/shorts/"]`.
  LOGIC_VER 20261001, 확장 manifest 1.11.0.
- 실크롬 실측(확장 로드): 수정 전 카드 0 → 후 15개(Right angle drill)·20개(쇼핑쇼츠), 클릭 시
  `/api/grab?url=https://www.youtube.com/shorts/<ID>` 팝업, 검색 페이지 이동 없음. 쇼츠 화면 플로팅·메인 꺼짐 유지.
- 테스트: tests/test_grab_yt_results_cards.py 신설, test_pinterest_grab 버전 단언을 '이상'으로.
- ⚠️ 확장은 웹스토어 미등록이라 **회원은 /grab에서 1.11.0을 다시 받아 설치해야** 반영된다.
