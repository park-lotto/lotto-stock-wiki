# 대본 교정 출구

## 원인

- 생성기와 의미 판정기는 확률적이라 정상 재료가 있어도 모든 후보를 반려할 수 있다.
- 스타일 생성과 픽업 생성이 각각 빈 배열을 반환했고, API가 이를 HTTP 502로 바꿔 대본 화면 자체를 막았다.
- 2026-09-15 박복래 고객 얼음정수기 작업에서 이 경로가 실제로 반복됐다.

## 수정

- 실패한 AI 초안을 검토용으로 다시 노출하던 임시 폴백을 제거했다.
- `script_fallback.py`가 `claim_evidence()`의 원본 발화·장면 관측·검증 상품 사실만 읽어 최소 대본을 만든다.
- 스타일과 픽업 생성 모두 정상 결과가 0개일 때 같은 장면 근거 출구를 사용한다.
- 화면은 `장면 근거로 자동 복구`임을 별도로 표시한다.
- 인증·소유권·재료 없음 422는 유지한다. 영상 재료가 있는 생성 요청만 0안 금지 대상이다.

## 검증

- 새 모듈 없음 → 실패, 빈 생성 결과 → 실패, 화면 안내 없음 → 실패를 각각 확인한 뒤 구현했다.
- 원본 근거만 사용, 중복 제거, 실패 AI 주장 미노출, 스타일·픽업 빈 결과 복구, 정상 결과 우선, 화면 안내를 회귀 테스트로 고정했다.

## 배포 후

- 실제 얼음정수기 또는 QA 작업에서 생성 API가 HTTP 200과 초안 1개 이상을 반환하는지 확인한다.
- 정상 AI 대본이면 기존 결과만 보이고, 강제 실패 조건에서만 장면 근거 복구 안내가 뜨는지 확인한다.
