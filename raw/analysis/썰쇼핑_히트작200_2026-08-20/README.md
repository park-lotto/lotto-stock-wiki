# 썰쇼핑 히트작 200편 골격 실측 (2026-08-20)

> **용도**: ①대본 틀(스파인) 설계 근거 ②숏템하우스 3편 영상 소재
> **찾는 법**: `py tools/find_work.py 골격` / `py tools/find_work.py 히트작200`
> 보고 문서(사장님이 보신 것): https://claude.ai/code/artifact/2ac9ef2d-e20e-4b89-a6f4-050c37ec0aea

## 무엇을 쟀나

썰쇼핑 등록 채널 **107곳** → yt-dlp로 **2,428편** 수집 → 조회수 상위 **200편 자막 전량**
(확보율 100%) → 문구 규칙으로 골격 판정 → 상위 31편은 Gemini로 슬롯·장면까지 분해.

**YouTube API 쿼터 0** (yt-dlp가 조회수까지 준다 — 발굴 루프가 쿼터를 다 써서 403이 나던 상황을 우회).

## 핵심 수치 (영상에서 인용할 것)

| 항목 | 실측값 |
|---|---|
| 표본 | 200편 / 조회수 6.6만 ~ 1,200만 |
| **오용형 계열** | **92편(46%) · 평균 151.8만** ← 편수·조회수 동시 1위 |
| 은폐형(이븐쇼핑류) | 15편(7%) · 평균 27.0만 |
| 목격담형 | 12편(6%) · 평균 75.7만 |
| 권위자형 | 4편(2%) · 평균 56.6만 |
| 기타(규칙 미분류) | 77편(39%) — Gemini 분해 시 3%로 떨어짐 |
| **필요 장면 개수** | **평균 3.3개 / 중앙값 3개 / 범위 2~5개** |
| 훅이 장면을 안 가림 | **58%** (아무 제품샷이나 가능) |
| 클라이맥스 보유 | 53% / 고조("심지어") 보유 55% |

★**가장 중요한 발견**: 사장님이 예시로 주신 이븐쇼핑(은폐형)은 소수파다.
실제로 터지는 주류는 **원래 용도를 뒤집는 오용형** — 1,200만·1,000만·910만 상위권이 전부 오용형.

## 오용형 골격 (슬롯)

```
훅          "코스트코 본사도 몰랐던 천재 아이디어"      장면 자유(58%)

숨은성질     "사람들이 특유의 접착력에 주목하면서"       없어도 통과
용도 나열    "바로 강아지 산책시킬 때"                 ★장면 필수 (용도 1개 = 장면 1개)
클라이맥스   "근데 진짜 미친 사용법은 따로 있었는데"     ★장면 필수 (53%)
고조         "심지어 FDA 승인 받아서"                  (55%)
```

## 파일

| 파일 | 내용 |
|---|---|
| `hits.json` | 2,428편 목록(조회수·제목·채널·길이) — 표본 늘릴 때 여기서 더 뽑는다 |
| `hits_subs.json` | **200편 자막 전문**(구간 타임코드 포함) — 가장 값진 것 |
| `gemini_struct.json` | 31편 정밀분해(골격·원래용도·용도별 필요장면·역할) |
| `classified.json` / `classify_out.txt` | 200편 문구규칙 판정 결과 |
| `report.txt` · `table_report.txt` | 집계 리포트(위 표의 출처) |
| `sul_channels.txt` | 썰쇼핑 채널 107개(채널ID+이름) |
| `collect_ytdlp.py` | 채널→조회수순 수집 (API 0원). 인자=채널당 편수 |
| `pull_subs.py` | 자막 받기. 인자=상위 N편. 429 회피로 1.2초 간격 |
| `classify.py` | 문구규칙 골격 판정 → report.txt |
| `gemini_struct.py` | Gemini 슬롯 분해 → **서버에서 실행**(키가 /etc/shopping-shorts.env에만 있다) |
| `uses.py` | 용도 개수 규칙 카운터 — **부정확**(1,200만 영상을 2개로 셈). Gemini 쪽을 믿어라 |

## 다시 돌리는 법

```bash
# 1. 수집(로컬, API 0원)
python collect_ytdlp.py 25            # 채널당 25편 → hits.json

# 2. 자막(로컬)
python pull_subs.py 200               # 상위 200편 → hits_subs.json

# 3. 골격 판정(로컬)
python classify.py                    # → report.txt

# 4. 슬롯 분해(★서버에서)
scp gemini_struct.py hits_subs.json ubuntu@43.200.48.69:/tmp/
ssh ... "cd /tmp && set -a && . /etc/shopping-shorts.env && set +a && python3 gemini_struct.py hits_subs.json 60"
```

## 함정 (다음에 또 밟지 마라)

- **Gemini 키는 하루 한도가 있다.** 31편에서 429로 끊겼다(60편 요청 중). 나머지는 다음날.
- **YouTube API는 발굴 루프가 다 쓴다.** `harvest_styles_forever.py`가 상시 돌아 403이 난다
  → yt-dlp를 써라(쿼터 무관, 조회수도 준다).
- **윈도 콘솔은 cp949**라 한글·유니코드 기호를 print하면 죽는다 → 결과는 파일로 써라.
- **문구 규칙으로 용도 개수를 못 센다.** 자동자막은 오탈자·경계가 흐리다. 의미 판단은 Gemini에게.
- **script_extracts(581건)는 대부분 인스타다.** 유튜브 은폐형 표본은 여기 거의 없다 —
  그래서 이번에 따로 모았다.
