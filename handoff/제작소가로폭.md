## ★다음 세션이 반드시 알아야 할 함정 2개

### 1. `theme.css`가 `<style>`보다 **뒤에** 링크돼 있다 (`produce.html:504`)
같은 특이도면 **theme.css가 이긴다.** 실측으로 조용히 죽었던 규칙들:

```
.orb .ball{width:44px}          → 무시됨(computed 36x36 그대로)
.orbbar{justify-content:...}    → 무시됨(space-between 그대로)
.orb{flex:0 0 auto}             → 무시됨(1 1 0% 그대로)
```

모바일 진행바는 theme.css가 **안 정한** `overflow-x`·`min-width`만 우연히 살아남아
"되는 것처럼" 보였다. **computed style로 잡아야 보인다** — 눈으로는 성공처럼 보였다.
→ 해결: `!important` 대신 `.main` / `.orbbar`를 앞에 붙여 특이도를 한 단 올렸다.

**theme.css에 있는 셀렉터를 produce.html에서 건드릴 땐 반드시 computed로 확인해라.**
겹치는 것: `.cand` `.cand p` `.cmp-title` `.stat-tile span` `.stt .k` `.cta-shine` `.orb*`

### 2. 인라인 `style`은 CSS를 이긴다
대본카드 `font-size:15.5px`가 JS 템플릿 인라인이라 넓은화면 16px 확대가 통째로 죽었다.
→ 인라인에서 빼고 CSS `.main .cand`로 옮겼다. **크기를 정하는 곳은 한 군데**(0순위-B).
같은 이유로 `.cand .ghost` 버튼도 인라인 `font-size:11px;padding:4px 8px`를 지우고 클래스만 남겼다.

`#mixPreviewPanel{min-height:520px}`는 인라인이라 모바일에서 `!important`가 필요했다(실측 확인).
