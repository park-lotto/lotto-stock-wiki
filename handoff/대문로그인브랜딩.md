# 대문·로그인·브랜딩

> 트리거: "대문로그인 브랜딩 이어서" / "쇼핑쇼츠 이름·대문 이어서"
> 상태(2026-07-20 갱신): **★이름 확정 = `숏템탑스` + CI/BI 1차 보드 완성.** 다음 = 대문·로그인 실구현.

## ✅ 이름 확정 (2026-07-20 사장님) = **숏템탑스**
숏(쇼츠) + 템(파는 아이템) + 탑스(TOP 인기템) = "팔리는 숏폼 인기템을 뽑아낸다".
- 기준: 일반 쇼츠 아닌 **쇼핑쇼츠 특화** + 빠르고 편리(똑딱/뚝딱) + **어려우면 절대 안 됨**(쉬움 최우선).
- 기존 5안(영어=어려움) 반려 → 똑딱형→공장형(찍어낸다)→박스형 거쳐 숏템탑스 결정.
- 내부 코드/시스템명(shopping_shorts·제작소·딸깍)은 유지 — 이건 **고객 노출용 브랜드**.
- 메모리: `project_brand_name_shottemtops`.

## ✅ CI/BI 1차 보드 (2026-07-20, 오푸스 — 크롬 실렌더 검증)
`out/브랜딩_CI_숏템탑스.html` (더블클릭해서 보기).
- **워드마크**: 숏템(민트 그라디언트) + 탑스(골드) — Black Han Sans(디스플레이) / Noto Sans KR(본문).
- **시그니처 심볼**: STT 티어박스 — 상자(제작소·공장처럼 찍어낸다)에서 랭킹된 아이템이 쌓여 올라오고
  맨 위 한 칸만 골드=TOP 인기템. 앱아이콘~파비콘 축소도 실루엣 유지. (SVG 인라인, 3티어 rect + 골드 캡)
- **색**: 민트×블랙 계승(#6ff0d6→#1f9e7a, 패널 #111722) + **골드(#ffcf6f→#f0a93a)를 TOP/인기 딱 한 곳에만**.
- **응용**: 로고 4종(가로·세로·모노·반전 라이트) + 대문 히어로 미리보기(무료로 시작 CTA·9:16 TOP배지·댓글키워드).
- 실렌더서 잡은 결함 2건 수정: 한글 word-break:keep-all(단어 중간 끊김), 폰 TOP배지 z-index(제품 뒤 가림).

## 무엇을 만드나 (사용자 요청, 2026-07-20)
판매용 SaaS(현 내부명 "쇼핑쇼츠")의 **① 멋진 브랜드 이름 ② 대문(랜딩) 페이지 ③ 로그인 페이지**.
- 참고: 사용자가 보여준 레퍼런스는 **"Shopping Factory"** 로그인(다크·로고·구글버튼·"멤버십은 가입한
  아이디의 구글 로그인으로 진행해주세요"). **UI를 베끼지 말고 그 "구조"로, 우리 브랜딩으로** 만들 것.
- 지금 앱엔 공개 대문이 없다. `/`=로그인 뒤 레퍼런스 랭킹, 로그인=app.py `_LOGIN_HTML`("🛍️ 쇼핑쇼츠").
- 제품 본질: 레퍼런스 링크 넣으면 팔리는 쇼츠가 나오는 자동 제작(레퍼런스 랭킹·렌즈·대본추출·제작소·보이스).
- 기존 브랜드 토큰(계승): **민트×블랙** — `--grad:linear-gradient(135deg,#6ff0d6,#1f9e7a)`, `--sel-fg:#6ff0d6`,
  panel `#111722` (sidebar.js). 대문·로그인도 이 톤을 잇는다.
