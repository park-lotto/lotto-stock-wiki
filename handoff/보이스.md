**🔴 실사용에서 드러난 진짜 문제 — 강도 슬라이더가 안 먹는다 (사장님 관측, 재현 완료)**
`naturalize()`에 intensity 0.3/0.7/1.0을 넣어도 **출력이 완전 동일**. 0으로 내려야만 꺼짐 = 사실상 on/off 스위치. 스테이지별 원인:

| 스테이지 | 실제 동작 |
|---|---|
| 추임새 | `intensity < 0.15`면 off, 넘으면 **무조건 1개**(cap=1) — 임계형, 비례 아님 |
| 감정곡선 | 동일하게 `0.15` 임계 + 태그 1개 캡 → on/off |
| 끝음 | **마침표를 `…`로** 바꾸는 건데 **코퍼스 10줄에 마침표가 0개** → 영원히 무발동 |
| 구어체 | `take=int(len(hits)*intensity)` — 짧은 문장은 hits 0~1개라 `int(1×0.9)=0` → **1.0에서만** 발동하는 계단 |
| 끊어읽기 | 연결어미가 문장에 있어야 함 — hook 문장엔 없음 |
| 연음/발음 | 사전이 **비어있음**(`dict:{}`) |
| 억양 | **미구현** — 코드가 `return text`("최소 구현: 현재는 무변경에 가깝게") |

→ 8개 중 이 코퍼스에서 실제로 동작하는 건 **정규화·추임새·감정곡선 3개뿐**이고 그나마 강도는 on/off. 텍스트가 안 변하니 **소리도 동일**(seed 42 고정 = 같은 take).
→ **왜 테스트가 통과했나**: 각 스테이지를 자기한테 맞는 입력(마침표 있는 문장 등)으로 **격리** 테스트. 진짜 코퍼스로 통과시킨 적 없음. 오늘 리뷰가 잡은 게 "배선의 seam"이면 이건 **"내용의 seam"**.
