**Goal:** 사장님이 승인한 사람만 shopping_shorts를 쓸 수 있게 한다(대기실 방식). 기존 사용자는 안 막힌다.

**Architecture:** `customers.approved_at`(NULL=대기/값=승인시각) 컬럼 1개 추가. 판정 단일진실원 `access_level`에 `"pending"` 상태 추가. 공개 가입 경로 2곳만 대기계정 생성, 사장님이 admin `[승인]`으로 체험 시작. 세션은 무상태 쿠키라 승인 즉시 반영.

**Tech Stack:** FastAPI, SQLite(Store), 순수 HTML admin, pytest + TestClient.

## Global Constraints

- 작업 폴더: `.tracks/회원승인` 절대경로만. main 폴더 코드 절대 금지.
- 마이그레이션은 기존 라이브 DB 파괴 없이 ALTER 멱등. `_ensure_paywall_schema`(store.py:630) 패턴 복제.
- 테스트 파일: `shopping_shorts/tests/test_paywall_*.py` (루트 `tests/` 아님). 기존 conftest 픽스처 재사용.
- `create_customer`는 **기본 `approved=True` 유지** — 기존 직접호출 테스트(access/admin/gate/usage)가 "체험중=full"을 전제하므로 깨면 안 된다. 대기계정은 공개 가입 2경로만 `approved=False` 명시.
- 판정 순서(access_level): `cid==0→full` / `cust없음→ranking_only` / `approved_at IS NULL→pending` / `plan==pro→full` / `체험중→full` / `else ranking_only`.

    def create_customer(self, username, password, email=None, google_sub=None, approved=True):
        """신규 고객 계정 생성. username 중복이면 ValueError. 성공 시 customer_id 반환.
        approved=True(기본): 가입 즉시 승인+무료체험 시작(full_access_until=now+trial_days).
        approved=False: 대기중(approved_at=NULL) + 체험 미시작(full_access_until=0).
        체험은 사장님 승인 시점(approve_customer)에 시작된다."""
        salt = secrets.token_hex(16)
        pw_hash = self._hash_password(password, salt)
        now_ts = int(datetime.now(timezone.utc).timestamp())
        if approved:
            try:
                trial_days = int(self.get_setting("trial_days", 7))
            except (TypeError, ValueError):
                trial_days = 7
            full_access_until = now_ts + trial_days * 86400
            approved_at = now_ts
        else:
            full_access_until = 0
            approved_at = None
        with self._conn() as c:
            try:
                cur = c.execute(
                    "INSERT INTO customers(username, password_hash, salt, created_at, "
                    "plan, full_access_until, email, google_sub, approved_at) "
                    "VALUES(?,?,?,datetime('now'),'free',?,?,?,?)",
                    (username, pw_hash, salt, full_access_until, email, google_sub, approved_at),
                )
            except sqlite3.IntegrityError:
                raise ValueError(f"이미 존재하는 아이디: {username}")
        return cur.lastrowid
```

def access_level(customer_id, now=None):
    """customer_id → "full"(전기능) | "ranking_only"(랭킹만) | "pending"(승인대기, 전면차단).
    규칙: 사장님(0)=full / 계정없음=ranking_only / 미승인(approved_at NULL)=pending /
    plan=pro=full / 체험중(now<full_access_until)=full / 그 외 ranking_only."""
    if customer_id == 0:
        return "full"                       # 사장님 = 영구 pro+admin
    cust = Store(DB_PATH).get_customer(customer_id)
    if not cust:
        return "ranking_only"
    if cust.get("approved_at") is None:
        return "pending"                    # ★승인 전엔 plan/체험보다 우선해 전면 차단
    if cust.get("plan") == "pro":
        return "full"
    if now is None:
        now = int(datetime.now(timezone.utc).timestamp())
    if now < (cust.get("full_access_until") or 0):
        return "full"                       # 무료 체험 창
    return "ranking_only"
```
