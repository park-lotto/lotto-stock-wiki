## 2026-10-25 (사장님 PC) — 브레인스토밍 진행 중, 코드 없음

**목표(사장님)**: 하이퍼프레임 + 우리 모션팩 + 영상 찾기 기술 + 쇼츠 제작 기술로
주식시장에서 지금 제일 이슈가 되는 내용을 쇼츠로 자동 제작. 1차 목표 = **1편이 사람 손 없이 끝까지 나오는 것**
("한 편을 만들 수 있으면 나머지(시간당 편수)는 나중 문제").

### 정해진 것 (사장님 답)
| 질문 | 결정 |
|---|---|
| 어디까지 자동 | **자동 제작 → 사람이 확인 후 업로드** |
| 화면 재료 | **B. 우리 그래픽(차트·숫자·헤드라인 카드, 하이퍼프레임+모션팩) + 찾아온 실사 영상 몇 초씩** (영상마다 출처 기록) |
| 이슈 고르기 | **C. 시세(급등락·거래대금·지수 급변) + 화제(뉴스·텔레그램 언급 급증) 양쪽 후보 → 점수로 1개** |
| 시간대 | **A. 한국장 중심** (장전 08시~마감 16시). 편수는 1편 성공 뒤 문제 |
| 내용 깊이 | **겉 설명 말고 핵심을 관통**하는 내용 |
| ★제1원칙 | **추측 금지 — 대본 모든 문장은 근거(시세·수급·공시·기사·리포트)에 묶인다. 근거 없는 문장은 기계가 지운다** |

### 제안한 1편 골격(50~60초, 사장님 확정 전)
훅(사건+숫자) → 겉 이야기(뉴스가 다 하는 설명) → 진짜 이유(돈의 흐름·수급, 숫자 근거) → 번지는 곳 → 볼 신호(매수·매도 권유 금지)
