# 대본 지침

## 형식

```
## [훅]
문장. {F1}
[범퍼]
## [큰 질문 : 짧은 소제목]
문장. {F2·F3}
## [마무리]
```

- 한 줄이 한 문장이다. 줄 끝 `{F번호}` 는 읽지 않는 근거 표시다.
- 사실을 말하는 문장에는 반드시 번호를 붙인다.
- 분량은 필재 1.2 기준 음절 수 ÷ 391 = 분. 쓰기 전에 잰다.

## 구성

| 구간 | 길이 | 할 일 |
|---|---|---|
| 도입 | 40~60초 | 뉴스 숫자, 체감과의 차이, 흔한 설명, 그것만은 아니라는 근거, 큰 질문 |
| 본론 | 챕터 7~9개 | 챕터마다 원인 하나. 숫자 1~3개와 쉬운 비유 |
| 마무리 | 30~45초 | 세 문장 정리, 한 줄 결론, 앞으로 볼 지표 |

구독·좋아요 요청과 다음 편 예고는 넣지 않는다.

## 말투

- 옆자리 사람에게 설명하듯 쓴다. 존댓말 구어체가 기본이다.
- 긴 설명 뒤에 짧은 한 문장으로 끊는다.
- 어려운 경제 용어는 나오자마자 일상 비유로 푼다. 예: 실질과 명목 → 붕어빵 가게.
- 입으로는 어림수, 화면에는 정확한 수치와 출처.
- 시청자가 할 만한 반론을 먼저 꺼내고 답한다.
- 반대 근거도 말한다. 일회성 요인, 회복 전망, 인구 감소 같은 약한 고리를 숨기지 않는다.

## 금지

- 사실기록에 없는 숫자, 날짜, 비교
- 근거보다 센 표현. 예: "못 구해서 난리"를 근거 없이 쓰지 않는다
- 특정 회사·인물을 원인으로 단정
- 정치인 이름을 넣은 평가
- 전망을 사실처럼 말하기
