**날짜**: 2026-07-10
**목적**: 5개 진행 중 프로젝트(스탁브레인, 유튜브 자동화, 쇼핑쇼츠 자동화, SEO 워드프레스 자동화, 위키창고)의 "지금 뭘 하고 있었는지 + 다음 할 일"을 매일 자동으로 기록하고, 세션이 끝나도 진행 상황을 까먹지 않도록 한 화면에서 보여주는 개인용 대시보드.

카테고리 목록은 고정 5개로 시작. 추가/변경은 `config.json` 수정으로 처리 (요청 시).

## 저장소

`~/.claude/dashboard/` 아래:

- **`config.json`** — 카테고리 5개(이름 + 경로 힌트) + 발행된 Artifact URL(최초 발행 후 저장, 이후 재발행 시 항상 이 URL로 업데이트해 링크 고정)
- **`log.json`** — flat list, 각 항목 `{date, category, summary, next}`. 매 갱신 시 오늘 기준 7일 넘은 항목은 제거.
- **`dashboard.html`** — 매 갱신 시 재생성되는 Artifact 소스 파일.

## 자동화 흐름 (Stop 훅)

전역 훅(`~/.claude/settings.json`의 `hooks.Stop`)으로 등록 — 프로젝트마다 폴더가 다르므로 프로젝트별 설정이 아니라 전역 설정이어야 함.

1. 세션 종료 시 훅 발동.
2. 훅이 현재 세션의 작업 경로(cwd)가 `config.json`의 5개 카테고리 경로 힌트 중 하나와 매칭되는지 확인.
3. 매칭 안 되면 조용히 통과 — 무관한 세션(잡담, 다른 작업)은 로그를 남기지 않음.
4. 매칭되면 Stop을 한 번 막고, "오늘 이 카테고리에 대해 1~3줄 요약 + 다음 할 일을 `log.json`에 기록하라"는 지시를 주입.
5. Claude가 `log.json`에 오늘자 항목 추가 → 7일 넘은 항목 정리 → `dashboard.html` 재생성 → `config.json`에 저장된 Artifact URL로 재발행(새 링크 생성 안 되게 `url` 파라미터 필수로 사용).
6. 완료 후 Stop 통과, 세션 정상 종료.

**애매한 경우 처리**: 카테고리 매칭이 확실하지 않으면 추측해서 기록하지 않고 건너뜀 (엉뚱한 로그 방지). 한 세션에서 이미 기록을 남겼다면 같은 세션에서 재차 강제하지 않음(무한루프 방지).

## 화면 레이아웃 — 카드 그리드

카테고리 5개 = 카드 5개. 각 카드:
- 카테고리 이름
- 현재 상태 (최신 `summary`)
- 다음 할 일 (최신 `next`)
- 최근 7일 미니 로그 (기록 있는 날 ●, 없는 날 ○)

다크/라이트 테마 모두 대응. Artifact는 기본 비공개.
