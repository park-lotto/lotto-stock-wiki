# 유료게이트 (판매용 티어 접근) 설계

**작성**: 2026-07-19 / 트랙: 유료게이트
**목표**: 유튜브로 파는 웹앱을 "레퍼런스 랭킹만 맛보기(무료) → 결제 시 전 기능"으로 게이팅. 페이블 검토 반영.

---

## 1. 핵심 판단 (페이블 검토 수용)

1. **비용 게이트가 권한 게이트보다 중요**. 체험/무료 유저가 SerpApi(유료)·제작소 렌더·VMake 크레딧을 태울 수 있고 현재 서버측 호출 상한 코드가 **없다**(`lens_discover.py` 확인). → 시간제 체험 + **계정별 크레딧 상한**을 결합해 다계정 악용 피해를 계정당 상한으로 캡핑.
2. **게이트는 deny-by-default 미들웨어 한 곳**. 엔드포인트별 잠금은 새 API 추가 때마다 구멍. 무료 허용 경로 prefix만 명시, 나머지 전부 차단. (기존 `_AUTH_ALLOW` allowlist 패턴 재사용)
3. **다계정 리셋은 방어 대상 아님** — 크레딧 상한으로 피해 캡. 핑거프린팅은 과설계.
4. **관리자 승격 페이지 필수** — 없으면 서버 DB 직접수정 → 배포 정지 실사고(2026-07-14) 재발.
5. **시니어 UX**: 만료가 "고장"으로 안 읽히게. 잠긴 메뉴는 숨기지 말고 🔒 표시 + 클릭 시 안내 모달.

## 2. 접근 모델 (통합 스키마)

`customers` 테이블 확장:
- `plan TEXT DEFAULT 'free'` — 'free' | 'pro'
- `full_access_until INTEGER` — epoch초. 이 시각 전이면 전기능(=체험 창). pro는 무시.
- `google_sub TEXT` / `email TEXT` — 구글 계정 식별
- (기존 `id`=customer_id, username/pass 유지 — 사장님 admin 전용)

**판정기(단일 함수)** `access_level(customer) -> "full" | "ranking_only"`:
```
if customer.plan == 'pro': return "full"
if now < customer.full_access_until: return "full"   # 체험 중
return "ranking_only"
```
- 최초 구글 로그인 → 계정 생성 시 `plan='free', full_access_until = now + TRIAL_DAYS*86400` (이게 곧 체험)
- 체험 만료 → 자동 ranking_only (레퍼런스 랭킹만)
- 결제 → admin이 `plan='pro'` 승격 → 전기능 무기한
- **판정은 반드시 서버 DB 기준**(쿠키에 넣지 않음. 현 HMAC 쿠키는 세션 식별용만).

## 3. 로그인 (구글 OAuth, 1차 포함)

- 고객: **구글 OAuth**로만. 콜백에서 `google_sub`으로 기존계정 조회/신규생성.
- 사장님(admin): 기존 아이디/비번 로그인 유지, `customer_id=0` 고정 = 영구 pro + admin.
- `_AUTH_ON` 재정의: 비번(DASH_PASS) 또는 구글 설정 둘 중 하나라도 있으면 ON.
- 세션 쿠키 30일+ (시니어 재로그인 최소화). 판정이 DB 기준이라 세션 길어도 안전.
- **사장님 직접 작업**: 구글 클라우드 콘솔 OAuth 클라이언트 발급 → CLIENT_ID/SECRET을 `.env`에. redirect URI = `https://shoppingshorts.duckdns.org/auth/google/callback`.

## 4. 게이트 (deny-by-default)

미들웨어에서 `access_level` 판정 후:
- `FREE_ALLOWLIST` (ranking_only도 허용) prefix: 레퍼런스 랭킹 조회 API + `/`,`/static`, `/login`,`/auth/google/*`, `/api/me`, 로그아웃.
- 그 외 전부 → **402 Payment Required**(만료/무료) 또는 로그인 안내.
- 백그라운드 렌더 잡: **큐잉 시점 아니라 실행 시작 시점에도 재판정**(만료 직전 대량 큐잉 우회 차단). 진행 중 잡은 완주.

## 5. 비용 방어 (plan 무관, 지금 필요)

- **계정별 일일 크레딧**: `usage(customer_id, day, op, count)`. op = lens / render / script. 상한 초과 시 429 + 안내. (기본값: 무료·체험 lens 5, render 2, script 10 / pro 높게)
- **전역 일일 상한**: SerpApi·VMake 호출 총량 상한. 소진 시 텔레그램 알림(인프라 기존).

## 6. 화면 (시니어 UX)

- `/api/me` → {plan, access_level, days_left, limits}. 프론트가 이걸로 렌더.
- 체험 중: 상단 상시 배너 "무료 체험 D-N" (숫자 크게).
- ranking_only: 사이드바 유료 메뉴 🔒 표시(숨기지 않음) → 클릭 시 모달 "무료 체험이 끝났어요. 계속 쓰시려면 카톡/전화로 연락주세요" + **데이터는 보존됨** 안내.
- 잠긴 기능 소리없이 사라짐 금지.

## 7. 관리자 (`/admin`, customer_id=0 전용)

- 고객 목록(이메일·plan·가입일·체험만료·오늘 사용량) + [pro로]/[free로] 버튼 + 변경 로그.

## 8. 트라이얼 길이

`TRIAL_DAYS` 설정 상수. **기본 7일**(페이블: 48h 랭킹 갱신을 여러 번 봐야 가치 체감, 시니어 학습속도). 크레딧 상한이 비용을 캡핑하므로 기간 늘려도 손실 안 늚. → 사장님 확인값.

## 9. 구현 순서 (각 단계 독립 배포 가능)

1. **스키마+판정기**: customers 확장, `access_level`, `/api/me`
2. **구글 OAuth**: 콜백·계정생성·세션, admin 비번 유지
3. **API 게이트**: deny-by-default 미들웨어 + FREE_ALLOWLIST
4. **비용 방어**: usage 크레딧 상한 + 전역 상한 + 텔레 알림
5. **화면**: 배너·🔒메뉴·만료 모달
6. **관리자 페이지**: 승격 버튼

## 10. 범위 밖(다음)

- 카카오 로그인(시니어 친숙) — 구글로 1차, 필요 시 추가.
