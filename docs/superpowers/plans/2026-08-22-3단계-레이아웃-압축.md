# 3단계 레이아웃 압축 — 중복 제거·위로 올리기·스크롤 최소화

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development 또는 executing-plans.

**Goal:** 3단계(영상대본MIX)에서 ①중복 UI 2개를 없애고 ②장면 편집을 위로 크게 올리고 ③아래 썸네일을 위 카드와 같은 크기로 줄여 ④스크롤을 최소화한다.

**Architecture:** "자막+음성 완성본" 탭이 이미 렌더 입구 역할을 하므로 `🎬 대본×영상믹스 확정` 버튼과 매칭 진행바(다운로드~완료)는 **중복**이다. 지운 만큼 장면 편집이 위로 올라온다. 아래 소스 카드가 `aspect-ratio:9/16`(세로로 김)이라 스크롤을 길게 만드는 주범 — 위 타임프레임 카드와 같은 `4/5`로 맞춘다. iframe 높이 `150vh/1100px`(화면보다 크게 잡아 바깥 페이지가 스크롤되던 것)을 화면에 맞춘다.

**Tech Stack:** 바닐라 JS/CSS (produce.html / scene_lab.html), pytest + node JS 하네스

// ★'자막+음성 완성본' 탭이 렌더 입구다(2026-08-22 사장님 "이걸 누르면 랜더되는걸로").
//   예전엔 별도 [🎬 대본×영상믹스 확정] 버튼이 있었는데 탭과 역할이 겹쳐 지웠다.
//   ⚠️서버 렌더는 20초+ 걸리는 유료 작업이다 — **이미 만들어둔 게 있으면 다시 안 만든다.**
//   비어 있을 때만 부모의 startPreview를 부른다(부모가 로더·결과를 이 자리로 돌려준다).
function _askRender(){
  var body = document.getElementById('confirmBody');
  if (!body || body.innerHTML.trim()) return;        // 이미 있다(또는 만드는 중) — 그대로 본다
  try{
    var up = _outerPlayer();
    if (up && typeof up.startPreview === 'function'){ up.startPreview(); return; }
  }catch(e){ console.warn('렌더 요청 실패', e); }
  body.innerHTML = '<div class="cfLoad">⚠️ 제작소 화면에서 열어야 만들 수 있어요</div>';
}
window._askRender = _askRender;
