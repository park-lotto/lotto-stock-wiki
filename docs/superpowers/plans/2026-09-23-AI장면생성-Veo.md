# AI 장면 생성(Veo) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3단계 편집안의 각 칸에서 「✨ AI 장면」을 누르면, 그 칸의 재료 프레임(제품만 나오는 컷 우선, 청소본 우선)을 베이스로 Veo 3.1 Lite가 4·6·8초 클립을 만들어 장면 자산으로 저장하고 그 칸의 컷어웨이로 붙인다. 관리자만(스위치 `ai_scene_enabled` 기본 `admin`).

**Architecture:** 새 모듈 `shopping_shorts/ai_scene.py`가 베이스 프레임 선택·프롬프트 조립(초 단위 사건 순서, 금지 목록)·Vertex 호출·자산 저장을 맡는다. 워커 태스크 `ai_scene`이 돌리고, 결과는 `beat["cutaway"]`(기존 경로) + `beat["ai_scene"]`(상태)에 남는다. 화면은 `/api/mix/result`를 2초 폴링해 상태를 그린다.

**Tech Stack:** google-genai(Vertex, `veo-3.1-lite-generate-001`) · ffmpeg · 기존 scene_assets/cutaway 경로 · `_vault_call`(Gemini JSON) 프롬프트 생성

**Spec:** `docs/superpowers/specs/2026-09-22-AI장면생성-Veo-design.md` (+ 스파이크 실측 2026-09-22 20:10~21:00: 프롬프트는 "첫 프레임 묘사 + 초 단위 사건 + 재질·조명 + 금지 목록" 형태여야 하고, 제품만 나오는 장면은 제품만 있는 베이스 프레임이 필요하다)
