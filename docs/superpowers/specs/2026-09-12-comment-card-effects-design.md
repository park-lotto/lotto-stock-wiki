# 댓글 카드 효과 2종 설계

## 목표

숏템메이커 `장면꾸미기 > 효과`에서 댓글 카드를 고르고 문구를 수정한 뒤, 미리보기와 최종 세로 영상에 같은 모습과 타이밍으로 나오게 한다. 1차는 스타일 2종과 댓글 카드 1개만 지원한다.

## 사용 흐름

1. 효과 탭의 `댓글 카드`에서 `다크 소셜` 또는 `프리미엄 팝`을 누른다.
2. 작성자, 경과 시간, 댓글, 좋아요 수를 입력하고 프로필 사진을 선택적으로 올린다.
3. 미리보기 위의 카드를 드래그하고 크기, 시작, 노출 시간을 바꾼다.
4. 설정은 기존 `saveHeadcopy()` 통로로 `deco.comment_card`에 저장되며 재접속 시 복원된다.
5. 최종 렌더는 서버가 동일한 스타일 렌더러로 투명 PNG를 만들고 기존 타임드 오버레이 배관에 합성한다.

## 스타일

### 다크 소셜

검은 반투명 카드, 얇은 경계, 원형 프로필, 작성자·시간, 본문, 좋아요·댓글 표시를 가진다. 유튜브 소유 로고나 아이콘은 복제하지 않고 독자 형태를 쓴다. 아래에서 올라와 감속하며 제자리에 멈춘다.

### 프리미엄 팝

밝은 유리 카드, 색 그라데이션 프로필 링, 큰 인용 기호, 키워드 형광 선을 사용한다. 작게 팝업된 뒤 위로 들어오고, 핵심 문구가 지나가는 표현을 사용한다.

## 데이터 계약

`deco.comment_card` 필드는 `style`, `author`, `age`, `text`, `likes`, `avatar_file`, `x`, `y`, `width`, `alpha`, `start`, `dur`, `animation`을 가진다. 서버의 정규화 함수가 문자 길이, 숫자 범위, 스타일 ID를 한 곳에서 검증한다. 잘못된 값은 기본값으로 정규화하고 외부 경로는 허용하지 않는다.

## 렌더 구조

- `comment_card.py`가 스타일 토큰과 문구 배치의 단일 정본이다.
- 미리보기 API와 최종 렌더가 같은 `render_to()`를 사용한다.
- 생성된 PNG는 정규화된 스펙의 SHA-1 키로 캐시한다.
- 기존 `_motion_layer_filters()`가 `slide_up` 댓글 레이어의 시작·종료·위치를 처리한다.
- CSS 애니메이션은 편집기 미리보기에서만 사용하고, 최종 영상은 FFmpeg 시간축으로 결정론적으로 합성한다.

## 실패 처리

빈 댓글은 카드를 렌더하지 않는다. 프로필 사진을 읽지 못하면 작성자 첫 글자로 대체한다. 댓글 카드 생성이 실패하면 정상 영상까지 실패처리하여, 사용자가 댓글이 빠진 완성본을 성공으로 오인하지 않게 한다.

## 검증

- 정규화·PNG 렌더·캐시·프로필 폴백 단위 테스트
- 저장 호출·복원·스타일 2종 노출 UI 회귀 테스트
- FFmpeg 타임드 오버레이 필터 테스트
- 1080×1920 샘플 영상을 실제 렌더한 뒤 등장 전·중·후 프레임과 오디오 유지를 확인한다.

## 1차 제외 범위

유튜브 API 댓글 자동 가져오기, 댓글 여러 개 순환, AI 댓글 작성, 플랫폼 로고 복제, 픽셀 군중 효과는 포함하지 않는다.
