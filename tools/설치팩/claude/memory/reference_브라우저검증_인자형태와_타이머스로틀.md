2026-08-28, 쇼핑쇼츠 제작소. 사장님 **"이제 다시는 버그 안 생기는거 확실한지 검증해"**
한마디로 내 앞선 수정의 구멍 **3개**를 찾았다. 검증을 안 했으면 반쪽으로 끝났을 것이다.

## ① 인자 형태를 짐작하면 검증이 통째로 무효가 된다
`_renderPreviewVideo(job)`의 `job`은 **문자열 job_id**인데 나는 **객체**를 넘겨 검증했다.
브라우저 3건 + node 테스트 전부. 결과가 초록이든 빨강이든 **의미가 없었다.**

**실측 증거로 알아챘다**: 브라우저 `_PV_LAB_WAITED`에 `"[object Object]"` 키가 실제로
생겨 있었다(객체를 키로 쓰면 모든 항목이 한 칸을 공유한다).

→ **호출부를 grep해 실제로 무엇을 넘기는지 보고 나서** 하네스를 만든다.
   시그니처 이름(`job`)만 보고 짐작하지 마라. [[feedback_하네스는_호출부_형태_그대로]]

## ② 자동화 탭은 타이머가 심하게 느려진다(백그라운드 스로틀)
`setInterval(fn, 100)`이 **3초에 4회**만 돌았다(정상 30회). 장시간 백그라운드면 더 떨어진다.
→ "타이머가 20회 돌면 폴백" 같은 경로는 **브라우저로 실측 불가**.
   node 하네스에서 `setInterval`을 스텁으로 두고 수동 tick으로 검증하라.
→ 20초를 기다려도 안 되면 스로틀을 의심하라. 먼저 이걸로 재라:
   `let n=0; const t=setInterval(()=>n++,100); await sleep(3000); clearInterval(t);`

## ③ 고친 걸 **되돌려 실패하는지** 반드시 확인하라
이번에 두 번 헛돌았다. 처음 만든 테스트는 **버그를 되돌려도 초록**이었다(시나리오가
실제와 달라 문제 분기에 닿지도 않았다). 왕복 확인을 하고서야 진짜로 잡는 테스트가 됐다.
```
버그 되돌림 → 해당 테스트 실패 ✅
안전벨트 제거 → 해당 테스트 실패 ✅
둘 다 정상   → 전부 통과
```

## ④ 곁가지 — 내 수정이 남의 하네스를 깰 수 있다
복원 함수에 `_pvClose()`(document 사용)를 넣었더니, 그 함수를 잘라 node로 돌리는
**기존 테스트 7건이 ReferenceError로 죽었다.** 그 파일 관례대로 `try{...}catch(_){}`로 감싸 해결.
→ 함수에 줄을 추가하기 전에 **그 함수를 잘라 쓰는 테스트가 있는지** 확인하라.

## ⑤ "입구가 몇 개인지" 세어라
한 증상을 고칠 때 그 상태를 만드는 **입구가 여러 개**일 수 있다. 이번엔 레일을 여는
곳이 3곳인데 1곳만 고쳤다. 나머지로 열리면 그대로 남았다.
→ `grep`으로 입구를 전부 세고, **입구 수가 늘면 깨지는 테스트**를 넣어 두면 다음이 안전하다.
