인포그래픽 브랜드 스타일을 새로 추가할 때는 작업부터 벌이지 말고, **먼저 질문지로 어떤 스타일을 할지 사용자에게 확인**한 다음 진행한다.

**Why:** 클로드/클레이 스타일 실험을 여러 라운드(텍스트만 → 이미지소스 추가 → 재확인)로 반복하며 사용자가 매번 방향을 지정해왔음. 사용자가 "이제 질문지를 먼저 달라"고 명시적으로 요청(2026-07-03) — 매번 시행착오로 스타일을 좁혀가는 대신 처음부터 후보를 제시받고 싶어함.

**How to apply:**
- 새 브랜드 스타일(예: 애플/구글 등) 작업 요청이 오면, 실제 이미지 다운로드·프리셋 작성·테스트 생성에 들어가기 전에 먼저 질문지를 제시한다: (1) 어떤 톤/무드를 원하는지, (2) 실제 브랜드 이미지 레퍼런스를 줄지 텍스트 설명만으로 할지, (3) 다크/라이트 어느 쪽인지 등.
- 사용자가 컨펌하면 그 스타일은 `nlm_bridge.py`의 `BRAND_STYLE_PRESETS` dict에 영구 등록한다(임시 실험이 아니라 계속 재사용 가능한 프리셋으로 취급).
- 지금까지 등록된 프리셋: `claude`(크림+코랄 에디토리얼), `claude_terminal`(다크+픽셀아웃라인폰트+터미널창), `clay`(3D클레이메이션+채도색카드순환). 참고: [[project_brand_style_infographics]]
- 실제 브랜드 이미지 레퍼런스는 **꼭 주는 게 낫다**는 게 사용자 결론 — 텍스트 지침만보다 실제 CDN 이미지를 노트북 소스로 추가했을 때(clay 케이스) 훨씬 정확하게 재현됨. `getdesign.md`류 사이트의 GitHub raw 파일(design-md/{brand}/DESIGN.md)에서 텍스트 스펙을, 실제 브랜드 공식 사이트에서 이미지 몇 장을 직접 다운로드해서 병행하는 게 최선.
