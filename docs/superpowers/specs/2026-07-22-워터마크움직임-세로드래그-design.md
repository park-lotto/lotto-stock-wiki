# 워터마크 움직임 + 세로 드래그 — 설계/계획

- 날짜: 2026-07-22 / 트랙: 워터마크움직임 / 승인: 사장님 "고"
- 결정: 움직임=위아래 부드럽게 떠다니기(float) · 적용=미리보기+실제 MP4 둘 다

## 요구 (사장님)
1. 워터마크에 살짝씩 위아래 움직임 효과
2. 워터마크 기본 위치를 조금 더 살짝 위로
3. 워터마크를 미리보기에서 수동으로 이동 가능하게
4. 자막·워터마크를 마우스로 옮길 때 **세로로만**(가로 불필요)

## 해석
"자막"= 미리보기에서 드래그되는 화면 텍스트로 해석 → **헤드카피 + 추가텍스트 + 워터마크**를 세로 제약.
오버레이 이미지는 대상 아님(텍스트/워터마크가 아님). "가로 필요없어"에 부합.

## 변경 (2파일)

### produce.html
- **WM_POS.bc** `y:95 → y:88` (기본 하단중앙 살짝 위로).
- **updateDeco()**: 워터마크 spec에 `float:true` 추가. y는 `WM_MANUAL_Y`(드래그로 잡은 값)가 있으면 그걸,
  없으면 프리셋 y. 모듈 스코프 `let WM_MANUAL_Y=null;` 선언(WM_POS 옆).
- **wmPos select onchange**: `WM_MANUAL_Y=null; updateDeco()`로 바꿔, 위치 드롭다운 다시 고르면 수동 y 초기화.
- **wmPreview 렌더 블록**: 표시될 때 `pointer-events:auto`(현재 none이라 드래그 불가), `cursor='move'`.
  float 애니메이션 = Web Animations API `wp.animate([{transform:'translateY(-4px)'},{transform:'translateY(4px)'}],
  {duration:1500,direction:'alternate',iterations:Infinity,easing:'ease-in-out',composite:'add'})` —
  `composite:'add'`로 기존 `translate(-50%,-50%)` 센터링 보존. 1회만 바인딩(`wp._floatAnim` 가드).
- **워터마크 드래그(신규, 세로만)**: `wp.onmousedown`에서 `hcPreview` 기준 `clientY`만 읽어 `WM_MANUAL_Y` 갱신,
  `wp.style.top` 갱신. mouseup에 updateDeco(). `wp._dragBound` 가드로 1회 바인딩.
- **추가텍스트 드래그(bindExtraDrag)**: x 갱신 줄 제거 → **y만**.
- **헤드카피 드래그(bindHCDrag)**: hcX 갱신 제거 → **y만**(hcY만).

### video_assemble.py
- **_fixed_drawtext**: `spec.get("float")`이면 y표현식에 sin항 추가 —
  `y=(h*{yf}-th/2 + h*0.006*sin(2*PI*t/3))` (진폭 화면높이 0.6%, 주기 3s). 아니면 기존 `y=(h*{yf}-th/2)`.
  ffmpeg 식평가는 sin/PI/t 지원(자막 slide 선례로 검증됨).
- **워터마크 spec**(≈1082): `"float": wm.get("float", True)` 추가 → 기본 float on.

## 검증
- produce.html: 인라인 `<script>` 추출해 `node --check` 통과. grep로 x갱신 제거 확인.
- video_assemble: `py -c "import shopping_shorts.video_assemble"` clean. 가능하면 float spec으로 y표현식 문자열에
  `sin(` 포함되는지 단위 확인.
- 실제 float 렌더/청감은 finish 배포 후 실영상 1편으로 확인(로컬 렌더 무거움).
