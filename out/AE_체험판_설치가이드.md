## 1단계 — 체험판 신청

### 🚫 먼저 — 이 팝업은 닫으십시오

제품 페이지에 들어가면 이런 팝업이 뜹니다:

> **모션 디자인의 혁신** … Creative Cloud **모든 앱** 플랜을 40% 할인 … **₩46,860/월**

**이건 20개 이상 앱이 다 들어간 비싼 플랜입니다.** [구매하기] 누르지 마십시오.

### ✅ 실제 가격 (2026-07-25 Adobe 공식 플랜 페이지 확인)

| 플랜 | 가격 | |
|---|---|---|
| Creative Cloud 모든 앱 | ₩46,860/월 (정가 ₩78,100) | ❌ 과함 |
| **After Effects 단일 앱** | **₩30,800/월** | ✅ **이것** |

→ **₩16,060 차이.** 우리는 AE 하나만 필요합니다.

⚠️ 단일 앱은 **"연간 구독, 월별 청구"** = **1년 약정**입니다. 중도 해지 시 위약금이 있습니다.
   다만 Adobe 플랜 페이지에 **"구매 후 14일 이내에는 언제든지 무료로 취소"**라고
   명시돼 있고, 실제 결제화면도 '8월 08일 전 취소 시 전액 환불'이라 테스트는 안전 범위입니다.

### 신청 절차

1. **https://www.adobe.com/kr/products/aftereffects.html** 접속
2. 뜨는 "모든 앱" 팝업은 **닫기(X)**
3. 페이지에서 **[무료 체험판]** 버튼 찾아 클릭
   - 안 보이면: **https://www.adobe.com/kr/creativecloud/plans.html** →
     목록에서 **After Effects (₩30,800/월)** 카드 찾기
4. **결제 화면에서 반드시 확인**:
   - 상품명이 **"After Effects"** 인지 (❌ "Creative Cloud 모든 앱" 아님)
   - 금액이 **₩30,800** 인지
5. Adobe 계정 로그인 (없으면 가입 — 구글 계정 가능)
6. 카드 정보 입력 → 신청 완료

> 💡 결제 직전 화면을 **스크린샷 찍어 저에게 보내주시면** 맞는 플랜인지 확인해 드립니다.

## 2단계 — 설치

1. **Creative Cloud 데스크톱 앱**이 자동으로 다운로드됩니다
2. 설치 후 CC 앱 실행 → 목록에서 **After Effects [설치]** 클릭
3. ⏳ **용량이 큽니다(수 GB). 시간이 걸립니다** — 다른 일 하시면 됩니다
4. 설치 완료 후 **After Effects를 한 번 실행**해서 정상 구동 확인

> 💡 버전은 최신(2026)으로 받으시면 됩니다. 우리가 쓸 MCP가 2022~2026을 지원합니다.

## 3단계 — Claude에게 알리기

설치 끝나면 **"AE 설치 끝났어"** 라고만 말씀해 주십시오.

그다음은 제가 합니다:
- after-effects-mcp 내려받기 → 빌드 → AE 패널 설치
- ⚠️ **사장님 클릭 1회 필요**: AE 메뉴에서 `Window > mcp-bridge-auto.jsx` 열고
  "Auto-run commands" 체크 (제가 그때 화면으로 안내드립니다)
- 연결 확인 → P0 미지수 3개 검증 → 결과 보고
