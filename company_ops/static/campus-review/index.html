숏템메이커 구역

왼쪽 프로그램 구역 안에 내부 작업공간을 연결합니다. 표시한 건물은 진입점 후보이며, 정확한 동·층 배치는 아직 확정하지 않았습니다.

한 건물 안에서 이어질 공간

  1. 2F · 리더·프로젝트 공간배치 제안 · 아직 미구현
  2. 1F · 기획 / 개발 / 독립 검수현재 3D 내부 3구역을 연결할 후보 층
  3. B1 · 수집·운영 시스템원본 이미지의 수집 안정화 위치 · 아직 미구현
  4. 개별 워커 → 업무·보고·실행선택·예시 상세 구현 / 실제 실행 미연결

원본의 ‘B1 수집 안정화’를 현재 ‘1F 기획팀’과 같은 방이라고 취급하지 않습니다.

기존 8석 내부 시안 별도 열기 ↗기존 3구역 조작 시험본 별도 열기 ↗두 번째 링크의 작은 외관은 반려된 시험 모델입니다. 최종 외관 기준은 왼쪽 이미지입니다.
