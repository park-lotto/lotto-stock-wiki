# 숏클 쇼츠 4편 — 필재 TTS 나레이션 대본 v2 (페이블 · 2026-10-30)

- 원칙: 한 편 = 개념 하나. 기능 나열 없음. 시청자 경험("~잖아요")으로 들어가 긴장 → 보상. 첫 문장 = 화면 위 고정 제목과 같은 뜻.
- 숫자·사실은 롱폼(`데일리_1편_대본_페이블.md`)과 라이브 전사문에 실제로 있는 것만 썼다. 가격·채널 이름·반 비교·미동의 후기 없음.
- 말투: `사장님_말투_가이드.md` — 그냥 / 자, 보시면 / 예를 들어서 / ~잖아요 / 근데 / 아시겠죠? · "솔직히" 없음 · 어미 섞음. "그냥·진짜·굉장히"는 편당 한두 번.
- 표기: TTS가 읽는 대로 숫자는 한글(육백구십만·칠 분·열두 개). "세번째자막"은 붙여 쓴다(필재가 "세 번째, 자막"으로 끊어 읽는 것 방지 — 화면 글자도 붙여서 통일).
- 글자 수 = 나레이션만, 공백 제외(공백 포함은 괄호). 목표 170~230자 ≈ 35~45초.
- 장면 메모의 [롱폼] = 롱폼 소재 재사용, [신규] = 쇼츠용으로 새로 만드는 컷.
