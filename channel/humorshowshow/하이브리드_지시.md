## 0. 만드는 꼴 — 한 대본으로 한 번에 렌더(같은 옷)
- 썰템쇼는 엔진이 `preset_make.py` 하나다. 하이브리드도 **같은 제작기·같은 틀·같은 목소리(박창수, manifest)·같은 BGM** 으로 한 번에 렌더한다 → 앞뒤 옷이 자동으로 같다. 이어 붙이기 렌더러를 새로 만들지 않는다.
- 새 폴더 `channel/humorshowshow/하이브리드_작품N_<소재>/` 에 `대본.json`·`재료.json`·`근거.md` 를 둔다.
  - `대본.json` = 원 작품 대본.json 복사 → **앞 줄 = 원 대본의 첫 줄부터 앞 ~13~17초 분량**(이야기의 가장 신기한 대목까지, 줄 경계에서 끊는다) + **뒤 체험 줄 5~6줄**(15~20초).
  - 맨 위에 `"hybrid": {"front_from": "channel/humorshowshow/작품N_…", "front_lines": <앞 줄 수>, "product": "<쿠팡 상품명(상품번호)>", "coupang": [상품번호…]}` 와 `"흥미이음": {원본흥미, 뒤흥미, 판정, 근거}` — 판정 '같음'만 렌더.
  - `desktop_title` = `<원 소재>_하이브리드`(예 `바나나맛우유_하이브리드`). frame_vars 는 원 대본 그대로(제목·라벨 같은 틀).
  - `재료.json` = `cand_dir` 는 **원 작품의 C 자료 폴더 그대로**(`C:/숏템_칼카피/humorshowshow/작품N_…`) — 앞 행은 원 재료.json 의 해당 행 복사, 뒤 행은 새로 받은 같은 제품 영상을 그 폴더 `hybrid/` 아래에 두고 `"src": "hybrid/<파일>.mp4"`.
- `"hybrid"` 표식이 있으면 preset_make 가 검사 기준을 manifest `hybrid_checks`(길이 30~42초·효과음 ≤10) 로 덮고 출력은 `<cand_dir>/make_hybrid/` (커밋 e314b7ff1).

## 1. 뒤 체험 줄 쓰는 법
- 말투는 **썰템쇼 그대로**(반말 혼잣말·게시글 썰 결 — 원 대본의 어미를 본다). 뒤 첫 줄은 연결어로 앞을 받는다: "근데 이 얘기 듣고 나도 바로 쿠팡에서 시켜봤는데" 같은 결(광고 말투 금지).
- 골격 = 대본설명서 §1(B1 이음 → B2 불편/기대 → B3 써(먹어) 보니 ① → B4 심지어 ② → B5 근거 있는 새 사실(원 대본 뒤쪽에 있던 사실을 여기로 옮겨 써도 된다) → B6 끝 = 사회 반응). **CTA 없음**, **금액·가격 숫자 금지**(대본·자막 모두), 최상급·효능 단정 금지, 다른 브랜드 이름 금지.
- 화자 대사 줄(`speaker`)은 써도 된다(썰템쇼 옵션). 자막 한 줄 ≤18자, `/` 로 줄바꿈 자리. tts 에 ㅋㅋ 같은 낱자 금지.
- 제품 사실(용량·구성·맛·식감 근거)은 `근거.md` 에 줄마다 출처(쿠팡 상품명·영상 id·초).

## 2. 같은 제품 찾기 → 쿠팡
1. 원 소재가 곧 제품이다(바나나맛우유·새우깡 등). 이름으로 바로 `PYTHONUTF8=1 py tools/calcopy/coupang_api_search.py <out.json> "<검색어>" "<다른 표기>"` (서버 파트너스 키, 최대 10개).
2. 같은 제품이 쿠팡에 없으면(예: 코스트코 매장 메뉴) 원본 흥미("무엇이 신기했나")가 그대로 보이는 쿠팡 제품만 '같음'. 없으면 **그 편은 만들지 않고 사유를 보고**한다(억지로 만들지 않는다).
3. 쿠팡 결과 json 은 `channel/humorshowshow/하이브리드_작품N_…/쿠팡.json` 으로 둔다.

## 3. 뒤 화면 = 그 제품을 먹는/쓰는 사람들 영상
- `tools/calcopy/hybrid/screen.py` 로 유튜브(쇼츠)·인스타·틱톡 후보를 찾고 가려낸 뒤 고른 것만 받는다(README §파일). 컷마다 다른 사람·장면, 원본 샷 경계 안, 남의 박힌 자막·워터마크는 `src_crop` 밖으로(0.5초 시트로 확인).
- 확대 ≤2.3배·720p 이상(A4). 짤(meme:) 비율 ≤0.3·같은 짤 1컷.

## 4. 순서 (편 하나를 끝까지 — 남에게 넘기지 않는다)
1. 원 작품 `대본.json`·`재료.json`·`make/timeline.json`(줄 시각) 을 읽고 앞을 어디서 끊을지 정한다.
2. 쿠팡 → 흥미이음 판정 → 뒤 영상 모으기 → 대본·재료·근거 쓰기.
3. `PYTHONUTF8=1 py tools/calcopy/engine/preset_make.py channel/humorshowshow/preset/썰템쇼_화자썰 channel/humorshowshow/하이브리드_작품N_… --plan` → 계획 시트(`plan/계획_시트_자동.jpg`)를 **직접 열어 보고** 컷이 줄 내용과 맞는지 확인. 계획 검사 전부 ○.
4. `… --allow-tts --desktop-dir "C:/Users/CH/Desktop/칼카피영상/썰템쇼/하이브리드" --tag 1차` (폴더 없으면 만든다). 자동 검사 전부 ○ 여야 바탕화면에 복사된다. 미달이면 고쳐서 다시.
5. 완성본 1초 시트(`make_hybrid/sheet_1s.jpg`)와 이음 자리 앞뒤 프레임을 **눈으로** 보고, 이음 자리 소리(앞 끝 줄 → 뒤 첫 줄)가 끊기지 않는지 확인.
6. 드라이브: PowerShell 로만 `Copy-Item` → `G:\내 드라이브\칼카피영상\4번 썰템쇼\하이브리드\<NN>_<영어이름>_hybrid.mp4` (NN·영어이름은 아래 표, 폴더 없으면 New-Item). 복사 뒤 MD5 = make_hybrid/final.mp4 확인. /MIR·삭제 금지.
7. 커밋: `git -C "C:/Users/CH/Desktop/로또의 주식/.tracks/칼카피숏템엔진" add <내 하이브리드 폴더만>` → `git diff --cached --stat` 로 남의 파일 없음 확인 → commit(메시지 끝 `(관제 097)` + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`) → push origin track/칼카피숏템엔진. `git add -A`·stash·pull·finish 금지.

## 5. 지킬 것
- 남의 프로세스를 끄지 않는다(이름으로 taskkill 금지). 무거운 프로세스는 한 번에 하나. 유료 API = 타입캐스트만(제미나이 판정 금지 — 판정은 직접 눈으로).
