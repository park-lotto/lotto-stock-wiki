## 1. 제작 순서 (규칙)

```
① 라이브/강의 받아쓰기 → 발언정리(구간·태그) → 반응분석(채팅×발언)
② 대본 = Fable (설득 7단계·감정 곡선·관통 장치) + 사장님 말투 가이드 → 사실 대조(라이브 원문만)
③ 필재 TTS (타입캐스트, 서버 /home/ubuntu/yt_piljae_file.py) — 장면 단위 통째 합성
④ ★장면 길이 = 그 장면 필재 음성 길이. 이 숫자로 장면을 설계한다(짐작 길이 금지)
⑤ 조각별 제작 → 사장님 컨펌 → 다음 조각 (앞부분부터 하나씩)
⑥ 전부 컨펌된 뒤 마지막에 한 번 최종 렌더
```

**한 번에 다 만들지 않는다.** 사장님 10-30: "한번에 다 할려고 하지 말고 앞부분 완성하고 하나씩 조각별 컨펌하고 마지막에 렌더."
