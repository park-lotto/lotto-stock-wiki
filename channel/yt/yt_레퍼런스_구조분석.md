## 2. 제목 패턴 해부

### 잘된 제목 공통 공식

```
[숫자] + [AI 직원/채용] + [충격 조건] + [부제: 실제 방법/도구]
```

| 요소 | 잘된 예시 | 효과 |
|------|---------|------|
| **숫자** | "5명", "10명", "$10M", "24시간" | 구체성 → 신뢰 |
| **채용/고용** | "채용했습니다", "고용했습니다" | 과거형 → "이미 해봄" 권위 |
| **충격 조건** | "인건비 0원", "월급 0원", "완전 무료" | 믿기 어렵지만 → 클릭 유도 |
| **부제** | "Manus Skills 세팅 공개", "모든 코드 무료 공유" | 실용성 → 끝까지 볼 이유 |

### 잘 안된 제목 패턴

| 실패 패턴 | 예시 | 조회수 |
|---------|------|--------|
| 개념 설명형 | "단순 AI는 끝났습니다. 스스로 생각하고..." | 404회 |
| 추상적 | "AI 에이전트 핵심 총정리" | 낮음 |

> **결론**: 제목은 개념X. 결과 + 숫자 + 무료/공개 조합.

## 4. 구조 패턴 분석

챕터 타임스탬프가 없어 댓글·제목·조회수로 역추론.

### 잘된 한국 영상 (KR-02, KR-03) 추정 구조

```
[0:00~0:30] 결과 먼저 보여주기
            "이게 AI 직원들이 만들어놓은 결과물입니다"
                  ↓
[0:30~1:30] 문제 공감
            "혼자 이거 다 하고 계셨죠?"
                  ↓
[1:30~3:00] 시스템 개요 (직원 소개)
            도식으로 N명 역할 설명
                  ↓
[3:00~8:00] 실제 도구 데모
            화면 녹화 → 각 직원 실행 장면
                  ↓
[8:00~종료] 무료 공개 + CTA
            "링크에서 다 가져가세요"
```

### 잘된 영어 영상 (EN-04 Dan Martell) 구조

```
[0:00~0:30] 숫자로 훅 ($10M, 0 coding)
                  ↓
[0:30~2:00] 왜 지금인가 (시장 타이밍)
                  ↓
[2:00~10:00] 3단계 프레임워크
             1. 문제 선택 / 2. 수동으로 검증 / 3. AI로 자동화
                  ↓
[10:00~14:00] 실제 사례 데모
                  ↓
[14:00~종료] CTA (커뮤니티 + 코스)
```

## 5. 잘된 영상 vs 안된 영상 — 결정적 차이

| 요소 | 잘된 영상 (100K+) | 안된 영상 (404회) |
|------|-----------------|----------------|
| **시작** | 결과물/수치 먼저 | 개념 설명 먼저 |
| **도구** | 실제 도구 이름 명시 | 추상적 |
| **공개 수준** | 코드/링크 전부 무료 | 개념만 설명 |
| **숫자** | N명, 0원, 24시간 구체화 | 숫자 없음 |
| **감정** | 충격 → 실용 → 행동 | 정보 전달에 그침 |

## 6. 우리 영상에 적용할 것

### 제목 최종안 (패턴 적용)

```
[안 A] "AI 직원 10명 뒀더니 주식 분석이 혼자 됩니다 (새벽 4시 실화)"
[안 B] "월급 0원 AI 직원 10명이 내 주식을 24시간 분석한다"  
[안 C] "나는 잠자는데 탑픽 3개가 뽑혀있었다 (AI 직원 시스템 공개)"
```

**추천**: 안 A — 숫자+결과+시간+실화 4요소 다 들어있음

### 훅 구조 (KR-03 + EN-04 혼합)

```
결과 먼저 (KR-03 방식)
+ 숫자+임팩트 (EN-04 방식)  
+ 주식 전문성 (우리만의 차별점)
```

### 무조건 넣어야 할 요소

```
✅ 실제 터미널/텔레그램 화면 (가짜처럼 보이면 즉사)
✅ "완전 무료" or "전부 공개" 언급 (댓글 반응 보면 이게 핵심)
✅ 숫자: 10명, 새벽 4시, 23분 등 구체화
✅ 실제 탑픽 결과물 보여주기 (종목명, 점수)
```

### 우리만의 차별점 (타 채널과 다른 것)

```
타 채널: 일반 업무 (이메일, 리드, 콘텐츠)
우리 채널: 주식 리서치 전용 → 한국에서 유일

타 채널: n8n/Make 같은 범용 도구
우리 채널: 실제 주식 데이터(수급빈집, 컨센서스, 탑픽) → 전문성
```

## 7. 단계별 기획서 설계 방향

위 분석 기반으로 기획서를 3단계로 나눠서 잡는다:

```
STEP 1: 훅 + 오프닝 설계
        → KR-03, KR-02 방식 적용
        → 결과 먼저, 숫자 포함, 실화 강조

STEP 2: 본론 구조 설계  
        → 직원 소개 → 실제 데모 순서
        → EN-04 방식: 3단계 프레임 줌

STEP 3: 엔딩 + CTA 설계
        → KR-05 방식: 전부 공개 → 신뢰 구축
        → 다음 편 예고: 설계 구조 공개
```
