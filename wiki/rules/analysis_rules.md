## 0-1. 테마 대장주 크로스체크 (리서치 완료 후 필수)

> **배경**: 전고체 리서치에서 이수스페셜티케미칼(황화리튬 대장주)을 누락한 사례.
> 원인: "전고체 관련주" 광범위 검색 → 장비주만 뜨고 핵심 원료 소재 기업 누락.

### 적용 규칙

Gemini Q10 리서치 + 위키 작성 후 반드시 아래 추가 검색 실행:

```
□ 1. WebSearch: "{테마/섹터명} 관련주 대장주 테마주"
       → 시장에서 대장으로 꼽히는 종목 확인
□ 2. 위키에 없는 대장주 발견 시 → 즉시 WebSearch로 포지션 확인
□ 3. 체인 원료 레이어까지 파고들기:
       완성품 → 소재 → 원료 → 원료의 원료
       예) 전고체 셀 → 황화물 전해질 → 황화리튬(Li₂S) → 이수스페셜티케미칼
□ 4. 확인된 대장주를 위키에 추가 + ⚠️ 누락 사유 기록
```

### 검색 키워드 패턴

| 상황 | 검색 키워드 |
|------|-----------|
| 테마 대장주 확인 | "{테마명} 대장주" / "{테마명} 관련주 TOP10" |
| 핵심 소재 원료 기업 | "{핵심 소재명} 제조 기업 한국" |
| 체인 상류 기업 | "{소재명} 원료 공급 업체" |

### 대장주 확인 후 실제 주가 검증 (필수)

```
□ 대장주 선정 후:
  1. 해당 종목 실제 주가 상승률 확인 (WebSearch: "{종목명} 주가 상승률 2026")
  2. 어떤 뉴스·공시가 트리거였는지 확인
  3. 위키에 적은 트리거와 실제 트리거 일치 여부 검증
  4. 불일치 시 위키 수정
```

### 교차검증 테이블 (리서치 완료 시 작성)

| 항목 | 위키 내용 | 실제 시장 | 판정 |
|------|---------|---------|------|
| 대장주 | — | — | ✅/⚠️/❌ |
| 트리거 | — | — | ✅/⚠️/❌ |
| 양산 일정 | — | — | ✅/⚠️/❌ |

### 과거 누락·검증 사례 (기록)

| 테마 | 누락·오류 | 이유 | 교훈 |
|------|---------|------|------|
| 전고체 배터리 | **이수스페셜티케미칼(457190)** 누락 | "관련주" 검색 시 장비주만. 황화리튬 원료 레이어 미검색 | 체인 원료까지 역추적 |

## 0. 질문 답변 순서 (최우선 원칙)

```
① 위키 먼저 읽기 — 섹터/종목 파일에서 구조·논리·체인 확인
② WebSearch로 현재 상태 교차검증 — "지금도 유효한가" "최신 수치 맞나"
③ 위키(구조) + WebSearch(현재) 합쳐서 답변
```

위키 = 구조·논리·체인·히스토리 (변하지 않는 것)
WebSearch = 현재 상태·최신 수치·살아있는지 여부 (변하는 것)
위키를 쌓는 이유 = 매번 검색 안 하기 위해서. 위키가 1차 답, WebSearch는 검증.

## 1. 섹터 투자 논리 TYPE 분류

> 섹터마다 주가를 움직이는 논리가 다르다. 잘못된 지표를 보면 잘못된 판단이 나온다.

### TYPE A — 실적·수출 데이터형
수출 데이터 발표일 = 주가 반응일. 탑픽: #1수출 #3어닝서프 우선.

| 섹터 | 핵심 트리거 | 보는 데이터 |
|------|-----------|-----------|
| 반도체 | 수출 데이터, HBM 판가, 실적 | 관세청 수출통계, TP 컨센 |
| 조선 | 수주잔고, 신규 수주 공시 | 클락슨 수주잔고 |
| 전력기기 | 수주 공시, 미국 전력 발주 | 수주잔고, 미국 RFP |
| 방산 | 수출 계약 공시, 예산 배정 | 수출 계약 금액 |
| MLCC·기판·소재 | 판가YoY, 물량YoY | 수출 데이터 시트 |
| 2차전지·ESS | 수주잔고, 판가, 메탈가격 | LiCO3 가격, 수주 공시 |

### TYPE B — 성장성·기대감형
PER·PBR 무의미. 이벤트 캘린더·파이프라인이 전부. 탑픽: #6정책 #7일정 우선.

| 섹터 | 핵심 트리거 |
|------|-----------|
| 로봇·피지컬AI | 양산 일정 발표, 파트너십 공시, 납품처 확정 |
| 바이오·제약 | 임상 단계 진입, FDA 승인, 기술이전 계약 |
| 우주·항공 | 발사 성공, 정부 예산 배정 |
| AI 소프트웨어 | 대형 계약 공시, 사용자 수 |
| 수소경제 | 정책 발표, 수주, 상업화 일정 |
| SMR·원전 | 정부 예산, 수주 계약, 인허가 |

### TYPE C — 하이브리드 (실적 + 성장성 공존)
지금 어느 논리가 지배적인지 먼저 판단 후 분석.

| 섹터 | 지금 지배 논리 |
|------|-------------|
| 이차전지 대형주 | 실적형 우세 (2024~25) |
| 반도체 소부장 | 실적형 + 성장형 혼재 |
| 두산로보틱스 | 두 가지 혼재 |

### 분석 적용 규칙
```
□ 1. 섹터 분석 전 — TYPE A/B/C 먼저 판단
□ 2. TYPE A → 수출·수주잔고·실적 중심
       "데이터 미확인" 명시
□ 3. TYPE B → 이벤트 캘린더·파이프라인 중심
       "매출 없다 = 안 좋다" 판단 금지
□ 4. 탑픽 선정 시 TYPE별 체크 항목 가중치 다르게
□ 5. 브리핑·아침 노트에 TYPE 태그: [실적형] / [성장형]
```

## 2. 대내외 매크로 변수 체크

> 아무리 좋은 종목도 매크로 역풍 앞에서는 못 버틴다. 종목 분석 전에 매크로 온도를 먼저 읽는다.

### Layer A — 국내 정책·수급
| 변수 | 체크 포인트 |
|------|-----------|
| 코스닥 부양책 | 정부·금융위 발표 |
| 국민성장펀드 | 편입 종목 리스트 업데이트 |
| 밸류업 프로그램 | 종목별 공시 여부 |
| 연기금·기관 수급 | 순매수 상위 섹터 |

### Layer B — 금리·환율
| 변수 | 섹터별 영향 |
|------|-----------|
| 한국 기준금리 | 인하→성장주 유리 / 인상→가치주 유리 |
| 미국 Fed 금리 | 인하기대↑ → 나스닥·반도체·로봇 강세 |
| 원달러 환율 | 원화약세 → 수출주(반도체·조선·방산) 수혜 |
| 미국채 10년물 | 금리↑ → 고PER 성장주 부담 |

### Layer C — 글로벌 매크로
| 변수 | 판단 기준 |
|------|---------|
| VIX | 20↓안정 / 25↑경계 / 30↑위험 |
| DXY | 달러강세 → 신흥국 자금 이탈 |
| 나스닥·S&P500 | 강세 → 국내 반도체·AI·로봇 커플링 |
| WTI | 급등 → 조선·방산 수혜 |
| 미중 관계 | 관세강화 → 반도체·이차전지 직격 |

### 섹터별 민감도
| 섹터 | 가장 민감한 변수 |
|------|--------------|
| 반도체 | 나스닥·DXY·미중관세 |
| 조선 | 유가·환율·수주 |
| 로봇·피지컬AI | 나스닥·정책·금리 |
| 전력기기 | 미국 전력인프라 정책·환율 |
| 코스닥 소형주 | 코스닥 부양책·국민성장펀드 |

### 적용 규칙
```
□ 역풍 변수 2개 이상 → "진입 보류" 표시
□ 순풍 변수 겹칠 때 → "+매크로 순풍" 태그
□ 정책 변수 변화 감지 → stock/ 최신 이벤트 즉시 반영 + 탑픽 #6 갱신
□ 브리핑·아침 노트에 "오늘의 매크로 온도" 1줄 필수
```

## 4. Gemini 리서치 사후 검증

> Gemini는 실제 사례와 가상 사례를 섞어서 뱉는다. 위키에 쌓기 전에 반드시 걸러야 한다.

### 검증 대상 — 이런 주장은 무조건 WebSearch
| 주장 유형 | 검증 방법 |
|---------|---------|
| "XX 기업이 YY 행사에서 발표" | 기업명 + 행사명 + 연도 |
| "XX와 파트너십/협력 확인" | 기업명 + 파트너사 + 협력 |
| "XX 날짜에 YY 발표/계약" | 기업명 + 날짜 + 공시 |
| "XX가 YY에 납품" | 기업명 + 납품처 |
| "가상 사례" 날짜 명기 | 즉시 제거 |

### 검증 결과 3등급
```
✅ 실제 — 뉴스·공시 확인 → 그대로 반영 + 출처 URL
⚠️ 부분 실제 — 방향 맞지만 세부 다름 → 확인된 것만 반영
❌ 허위 — 근거 없음 → 위키 반영 금지
```

### 자주 틀린 패턴 (기록)
| Gemini 주장 | 실제 | 판정 |
|-----------|------|------|
| 레인보우로보틱스 GTC 2024 시연 | 파트너 명단에 없음 | ❌ |
| 유진로봇 Isaac 협력 | 검색 근거 없음 | ❌ |
| 두산로보틱스 GTC 2024 발표 | CES 2026 + 2026.04 협력 | ⚠️ |
| LS일렉트릭 수주잔고 8.7조 | 실제 연결 7.2조 | ❌ |
| HD현대일렉트릭 67.31억달러 | 2025말 구수치 (2026Q1=78.88억) | ⚠️ |

### 검증 안 해도 되는 것
- 수치 없는 일반론
- 이미 위키에 있는 ingest 확인 내용
- 사용자가 직접 가져온 뉴스·리포트
