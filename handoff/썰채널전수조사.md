## ★먼저 읽어라 — 1차 시도는 폐기됐다 (같은 실수 반복 금지)

이 세션에서 **틀 3종을 만들었다가 사장님 지시로 되돌렸다**(커밋 2개 삭제).
왜 틀렸는지가 이 작업의 핵심이다:

| | 오용형·은폐형을 만든 순서(옳음) | 1차 시도(틀림) |
|---|---|---|
| ① | 조회수로 터진 영상을 모은다 | 채널 3개 고름(조회수 상위) |
| ② | **터진 영상을 뜯어 스타일로 분류** | **없음** ← 통째로 빠짐 |
| ③ | 분류가 뭉치는 덩어리 = 축 | 없음 |
| ④ | 그 축에서 문장틀 | 바로 여기부터 시작 |

**이름을 먼저 짓고 영상을 밀어넣으면 안 된다.** 뭉치는 덩어리를 찾고 거기 이름을 붙여야 한다.

### 1차 시도에서 드러난 구체적 실패 (되풀이하지 마라)

- **지인목격형**은 라이브 `가족갈등 반전형`과 사실상 같은 틀이었다.
  훅이 거의 글자 그대로 같다: `저 친구 만났다가 진짜 충격 받았어요` vs `{지인}네 집 갔다가 … 충격 먹었어요`
  → **유튜브·인스타에 같은 포맷을 두 벌 만들지 마라**(사장님 지시).
- **A 비법조제형**은 20채널 검사에서 **20편 중 17편이 수복수복 한 채널**이었다.
  축이 아니라 **한 채널 습관**일 가능성이 크다.
- **바바라핵팁**은 조회수 700만만 보고 골랐는데 판정 **0/0 미달**이었다.

## ★★가장 중요한 발견 — 이 판정기로는 새 축을 못 찾는다

`categorize.py`는 **이미 정의된 축만** 알아본다(오용형·제품정체형·장비템·차량템 — 전부 라이브에 있는 것).
즉 발굴 루프는 "기존 축을 쓰는 채널을 잘 찾는 도구"지 새 축 발견 도구가 아니다.

    통과 41채널 · 검사 995편 → 축에 걸린 것 292편 / **안 걸린 것 703편**

★**새 축은 저 703편에 있다** — 좋은 채널이 만들었는데 판정기가 모르는 문법이다.
그래서 `pick_unknown.py`가 **안 걸린 영상을 우선** 전사 대상으로 뽑는다.
걸린 영상도 일부 섞는다(**대조군** — 없으면 "새로 보이는 것"이 진짜 새것인지 못 가른다).

실증: 아래 3편은 한국어 원제목으로 판정해도 **어느 축에도 안 걸린다**.

## ⚠️★yt-dlp 제목은 영어다 — 이 세션에서 **3번** 밟은 함정

`yt-dlp --print %(title)s`는 **유튜브 자동번역 영어 제목**을 준다.
실측: 2,707편 중 **96%가 영어**. 그 제목으로 `categorize` 판정을 하면 **100%가 '안 걸림'**이 나온다.

```
잘못  yt-dlp 제목 → categorize      → 전 채널 "미달" (판정기가 죽은 것)
맞음  YouTube API 제목 → categorize → 정상 판정
```

- 발굴 루프(`harvest_sul_local.py`)는 **API를 쓰므로 무사**하다.
- `pick_unknown.py`는 판정 전에 **API로 한국어 원제목을 받아** `title_ko`에 채운다(videos.list, 50편당 1 unit).
- 자기검사를 넣어뒀다 — "걸린 영상이 0건이면 판정기가 안 도는 것을 의심하라"가 화면에 뜬다.

### 또 하나 — 판정 함수 인자 순서

`cz._is_misuse(name_t, cap_t)` — **영상 제목은 두 번째(cap_t)**다. 첫 자리는 채널명.
제목을 첫 자리에 넣으면 오용형 제목도 False가 나온다(실측). handoff/오용형발굴.md의
'살림치트키' 실사고(채널명의 차단어가 그 채널 전 영상을 죽임)와 같은 자리다.
