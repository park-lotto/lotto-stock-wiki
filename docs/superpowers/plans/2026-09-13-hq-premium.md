# 본사 소재·실내 디테일 보강 계획

> 실행: superpowers:executing-plans. 사용자가 따뜻한 고급 AI 사옥 방향을 승인하고 상세 수정을 지시했다.

**Goal:** A 본사 형태와 비교 카메라를 보존하며 고급 외장과 창 너머 실제 깊이 있는 실내를 제작한다.
**Architecture:** v2.blend를 읽고 `hq_premium.py`로 v3.blend를 별도 저장한다. 기존 v2와 렌더를 보존하며 새 결과만 검토 화면 기본값으로 연결한다. 물리 재질/실제 가구와 건축 메시를 수정하며 생성 이미지로 대체하지 않는다.
**Tech Stack:** 설치된 Blender4.5.9, Cycles/OptiX, 기존 정적 검토 페이지/Puppeteer.

- [x] `hq_premium_verify.py`: v2에서 소재 노드·회의실·라운지·업무석 미존재로 RED. v3에서 GREEN. 카메라 위치/기존 사인/건물 층고 유지 검사.
- [x] `hq_premium.py`: v2에만 적용 가능한 버전 가드. 절차적 석재 결/월넛 결/패브릭 미세 요철, 짙은 브론즈, 유리 거칠기 보정. 회의실/라운지/업무석·책장·천장조명·파티션·실내 마감 실제 모델 생성. v3 별도 저장.
- [x] `hq_render.py`: 출력 접두어·디테일 카메라 선택을 장면 속성으로 받되 기존 v2 기본 동작 유지. 같은 외관 카메라의 주야간/입구/로비 + 창가 근접 렌더.
- [x] 실제 5개 렌더 확인→빛/가림/물체 충돌 등 눈에 보이는 문제 보정. 테스트만으로 시각 완성 주장하지 않는다.
- [x] `static/hq-building/index.html`: 새 렌더를 기본값, 이전 외관 비교 버튼, 창가 근접 버튼. 원본 크게 보기와 실제렌더/웹회전미연결 구분 유지.
- [x] `tests/hq-building.cjs`: 모든 탭·이미지·모바일 검증. handoff/작업로그 갱신 후 트랙 커밋. main 배포 없음.

승인 범위 밖: 다른 건물, 회전/보행, 실제 직원/업무 연결. 과장된 금색·쇼핑몰 연출 없이 재료 대비와 공간 깊이로 개선한다.
