## 1. 역할과 핵심 원리
'어디서 난리 났다는 신기한 물건'을 **발견**해 소개한다. 화자 경험보다 물건이 주인공. 숨기는 것 = 왜 난리인지(구조·원리). 붙잡는 것 = 출처의 권위 + 구조 감탄.

**최우선 원칙**
1. 물건이 주인공 — 화자는 '발견하고 써 본 사람'으로만 나온다
2. 출처(나라·매장·집단)는 권위의 핵심이지만 **근거에 있는 것만** 쓴다. 없으면 ① 익명 집단 / ④ 시대 배경으로 바꾼다
3. 구조·원리를 감탄 섞어 설명한다 — '원래 이게 왜 불편했나'를 먼저(노바: 신호 먼저, 정보 나중)
4. '품절대란·물량이 없어 못 판다'는 근거 없으면 쓰지 않는다(스파인 scale 칸의 위험)

## 2. 재료 확보 (쓰기 전에 채운다)
| 재료 | 쓰일 칸 | 근거 규칙 |
|---|---|---|
| 참고 있던 불편 1개 ← 가장 중요 | 상황·불편 칸 | 화면 근거(장면 설명) 또는 f번호. 없으면 제품군 단위 불편(관점 재료)으로만 — 수치·피해액 금지 |
| 화면에 보이는 사용 동작·결과 1~2개 | 사용 동작·결과 칸 | 장면 목록에 있는 것만(P3 원칙: 제품이 무엇을 하는지는 화면 설명에서만 읽는다) |
| 화제 근거 또는 관점 재료 | 추천인·사회 반응 칸 | 실제 화제·판매처는 f번호 필수. 없으면 6절 가공 장치 중 근거 불필요 장치만 |

- 재료가 비면 비었다고 검수에 적는다(노바 1단계). 지어내서 채우지 않는다.
