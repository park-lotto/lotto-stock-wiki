# 말투 비교 — 같은 요거트 대화, 원인별로 한 가지씩만 바꿈

1차 `A_묻고답하기.mp3` = 줄마다 따로 녹음(v3는 앞뒤 문맥을 못 받음) → 사장님 "말투가 왜 이렇게 어색해?"

| 파일 | 바뀐 것 |
|---|---|
| V1_같은대사_대화API | **녹음 방식만** — 대사 그대로, 일레븐 대화 API로 대화 전체를 한 번에 |
| V2_구어대사_대화API | + **대사를 말투로** ("사 먹긴 뭘 사 먹어~ 그냥 만들어 먹지") |
| V3_구어+감정태그 | + **감정 지시** ([laughs] 등 — 읽지 않고 웃음으로 연기됨, 받아쓰기 "흐흐") |

- `_원본속도` = API가 준 그대로(말 사이 공백 1.0~1.4초 — 쇼츠엔 늘어짐)
- `_간격정리_1.25배` = 공백 약 0.4초로 줄이고 라이브 기본 1.25배 (★이걸로 비교 권장)

듣는 순서: A_묻고답하기 → V1 → V2 → V3 (모두 `_간격정리_1.25배`)
- A→V1에서 나아지면: 원인은 "줄마다 따로 녹음"
- V1→V2에서 나아지면: 원인은 "글말 대사"
- 받아쓰기에서 "면포"가 계속 "면코·면콰"로 잡힘 — 귀로 확인 필요
