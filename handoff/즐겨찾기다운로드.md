# 즐겨찾기다운로드 — 영상 즐겨찾기에서 원본 mp4 저장

## 2026-09-04 (사장님 "프로등급만 / 횟수제한 없음 / 영상즐겨찾기 페이지만 / 파일명 넣고")

### 왜 쉬웠나
서버는 이미 원본을 받고 있었다 — `/api/play`가 `download_any`로 mp4를 내려받아
`data/play_cache/`에 두고 FileResponse로 준다(카드 인라인 재생용). 다운로드는
**새 경로가 아니라 그 파일에 저장 헤더를 붙이는 일**이었다.

### 무엇을 넣었나
| 자리 | 내용 |
|---|---|
| `app.py` `/api/mix/basket/download?sc=` | 프로 전용. 게이트는 `access_level(cid) != "full"` → 402 `need_pro`. **횟수 제한 없음**(사장님 지시) |
| 같은 곳 | 대상 URL은 **회원 자기 바구니**(`mix_basket_list`)에서만 꺼낸다 — 클라이언트 url을 받으면 SSRF |
| 같은 곳 | `download_any` + `_PLAY_CACHE_DIR` 재사용(0순위-B). 같은 영상 두 번째부터는 캐시 즉시 |
| `app.py` `_safe_download_name()` | 경로문자·제어문자 제거, 60자 컷, 항상 `.mp4`. 이름은 `name → caption → shortcode` 순 |
| `collection.html` | 카드에 `💾 영상 저장`(제작소로 보내기 위). `CAN_DL`은 `/api/me`의 `level==='full'`로만 켠다 |
| 같은 곳 | 링크가 아니라 fetch+blob — 402/502를 **문구로** 안내하려고(그냥 링크면 빈 탭이 뜬다) |

### 등급 해석 (중요)
`access_level == "full"` = 사장님(cid 0) + `plan="pro"` + **입금 승인 기간(full_access_until) 안의 고객**.
즉 "돈 낸 사람"이다. `plan=="pro"` 문자열만 보면 결제 승인 고객이 못 받는다 — 그래서 안 썼다.

### 받을 수 있는 플랫폼
`download_any`가 처리하는 전부: 유튜브·틱톡·인스타·쓰레드·핀터레스트·샤오홍슈(+직접 mp4·업로드 파일).
도우인은 헤드리스 크롬 경로라 느리다(되긴 된다).
