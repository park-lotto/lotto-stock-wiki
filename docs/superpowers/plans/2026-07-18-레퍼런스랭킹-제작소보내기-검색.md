# 레퍼런스 랭킹 개편 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 레퍼런스 랭킹 카드에서 버튼 하나로 영상+대본을 제작소로 보내고, 랭킹을 키워드로 검색하며, 제작소 담긴 대본에 선택 삭제를 붙인다.

**Architecture:** 서버 신규 라우트 0개 — 기존 통로 재사용. 랭킹 카드 → `POST /api/extract_script`로 대본 뽑고 → `sessionStorage.produce_handoff`(collection.html이 이미 쓰는 통로)에 `useFootage:true·pickScript:true·script`로 담아 `/produce` 이동. 제작소는 핸드오프 플래그를 보존하고, 담긴 대본(`loadWikiForMix`)이 서버 picks + 임시 대본을 합쳐 보여준다. 검색·전체선택·삭제는 순수 프론트.

**Tech Stack:** 바닐라 JS(`index.html`·`produce.html`) · 기존 FastAPI 라우트 · Node 슬라이스 테스트(pytest가 실소스를 앵커로 잘라 node로 구동)
