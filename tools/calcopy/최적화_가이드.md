## 2. 제미나이 — 언제 로컬, 언제 서버 (실측 10-18)
- 로컬 공용 풀 글 1회 4.4~9.1초 · 8개 동시 13.8초. 서버 풀 1요청 = 모델 2~4초 + SSH·기동 고정비(실측 6.5초~20초 벽시계).
- 그래서 **기본 auto = 로컬 먼저, 한도(quota/no_key/429)면 서버**. 묶음(클립 여럿×모델 여럿)은 처음부터 서버가 유리 → `gemini_server.ask_files`.
- 강제: `CALCOPY_GEMINI_BACKEND=server|local`. 동시 상한 `CALCOPY_GEMINI_WORKERS`(기본 8, 서버 요청당 스레드 ≤12 고정).
- 모델: 로컬 PRIMARY `gemini-3.5-flash`(3바퀴) → `gemini-flash-lite-latest`. 서버 받아쓰기 `gemini-3-flash-preview`+`gemini-flash-latest`(후자 50초 느릴 때 있음). `gemini-2.5-flash` 는 새 키 404 — 쓰지 마라. **버텍스 금지** 그대로.
- 키가 적게 보이면(42개 등) `py tools/calcopy/pull_pool_keys.py` 먼저(공용 풀 → .env).

제미나이 로컬 동시 8 · 서버 요청당 스레드 12 · yt-dlp 자막 동시 2(3이면 429) · 무거운 일 동시 4(`MA_WORKERS`, 연속 제작은 2) · 창고 워커는 큰 분석과 동시에 켜지 않는다.

## 5. 함정
- 프로세스 이름 일괄 종료(`taskkill /IM yt-dlp.exe`) 금지 — 다른 세션 것도 죽는다. 내가 띄운 PID 만.
- 구글 드라이브 `G:\` 는 **PowerShell 만**(Bash cp 가 폴더를 파일로 덮은 사고).
- 작업 폴더에 한글 경로면 OpenCV·drawtext 가 깨진다 — 재료·렌더 작업 폴더는 영문(`C:/숏템_칼카피/...` 아래 영문 slug).
- 자동 검사 통과 ≠ 됐다. 사람이 안 본 건 "자동 검사만"이라고 말한다.
- 서버 풀은 유료 고객과 같은 키 — 요청당 12 스레드를 넘기지 않는다. 키 값·소재는 PC 로 가져오지도, 서버에 남기지도 않는다.
