## T1 — 🖼 이 장면을 썸네일로 (커밋 50b3f32f3)

6단계에서 보고 있는 장면을 7단계 썸네일 후보 **맨 앞**에 꽂는다.

| 파일 | 무엇 |
|---|---|
| `app.py` | `_beatframe_file()` 신설 — 프레임 경로 판단을 **한 곳으로**(0순위-B). 미리보기 API와 핀이 같은 함수를 쓴다 |
| `app.py` | `POST /api/produce/thumb/pin` (`remove:true`면 빼기) · `_with_pins()` |
| `produce.html` | [🖼 이 장면을 썸네일로] 버튼 + 후보 카드에 금색 배지·× |

### ★핀을 `thumbnail.frames`에 섞지 않는다
`frames`는 재추출 때마다 **통째로 갈아엎히는 서버 소유 목록**이다. 거기 넣으면
[다른 장면 더 뽑기] 한 번에 사장님이 고른 장면이 조용히 사라진다. 별도 키(`pins`)에 두고
**응답을 만들 때만** 앞에 붙인다. 파일명도 `pin_*.jpg`라 `grid_*` 고아정리에 안 걸린다.

### 실브라우저 관찰로 잡은 구멍 2건 (정적 검토로는 못 잡는다)
- 믹스 영상이 없으면 `frames`가 404로 끝나 **핀까지 안 보였다** → 핀만이라도 돌려준다
- 마지막 핀을 뺀 뒤 그리드를 안 비워 **유령 카드**가 남았다(누르면 지워진 그림으로 제작)

## T2 — 🔎 장면 강조 (원형 돋보기 / 스포트라이트)

| 파일 | 무엇 |
|---|---|
| `video_assemble.py` | `scene_hl_of()` 해석 단일 지점 · `_hl_dist()` 모양 거리식 · `highlight_fc()` 필터 생성 |
| `video_assemble.py` | 비트 클립 렌더에서 강조가 있을 때만 `-vf` → `-filter_complex` |
| `app.py` | `POST /api/produce/mix/{job}/scenehl` · beats API가 `hl` 동봉 |
| `produce.html` | 효과 탭 맨 위 강조 상자 + 미리보기 위 드래그 원(`#hlCircle`) |

### ★geq를 프레임마다 돌리면 안 된다 — 실측 15배 차이
| 방식 | 3초 소스 렌더 |
|---|---|
| 전면 geq 매 프레임 | **13.0초** (4.3배 느림) — 라이브 불가 |
| 마스크 1장 + `loop` 재사용 | **0.86초** (0.28배) |

성장 애니메이션도 마스크를 다시 그리지 않는다 — **다 만든 원을 `scale`(eval=frame)로 키운다**.
그래서 커지는 동안 추가 비용이 0이다.
기준선 대비: 강조 없음 0.62초 → 강조 켬 2.0~2.7초(3초 클립). **강조 건 장면만** 이 비용을 낸다.

### ★모양은 지수 하나로 다룬다 (0순위-B)
`_HL_SHAPE_N = {circle:2, round:4}` — 마스크·테두리·어둡기가 **같은 거리식**을 쓴다.
모양마다 식을 따로 적으면 테두리만 원이 되는 식으로 어긋난다.
미리보기 CSS(`HL_RADIUS_CSS` 50%/22%)가 이 표와 짝이다 — **한쪽만 고치면 화면과 완성본이 달라진다**.

### ★등장 성장은 비트의 첫 컷에서만
한 비트가 컷 여러 개로 쪼개지면(`plan`) 컷마다 원이 다시 톡 튄다 → `grow=(j==0)`.

### 확대(scene_zoom)와 강조는 다른 물건
확대는 화면 구도를 바꾸고(크롭), 강조는 구도를 그대로 둔 채 위에 얹는다. **같이 걸 수 있다.**
강조는 base 크롭 **다음**에 오므로 좌표가 최종 프레임 기준 = 미리보기에서 보는 자리 그대로.

## ⚠️ 함정 (다음에 밟지 마라)

- **`t.index('          </div>\n')`처럼 공백 들여쓰기로 태그를 찾지 마라.** 12칸 들여쓴
  `</div>`도 10칸 문자열을 **부분일치로 포함**해서, 엉뚱한 줄을 닫는 곳으로 잡는다.
  실제로 pbBox가 안 닫혀 `decoPaneFx`를 통째로 삼켰다. → **div 깊이를 세라**(작업 스크립트 참고),
  그리고 옮긴 뒤엔 `html.parser`로 균형을 확인하라.
- **블록을 탭 안으로 옮겼다고 믿지 마라 — `closest('#pane')`로 확인하라.** 처음엔 두 블록이
  탭 **바깥**에 놓여 모든 탭에서 보였는데, "탭 열었을 때 보이나"만 봐서는 통과해 버렸다.
- **`computer` 도구 좌표 ≠ CSS 픽셀.** 스크린샷 1568×744 vs `innerWidth/Height` 1920×855
  → **×0.817/0.870** 환산이 필요하다. 안 하면 클릭이 엉뚱한 요소에 떨어지는데
  **조용히 실패**해서 "기능이 안 된다"로 오진한다(실제로 드래그를 두 번 오진했다).
- **끌기를 `hasPointerCapture`로 판정하지 마라.** 캡처가 안 되는 환경에서 원이 통째로 안 움직인다.
  캡처는 `try/catch`로 감싸고 **로컬 플래그**로 판정한다.
- **미리보기 폭이 0일 때 그리면 원이 16px로 뭉개져 굳는다**(패널이 숨어 있을 때 계산).
  → 폭 <10이면 그리지 않고 `ResizeObserver`로 크기가 잡히는 순간 다시 그린다.
- 로컬 검증용 job은 `edit_plan.beats[i]`에 **`beat_idx`가 있어야** scenehl/scenezoom이 먹는다
  (`_mix_job_beat_or_error`는 순번이 아니라 `beat_idx` 값으로 찾는다).

### 이번에 배운 함정 (같은 모양이 또 나온다)

- **"목록에만 적힌 예외"는 아무것도 안 막는다.** `_zoomOnText`에 `[data-maskbox]`가
  적혀 있었지만 상자를 만드는 쪽이 그 속성을 안 붙여, 예외가 통째로 무력이었다.
  예외 목록과 표식은 **짝**이다 — 한쪽만 있으면 조용히 실패한다.
- **증상 하나를 막았다고 뿌리가 잡힌 게 아니다.** 강조 원만 예외로 뺐더니 가림막에서
  같은 증상이 또 났다. 진짜 뿌리는 "클릭 확대가 늘 켜져 있다"였다.
- **미리보기와 렌더가 같은 판단을 다르게 적으면 반드시 어긋난다**(헤드카피 배경, 0순위-B).
- **마크업을 옮기면 주석이 반쪽만 따라온다.** 여는 `<!--`가 원래 자리에 남아 효과 탭
  맨 위에 안내문이 **글자로 노출**됐다. 옮긴 뒤 브라우저로 눈으로 보고 태그 균형을 파서로 검사하라.
- **들여쓰기 공백으로 태그를 찾지 마라.** 12칸 들여쓴 `</div>`가 10칸 문자열을 부분일치로
  품어 엉뚱한 곳을 닫는 곳으로 잡는다 → div 깊이를 세라.
- **`computer` 도구 좌표 != CSS 픽셀** (스크린샷 1568x744 vs innerWidth 1920x855,
  x0.817/0.870). 환산 안 하면 클릭이 엉뚱한 데 떨어지고 **조용히** 실패해 오진한다.
- **한글을 유니코드 이스케이프로 손수 적지 마라** — 글자 하나를 잘못 적어 스크립트가 죽었다.
