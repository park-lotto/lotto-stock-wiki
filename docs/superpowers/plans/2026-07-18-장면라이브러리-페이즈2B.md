# 장면 라이브러리 페이즈2-B 구현 계획 — 역할/기분 기반 매칭

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 소재 매칭이 못 채운 빈 비트에, 비트의 역할 자리에 맞는 요소짤을 결정적 매핑표로 자동 배치한다(귀여운 리액션→훅, 눈물 양파→문제, 만족 슬라이스→과정, ASMR→완성).

**Architecture:** `match_scene_assets`에 2차 "역할 패스"를 추가한다. 1차 소재 패스(기존 Gemini 매칭)가 끝난 뒤, `cutaway`가 없는 비트에 대해 **결정적 매핑표**(`_ROLE_FALLBACK`)로 비트 역할↔자산 역할을 맞춰 배치한다. 역할 패스는 Gemini를 안 쓰므로 과배치가 불가능하다. 렌더·배선은 페이즈2-A 그대로 재사용(`beat["cutaway"]`에 asset_id만 있으면 렌더됨).

**Tech Stack:** Python 3.14, pytest, 순수함수(Gemini 없음), FastAPI(app.py 컷어웨이 엔드포인트), produce.html(검수판 배지).

## Global Constraints

- **역할 패스는 Gemini(`_vault_call`)를 쓰지 않는다** — 결정적 매핑표로만. AI 과배치(2-A grounding에서 관측) 원천 차단.
- **소재 우선**: 1차 소재 패스가 배치한 비트는 역할 패스가 절대 안 건드린다.
- **한 영상 내 반복 금지**: 같은 asset_id는 한 영상에서 한 번만 배치.
- **`match_type` 필드**: 모든 자동배치 cutaway에 `"match_type": "subject"|"role"` 표기. 검수판이 구분해 보여준다. (수동 넣기는 `"manual"`.)
- **후보 필터**(기존 `_candidates` 재사용): `asset_type=="clip"` 且 `source_origin ∈ {짜집기,촬영원본}`.
- **렌더·배선 무변경**: `video_assemble.py`·`mix_pipeline.py`는 건드리지 않는다(2-A 그대로 탐).
- **순수함수 유지**: `match_scene_assets`는 plan을 deepcopy, 원본 불변.
- **파일 수정은 Edit로**(Python write_text 통짜 재작성 금지 — CRLF 오염).
- **produce.html 최소 변경**: 4트랙 동시편집 중. `scene-cutaway` 블록·`renderSceneCutaway`만 손대고 공용 프리뷰·ID 무접촉.

## 자료 형태 (구현자 참고)

**자산**(`_candidates` 반환): `{id, asset_type, role, tone, subject, keywords[], category, source_origin, media_path, ...}`. `role ∈ {훅,반전,CTA,비법공개,반응,전환,본문}` (autotag가 부여, 빈 문자열일 수 있음).

**비트**: `{beat_idx, role, narration, target_seconds, primary, ...}`. `role`은 video_type별 문자열(예: `hook`, `problem_solution`, `easy_process`, `process_step1`, `result_wow`, `benefit`, `cta`).

**현 `match_scene_assets`**(scene_match.py): 소재 패스 루프 → `beat["cutaway"]={asset_id,score}` 또는 `plan["asset_suggestions"]`. 이 뒤에 역할 패스를 붙인다.

```python
def _role_pass(plan, cands):
    """소재 패스가 못 채운 빈 비트에, 비트 역할에 맞는 요소짤을 결정적으로 배치한다.
    Gemini 안 씀 — 역할 호환표로만. plan을 제자리 수정. 한 영상 내 반복 금지."""
    used = {b["cutaway"]["asset_id"] for b in plan["beats"] if b.get("cutaway")}
    by_role = {}
    for a in cands:
        by_role.setdefault(a.get("role") or "", []).append(a)
    for beat in plan["beats"]:
        if beat.get("cutaway"):
            continue  # 소재 패스가 이미 배치 — 안 건드림
        compatible = _ROLE_FALLBACK.get(beat.get("role") or "")
        if not compatible:
            continue  # 이 비트 역할은 요소짤 자리가 아님 → 빈 채로
        pool = [a for role in compatible for a in by_role.get(role, [])
                if a["id"] not in used]
        if not pool:
            continue
        chosen = _pick_role_asset(pool, beat.get("narration") or "")
        beat["cutaway"] = {"asset_id": chosen["id"], "match_type": "role"}
        used.add(chosen["id"])


def _pick_role_asset(pool, narration):
    """역할 호환 후보 중 1개. 나레이션과 keyword/subject 겹치면 우선(Gemini 없음),
    없으면 결정적 순서(최근 담은 것 = id 큰 것 우선)."""
    def overlap(a):
        text = (a.get("subject") or "") + " " + " ".join(a.get("keywords") or [])
        return sum(1 for w in text.split() if w and w in narration)
    return sorted(pool, key=lambda a: (-overlap(a), -a["id"]))[0]
```
