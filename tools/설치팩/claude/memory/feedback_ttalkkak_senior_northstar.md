쇼핑쇼츠 제작소(produce) 기능을 설계할 때 **북극성 = "캡컷 못 쓰는 시니어도 쓸 수 있는 프로그램"**.
사장님 명시(2026-07-18): *"편집없이는 자동으로 될수가없어 그 편집도 결국 딸깍으로 할수있게 해야해. 캡컷 못쓰는 시니어도 쓸수있는 프로그램이야."*

**Why:** 타깃 사용자가 영상편집 도구(캡컷 등)를 못 다루는 시니어다. 자동화만으로는 부족해서
사람의 개입(편집)이 반드시 필요한데, 그 편집을 슬라이더·타임라인 드래그·수치입력으로 주면 타깃이 못 쓴다.

**How to apply:**
- "편집은 나중에, 일단 자동만" 식으로 편집을 빼지 마라 — 자동만으로 안 되니까 편집이 **필수**다.
- 단 모든 편집은 **딸깍(버튼 한 번)**으로. 슬라이더/드래그/수치입력은 기본화면에서 감추고 "고급"으로만.
- 어긋난 것은 **색으로 표시**해 시니어가 문제 줄만 찾아 버튼 한 번 누르게. "전부 맞추기/되돌리기" 같은 일괄 딸깍도.
- 모션효과 트랙도 같은 북극성("60대도 쓸 수 있게")을 세웠다 — 제작소 전 기능 공통 원칙으로 본다.
