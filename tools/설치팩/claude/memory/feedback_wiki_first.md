질문이 들어오면 위키 먼저 읽고, WebSearch로 최근 내용 교차검증해서 답한다.

**Why:** 위키를 쌓는 이유가 매번 검색 안 하기 위해서인데, 질문마다 WebSearch부터 하면 위키의 의미가 없다. MASGA 질문에서 위키에 이미 다 있는데 WebSearch 먼저 한 게 잘못된 사례.

**How to apply:**
```
① 위키 먼저 — 섹터/종목 파일에서 구조·논리·밸류체인 확인
② WebSearch — "지금도 살아있나?" "최신 수치 맞나?" 현재 상태만 검증
③ 위키(구조) + WebSearch(현재) 합쳐서 답변
```

위키 = 구조·논리·체인·히스토리 (변하지 않는 것)
WebSearch = 현재 상태·최신 수치·살아있는지 여부 (변하는 것)
