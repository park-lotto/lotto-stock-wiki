# 03 배치·자리 검출 일반화 — `placement.py` + `fx_target.py` + `sound/sfx_events.py` (표준 §3-3 A1·A2·A3)

## 목표
"어느 줄에 무엇을 붙이나"(placement) 가 **전환·효과음·짤·스티커·화살표/원** 전부를 k/n 규칙으로 정하고, 자리는 **검출**로 받는다(눈대중 좌표 금지 — handoff 10-18 샥탬 "빨간원 너무 안 맞는다"). 샥탬 전용 `shark/fx_place.py` 의 검출을 채널 무관 모듈로 뽑는다. 벤치 효과음 신호표는 채널마다 자기 파일을 갖는다.

## 실측 배경(10-24)
- `placement.place(rows, style, seed)`(197~315): 본보기 벤치 편 1개(`reference`) → 칸(narr/orig × first/rest)마다 등장 비율 배분 · 강조 · 스티커(종류·개수, 조건 lex 4종 excl/lux/price/q) · 효과음(`want` = 본보기 편 sfx 시각을 우리 덩어리 시작에 배분, kind 하나) · 번쩍 `flashes`(share). 스티커 좌표는 **고정**(`hearts x50 y41`, 연예인레시피 `object_pop x62% y54%`). `effects_step`(360~) 은 `caption-motions.js /*RULES*/` 계약 규칙(rgbGlitch·wipeRTL·rainbowCycle·hearts·comic_burst·aside_line…)을 벤치 채널(`bench.ko`)에만 적용.
- `count(style)`(108~149): 줄판독 + `_sfx_table`(`bench.sfx_events` 파일에서 `sfx_key/` 접두 키) → `counted`. **sfx_events 파일 = `channel/starpickroom/_tools/결과/sfx_events_rules.json` 하나**를 키치잇·꿀템노트·스타픽룸 판이 공유(키 `kitchit/<id>`·`kkultemnote/<id>` 실측).
- 벤치 검출 도구 `tools/calcopy/engine/sound/{sfx_events,sfx_rules,sfx_table,sfx_fp,sfx_ncc}.py`(관제 235 가 옮김 — README 있음).
- `shark/fx_place.py`: `propose`(박자→꾸밈) · `hook_object`(0초 빨간 원 = 물건 상자, 얼굴 겹치면 거절) · `on_target`(끝점이 대상 상자 가장자리, 자막 띠·창 밖이면 drop) · `track_box`(템플릿/NanoDet 추적) · `cut_canvas`(렌더와 같은 좌표계). 샥탬 `rules.json`·`caption_style.rules` 에 묶여 있다.
- 줄판독 칸 `transition`(cut|zoomblur|flash|black)·`sticker{x,y,w,anim}`·`sfx{kind,t,basis}` 는 지침서 §6 정의(대부분 비어 있음 — 06 이 채운다).

## 설계(판단 주인)
1. **전환(A1)** — `place()` 가 `transitions:[{t, kind, ms}]` 를 낸다: 본보기 편 줄판독 `transition` 칸 비율(없으면 `counted.transition`)을 우리 컷 경계에 배분. 조건: 화자 바뀜·공개 줄 앞·컷 길이 ≥1.2초(짧은 컷엔 안 붙임). 판 칸 `placement.rules.transition{kinds, cond, max_per_video}` + `cuts.transition.ms`(02 와 같은 이름). 기존 `flashes` 는 `transitions kind=flash` 로 **통합**(한 자리에서만 정한다).
2. **효과음(A2)** — 조건을 lex 4종 → `role`(훅·공개·반전·끝)·강조 낱말 자리·컷 경계·전환 종류로 늘리고, `kind` 를 하나가 아니라 `placement.rules.sfx.kinds{pop:…, whoosh:…, ding:…}` 비율로. 시각 편차 = 벤치 `basis`(덩어리 시작 −0.03 등) 중앙. 벤치 신호표는 `sfx_events.py <slug>` → `channel/<slug>/_kal/sfx_events.json`(키 `<id>`), `count()` 는 `bench.sfx_events` 를 그 경로로 읽는다(옛 공유 파일은 변환 1회).
3. **자리 검출(A3)** — `fx_target.py`: `find(kind, frame_png|mp4+t, win, avoid=['face'])` → `{x,y,w,h,conf}`(물건 = 손 상자·`object_box`(제미나이 금지 → Claude CLI `claude_cli.ask` 또는 YuNet/NanoDet 로컬) · 얼굴 = YuNet(`hybrid/thumb.py` 모델 재사용) · 자막옆 = 자막 띠 상자 바깥 가장 가까운 빈 자리) · `on_target(target_box, size, canvas, caption_band)`(샥탬 on_target 논리 이식 — 자막 띠 덮음·창 밖이면 None). `place()` 스티커·짤·pointer 는 `rules.stickers.<kind>.target`(face|object|caption_side|fixed{x,y}) 로 자리를 받는다 — `fixed` 는 **벤치 실측 좌표가 있을 때만**(why 필수).
4. **짤(meme)** — `rules.meme{rate, cond(role·lex), tone, len_s, pack}` → `stickers kind=meme src=<팩 파일>`(짤 팩 `C:/숏템_칼카피/packs/meme`·`meme_exclude.json`). 벤치에 짤 0 인 채널(두유노)은 rate 0 → 0개(없는 것도 스타일).
5. `check_place()` 에 전환·효과음 종류·짤·스티커 자리(검출 conf ≥0.6·얼굴 안 겹침) 대조 추가 — 04 가 그대로 부른다.

## 합격 검사(사보타주 먼저)
1. 전환: 본보기 편 줄판독에 `transition` 을 zoomblur 3개로 꾸민 픽스처 → `place()` 출력 `transitions` 에 zoomblur 가 3±1 개, 전부 컷 경계 시각과 ±1프레임. 고치기 전 코드는 키 자체가 없어야 한다(검사 실패 확인).
2. 효과음: 픽스처 줄판독(sfx 6발, role 훅 2·공개 2·끝 2) → 배치가 role 비율을 ±1발 안에서 따라간다 · 종류 비율 따라감 · 0.3초 안 겹침 0.
3. 자리: 샥탬 QMJ 1차 완성본 재료(`channel/foreignshowshow/preset/_hand` 손 측정 상자)로 `fx_target.find object` 가 손 상자와 IoU ≥0.5 · 얼굴 겹침 시 None · 자막 띠 덮으면 None(3건 픽스처).
4. 회귀: 키치잇판 성시경 `placement.py plan` 결과가 고치기 전과 **등장·강조·스티커 개수 같음**(전환·효과음 종류만 늘어난다) — 자막표.json diff 를 보고에.
5. `count 키치잇판` 결과 `counted.sfx` 가 옛 공유 파일 기준과 같다(변환 검증).
