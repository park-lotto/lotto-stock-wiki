## ⚠️ 다시 밟지 말 것

1. **테스트에 고정 날짜를 박지 마라.** 랭킹·수집은 전부 시간 창이 있어서
   며칠 지나면 조용히 `[]`가 된다. `datetime.now(timezone.utc) - timedelta(...)`를 써라.
   (단 `now`까지 함께 고정해 자기완결인 테스트는 그대로 둬도 된다)
2. **`except: pass`는 기능을 통째로 죽인다.** 이번 SQL 버그가 정확히 그 형태였다.
   삼키더라도 **로그는 남겨라** — 안 남기면 못 찾는다.
3. **일회성 스크립트에 `test_` 이름을 쓰지 마라.** pytest가 주워가 import 시점에
   실행된다. `scripts/_*.py` 관례를 따라라.
4. 루트에서 `pytest`가 0개를 뱉으면 **폴더별로 rc를 대조**해라(빈 폴더는 rc=5,
   범인만 rc=1). 이번에 그걸로 `docs`를 특정했다.
