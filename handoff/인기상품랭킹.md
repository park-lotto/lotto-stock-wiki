## 2026-10-19 (회사 PC, TheRose) — 기획·수집 실측·시안 v3

**무엇·왜**: 숏템메이커 회원이 "지금 잘 팔리는 신박템"을 보고 → 제품명으로 숏템파워(`/?kwfind=<제품명>`) 검색 → 영상 제작.
레퍼런스랭킹 같은 UI, 사이트 탭 + 카테고리(홈템·뷰티·장비템·차량템·반려템·육아템·디지털템) + 정렬. 매일 **오전 8시** 수집(사장님 확정).
사장님 요구: 객관 데이터(시간당 판매·리뷰 등)로 "진짜 잘 팔린다"를 잰다 · **광고 상품 제외** · 식품·소모품 등 쇼츠 불가 제외 ·
아이템스카우트·판다랭크·셀러라이프·데이터랩 로직을 **우리 것으로** 만든다.

- `NAVER_SEARCHAD_CUSTOMER_ID/ACCESS_LICENSE/SECRET` — 사장님 검색광고 계정(chjh_1020) **10-19 회사 PC .env 에만 넣음** → 집 PC `.env` 에도 넣어야 한다(광고주센터 도구 → SA API 사용 관리에서 다시 볼 수 있음)

- 테무 로그인 프로필 `~/.claude/temu_ff_profile` — **PC마다** 파이어폭스로 한 번 로그인

### 시안 v3 (`tools/hot_products/시안_v3.html`, 바탕화면 사본)
1,609개 수집 → 쇼츠 가능 538개(광고 86 제외). 종합 점수 = 판매속도 35%(사이트 내 백분위) + 검색수요 25% + 신박함 25%(AI 0~3) + 쇼츠기회 15%(검색 많고 유튜브 조회 적음). 비율은 임시.
크롬으로 사이트 5 × 정렬 3 눌러 확인, JS 오류 0.

### 조사 (research/)
- 국내: 쇼핑쇼츠 강사는 숫자 기준 거의 없음(신기함·시즌성). 셀러 강사: 월 검색 1천~1만+, 경쟁강도=상품수÷검색수, 3년 추세, 리뷰1≈판매30
- 해외: 판매 성장률 20%+, 30일 판매 1천~5천 중간구간, 크리에이터 수(포화), 일주일 내 영상, 국내 미출시. **누적 판매순만 보면 오래된 상품이 위로 오는 함정**
- 아마존: 월판매 100~300+, 리뷰 50~500 이하, BSR 하락 횟수=판매(Keepa 방식)
