# 자막장면조절

## 2026-08-31 — 자막 드래그 적용 범위(이 장면만 / 모든 장면)

사장님 요청: "장면꾸미기에서 자막을 이동하면 한장면씩 적용이랑 모두 적용할수있게"

### 무엇이 문제였나
- 미리보기 자막 드래그(`bindCapDrag`)는 **전체 설정**(CAP_X_PCT / capY)만 바꿨다 → 늘 모든 장면.
- 장면별 자리는 버튼 3단(위/중간/아래 = `cap_pos`)뿐이라 "이 장면만 조금 옆으로"가 불가능했다.

### 한 것 (커밋 684aa1b8c)
- `produce.html` 미리보기 아래 **[🌐 모든 장면 / 🎯 이 장면만]** 토글(`CAP_DRAG_SCOPE`, 기본 all=종전 동작).
- `one` → 끈 자리를 그 비트에만 `cap_xy{x_pct,y_pct}` 저장. 전체 설정은 안 건드린다.
- `all` → 전체 설정 저장 + `{apply_all:true}`로 **장면별 덮어쓰기를 싹 지운다**
  (안 지우면 손댔던 장면만 안 따라와 "모두 적용했는데 몇 개는 그대로"가 된다).
- 저장은 **손 뗄 때 한 번**(드래그 중 매 픽셀 POST 금지).
- API `/api/produce/mix/{job}/cappos` 3가지 body: `{beat_idx,pos}` / `{beat_idx,x_pct,y_pct}` / `{apply_all}`.
- 우선순위 **cap_xy > cap_pos** 는 `video_assemble._beat_cap_style` 한 곳에서만 푼다(0순위-B).
  미리보기(`updateCaption`)·`beats_preview`도 같은 순서.
- 버튼(위/중간/아래)을 누르면 그 장면의 `cap_xy`를 지운다(두 벌 방지).

### 검증
- 신규 `shopping_shorts/tests/test_cap_drag_scope.py` 4건 통과.
- 기존 `test_beats_preview` + `test_caption_size_matches_preview` 14건 통과.
- `produce.html` 인라인 JS `node --check` 통과.

### ⏭ 남은 것
- **브라우저 실측 미완**: 실제 job으로 5단계에서 끌어보고 (a)'이 장면만'이 옆 장면을 안 건드리는지
  (b)'모든 장면'이 장면별 표시를 되돌리는지 (c)최종렌더 자막이 그 자리로 나오는지 눈으로 확인.
- 자유 좌표를 쓴 장면에 "이 자리를 모든 장면에" 버튼(현재는 다시 끌어야 함) — 필요하면 추가.
