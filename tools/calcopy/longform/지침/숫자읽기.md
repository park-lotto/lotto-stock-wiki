# 숫자 읽기 지침

`numread.py` 가 소리 칸을 만든다. 자막은 숫자 그대로 두고, 소리 칸만 한글로 바꾼다.

## 자동으로 처리

| 표기 | 소리 |
|---|---|
| `18.8%` | 십팔 점 팔퍼센트 |
| `1977년` | 천구백칠십칠년 |
| `6월`, `10월` | 유월, 시월 |
| `1만 6천` | 만 육천 |
| `3개`, `3명`, `3배` | 세 개, 세 명, 세 배 |
| `300명` | 삼백 명 |
| `GDP`, `IMF`, `AI`, `K자` | 지디피, 아이엠에프, 에이아이, 케이자 |

## 사람이 고칠 것

- 사전에 없는 영문 약어
- `1.5배`처럼 고유어와 소수가 섞인 표현
- 전화번호, 코드, 모델명
- 받아쓰기에서 다르게 들린 줄

숫자·기호·영문이 남으면 `tts.py` 는 녹음하지 않고 멈춘다. 고친 소리 칸은 같은 문장이면 다시 돌려도 유지된다. 한 줄만 다시 녹음할 때는 `--only 줄번호`.

## 발음 확인

받아쓰기로 전 문장을 대조한다. 숫자는 표기 차이로 일치율이 낮게 나오므로, 숫자가 다르게 받아써진 줄만 사람이 듣는다.
