# 롱폼차단 — 가로형(롱폼)은 제작소 1단계에서 막는다

> **소유 트랙**: 롱폼차단 — 이 파일은 이 트랙 세션만 수정한다.

## 2026-09-03 사장님
"롱폼이나 쇼츠 비율 아닌 게 들어오면 1단계에서 막아줘. 매칭에서 막으니까 돌아오게 되니까."

### 착수 전 실측
- 판정은 이미 한 곳: `mix_pipeline.is_landscape_wh` (비율 1.15 초과 = 가로형, 못 재면 None).
- 1단계 `source_brief` API가 `landscape`를 내려주고 화면은 **배지만** 붙였다(08-27).
- 실제 차단은 3단계 믹스 `_block_landscape` → 분석·다운로드를 다 치른 뒤 실패해 1단계로 되돌아왔다.

### 한 일 (produce.html만)
- `_applyLandscapeGate(code, d)` 신설 — 분석 결과 적재 직후 호출. `landscape===true`면 그 영상의
  `useFootage/bbMain`을 풀고 `h.landscape=true` 표식, 토스트로 사유(해상도 포함) 알림.
  None(못 잼)·false는 안 건드린다(서버 설계 그대로, 판정 재계산 없음 = 0순위-B).
- `pickFootage`: landscape 카드는 눌러도 안 담기고 토스트만.
- 카드 CSS `.pool-card.lscape` — 흐리게 + "가로형(롱폼) · 못 씀" 라벨.
- 테스트 `test_produce_landscape_gate_step1.py` 4건. produce/pool 관련 390 passed
  (실패 3건 `test_pooled_keys_status`는 내 변경 stash해도 똑같이 실패 = 기준선).
