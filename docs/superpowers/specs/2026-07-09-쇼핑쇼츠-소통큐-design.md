# 쇼핑쇼츠 자동화 — 소통 큐 (기능 ②) 설계

날짜: 2026-07-09
상태: 설계 확정 대기
선행: 기능 ① 레퍼런스 랭킹 (완성, `shopping_shorts/`)

---

## 1. 목적 (What & Why)

내 인스타 계정을 초반에 키우기 위한 **반자동 소통 보조**. 레퍼런스 채널들의 릴스에 직접
댓글을 달아 노출·맞팔을 유도한다. **자동 댓글·좋아요·팔로우는 봇 감지로 밴 위험이 커서 절대 안 함.**
사람(사용자)이 실제로 타이핑/전송하고, 프로그램은 **"어디에·뭘 남길지 준비"까지만** 반자동으로 돕는다.

- 소스: 기능 ①이 수집한 릴스 데이터 (SQLite + 메모리 캐시) 재활용
- 큰 그림: 기능 ①(터진 거 벤치마킹)과 목적이 정반대 — ②는 **갓 올라온 거 선점**해서 초기 댓글로 노출.
- 이 스펙 범위는 기능 ②만. 같은 웹앱(`shopping_shorts/`)에 **새 사이드바 메뉴 "소통 큐"** 추가.

### 절대 금지 (밴 방지)
- ❌ 자동 댓글 입력·전송 / 자동 좋아요 / 자동 팔로우 (셀레니움 등)
- 프로그램은 **문구 준비 + 게시물 새탭 오픈 + 클립보드 복사**까지만. 붙여넣기·전송은 사람.

## 2. 정렬 (3옵션, 사용자 선택)

기능 ①이 이미 계산한 지표(`timestamp`/`age_hours`, `comments`, `speed`) 재활용. 정렬만 추가.

| 옵션 | 기준 | 소통 전략 |
|------|------|----------|
| **🆕 최신 업로드순** | age_hours 오름차순 (최근이 위) | 갓 올라온 거 선점 |
| **🔥 갓 올라온 터진 영상** | speed(시간당 댓글) 내림차순 | 지금 뜨는 거에 올라타기 |
| **🎯 골디락스** | 최신 + 댓글 적은 것 (age 낮고 comments 낮은 순 결합) | 내 댓글 상단 오래 노출 |

> 골디락스 점수(안): `1/(1+comments)` × `1/(1+age_hours)` 내림차순 → 최근+저댓글 상위.
> (구현 시 튜닝. 핵심: "방금 올라왔는데 아직 댓글 적은" 영상 우선.)

## 3. 댓글 문구 자동 생성 (Gemini)

- **엔진**: Gemini flash (`gemini-3-flash-preview` — 프로젝트 규칙, 메모리 `project_gemini_api`)
- **입력**: 각 릴스의 캡션(`caption`) + 채널명 + 카테고리
- **출력**: 자연스러운 한국어 댓글 **3개** (각 1~2줄, 서로 다른 톤)
- **생성 시점**: **수집 시점에 미리 생성** (진행 모드에서 대기 없게). ①번 collect() 확장 or 별도 배치.
- **핵심 원칙 (봇 감지 회피)**: 캡션 내용에 맞춘 맥락 있는 댓글만. **고정 템플릿·범용 문구 금지**
  (반복 패턴 = 봇 탐지 대상). 영상마다 내용이 다르므로 자연히 다양해짐.
- 프롬프트 방향: "이 릴스를 방금 본 팔로워인 척, 영상 내용에 반응하는 짧은 댓글 3개.
  질문형/공감형/칭찬형 등 서로 다르게. 해시태그·이모지 남발 금지, 사람스럽게."
- 저장: SQLite에 `comment_drafts` (shortcode → 3개 문구 JSON)

## 4. 화면 (리스트 모드 + 진행 모드, 둘 다)

사이드바 "소통 큐" 진입 → 상단에 정렬 3옵션 + 「완료 감추기」 토글 + 「진행 시작」 버튼.

### 4-1. 리스트 모드 (기본)
①번 카드 그리드와 유사. 각 카드에:
- 썸네일 · 채널명 · 카테고리 · 업로드 경과시간 · 댓글수
- 캡션 미리보기 (2줄)
- 댓글 후보 3개 (각각 「복사」 버튼)
- 「🔗 게시물 열기+복사」(문구① 클립보드 복사 + 게시물 새탭 오픈 동시)
- 「✓ 완료」 (DB 기록 + 감추기 토글 ON이면 즉시 사라짐)

### 4-2. 진행 모드 (「진행 시작」 클릭 시)
한 번에 **1개 영상만** 크게 표시. 집중 작업용.
```
┌──────────────────────────────────────┐
│ [썸네일]   채널명 · 3시간 전 · 인테리어  │
│            캡션: "좁은 원룸 수납 꿀팁…"  │
│  댓글 후보                              │
│   ① 이 선반 어디 거예요? 너무 예뻐요 😍  [복사]│
│   ② 원룸인데 딱 참고되네요, 감사해요!    [복사]│
│   ③ 수납 이렇게 하면 되는군요 저장했어요 [복사]│
│  [🔗 게시물 열기+복사]   [✓ 완료 → 다음] │
│                          3 / 47 진행중  │
└──────────────────────────────────────┘
```
「완료 → 다음」: 완료 기록 + 자동으로 다음 영상. 큐 끝나면 "오늘 소통 완료 🎉".

### 4-3. 클립보드/새탭 동작
- 「복사」: `navigator.clipboard.writeText(문구)` — 인스타 가서 Ctrl+V.
- 「게시물 열기+복사」: 문구①을 클립보드 복사 + `window.open(url)`로 게시물 새탭.
  → 사용자: 새탭에서 댓글창 클릭 → Ctrl+V → 엔터.

---

## 5. 완료 관리

- 「완료」 클릭 → SQLite `commented` 테이블에 `(shortcode, commented_at)` 기록.
- **「완료 감추기」 토글**: ON(기본) → 완료한 영상 목록에서 숨김. OFF → 완료한 것도 회색으로 다시 표시.
- 내일 다시 수집해도 이미 `commented`에 있는 영상은 (토글 ON이면) 안 뜸 → 매일 새 대상만.

## 6. 아키텍처 (기능 ① 확장)

`shopping_shorts/` 안에 추가:
```
shopping_shorts/
├── (기능 ① 파일들 그대로)
├── comment_gen.py     # Gemini 캡션→댓글 3개 생성
├── outreach.py        # 소통 큐 로직: 정렬 3옵션 + 완료 필터
├── (store.py 확장)     # comment_drafts, commented 테이블 추가
├── (app.py 확장)       # /api/outreach, /api/comment/done 엔드포인트
└── static/
    ├── index.html      # (①) 레퍼런스 랭킹
    └── outreach.html   # (②) 소통 큐 (리스트+진행 모드)
```

### 구성 요소
1. **comment_gen** — 캡션+메타 → Gemini 호출 → 댓글 3개. (키·모델·프롬프트·에러처리)
2. **store 확장** — `comment_drafts(shortcode, drafts_json)`, `commented(shortcode, commented_at)`.
3. **outreach** — 캐시된 릴스 + drafts 결합, 정렬 3옵션 적용, `commented` 제외(토글) → 큐 반환.
4. **app 확장** — `GET /api/outreach?sort=&hide_done=`, `POST /api/comment/done`.
5. **outreach.html** — 리스트+진행 모드 프론트, 클립보드/새탭 동작.

### 데이터 흐름
```
① collect() → 릴스 수집
   └ (신규) 각 릴스 캡션 → comment_gen → drafts 3개 → store.comment_drafts 저장
② 소통 큐 열기 → outreach.build_queue(sort, hide_done)
   → 릴스+drafts 결합, commented 제외, 정렬 → 큐
   → 화면(리스트/진행) → 「완료」 → store.mark_commented(shortcode)
```

## 7. 에러 처리

- Gemini 실패/키 없음 → 그 영상 drafts는 빈 배열, 화면에 "문구 생성 실패, 직접 작성" 표시. 전체 중단 안 함.
- 캡션 없는 릴스 → 채널명+카테고리만으로 생성 시도, 실패 시 위와 동일.
- 클립보드 API 실패(권장 http localhost는 OK) → 문구 textarea로 표시해 수동 복사 폴백.
- `commented` 중복 기록 → INSERT OR IGNORE.

## 8. 범위 밖 (YAGNI)

- ❌ 자동 댓글/좋아요/팔로우 (밴 — 절대 금지)
- ❌ 계정 로그인·세션 관리 (사람이 이미 브라우저에 로그인돼 있음)
- ❌ 댓글 반응(답글) 추적 — 후속
- ❌ 여러 계정 운영 — 단일 계정 먼저
