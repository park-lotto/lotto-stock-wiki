# 제품 판정 장애·혼합 영상 대본 차단 수정 (2026-09-16)

- 선택 레퍼런스 제품을 다수결보다 우선하고 같은 제품군의 추가 영상만 대본 재료로 사용한다.
- 제품 판정 장애·제품군 동률은 선택 레퍼런스를 확인할 수 있으면 422로 막지 않고 생성하며, 딴 제품 자료는 제외한다.
- 씨앗 선택이 대본 소재 확인 기준임을 카드 위에 안내하고, 추가 영상은 모두 분석하되 같은 제품군만 쓴다고 표시했다.
- 관련 회귀검사 71개 통과.
- 서버 `3e897d89e` 강제 재시작·HTTP 200 확인. 제품 판정 503 강제 조건에서 박복래는 `마늘 오일 보관법`, 박진우는 `맥세이프 셀카 모니터` 재료를 예외 없이 반환했다.
