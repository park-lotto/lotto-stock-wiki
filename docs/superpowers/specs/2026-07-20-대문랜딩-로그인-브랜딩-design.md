# 대문(랜딩) + 로그인 재디자인 — 브랜딩 (민트×블랙)

날짜: 2026-07-20 · 트랙: 유료게이트 · 상태: 설계 확정(사용자 승인 "고")
선행: `handoff/대문로그인브랜딩.md`(이름 5안·브레인스토밍), `handoff/유료게이트.md`(OAuth·게이트 라이브)

## 목적
판매용 SaaS의 **공개 대문(한 페이지 랜딩)**과 **로그인 페이지**를 브랜드 톤(민트×블랙)으로
만든다. 지금은 공개 대문이 없고(`/`=로그인 뒤 랭킹), 로그인 페이지는 오렌지 로고+🛍️"쇼핑쇼츠"라
브랜드와 어긋난다. 방문자가 스크롤 1~2번에 "무엇을 하는 서비스인지 + 어떻게 파는지"를 이해하고
**무료 체험 CTA**로 유입되게 한다.

## 확정 범위: B(한 페이지 랜딩)
A(미니멀 스플래시)·C(풀 마케팅)를 제치고 B. 히어로 + 3스텝 + 기능 4카드 + 하단 CTA.

## 브랜드 토큰 (계승 + 스왑)
- **팔레트(고정)**: `--grad:linear-gradient(135deg,#6ff0d6,#1f9e7a)` · `--mint:#6ff0d6` ·
  패널 `#111722` · 배경 `#0a0a0d` (sidebar.js 계승).
- **이름/워드마크/슬로건(미확정 → 스왑 상수)**: 사용자가 5안(ShortsFactory/Reelery⭐/ShopReel/
  ShortsForge/Vidory) 중 선택해 알려줄 예정. **`_BRAND` 상수 1곳**(name·tagline·logo_glyph)에
  몰아 확정 시 1줄 교체. 미정 동안 플레이스홀더(`Reelery` 가안, 추천안)로 렌더.

## 라우팅 (핵심 변경)
- `/` **분기**: 비로그인 → **공개 대문(`_LANDING_HTML`)**, 로그인 → 기존 앱 홈(현 동작 유지).
  - 현재 `/`는 게이트/로그인 뒤에 있다. 대문은 로그인 전에 보여야 하므로 **게이트에서 대문을
    공개 경로로** 연다. 미들웨어가 비로그인 `/`를 로그인으로 리다이렉트하던 흐름을 "비로그인=대문
    렌더"로 바꾼다(대문 안에 로그인 CTA가 있으므로 리다이렉트 불필요).
- 대문 CTA/[로그인] → `/login`(구글 OAuth, 기존) → 로그인 후 앱 홈.
- **로그인 상태 회귀 금지**: 로그인 사용자가 `/`로 오면 대문이 아니라 앱 홈(랭킹)이어야 한다.

## 대문 섹션 (`_LANDING_HTML`)
1. **히어로** — 워드마크 + 슬로건(가안 "레퍼런스 링크 하나로, 팔리는 쇼츠가 나옵니다") +
   서브카피 1줄 + `[무료로 시작하기]`(→`/auth/google/login`) + `[로그인]`(작게 →`/login`).
   민트×블랙 그라디언트 배경.
2. **이렇게 작동 · 3스텝** — ① 잘 팔리는 레퍼런스 링크를 넣는다 → ② AI가 렌즈·대본·장면을
   분석·재구성 → ③ 내 상품으로 팔리는 쇼츠 완성. 아이콘+한 줄.
3. **핵심 기능 4카드** — 레퍼런스 랭킹(터진 영상 발굴) / 렌즈·유사영상 / 대본 추출·리메이크 /
   제작소·보이스(원클릭 편집).
4. **하단 CTA** — "지금 무료 체험 시작"(→구글) 1회 + 신뢰 한 줄("N일 무료, 카드 없이").
- 반응형: 모바일 1열, 데스크톱 3스텝·4카드 그리드. 자체완결 인라인 CSS(외부 의존 0).

## 로그인 페이지 (`_LOGIN_HTML` 교체)
- 오렌지(#ff8a4c/#ff5e62) → **민트×블랙**. 🛍️ → 새 로고 글리프. 워드마크=`_BRAND.name`.
- **구조 유지**: 구글 버튼 + 운영자 접이식(`/api/login`) + "처음이면 무료 체험이 바로 시작돼요" 톤 +
  "← 홈으로"(→`/` 대문). 에러 `__ERR__` 치환·XSS 이스케이프 그대로.

## 구현 위치 (app.py)
- `_BRAND` 상수 신규(name·tagline·glyph) → 대문·로그인이 공유.
- `_LANDING_HTML` 신규(공개 대문).
- `/` 라우트: 비로그인 분기 시 대문 반환(게이트/미들웨어 공개경로 처리).
- `_LOGIN_HTML` 교체(민트 톤).
- **게이트 공개경로**: 대문 GET을 `_FREE_EXACT_GET`(또는 동급)에 추가 — 로그인 전 접근 허용.

## 검증(실렌더 그라운딩)
- 로컬에서 앱 기동 → 비로그인 `/`가 대문을 렌더하는지 / `/login`이 민트 톤인지 **브라우저로 눈확인**.
- 반응형(모바일 폭) 깨짐 확인. CTA 링크가 `/auth/google/login`·`/login`으로 정확히 가는지.
- ⚠️ 로컬은 `_AUTH_ON`이 off라 실제 구글 로그인 흐름은 라이브에서만 — 여기선 **대문/로그인
  마크업·라우팅·톤**까지만 그라운딩, 로그인 성공 후 흐름은 라이브 그라운딩으로 넘긴다.

## 비고 (스코프 밖)
- 유저 자기 설정 페이지(2번), 남은 백엔드 크레딧 결정(3번)은 별도 — 이 스펙은 대문·로그인만.
- 가격/티어 노출은 대문에 안 넣는다(수동 승격 모델이라 공개 가격표가 아직 이르다) — 후속 판단.
