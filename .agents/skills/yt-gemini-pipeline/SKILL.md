# yt-gemini-pipeline

## ⚡ 핵심 원칙 — 신선함이 베이스다

> 대본을 잘 쓰는 것보다, **각도를 신선하게 찾는 것**이 먼저다.
> 소재가 낡으면 대본이 아무리 좋아도 시청자는 10초 만에 나간다.

### 신선함 자가진단 — 브리프 쓰기 전 필수

아래 질문 중 하나라도 "YES"면 각도를 다시 파야 한다.

```
□ 유튜브에 같은 소재 영상이 이미 10개 이상 있나?
□ 증권사 리포트나 경제 뉴스에 이미 다뤄진 내용인가?
□ "~는 좋다더라" 수준의 이미 알려진 결론인가?
□ 시청자가 이미 알고 있을 가능성이 높은가?
```

**전부 NO일 때만** 브리프 작성으로 넘어간다.

---

### 신선한 각도 발굴법 — 3가지 방법

**① 두 번 더 파기**
알려진 사실에서 멈추지 않는다. "그런데 왜?" → "그래서 어떻게?" 두 번 더 파고 들어간다.
```
낡은 각도: "조선 수주잔고가 많다"
한 번 더:  "그런데 왜 수주를 더 안 받나?" → "도크가 꽉 찼기 때문"
두 번 더:  "그러면 비싼 것만 골라 받고 있다는 뜻" → 이게 신선한 각도
```

**② 대중의 오해 뒤집기**
"당연히 X인 줄 알았는데 사실은 Y다" 구조. 역설과 반전이 가장 강한 훅이다.
```
오해: "전쟁 끝나면 방산주 끝난다"
반전: "역사적으로 전쟁 후 국방비는 오히려 더 늘었다"
```

**③ 연결고리 찾기**
관련 없어 보이는 두 가지를 연결한다. "A가 B에 영향을 준다는 걸 몰랐다"는 게 핵심.
```
연결: "미국 데이터센터 전력난" → "한국 변압기 회사 수주잔고"
더 나아가: "트럼프 관세" → "오히려 협상력이 높아진 이유"
```

---

### 지속가능성 — 시리즈 구조 원칙

영상은 독립적이되 연결되어야 한다. 시청자가 다음 편을 기다리게 만든다.

```
이번 편: 왜 이 섹터가 지금인가 (큰 그림)
다음 편: 그 안에서 어떤 종목을 어떻게 (구체 실행)
그 다음: 실제 매매 후 결과 공유 (신뢰 쌓기)
```

**다음 편 연결 원칙:**
- 이번 편 마지막에 "다음 편에서 X를 보여드립니다"를 심어둔다
- 단, X는 이번 편에서 **못다 한 이야기**여야 한다. "더 보고 싶다"는 감정을 남겨야 한다
- "구독하세요" 보다 "다음 편에서 Y의 비밀을 공개합니다"가 훨씬 강하다

---

## 언제 실행하나

각도가 신선함 자가진단을 통과한 주제에 대해.
"대본 써줘" / "리서치해줘" / "스크립트 뽑아줘" 요청 시.

---

## 전체 흐름

```
[Claude] 브리프 생성 (STEP 1)
    ↓ claude_brief 포맷으로 출력
[Gemini API] 딥리서치 → 스토리 설계 → 구어체 대본 (STEP 2)
    ↓ 완성 대본 반환
[Claude] 검수 체크리스트 (STEP 3)
    ↓ 통과 시 → yt-planner / Remotion 단계로
```

---

## STEP 1 — Claude 브리프 생성

주제 확정 후 아래 포맷으로 브리프를 출력한다.
**Claude 기억 기반 내용 금지. 현재 시점 데이터만.**

```
============================
[GEMINI INPUT BRIEF]
============================

[채널]
채널명: 로또의 스탁브레인
콘텐츠 타입: {A형(순수정보) / B형(간접노출) / C형(직접CTA)}
절대 금지: 특정 서비스명·프로그램명 직접 언급, 선동 표현

[주제]
{확정된 주제}

[신선함 근거 — 왜 이 각도가 신선한가]
{시청자 대부분이 모르는 것 / 연결고리 / 뒤집는 오해 — 1줄로}

[훅 아이디어]
{30초 안에 멈추게 만드는 역설·충격 팩트 1줄}

[주인공 종목 — 스토리 속에서 자연스럽게 등장할 1~2개]
⚠️ 주인공 종목 선정 규칙 (반드시 이 순서):
  STEP 1. Claude가 후보 2~3개를 다각도 분석해서 사용자에게 제시
           분석 각도: 스토리 적합성 / 시청자 공감도 / 수혜 구조 명확성 / 리스크
  STEP 2. 사용자가 선택 + 조언 추가
  STEP 3. 선택된 종목 검증
           ① wiki/ 먼저 확인 — 기존 분석 있으면 활용
           ② 없으면 최근 증권사 리포트 WebSearch로 수집
           ③ 수급·RS 단기 지표 금지 — 실적·사업구조·밸류에이션 펀더멘털만
  STEP 4. 검증 데이터를 브리프 보강 자료로 포함 → Gemini 실행
  → 사용자 선택 없이 Gemini 실행 절대 금지

[섹터/종목별 스토리 각도]
각도만 제시. 데이터는 Gemini가 직접 리서치.

★ {섹터1}
- 찾아야 할 각도: {어떤 방향에서 파야 하는지}
- 갈등: {어떤 반론/리스크를 정면으로 다룰 것인지}

★ {섹터2}
...

[영상 길이]
{8~10분}

[다음 편 연결]
{이번 편에서 못다 한 이야기 — 시청자가 기다리게 만드는 것}
============================
```

## STEP 2 — Gemini API 호출 (3단계 수행)

브리프 + 시스템 프롬프트를 Gemini에 전달. Gemini가 아래 3단계를 순서대로 수행한다.

**호출 방법**:
```bash
python channel/tools/gemini_script.py \
  --brief "channel/yt/brief_{주제}.md" \
  --output "channel/yt/script_{주제}_gemini.md"
```
스크립트 없을 경우 → 브리프를 직접 Gemini에 붙여넣고 결과를 `channel/yt/` 에 저장.

---

━━━━━━━━━━━━━━━━━━━━━━
1단계 | 딥 리서치
━━━━━━━━━━━━━━━━━━━━━━
클로드가 제시한 주제와 관련하여, 현재 자본시장에서 가장 신뢰도 높은
최신 정보와 데이터를 실시간으로 서치(Search) 및 수집하세요.
리서치에는 아래 3가지 요소가 '필수'로 포함되어야 합니다.

① 시장을 움직이는 핵심 모멘텀
   예: 글로벌 빅테크 CEO의 방한 일정, 특정 산업의 대규모 공급 계약,
   정부 정책 발표 등 주제와 직접 관련된 트리거

② 논리를 뒷받침할 계량적 데이터
   예: 관련 업종의 예상 밸류에이션(PER/PBR), 수출입 통계,
   글로벌 공급망 점유율 등

③ 시장의 이면과 잠재적 리스크
   예: 단기 과열에 따른 차익실현 물량, 매크로 금리 변동성,
   공급 과잉 우려 등 낙관론을 반박할 수 있는 현실적인 팩트 체크

━━━━━━━━━━━━━━━━━━━━━━
2단계 | 스토리 설계
━━━━━━━━━━━━━━━━━━━━━━
수집된 데이터와 클로드가 제시한 [채널 메인 뷰]를 기반으로,
이 주제에 가장 자연스러운 스토리 흐름을 직접 설계하세요.

구조는 주제마다 다릅니다. 아래 원칙만 지키면 됩니다:
- 시청자가 영상 초반에 "왜 이걸 봐야 하는지" 느껴야 한다
- 클로드가 제시한 핵심 주장이 중심축이 되어야 한다
- 리스크와 반론은 반드시 포함한다 (채널 신뢰도 보호)
- 마지막은 클로드가 지정한 [다음 편 연결]로 마무리한다

스토리 설계 후, 선택한 흐름을 1줄로 먼저 제시하세요.
예) "공감 훅 → 과거 데이터 비교 → 현재 차이점 → 리스크 → 결론"

━━━━━━━━━━━━━━━━━━━━━━
3단계 | 대본 작성
━━━━━━━━━━━━━━━━━━━━━━
설계된 스토리 흐름대로 구어체 풀 대본을 작성하세요.

[말투 규칙]
- 편안한 대화체: "~죠", "~요", "~거든요"
- 자연스러운 추임새: "솔직히", "근데 어라?", "가만 있어봐요", "이거 봐요"
- 호흡 가이드: (잠깐 멈춤), (진지하게), (싱긋), (강조) 괄호 표기
- 숫자는 말로 풀기: "37.2%" → "세 집 중 한 집 이상"

[리스크 관리 문구 — 결론 직전 반드시 삽입]
"물론 이게 100% 확정은 아닙니다. 데이터상 확률 높은 시나리오로
보시고, 본인 판단과 리스크 관리는 꼭 병행하세요."

[출력 형식]
씬번호 | 예상시간 | 핵심대사 | 화면설명

## STEP 3 — Claude 검수 체크리스트

Gemini 대본 받은 후 아래 항목 전부 확인. 하나라도 ❌면 해당 씬 수정 후 재확인.

```
[신선함]
□ 이미 알려진 이야기를 재탕한 것이 아닌가?
□ 시청자가 "이건 몰랐다"고 할 반전·연결고리가 최소 1개 있는가?
□ 다음 편이 궁금해지는 "못다 한 이야기"가 마지막에 심겨 있는가?

[품질]
□ 서비스명·프로그램명 0회인가
□ "무조건·폭등·반드시" 류 선동 표현 0회인가
□ 수치마다 출처가 있는가 (grounding 확인)
□ 리스크가 정면으로 다뤄졌는가 (회피 금지)
□ 첫 30초 안에 "왜 봐야 하는지" 나오는가
□ 다음 편 연결이 브리프와 일치하는가
□ 문어체 문장이 없는가 ("~이다", "~하였다")
```

전부 ✅ → `channel/yt/script_{주제}_final.md` 로 저장 → yt-planner 단계로.
