# 타입캐스트 성우 「지훈」 추가

**날짜**: 2026-09-22 · **트랙**: `타입캐스트지훈` · 선행: `handoff/타입캐스트배선.md`

## 무엇을
사장님 요청 "tts부분에서 타입캐스트 지훈 신규로". 성우 카드에 지훈(3톤) 추가.

- voice_id `tc_61f0859907085fc68561c9a1` — `/v1/voices` 1143건 중 이름 매칭 1건(`Jihoon`), ssfm-v30 지원,
  감정 normal·toneup 지원 실측. `/v2/voices` 메타: male · young_adult · Conversational
- 세팅은 기존 6명과 동일(ssfm-v30 · 속도 1.2 · stable/natural/expressive). whisper는 같은 기준으로 뺌
- 한줄설명 "대화체에 맞는 젊은 남성" = API 메타데이터만 옮김(청취 전이라 음색 형용사 안 붙임)
- `best:false` → '더보기'에 붙는다

## 파일
- `shopping_shorts/scripts/add_typecast_presets.py` — VOICES에 지훈, `--only <group_id>`, 굽기 가드
- `shopping_shorts/assets/voice_presets.json` — 65→68행(+63줄, 삭제 0)
- `shopping_shorts/assets/voice_samples/tc-jihoon-{stable,natural,expressive}.mp3`

## ★함정 — 샘플이 무음으로 구워지는데 [OK]가 찍혔다
`TYPECAST_ENABLED` 기본값 0(09-07~) → `tts.py:129`가 일레븐랩스로 갈아끼움 → 그 키가 없어 무음 mock.
첫 굽기 3개가 전부 53,683B · MD5 동일 · -91dB였다. 스크립트는 예외가 없어 [OK]를 찍었다.
→ 굽기 전에 `enabled()`·`api_key()` 없으면 중단하는 가드 추가(엔진 끈 채 실행해 중단되는 것 확인).
굽는 법: `TYPECAST_ENABLED=1 TYPECAST_API_KEY=<루트 .env 값> py …/add_typecast_presets.py --bake --only tc-jihoon`
(config는 루트 `.env`를 안 읽는다 — env로 직접 넘겨야 한다)
