# 휴지통띠제거 — 장면MIX 빨간 띠 먹통

## 2026-09-16 (CH) — 완료

### 증상 (사장님 제보 + 캡처)
장면MIX 화면 하단에 빨간 띠 **"🗑 여기에 놓으면 이 장면이 빠집니다"**가 뜨고 **먹통**.

### 원인 (브라우저 실측으로 확정)
빨간 띠는 에러가 아니라 **휴지통 기능의 안내문구**(2026-08-15 "좌측으로 끌어다 버리면 빠지게").
`dragStart`가 `dragFrom`과 왼쪽 패널 `bin` 클래스 **둘을 켜는데**,
`dragDrop`의 이른 반환이 **`dragFrom`만 비우고 `bin`은 안 걷어서** 띠가 남았다.
`render()`가 끌던 요소를 지우면 `dragend`도 안 와 스스로 회복되지 않는다.

실측(Playwright): 제자리 드롭 후 `dragFrom=null` / `bin=true` → 띠 잔존.

### 조치 — 사장님 지시 "필요없는거면 없애서 이 현상 없애"
`shopping_shorts/static/scene_lab.html` 에서 휴지통 기능 전체 제거:
- `#binmsg` 마크업 · CSS(`.pane.left.bin`) · `body.tight #binmsg` 규칙
- 왼쪽 패널 `ondrop="paneDrop(event)"` · `ondragover` · `paneDrop()` 함수
- 드래그 종료 경로를 **`itemDragEnd()` 하나로 통일**(이른 반환도 이걸 부른다)

**빼기 기능은 그대로** — 썸네일 **두 번 클릭**(`dropCutFromBand`·`delSeg`) 유지.

### 검증 (실제 페이지, Playwright)
- 빨간 띠 엘리먼트 **null** · 문구 **0개** · `paneDrop` **undefined**
- 콘솔 오류 **0**
- 잡기/제자리드롭/취소 전부 `bin=false`, `dragFrom=null` (잔존 없음)
- 순서 변경 정상 (`a,b,c,d` → `b,c,d,a`)
- 빼기 함수 `delSeg`·`dropCutFromBand` 살아 있음
