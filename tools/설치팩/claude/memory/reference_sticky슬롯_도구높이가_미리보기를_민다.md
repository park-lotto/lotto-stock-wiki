produce.html 장면꾸미기에서 사장님이 "장면 넘길 때 미리보기창 크기가 바뀌는 지점들이
생긴다"고 제보. **상자 크기는 안 변했다** — 20컷 내내 `460x818` 고정.

진짜 원인: 미리보기 **아래** `#capLinesBox`(줄 나누기 칸) 높이가 자막 줄 수를 따라
`82 / 123 / 164px`(2·3·4줄 × 41px)로 바뀌고, 슬롯이 `position:sticky`라
슬롯 전체 높이가 `1430 / 1471 / 1512`로 튀며 미리보기를 위아래로 **민다**.
바뀌는 지점 = 컷 2·8·12·16. 고침 = 4줄분 고정 + 내부 스크롤 → 20컷 전부 1512 단일값.

**적용 규칙**: sticky 요소 안에 높이가 데이터에 따라 변하는 칸을 넣지 마라.
넣어야 하면 고정 높이(또는 내부 스크롤).

**측정 함정**: 처음 12컷을 쟀을 땐 "고정"으로 나왔다 — 그림 로딩을 안 기다려
도구 영역이 아직 다시 안 그려졌기 때문. 레이아웃 측정은 **로드·리렌더를 기다린 뒤**,
그리고 **전 구간**을 재라. 일부만 재고 "변화 없음"이라 답하면 사장님 제보를 부정하게 된다.
