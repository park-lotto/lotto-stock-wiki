# 담은장면전부 — 구절 맞춤 끈 칸 컷 규칙 단순화 (2026-09-14)

## 왜
- 고객 제보 2건: ① 같은 영상이 칸마다 3·2·1개로 쪼개짐 ② 훅 7초에 조각 2초+5초를 담으면 5초가 2.2초 상한에 잘려 `1,2,2` → 순서를 `2,1`로 못 바꿈. 간헐적으로 1컷이 되기도.
- 사장님 로컬 조작: 규칙이 너무 많아(비율 배분·✋·0.6초 떼어주기·2.2초 쪼개기·0.8초 하한·전체 늘리기) "매번 계산이 들어가니 아무도 모른다".

## 확정 규칙 (사장님 2026-09-14)
1. 구절 맞춤 켬 = 자막 줄마다 컷(기존 그대로)
2. 구절 맞춤 끔 = **켜져 있던 화면 그대로 얼린다**(연속 같은 장면 컷은 한 컷으로 합침)
3. 경계 끌기 = **양옆 두 컷만** 바뀐다. 하한 0.3초
4. 장면 빼기 = 그 시간은 **앞 컷**이 받는다(첫 컷이면 뒤 컷)
5. 장면 넣기 = 맨 뒤에 붙고 **마지막 컷을 반으로**
6. 음성이 짧아지면 뒤 컷부터 줄인다 / 모자라면 **알아서 안 채운다** → 안내 "N초가 비었어요 — 앞 조각들에서 조금씩 장면을 길게 해주세요" + [전체 살짝 느리게](배속 한도 1.15 넘으면 경고만)
7. 빈 시간이 있으면 **완성본 만들기 막음**(사장님 "안채우면 안되지")
8. 박스 교체(🔁)는 그 컷 자리 그대로 새 조각으로, 짧아지면 빈 시간 발생
- 옛 저장본(끔인데 얼린 컷 없음) = 장면마다 자기 길이 1컷(고객 화면이 구절 화면으로 바뀌지 않게)
- 1장=1컷 버튼 제거

## 구현 위치
- 화면: `static/scene_play.js` CUTS·SLOW·syncCuts·frozenClips·freezeCuts·dragCut·cutsGap·slowFill, planClips 맨 앞 분기
- 경계끌기: `static/scene_timeline.js` wireEdges(CUTS면 dragCut)
- 머리글 안내·렌더 막기·저장/복원/전송: `static/scene_lab.html` (renderBand gapHtml, _askRender, snapWork cuts/slow, hydrateCuts, _editPayload cuts/slow, replaceRoll)
- 서버: `edit_plan.apply_scene_lab` → beat.manual_cuts[{seg_id,video_id,start,dur}]·slow / `video_assemble.plan_beat_clips_for` manual_cuts 분기(phrase_sync False). manual_cuts 없는 끔 칸은 장면마다 1컷 비례(`_all_in`)
