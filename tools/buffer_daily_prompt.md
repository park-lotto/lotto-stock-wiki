## 0. 파일 이름부터 영어 규칙으로 (사장님 11-04 — 버퍼에 올리기 전 필수)
- 계획의 `rename_first`(한글·번호 없음·대문자·띄어쓰기 이름, ready·prepare 에 든 것 포함)는 1번 장면 모음으로 내용을 본 뒤 이름부터 바꾼다:
  `py tools/buffer_post.py rename --folder "<folder>" "<지금 이름.mp4>" <english_words>`
  - english_words = 쉬운 영어 소문자, 단어 사이 밑줄(예 shrimp_crackers). 얜샷템은 연예인 이름 로마자를 앞에(예 choihwajung_grandpa_seaweed).
  - 끝에 날짜·시간(_1027_1508 같은 것)은 넣지 않는다(사장님 11-04). 이미 규칙에 맞는데 날짜·시간만 붙은 이름은 post 가 알아서 뗀다.
  - 번호 NN_ 은 도구가 그 폴더 다음 번호로 붙인다. 같은 이름 .txt 도 같이 바뀐다. `칼카피_`·채널명·`1차/v2` 는 넣지 않는다.
- 바꾼 뒤에는 새 이름으로 아래 준비·예약을 한다. 규칙 밖 이름 그대로면 post 가 건너뛴다. `moacco_…`(볼케이노)는 예외라 그대로 둔다.
- 이미 `예약\`·`완료\` 에 있는 영상 이름은 바꾸지 않는다(앞으로 올릴 것만).

## 영상 하나 준비 (prepare 의 각 영상)
드라이브 폴더 = {drive}\<folder>\<영상>
1. 장면 모음: 파이썬 subprocess 로 ffmpeg — 길이/12 간격 12장, 가로 200, 6x2 타일 한 장(jpg)을 {report}.d\ 에 만들고 Read 로 본다.
   - 오른쪽 위 '광고' 표시가 없으면 그 영상은 건너뛰고 보고에 적는다(배지 없는 영상은 올리지 않는다).
   - 화면 글자·자막으로 제품을 알아낸다. 확신이 없으면 2~3번을 건너뛰고 4번에서 `인포크: 없음` 으로 쓴다.
2. 쿠팡 후보: `cd "{shoplink}" && py tools/shoplink/run.py find "<검색어>"` (아무것도 안 만든다)
   - 영상 속 제품과 **같은 물건**인 후보가 있을 때만 3번으로. 비슷한 물건뿐이거나 없으면 3번을 건너뛰고 4번에서 `인포크: 없음` 으로 쓴다(사장님 11-01: 쿠팡 연결이 없어도 영상은 올린다. 비슷한 상품으로 억지로 잇지 않는다). 보고에 적는다.
3. 링크·인포크: `cd "{shoplink}" && py tools/shoplink/run.py make "<검색어>" --account <계획의 inpock> --match "<그 후보 이름 일부(유일하게)>" --name "<짧은 상품 이름>"`
   - `--account` = 계획에 적힌 그 폴더의 `inpock`(예: 995_2 얜샷템 = ystem). 출력의 `인포크: <계정> <블록 제목>` 과 `공개 페이지 실측: 있음` 을 확인한다. '없음'이거나 "로그인돼 있지 않다"면 그 계정은 건너뛰고 보고에 적는다.
4. 같은 이름 .txt 를 영상 옆에 UTF-8 로 쓴다:
   ```
   <제목 — 한국어, 숫자로 시작 금지, 영상 상단 문구를 살린 한 줄>

   <설명 2~3문장 — 영상에서 실제로 나온 내용만. 지어낸 사실·과장된 수치 금지>

   #쇼츠 #<태그> #<태그> #<태그> #<태그>
   인포크: <3번 출력의 블록 제목 그대로, 예: [14] 손 안 쓰는 외다리 목발 / 14. 먹는 숟가락>
   (쿠팡 상품이 없으면 이 줄을 `인포크: 없음` 으로)
   ```
   - 쿠팡 링크는 .txt 에 쓰지 않는다(쿠팡은 인포크에만). '프로필 링크 N번' 문장도 쓰지 않는다(buffer_post 가 채널 말투로 넣는다).

## 예약
- 준비가 끝난 계정마다: `py tools/buffer_post.py post --folder "<folder>"`  → 유튜브+틱톡이 오늘 빈 칸에 들어간다.
  관문(인포크 블록 실측·중복·칸 겹침)이 막으면 억지로 넘기지 말고 보고에 적는다.
