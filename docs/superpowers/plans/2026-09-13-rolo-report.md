# 로로 첫 보고 연결

**목표:** 실제 저장소 handoff 기록을 읽어 출처·수집시각·범위·미확인 상태가 명시된 Markdown 보고서를 생성하고 브라우저에서 내려받는다.

**범위:** AI 모델/음성/워커 지휘는 미연결. 고정된 보고 요청만 지원하는 연결 기반이다. 사용자 자연어를 임의 셸로 실행하지 않는다. 외관은 변경하지 않는다.

1. `tests/test_rolo.py`에서 실제 임시 기록/빈 기록/심볼릭 링크 제외 테스트를 먼저 실행한다.
2. `rolo.py`에서 명시적으로 설정된 저장소의 handoff/*.md를 수정시각순 최대 10건 읽는다. 파일당 앞 40줄만 인용하고 생략을 표시한다. 완료율·워커 수·실행 상태를 추정하지 않는다. 출력은 서버 측 고정 보고 폴더에 UUID 파일로 저장한다.
3. 기존 `app.py` 보안 미들웨어 안에 POST `/api/rolo/reports`, GET 다운로드를 추가한다. COMPANY_ROLO_ROOT 미설정이면 503. URL 입력 경로는 받지 않는다.
4. `static/rolo/`에서 고정 보고 요청 버튼 → 생성 결과 표시 → Markdown 다운로드. 오류는 숨기지 않는다. AI 미연결 고지.
5. 테스트 및 별도 시험 DB/localhost 8932에서 실제 보고 생성·화면·다운로드 대조. 트랙 기록/커밋, main 미배포.
