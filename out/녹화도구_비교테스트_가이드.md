## 1. 세 도구 모두 동일하게 찍을 30초 시나리오

**같은 걸 찍어야 비교가 됩니다.** 매번 이 순서로:

```
① 숏템메이커 → 레퍼런스 랭킹
② 카테고리 버튼 클릭   ← 3초 안에 2번 (Cursorful 자동줌 조건)
③ 영상 카드의 [대본 추출] 클릭   ← 3초 안에 2번
④ 대본 세그먼트 팝업 뜨는 것 보여주기   ★이 장면이 VSL 핵심 소재
⑤ 닫고 [담기]
```

### 공통 준비 (지난번 지적 3가지 반영)
- [ ] **브라우저 창 최대화** (해상도 확보 — 지난번 1496×1080밖에 안 나왔음)
- [ ] **탭·북마크바 숨기기** (지난번 탭 9개 그대로 찍힘 — 사생활 노출)
- [ ] **줌 깊이 낮추기** (지난번 좌측 사이드바가 잘려 맥락 소실)
- [ ] 저장 파일명 앞에 도구 이름 붙이기 → `focusee_test.mp4`, `canvid_test.mp4`

## 2. FocuSee 테스트

**다운로드**: https://focusee.imobie.com/ → [Get It Free] / [무료 다운로드]

1. 설치 후 실행 → **화면 녹화** 선택
2. 위 ①~⑤ 시나리오 30초
3. 정지하면 **자동으로 줌·커서 효과가 입혀진 상태**로 편집기가 열립니다
4. 확인할 것:
   - **3D 모션 효과** — 화면이 살짝 기울어지는 연출 (Cursorful엔 없음)
   - 줌 깊이·타이밍 조절
   - 배경 교체
5. **내보내기: 반드시 4K로** ← 무료 1편이 이 기회입니다
6. `focusee_test.mp4`로 **바탕화면 저장**

> ⚠️ 무료는 **고화질 내보내기 1편**입니다. 아껴 쓰십시오 — 편집을 다 끝내고 마지막에 내보내세요.
> ⚠️ 워터마크가 붙는지 내보내기 화면에서 확인해 주십시오. (붙으면 알려주세요)

## 3. Canvid 테스트

**다운로드**: https://www.canvid.com/

1. 설치 후 위 시나리오 30초 녹화
2. **내보내기는 무료로 안 됩니다.** 대신 **편집기 화면에서 판단**:
   - 자동 줌이 자연스러운가
   - 커서 움직임이 다듬어졌는가
   - 자막(캡션) 자동 생성이 되는가 ← Canvid 강점
3. **편집기 화면을 스크린샷 3~4장** 찍어서 저장
   - 전체 뷰 / 줌인된 순간 / 타임라인 / 내보내기 설정 화면

> Canvid는 "결과물"이 아니라 "도구 화면"으로 평가할 수밖에 없습니다.

## 4. 결과 제출

바탕화면에 이렇게 모아주십시오:

```
focusee_test.mp4          ← 4K
canvid_편집기_1.png ~ 4.png
(cursorful은 이미 있음: cursorful-video-1784979179235.mp4)
```

**제가 할 것**: 프레임 추출 → 확대 비교 → 줌 품질·화질·커서 처리 판정 → **어느 걸 사야 하는지 근거와 함께 보고**

## 5. 판정 기준 (제가 볼 것)

| 항목 | 왜 중요한가 |
|---|---|
| **4K 실효 화질** | AE에서 3D로 기울이고 확대할 때 글자가 버티는가 |
| 자동 줌의 자연스러움 | 어지럽지 않고 시선이 따라가는가 |
| 커서 스무딩 | 손 떨림이 제거됐는가 |
| 맥락 유지 | 줌해도 화면이 잘려나가지 않는가 |
| 배경·프레임 완성도 | AE 목업 템플릿을 안 사도 되는가 |
