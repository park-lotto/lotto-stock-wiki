숏템메이커 런칭 VSL — 일레븐랩스 v3 내레이션 v2 (감정톤 설계판)
======================================================================
v1 대비 바뀐 것
· 씬마다 **감정 곡선**을 설계해 태그를 '아무 데나'가 아니라 **전환점**에만 박았다.
· 태그 수는 v1 원칙(씬당 2~4개)을 지켰다 — 많이 넣으면 목소리가 튄다(사장님 실측 메모).
· 태그로 못 만드는 감정은 **문장 길이·끊기·<break>**로 만들었다. 이게 실제로 더 잘 먹는다:
  짧은 문장 = 단호 / 긴 문장 = 설명 / … = 망설임·뜸 / <break> = 무게.
· 낭독 시간은 v1과 거의 같다(대사량 유지). <break> 합계 약 +20초.

사용법
· 모델 = Eleven v3 / 안정성 = 견고한(Robust) / 음성 = 하나로 통일
· **▼▼▼ ~ ▲▲▲ 사이만 복사**해서 붙여넣는다. 그 위의 ※줄은 지시문이니 붙여넣지 말 것.
· 씬 블록은 통째로 한 번에 생성(문장 쪼개면 톤이 튄다).
· 느리면 뽑은 뒤 1.1~1.15배 가속. 태그를 지우기보다 가속이 안전하다.

⚠️ 미완 2곳 — 사장님 결정이 있어야 채울 수 있다(없는 숫자를 지어 넣지 않았다)
   · [S8] 오퍼: 가격 / 한정 인원 수 / 마감일 / 환불 보장 → 지금은 자리표시만
   · [S10] CTA: 현재 6초뿐. 목적지(가입 페이지? 카톡?)가 정해지면 40~60초로 확장 필요

  [impressed] 감탄·인정 / [excited] 들뜸 / [determined] 결의 / [whispers] 귓속말

감정 설계 원칙 (왜 이렇게 배치했나)
  1. 앞을 담백하게 → 뒤가 산다. S5-7 [amazed]가 정점이므로 S5-2~6은 일부러 낮게 깔았다.
  2. 페인 구간(S2)은 세게 읽으면 안 된다. 시청자 자기 얘기로 느껴야 하는 구간이다.
  3. 밀어내는 화법(S6)은 낮고 차분하게. 톤이 세면 시비로 들린다.
  4. [sincere]는 두 번만 썼다(S5-끝, S7). 남발하면 진심이 연기로 들린다.
  5. 태그가 아니라 **끊기**로 만드는 감정이 더 자연스럽다 — 짧은 문장·<break>·… 를 먼저 쓴다.
