# 숏템메이커 UI 전면 리뉴얼 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 영상 제작소를 "🛠 숏템메이커"로 리브랜딩하고, 1단계(영상/대본)를 AI PICK 원클릭 구조로 갈아엎으며, 매칭을 독립 "화면 붙이기" 단계로 분리한 네온 작업대형 UI로 재구성한다.

**Architecture:** 백엔드 `/api/produce/*` 시그니처는 유지(프론트 재구성이 본체). 색토큰·오브·카드·CTA·오로라 배경을 공통 `static/theme.css`로 추출해 produce.html에 먼저 적용. AI PICK 채점·구조전시는 기존 `backbone.pick_backbone`/`score_backbones` + `structure_analyze.analyze_structure`를 감싼 신규 조회 엔드포인트 하나로 사전분석 결과를 프론트에 공급한다.

**Tech Stack:** FastAPI(app.py) · 순수 HTML/CSS/JS(빌드툴 없음, produce.html 인라인 + theme.css) · pytest(HTML grep / `node --check` / 마커 슬라이스+node 실행) · 목업 `docs/superpowers/specs/assets-숏템메이커목업/`가 마크업 정본.

## Global Constraints

이 절은 **모든 태스크에 암묵적으로 포함**된다.

- **트랙 격리**: 구현은 `py tools/track.py start 숏템메이커리뉴얼` 후 `.tracks/숏템메이커리뉴얼/...` 절대경로에서만. main 폴더의 코드는 하나도 건드리지 말 것(흡수 방지). git은 전부 `git -C .tracks/숏템메이커리뉴얼`.
- **자막제거 동시편집 = NO-TOUCH**: `produce.html`의 `data-step=1`(자막제거) 패널과 그 JS(`#subToggle`, `onSubToggle`, `startCleanPreview`, `#cleanPreview`, `.hero` 자막제거 히어로, `/api/produce/mix/clean*`)는 **다른 세션 소유**. 읽기만 하고 수정 금지. 재구성으로 인한 단계 재인덱싱은 자막제거 패널을 물리적으로 건드리지 않는 방식으로만(아래 Task 2 참조).
- **JS 문법 깨지면 제작소가 안 열린다**(전례: 2026-07-19 SyntaxError로 제작소 먹통). produce.html을 편집한 모든 태스크의 마지막 검증 단계에 `node --check`(추출 스크립트)를 포함한다.
- **마커 주석 보존**: 기존 `tests/*_js.py`는 함수 시작문자열 + `// ── …끝 ──` 종료주석으로 JS 블록을 슬라이스한다. 함수를 옮기거나 지울 때 해당 마커 쌍을 함께 옮기거나, 테스트도 같은 커밋에서 갱신.
- **카피 규칙**: "복사가 아니에요" · "100%" 문구 **금지**. 대본 강조줄은 정확히 `✨ 이 뼈대로 완전 새로운 대본을 만듭니다`.
- **비주얼 토큰(단일소스 theme.css)**: 배경 `--bg:#070b14` · 민트 강조 `--mint:#3ee0bf` · 퍼플 오로라 `--aurora:#8c6ef0` · 완료 금색 `--gold:#facc6b`. 폰트 두껍게(≥700)·크게(가독 우선).
- **API 불변**: 새 백엔드는 조회 엔드포인트 1개(`GET /api/produce/aipick`) 추가만 허용. 기존 경로 시그니처 변경 금지.
- **그라운딩 필수**(fablize): produce.html을 바꾼 태스크는 정적 검사로 끝내지 말고 **실제 브라우저에서 열어 관측**(빈 상태 → 재료 도착 → 단계 전환)하고, 관측이 드러낸 것을 고친 뒤 재관측. 로컬 서버 대신 서버 대시보드(shoppingshorts.duckdns.org)로 확인하거나 `assets-숏템메이커목업/*.html`을 나란히 대조.

```python
"""AI PICK 사전분석 조립 — 기존 채점/구조분석을 하나의 프론트 계약으로 묶는다."""
from backbone import pick_backbone, score_backbones
from structure_analyze import analyze_structure

_SEG_COLORS = {"훅":"#facc6b","문제제기":"#7db8f5","주변인물":"#c99af5","결과":"#7df5db","CTA":"#f5a97d"}

def _by_id(sources):
    return {str(s.get("video_id")): s for s in sources}

def build_aipick(sources, meta, forced=None):
    if not sources:
        return {"pick_id": None, "pick_index": -1, "tiles": {}, "structure": {}, "candidates": []}
    meta = meta or {}
    scored = score_backbones(sources, meta)                 # [{video_id,coverage,engagement,score}] score desc
    ranks = {r["video_id"]: i+1 for i, r in enumerate(scored)}
    pick_id = pick_backbone(sources, meta, forced=forced)   # forced(⭐메인) 우선
    idx = next((i for i,s in enumerate(sources) if str(s.get("video_id"))==str(pick_id)), 0)
    pick = sources[idx]
    m = meta.get(str(pick_id), {})
    views, followers = pick.get("views"), pick.get("followers")
    comments, avg = pick.get("comments", m.get("comments")), m.get("avg_comments")
    tiles = {
        "views": views,
        "views_x_followers": round(views/followers, 1) if views and followers else None,
        "comments": comments,
        "comments_x_avg": round(comments/avg, 1) if comments and avg else None,
        "engagement_rank": ranks.get(str(pick_id), 1),
        "seconds": pick.get("seconds"),
    }
    struct_raw = analyze_structure(pick.get("text","")) or {}
    structure = {}
    if struct_raw:
        segs = struct_raw.get("segments") or []
        structure = {
            "segments": [{"label": s.get("label"), "pct": s.get("pct"),
                          "color": _SEG_COLORS.get(s.get("label"), "#8ea2ff")} for s in segs],
            "hook_type": struct_raw.get("hook_type",""),
            "devices": struct_raw.get("devices", []),
        }
    return {"pick_id": pick_id, "pick_index": idx, "tiles": tiles,
            "structure": structure, "candidates": [{"video_id": r["video_id"], "score": r["score"]} for r in scored]}
```
