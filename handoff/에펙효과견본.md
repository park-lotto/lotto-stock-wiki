## 실측으로 알게 된 함정
- `AfterFX.exe -r` 에 한글 경로를 주면 조용히 안 돈다 → 영문 폴더로 복사(`run_jsx.py`).
- 앱 안 `renderQueue.render()` 는 파일을 안 냈다(2초 만에 끝, 출력 0개) → `aerender.exe -project` 로 뽑는다.
- ★렌더하면 에펙 디스크 캐시가 `C:\Users\CH\AppData\Local\Temp\Adobe` 에 쌓인다. 34개 뽑는 동안 19.27GB → C 여유 0GB 사고. `render.py` 가 렌더 뒤 이번에 생긴 `.aecache` 를 지운다.
- 도형 레이어에 흐림 효과를 걸면 도형 테두리 상자에서 네모로 잘린다 → 큰 단색판 + 타원 마스크 번짐으로.
- 이 PC 에펙은 한글판 — 속성은 matchName·순번으로 잡는다. MCP(`AfterEffectsMCP`)는 정해진 스크립트 12개뿐이라 견본 제작엔 안 썼다.
