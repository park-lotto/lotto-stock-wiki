# 화면 지침

기준 화면은 `sample/` 의 GDP 착시 편이다.

## 고정 배치

| 요소 | 자리 |
|---|---|
| 채널명 | 위 한쪽, 빛 점 + 글자 (`logo_side`) |
| 챕터 표지 | 반대쪽 위, 자간 넓은 작은 글자 |
| 자막 | 아래 그늘 위 큰 글자(띠 없음), 숫자만 강조색 |
| 출처·AI 생성 | 오른쪽 위 표시줄 아래 |
| 짧은 문구 태그 | 왼쪽 아래 |
| 경고 패 | 오른쪽 위 |
| 큰 숫자 | 화면 가운데, 입자가 모이고 고리가 번진다 |

## 샷 종류

`add(시작문장, 끝문장, "종류", ...)` 로 쓴다. 문장 1~2개마다 샷 하나, 평균 6초 안팎이다.

| 종류 | 언제 |
|---|---|
| `stock` | 기본. 실사 영상(`q`) + 없을 때 그릴 장면(`ai`) |
| `ai` | 실사로 구할 수 없는 장면 |
| `bar` | 숫자 비교. `reveal` 로 말하는 순간에 맞춘다 |
| `bignum` | 그 챕터의 핵심 숫자 하나 |
| `typo` | 결정적인 한 문장. 편당 12~15개 |
| `vs` | 두 개념 대비 |
| `labels` | 흐름 요약 |
| `quote` | 기관·기사 내용 요약 카드. 원문을 지어내지 않는다 |

- `img=번호` 는 png 가 있는 칸만 가리킨다. 실사 칸을 다시 쓰려면 `clip=번호`.
- 숫자는 사실기록에 있는 것만, 출처는 `src` 에 매체와 날짜로 쓴다.

## 실사 고르기

- 검색어가 맞아도 장면은 안 맞는 일이 많다. GDP 편은 40개 중 22개를 뺐다.
- 한국 이야기에 외국 얼굴이 정면으로 나오면 뺀다.
- 만화, 화면 조정 패턴, 합성 배경은 뺀다.
- 상표가 크게 보이면 뺀다. 작게 지나가는 간판은 수익화 전에 사람이 판단한다.
- 방송사 공식 영상은 쓰지 않는다.

## 그림

- 다큐 사진 톤, 자연광, 글자·로고 없음.
- 한국 장면은 프롬프트에 `Korean, East Asian face, Seoul` 을 넣는다.
- 인물이 특정 실존 인물처럼 보이면 다시 그린다.
