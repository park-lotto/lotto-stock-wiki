## ★함정 5개 (다음 세션이 밟지 않게)

### ① 렌즈를 prefix로 열면 과금이 샌다
렌즈 엔드포인트 **9개 중 과금검사가 있는 건 2개뿐**(`/api/lens/search`, `/api/lens/trace_url`).
나머지 7개는 검사가 없는데 그중 **`/api/lens/kw/search`는 틱톡이 Apify 유료**,
`/api/lens/cn/search`도 Apify 폴백이 있다. → `/api/lens/` prefix로 열었으면 **상한 없이 샜다.**

### ② 담기의 유료 부작용은 인스타 크롤만이 아니다
`api_mix_basket_toggle`은 담길 때 **둘**을 돌린다: `_enrich_grab`(인스타 크롤 — 429 나면
**본 수집이 죽는다**, 2026-07-30 실사고)와 **`_enqueue_prewarm`(Gemini 추출 = 실과금)**.
설계 땐 크롤만 봤는데 예열이 더 비쌌다. → `if access_level(cid) == "full":`로 **둘 다** 감쌌다.
담기 자체(`mix_basket_toggle`)는 게이트 **밖**이라 무료 등급도 정상 저장된다.

### ③ 라우트만 만들면 도달조차 못 한다
미들웨어가 라우트보다 **먼저** 돈다. `/produce`를 화이트리스트에 안 넣으면 새 라우트가
불리기 전에 402가 나간다. **HTML 2개만** 열었다(`/api/produce/*`는 하나도 안 열었다).
`/produce.html`도 함께 등록해야 StaticFiles 마운트(`app.py` 맨 끝)로 안 뚫린다.

### ④ ★버튼을 하나씩 잠그면 반드시 샌다 — 스크립트를 통째로 걷어내라
원본 `produce.html`은 `onclick` **221개** · `fetch` **122개**다. 하나씩 잠그는 방식은
**빠뜨린 하나가 곧 과금**이다. 그래서 미리보기는 `<script>`를 **전부 제거**(외부 src 포함)해
**부를 코드 자체를 없앴다**. 생성기가 매번 자가검증한다(script 1개·fetch/onclick/api 0건·패널 9개).

### ⑤ ★판정 기준이 낡으면 게이트가 막는다 (실제로 막혔다, 라이브는 무사)
미리보기를 진짜 화면의 **복사본**으로 만든 순간, `mixScriptPick` 문자열이 양쪽에 다 들어가
"이건 소개 페이지다"라는 판정이 깨졌다. → 판정을 **성질**로 바꿨다:
미리보기=배너 있고 `<script>` 1개 / 유료=배너 없고 `<script>` 여러 개.
**`finish`는 exit 0이어도 병합 안 됐을 수 있다** — 반드시 `git branch -r --contains`로 판정하라
(이번에도 exit 0인데 실제로는 게이트가 막았다).

## 2026-08-20 (2차 세션) — 체험 계정이 402로 막힌 진짜 이유

사장님 제보: "무료체험을 부여했는데 연동이 안 되는 것 같다" / "관리자에서 변경해도 적용 안 됨".

**등급은 처음부터 정상이었다.** 라이브 서버에서 직접 실행한 실측:
```
cid 5  level= full  balance= 0  should_charge_serp= True  cost= 10
cid 9  level= full  balance= 0  should_charge_serp= True  cost= 10
```
`plan=pro`, `full_access_until`=8/27 → `access_level`=full. 미들웨어는 통과한다.

**막은 건 두 번째 관문인 포인트 차감이다.** 렌즈 1회 = 내부값 10(0.1P)인데 잔액 0
→ `_charge_or_402`(app.py:5667)가 402. 개인 SerpApi 키도 없어 `should_charge=True`.

### 뿌리 2개
1. **포인트를 주는 경로가 없었다** — `points.add()` 호출부가 app.py에 0건, admin UI에도 없음.
   '결제추가'(`/api/admin/payment`)는 **기간 연장**일 뿐이다. 즉 체험을 부여해도
   포인트는 영원히 0 → 유료 op 전부 402. **등급만 열고 연료를 안 준 구조.**
2. **402 모달이 사유를 안 갈랐다** — `sidebar.js`의 전역 fetch 래퍼가 402면 무조건
   "무료 체험이 끝났어요"를 띄운다. 실제 서버 메시지는 `포인트가 부족합니다 (필요 10P, 보유 0P)`.
   → "체험 부여가 연동이 안 됐다"는 오진이 여기서 나왔다.

### 고친 것 (main 병합 `901e3ed58`, `git branch -r --contains`로 확인)
- `POST /api/admin/points` — 관리자 전용, 화면 단위 P(음수=회수). 내부 ×100 변환.
- 고객 목록에 **포인트 잔액 열**(0이면 빨강) + 행마다 **'포인트' 버튼**(기본 1000P 프롬프트).
- 402 모달 사유 분리 — 메시지에 '포인트'가 있으면 "포인트가 부족해요" + 서버 문구 그대로.
