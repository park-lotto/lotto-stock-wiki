# 유니버스 진입 검토본

정적 서버의 `/universe/`. 메이커스랩 외부 → 숏템메이커 건물 클릭 → 입장 → 1층 3구역/팀장/워커 선택 → 상단 메이커스랩 버튼으로 복귀.

기획 8석, 개발 4석, 독립 검수 4석은 atlas-data의 고정 예시다. 실운영·명령·중단·터미널 연결 없음. 스탁브레인은 외관만, 확장 부지는 배치 원칙 설명이며 자동 증축 기능은 아니다. 2F/B1 미구현. 현재 고밀도 조형을 수백 개로 단순 복제하면 안 되며 LOD/인스턴싱 검증이 필요하다.

빌드: company_ops/scene에서 `npm run build:universe`.
브라우저 검증: 트랙 루트에서 `node company_ops/tests/universe.cjs` (127.0.0.1:8931 정적 서버 필요).
Three.js MIT 고지는 번들에 포함. 기존 `/studio/`, `/atlas/` 보존.
