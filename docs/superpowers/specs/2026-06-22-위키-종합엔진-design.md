# 위키 종합엔진 설계서 (Wiki Synthesis Engine)

> 작성: 2026-06-22 | 상태: 설계 확정 대기 (사용자 검토 중)
> 목표: 정보의 홍수를 **질문하면 답이 나오는 고품질 도서관**으로 자동 증류

---

## 0. 한 줄 정의

매일 들어오는 원자(news·report·telegram·youtube·blog 추출본)를 **종목 페이지 골드 포맷에 자동으로 녹여 넣는 엔진.** 출처는 실존 파일만, 주장은 검증등급을 달고, 모르면 "없다"고 답한다.

---

## 1. 왜 만드나 (문제)

현재 파이프라인은 `크롤링 → Gemini추출 → DB → wiki_update(파이썬 덤프) → 섹터파일`.
- **병목**: `wiki_update.py`에 LLM 호출 0개. 날짜+이모지 붙여 append하는 멍청한 덤프.
- **증거**: 섹터 파일에 같은 리포트가 06-21/06-19 중복, 잘린 인용("…"), 종합·검증 전무.
- **결과**: 품질을 만드는 지능(Claude)이 자동 루프 밖에 있음. 골드 종목페이지(SK하이닉스 등 176개)는 06-09에서 방치.

→ **덤프 스크립트 자리에 지능(Sonnet 종합)을 앉힌다.** 토대(종목 215페이지·원자DB·5소스·딥리서치)는 다 살린다.

## 2. 성공 기준 = 질문 7종 테스트 (합격/불합격 판정)

반도체에서 아래 7개 질문에 **추적가능하고 검증된 답**이 나오면 합격.

| # | 질문 유형 | 예시 | 답하는 페이지 구조 |
|---|----------|------|-----------------|
| 1 | 현재 상태 | "SK하이닉스 지금 어때?" | 종합 스토리 |
| 2 | 히스토리 | "TP 어떻게 변해왔어?" | 컨센서스·리포트논거 롤링표 |
| 3 | 근거·검증 | "최태원 머스크 회동 근거가?" | 출처 + 검증등급 |
| 4 | 횡단 테마 | "HBM 밸류체인 대장은?" | 테마 롤업 페이지 |
| 5 | 횡단 섹터 | "반도체 vs 2차전지 누가 세?" | 섹터 인덱스 |
| 6 | 맥락 주입 | "오늘 이 단독뉴스 무슨 맥락?" | ChromaDB 검색 → 종목 연결 |
| 7 | 충돌 | "하나 175만 vs 전진 320만 왜?" | 충돌·모순 섹션 |

**8번째 메타 규칙(정직한 공백)**: 위키에 없는 걸 물으면 **"위키에 없음 — 자료 추가 필요"**라고 답해야 한다. 지어내면 즉시 불합격.

## 3. 아키텍처

> **실데이터 검증(§11)으로 2개 구멍을 발견해 반영함**: ① 원자 60%가 종목 미연결 → 섹터 종합 경로 추가 ② 추출이 출처매체·불확실성을 버림 → 추출 단계 메타 보존.

```
[1. 추출+메타]  Gemini 추출 (구멍2 해결)
    · 기존: content만 추출 → 출처매체·불확실성 소실
    · 신규 필수: [source_pub(보도매체) + certainty(사실/관측/전망/단독설)] 동시 추출
    ↓
[2. 입력QC]  원자 정제 + 라우팅 분기 (구멍1 해결)
    · 중복제거(같은 사건 멀티원자 통합)·깨진것폐기(38만→380만 차단)·종목명정규화
    · asset_level로 분기: stock → 종목경로 / sector·market·theme → 섹터경로
    ↓
[3. 종합엔진]  차분-병합 (Sonnet) — 2개 타깃
    · stock_synth (종목레벨 ~40%): (현재 종목페이지 + 신규원자) → 바뀐 섹션만 재작성
    · sector_synth (섹터/시장레벨 ~60%): (섹터 국면섹션 + 신규원자) → 시장국면·테마 종합
    · 둘 다 기존 골드 보존, 신규만 녹임
    ↓
[4. 검증게이트]  하이브리드 (certainty 활용)
    · 모든 주장 = 실존 출처파일 + 검증등급. certainty가 등급 기본값 결정
      (사실→검증완료 후보 / 관측·전망→미검증 / 단독설→설)
    · report(A) → 자동  · 파트너십·납품·고위험 → WebSearch 통과 시만 🔴 승격
    · 충돌 → 충돌섹션 양쪽 보존(덮어쓰기 금지)  · 저신뢰·미검증 → staging/ → 사람/Opus 승인
    ↓
[5. 롤업]  종목+섹터 → 인덱스·테마
    · 섹터 인덱스 = 종목 요약 + sector_synth 국면 결합
    · 테마 페이지 = HBM·유리기판 등 횡단 묶음
    ↓
[6. 쿼리]  ChromaDB 벡터 + 구조화 페이지
    · 7종 질문 → 해당 섹션 검색·결합  · 없으면 "위키에 없음" 정직 응답
```

## 4. 컴포넌트 (각각 단일 책임)

### 4.0 추출 메타 (`atomizer` 보강) — 구멍2 해결
- **무엇**: Gemini 추출 시 검증 메타를 함께 뽑아 원자 스키마에 저장.
- **신규 필드**: `source_pub`(보도매체/리포트발행사, 예 "디지털데일리 단독"), `certainty`(사실/관측/전망/단독설).
- **이유**: 검증은 *추출 단계에서 결정*된다. 여기서 출처매체·불확실성을 버리면 다운스트림에서 복구 불가(검증 토대 소실). 실증: 최태원-머스크 텔레 원본의 "디지털데일리 [단독]·대외비"가 추출 원자에서 통째로 사라짐.
- **기존 원자 처리**: 메타 없는 과거 원자는 `certainty=불명` → verify_gate가 자동 승격 금지(미검증 취급).

### 4.1 입력QC (`atom_qc`)
- **무엇**: 종합 직전 원자 묶음을 정제 + 경로 분기.
- **인터페이스**: `clean_and_route(atoms) -> {stock: [...], sector: [...]}`.
- **의존**: 기존 `stock_resolve`(종목명), DB.
- **정제 규칙**: content 동일/유사 → 1개 병합(출처 다중 보존). 숫자 깨짐 휴리스틱(단위 모순) → 격리 로그.
- **라우팅 규칙(구멍1 해결)**: `asset_level=stock` & 실존 종목명 → 종목경로. `sector/market/theme` 또는 generic asset("반도체"·"MLCC") → 섹터경로. 실증: 반도체 원자 60%가 후자 → 종목페이지로 못 가므로 섹터 종합 필수.

### 4.2 종목 종합 (`stock_synth`)
- **무엇**: 종목 1개의 페이지를 신규 원자로 갱신.
- **인터페이스**: `synth(page_path, new_atoms) -> updated_markdown` (Sonnet 호출).
- **의존**: 골드 포맷 스펙(§5), 검증게이트.
- **원칙**: 섹션별 갱신 규칙 준수 — 이벤트표(7일 롤링), 컨센서스(증권사당 1행 덮어쓰기), 리포트논거(30일 롤링·WHY보존), 종합스토리(최신 단락 추가). **출처는 입력 원자의 실존 raw_file만 인용. 합치거나 날조 금지.**

### 4.2b 섹터 종합 (`sector_synth`) — 구멍1 해결
- **무엇**: 종목 미연결 원자(60%)를 섹터 페이지의 "시장 국면·테마 코멘트" 섹션에 종합.
- **인터페이스**: `synth_sector(sector_page, sector_atoms) -> updated_markdown` (Sonnet 호출, stock_synth와 동일 방식).
- **이유**: 롤업을 *종목 페이지 집계*로만 두면 generic "반도체"·시장레벨 원자 84개가 어디로도 안 감. 섹터 페이지가 이들을 직접 종합해야 ⑤섹터비교·⑥맥락주입 질문이 답된다.

### 4.3 검증게이트 (`verify_gate`)
- **무엇**: 종합 결과를 신뢰도로 분류해 자동/스테이징 결정.
- **인터페이스**: `gate(claim) -> {grade, route}` — route ∈ {auto, staging}, grade ∈ {검증완료, 미검증, 설}.
- **의존**: 소스 신뢰도(§6), WebSearch(고위험 주장).
- **규칙**: report A=auto. 파트너십/납품/M&A/실적 주장 = WebSearch 확인. blog/youtube 해석 = staging. 충돌 = 보존.

### 4.4 롤업 (`rollup`)
- **무엇**: 종목 페이지 + 섹터 국면 → 섹터 인덱스·테마 페이지 생성.
- **인터페이스**: `roll(sector) -> index_md, theme_mds`.
- **의존**: 종목 페이지 + `sector_synth` 국면 섹션(§4.2b). 섹터 멤버십 = `반도체/stock/` 폴더(1단계) / Excel 매핑(2단계).
- **주의**: 인덱스 = 종목 요약 + 섹터국면 *둘 다* 결합 (종목 집계만 하면 60% 누락).

### 4.5 쿼리 (`wiki_query`)
- **무엇**: 질문 → 페이지 검색·결합 답변.
- **인터페이스**: `ask(question) -> answer + sources` 또는 "위키에 없음".
- **의존**: ChromaDB(기존), 구조화 페이지.
- **범위 주의**: 1단계는 *새 쿼리 도구를 짓지 않는다.* 기존 경로(ChromaDB 검색 + 세션에서 Claude가 구조화 페이지 읽기)로 7종 질문을 검증한다. 즉 1단계 쿼리 테스트는 **쓰기 품질**을 검증하는 수단이지 별도 빌드 타깃이 아니다. 전용 쿼리 도구·대시보드 연동은 2단계.

## 5. 골드 포맷 스펙 (종목 페이지 = SK하이닉스 기준)

합격 페이지가 반드시 갖출 섹션 (이미 176개가 보유):
1. **탑픽 스코어** (선택) — 빈집/수출/판가 등 (수치는 태린이 파일 연동)
2. **종합 스토리** — 최신 단락 누적, 각 항목 출처+날짜
3. **최신 이벤트** — 7일 롤링, 표(날짜·내용·출처·신호)
4. **일정** — 촉매·정기 이벤트
5. **증권사 컨센서스** — 증권사당 1행 덮어쓰기 (최신 TP·의견·직전TP·방향)
6. **리포트 핵심 논거** — 30일 롤링, 증권사당 최신 1건, WHY 보존
7. **뉴스 반응 패턴** — 어떤 뉴스에 얼마나 움직이나 (저빈도 갱신)
8. **미국 커플링** — 페어 종목·반응 강도·브리핑 로직
9. **충돌·모순** — 상반 정보 양쪽 보존
10. **관련 페이지** — 섹터/테마 링크

**강제 규칙**: 모든 사실 행에 **실존 raw 파일명 + 날짜**. 검증등급(`⚠️미검증`/`(설)`) 명시.

## 9. 범위 밖 (명시)

- **빈집/주도 강도 계산** = 태린이 파일(오실레이터) 담당. 위키 엔진은 그 수치를 *연동*만.

- **딥리서치(Q1~Q10)** = 분기/반기 정적 토대. 유지하되 일상 엔진과 별개 레이어.

## 11. 실데이터 검증 결과 → 해결 반영 (2026-06-22)

종이 스펙을 신뢰하지 않고 실제 볼륨·요약을 검증한 결과 2개 구멍 발견. **둘 다 해결책을 위 설계에 반영함.**

### 구멍1 — 볼륨: 원자 60%가 종목 미연결
- **발견**: 반도체 원자 141개 중 84개(60%)가 generic "반도체"·시장레벨 → 종목 페이지로 못 감. 종목별 집중도는 최대 20개(SK하이닉스)로 차분병합엔 무리 없음.
- **해결**: `atom_qc`가 asset_level로 분기(§4.1), `sector_synth`가 섹터레벨 60%를 섹터 페이지 국면섹션에 직접 종합(§4.2b). 롤업은 종목+섹터국면 결합(§4.4).

### 구멍2 — 요약: 추출이 검증 메타를 버림
- **발견**: 텔레 원본 "디지털데일리 [단독] 최태원-머스크 회동(대외비)" → 추출 원자에서 **출처매체·불확실성 통째 소실**. 요지는 잡지만 "단독설"이 평서문 "예정"으로 둔갑. (Claude가 수동으로 ⚠️미검증 달아야 했던 근본 원인.)
- **해결**: 추출 단계에서 `source_pub`+`certainty` 동시 추출(§4.0). verify_gate가 certainty로 등급 기본값 결정(§4.3). 메타 없는 과거 원자는 자동승격 금지.

### 검증 종료 선언
이 2개가 볼륨·요약의 핵심 리스크였고 둘 다 해결 반영됨. **추가 검증 루프 없이 구현으로 진행한다.** (구현 중 발견되는 건 그때 수정 — 무한 사전검증 금지.)
