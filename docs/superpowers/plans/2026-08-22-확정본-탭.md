# 확정본 탭 — 확정 영상을 장면편집 안 재생 자리에서 보기

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development 또는 executing-plans.

**Goal:** 🎬확정을 누르면 **왼쪽에 새 칸이 생기지 말고**, 장면 편집 안에서 이미 재생하던 그 자리에 [가조립 | 확정본] 탭이 생겨 거기서 보인다.

**Architecture:** 확정 결과 mp4는 지금 부모(produce.html)의 `#mixPreview`에 `<video>`로 그려진다. 이걸 iframe(scene_lab) 안 `#vidbox` 옆 **확정본 패널**로 옮긴다. 부모→iframe은 **같은 도메인이라 `contentWindow.함수()` 직접 호출**이 이미 쓰이고 있다(`produce.html:6963` `w.makeTts()`). postMessage는 2026-08-15에 조용히 실패해 버린 경로다 — 쓰지 마라. 부모 좌측 레일(`#mixPreviewRail`)은 통째로 감춘다.

**Tech Stack:** 바닐라 JS (produce.html / scene_lab.html), pytest + node JS 하네스(`shopping_shorts/tests/js_harness.py`)
