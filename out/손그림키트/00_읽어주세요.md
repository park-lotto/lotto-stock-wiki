# 손그림 키트 (3편 손그림 모션 — 2026-11-04 TheRose PC에서 옮김)

3편(숏클 1편 롱폼)의 손그림 장면은 TheRose PC `숏템자료\모션그래픽엔진`에서만 만들 수 있었다. 그걸 다른 PC에서도 쓰도록 여기 모았다.

## 어디에 뭐가 있나
| 위치 | 내용 |
|---|---|
| **git** `out/손그림키트/` (이 폴더) | 코드·장면 대본(scene.js)·템플릿·글꼴·주인공 그림(hero png)·규칙 문서. **영상(mp4)과 주인공 초안 그림은 뺐다** |
| **드라이브** `내 드라이브\손그림키트_3편\` | 위 전부 + 장면별 완성 영상(out.mp4)·주인공 초안 그림(_hero_draft) — 537MB, 1,490개 |

## 폴더
- `INK_스타일규칙.md` — 고급판 손그림 규칙(종이 바탕·펜 획 순서 그리기·색 한 겹·한 글자씩 손글씨). **먼저 읽는다**
- `3편_손그림_고급판_INK_hq/` — 3편에 실제로 쓴 고급판. 장면 P1~P10·Q1~Q4
  - `P1/scene.js` = 그 장면 그림·움직임 / `P1/template/` = 바로 렌더되는 완성 틀
  - `_lib_p/hq.js`·`_lib/ink.js`·`hero.js` = 펜 그리기 엔진 / `_assets/` = 소품 그림 / `_hero_draft/` = 주인공 만들기(gen_hero.py, SHOTLIST.md)
  - `build.py`(P1~P5), `_lib_p/build.py`(고급판) = scene.js → template 다시 만들기
- `3편_손그림_초판_A_ink_question/`, `3편_손그림_초판_N_hours_pain/` — 초판(사장님: "이야기 풀 때 좋다, 더 고퀄로")
- `프리셋_ink_explainer/` — 원작 프리셋(혼자스 스타일). 선화 → `tools/trace.py` → 펜 획

## 렌더
```
cd 3편_손그림_고급판_INK_hq/P1
npx -y hyperframes@0.8.105 render template --fps 30 -o out.mp4
```
11-04 확인: 이 키트의 P1 을 다른 폴더에 복사해 렌더 → 12.0초, 원본 3편 P1 과 SSIM 1.000(같은 영상).

## 4회차에 쓰는 법
4회차 `out/유튜브4회차/작업/build2.py` 의 `PAGES`(지금은 코드로 그린 초안)를 이 고급판 방식으로 교체한다.
새 장면 = P 폴더 하나 복사 → `scene.js` 를 그 문장에 맞게 고침 → 빌드 → 렌더 → 1초 간격 시트로 확인.
