# 쿠팡파트너스·인포크 연결

## 2026-07-28 (회사PC) — 승인 전 수동 흐름 1차 구현, 미병합

### 결론부터
- 파트너스 오픈API는 **최종 승인된 회원만** 발급. 최종 승인은 **실제 판매 실적**이 나야 넘어간다
  (자료마다 "판매금액 15만원" 등 — 현재 기준은 파트너스 대시보드에서 직접 확인 필요).
  키 유효기간 **180일**이라 승인 후에도 만료 관리가 따로 필요하다.
  → **지금은 자동 상품검색·딥링크 생성을 못 한다. 수동 흐름으로 먼저 붙였다.**
- **쿠팡 링크는 영상 픽셀에 안 들어간다.** 그래서 "썸네일 다음"에 단계를 새로 만들지 않았다.
  상품 *확정*만 앞단(매칭 검토)에서 하고, *링크*는 7단계 SEO 설명란·8단계 인포크 등록에서 꺼내 쓴다.
- 인포크링크(링크인바이오)가 최종 목적지 — 영상 설명란엔 인포크 프로필 링크 하나만 넣고
  상품은 인포크 안에서 관리하는 구조.

### 함정 (다음 사람이 밟지 말 것)
- ⚠️ `#mixReview`는 **접힌 `<details>` 안**이다. 여기에 UI를 넣으면 묻혀서 아무도 못 본다
  (이번에 한 번 밟았다 → `#coupangSlot`을 따로 팠다. `#mixPreviewCta`와 같은 규약).
- ⚠️ 설명란 삽입은 **버튼**으로 뒀다. `seoGenerate`가 설명을 다시 만들 때 자동 삽입분이
  사라지거나 두 번 붙는 사고가 나기 때문. 같은 링크가 이미 있으면 안 붙인다.
- ⚠️ `inpock_registered`는 링크만 수정할 때 **초기화하지 않는다**(안 그러면 인포크 중복 등록).
  회귀 테스트로 못 박아뒀다.
- ⚠️ `product_json`은 `update_mix_job` 화이트리스트를 안 거치고 `set_mix_product` 전용 메서드로 쓴다.
