### 3. ★429 키 로테이션 버그 (커밋 `f7a8aa50f`)
`search_shorts`가 **403에서만** 로테이션 → 키1이 429면 **모든 검색이 조용히 0건**.
```
같은 시각·같은 키워드   기본 로테이션 → 0건 / 키2 지정 → 50건
키 상태               200:6개 403:3개 429:1개   ← 6개가 멀쩡한데 죽어 있었다
```
`status in (403, 429)`로 수정. 라이브 실행으로 **0건 → 50건** 확인.
`_first_ok`는 `raise_for_status` 덕에 이미 로테이션함(확인, 수정 불필요).
⚠️ 예외도 안 나는 **조용한 실패**라 호출부는 "영상이 없나 보다"로 읽는다.
