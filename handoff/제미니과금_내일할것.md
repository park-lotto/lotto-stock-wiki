## 2. 코드에 Vertex 붙이기 (Claude가 할 일 — 아직 미구현)

**전환 지점은 6곳뿐이다.** 클라이언트를 만드는 곳만 고치면 34개 호출부가 다 따라온다.

| 파일 | 줄 | 비고 |
|---|---|---|
| `shopping_shorts/video_analysis.py` | 99 | **★태깅이 쓰는 곳 — 여기만 해도 태깅은 된다** |
| `shopping_shorts/comment_gen.py` | 146 | |
| `shopping_shorts/similarity.py` | 31 | |
| `shopping_shorts/longform_shorts.py` | 170 | |
| `pipeline/atoms/key_vault.py` | 169 | 주식위키 공용 |

바꾸는 모양 (google-genai SDK는 Vertex를 인자로 지원한다):
```python
# 지금
genai.Client(api_key=key, http_options=...)
# Vertex
genai.Client(vertexai=True, project=<프로젝트ID>, location="us-central1",
             http_options=...)
# 인증은 GOOGLE_APPLICATION_CREDENTIALS=/home/ubuntu/vertex_key.json 환경변수로
```
그리고 계측에 `auth="vertex"`를 넘긴다 → `usage_meter.wrap(cl, auth="vertex")`
(이미 `auth` 필드가 준비돼 있어 API키분/Vertex분을 갈라서 볼 수 있다)

⚠️ **모델명이 다를 수 있다.** Vertex는 리전별 가용 모델이 달라서
   `gemini-3.1-flash-lite`가 그대로 되는지 **1건 먼저 돌려서 확인**할 것.
   안 되면 리전을 바꾸거나 모델명을 맞춰야 한다. (미검증 — 내일 실기 확인 필요)

⚠️ **`pip install google-cloud-aiplatform`이 서버에 필요할 수 있다.** 확인할 것.

## 3. 태깅 실행 (서버)

```bash
ssh -i C:/Users/CH/crawling_bot_client/LightsailDefaultKey-ap-northeast-2.pem ubuntu@43.200.48.69

cd /home/ubuntu/lotto-stock-wiki
set -a; . /etc/shopping-shorts.env; set +a          # ★키는 .env가 아니라 여기 있다
export GOOGLE_APPLICATION_CREDENTIALS=/home/ubuntu/vertex_key.json

# 먼저 소량으로 검증 (20건)
python3 -m shopping_shorts.archive_tagger --mode views --batch 20

# 잘 되면 대량 (백그라운드, 로그 남기며)
nohup python3 -m shopping_shorts.archive_tagger --mode views --batch 200 \
      > /tmp/tagger_vertex.log 2>&1 &
```

**조회수 높은 순으로 태운다**(`--mode views`가 기본). 즉 중간에 멈춰도
**중요한 것부터 이미 되어 있다.**
