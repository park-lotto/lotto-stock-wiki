# 숙소 쇼츠 카피 엔진 — 지침서

> 잘된 숙소 쇼츠 **한 편의 틀 그대로**, 숙소만 바꿔 만든다. 첫 판은 원본과 똑같이(숙소·브랜드만 다르게), 업그레이드는 그다음.
> 처음 정리 2026-10-23(관제 239). 첫 실전 = 스테이브로 1위 '상위 1% 고급 온천'(13.9만 회) 틀 → 스카이베이 경포.

## 0. 한 줄 사용법

```
py tools/travel/hotel_copy/engine.py new <이름> --ref <원본id> --hotel "<숙소명>" \
   --official <공식홈> --trip <트립닷컴 상세> --yeogi <여기어때 상세> --agoda <아고다 상세> [--insights 후기분석.json] [--brand @계정] [--bgm 곡]
py tools/travel/hotel_copy/engine.py ok <이름>        # ⏸ 확인 후 다음으로
py tools/travel/hotel_copy/engine.py redo <이름> --step <단계>   # 그 단계부터 다시
py tools/travel/hotel_copy/engine.py status <이름>
```
작업 폴더 `~/숏템자료/여행/hotel_copy/<이름>/` — 사진·소리·영상은 **git 에 넣지 않는다**(사진만 100MB 넘는다).

## 1. 단계 (순서 고정 — "만들자"면 처음부터 이 순서로)

## 2. 원본 읽기 (refs/<id>.json 만들기) — 원본마다 한 번

원본이 정본이다. 숫자는 전부 원본에서 잰다. 디자인 값을 새로 지어내지 않는다.

```
□ 받기         yt-dlp 1080p (C:/숏템_칼카피/<채널>/src/ 에 있으면 그것)
□ 컷           ffmpeg scene>0.25 → 컷 시각·길이(첫 0.1초 썸네일 컷 따로)
□ 자막 조각    0.2초마다 자막 띠(y 470~830)를 잘라 한 장 모음 → 눈으로 조각·바뀌는 시각을 적는다
□ 글자 모양    한 프레임 원본 배율로: 글자 높이·폭·띄어쓰기 유무·그림자(외곽선인지 번짐인지)
□ 소리         ebur128 LUFS · 말 속도(공백 뺀 글자/초) · 같은 목소리인지(F0)
□ 움직임       컷 처음·끝을 아핀으로 맞춘 뒤 남는 어긋남 %(사진 줌이면 ~0%, 입체면 20%+) · 프레임 반복(24fps 흔적)
□ 줄 역할      문장마다 역할·규칙·반드시 들어갈 말(must)·컷 수 — 이야기 순서를 적는다
```
□ 썸네일 글자   첫 프레임 흰 글자 상자(작은 줄·큰 줄 y·가로)를 재서 크기·높이를 맞춘다 — 원본마다 다르다
              (실측: 1위 온천 큰 줄 172px·y690 / 촌캉스 큰 줄 190px·y803, 화면 폭을 꽉 채움)
□ 원본마다 다른 규칙은 refs/<id>.json 에 적는다(엔진 코드에 적지 않는다):
              story(이야기 순서) · script_rules(줄 규칙) · thumb_rule · thumb_hint · thumb_kinds(썸네일 사진 종류, 없으면 아무거나) · end_same_as_thumb(끝 컷=썸네일?)
```
원본 틀 목록: `refs/ee3U4FtLb10.json`(1위 온천 — 걸어 들어가는 순서) · `refs/AVo84VRq55k.json`(촌캉스 — 체험 먼저: 간판 체험 → 직접 해 보는 감각 → 숙소 앞 자연 → 객실 → 가격 → 누구와)

```
예: `refs/ee3U4FtLb10.json` (스테이브로 1위). 이야기 = **걸어 들어가는 순서**:
훅(손꼽히는 ○○가 있습니다) → 입구(○○를 지나면 …할 수 있고요) → 안 시설(…에 …까지 있습니다) → **특히** 하이라이트(…가 펼쳐져요) → **~지만** 반전(문턱이 낮아지는 사실) → 권유(…싶다면 한 번쯤 …볼 만하겠죠?) · 끝 컷 = 썸네일 건물.

## 3. 사진 — 한 사이트만 보지 않는다

| 곳 | 방법 | 2026-10-23 스카이베이 실측 |
|---|---|---|
| 공식 홈페이지 | 일반 접속, 첫 화면 링크 전부(62쪽) 훑기 | 84장(700px+) · 드론 조감도·세로 1080×2148 ★가장 좋다 |
| 트립닷컴 상세 | 일반 접속, 그림 주소 크기 꼬리를 떼면 원본 | 74장 · 최대 2000px, 세로 일출 · 손님 사진이 섞인다 |
| 여기어때 상세 | 기존 주인 함수 `travel_source.fetch` | 44장(객실 포함) |
| 여기어때 후기 사진 | `travel_source.yeogi_reviews` 의 images — 숙소 사진에 체험 컷(고기 굽는 장면 등)이 없을 때 살린다. 고를 때 숙소 사진 뒤 | 아이리스 촌캉스: 숙소 74장에 굽는 장면 0 → 후기 197장에서 솥뚜껑 굽는 컷 |
| 아고다 상세 | 브라우저(playwright)로 열고 내려가며 모으기 | 4장(700px+) |
| 안 되는 곳 | 부킹닷컴 403·주소 다름 / 익스피디아·호텔스닷컴 429 / 트립어드바이저 로봇 확인 / 네이버 플레이스 썸네일만 / 야놀자 검색에 숙소 번호 없음 | |
| 유튜브 | 공식 채널 영상만 후보(개인 드론 영상은 남의 저작물) | 공식 채널 '스카이베이호텔 경포' 있음 |

- robots.txt 지킨다: 트립닷컴 `/htls/restapi`·`/hotels/Detail/Get*` 금지 → 상세 HTML 만 / 아고다 상세 허용 / 공식홈 전체 허용.
- 합치기: 같은 사진은 지문(dhash ≤6)으로 합치고 큰 쪽을 남긴다. 고를 때는 한 편에 같은 장면이 두 번 안 나오게 **ORB 특징점 60개 이상 = 같은 장면**(실측: 같은 사진 다른 자르기 182 / 다른 사진 0~3).
- 빼는 사진: 글자·간판(판정 has_text) · 홈페이지 합성 그림(네 변이 흰 띠).
- 공지도 본다: 스카이베이 공식홈 '20층 수영장 10/28~10/30 휴장' — 올리는 날짜를 맞춘다.

## 4. 대본 볼 것 (⏸ script_ok)

자동 검사(`check.script_issues`)가 보는 것: 줄 수 · 역할 말(must) · 줄 글자 수(원본 ±25%) · 자막 조각=문장·9자 이하 · 컷 수 · **숫자는 자료에 있는 것만**.
사람이 보는 것(검사가 못 잡는다 — 실측으로 걸린 것들):
```
□ 훅이 희소·권위로 여나 — 위치 설명만으로 열면 약하다('경포해변 바로 앞에' ✗ → '경포에서 손꼽히는 평점 9.1' ✓)
□ 입구·안 시설이 품격 꾸밈말인가 — 생활 정보 나열 ✗('치킨집과 편의점이 있는 1층 로비')
□ 반전이 문턱을 낮추나 — 단점을 꺼내면 ✗('투숙객도 유료지만')
□ 후기에서 불만이 더 많은 걸 자랑하지 않나 — 조식 '아쉽다' 60 > '맛있다' 48 → 조식 자랑 ✗
□ 문장 첫 말이 또렷한가 — '탁 트인'이 '하트인'으로, 첫 줄 '가마솥'이 '자마솥'으로 들렸다(첫 자음이 약함) → '시원하게 트인'·'솥뚜껑에'
```

```
□ 말과 장면이 맞나(피트니스에 수영장 ✗, 사우나에 식당 ✗ — 글자 맞추기만 하던 때 실제로 걸림)

```

## 6. 결과물 검사 (check) — 원본과 대조, 미달이면 전달 안 함

| 항목 | 기준 |
|---|---|
| 길이 | 원본 ±12% |
| 컷 수 | 원본 ±2 |
| 컷 길이 | 원본 최단×0.85 ~ 최장×1.15 (`check.CUT_MAX_K` — shots 단계도 이 값으로 컷 수를 정한다: 실제 어절 시각으로 잘라 보고 넘으면 한 컷 더. 컷은 자막 조각 중간 어절에서도 바뀐다) |
| 말 속도 | 원본 ±1.2자/초 |
| 소리 크기 | 원본 ±1 LUFS |
| 다시 받아쓰기 | 대본과 같다. 소리는 같은데 글자만 다른 것(`check.ASR_SAME`: 촌→총·솥→소 — 원본 영상도 '총캉스'로 받아씀)은 '발음 같음'으로만 남긴다. 한 글자씩 2곳까지는 받아쓰기 잡음일 수 있어 통과시키되 '귀로 확인'으로 남긴다. 받아쓰기 실패는 '다름'이 아니라 오류로 멈춘다 |
| 입체 움직임 | 기록만(원본 26~53%, 우리 3~33% — 사진 깊이 방식의 한계. 물·김은 안 움직인다) |

## 7. 남은 것 / 알려진 한계

- 입체 움직임이 원본보다 약하다(수영장·하늘처럼 무늬 없는 컷). 물 컷 몇 개만 AI 영상(Veo·클링)으로 바꾸는 판을 비교할 것.
- 배경음악 = 임시(라이브러리 곡, 사용권 미확인). 올리기 전 교체.
- 워터마크 계정명 = 임시(`--brand`).
- [광고] 표시는 협찬일 때만.
- 원본 읽기(2장)는 아직 사람 눈 — 새 원본마다 refs/<id>.json 을 만든다.

## 8. 2026-10-23 추가 — 대본 결 바꾸기·살아 있는 컷·끊김 줄이기

- **대본 결을 다른 채널 설명서로**: 화면은 숙소 원본 틀, 대본은 다른 채널 설명서(예: 두유노홈디노 체험담)로 합친 틀 = `refs/hdn_AVo84VRq55k.json`
  (`length_from_script`: 길이·컷 수를 원본 영상이 아니라 대본 글자 ÷ 원본 말 속도로 잰다). 대본은 그 설명서의 검사
  (`tools/calcopy/engine/script_frame` hook_formula_check·points_check·judge_like — 칼카피숏템엔진 트랙)를 통과시켜 ep.json 에 손으로 넣는다(state.script_manual).
- **살아 있는 컷만 AI 영상**(사장님 "불 피우는 거나 움직임이 있는 생동감 넘치는 것 몇 개만 중간에"): ep.json 컷에 `live`(움직임 영어 한 줄)·`live_desc` → `clips` 단계가 Veo 4초(시작 화면 = render.crop 세로 자르기, 프롬프트 = ai_scene.build_travel_prompt(motion=…)).
  실측: 솥뚜껑 김·캠프파이어 불꽃·계곡 물은 뚜렷이 움직임 / 사우나 난로 불은 약함.
- **끊김 줄이기(사장님 "조각을 붙인 것 같다")**: ① 목소리 = 대본 전체 한 번에 합성 → 어절 시각으로 줄 나눔(문장마다 따로 만들면 억양이 매번 새로 시작) ② 컷 바뀌는 곳 = `shot_at`(자막 조각 번호) — 말과 장면을 맞춘다 ③ 색 한 톤 = refs measured.look(원본 컷 평균 밝기·채도·따뜻함) 쪽으로 컷마다 당김.
- 자동 가운데(auto_cx)가 주인공을 잘라낼 때가 있다(곰 모자 강아지 0.352 → 화면 밖). ⏸ 사진 확인에서 세로 자른 모양으로 본다.
