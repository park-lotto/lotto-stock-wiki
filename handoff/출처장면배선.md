### ★진짜 문제 ①: 라벨(shot_role)이 묘사와 따로 논다
같은 AI가 같은 그림을 보고 쓴 묘사와 붙인 라벨이 어긋난다:

| 라벨 | 묘사에 그 라벨다운 낱말이 있나 |
|---|---|
| 도포 52% · 설치 47% · 정리 45% | (동작 축이라 그나마 맞음) |
| 완성 28% · 조작 25% · before 22% | |
| **문제 15% · 실증 7%** | ★`실증` 3,740개 중 93%가 안 맞음 |

원인: `shot_role`은 **한 장면에 하나만** 붙는데 실제 장면은 성질이 여럿이다.
"물티슈로 방충망 닦으니 때가 묻어난다" = 정리(동작) + 문제(상태) + 실증(증명) 셋 다 맞다.
게다가 축이 섞여 있다 — 설치·조작·도포·정리는 **동작**, 문제·완성·실증은 **상태·기능**.

```

지금 지시문은 "훅은 **완성** 또는 **실증:Y**로 열어라 / 준비동작으로 열지 마라"인데

```

레시피 상위 조작30%·실증20%  /  하위 사용중40%

그런데 훅 지시·재픽 둘 다 is_key를 우선하라고 시킨다.
