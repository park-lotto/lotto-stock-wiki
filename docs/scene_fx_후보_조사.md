## 권고 (1차로 만들 묶음)

1. 오버레이 PNG 묶음 하나로 끝나는 것부터 만든다. 캡컷까지 그대로 가고, 판단 주인도 오버레이 배치 함수 하나다.
   - 빨간 화살표 (직선·곡선)
   - 빨간 동그라미 (실선·점선·손그림, 라벨 선택)
   - ✓/🚫/✗ 깜빡임
   - 빨간 네모
2. 기존 경로를 확장하는 것:
   - 번호 챕터 카드 = "어둡게 강조" 프리셋 확장
   - Before/After 라벨 = 자막 요소
   - 상품번호 배지 = 자막 요소
3. 미디어 필터가 필요해 캡컷으로 굽기 작업이 필요한 것은 2차로 미룬다.
   - 흐린 배경 정보 카드의 "흐림"
   - 돋보기
   - 누끼 패턴 배경
