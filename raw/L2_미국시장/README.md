# L2 — 미국 시장 구조

글로벌 유동성이 실제로 미국 시장에서 어떻게 움직이는지.
한국 시장은 미국을 6~12시간 지연 추종하므로 방향 예측의 핵심.

## 수집 대상

| 소스 | 내용 | 수집 주기 |
|------|------|---------|
| 3대 지수 | S&P500·나스닥·다우·러셀2000 흐름 | 주 1회 |
| 섹터 ETF | XLK·XLE·XLF·SMH 등 자금 흐름 | 주 1회 |
| 빅테크 실적 | 애플·엔비디아·마이크로소프트 가이던스 | 분기 실적 시즌 |
| 옵션 데이터 | 풋콜 비율, 감마 레벨 | 주 1회 |
| 미국 유튜버 | 미국 시장 해석 채널 요약 | 주 1~2회 |

## 하위 폴더
- `index/` — 지수 흐름, 주간 시황
- `sector_rotation/` — 섹터 ETF 자금 흐름, 로테이션
- `earnings/` — 빅테크 실적, 가이던스, 어닝 서프라이즈

## 파일 네이밍
`{날짜}_{소스}_{내용}.md`
