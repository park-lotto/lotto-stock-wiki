# 꾸미기 피팅룸 UX 재설계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 쇼핑쇼츠 꾸미기(5단계) 페이지를 "버튼 벽"에서 "피팅룸"으로 재설계 — 진입 시 좋은 기본 스타일이 실장면 위에 이미 적용돼 보이고, 스타일은 실장면 썸네일 위 시각 카드로 고르며, 세부 조정은 고급 접기로 감춘다.

**Architecture:** 순수 프론트엔드(`shopping_shorts/static/produce.html` 단일 파일). 서버·렌더(`video_assemble.py`) 무변경. 기존 자산 재사용: `FULL_PRESETS`(19종)·`applyFullPreset`·`updateHC`·`updateCaption`·`fontCss()`·`toggleSceneBg()`·poster 엔드포인트(`/api/produce/mix/poster/{MIX_JOB}`)·강조단어 UI. 3태스크: (1)레이아웃 재배치+고급 접기 (2)스타일 카드 필름스트립 (3)진입 자동완성.

**Tech Stack:** 순수 JS + HTML/CSS(프레임워크 없음), FastAPI 정적 서빙. 검증은 pytest가 아니라 **브라우저 실렌더 grounding**(로컬 서버 + curl grep + 필요시 headless JS 실행).

## Global Constraints

- **파일은 `shopping_shorts/static/produce.html` 하나만 수정.** 서버(app.py/store.py)·렌더(video_assemble.py) 변경 금지.
- **공유 파일 git 위생(동시세션 편집 중):** 커밋 전 `git status --short`로 인덱스 확인 → `git add shopping_shorts/static/produce.html`만(‑A 금지) → 남의 staged 파일 있으면 `git restore --staged`로 제외. repo에 post-commit 자동푸시 훅 있음(스테이징 정확히 후 커밋).
- **서버는 repo 루트에서 기동:** `python -m uvicorn shopping_shorts.app:app --port <p>`(app.py가 절대 임포트라 `shopping_shorts/` 안에서 띄우면 ModuleNotFoundError).
- **기존 동작 보존:** `STATE.headcopy`/`captionStyle`/`deco` 구조 불변, `/api/produce/mix/settings` payload 동일, `updateHC`/`updateCaption`/`applyFullPreset`/강조단어/드래그 로직 불변(이동·재배치만).
- **기본 스타일 = "임팩트 옐로"**(FULL_PRESETS name으로 인덱스 조회, 순서 바뀌어도 안전).
- **대표 카드 5종(name):** `모던 화이트`, `임팩트 옐로`, `옐로 2톤 A`, `네온 글로우 화이트`, `레드 강조`.
- UI 텍스트·주석은 한국어, 기존 스타일 관용구(인라인 style, `class="tab"`, `var(--line)/--sub/--accent2` 등) 따를 것.

const FEATURED = ['모던 화이트','임팩트 옐로','옐로 2톤 A','네온 글로우 화이트','레드 강조'];
let MORE_OPEN = false;
let POSTER_URL_CACHE = null;
function currentPosterUrl(){
  // MIX_JOB 있으면 실장면 poster, 없으면 null(카드 폴백=chip 그라데이션). 한 번 계산해 캐시.
  if(POSTER_URL_CACHE!==null) return POSTER_URL_CACHE || null;
  POSTER_URL_CACHE = (typeof MIX_JOB!=='undefined' && MIX_JOB) ? ('/api/produce/mix/poster/'+MIX_JOB) : '';
  return POSTER_URL_CACHE || null;
}
function styleCardHTML(p, idx, selIdx){
  const sample = ((document.getElementById('hcText')||{}).value||'').trim() || '이거 실화?';
  const esc = s => s.replace(/&/g,'&amp;').replace(/</g,'&lt;');
  const hc = p.hc||{}, extra = (p.extra&&p.extra[0])||null;
  const poster = currentPosterUrl();
  const bg = poster ? `background:#000;` : `background:linear-gradient(160deg,${p.chip||'#333'},#0d1420);`;
  const bgImg = poster ? `<img src="${poster}" style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover;opacity:.9" alt="" onerror="this.style.display='none'">` : '';
  // 카드 스케일: 카드폭 92px 기준으로 hc.size(1080기준)를 축소
  const sc = 92/1080;
  const oc = hc.outline_color||'#000', ow = Math.max(1,Math.round((hc.outline_w||6)*sc));
  const shadow = hc.outline ? `text-shadow:${ow}px ${ow}px 0 ${oc},-${ow}px -${ow}px 0 ${oc},${ow}px -${ow}px 0 ${oc},-${ow}px ${ow}px 0 ${oc};` : '';
  const line1 = `<div style="color:${hc.color||'#fff'};font-family:'${fontCss(hc.font)}',sans-serif;font-weight:900;font-size:${Math.max(10,(hc.size||64)*sc)}px;${shadow}line-height:1.1">${esc(sample)}</div>`;
  let line2 = '';
  if(extra){ const es=92/1080; const eoc=extra.outline_color||'#000', eow=Math.max(1,Math.round((extra.outline_w||6)*es));
    const esh = extra.outline ? `text-shadow:${eow}px ${eow}px 0 ${eoc},-${eow}px -${eow}px 0 ${eoc},${eow}px -${eow}px 0 ${eoc},-${eow}px ${eow}px 0 ${eoc};` : '';
    line2 = `<div style="color:${extra.color||'#FFE100'};font-family:'${fontCss(extra.font)}',sans-serif;font-weight:900;font-size:${Math.max(10,(extra.size||64)*es)}px;${esh}line-height:1.1;margin-top:2px">${esc(sample)}</div>`; }
  const selBorder = idx===selIdx ? 'outline:2px solid var(--accent2);outline-offset:1px;' : 'border:1px solid var(--line);';
  return `<button type="button" onclick="pickStyleCard(${idx})" title="${esc(p.name)}"
    style="flex:0 0 auto;position:relative;width:92px;aspect-ratio:9/16;border-radius:9px;overflow:hidden;cursor:pointer;padding:0;${bg}${selBorder}background-clip:padding-box">
    ${bgImg}
    <div style="position:absolute;inset:0;display:flex;flex-direction:column;align-items:center;justify-content:center;padding:4px;text-align:center;z-index:2">${line1}${line2}</div>

  </button>`;
}
function selectedStyleIdx(){
  // STATE.headcopy가 가리키는 현재 스타일 추정: 폰트+색 일치하는 첫 프리셋(없으면 -1)
  const h = (STATE && STATE.headcopy)||{};
  return FULL_PRESETS.findIndex(p => p.hc && p.hc.font===h.font && p.hc.color===h.color);
}
function renderStyleCards(){
  const box=document.getElementById('fullPresets'); if(!box) return;
  const selIdx = selectedStyleIdx();
  const featIdx = FEATURED.map(n=>FULL_PRESETS.findIndex(p=>p.name===n)).filter(i=>i>=0);
  const restIdx = FULL_PRESETS.map((_,i)=>i).filter(i=>!featIdx.includes(i));
  const show = MORE_OPEN ? featIdx.concat(restIdx) : featIdx;
  box.innerHTML = show.map(i=>styleCardHTML(FULL_PRESETS[i], i, selIdx)).join('');
  const mb=document.getElementById('moreStylesBtn'); if(mb) mb.textContent = MORE_OPEN ? '− 접기' : '+ 더보기';
}
