# 자막제거 2단계 — UI 미니멀 프리미엄 재설계

**날짜**: 2026-07-23
**트랙**: 자막제거UI재설계
**대상**: shopping_shorts 영상제작소 위저드 2단계(자막제거) — `static/produce.html`

---

## 문제

영상제작 위저드 2단계 자막제거 화면이 두 가지 문제가 있다.

1. **벤더 이름 "VMake"가 사용자에게 그대로 노출된다** — 부제·체크박스 라벨·힌트·로딩
   문구·에러 문구 여러 곳. 사용자는 우리가 어떤 외부 API를 쓰는지 알 필요가 없고, 오히려
   서비스가 덜 완성돼 보인다.
2. **화면이 싸고 불안해 보인다** — 로딩이 `⏳ 자막 제거 중… VMake AI (최대 ~1시간)` 한 줄뿐이라
   "1시간"이라는 숫자가 겁을 주고, 완료 화면은 작은 세로 썸네일 2장이 넓은 카드에서 붕 떠 보인다.

목표: **"VMake" 완전 삭제 + 처리 과정이 고급스럽게 잘 돌아가는 것처럼 보이는** 미니멀 프리미엄 UI.

## 통찰

백엔드 로직·라우트·과금 구조는 **하나도 바꿀 필요가 없다.** 이건 순수 표현(presentation) 문제다.
- 소스 단위 청소·캐시·최종렌더 재사용(이중과금 0)은 이미 [2026-07-19 설계](2026-07-19-자막제거-소스단위-미리보기-design.md)로 라이브다.
- VMake는 비동기 블랙박스라 **실제 진행률(%)을 주지 않는다** → 진행바는 가짜 %가 아니라
  **무한 흐름바(indeterminate)** + 안심 문구가 정직하다.

그래서 변경 범위는 **`produce.html`의 2단계 마크업·CSS·상태 렌더 JS** + **사용자에게 새는 에러 문구 3곳**뿐이다.

---

## 결정 사항 (사용자 확정)

| 항목 | 결정 |
|---|---|
| 전체 방향 | **A · 미니멀 프리미엄** (깔끔한 카드 + 무한 흐름 진행바) |
| 벤더 이름 | **"VMake" 완전 삭제 → "AI 자막 제거"** (사용자 노출면 전부) |
| 완료 결과 레이아웃 | **C · 가로 꽉 채운 비교** (`원본(BEFORE) → AI제거 → 제거됨(AFTER)`) |
| 진행 표시 | **무한 흐름바** (가짜 % 금지) + "길면 수십 분, 다른 단계 먼저 진행 OK" |
| 관리자 키등록 UI | **범위 밖** (운영자 전용 설정 화면, 사용자 노출 아님) |

## 아키텍처

순수 프런트 + 소량 백엔드 문구. 컴포넌트 경계는 기존과 동일 — 상태 머신은 그대로,
**렌더링만 교체**한다.

### 1. 마크업 — `static/produce.html` 2단계 패널 (현 L266–278)

카드 한 장 구조로 재구성. 기존 `id`(`subToggle`·`subState`·`cleanPreviewWrap`·`btnCleanPreview`·
`cleanPreview`)는 **JS 로직이 참조하므로 이름을 유지**하고, 감싸는 마크업·클래스만 교체한다.

```
<section class="panel" data-step="1">
  <h3>2 · 자막 제거</h3>
  <div class="sub">소스 영상에 박힌 원본 자막을 AI로 지우고, 우리 자막을 새로 입혀요.</div>

  <div class="clean-card">                      ← 새 카드 컨테이너
    <label class="clean-top"> (badge 🧼 · 제목 "AI 자막 제거" · desc · 스위치)
      <input type="checkbox" id="subToggle" onchange="onSubToggle()" class="sw-input">
      <span class="sw-track"></span>            ← CSS 스위치(체크박스는 시각 숨김)
    </label>
    <div id="subState" class="hint"></div>
    <div id="cleanPreviewWrap" style="display:none">
      <button id="btnCleanPreview" class="btn-clean" onclick="startCleanPreview()">✨ 자막제거 미리보기</button>
      <div id="cleanPreview"></div>             ← JS가 상태별로 채움(로딩/결과/실패)
    </div>
  </div>
</section>
```

- **desc는 토글 상태로 바뀐다**: OFF "끄면 원본 영상 그대로 사용해요" / ON "렌더 시 자동 적용돼요".
  `onSubToggle`/`refreshSub`에서 desc 텍스트도 갱신(작은 추가).

### 2. CSS (produce.html `<style>` 블록에 추가)

기존 토큰만 사용(`--accent #37e0bd`·`--inset`·`--line`·`--sub`·`--fire`). 신규 클래스:
- `.clean-card` 인셋 카드 / `.clean-top` 상단행(뱃지·제목·스위치)
- `.badge` 민트 그라디언트 라운드 뱃지(🧼)
- **프리미엄 스위치**: `.sw-input`(실제 체크박스, `position:absolute;opacity:0`) + `.sw-track`
  (46×26 알약, `:checked` 형제선택자 `.sw-input:checked ~ .sw-track`로 ON 표현). 접근성 위해
  체크박스는 지우지 않고 시각만 대체.
- **무한 흐름 진행바**: `.cp-bar`(트랙) + `::before`(40% 폭 그라디언트가 `@keyframes slide`로 좌→우 반복).
- **결과(C 레이아웃)**: `.cp-compare`(flex) = `.cp-cell`(BEFORE) + `.cp-arrow`(→ "AI 제거") +
  `.cp-cell`(AFTER). 프레임은 `width:100%;max-width:170px;aspect-ratio:9/16` — 카드 폭을 나눠 꽉 채운다.
- `.cp-frame`에 `BEFORE`/`AFTER` 라벨(좌상단 pill), AFTER에 `✓` 체크 배지.

### 3. 상태 렌더 JS — `startCleanPreview`/`pollClean` (현 L3166–3204)

문구·마크업만 교체. **폴링·fetch·gen 가드·`clean_status` 분기 로직은 그대로.**

- **로딩**(`box.innerHTML`, 현 L3175 · pollClean 진행중):
  ```
  <div class="cp-run">
    <div class="cp-bar"></div>
    <div class="cp-run-lbl"><span class="cp-dot"></span>AI가 자막 영역을 자연스럽게 복원하는 중…</div>
    <div class="cp-run-sub">보통 몇 분, 길면 수십 분 걸릴 수 있어요. 다른 단계 먼저 진행해도 돼요.</div>
  </div>
  ```
- **완료**(`clean_status==='ready'`, 현 L3193–3196) → **C 비교 레이아웃**:
  ```
  <div class="cp-compare">
    <div class="cp-cell"><div class="cp-frame"><img src=...kind=original&t=><span class="cp-lbl">BEFORE</span></div><div class="cp-cap">원본</div></div>
    <div class="cp-arrow">→<span>AI 제거</span></div>
    <div class="cp-cell"><div class="cp-frame"><img src=...kind=clean&t=><span class="cp-lbl on">AFTER</span><span class="cp-chk">✓</span></div><div class="cp-cap good">자막 제거됨</div></div>
  </div>
  <button class="cp-redo" onclick="startCleanPreview()">↻ 다시 미리보기</button>
  ```
  이미지 `src`는 기존 `clean_thumb` 라우트(`?kind=original|clean&t=`) 그대로.
- **실패**(`clean_status==='failed'`, 현 L3200) → 벤더명 없는 친절 문구:
  ```
  <div class="cp-fail"><b>자막 제거에 실패했어요.</b> 잠시 후 다시 시도해 주세요.
    (문제가 계속되면 관리자에게 문의)</div>
  <button class="cp-redo" onclick="startCleanPreview()">↻ 다시 시도</button>
  ```
  `clean_error` 원문은 화면에 노출하지 않는다(내부 문구에 벤더/기술 용어가 있을 수 있음).
  디버깅용으로 남기려면 `title=` 속성(hover)이나 콘솔로만.

### 4. 백엔드 사용자 노출 문구 — "VMake" 제거

사용자 화면(clean_error·렌더 실패 사유·예외 메시지)에 닿는 3곳만 교체. **주석의 VMake는 유지**(내부 문서).

| 파일 | 현재 | 변경 |
|---|---|---|
| `mix_pipeline.py` L695 | `clean_error="VMake 개인키가 등록되지 않았습니다"` | `"AI 자막 제거 설정이 완료되지 않았습니다 (관리자 문의)"` |
| `mix_pipeline.py` L793 | `RuntimeError("자막 제거가 켜져 있으나 VMake 개인키가 등록되지 않았습니다")` | `"자막 제거가 켜져 있으나 설정이 완료되지 않았습니다 (관리자 문의)"` |
| `vmake_client.py` L60·L64 | `"VMake 자막제거 실패: …"` / `"VMake 결과 URL이 비었습니다…"` | `"AI 자막 제거 실패: …"` / `"AI 자막 제거 결과가 비었습니다…"` |
| `vmake_client.py` L50 | `ValueError("VMake API 키가 등록되지 않았습니다")` | `"AI 자막 제거 API 키가 등록되지 않았습니다"` |

파일명 `vmake_client.py`·설정키 `vmake_api_key`·함수명은 **안 바꾼다**(내부 식별자, 사용자 비노출).

## 데이터 흐름 (변경 없음 — 확인용)

```
토글 ON → /api/produce/mix/settings (subtitle_removal 저장)
"미리보기" → POST /clean → clean_status=cleaning → run_clean_sources(소스 청소·캐시) → ready
GET /clean_thumb?kind=original|clean → 원본|클린 프레임
최종렌더: subtitle_removal ON → clean_sources 재사용(재과금 0)
```

UI 재설계는 이 흐름의 **표시층만** 교체한다. 라우트·폴링 주기(3s)·gen 가드·과금 전부 동일.

## 상태 → 화면 매핑

| 조건 | 화면 |
|---|---|
| 토글 OFF | 카드 + OFF desc, 미리보기 영역 숨김(`cleanPreviewWrap` display:none, 기존 로직) |
| 토글 ON + 매칭 전(`!MIX_JOB`) | subState 경고 "2단계 매칭 먼저", 버튼 숨김(기존) |
| 토글 ON + 매칭됨 | `✨ 자막제거 미리보기` 버튼 + 안내 힌트 |
| cleaning | 무한 흐름바 + 복원중 문구 + "길면 수십 분…" |
| ready | C 비교(원본→제거됨) + "↻ 다시 미리보기" |
| failed | 친절 실패 문구(벤더명 없음) + "↻ 다시 시도" |

## 에러 처리

- 청소 실패/키 미등록 → `clean_status=failed` → 친절 문구(§3). 원인 원문은 비노출.
- 네트워크 오류(fetch throw) → 기존대로 "네트워크 오류"(벤더명 없음, 유지).
- 백엔드 문구 교체(§4)로 렌더 실패 사유·예외 메시지에서도 VMake가 안 샌다.

## 테스트

프런트 문자열·백엔드 문구 위주(로직 무변경이라 회귀 방지가 핵심).

- **백엔드 문구**: `test_clean_sources`(있으면 확장) — 키 없음 시 `clean_error`에 "VMake" 미포함·
  "AI 자막 제거" 포함 assert. `remove_subtitles` 키 없음 `ValueError` 메시지 assert.
- **프런트(문자열 존재 검사, 기존 `test_*_js.py` 패턴)**: `produce.html`에
  "VMake" 문자열이 **0회**(주석 포함 사용자 노출 영역), "AI 자막 제거" 존재,
  무한바 클래스(`cp-bar`)·비교 레이아웃(`cp-compare`)·스위치(`sw-track`) 마크업 존재 assert.
- **회귀**: `subToggle`·`btnCleanPreview`·`cleanPreview`·`cleanPreviewWrap` id 유지 확인
  (JS 참조가 안 깨졌는지). 기존 `onSubToggle`/`startCleanPreview` 호출 경로 유지.

## 범위 밖 (YAGNI)

- 관리자 VMake 키등록 설정 화면(운영자 전용, 사용자 비노출).
- B안 우측 정보패널 / 드래그 비교 슬라이더(C 레이아웃으로 확정).
- 실제 진행률 % 표시(백엔드가 신호를 안 줌 — 무한바로 확정).
- 파일명·설정키·함수명 리네이밍(내부 식별자, 사용자 비노출).
- 백엔드 청소 로직·라우트·캐시·과금 구조(전부 무변경).
