아침 브리핑 — 어떤 흐름으로 만들까요?

정보 수집 후 Claude가 질문을 던지고, 운영자 판단이 녹아든 브리핑 카드를 만드는 방식입니다.
먼저 질문 방식을 정해주세요.

A

주제 선택형

Claude가 오늘의 핵심 주제 3~5개를 뽑고
"오늘 어느 섹터 브리핑 집중할까요?" 식으로 먼저 물어봄.

흐름: 정보수집 → 주제 후보 제시 → 사용자 선택 → 해당 섹터 브리핑 카드 생성

B

핵심 판단 질문형

Claude가 오늘 데이터에서 "판단이 엇갈리는 지점"을 찾아
A/B로 물어봄. 예: "오늘 반도체 — 브로드컴 쇼크가 일시적 조정인가 vs 추세 전환인가?"

흐름: 정보수집 → 판단 분기점 2~3개 질문 → 운영자 답변 → 인사이트 카드 생성

C

두 단계 조합

1단계: 주제 선택 (어느 섹터/이슈가 오늘 핵심인가)
2단계: 해당 주제 내 판단 질문 A/B

흐름: 정보수집 → 주제 선택 → 판단 질문 → 브리핑 카드 생성
질문이 2번으로 늘어나지만 인사이트 정확도가 가장 높음

💡 추천: C안 — 주제를 먼저 좁혀야 판단 질문도 날카로워집니다.
오늘 10개 섹터 중 어느 게 핵심인지 모르는 상태에서 판단 질문만 던지면 방향이 흐려질 수 있어요.
