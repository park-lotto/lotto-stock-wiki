## S6. STEP 2 — MCP 개념 (50초 인서트)
**`[IMPACT]` → `[SPLIT]` 비교 → `[REMOTION]` 허브 다이어그램**

```
레이어 구성:

  Phase 1 — 문제 제시 (0~15초) [IMPACT]
    어두운 배경 + 큰 글씨 3줄 stagger 등장:

    네이버  →  한국어 명령
    구글    →  영어 명령
    카카오  →  복잡한 인증코드

    → 마지막 줄 추가: "다 따로 코딩해야 한다"
    → 전체 빨간 X 오버레이

  Phase 2 — 비유 (15~30초) [SPLIT] 비교형
    좌: 옛날 충전기 이미지 (5핀/8핀/24핀 허브 어수선)
        텍스트: "삼성 5핀 / 아이폰 8핀 / 피처폰 24핀"
    우: USB-C 케이블 하나
        텍스트: "이제는 다 이거 하나"
    → 우측에 민트 체크 배지

  Phase 3 — MCP + PlayMCP (30~50초) [REMOTION] 허브 다이어그램
    중앙: PlayMCP 박스 (허브, USB-C 포트 아이콘, 민트 글로우 펄스)
    좌: 네이버 아이콘 → 화살표 → PlayMCP (scaleX 드로잉)
    우: 카카오톡 아이콘 → 화살표 → PlayMCP
    상단: 구글 캘린더 아이콘 → 화살표 → PlayMCP
    오른쪽 바깥: Claude 아이콘 ← 굵은 화살표 ← PlayMCP

    상단 고정 레이블:
      "MCP = AI 세계의 USB-C 대통합 규격"
      (Anthropic 로고 작게 옆에)

  ※ 테크피드 위성 다이어그램 구조 동일
    위성 = 각 서비스 아이콘 / 허브 = PlayMCP / 수신 = Claude
```

**나레이션**
잠깐, MCP가 뭔지 딱 한 번만 설명할게요.
AI한테 데이터를 가져오라고 시키면 되는데, 문제가 있어요.
네이버는 이 방식, 카카오는 저 방식, 구글은 또 달라요.
서비스마다 말투가 다 달라서 하나씩 따로 코딩해야 했던 겁니다.

기억하세요? 옛날 스마트폰 충전기.
삼성은 5핀, 아이폰은 8핀, 피처폰은 24핀.
충전기 허브가 이렇게 지저분했잖아요.

이걸 앤트로픽이 "앞으로 다 이걸로 통일하자"라고 만든 게 MCP입니다.
AI 세계의 USB-C 대통합 규격.

PlayMCP는 그 C타입 허브예요.
여기 꽂아두면 — Claude가 네이버도, 카카오톡도 딸깍 하나로 처리합니다.

**자막 1** | 서비스마다 말투가 달랐다 → 하나씩 코딩 필요
**자막 2** | MCP = AI 세계의 USB-C 대통합 규격 (by Anthropic)
**자막 3** | PlayMCP = 한국 서비스 전용 C타입 허브
