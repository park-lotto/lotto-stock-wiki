## 공통 강의 4강 (세 반 전체)

### 1강. 설치와 준비
**목표:** 수업이 끝나면 전원 내 PC에서 점검까지 끝난다.

1. 숏클이 도는 구조: 서버 = 노하우, 내 PC = 손, 내 Claude = 눈
2. 준비물: 윈도 PC, Claude Max 구독(별도 결제), 숏템 계정(숏클 승인 완료)
3. 설치 ✅: 마이페이지 숏클 칸 → `복사하기` → 윈도우 키 → `powershell` → 엔터 → 마우스 오른쪽 버튼 → 엔터
4. 첫 문장: `숏클 점검 준비해줘`
5. PC 규칙 ✅: 등록 2대, 동시 접속 1대, PC를 바꾸면 새 PC에서 신청 → 관리자 승인
6. 막혔을 때 보낼 것: 파워쉘 화면 캡처 + 어느 단계인지

**실습:** 함께 설치 (이 PC 라이브 설치 실측 5분 24초)
**과제:** 점검 완료 화면 캡처 제출
⚠️ 일반 회원 계정으로 다른 PC에서 끝까지 해 본 기록이 없다. 수업 전 박2 계정으로 시험한다.

### 2강. 프리셋 고르기와 내 채널 설정
**목표:** 내 채널에 맞는 프리셋 하나를 정하고 저장한다.

1. 형식 6가지 ✅
   - 쇼핑형: 제품 썰을 게시글·스토리 틀로
   - 해외원본: 해외에서 터진 원본 재편집(나레+원음 / 나레 / 자막+배경음)
   - 연예인쇼핑형: 연예인 원본 + 나레 + 제품
   - 연예인레시피형: 연예인 레시피 + 재료
   - 여행쇼츠형: 숙소 쇼츠 틀
   - 인물형: 인물 썰, 나레 없이 배경음
2. 내 채널 주제에 맞는 형식 고르는 기준
3. 설정 화면 ✅: 프리셋 고르기 → 템플릿 → 꾸미기 → 소리 → 완성본
4. 바꿔 보기: 채널 이름, 자막, 목소리, 미리보기
5. 키 연결 ✅: `숏템메이커에 등록한 키 가져오기`

**실습:** 설정 화면을 열어 내 채널 값 저장
**과제:** 고른 프리셋과 이유 한 줄 제출
⚠️ 회원에게 실제로 켜진 프리셋 목록은 라이브에서 못 뽑았다. 장부는 24개, 상품 약속은 5~10개다. 수업 화면으로 확인한다.

### 3강. 한 편 만들기
**목표:** 말 한 줄로 내 영상 1편을 완성한다.

1. 말하는 법: `내 채널(프로필 이름)로 이 영상 만들어줘 <유튜브 주소>`
2. 진행 순서 ✅: 소재 후보 확인 → 고르기 → 대본 확인·승인 → 제작 대기 → 완성
3. 사람이 결정하는 자리: 소재, 대본 승인, 완성본 확인
4. 입력을 무엇으로 줄까 ✅: 주제 / 영상 주소 / 해외 채널 주소 / 제품
5. 완성본 받기: 내 PC 작업 폴더, 텔레그램·드라이브 연결(`최근 완성본으로 시험 보내기` ✅)

**실습:** 강사 시연 1편, 수강생 각자 1편
**과제:** 완성본 1편 제출
⚠️ 시연은 수업 전에 같은 프리셋으로 1편 돌려 시간을 재고, 녹화본을 예비로 둔다.

### 4강. 고치고 올리기
**목표:** 완성본을 고쳐 실제 채널에 올리고, 혼자 반복할 수 있다.

1. 완성본 고치기 ✅: 영상을 보며 고칠 자리를 짚고 지시
2. `지금 설정으로 다시 만들기` ✅, `캡컷으로 내보내기` ✅
3. 꼭 지킬 것: 오른쪽 위 광고 표시, 남의 쇼츠 그대로 쓰지 않기, 연예인 장면 출처 규칙
4. 멈췄을 때: 다시 시도하기, 오류 보내는 방법
5. 하루 루틴: 소재 고르기 → 만들기 → 확인 → 올리기

**실습:** 3강 영상 한 곳 고치기
**과제:** 일주일 안에 3편 업로드, 링크 제출
⚠️ 쿠팡·인포크 자동 등록은 실측 전이라 넣지 않았다.

## 고급 강의 6강 (공통 강의 수강 후)

### 고급 1강. 터진 채널 찾고 해부하기
1. 어떤 채널을 고르나: 최근성, 조회수 편차, 내가 만들 수 있는 틀인가
2. 폰으로 채널 담기 ✅: 쇼츠 공유 → 숏템 → 채널 담기
3. 무엇을 보나: 훅, 스토리 흐름, 자막 스타일, 템플릿, 배경음, 효과음
4. 상위 영상을 묶어서 공통점 뽑기

**과제:** 벤치마킹 채널 3개와 공통 틀 정리

### 고급 2강. 원본 찾기와 소재 쌓기
1. 해외 채널 주소로 원본 찾기 ✅
2. 언어별로 찾는 이유
3. 좋은 원본 판정: 진짜 그 장면인가, 남의 편집본은 아닌가
4. 내 PC에 소재 쌓기
5. 창고에서 바로 제작 ⚠️ 출시 자료에 '준비 중'으로 표시돼 있다

**과제:** 내 벤치 채널 기준 소재 10개 확보

### 고급 3강. 벤치마킹해서 내 프리셋 만들기
1. 채널을 넣으면 분석 → 내 틀 만들기
2. 시험 영상 → 원본과 비교 → 수정
3. 그대로 따라 하는 것과 벤치마킹의 차이

⛔ 회원 도구 10개에 채널을 분석해 새 프리셋을 만드는 도구가 없다. 이 강의 전에 넣어야 한다.

### 고급 4강. Claude 고급 정보 ① 일 시키는 법
1. 모델 등급을 회사 직급처럼: Fable·Opus = 판단, Sonnet·Haiku = 단순 확인
2. 일꾼 여러 개 나눠 돌리기
3. 자는 동안 돌리기, 크레딧 아끼는 법
4. 긴 작업이 끊겼을 때 이어 가기

### 고급 5강. Claude 고급 정보 ② 나만의 도구 만들기
1. 규칙 파일(CLAUDE.md)과 기억
2. 스킬, 훅, MCP 연결
3. 작게 만들고 결과물로 검사하기
4. 사장님 실제 사례: 블로그, 카드뉴스, 주식 프로그램

**과제:** 내 일 하나를 Claude 자동화로 만들기

### 고급 6강. 해외 시장 함께 개척
1. 나라별 터진 채널 찾기
2. 한국판으로 가져오기 vs 현지 채널 개설
3. 함께할 채널 정하기, 이후 정기 공유 방식

## 프리미엄 1:1 (4주, 주 2회 Zoom = 8회)

공통·고급 강의는 녹화본으로 듣고, 1:1은 내 채널에만 쓴다.

| 회차 | 내용 | 끝났을 때 결과 |
|---|---|---|
| 1 | 목표와 현재 수준 확인, 채널 방향 | 채널 주제 확정 |
| 2 | 설치·기초 세팅 대신 진행 | 점검 완료 |
| 3 | 채널 개설, 프로필, 내 채널 설정 | 채널 준비 끝 |
| 4 | 첫 영상 같이 만들기 | 1편 업로드 |
| 5 | 벤치마킹 채널 고르기 | 벤치 채널 확정 |
| 6 | 벤치마킹을 내 채널에 적용 | 새 틀로 1편 |
| 7 | 올린 영상 지표 진단 | 수정 목록 |
| 8 | 한 달 뒤 운영 계획, 라운지 안내 | 주간 운영표 |

추가: 오프라인 특강 1회(횟수 확정 필요), 프리미엄 라운지.

## 수업에서 하지 않는 말

- 결과 단정: "금방 1등", "한계가 없다"
- "카피" → "벤치마킹"
- 타사 제품·채널 깎아내리기
- 수익·조회수 보장
- 실측 전 기능: 쿠팡·인포크 자동 등록, 1시간마다 채널 리포트
- 프리셋의 내부 벤치 채널 이름: 회원 화면에서도 숨긴 값이다

저작권은 숨기지 않는다: 중복 회피와 광고 표시를 하지만, 채널 판정 위험이 0은 아니라고 말한다.
