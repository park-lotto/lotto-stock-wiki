### 조사 결론 (출처는 대화 기록·아래)
- Buffer 업로드는 Buffer 서버가 공식 연동으로 함 → 폰 IP 무관. 유튜브 공식 "IP 제재" 규칙 못 찾음. 위험은 내용(스팸정책 6번 대량·반복 AI 영상)
- 하루 한도: 유튜브 미인증 10개/24h, 인증 무제한(Buffer 기준) · API 250요청/24h(무료·Essentials) · 무료 대기열 채널당 10개(월 한도 아님)
- 드라이브 공유링크는 Buffer가 못 가져감(developers.buffer.com/guides/hosting-media) → 공개 직링크 필요
- 고정댓글: Buffer 스키마에 댓글 칸 없음(YoutubePostMetadataInput 8필드 실측). 유튜브 API 문서에도 고정 기능 없음
- 유튜브 API 직접 업로드는 미심사 앱이면 비공개로 묶임 → 업로드는 Buffer 유지가 맞다
