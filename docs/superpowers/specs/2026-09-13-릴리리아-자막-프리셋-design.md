# 릴리리아(by. Lily) 자막 프리셋 — 설계

날짜: 2026-09-13 · 트랙: 릴리자막프리셋

## 목표

릴리리아(by. Lily) 예능 자막 스타일을 우리 렌더러(Remotion)로 재현해, 숏템메이커 **고급효과(fx, 유료)**
레이어에서 프리셋으로 고르고 **글자만 바꾸면** 그 스타일로 나오게 한다. mogrt 파일은 프리미어 전용이라
그대로 못 쓰므로, 그 디자인을 Remotion 컴포넌트로 다시 만든다.

## 왜 Remotion(고급효과)인가 — 실측 근거

- 숏템메이커 기본 자막은 **ffmpeg drawtext**(`video_assemble._burn_captions`)로 그린다. drawtext는
  글로우·반짝이·그라데이션이 **안 된다**(폰트·색·외곽선·강조·기본 애니메이션까지만).
- Remotion(`shopping_shorts/motion/`, React/HTML)은 `app.py:19847 remotion_render.render`로 이미
  고급효과(fx) 렌더에 쓰인다. CSS/SVG라 글로우·반짝이·기울임이 전부 된다.
- 사장님 결정: **유료 고급효과로 넣는다**(원본과 똑같이 나와야 하므로).

## 폰트 (실측)

- 릴리리아 #8 mogrt·블로그·영상 어디에도 폰트명이 안 적혀 있다(제미니로 100프레임 전수 확인,
  블로그 본문에도 "사용 폰트는 영상에서"만 있고 실제 이름 없음).
- 원본 자막 글자와 우리 폰트 41종을 제미니로 대조 → **티몬 몬소리(TmonMonsori.ttf)**가 최적
  (두꺼운 획 + 둥근 모서리). 살짝 기울임(skewX 8deg)을 주면 원본과 거의 같다.
- 즉 **새 폰트 안 받아도 된다.** 티몬 몬소리로 재현. Remotion은 @font-face로 로딩해야 다른 폰트로
  안 그려진다(Root.tsx에서 FontFace 로딩 + delayRender).

## 구성 (3파일)

1. `motion/src/lily_presets.ts` — 프리셋 목록(`deco_frame.PRESETS`처럼 한 곳). 항목: 폰트·기울임·
   글자색·강조색·외곽선색/두께·글로우·반짝이·애니메이션·크기. 첫 프리셋 `hee_pink`(#8 희로애락):
   **흰 글자 + 핑크 외곽선 + 은은한 핑크 글로우 + 강조어 핑크 + 반짝이 별**.
2. `motion/src/LilySub.tsx` — props `{text, highlight, preset, position}`. 화면 폭 넘으면 자동 축소
   (fit). highlight 단어만 강조색. 반짝이는 글자 양옆 바깥에 절대배치.
3. `motion/src/Root.tsx` — LilySub 컴포지션 등록(1080×1920) + 폰트 @font-face 로딩.

## 검증 (이번 세션 완료)

- `node src/render-one.mjs LilySub '{...}'` 로 알파 mov 렌더 성공. 검정 배경 합성해 원본과 비교:
  폰트·기울임·흰 글자·핑크 외곽선·핑크 글로우·"행복" 강조·반짝이 전부 재현.
- **글자 바꿔 재검증**: "오늘 진짜 대박 사건이야"(강조 "대박")로 같은 스타일 렌더 성공 → 글자만
  바꾸면 되는 것 실증. 비교 이미지 `out_compare.png`.
