# 자막꾸미기 ↔ 최종렌더 어긋남 (2026-08-31)

사장님 제보: **"자막꾸미기랑 렌더링이랑 검정으로 하니까 이상하게 나온다 / 화이트는 괜찮"**
→ 흰 자막에선 검은 테두리가 원래 그럴싸해 안 걸렸고, 검정 자막에서 글자가 뭉개져 발각.

## 고친 것 (5건 — 전부 미리보기 ≠ ffmpeg 렌더)

1. **두께 0인데 렌더는 검정 테두리 9px 강제** ★진짜 원인
   `borderw=max(1, _ui_px(outline_w, 9))` — `_ui_px`가 0을 "값 없음"으로 보고 기본값 9를 되살렸다.
   → `_outline_parts()` 하나로 뽑고 `zero_ok=True`. 0이면 테두리를 **아예 안 붙인다**.
   실측: 두께0 → `[]` / 미지정 → `borderw=9` / 두께5 → `borderw=8`(1080 환산).
2. **테두리 모양**: 자막 미리보기는 대각선 4방향 text-shadow였다 → 두꺼워지면 검은 사본이 글자 **위로**
   올라와 획을 메운다(헤드카피가 2026-08-20에 겪은 그 사고). `-webkit-text-stroke`+`paint-order`로 통일.
3. **박스 모서리**: 미리보기 `borderRadius:6px`(헤드카피는 30px) / 렌더 `drawbox`·`box=1`은 **각진 사각** → 0으로.
4. **강조 단어 박스가 설정 무시**: `@0.90`·`boxborderw=12` 하드코딩 → box_opacity·box_pad를 쓴다.
5. **그림자 질감**: 미리보기는 blur, ffmpeg `shadowx/y`는 blur 없음 → 딱딱한 오프셋으로.

## 파일
- `shopping_shorts/video_assemble.py` — `_outline_parts()` 신설, 호출부 2곳(자막·헤드카피/워터마크), 강조박스
- `shopping_shorts/static/produce.html` — `applyCapStroke()` 신설, 미리보기 3곳

## ⏭ 다음
- **실렌더로 눈 확인 안 했다.** 검정 자막 + 두께 0 / 두께 5로 job 하나 돌려 미리보기와 대조할 것.
- 썸네일 스타일카드(`styleCardHTML`, produce.html:5811)는 아직 대각 4방향 + `Math.max(1,…)`. 카드 축소본이라
  급하진 않지만 같은 함정이다.

# 필름 펼치기가 아무 반응 없었다 (2026-08-31)

사장님 제보: 제작소 3단계에서 소스별 묶음 헤더의 **[🎞 필름]을 눌러도 안 펼쳐진다**.

## 뿌리 (라이브 실측 work=33377557599e)
`toggleRoll`의 가드 `if (!anchor && !document.body.classList.contains('tight'))`.
- src 종류의 anchor는 `.srcfilm[data-vid]`인데, **소스별 묶음 헤더는 `.srcfilm` 없이 버튼만 그린다**
  (`.srcfilm`은 '필름형' 그룹에서만 생김 — scene_lab.html:2605 vs 2614).
- 제작소 안은 `body.inside-studio grow`라 **tight가 아니다** → 면제도 못 받고 통째로 return.
- 실측: src 클릭 후 `#rollbay` 자식 **0** / seg 클릭은 1(정상). tight를 임시로 붙여 같은 경로를
  태우니 자식 2 = "🎞 영상 1 전체" 필름이 펼쳐졌다 → 가드 하나가 원인임이 확정.

## 고침
anchor를 실제로 쓰는 건 `kind==='cut'`(그 칸 안 .tbcuts에서 펼침)뿐이다. src·seg는 고정 자리
(`#rollbay`)에 펴므로 anchor가 필요 없다 → `if (kind === 'cut' && !anchor)`로 좁혔다.

> 교훈: **셀렉터와 표식은 짝이다.** 한쪽에만 있으면 가드가 엉뚱한 걸 막는다
> (메모리 `목록에만_적힌_예외는_아무것도_안막는다`와 같은 계열).
