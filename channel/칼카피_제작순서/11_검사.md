# 11 검사 — 자동 · 받아쓰기 대조 · 눈. 셋 다 통과해야 납품

## ① 자동 검사
```
PYTHONUTF8=1 py tools/calcopy/hybrid/run.py <키> checks --version <판> --redo checks
```
벤치 판 = `bench_check` 6항목, 전부 ○ 여야 한다:
| 항목 | 기준 |
|---|---|
| 길이 | 판 설정 length 안(키치잇 25~30초) |
| 화면=시간표 | 완성본 길이 = 시간표 끝 ±1프레임 |
| 음량 | −14.0 LUFS ±0.5 |
| 최고점 | ≤ TP+0.5 (−1.0 dBFS) |
| 0초·첫 줄 얼굴 | YuNet 얼굴 ○ (0.0·0.1·0.6·1.1…초, 얼굴 비율 ≥0.20, 가운데 60%) |
| 배치 | 본보기 벤치 편 대조 칸 차이 |
결과 `<판>/자동검사.json` · `final_sheet_1s.jpg`(1초 시트) · 썸네일 JPG(로컬만 — 드라이브엔 안 올린다).
잇썸홈·재미썸홈 판은 `checks.py`(B표_draft.md · B1~B18 · T1)를 같은 명령이 돈다.

## ② 받아쓰기 대조 (필수 — 사장님 10-20 "배속 올린 나레는 되돌려 받아써 대조")
```
ffmpeg -i final.mp4 -ac 1 -ar 16000 asr/final.wav
PYTHONUTF8=1 py -c "from tools.calcopy.engine.asr_local import transcribe; print(transcribe('asr/final.wav', engine='speechmatics'))"     # 스피치매틱스(주인 asr_local)
(위스퍼: 06_받아쓰기.md 의 numpy 방식)
```
- 나레가 **대본 글자대로** 들리나 줄마다 대조. 이름·브랜드가 들리나.
- **스피치매틱스가 주(主)**(사장님 10-21 유료 승인), 대조는 제미나이 무료 모델(`server_ai.asr_clips`) 또는 위스퍼 small — 위스퍼 혼자 틀리게 들은 건 결함이 아닐 수 있다(정상 나레도 잘못 듣는다). 두 모델이 서로 다르게 들으면 **그 줄만 잘라** 다시 듣는다. 둘 다 틀리면 고친다(대본 tts 표기·재합성).
- 같은 소리 다른 표기는 통과로 본다(이해정/이혜정 · 베두먼/배드먼 = 본인도 원본에서 그렇게 발음).
- 원음 구간은 원본 말과 같은지(뭉개지면 그 조각을 뺀다).
- Claude 는 소리를 못 듣는다 — 귀로 못 들었다는 사실을 보고 첫 줄에 적는다.

## ③ 눈 확인 (Claude 가 직접 연다)
- `final_sheet_1s.jpg`: 틀·제목·자막 자리·로고·출처 줄, 줄마다 화면이 대사와 맞나(A3), 남의 얼굴·손·글자 없나.
- 첫 프레임(0초) 원본 크기 = 연예인 얼굴 크게.
- 바꾼 줄이 있으면 그 구간 프레임을 따로 뽑아 본다(`ffmpeg -ss <초> -i final.mp4 -frames:v 1 x.jpg`).
- 자동 검사가 못 잡는 것: 원본 샷 경계를 넘는 0.2초 섞임 · 방송 로어서드·예능 박스 · 같은 장면 반복 · 손·로고를 얼굴로 잡은 오탐 → 시트로.

## 걸리면
- 음량 × → 렌더러 음량 맞춤을 의심하고 단계별로 잰다(mix_raw → mix → final). 10-20 꿀템노트: 원본 최고점 −0.8 이라 선형 맞춤 포기 → 리미터 수리.
- 얼굴 × → 0초·훅 컷을 연예인 얼굴 컷으로 바꾸고 다시 렌더.
- 한 곳을 고치면 **같은 꼴 결함이 다른 편에도 있나** 찾는다(같은 묶음 전체에 같은 검사를 다시).
