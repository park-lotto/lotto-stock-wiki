# 04 품질 관문 한 벌 — `hybrid/quality_gate.py` + 1차 자 연결 (표준 §4-1·§5·§3-3 B2·B4·A5)

## 목표
자동 관문을 **한 함수** `quality_gate.gate(판, doc, work)` 로 합친다: bench_check 10항목 + 검수 B표 핵심(B5·B6·B7·B13·B14·B16·B17·B18·B9·B10) + `script_audit` + **1차 자 `kal_analyze.match_table`**(지금 관문 어디서도 안 돌린다) + **장면↔대사 `scene_fit`** + 표식 검사. 2단 눈 검수 묶음(E1~E8 자료)을 만든다. 통과 못 하면 `ok:false` — 회원 경로(08)와 우리 PC 가 같은 함수를 부른다.

## 설계
- `gate(style_name, doc, work, bench=True, eye_pack=True) -> dict{ok, rows:[{group, what, ok, value, src}], match, fit, eye_pack_dir}` — 표준 §5-1 표의 묶음·항목·판정 그대로. 항목 함수는 **기존 주인을 import**: `bench_check.*`(규격·화면·썸네일), `checks.reuse_violations/aba_violations/pauses_between/asr_check`(재료·소리), `check_seams`(되감김), `script_audit.audit`(대본), `placement.check_place`(배치), `kal_analyze.match_from_render`(1차 자 — `bench.line_reads` ≥1편 있을 때, 필수 칸 미측정은 ✗), `scene_fit.measure_render`(장면↔대사 — Claude CLI `claude_cli.ask` 소넷, 시트 10칸 1회·편당 ≤3회, 제미나이 금지), 표식(`render_info.json` 의 `style_sha`·`renderer_sig`·`placement.reference` — 없으면 ✗ '불신').
- 1차 판(`base` 없는 판)만 match 필수. 업그레이드 판(`base` 있음)은 match 뼈대 칸(표준 §5-1 뼈대)만 필수 + 05 의 `upgrade_table` 결과 첨부.
- 출력: `<doc>/품질관문.json`(항목·값·○×·근거 파일) · `<doc>/재현일치도.json`·`.md` · `<doc>/장면대사.json` · 눈 검수 묶음 `<work>/eye/`(1초 시트 + `compare_sheet` 벤치 나란히 + 훅 3초·끝 2초 0.1초 띠 + 받아쓰기 대조표 + 줄↔컷 대조표 + `눈검수_질문.md` E1~E8 번호 그대로) · `<doc>/자동검사.json` 은 호환으로 같은 내용.
- 사보타주 규칙(표준 §5-1): 항목마다 "그 결함이 있는 입력" 픽스처 1개 — 통과하면 항목 추가 거절.

## 합격 검사(사보타주 먼저)
1. 옛 결함 완성본(또는 픽스처) 5건이 각각 해당 항목 ×: 효과음 39발→B14 × · 컷 중앙 2.85 vs 1.63→match cut.median × · 되감김→B16' × · ABA→B16 × · 썸네일 2프레임 없음→썸네일 ×. 고치기 전 `bench_check` 가 이 다섯 중 몇 개를 못 잡는지 표로(= 두 벌이던 증거).
2. 잇템로그 ep13: bench_check 10항목 결과가 옛 `자동검사.json` 과 같다(회귀) + match 13칸 표 출력(✓/✗/미측정 수) + 눈 검수 묶음 파일 7종 생성.
3. 표식: `render_info.json` 에서 `style_sha` 를 지우면 gate `ok:false`(불신).
4. 1차 자 필수 칸 중 하나를 미측정으로 만든 픽스처 → `ok:false`(미측정 ≠ 통과).
5. `scene_fit` 어댑터: 컷 10개 픽스처(맞는 장면 7·틀린 3)에서 평균·7 미만 비율이 손 정답과 ±1칸.
