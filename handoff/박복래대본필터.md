# 박복래 대본 필터 회귀 수정

## 제보·원인

- 2026-09-15 23:26 전후 박복래 고객 작업 `b6e3a1a86122`의 얼음정수기 대본 생성이 반복해서 HTTP 502가 됐다. 해당 작업은 고객이 이후 삭제해 DB에서 원문 상태를 그대로 복원할 수 없다.
- 9월 14일 사실·주제 검사를 치명 게이트로 추가한 뒤, 선택한 스타일이 사실 검사에서 모두 탈락하면 후보를 전부 버렸다. 화면은 새 실패 종류(`근거부족`, `소재이탈`, `판매처이탈`)를 해석하지 못해 실제 원인 대신 카테고리 불일치라고 안내했다.
- 생성 502 비율은 9월 14일 해당 배포 전 4/107(3.7%)에서 배포 후 36/83(43.4%), 9월 15일 178/281(63.3%)로 뛰었다.

## 수정

- 정상 통과본이 하나라도 있으면 종전처럼 통과본만 반환한다.
- 전부 탈락했을 때 사실·수치 근거만 실패한 후보는 `needs_review` 초안으로 복구한다. 주제·제품·판매처 이탈 후보는 계속 폐기한다.
- 제작소와 구형 생성 모달 모두 검토 초안을 사실 근거 확인 필요 상태로 명시한다.
- 실패 안내가 새 실패 종류를 실제 원인별로 설명한다.

## 검증

- 신규 회귀 테스트: 사실 실패 후보 복구, 소재 이탈 후보 미복구, 실패 문구, 두 UI 경고.
- 관련 사실·주제·성공경로 테스트 63개 통과.

## 다음 확인

- 배포 후 실제 제작소에서 얼음정수기 자료로 생성해 HTTP 200과 검토 경고 또는 정상 통과본을 눈으로 확인한다.
- 고객이 사고 작업을 삭제했으므로 동일 work ID 재현은 불가능하다. 동일 고객의 남은 얼음정수기 작업 또는 별도 QA 작업을 사용한다.
