## 경쟁채널 분석 확정 (2026-06-07)

채널 "로보, AI 활용해서 살아남기" — 추정 월매출 ~4,000만원, 17개 VTT 자막 전수 분석.

**수익 모델 (확정)**
- 4가지 자동화 시스템 강의: 네이버API종목분석 / 종목선별기(75%백테스트) / 유튜브자동요약 / AI프롬프트모음
- 1:1 코칭 (피드백)
- 카카오 단톡방 DB 수집 → 강의 판매 퍼널
- 무료 프롬프트/뉴스봇 추첨으로 신뢰 구축

**수익 계산식**: 강의 30만원×100명 + 커뮤니티 10만원×100명 = ~4,000만원

**우리와 차이**:
- 로보: ChatGPT에게 "어떻게 물어볼까"를 판다 (방법론)
- 우리: 물어볼 필요 없는 시스템 결과(수급 신호)를 판다 (결과물)

**핵심 대사**: "로보는 ChatGPT한테 이렇게 물어보세요를 알려줍니다. 저는 ChatGPT한테 물어볼 필요 없는 시스템을 보여드립니다"

**Why:** 경쟁사 수익 구조 완전 역설계 → 우리 채널이 어느 포지션에서 더 강한지 명확화. 심화 트레이더 타겟 = 경쟁 없는 블루오션.

**How to apply:** 영상 제작 시 로보 레퍼런스를 기준으로 1:1 디벨롭 버전 만들기. 파일: `channel/yt/영상제작_플랜_로보벤치마킹.md`
