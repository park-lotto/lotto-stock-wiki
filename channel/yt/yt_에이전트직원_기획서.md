## 리서치에서 뽑은 핵심 법칙

떡상 영상들이 공통으로 쓰는 패턴:

```
법칙 1. 결과를 먼저 보여준다 — 설명은 그 다음
법칙 2. "나도 평범했다" 공감 포인트 — 동일시 유발
법칙 3. 실제 화면 데모 필수 — 추상적 다이어그램 X
법칙 4. "오늘 이 영상에서 전부 공개" — 끝까지 볼 이유 제공
법칙 5. 마지막은 여운 — 다음 편 기대감으로 끝냄
```

이 채널에서 유리한 점:
- 해외 AI 직원 영상은 많지만 **국내 주식 리서치에 적용한 실사례는 없음** → 독점 포지션
- 실제로 동작하는 스크립트들이 이미 있음 → 데모 영상 찍을 수 있음
- 주식 20년 경력 → 신뢰도 기반 있음

## 썸네일 공식 (리서치 기반)

떡상 영상 공통 공식: **[결과 숫자/이미지] + [잠/수면] + [임팩트 단어]**

```
[안 A]
배경: 어두운 방, 자는 사람 실루엣
텍스트: "직원 10명"  (크게)
서브:   "내가 자는 동안"  (작게)
포인트: 화면 한쪽에 실제 브리핑 알림 떠있는 폰

[안 B]
배경: 터미널 코드 화면 (녹색 텍스트)
텍스트: "새벽 4시"  (크게)
서브:   "이미 다 끝나있었다"  (작게)
포인트: 시계 04:00 이미지

[추천: 안 A]
이유: 인물(잠든 사람) + 숫자(10명) + 감정(대비) = CTR 최고 공식
```

```

```

조회수 폭발한 이유 = 첫 문장에 결론이 있어서.
설명을 먼저 하면 이탈. 결과를 먼저 보여주면 "어떻게?"로 유지.

## 3편 시리즈 구조

```
1편 (이 영상): "자는 동안 직원 10명이 분석한다" — 개념 + 데모
                ↓ 궁금증 생성: "어떻게 만들어?"
2편:           "실제 설계 공개 — 총괄이 직원한테 어떻게 지시하나"
                ↓ 욕구 생성: "나도 쓰고 싶다"
3편:           "이 시스템 쓰는 법" — STOCK BRAIN 오픈
```

매 영상이 자연스럽게 다음으로 연결.
3편에서 서비스 전환.
