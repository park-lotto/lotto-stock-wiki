## 0. 시작 전 — 반드시 먼저 할 것

```
□ py tools/find_work.py <주제어>        ← 과거 대본·핸드오프 찾기 (0순위-A2)
□ 직전 편 대본 읽기                      ← 톤·금지선·이미 쓴 소재 파악
□ 프로그램 실제 변경 이력 실측            ← 기억으로 기능 자랑하면 없는 걸 자랑한다
     git log --since=<직전편 날짜> --pretty=format:"%ad|%s" --date=short -- shopping_shorts/
□ 썸네일 먼저 확인                       ← 썸네일이 대본 방향을 정한다 (아래 §3)
```

⚠️ **기능은 반드시 git log로 확인한다.** 1편→2편 사이 커밋이 1,138건이었다.
메모리·핸드오프에 적힌 기능은 그 사이 바뀌었을 수 있다.

## 1. 산출물 3종 — 세트로 만든다

| # | 파일 | 용도 | 원본(복사해서 쓸 것) |
|---|---|---|---|
| ① | `out/<제목>_대본.md` | 정본 텍스트 | `out/숏템하우스_2편_대본.md` |
| ② | `out/<제목>_대본.html` | **수정 모드** — 사장님이 직접 고침 | `out/숏템하우스_2편_대본.html` |
| ③ | `out/<제목>_녹화콜시트.html` | 녹화 중 타이머·체크리스트 | `out/숏템하우스_2편_녹화콜시트.html` |

추가로 필요하면 `out/<제목>_자료화면_수집목록.md` (모아야 할 자료 우선순위).

**전부 바탕화면에도 복사한다** (`feedback_deliver_outputs_to_desktop`).

### ② 수정 모드 HTML — 반드시 들어갈 기능
- 대사·화면·자막 전부 `contenteditable`
- `localStorage` 자동저장 (창 닫아도 유지)
- 고친 블록에 **`수정` 배지**
- **수정본 뽑기** — 바뀐 곳만 `바뀐 내용` / `<원래>` 나란히 마크다운 추출 → 복사 → Claude에게 전달
- `.md 내려받기` · `원본으로` 복원
- `<meta charset="utf-8">` **필수** (없으면 한글 전부 깨진다 — 2026-08-19 실제로 겪음)

### ③ 녹화 콜시트 — 반드시 들어갈 기능
- 큰 타이머 + **[시작] / [구간 완료] / [리셋]** (스페이스바 = 구간 완료)
- 구간별 **목표 시간** · 초과하면 타이머 빨갛게
- 클릭 순서 체크박스 · **`필수` 표시**(놓치면 그 기능 자랑을 못 하는 것)
- 구간 완료 시 **랩타임 자동 기록 → 합계 → 복사용 텍스트**
- 녹화 전 세팅 체크리스트
- 구간별 촬영 팁 (예: "작은 UI는 2~3초 멈춰라 — 확대할 프레임이 필요하다")

## 2. 설득구조 7단계 — 이 골격을 벗어나지 않는다

| 단계 | 내용 | 핵심 |
|---|---|---|
| **1 문제 인식** | 시청자가 겪는 손해·불편을 **눈에 그려질 만큼 구체적으로** | 막연한 공감 ❌. "저장 100개, 올린 건 몇 개입니까" |
| **2 일반적 해결책** | 시청자가 이미 아는 해결책을 **먼저 인정**하고 **진짜로 다 알려준다** | ★이걸 빼면 즉시 광고가 된다. 가치 선지급 |
| **3 그 해결책의 한계** | 왜 현실에서 안 먹히는지 **구조적으로** | "아, 그래서 내가 안 됐구나" 납득 |
| **4 해결의 방향** | 내 제품 ❌ → **범주/방향**을 먼저 깐다 | "더 좋은 강의가 아니라 도구가 필요하다" |
| **5 다른 대안 배제** | 같은 범주 안 다른 선택지를 **구조로** 걷어낸다 | ★승부처. "그럼 다른 것도 있잖아"를 미리 차단 |
| **6 내 아이템** | 그래서 답은 이것뿐 — **여기에 시간을 몰아준다** | 10분 영상이면 **5분 이상** |
| **7 CTA** | 다음 행동을 **아주 쉽게** | "구매하세요" ❌ → "레퍼런스 하나 담아보기" |

### 시간 배분 원칙
- **1~5단계 합계를 3분 안에 끊는다.** 앞이 길면 이탈한다.
- **6단계에 절반 이상.** 이게 본체다.
- 페인포인트(1단계)는 **짧고 정확하게** 치고 빠진다. 길게 늘어놓지 않는다.

### 관통 키워드를 하나 정한다
2편은 **"왕복"**이었다. 3단계에서 문제로 등장 → 5단계에서 대안 배제 근거 → 6단계에서 "그걸 없앴다"로 회수.
**한 단어가 세 번 돌아오면 설득이 단단해진다.**

## 3. 썸네일이 대본을 정한다

썸네일이 먼저 확정되면 **거기 적힌 약속을 대본이 갚아야 한다.** 회수표를 대본 상단에 박는다.

| 썸네일 요소 | 대본에서 |
|---|---|
| 상단 미끼 카피 | 1단계 문제 인식의 각도를 결정 |
| 큰 숫자(`10분` 등) | **오프닝 45초 안에 반드시 언급** |
| 결과물 화면 | **첫 30초에 실물로 보여준다** |
| "내가 만든" 류 문구 | 6단계 진입 직전 개발 장면 한 컷 |

⚠️ **썸네일에 실제가 아닌 수치(좋아요·매출 등)가 들어갔다면, 영상 안에서 그 숫자를 주장하지 않는다.**
썸네일은 그대로 쓰고, 영상에서는 실제 결과물로 대체한다.

## 4. 금지선 — 예외 없다

```
🚫 금액 언급        — 강의 가격·프로그램 결제액 등 (분쟁 소지, 없어도 설득된다)
🚫 결제·이체 내역 제작 — 위조 증빙. 확대하면 들킨다. 걸리면 영상 전체가 거짓말이 된다
🚫 경쟁 제품 화면·이름 — 약관·분쟁 리스크. 화면 없이 '구조'만 지적하면 더 세다
🚫 가짜 수익창·없는 지표
🚫 동의 안 받은 후기
🚫 타 채널명·로고·얼굴 노출 — 전부 블러. 저격 아닌 '유형'으로
```

**대안 배제(5단계)는 지목하지 않는 쪽이 강하다.** 시청자가 자기가 써본 것을 알아서 대입한다.

## 5. 녹화 원칙

```
□ 녹화 = 화면 조작만. 말하지 않는다
    음성은 나중에 따로 (일레븐랩스 v3 · Liam · 안정성 Robust · 블록 통째 생성)
    → 문단 쪼개면 목소리가 튄다. 상세: handoff/AE영상제작.md
□ 제품 시연은 원테이크로 쭉 찍고 잘라 쓴다
    끊어 찍으면 "이어붙인 것"처럼 보여 딸깍 주장 자체가 약해진다
□ 로딩은 멈추지 말고 기다린다 → 편집에서 배속(×8 표시)
    완전히 잘라내면 "속인 것"처럼 보인다
□ 실수해도 멈추지 말고 진행 → 그 구간만 나중에 잘라낸다
□ 콜시트 창은 녹화 영역 밖(듀얼모니터·폰)
□ 작은 UI 앞에서 2~3초 멈춘다 — 나중에 줌인+빨간박스로 키울 프레임이 필요하다
```

### 녹화 전 세팅 (콜시트에 넣을 것)
알림 끄기 · 북마크바·확장 정리 · 창 크기·배율 고정 · **고객이 보는 계정**(관리자 메뉴 금지) ·
만들 제품 미리 정하기 · 개인정보 화면 확인 · 마우스 커서 표시 ON

## 6. 수치는 실측으로만 박는다

대본 초안의 시간·건수는 **전부 가안**이다. 녹화하면서 재고 그 값으로 교체한다.

```
□ 제작 소요시간   → 콜시트 타이머 실측 (더 느려도 정직하게 그 숫자)
□ 수작업 소요시간  → 정석 과정 재현하며 초시계 측정
□ 개선 건수       → git log로 실측
□ 근거 없으면      → 숫자를 빼고 "해보신 분들은 아신다"로만
```

**어림수 금지** (0순위 규칙).

## 7. 작업 순서

```
1. find_work.py + 직전 편 대본 + git log 실측
2. 썸네일 확인 → 회수표 작성
3. 7단계 매핑 + 시간 배분 → 사장님 승인
4. 대본 .md 작성
5. 대본 .html (수정 모드) + 녹화 콜시트 .html 생성
6. ★브라우저에서 실제로 열어 확인 (charset·타이머·저장·추출 동작)
7. 바탕화면 복사 → 사장님께 전달
8. 사장님 수정본 받아 반영
9. 녹화 → 실측값으로 수치 교체
10. handoff/유튜브제작.md + wiki/log.d/유튜브제작.md 기록
```

⚠️ **6번을 건너뛰지 마라.** 정적 검토는 관찰이 아니다. 2편 때 charset 누락으로 한글이
전부 깨진 것을 브라우저로 열어봐서 발견했다.
