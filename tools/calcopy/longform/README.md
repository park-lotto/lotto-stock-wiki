# 숏클 지식롱폼 프리셋

시사·경제를 숫자로 풀어 주는 가로 롱폼(1920×1080, 11~14분) 제작 꾸러미다. 기준작은 `예시/`의 GDP 착시 편(11분 51초, 사장님 합격 2026-11-02)이다.

## 시작 전

`python -X utf8 preflight.py` 가 전부 통과해야 시작한다. 고객 키는 환경변수 또는 `~/.shortem/keys/<이름>` 에 둔다.

| 키 | 쓰는 곳 |
|---|---|
| `typecast` | 나레이션 |
| `pixabay` | 실사 영상 |
| `gemini` | 그림 (유료 등급 필요할 수 있음) |
| `typesafe` | 소재 판정 |

## 제작 순서

1. **채널 설정:** `python -X utf8 apply_style.py <설정.json>` → 작업 폴더 `config.json`
2. **소재:** 후보를 파일로 쓰고 `jev_screen.py` 로 판정 (`지침/소재.md`)
3. **사실기록:** `사실기록.md`. 대본의 모든 사실은 여기서만 나온다
4. **대본:** `대본.md` (`지침/대본.md`)
5. **녹음:** `tts.py 대본.md narr` (숫자는 `numread.py` 가 소리로 바꾼다)
6. **샷:** `shots.py` (`지침/화면.md`)
7. **재료:** `stock.py` → `gen_images.py`
8. **렌더 전 확인:** `shot_sheet.py` 로 전 샷을 보고 안 맞는 재료를 뺀다
9. **타임라인과 샘플:** `render.py timeline` → 앞 25초만 구워 소리까지 확인
10. **렌더:** `render.py video-gpu 6` → `render.py mux`
11. **납품 전 검수:** `지침/검수.md`

막히면 멈추기 전에 `막힘대응표.md` 를 본다.

## 폴더

| 위치 | 내용 |
|---|---|
| 이 폴더 | 코드, 글꼴, 음악, 효과음 |
| `styles/` | 고를 수 있는 색 묶음 |
| `지침/` | 소재, 대본, 화면, 숫자 읽기, 검수 |
| 작업 폴더(`LONGFORM_WORK`) | 편마다 대본, 샷, 녹음, 재료, 결과 |
