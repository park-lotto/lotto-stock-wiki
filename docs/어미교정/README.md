# 대본 어미·문장연결 교정 — 예시 대량생산 (2026-08-05)

## 왜 하는가

사장님 지적: 뽑은 대본 3개가 **어미가 밋밋**하다.
`~하더라고요 / ~돼요 / ~되죠`만 돌려쓰고, **문장을 뚝뚝 끊어 써서** 광고 문구로 들린다.
원하는 결: `~하더라고요` `~되는 거 있죠?` `~했다니까요?` 가 섞이고 문장이 이어질 것.

## 원인 (실측)

1. **부품은행 어미 과포화** — 서버 `pattern_item` bucket='ending' 상위:
   `~거든요(84) / ~하더라고요(74) / 하더라고요(69) / ~더라고요(38) / ~더라구요(18)`
   → **같은 어미가 표기만 달라 5개로 중복 등록, 합계 203회.**
   프롬프트가 "은행에서 골라 써라"라 대본이 `~더라고요` 범벅이 되는 게 당연.
2. **비트당 21자** — 한 비트=한 문장이라 끊김이 구조적으로 강제됨(예: 9비트 192자).
3. 프롬프트에 말투 지시가 `edit_plan.py:1996` 한 줄뿐
   ("말투는 옆에서 썰 푸는 구어체. 어떻게 살릴지는 네가 판단해라").

(`remote_dump.py`), 사장님이 손본 대본 1개를 기준점으로 삼아 교정을 반복했다.

### 각 차수에서 배운 것 (되풀이 금지)

- **1차**: `~더라고요` 쏠림은 잡혔으나, 기준점이 러프 1개뿐이라 그 표현을 전부 복사.
  실측: `~것 같아요 21 / ~거 있죠 18 / 보내드릴게요 37`.
- **2차**: 위 3개를 제한 → 잡힘(`4 / 5 / 1`). **그러나 `~더라고요`가 16→30으로 악화.**
  원인: 대안 목록에 `~더라구요`·`~더라니까요`를 **예시로 적어준 것**.
  ★교훈: **금지하면서 같은 화면에 예시로 주면 예시가 이긴다.**
  (CLAUDE.md·`edit_plan.py:1935~1988`에 두 번 기록된 "규칙끼리 이긴다"와 같은 실패)
- **3차**: 사장님 2차 피드백(아래) 반영 → 통과 32/40으로 최고.

## ⏭ 다음 세션에서 할 일 (4차 교정)

3차 결과에서 **새로 생긴 결함 3개**를 잡는다. `repair3.py`를 복사해 `repair4.py`로:

1. **★명사끊기가 CTA 뒤에 붙어 문장이 미완성으로 끝남** (25·27·28·29·31번)
   - 잘못: `"댓글에 '김밥' 남겨주세요. 그 비법!"` ← 순서 뒤집힘
   - 맞음: `"하루 종일 쫀득한 김밥을 만드는 그 비법! 댓글에 '김밥' 남겨주세요."`
   - 프롬프트에 **"명사끊기는 반드시 CTA 앞"**을 명시할 것.
2. **마크다운 별표가 본문에 복사됨** (34·36·40번의 `**이 제품!**`)
   - 원인: 내가 프롬프트에 `**이것!**`로 강조 표기 → 모델이 본문에 그대로 복사.
   - ★프롬프트 예시에서 `**` 제거할 것. TTS가 "별별이 제품"으로 읽는다.
3. **"보이시죠" 14회로 굳음** — 화면 지목 표현을 흩을 것
   (보세요/보이시죠/저거 보이세요/화면 보세요/이거 좀 보세요 …).
4. 길이 이탈 8건(0.73~1.44배) — 프롬프트 말고 **후처리 검증으로 초과분만 재교정**.
