# 칼카피 시작 문서 — 세션을 열면 이것부터 (살아 있는 문서)

> **이 문서의 규칙(사장님 2026-10-18)**: 칼카피를 열면 가장 먼저 이 문서를 읽고 시작한다.
> 내용이 바뀌면 **그 자리를 고친다**(밑에 덧붙이지 마라). 옛 내용·중복은 **지운다**. 날짜 이력은 `handoff/칼카피숏템엔진.md`(일지)와 git 이 가진다.
> 이 문서 = "지금 사실" 한 장. 숫자는 실측만, 확인한 날짜를 옆에 적는다.
> 마지막 갱신: 2026-10-18 (CH PC)

## 0. 시작 순서 (매번)
1. `py tools/track.py use 칼카피숏템엔진` → 작업은 전부 `.tracks/칼카피숏템엔진` 안에서(관제 카드 **097**, 브랜치 `track/칼카피숏템엔진`).
2. 이 문서 → 아래 '지금 할 일' → 필요한 절만 `handoff/칼카피숏템엔진.md` 에서 찾아 읽기(`py tools/find_work.py <주제>`).
3. `git -C .tracks/칼카피숏템엔진 status --short` — **다른 세션이 같은 폴더에서 작업 중일 수 있다**(10-17 얜샷템 하이브리드). 내 파일만 경로 지정해서 add, `git add -A` 금지.
4. 탭 제목 `py tools/session_title.py set "<하는 일>"`.
5. 끝날 때: 이 문서 고치기(바뀐 사실만) → handoff 일지 몇 줄 → `wiki/log.d/칼카피숏템엔진.md` 1줄 → 커밋 → `git push origin HEAD:track/칼카피숏템엔진`.
   ⚠ **`track.py finish` 금지**(통째 병합하면 `shopping_shorts/` 68파일 — 고객 영상 라인까지 라이브로 간다). 라이브가 필요하면 그 부분만 떼어 새 트랙으로.

## 7. 워커·자동화
- **창고 워커**(소재 후보 찾기·점수, 채널 4: 썰풀다·yummyknow·방구석·핫템): `powershell -ExecutionPolicy Bypass -File tools/calcopy/engine/warehouse.ps1 start|stop|status`. 설명 `tools/calcopy/engine/README.md`. 코드 = 트랙 커밋본(`C:/숏템_칼카피/창고/code`, 커밋 바뀌면 따라감), 데이터 `C:/숏템_칼카피/창고`(DB·장부·로그), 채널 설정 `warehouse_channels.json`.
  - 한도: 제미나이 워커당 시간당 10 · 유튜브 4워커 합 시간당 300 · 429 → 30분 쉼. KPI `CALCOPY_DATA_DIR=C:/숏템_칼카피/창고 py tools/calcopy/engine/worker_ledger.py --hours 1`.
  - **상태(10-17 확인)**: 10-16 17:2x 페이블 지시로 정지(PC 과부하 — python 기동 28초·다운로드 90~240초). 장부 마지막 10-16 17:30, 24시간 활동 0.
  - **결함**: `status` 가 죽은 PID 를 살아 있게 표시(그 번호를 다른 프로세스가 씀). 켜기 전에 고칠 것.
  - 다른 분석(다운로드·제미나이)과 동시에 켜면 무료 키 429·과부하 — 큰 분석 끝난 뒤 켠다.
- **24시간 자동(설계 `docs/superpowers/specs/2026-10-15-칼카피엔진-design.md` §7)**: 보관함에 채널 → 서버 큐 → PC 실행기(유튜브는 서버 IP 막힘) → 단계 결과 반환. 판단 단계는 큐 작업, 클로드는 예약으로 새 세션이 주기마다 집어 감(한 세션 24시간 금지). **큐·실행기 미구현**(§6-6).
- 만들기 입구 `tools/calcopy/make.py`(후보 5줄까지 실물, 그 뒤 유튜브 시간 초과로 계획 시트 미확인).
- 관리 화면: 라이브 `/admin/calcopy` = 10-15 보관함(채널 4)만. 트랙에 탭 5개 '칼카피 홈'(미병합) → 다른 세션이 맡음(§1-5).
