# SEO 구조분석 → 애드센스 사업 로드맵 (design)

날짜: 2026-07-09
상태: 브레인스토밍 승인 완료, Phase 1 실행 전 대기(내일 이어서)

## 배경

잘 만들어진 구글 SEO 페이지들을 구조분석해서, 그 결과를 바탕으로 애드센스 광고 수익 사업을 시작하려 함. 니치는 아직 미정 — 구조분석 결과를 먼저 보고 정하기로 함. 로또의 주식 프로젝트와는 별개 사업이지만, 콘텐츠 자동생산 인프라(Gemini key_vault 등)는 재활용 가능성 검토.

## 확정된 전제

- **콘텐츠 언어**: 한국어 중심
- **콘텐츠 제작**: AI 자동생산 중심 (기존 `pipeline/atoms/key_vault.py` Gemini 파이프라인 재활용 검토)
- **플랫폼**: 워드프레스
- **운영 규모**: 파일럿 1개 사이트로 검증 후 확장 (바로 여러 니치 동시운영 안 함)
- **조사 도구**: 일단 무료 도구만 (구글검색·네이버데이터랩·무료 키워드툴). 유료 툴(Ahrefs 등)은 검증 후 필요시 재검토
- **구조분석 대상**: 직접 지정한 후보 사이트가 아니라, Claude가 여러 니치에서 상위노출·애드센스 붙은 페이지를 검색해서 샘플링

## 전체 로드맵

| 단계 | 내용 | 산출물 |
|---|---|---|
| 1. 구조분석 | 8개 니치 × 3~5개 사이트, 상위노출·애드센스 붙은 페이지 구조 조사 | 분석 리포트 + 니치 스코어카드 |
| 2. 니치 선정 | 리포트 기반 최종 1개 니치 확정 (사용자 결정) | 확정 니치 + 근거 |
| 3. 파일럿 사이트 구축 | 워드프레스 + 호스팅 + AI 콘텐츠 파이프라인 | 도메인 + 초기 글 20~30개 |
| 4. 애드센스 신청·승인 | 최소요건 충족 후 신청 | 승인 or 반려사유 대응 |
| 5. 검증(60~90일) | 트래픽·수익 데이터 관찰 → Go/No-Go | 판단 근거 데이터 |
| 6. 확장(조건부) | 검증되면 스코어카드 2·3위 니치로 파이프라인 복제 | 사이트 포트폴리오 |

## Phase 1 — 구조분석 (상세, 다음에 바로 실행 가능한 수준)

### 니치 후보 8개
1. 신용카드/정부지원금 혜택 정보
2. 부동산/청약 정보
3. IT·프로그램 활용팁
4. 레시피/요리
5. 여행지 정보
6. 육아/교육 정보
7. 반려동물 정보
8. 캠핑/인테리어 DIY

### 분석 체크리스트 (4개 층)

**페이지 구조/기술 SEO**
- 제목태그(H1~H3) 계층 구조
- URL 슬러그 패턴
- 스키마마크업(FAQ/HowTo/Article/Review) 사용 여부
- 내부링크·앵커텍스트 패턴, breadcrumb
- 목차(TOC) 유무
- 이미지 alt·최적화

**콘텐츠 전략**
- 평균 글자수
- 포맷(리스트·표·FAQ 섹션 구성)
- 키워드 배치(제목·소제목·본문 밀도)
- E-E-A-T 신호(저자정보·출처·업데이트 날짜)
- 시리즈/클러스터 구성 여부

**애드센스 배치/수익화**
- 광고 개수·위치(상단/본문중간/사이드바/하단)
- 광고 대 콘텐츠 비율, 반응형 여부
- 니치별 추정 CPC 대역(체감)
- 제휴링크 등 병행 수익화 여부

**사이트 전체 구조**
- 카테고리/사일로 구조
- 필러페이지 + 클러스터 서브페이지 연결 구조
- 내비게이션·푸터 링크, 사이트맵

### 실행 방식
니치당 1개씩 조사 에이전트를 병렬로 띄워 각 니치 상위노출 3~5개 사이트를 검색·분석 → 표준 체크리스트로 리포트 작성 → 취합 후 니치 스코어카드로 정리.

## Phase 2 — 니치 선정 스코어카드 (프레임워크)

4축 각 5점 만점으로 채점, 총점 상위 니치를 후보 제시 → 최종 확정은 사용자.

| 축 | 확인 내용 |
|---|---|
| 경쟁강도 | 상위노출 사이트 수·규모, 신규진입 난이도 |
| 추정 CPC | 니치 특성상 광고단가 대역 |
| AI콘텐츠 생산난이도 | AI가 사실오류 없이 자동생산 가능한 정도(YMYL일수록 어려움) |
| 애드센스 정책리스크 | 금융/건강 등 민감 카테고리 여부, 승인 반려 이력 사례 |

## Phase 3~6 — 개요 (니치 확정 후 상세 설계 예정)

- **Phase 3 (구축)**: 워드프레스 + 호스팅(기존 라이트세일 서버 재사용 검토) + AI 콘텐츠 파이프라인(Gemini key_vault 연동) → 필러페이지 3~5개 + 클러스터 글 20~30개
- **Phase 4 (신청)**: 개인정보처리방침·이용약관 페이지, 최소 콘텐츠량 확보 후 애드센스 신청
- **Phase 5 (검증)**: 60~90일 트래픽·수익 관찰, Go/No-Go 판단 기준(월 방문자 수·RPM 목표치) 사전 설정
- **Phase 6 (확장, 조건부)**: 검증되면 스코어카드 2·3위 니치로 파이프라인 복제

## 다음 세션 시작점

Phase 1 실행: 8개 니치 조사 에이전트 병렬 실행 → 리포트 + 니치 스코어카드 산출.
