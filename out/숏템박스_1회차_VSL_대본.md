# 숏템박스 런칭 VSL — 1회차 촬영 대본 (10분 임팩트판)

- **목적:** 1기 모집 · "무료 공략법" 포지션으로 신뢰 → 비밀·한정으로 회수
- **포맷:** 실루엣/음성변조 **인터뷰(서사)** + **화면녹화 데모(증거)** 교차편집
- **톤:** 짧은 `~다/~습니다` 단문으로 빠르게 밀어붙이기. [페인 자극 → 강점 → "우와 편하다"]. 언더그라운드("쉿, 아는 사람만"). **"놀랍습니다·미쳤습니다·굉장합니다"를 임팩트 지점마다 한 방씩.**
- **정직선:** 가짜 수익창 ❌ / '수천만원·5개 프로그램 결제' 과장 ❌ (단 **300만원 최고 강의 수강은 사장님 실경험 → 사용 OK**) / 증거 = **베타테스터 실제 반응**(구독자0 테스트채널 실조회수는 확보되면 추가) / 인터뷰는 사장님 실제 서사 범위 안에서만
- **길이:** ~10:00 (600초) · 컷 10개

### 🎬 편집 원칙 — 화면은 "빠르게 넘어가는" 게 기본
- **기본 리듬 = 0.5~1.5초 빠른 컷.** 한 문장 말하는 동안 화면 **2~3개**가 지나간다. **정지 화면 금지**(멈추면 흡수·이탈).
- 반복 **모티프 3종**을 계속 교차해서 뇌를 안 쉬게 한다:
  - 🅐 **빌드 몽타주** — 숏템박스가 **만들어지는 실제 장면**: 클로드 코드 터미널 폭포 스크롤, 대시보드에 기능이 하나씩 붙는 타임랩스, 밤→새벽 시계, 커밋/화면 갱신. → "직접 만들었다"를 눈으로 증명(아무도 안 보여주는 플렉스)
  - 🅑 **페인 짚기** — **실제 유튜브 쇼핑쇼츠 영상들** 위에 빨간 동그라미·화살표로 문제 지적(템플릿 똑같음/성우 티남/트렌드 지남/후킹 없음). **채널명·로고 가림, 저격 아닌 '유형'**
  - 🅒 **원클릭 데모** — 레퍼런스 담기 → 자동 생성 → 완성까지 화면녹화, **배속 + 클릭마다 하이라이트 링**
- 전환: 하드컷/휘프팬 위주. 트랜지션 효과는 최소. 자막은 **키워드 몇 단어만** 큼직하게 번인(문장 통째 X).
