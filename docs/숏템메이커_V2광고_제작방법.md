## 효과 목록

**배경 6종 (`V2_Bg.tsx`)** — 문단마다 돌려 쓰고 **같은 배경 연속 금지**. 어머니 영상이 배경이면 히어로로.
1. 기울어진 3D 벽 — 기둥이 엇갈려 흐름
2. 회전 고리 — 폰들이 원통 위에서 회전, 정면 하나가 빛남
3. 모자이크 줌아웃 — 한 칸에서 수십 칸으로
4. 히어로 — 영상 하나 가득 + 금·흑 듀오톤 + 빛 번짐
5. 분할 패널 — 세로 3칸이 차례로 열림
6. 오로라 — 금빛 그라데이션 + 빛 입자

**컷·글자 효과 (`V2_Engine.tsx`)**
- 컷 진입: 확 당겼다 놓기 + 흔들림 / 컷 경계 플래시 + 빛 줄기
- 집중선(큰 글자 뒤) / 불꽃 입자(터지는 순간)
- 숫자 카운트업(굴러가다 마지막 폭발) / 막대 그래프(마지막 막대 금색으로 터짐)
- VS 화면 분할(왼쪽 회색·빨강 X, 오른쪽 금색) / 단계 흐름(카드가 날아와 화살표로 연결)
- 네온 간판 글자 / 3D 플립 글자 / 글자 스타일 5종 순환
- 배경 형식: 영상 전체 / 폰 프레임 / 모니터 / 이미지

**증거 장면 (`V2_Fx2.tsx`, `V2_S47_Proof.tsx`)**
- 회원 쇼츠 벽(3D 면 위 기둥 5줄) · 회원 작품 갤러리(폰 12개 튀어 오른 뒤 카메라 훑기)
- 카톡 후기 원문 그대로(이름 가운데 ○) + 형광펜 구절
- 카톡방 메시지 차례로 올라오기 + 하트
- 실전 한 달: 실제 캡처의 날짜·조회수 그대로(8/28~9/20, 하루 1~3편), 점점 빨라지는 스크롤 + '매일' 카운터
- 캡처 확대 진입(나머지 어둡게) · 큰 숫자 + 설명 · 그래프 끝 급등으로 밀고 들어가기

**쇼츠 처리 (`V2_S1b.tsx`, `V2_S1_Open.tsx`)**
- 세로 쇼츠를 가운데 폰 모양으로, 뒤는 같은 영상 흐림
- 맨 위 채널 띠(높이 8.9%)를 금색 띠로 덮고, @워터마크(90~94.5%)는 흐림
- 오프닝: 두 작품 겹침 — 뒤는 무음, 앞은 원래 TTS 그대로
