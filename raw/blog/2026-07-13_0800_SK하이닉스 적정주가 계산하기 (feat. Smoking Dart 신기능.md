# SK하이닉스 적정주가 계산하기 (feat. Smoking Dart 신기능)































- **출처**: gunbaram 블로그















- **날짜**: 2026-07-13















- **링크**: [원문 보기](https://blog.naver.com/gunbaram/224344512642?fromRss=true&trackingCode=rss)































## 본문































[핵심 주장]  















- SK하이닉스 적정주가를 계산하기 위해 Smoking Dart의 "적정주가 시뮬레이터" 기능을 활용할 수 있다고 지적  















- 기본 모델은 가정한 PER, 매출 성장률(158%→50%→1%), 순이익률(70%→63.5%→61%) 기반으로 3년 후 예상주가를 산출하며, 전문가형 모델은 원가율/판관비율/고정비율 등을 추가로 고려할 수 있음  















- 컨센서스 기준 기본 모델을 사용해 계산한 적정주가는 441,800원으로 제시  































[근거 및 데이터]  















- 기본 모델 예측: 3년간 매출 성장률 158%→50%→1% / 순이익률 70%→63.5%→61% 적용  















- PER 기준 3배→13배 감소 시 적정주가 변화 수치 제시  















- 전문가형 모델은 BULL/BASE/BEAR 시나리오별 매출 성장률, PER/PSR/PBR 모델, 자사주 소각률 등을 변수로 입력 가능  















- 컨센서스 기준 PER 10배 가정 시 441,800원의 적정주가 도출  































[투자 시사점]  















1. 적정가 모델링 시 다양한 시나리오(성장률/PER/비용 구조)를 직접 입력해 실적 감도 분석 가능  















2. 기본 모델의 예측치(441,800원)는 보수적 가정에 따른 것이며, 시장 전망/원재료 가격 변동 등 외부 요인 반영 시 실제 주가와 차이가 발생할 수 있음
