# 얜샷템 하이브리드 — 키치잇판 설계 (2026-10-18, 관제 097)

잇썸홈판(두유노 결·박창수)·재미썸홈판(이븐쇼핑 결·박창수) 옆에 **세 번째 판**. 하이브리드 뼈대(연예인 원음 훅 → "저 영상 보고 나도" → 써 보니 좋다 → 사회 반응, CTA 없음 — `tools/calcopy/hybrid/briefs/script.md`·`channel/칼카피_시작.md` §12)는 그대로 두고, **겉옷(대본 말투·박자·틀·자막·장면·소리·목소리)을 키치잇으로** 바꾼다. 근거 = `channel/kitchit/스타일분석.md`.

## 1. 대본 결
- **박자**(키치잇 8편 꼴 + 하이브리드 뒤): `N 훅(전언 의문 1줄)` → `O 원음 증언` → `N 질문 1줄('대체 어떻게/어떤 ~길래?')` → `O 원음 답(디테일)` → `O 원음 한마디(평)` → **이음** `N "저도 보자마자 따라 ~ 봤는데요,"` → `N 와우·비유(감상)` → `N 권위 전언('~대요')` → `N 사회 반응 끝('~난리래요'·'~말 다 했죠')`.
- 나레 줄 6줄 안팎, 줄당 1.2~4초. 앞(훅~원음) 12~14초 · 뒤(하이브리드) 12~14초 → **전체 25~28초**(벤치 단독은 10~21초 — 뒤 판매 이야기만큼 길다).
- 어미: 앞 = 전언 의문('~다네요?'·'~다고?'·'~길래?'), 뒤 = 해요체 전언('~더라고요'·'~대요'·'~래요'). 키치잇 끝맺음 '~말 다 했죠'도 가능(사회 반응 줄일 때).
- 지킬 것(얜샷템 §12 그대로): 1인칭 체험은 '따라 사 봤는데/따라 끓여 봤는데' 꼴, 효능·질병 말 금지, 권위자 말은 전언으로만, 연예인이 인정 안 한 것은 인정했다고 안 쓴다, CTA 없음.
- 예시 1편 = `channel/kitchit/하이브리드_성시경/대본.json`(성시경 신라면):
  | 줄 | 글 | 종류 |
  |---|---|---|
  | N1 | 가수 성시경이 신라면 1등 레시피를 따라 해 봤다네요? | 나레 훅 |
  | O1 | (근데) 신라면 제일 맛있게 끓이기 1등한 레시피가 있길래 | 원음 |
  | N2 | 대체 어떻게 끓이길래? | 나레 질문 |
  | O2 | 끓이다가 면 빼서 그 면을 참기름 다진 마늘에다 비벼요 | 원음 답 |
  | O3 | 분명히 되게 고급스러워집니다 | 원음 한마디 |
  | N3 | 저도 보자마자, 따라 끓여 봤는데요, | 이음 |
  | N4 | 참기름 마늘 향이 확 올라오는 게 진짜 중국집 요리 같더라고요. | 와우·비유 |
  | N5 | 게다가 신라면은 1991년부터 한 번도 1위를 안 놓쳤대요. | 권위 전언 |
  | N6 | 그래서 요즘 라면 좋아하는 사람들 사이에서 이 레시피가 난리래요. | 사회 반응 끝 |

## 2. 틀
- 검정 바탕 · 제목 1줄 흰 **기울임** Jalnan2 79 · 2줄 **노랑 박스 `#FDE600` x42~1037 y269~399 + 검정 글** Jalnan2 77 · 영상 창 **1080×1080 y420** · 창 왼쪽 위 로고 **'얜샷템'**(벤치 '키치잇' 자리·크기, 회색+진회색 테두리) · 창 아래 **'출처: <원본 채널>'** 회색 y1535.
- 제목 꼴: 1줄 = 인물+대상 느낌표('성시경 신라면 1등 레시피!'), 2줄 = 반전 질문('면을 따로 비빈다고?'). 숫자: `channel/kitchit/preset/kitchit_frame.json`. 기록 프리셋 `channel/kitchit/preset/검정창_노랑박스제목/`.

## 3. 자막
- 자막팩 키치잇(`channel/kitchit/자막팩_보강안.json` pack.kitchit): 흰 Jalnan2 73 · 검정 외곽선 0.10em + 흰 바깥 0.03em · 덩어리 하나에 강조 낱말 하나(5색 돌림) · 줄 첫 덩어리 `kitchitPop` · 원음 핵심 한 덩어리 `kitchitTyping`(+♥) · 고급·부(富) 낱말에 💎.
- 대본 줄마다 `caps`(덩어리·강조 낱말·스티커·타이핑) → 렌더가 `자막표.json` 으로 시각을 붙인다.

## 4. 장면
- 컷 중앙 1.0~1.3초, 나레 줄은 1~1.4초마다 새 컷(줄 길이를 컷 수로 나눔), 원음 줄은 원본 그대로(입 맞음, 원본 장면 바뀜에서 자르고 조각마다 얼굴 크롭).
- 첫 프레임·훅 = 연예인 얼굴(YuNet 검사 `thumb.face_check`). 뒤 하이브리드 = 그 제품만(조리·봉지·그릇).
- 컷마다 천천히 밀기(줌 3~6%) · 나레↔원음 바뀌는 자리에 **흰 번쩍임 0.1초**(벤치 BRa 19초·_Wa).
- 원본 박힌 자막·남의 글자 = 크롭 밖(성시경 원본 y≥840 → 정사각 변 835·y0).

## 5. 소리
- BGM 0초~끝 경쾌·발랄(이 편 `qiuqiu`, 벤치 곡은 미식별) · 원음 줄에서 −6dB · 끝 0.4초 페이드.
- 효과음 적게(벤치 편당 0~3발): 0초 '띵' + 나레↔원음 바뀌는 자리 '휙'(벤치 BRa 3.4·Cs-Ka 1.6/11.2 = 바뀌는 자리).
- 전체 **−16 LUFS**(벤치 중앙 −16.0), TP −1.5.

## 6. 목소리
- 일레븐랩스 **미나 `kr-mina-expressive`**(`tools/calcopy/mina_tts.py` 서버 합성) — 벤치 나레(여자·밝은·F0 285~313Hz)와 같은 결. 나레 전부 한 번에 합성 → 문장 경계(alignment)로 자르고 앞뒤 무음 깎기 → atempo **1.35**(서비스 미나 규칙) → 6.1~7.7자/초(벤치 6.8~7.5).
- ★받아쓰기로 이름·낱말 확인 필수: 이 편 1차 '성시경이'→'농심 경영진이'·'심지어'→'유재석 씨라면은'·'중식당'→'정식당'(2모델) 오독 → '가수 성시경이,'·'게다가'·'중국집'으로 3차 합성 뒤 통과(전체 소리 한 번에 2모델 받아쓰기 — 줄 조각 받아쓰기는 앞뒤가 잘려 오독이 많다).

## 7. 만드는 길(지금)
`channel/kitchit/하이브리드_성시경/` 전용 렌더(`render_kitchit.py`, 시각 주인 `timeline()`) → `base_nocap.mp4` + `자막표.json` → (지휘자) 자막팩 키치잇으로 자막 입히기 → 바탕화면·드라이브. 다른 편으로 넓히려면 대본.json·재료.json·fetch.py 만 바꾸면 된다(렌더는 편 이름 상수 `OUT` 한 곳).
