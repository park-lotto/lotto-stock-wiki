# 채널 원본 실측 도구 (2026-09-25, 뜨거운사람들 10편에 사용)

표본 mp4(1080×1920)를 한 폴더에 받고 **그 폴더에서** 순서대로 돌린다(`PYTHONUTF8=1 python <스크립트>`).
좌표(슬롯 483~1273, 자막띠 1272~) 는 뜨거운사람들 기준 하드코딩 — 다른 채널은 rows.py 결과로 바꿔라.

| 스크립트 | 재는 것 | 출력 |
|---|---|---|
| rows.py | 영상 슬롯 y/x, 위아래 글자 띠 (24프레임 비흰색 비율) | rows.json |
| hl.py | 헤드라인 영역 글자가 언제까지 보이나 (2fps) | 콘솔 타임라인 |
| cuts.py | 슬롯 컷(scene>0.3)·자막 교체 시점(자막띠 차분) | cuts.json |
| sheet.py | 편마다 헤드라인+자막 전부를 한 장으로(사람/모델이 판독) | sub_<id>.png |
| lines.py | 자막 줄 수·줄 폭·시작 y·형광펜 빈도 (전수) | 콘솔 |
| color.py | 배경·형광펜·강조색 | 콘솔 |
| font.py / font4.py | 자막 잉크를 후보 글꼴 렌더와 IoU 대조 / 나란히 그림 | 콘솔 / font_grid.png |

★글꼴은 IoU 숫자만 믿지 마라 — font4.py 그림으로 획 모양을 눈으로 같이 봐라(2026-09-25: IoU 1위 주아도 굵기가 달랐다).
