# 발음 제보함 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 제작소 비트에서 어색한 발음을 코멘트와 함께 제보하면 작업대 제보함에 쌓이고, 거기서 몰아 교정한다. 전부 관리자 전용.

**Tech Stack:** FastAPI, SQLite(Store), vanilla JS, 기존 `_require_admin`·`window.IS_ADMIN`.

## Global Constraints

- 코드 작업은 전부 `.tracks/보이스/...` 절대경로. main 폴더 코드 금지. git은 `git -C .tracks/보이스`. `git stash` 금지(워크트리 공유 스택).

```python
                CREATE TABLE IF NOT EXISTS pron_reports (
```

그리고 Store 클래스에 메서드 3개 추가(기존 `get_setting`/`set_setting` 근처, `self._conn()` 패턴 그대로):
```python
    def add_pron_report(self, text, comment, created_at):
        """발음 제보 1건 저장. 신규 row id 반환."""
        with self._conn() as c:
            cur = c.execute(
                "INSERT INTO pron_reports(text, comment, created_at) VALUES(?,?,?)",
                (text, comment or "", created_at),
            )
            return cur.lastrowid

    def list_pron_reports(self, include_resolved=False):
        """제보 목록(최신순). 기본은 미처리(resolved=0)만."""
        q = ("SELECT id, text, comment, created_at FROM pron_reports "
             + ("" if include_resolved else "WHERE resolved=0 ")
             + "ORDER BY id DESC")
        with self._conn() as c:
            rows = c.execute(q).fetchall()
        return [{"id": r[0], "text": r[1], "comment": r[2], "created_at": r[3]} for r in rows]

    def resolve_pron_report(self, report_id):
        """제보를 처리됨으로 표시(resolved=1)."""
        with self._conn() as c:
            c.execute("UPDATE pron_reports SET resolved=1 WHERE id=?", (report_id,))
```
> 주의(실행자): `_conn()`이 컨텍스트매니저로 커밋까지 하는지 기존 `set_setting` 구현으로 확인하고 동일 패턴을 따를 것. `lastrowid`는 `with self._conn() as c` 블록 안에서 읽어야 유효하다.

```javascript
function pronReport(btn, i){
  const beats = window.__beats || [];
  const b = beats[i]; if(!b) return;
  const text = b.narration || b.text || '';
  // 버튼 자리에 인라인 미니폼(프롬프트 아님)
  const wrap = document.createElement('span');
  wrap.innerHTML = `<input placeholder="코멘트(선택)" style="width:140px"> `
    + `<button>보내기</button> <button>취소</button>`;
  const [inp, send, cancel] = wrap.querySelectorAll('input,button');
  btn.replaceWith(wrap);
  cancel.onclick = () => wrap.replaceWith(btn);
  send.onclick = async () => {
    send.disabled = true;
    try{
      const r = await fetch('/api/pron/report',{method:'POST',headers:{'Content-Type':'application/json'},
        body:JSON.stringify({text, comment: inp.value})});
      wrap.textContent = r.ok ? '✓ 제보됨' : '제보 실패';
    }catch(_){ wrap.textContent = '제보 실패'; }
  };
}
```

```javascript
let plReports = [];
async function plLoadReports(){
  try{
    const j = await (await fetch('/api/pron/reports')).json();
    plReports = j.reports || [];
  }catch(_){ plReports = []; }
  ri_list.innerHTML = plReports.length
    ? plReports.map((r,i)=>`<div style="margin:4px 0;padding:4px;border-bottom:1px solid #eee">
        <b>${esc(r.text)}</b> <span style="color:#888">${esc(r.comment||'')}</span><br>
        <button onclick="plReportPick(${i})">이 문장 교정</button>
        <button onclick="plReportResolve(${i})">✓ 처리됨</button></div>`).join('')
    : '<span style="color:#999">제보 없음</span>';
}
function plReportPick(i){
  const r = plReports[i]; if(!r) return;
  pl_text.value = r.text;
  document.getElementById('pron-lab').scrollIntoView({behavior:'smooth'});
}
async function plReportResolve(i){
  const r = plReports[i]; if(!r) return;
  await fetch('/api/pron/reports/'+r.id+'/resolve',{method:'POST'});
  plLoadReports();
}
```
