# 인스타 대본 패턴화 — 다이소축 (2026-08-19)

사장님 지시: **"유튜브 천재시리즈처럼 인스타도 패턴화시키고 거기서 변형을 주면
장면매칭도 쉬울 거야."**

## 🏠 집에서 이어하는 법

```
git pull                                  # main 폴더에서
py tools/track.py start 인스타대본스파인      # 폴더 없으면
"인스타 대본 스파인 이어서"                   # 라고만 하면 된다
```

**미커밋 0 · 미병합 있음(`finish` 안 했다 — 작업이 진행 중이라 일부러 안 했다).**
트랙 브랜치 `track/인스타대본스파인`에 전부 push돼 있어 유실 없음. 단 **라이브엔 안 갔다.**

### ⏭ 바로 할 일 — 장면 근거 게이트 (설계까지 끝났다)

사장님 마지막 지적: **"장면에도 없는 대본이 나오는 거 아닌가"** → **실측해보니 맞았다.**

```
슬롯을 두 종류로 가른다:
  [보여줘야 하는 것]  사용법 · 적용대상 · 적용대상2 · 적용대상들 · 불편함
      → 장면 인벤토리(scene_desc)에 근거가 없으면 그 값을 버리고 다음 후보로
  [말로만 하는 것]    효과 · 수치 · 차별점 · 가격
      → 면제 (원래 화면에 못 찍는다)

붙일 자리: spine_fill.fill() 다음. slots를 거른 뒤 조립한다.
값이 하나도 안 남으면 그 칸은 비운다(지금도 그렇게 돈다 — "못 채운 칸" 표시).
```

★사장님이 "장면 있으면 1번 대본, 없으면 2번 대본이냐"고 물으셨는데 **아니다.**
대본은 **한 벌**이고, 그 안에 들어갈 **단어(슬롯 값)가 바뀐다**. 재료가 한 칸에
10여 개씩 있어서 걸러도 대체가 있다. 다 걸리면 그 칸만 빠진다.

## ⚠️ 오늘 밟은 함정 6개 (다시 밟지 마라)

1. **조용한 실패가 "재료 없음"으로 보였다.** 5편 전부 0/7인데 로그가 한 줄도 없었다.
   진짜 원인은 `pipeline` import 실패. → `_fail(why)`로 3갈래 로그를 남기게 고쳤다.
   **재료 없음(정상)과 고장(비정상)은 화면에서 구분돼야 한다.**
2. **서로 다른 제품을 합치면 말이 안 된다.** 조회수 상위 5편을 그냥 집었더니
   양말세제+바닥메꿈제+촉감놀이가 섞여 `"흰 양말부터 바닥 찍힘까지"`가 나왔다.
   → 같은 소재끼리만. 실무는 사장님이 같은 소재로 담으니 자연히 지켜진다.
3. **재료 어미가 안 맞으면 문장에 못 끼운다.** `effects`를 명사형으로 뽑았더니
   `"완전 새 것처럼 닦임 거 있죠"`. → 프롬프트에서 **관형형(~는) 강제**.
4. **칸이 빠질 수 있는 구조에서 앞 칸을 가리키면 어긋난다.** reveal의 "그런데"가
   problem이 빠지자 붕 떴다. → 접속사 제거(실측 원문도 접속사가 없다).
5. **프롬프트가 말해도 검사 안 하면 안 지켜진다.** "반드시 한국어로"를 넣었는데도
   `镂空`·`瓶瓶罐罐`이 샜다. → 한자·가나 필터 추가(버리고 로그).
6. **같은 판단이 두 군데(0순위-B).** `[:3]` 상한이 `_sul_block_for_sources`와
   조립 경로에 따로 있었다. → `_FACTS_MAX_SOURCES` 상수 하나로.
   실험실 `gen.py`의 CTA 검사도 라이브(`script_gate`)와 달라 정답을 FAIL로 잡았다.

### ★음성=스토리 / 화면=시연 분리 (전사 43편·654컷 실측)

```
대사에 등장인물(시어머니·친구·사장님)이 나오는 컷   49개
그중 화면에도 사람이 나온 컷                        1개  ← 2%
```
"시어머니가 화내시는 거예요"라고 말할 때도 화면은 양말을 빨고 있다.
화면 어휘 상위 35개에 **사람 얼굴 관련 단어가 하나도 없다**(모습534·보여주는96·손으로62).

→ 필요한 화면은 4종뿐: **① 문제 상태 → ② 투입·도포 → ③ 작동 → ④ 결과 대비**
   (④ 반반 대비샷이 클라이맥스). 이 4종만 있으면 어떤 스토리든 얹힌다.

### 화면 뒷받침 실측 (장면 게이트의 근거)

| | 한국 5편(68컷) | 중국 3편(58컷) |
|---|---|---|
| 슬롯이 화면에 근거 있음 | **5/7** | **5/6** |

규칙이 있다 — **사물·동작 슬롯**(사용법·적용대상·불편함)은 전부 화면에 있고,
**판단·추상 슬롯**(가격·효과·차별점)은 화면에 없다. 위 게이트가 이 구분을 그대로 쓴다.
