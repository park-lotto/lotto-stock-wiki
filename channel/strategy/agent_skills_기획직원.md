# 기획 직원 스킬 가이드

> 목적: 지금 유튜브에서 터지는 영상을 찾아 분석하고,
> 그 에너지를 STOCK BRAIN 서비스 소개 영상으로 끌어온다.

---

## 핵심 공식

```
앞 2/3 — 지금 핫한 주식/경제 이슈로 공감·FOMO 유발
뒤 1/3 — "이게 우리 서비스로 이렇게 해결됩니다" (은근하게)
```

영상의 목적은 서비스 기능을 직접 광고하는 게 아니다.
시청자가 "저거 나도 쓰고 싶다 / 어떻게 만든 거지?"를 느끼게 하는 것.

---

## STEP 1 — 소재 탐색 (WebSearch 필수)

### 검색 쿼리 (복수 실행)
```
주식 유튜브 조회수 급상승 오늘
경제 유튜브 핫클립 최근
주식 숏폼 바이럴 최신
"조회수" site:youtube.com 주식 최근
```

### 수집 기준
- 최근 7일 이내 업로드
- 조회수 10만 이상 OR 채널 평균 대비 3배 이상
- 주식·경제·재테크 카테고리
- **최소 5개** 수집 후 비교

### 수집 항목 (영상별)
```
제목:
채널명:
조회수:
업로드일:
썸네일 텍스트:
영상 첫 10초 훅 (제목/썸네일로 유추):
```

---

## STEP 2 — "왜 터졌는가?" 분석

각 영상에서 **터진 포인트** 추출:

| 유형 | 설명 | 예시 |
|------|------|------|
| **공포/손실** | "이거 모르면 손해" 프레임 | "내가 왜 계속 물리는가" |
| **비밀 공개** | "기관만 아는 것" 느낌 | "외국인이 매집하는 종목" |
| **숫자 충격** | 구체적 수치로 FOMO | "3개월에 +300%" |
| **시간 압박** | 지금 안 하면 늦는다 | "오늘 마지막 기회" |
| **공감 정확타** | "나도 그래" 유발 | "매일 아침 시황 찾아보는 당신" |
| **시스템 공개** | "나는 이렇게 한다" | "나만의 매매법" |

### 분석 출력 형식
```
영상 N:
  터진 포인트 유형: [위 표의 유형]
  핵심 감정 1줄: [시청자가 느끼는 것]
  제목/썸네일 공식: [숫자+키워드+프레임]
  우리가 배울 것: [벤치마킹 포인트]
```

---

## STEP 3 — STOCK BRAIN 연결

### 서비스 5가지 소재 유형 (각 영상 시리즈)

| # | 소재 | 보여줄 기능 | 핵심 장면 |
|---|------|------------|---------|
| 1 | **뉴스 크롤링** | 실시간 뉴스 자동 감지 | 키워드 잡히는 순간 |
| 2 | **유튜브 요약** | 채널 인사이트 자동 추출 | 핵심 3줄이 뽑히는 순간 |
| 3 | **리포트 분석** | 증권사 리포트 자동 정리 | TP 신고가 자동 감지 |
| 4 | **텔레그램 수집** | 100개 채널 자동 모니터링 | 알림 → 즉시 분류 |
| 5 | **조합 데모** | 2~4가지 동시 작동 | 아침 브리핑 1장 완성 |

### 연결 방식
```
터진 포인트가 "매일 아침 시황 찾느라 힘들다" 공감
→ 우리 서비스: "저는 AI가 자동으로 다 읽어요"
→ 연결 소재: [2] 유튜브 요약 + [4] 텔레그램 수집

터진 포인트가 "기관이 사는 종목 몰라서 억울하다"
→ 우리 서비스: "수급 빈집 자동 스캔"
→ 연결 소재: [3] 리포트 분석 + [1] 뉴스 크롤링
```

---

## STEP 4 — 영상 설계

### 결정 사항
```
메인 소재 유형: [1~5 중 선택]
벤치마킹 영상: [가장 터진 영상 1개]
훅 방향: [터진 포인트 유형 복사]
서비스 연결: [어떤 기능을 어떻게 보여줄지]
데모 장면: [실제 보여줄 화면 3~5개]
```

### 씬 구조 템플릿
```
씬1 훅 (20~30초)    ← 벤치마킹 영상의 터진 포인트 방식 그대로
씬2 공감 (40~50초)  ← "맞아 나도 그래"
씬3 선언 (20~30초)  ← "이걸 해결했습니다"
씬4 데모 (3~5분)    ← 소재 유형 실제 화면 + 과정
씬5 클라이맥스      ← 결과물 한 장 (아침 브리핑)
씬6 자각            ← "이제 그 시간 안 씁니다"
씬7 여운            ← 다음 편 예고 (다른 소재 유형)
씬8 CTA             ← 댓글 키워드 + 서비스 대기 신청
```

```markdown
- 조회수: ...
- 터진 포인트: ...
- 우리가 배울 것: ...

## 영상 전략
- 소재 유형: [1~5]
- 훅 방향: ...
- 서비스 연결: ...

## 제목 후보 (3개)
1. ...
2. ...
3. ...

## 썸네일
...

## 씬 구성표
| 씬 | 목적 | 시간 | 화면 |
...

1. 실제 보여줄 화면 1
2. ...
```

## 기획 검수 직원 체크리스트 (10항목 / 8점 이상 통과)

```
✅ 벤치마킹 영상 5개 이상 조사했는가?
✅ 터진 포인트가 명확히 분석됐는가?
✅ 서비스 소재 유형이 선택됐는가? (1~5 중)
✅ 앞 2/3이 공감/FOMO로 채워지는가?
✅ 뒤 1/3이 서비스 데모인가? (광고처럼 안 보이는가)
✅ 제목에 숫자+충격+시간 조합이 있는가?
✅ 첫 10초 훅이 벤치마킹 영상 방식을 쓰는가?
✅ 데모 장면이 실제 화면으로 보여줄 수 있는가?
✅ 다음 편 소재(다른 유형)로 이어지는 구조인가?
✅ CTA가 "댓글 키워드 + 서비스 대기 신청" 구조인가?
```
