# SEO/애드센스 사업 — 영상 리서치 누적 가이드

상태: 진행중 (영상 계속 투입 예정, 새 영상 분석할 때마다 이 문서 업데이트)
관련: `docs/superpowers/specs/2026-07-09-SEO-애드센스-사업-design.md` (니치 스코어카드·로드맵 본체)

이 문서는 유튜브 영상들을 분석하며 얻은 실전 팁을 모으는 곳. 개별 영상 전체 요약이 아니라 **2개 이상 영상에서 교차확인된 것**과 **경고 신호**를 뽑아서 정리한다.

## ✅ 교차검증된 핵심 기법

- **AI에게 구글 공식 가이드를 직접 읽혀서 사이트 최적화** — 구글 애드센스 코리아 블로그의 "고품질 사이트 만들기" 공식 문서 링크를 Claude Code 등에게 던지고 "이거 읽고 내 사이트를 애드센스 통과하게 최적화해줘"라고 한 문장 프롬프트만 주면, 개인정보처리방침·소개페이지·사이트맵·SEO 구조를 AI가 알아서 고침. **3개 영상(혼잡스·조코딩·디파서블 간접확인)에서 독립적으로 검증된 실동작 패턴.**
- **필수페이지는 최소한**: 개인정보처리방침 + 이용약관/소개(한 단락이면 충분) + 문의페이지(이메일 주소 하나). 그 이상 필요 없음.
- **심사 기준은 분량이 아니라 완성도·고유성·신뢰요소** — 글 9개로 승인된 사례도, 800자 핵심정보글이 억지로 늘린 2,500자보다 나은 사례도 실존(디파서블). "글 50개·2,000자 필수"는 미신.
- **주제를 하나로 좁혀야 함** — 여러 카테고리(여행·맛집·재테크·육아·IT 등) 섞인 사이트는 구글이 "미완성 사이트"로 평가. 승인 전에는 실제 글이 있는 카테고리만 남기기(디파서블). → **어제 짠 "마이크로니치 하나로 좁히기" 전략과 정확히 일치, 교차검증됨.**
- **FAQ/Review 스키마마크업**은 버튼 클릭 몇 번으로 AI가 자동삽입 가능(혼잡스 사례) — 리치스니펫 노출에 유리.
- **완벽 대기보다 기본 갖추고 신청** — 승인까지 며칠~4주 편차 크고, 신청 후에도 발행을 멈추지 말 것(운영중인 사이트로 보여야 함).
- **애드센스+제휴(쿠팡파트너스 등) 병행**은 흔한 하이브리드 수익모델.
- **발행 후 수정은 문제없음** — "발행하면 수정 못 한다"는 미신, 구글 문서 어디에도 없음.

## ⚠️ 의심해야 할 신호 (영상이 마케팅 콘텐츠인지 판별)

- **자체 스크린샷만으로 된 수익 주장은 검증 불가** — "누적 100억", "학생 월 4천만원" 같은 수치는 전부 영상 제작자 본인이 보여주는 자료일 뿐 제3자 검증 수단이 없음.
- **긴급성 마케팅 문구** ("오늘만/하루만", "○○만원 상당 사은품", "댓글+설문 남기면 무료강의") = 유료 코칭 프로그램 세일즈 퍼널 신호. 콘텐츠 자체 신뢰도와 별개로 판별 필요.
- **구분법**: 주장의 근거가 "본인 후기/스크린샷"인지 "구글 공식문서 캡처"인지 확인. 후자가 훨씬 신뢰도 높음(디파서블 영상 사례).

## 🚫 하지 말 것 (정책위반 편법 — 실제로 언급됐지만 비추천)

- **심사통과용 가짜 콘텐츠 채우기** — 승인용으로만 블로그 하위페이지에 의미없는 글 10~15개를 채워넣고 통과 후 삭제하는 수법(조코딩이 실토). 구글 정책 취지 위반, 계정정지 리스크. **추천 안 함.**
- **트렌드 클릭베이트/퀴즈락형 콘텐츠** ("정답 보려면 광고 봐야 함", 혜택정보 트렌드키워드 올라타기) — 구글의 "스케일드 콘텐츠 남용" 정책 집중 단속 대상(로알남 영상에서 소개된 방식). 저유지보수 안전전략과 반대 방향.

## 두 가지 사업모델 갈래

| 모델 | 대표사례 | 특징 |
|---|---|---|
| A. 블로그/콘텐츠형 SEO | 로알남, 디파서블 | 워드프레스/티스토리, 키워드기반 정보글 대량생산. 우리가 짜고 있는 기본 전략 |
| B. 미니 웹툴/서비스형 | 혼잡스, 조코딩 | 바이브코딩으로 실용 웹앱(계산기·변환기 등) 만들고 애드센스 부착. 니치 확정 후 병행 검토 후보 |

## 다음 영상 투입 시 처리 방법
새 영상 링크 오면: watch 스킬로 분석 → 위 4개 섹션(교차검증팁/경고신호/금지사항/모델갈래) 중 해당하는 곳에 **병합**(단순 로그 추가 아니라 기존 항목 보강 또는 새 항목 추가) → 영상 로그 표에 한 줄 추가.
