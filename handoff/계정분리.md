### ⚠️ 오진 주의 — 이번에 크게 헤맨 지점

- **REST API(`web_profile_info`)로 계정 상태를 판정하지 마라.** 429가 나와도 **실제 수집 경로
  (Playwright)는 정상**일 수 있다. 반대도 성립한다. 반드시 `_scrape_one_playwright`로 확인할 것.
- **`challenge` 문자열로 페이지를 검사하지 마라** — 인스타 CSS 변수(`--challenge-width` 등)에
  그 단어가 원래 들어 있어 **정상 페이지도 걸린다**(오탐). `page.url` 로 판정할 것.
- **"계정이 막혔다"는 결론 전에 계정 4개를 각각 갈라서 볼 것.** 4개 중 1개만 막힌 상태였다.

### ✅ 이번에 배포한 것

1. **계정 풀 분리** (`8653ab071` 외) — `ig_sessions/{archive,reference}/` 하위폴더로 계정을 가른다.
   - `session_slots(pool)` / `slot_proxy(index, pool)`, 오프셋 archive=0.. / reference=10..
     (겹치면 계정↔IP 1:1이 깨진다)
   - **하위 폴더가 비어 있으면 상위 폴더로 폴백** → 지금은 분리 OFF 상태(동작 불변).

2. **관문 URL 분류 수정** — `update_risky_contactpoint`·`/challenge`·`/accounts/suspended`를
   `login_wall`로 잡는다. 전엔 `not_found` 폴백으로 떨어져 **"채널 199개가 다 없어졌다"로 오독**됐다.
   `channel_archive`도 같은 목록(`_WALL_URL_HINTS`)으로 즉시 중단 → 계정 교체 재시도.
   (전엔 챌린지면 릴스 0건을 "수집 끝"으로 처리해 **빈 채로 done** → 그 채널 영구 유실)
3. **썸네일 만료 자가복구** — CDN 서명(`oe=`)이 만료되면 공개 **oembed**로 새 주소를 받아 복구.
   **로그인 불필요**라 계정이 429여도 된다. 실측: 계정 전원 429 상태에서 75건 중 66건 복구.
4. **썸네일 실패 no-store + `THUMB_V` 캐시버스터** — 404를 브라우저가 기억해 복구 후에도
   검게 남던 문제. `thumbURL(u, sc)` 헬퍼로 호출부 5곳 통일.
