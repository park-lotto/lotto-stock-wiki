숏템메이커 VSL — 심플 촬영 시트 (2026-07-30)
======================================================================
원칙 3개
 1. 데모는 **원테이크**. 잘게 자르지 말고 쭉 흐르게 찍는다.
    (경쟁사 실측: 데모 구간 컷이 분당 1~2개뿐. 감정 구간만 분당 8~13컷)
 2. **화면에 시간(타이머) 안 띄운다.** 렌더가 서버 부하에 따라 흔들려서 숫자가 배신한다.
    "10분" 문구는 나레이션으로만 말한다.
 3. 클릭 수는 **찍으면서 직접 센다.** 다 찍고 실제 숫자를 자막으로 얹는다.

준비
 · 1080p 이상 / 마우스 커서 강조 켜기(시니어 타깃) / 알림창·다른 탭 정리
 · 화면에 개인정보(계정명·이메일·크레딧 잔량) 안 나오게 한 번 훑기
 · 브라우저 배율 100%, 전체화면(F11) — 주소창 없으면 화면이 깔끔하다


======================================================================
■ 촬영 A — 완성본 3개 (S1 훅 재료)                        [30초]
======================================================================
완성된 쇼츠 3개를 폰 또는 화면에서 나란히 재생. 소리 켜서.
→ 후반에 3분할(트립틱)로 배치.
※ 이게 없으면 S1이 성립 안 된다. 최우선.


======================================================================
■ 촬영 B — 소재 찾기 (S5 챕터1)                            [원테이크]
======================================================================
찍는 순서 (멈추지 말고 쭉)
 1) 레퍼런스 랭킹 열기 → 카테고리 하나 클릭
 2) 상위 카드 하나 보며 잠깐 멈춤 (2초) ← 시청자가 읽을 시간
 3) '렌즈 검색' 클릭
 4) ★결과가 뜨는 순간 3초 멈춤 — 유튜브·인스타·틱톡·샤오홍슈·도우인 5개가 보이게
    (여기가 경쟁사가 못 하는 지점. 절대 빨리 넘기지 말 것)
 5) 마음에 드는 것 2~3개 '담기' 클릭
 6) 영상 즐겨찾기로 이동 → **1~2초만 보여주고** 바로 제작소로

⚠️ 즐겨찾기는 설명할 게 없다. 스치듯 지나가는 게 맞다.


======================================================================
■ 촬영 C — 제작소 1~7단계 (S5 챕터2~7)                     [원테이크]
======================================================================
 1) 1단계 대본: AI PICK 뜨는 것 보여주고 하나 선택
 2) 2단계 매칭: 시작 누르고 → **대기는 여기서 녹화 멈춤**(나중에 컷)
    ※ 재개할 때 마우스 위치를 비슷하게 두면 컷이 안 튄다
 3) 자막 제거: 전/후만. 처리 대기는 컷.
 4) 성우: 목록 보여주고 미리듣기 **소리 켜서 3초** (이 영상 목소리와 같은 엔진이라 증거가 된다)
 5) 꾸미기 / 썸네일 / 해시태그: 버튼 누르고 결과만. 각 5초 이내.
 6) ★최종 렌더 → 대기 컷 → **결과물 재생은 배속 없이 1배 그대로 끝까지**
    (여기가 영상의 정점. 배속 걸면 감동이 죽는다)


======================================================================
■ 촬영 D — 옛 방식 (선택, 5분)                             [정지 캡처만]
======================================================================
녹화 안 한다. **스크린샷 4장**만.
 ① 번역기에 한국어 넣고 중국어 뽑는 화면
 ② 도우인/샤오홍슈 검색 결과 (중국어 UI 그대로)
 ③ 영상 다운로드 사이트
 ④ 캡컷에서 자막 지우는 화면
→ 후반에 좌우 대결로 씀(왼쪽=이 4장 순서대로 / 오른쪽=촬영B의 담기 클릭).
※ 안 찍어도 됨. 그 경우 왼쪽을 텍스트 체크리스트 애니메이션으로 대체.


======================================================================
■ 후반 작업 3개 (촬영 필요 없음)
======================================================================
1. 클릭 카운터
   화면 우측 상단에 작게 `클릭 3` → 누를 때마다 숫자 올림.
   ※ 촬영하면서 센 실제 횟수를 쓴다. 마지막에 "영상 하나에 클릭 N번"으로 닫기.

2. 좌우 대결 (촬영D 있으면 캡처, 없으면 텍스트만)
   왼쪽                        │ 오른쪽(촬영B)
   □ 키워드 정하기              │ 렌즈 검색 클릭
   □ 중국어로 번역              │ 5플랫폼 결과
   □ 도우인 접속·검색           │ 담기 클릭 ✅ 끝
   □ 다운로드 사이트 찾기        │
   □ 캡컷으로 자막 지우기        │   ← 오른쪽 끝난 뒤에도 왼쪽은 계속 켜진다

3. 대본↔화면 일치 증명 (우리 최대 차별점)
   위: 대본 문장 한 줄 / 아래: 그 장면
   문장이 넘어갈 때 장면도 같이 넘어가는 걸 **3~4번 연속**으로 보여준다.
   "그냥 붙인 게 아니라 맞춘 것"이 말 없이 증명된다.

4. 딤 + 중앙 자막 (훅 구간)
   제품 화면을 어둡게 깔고 흰 굵은 자막 한 줄. 편집 난이도 0, 효과 큼.


======================================================================
촬영 순서 추천 (한 번에 몰아서)
======================================================================
 B(소재찾기) → C(제작소) 를 **끊지 않고 이어서** 찍는다. 실제 작업 한 번이 곧 촬영이다.
 그다음 A(완성본 3개). D는 여유 있으면.
 → 다 찍고 클릭 수 합계를 적어두면 후반에 바로 카운터를 얹을 수 있다.

찍으면서 적을 것
 · 클릭 총 횟수:        회
 · B 소요:      분   /  C 소요:      분
 · 대기(컷할) 구간 위치: 매칭 후 __분 / 자막제거 __분 / 최종렌더 __분
