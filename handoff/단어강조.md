# 단어강조 트랙 — 장면꾸미기 단어 강조 + 글자 직접 조절 (관제 102·103)

## 2026-10-03 (CH PC) — 구현·로컬 확인 끝, ★라이브 전(사장님 "한 번에 라이브")

**주인 함수**
- 단어가 켜지는 시각: `shopping_shorts/scene_style.py:attach_scene_words`(context_for 가 부른다). 화면·렌더·캡컷은 `scene.words` 만 읽는다. 추정(글자수 비례)은 `out/precision20-ui.js:wordFxTimes` 한 곳.
- 글자 크기·맞춤·그림자: `out/precision20-ui.js:addText`. 크기 쓰기는 `setFontScale` 하나(＋/− 버튼·글자 설정 줄·끌어 늘리기).

**결과물 검사**
- `py tools/word_fx_check.py --job-dir <표본 작업 폴더> --beats 2 [--style color] [--grow]` — 완성 영상(compose)을 강조 켬/끔 두 벌로 굽고 단어 상태마다 프레임 대조 + 캡컷 구간 + 썸네일. 표본 409f894230c6(main 폴더 tools/scene_lab/out, git 밖) 28상태 어긋남 0.
- 기존 도구도 통과: `tools/scene_font_research/check_plain_downstream.py`·`check_plain_template.py`·`check_plain_caption_bugs.py`(8773 서버 필요).

**한 것**
1. 단어 강조(102): 본문 모션 카드에 없음/박스/색 바뀜 + 강조색(자동=템플릿 포인트 색) + 살짝 키우기(1.08배, 커진 채로). 렌더러는 단어가 바뀐 프레임만 찍고 복사, 캡컷은 `overlay_spans` 가 단어마다 한 장.
2. 글자 직접 조절(103): 손으로 정한 크기는 자동 줄임·줄바꿈·찌그러뜨림 없음(원인: `oneLineTitleLines` 가 도로 줄였다). 제목·채널명 칸도 Enter 줄바꿈. 표식 `manualText:2` — 손으로 키운 글자·그림자가 있는 옛 저장본은 예전 그림.
3. 템플릿 훅 장면 자막 카드는 안내만(사장님 '가': 띠=보조제목 유지). 원본그대로 자막은 그려진 제목 끝 아래로.
4. 그림자 = 썸네일식 검정 3겹(검은 글자엔 안 건다). 폰트 탭 글자 설정 다섯 줄(크기·두께·그림자·자간·행간).
5. 글자 끝 손잡이로 끌어서 크기 조절. 칸 조절 줄에 이름(크기/위치/처음으로), 자막 위치 버튼 이름(기본 자리로/끌어서 옮기기).

**⏭ 남은 것**
- 편집기에서 단어 강조 버튼을 직접 눌러 보기(완성본·캡컷 구간·썸네일은 확인, 버튼 클릭 흐름은 미확인) / 캡컷 앱에서 열어 보기(불가 — 구간 파일까지만 확인)
- 전체 pytest, `finish`(영상 관문), 라이브에서 직접 눌러 보기. ★사장님 승인 뒤 한 번에.
- 사장님 케이크 작업(원본그대로 겹침)은 작업 번호를 못 받아 표본으로만 재현.
- 자막(여러 장면)은 손으로 키워도 화면 폭을 넘으면 줄을 넘긴다(제목과 다름) — 사장님 확인 대기.
