## 탑픽 선정 기준 요약
```
수급빈집(2점) + 수출신호(1) + 판가(1) + 어닝서프(1)
+ 리포트신고가(1) + 미국커플링(1) + 정책이슈(1) + 일정재료(1)
= 최대 9점

7~9점 → 🔴 오늘의 탑픽
5~6점 → 🔴 탑픽 후보
3~4점 → 🟠 관심주
```
