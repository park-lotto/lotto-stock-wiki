## 1. 상품 구상 (사장님 확정)

- **숏템메이커 2기 88만원은 그대로 유지.**
- **클로드형** = 고객 본인 클로드(무제한 구독) 안에서 프리셋 스타일 숏폼을 만드는 상품.
  - 숏템 구매자가 추가하면 **+50만원, 1회성**
  - 클로드형만 사면 **88만원** (랭킹 수집 + 프리셋)
  - 클로드형은 아직 판매 전 → "클로드형 먼저 산 사람이 숏템 추가" 규칙은 출시 공지 때 한 줄 정하면 된다
- **역할 분담 (사장님 확정)**
  - 숏템 서버 = **레퍼런스 수집·랭킹만**. 우리 서버에서 제작(AI·렌더) 금지
  - 대본·판단 = 고객 클로드 구독
  - 외부 API(음성·이미지 등) = **고객 본인 키 등록** (숏템의 `/api/settings/keys`처럼)
  - 렌더 = 고객 PC
- 흐름: 숏템 페이지에서 레퍼런스를 찾는다 → 제작소 넘기듯 보낸다 → 고객 클로드에 설치한 **숏템 MCP**에 "OO 프리셋으로 만들어"
- 영상 형태는 **B = 볼케이노 같은 정보·썰 숏폼**(이미지 생성·짤·효과음). 숏템식 실장면 컷 아님
- **프리셋은 사장님이 계속 만든다** → 엔진 하나 + 프리셋 데이터 교체 구조여야 한다
- 프리셋 만드는 법 = **역분석을 "분석 시스템"으로 확정**해 도구화
