# 썸네일그림자 — 썸네일 꾸미기 글자 크기 −＋·숫자 + 그림자 (2026-09-17, 사장님 PC)

**소유 트랙**: 썸네일그림자

## 한 것
- `produce.html` 글자 편집칸: 크기 슬라이더 → `thumbNumRow`(− 슬라이더 ＋ 숫자). 크기 30~200(5씩), 그림자 0~100(10씩).
  버튼·슬라이더 모두 `thumbNumSet` 한 곳 → `setThumbField`.
- 새 필드 `L.shadow`(0~100, 없으면 0 = 옛 저장본 그림 불변). 글자 크기 비율로 그려 미리보기(270)=저장(1080).
  외곽선이 있으면 외곽선 두께째로 그림자를 떨어뜨린다. 프리셋을 바꿔도 shadow 유지.
- 실측(로컬 정적서버+크롬): ＋클릭 → L.size 120·숫자 120·슬라이더 120 / 그림자 0→50→100 어두운 픽셀 290,247→293,746→300,040, 화면으로도 확인.

## ⏭ 남은 것
- 배포본(라이브)에서 실제 job으로 썸네일 저장 PNG에 그림자가 실리는지 확인 — 아직 못 함.
- 자간·행간·회전·외곽선도 같은 −＋ 줄로 바꿀지는 사장님 요청 시(`thumbNumRow` 재사용).
- 참고: 대본믹스 "접기" = 1단계 소스 분석 카드(`toggleSrcCard`). 없어지지 않았고 `53464338d`(08-16)에서 기본이 펼침으로 바뀜. 카드를 누르면 접힌다.
