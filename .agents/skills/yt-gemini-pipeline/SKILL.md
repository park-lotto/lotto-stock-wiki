# yt-gemini-pipeline

## 언제 실행하나

`yt-content-research`로 주제·각도가 확정된 직후.
"대본 써줘" / "리서치해줘" / "스크립트 뽑아줘" 요청 시.

---

## 전체 흐름

```
[Claude] 브리프 생성 (STEP 1)
    ↓ claude_brief 포맷으로 출력
[Gemini API] 딥리서치 → 스토리 설계 → 구어체 대본 (STEP 2)
    ↓ 완성 대본 반환
[Claude] 검수 체크리스트 (STEP 3)
    ↓ 통과 시 → yt-planner / Remotion 단계로
```

---

## STEP 1 — Claude 브리프 생성

주제 확정 후 아래 포맷으로 브리프를 출력한다.
**Claude 기억 기반 내용 금지. 현재 시점 데이터만.**

```
============================
[GEMINI INPUT BRIEF]
============================

[채널]
채널명: 로또의 스탁브레인
운영자: 친근한 주식경제분석가
강점: 경제흐름 인사이트 + AI 도구 활용 빠른 습득
콘텐츠 비율: 정보 70% / 간접 20% / CTA 10%
절대 금지: 특정 서비스명·프로그램명 직접 언급, 선동 표현

[주제]
{확정된 주제}

[채널 메인 뷰]
{합리적 낙관론 / 경고 / 역발상 / 데이터 분석 중 선택 + 1줄 설명}

[핵심 주장 1줄]
{이 영상이 전달하는 단 하나의 메시지}

[필수 리서치 항목]
- {수치가 필요한 항목 1}
- {수치가 필요한 항목 2}
- {수치가 필요한 항목 3}

[경쟁 영상이 안 다루는 각도]
{우리가 차별화하는 지점}

[영상 길이]
{8~10분}

[다음 편 연결]
{있음 — 주제 / 없음}
============================
```

## STEP 2 — Gemini API 호출 (3단계 수행)

브리프 + 시스템 프롬프트를 Gemini에 전달. Gemini가 아래 3단계를 순서대로 수행한다.

**호출 방법**:
```bash
python channel/tools/gemini_script.py \
  --brief "channel/yt/brief_{주제}.md" \
  --output "channel/yt/script_{주제}_gemini.md"
```
스크립트 없을 경우 → 브리프를 직접 Gemini에 붙여넣고 결과를 `channel/yt/` 에 저장.

---

━━━━━━━━━━━━━━━━━━━━━━
1단계 | 딥 리서치
━━━━━━━━━━━━━━━━━━━━━━
클로드가 제시한 주제와 관련하여, 현재 자본시장에서 가장 신뢰도 높은
최신 정보와 데이터를 실시간으로 서치(Search) 및 수집하세요.
리서치에는 아래 3가지 요소가 '필수'로 포함되어야 합니다.

① 시장을 움직이는 핵심 모멘텀
   예: 글로벌 빅테크 CEO의 방한 일정, 특정 산업의 대규모 공급 계약,
   정부 정책 발표 등 주제와 직접 관련된 트리거

② 논리를 뒷받침할 계량적 데이터
   예: 관련 업종의 예상 밸류에이션(PER/PBR), 수출입 통계,
   글로벌 공급망 점유율 등

③ 시장의 이면과 잠재적 리스크
   예: 단기 과열에 따른 차익실현 물량, 매크로 금리 변동성,
   공급 과잉 우려 등 낙관론을 반박할 수 있는 현실적인 팩트 체크

━━━━━━━━━━━━━━━━━━━━━━
2단계 | 스토리 설계
━━━━━━━━━━━━━━━━━━━━━━
수집된 데이터와 클로드가 제시한 [채널 메인 뷰]를 기반으로,
이 주제에 가장 자연스러운 스토리 흐름을 직접 설계하세요.

구조는 주제마다 다릅니다. 아래 원칙만 지키면 됩니다:
- 시청자가 영상 초반에 "왜 이걸 봐야 하는지" 느껴야 한다
- 클로드가 제시한 핵심 주장이 중심축이 되어야 한다
- 리스크와 반론은 반드시 포함한다 (채널 신뢰도 보호)
- 마지막은 클로드가 지정한 [다음 편 연결]로 마무리한다

스토리 설계 후, 선택한 흐름을 1줄로 먼저 제시하세요.
예) "공감 훅 → 과거 데이터 비교 → 현재 차이점 → 리스크 → 결론"

━━━━━━━━━━━━━━━━━━━━━━
3단계 | 대본 작성
━━━━━━━━━━━━━━━━━━━━━━
설계된 스토리 흐름대로 구어체 풀 대본을 작성하세요.

[말투 규칙]
- 편안한 대화체: "~죠", "~요", "~거든요"
- 자연스러운 추임새: "솔직히", "근데 어라?", "가만 있어봐요", "이거 봐요"
- 호흡 가이드: (잠깐 멈춤), (진지하게), (싱긋), (강조) 괄호 표기
- 숫자는 말로 풀기: "37.2%" → "세 집 중 한 집 이상"

[리스크 관리 문구 — 결론 직전 반드시 삽입]
"물론 이게 100% 확정은 아닙니다. 데이터상 확률 높은 시나리오로
보시고, 본인 판단과 리스크 관리는 꼭 병행하세요."

[출력 형식]
씬번호 | 예상시간 | 핵심대사 | 화면설명

## STEP 3 — Claude 검수 체크리스트

Gemini 대본 받은 후 아래 항목 전부 확인. 하나라도 ❌면 해당 씬 수정 후 재확인.

```
□ 정보 씬 비율 70% 이상인가
□ 서비스명·프로그램명 0회인가
□ "무조건·폭등·반드시" 류 선동 표현 0회인가
□ 수치마다 날짜·출처가 있는가
□ 리스크 관리 문구가 결론 직전에 있는가
□ 첫 10초 안에 "왜 봐야 하는지" 나오는가
□ 다음 편 연결이 브리프와 일치하는가
□ 문어체 문장이 없는가 ("~이다", "~하였다")
```

전부 ✅ → `channel/yt/script_{주제}_final.md` 로 저장 → yt-planner 단계로.
