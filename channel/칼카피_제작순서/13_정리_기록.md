## 로컬 정리 (사장님 10-20 — 납품한 편의 작업 폴더는 지운다)
조건 둘 다 확인한 뒤에만: ① 드라이브 크기 = 로컬 크기 ② DriveFS `operations` = 0.
```powershell
Remove-Item -LiteralPath "C:\숏템_칼카피\yanshottem\하이브리드_<키>" -Recurse -Force -Confirm:$false
Test-Path -LiteralPath "C:\숏템_칼카피\yanshottem\하이브리드_<키>"     # False
```
- 지우는 것: 그 편 작업 폴더 전체(src·render·screen·asr) + 바탕화면 사본.
- 지우지 않는 것: git 의 `channel/yanshottem/하이브리드_<키>/`(조사·대본·재료·근거) · 드라이브 `_이전판`.
- 사장님 판정 전에 다시 손볼 수 있는 편(사실 확인 대기 등)은 판정 뒤에 지운다.
- 멈춘 편(만들지 않은 편)의 받은 원본도 묶음이 끝나면 지운다.
- 권한 판정이 삭제를 막으면 우회하지 말고 사장님께 PowerShell 명령을 드린다.
- 다시 손볼 일이 생기면: 근거.md 의 URL·구간으로 src 를 다시 받는다.

git -C <워크트리> add channel/yanshottem/하이브리드_<키>/ <내가 고친 도구 경로>
git -C <워크트리> commit -m "<무엇> (관제 097)" -m "Co-Authored-By: …"
