# 66 · 유튜브 「그거 때문에 답답했잖아」

> 플랫폼 유튜브 썰 · 출처 발명품형 4갈래 중 ③ '기존에는 ~였음'으로 밀기 (27편, 209~217자, 원문 존댓말 → 반말) — 로또의 주식/tools/seed_spine_invention4.py:1-40 (발명품형 4갈래, 자막 222편)
> 맞는 재료: 누구나 겪는 불편이 또렷하고, 기존 제품과 비교할 거리가 있는 생활용품·홈템. 성과·화제 재료가 없어도 된다
> 라이브: approved · 사용 192회 (styles_inventory.json:customer_selectable_styles notes)

## 1. 역할과 핵심 원리

자랑이 아니라 **내 불편**에서 출발한다. 숨기는 것은 정체가 아니라 '이게 왜 다르냐' — 불편을 길게 깔고 해결을 보여준 뒤 **기존 방식의 한계**로 못 박는 공감극.

1. 불편이 먼저다 — pain 칸이 이 갈래의 축이다. 노바 '참고 있던 불편'을 가장 길게 쓰는 스타일.
2. 제품을 숨기지 않는다(제목에서 해결된 장면으로 연다). 성과 자랑(떼돈·바이럴)이 없다 — 원문 ③ 실측(로또의 주식/tools/seed_spine_invention4.py:1-40 (발명품형 4갈래, 자막 222편)).
3. '기존에는 ~였음'으로 옛 방식의 한계를 못 박는다 — 비교가 이 갈래의 증거다.
4. 원리(how)는 한 문장 — 설명서처럼 늘이지 않는다.

| 재료 | 쓰일 칸 | 없을 때 |
|---|---|---|

## 7. 연결 — 닫지 않고 잇는다

- 신호어는 **코드가 붙인다**(story_writer.pick_signals). 모델은 신호어 다음 말부터 쓴다.

- title→pain: 여태 · 원래
- pain→solve: ~였음 → 근데(코드)
- solve→how: ~는 거 / ~는데
- how→limit: 기존에는(코드)
- limit→land: ~였음 → 이제

## 8. 말투 · 표기

- 허용 어미: ~였음 · ~는 거 · ~는데 · ~다는데 · ~다고 · ~버림

- 왜: pain 을 '정신 나가 버릴 것 같은' 장면으로 깐 예
- ⚠️ '정체' 은폐는 이 갈래와 다름 — pain 문장만 참고

```
… 한끼 먹고 설거지 산더미라 정신 나가 버릴 것 같은 현대인들을 구원한
전설의 그릇이 등장했는데 … 요리와 플레이팅을 한 방에 끝내니 설거지 스트레스도 사라진다고
```

## 라이브 스파인과 어긋나 바로잡은 곳

- first_line_molds 의 '{대상} 구원한 {제품군}의 정체' — 이 스타일은 '제품을 숨기지 않는다'인데 '정체'는 은폐 신호. '~의 정체'를 빼고 P3 로 바로잡음
- 원문 ③의 반전('근데 진짜 필요한 사람들은 따로 있었는데')이 라이브 칸에 없다 — 선택 칸 twist 로 추가 제안
