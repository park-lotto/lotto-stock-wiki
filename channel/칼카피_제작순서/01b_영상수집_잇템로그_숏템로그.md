## 1. 씨앗 채널
- 첫 씨앗 = 사장님이 준 쇼츠 하나(떠튜브 ZQphwE2W1Aw — '외국인이 한국제품' 검색, 구독 25.2만·1,238만 회). 그 렌즈 결과에서 같은 원본을 쓴 쇼츠타르트(UC71TbR88ZOAsa8-JG3UD3pw, 58.3만)가 둘째 씨앗.
- 정해 둔 씨앗 목록은 없다 — **같은 원본을 쓴 한국 채널이 다음 채널**이 된다.
- 장부: `channel/해외원본소재/원본찾기.json` 의 `channels{"yt:<id>": {name, role: korean|origin|overseas, classified, shorts_n, cats, file}}` + `channel/해외원본소재/한국채널/<채널>.json`.
- 10-21 분류 끝: 떠튜브 740 · 쇼츠타르트 1,793 · 찐텐펭귄 538 · K감탄기록 88 · Daily Drama F1 21.

## 2. 채널 쇼츠 분류
```
PYTHONUTF8=1 py tools/calcopy/origin_find.py channel <채널id …>
```
- `yt-dlp --flat-playlist` 로 `https://www.youtube.com/channel/<id>/shorts`(id·조회·제목, 영상 안 받음).
- 분류기 `origin_find.classify` → `claude_cli.ask(model=haiku, tag of_cat)`, 지시문 `CAT_PROMPT`.
  카테고리: 화장품(스킨·메이크업·헤어·뷰티 도구) / 제품(생활·아이디어·가전·장난감·주방) / 음식 / 동물 / 사람·유머 / 기술·탈것 / 스포츠 / 기타 (+ korea·foreigner·item 칸).
- 브랜드: 화장품 → **잇템로그** · 제품·기술·탈것 → **숏템로그** · 음식 → 맛템 · 동물 → 동물 · 사람·유머 → 썰 · 그 외 → 기타.
- **150개씩 4병렬**(하이쿠 답이 길면 번호가 빠진다) — 빠진 번호는 3번 다시 묻고, 끝내 없으면 '미분류'. 실측 미분류 0. 같은 제목도 판마다 조금 갈린다(찐텐펭귄 화장품 7 → 재분류 10).
- 사고: 'masked singer' 가 mask 로 화장품 → 영어 낱말 경계. 씨앗 브랜드는 분류 파일 cat 이 주인(cat_brand), 없을 때만 제목 낱말.

## 3. 대기열
- `queue` = 유튜브 주소 목록, channel 명령 끝에 한국채널 전체를 **조회수 순으로 다시 정렬**. run 은 늘 1위부터.
- 한 것은 `done("yt:<id>")` 로 거른다. 실패는 `failed{url: 이유}`.
- 한 편 = 렌즈 4번 + 링크 27~38개 메타(yt-dlp 6병렬) + 소넷 판정 1~2번 → **3~5분, 0원**(렌즈 무료·yt-dlp·Claude 구독, SerpApi 안 씀).
- 10-21: 대기열 3,190편 · 처리 4편(시험) · 실패 0 · 01:22 전체 실행(로그 `C:/숏템_칼카피/_origin/run.log`).

- 남기는 링크 3종: 유튜브 shorts/watch/youtu.be · `tiktok.com/@x/video/<숫자>` · 인스타 reel·p. 틱톡 /discover 같은 검색 페이지는 버린다.

## 5. 같은 영상 판정 (`judge_same`) — Claude 눈
- 시트: 첫 줄 씨앗 장면 S1~S4, 아래 후보 썸네일 24칸(200×300, 8열, 파란 번호), 넘으면 여러 장 → `_origin/<씨앗id>/judge_N.jpg`.
- `claude_cli.ask(model=sonnet)`, 지시문 `JUDGE_PROMPT`: 같은 원본 촬영분이면 자막·띠·잘림·확대·반전·뉴스 삽입이 달라도 '같음' / 주제만 비슷하거나 **같은 출연자의 다른 무대·방송은 '다름'** / 판단 불가면 넣지 않는다. 썸네일 못 받은 후보는 미판정(등록 안 함).
- 정확도는 숫자로 안 쟀다(떠튜브 시트 1장 눈 대조: MissDarcei·곱슬머리 여성·golloria 맞음).
- 사고: BGT 씨앗에서 같은 마술사의 SBS 국내 무대를 '같음'으로 → SBS 예능 2,958편 등으로 넓혀짐 → 원본보다 먼저 올린 한국 채널은 넓히지 않게 + 지시문 수리, 4채널은 `한국채널/_제외/`.

## 6. 원본 고르기 · 장부
- `pick_origins`: 같은 영상 중 **해외(제목·렌즈 글·채널에 한글 없음) 채널마다 가장 먼저 올라온 것**. 씨앗 날짜보다 늦은 해외 계정은 퍼 간 쪽 → 제외.
- `videos{"<yt|tt|ig>:<id>": {platform, id, url, title, channel, channel_id, subs, views, date, dur, thumb, lens_text, lens_hits, korean, match, judge:"eye", role(origin|korean_reup|overseas_copy|korean_found|overseas_found), brand, seen_from[]}}` · `pairs[{copy, origin, seed, brand, at}]`.
- `PYTHONUTF8=1 py tools/calcopy/origin_find.py report` → 원본별 '한국 재편집 n개 · 조회수 합'.
- **제작으로 넘기는 기준 = 사장님 결정 대기.** 제안: 한국 재편집 수·조회수 합 큰 순(예 BGT 원본 한국 7개 합 3,575만 · MissDarcei 17개 합 1,545만). 쓰기 전 원본을 받아 우리 판 장면과 눈 대조.

## 7. 넓히기
- run 이 같은 영상의 한국 유튜브 채널을 `channel_queue` 에 넣는다(그 영상 날짜 ≥ 원본 날짜, 아직 분류 안 한 채널) → 다음 씨앗 전에 그 채널 쇼츠 전부 분류 → 대기열 재정렬.
- 멈춤 = 대기열이 비거나 `--n` 개수. 무한 반복 막기 = done 거르기 + 채널당 한 번 분류(classified). 옛 `expand` 는 지금 흐름에서 안 쓴다.
