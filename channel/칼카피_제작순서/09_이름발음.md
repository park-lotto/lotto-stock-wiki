# 09 이름 발음 — 연예인 이름이 제대로 들리게

```
PYTHONUTF8=1 py tools/calcopy/hybrid/run.py <키> name_check
```
- 이름 구절만 먼저 합성 → 받아쓰기 → 표기를 고른다 → 대본 `tts` 에 반영. 사전에 있으면 0초(재사용).
- 사전 주인 = `tools/calcopy/engine/name_dict.json` + `name_dict.py`(모든 TTS 가 읽는다). 새로 통한 표기·틀리게 들린 표기(bad)는 여기에.
- 통한 표기 예: '방송인, 최, 은경 씨가' · '방송인 이영자 씨가' · '요리연구가 빅마마 이혜정이'.
- 실제 사고: 최은경 → '최화정', 이영자 → '미영자'(전체 재합성 21회 → 이름 구절 ≤6회로 줄인 이유).
- ⚠ 알려진 결함: `name_check.py:56` 이 미나 판인데도 타입캐스트로 합성한다 → 미나 판은 이 점검 결과를 믿지 말고 **11단계 완성본 받아쓰기로 이름을 확인**한다.
- 렌더 뒤 두 모델 중 하나라도 이름을 틀리게 들으면 name_dict bad 에 추가, 둘 다 틀리면 표기를 바꿔 다시 렌더.
