# AI+주식 신채널 설계 — 브레인스토밍 메모

> 날짜: 2026-06-13 | 상태: 브레인스토밍 진행 중 (미완료)

---

## 확정 사항

| 항목 | 결정 |
|------|------|
| 기존 채널과의 관계 | **별도 채널** — 로또의 주식인사이트와 섞지 않음 |
| 핵심 철학 | AI가 인간보다 잘하는 모든 걸 AI에게 / 인간은 선택만 |
| 영상 페르소나 | 페르소나 분리 — 영상마다 "이건 초급용" 명시하고 혼합 업로드 |
| 영상 형태 | 단독 (철학/튜토리얼) + 혼합 (철학으로 시작→실습으로 끝) |
| 전략 방향 | **B안: 내 시스템 공개 채널** |
| 수익화 목표 | 무료 프롬프트로 구독자 → 전자책·강의·프로그램 판매 |

---

## 핵심 철학 문장

> "AI가 할 수 있는 건 AI에게. 인간은 선택하는 존재다."

---

## 채널 접근법 — B안 선택 이유

- 운영자가 실제로 가진 시스템(크롤링→위키→인사이트)이 콘텐츠 자체
- 초급(챗봇) → 고급(파이프라인)으로 자연스러운 커리큘럼 형성
- 시청자가 따라하다 한계에 부딪히면 서비스 구매로 자연 전환
- 차별화 명확 — "실제 쓰는 사람이 직접 공개"

## 영상 주제 구성 (레벨 5단계)

### Level 0 — 철학 입문 (전연령 공통)

| 주제 |
|------|
| AI 시대 주식투자자의 역할이 바뀐다 |
| AI가 잘하는 것 vs 인간이 해야 하는 것 |
| 감정이 투자를 망치는 이유, AI가 차단하는 방법 |
| 주식을 로또처럼 하는 사람 vs 시스템으로 하는 사람 |

### Level 1 — 챗봇 기본 (완전 초급, 60대도 가능)
*무료 프롬프트 공개로 구독자 유입*

| 주제 | 도구 |
|------|------|
| ChatGPT에게 종목 분석 시키는 법 | ChatGPT |
| 증권사 리포트 AI에게 30초에 요약시키기 | NotebookLM |
| 뉴스가 주가에 미치는 영향 AI로 판단하기 | Perplexity |
| 실전 프롬프트 10개 무료 공개 | 전부 |
| 스마트폰으로만 하는 AI 주식 루틴 (시니어용) | 챗봇 |

### Level 2 — 정보 정리 (초중급)

| 주제 | 도구 |
|------|------|
| NotebookLM으로 나만의 종목 노트 만들기 | NotebookLM |
| 텔레그램 채널 100개 대신 AI 필터 1개 | ChatGPT |
| 섹터별로 뉴스 자동 분류하는 법 | Claude/GPT |
| AI로 IR자료·사업보고서 핵심만 뽑기 | NotebookLM |
| 공시 떴을 때 AI에게 묻는 프롬프트 | ChatGPT |

### Level 3 — 자동화 입문 (중급)

| 주제 |
|------|
| 크롤링이 뭔지 — 비개발자도 이해하는 3분 설명 |
| n8n/Make로 뉴스 자동 수집 — 코딩 없이 |
| AI에게 매일 아침 리포트 받는 루틴 만들기 |
| 내가 관심 종목 알림 AI로 자동화한 방법 |

### Level 4 — 시스템 구축 (고급)

| 주제 |
|------|
| 내 위키 시스템 공개 — 종목 지식이 쌓이는 구조 |
| 섹터 분석 자동화 — AI가 매일 신호 분류하는 법 |
| 수급 데이터 + AI 해석 조합하는 법 |
| AI 판단 vs 내 판단 — 어디서 갈리는가 |
| 크롤링→위키→인사이트 전체 파이프라인 공개 |

### 특별 시리즈

| 시리즈명 | 형태 |
|---------|------|
| AI 도구 대결 | ChatGPT vs Claude vs Gemini 주식 분석 승자는? |
| 실수 케이스 | AI 믿었다가 틀린 사례 |
| 70대 부모님도 한다 | 시니어 페르소나 실제 따라하기 |
| 프롬프트 주간 공개 | 이번 주 실전에서 쓴 프롬프트 무료 공개 |
| AI로 내 매매 복기 | 틀린 매매를 AI에게 돌려보면? |

## 수익화 퍼널

```
Level 0~1 영상 (무료 프롬프트)
        ↓ 구독자 유입
Level 2~3 영상 (자동화 방법론)
        ↓ "이걸 직접 만들기 어렵다"
Level 4 영상 (내 시스템 공개)
        ↓ "완성된 걸 쓰고 싶다"
전자책 → 강의 → 프로그램(STOCK BRAIN)
```
