제작소 믹스 영상(대본+담은 영상 2개→매칭 렌더)의 두 고질병 재설계. 트랙 `장면스파인`.

**근본 통찰**: 벤치마크(홈에디터류)는 문장↔장면 의미매칭을 **안 한다**. 화면은 요리
과정을 시간순으로 흘리고, 나레이션은 그 위에 스토리를 얹으며, 동기화는 **앵커(행동
언급) 순간만**. 우리 오류 = 문장마다 맞는 장면을 찾으려 한 것 자체 → 장면이 시간을
넘나들고(완성↔붓기 핑퐁) 못 찾으면 슬로우로 때움.

**확정 방향 = 원클릭 완전자동**: 사장님 [최적 믹스] 한 번, AI가 비트마다 장면교체냐 대본
수정이냐 스스로 판단. 버튼 딸깍딸깍 재생성 없음. "장면 더 담으세요" 커버리지 신호등은
**폐기**(60대는 소싱 안 함 — 시스템이 알아서). 소싱은 "개수"가 아니라 "단계 커버리지"인데,
샘플 영상은 이미 단계 다 있고 순서만 엉킴 → 시간순 정렬만으로 추가소싱 0 해결.
