답변 못 했을 때 — 카드는?

07:30에 질문 전송 → 운영자가 바빠서 답변 못 한 경우.
카드를 어떻게 처리할까요?

A

자동 초안 생성

답변 없으면 Claude가 데이터 기반으로
판단 방향을 스스로 잡아 초안 카드 자동 생성 + 전송.

장점: 매일 카드가 무조건 나옴
단점: 운영자 인사이트 없는 "정보 퍼오기" 카드가 나갈 수 있음

B

스킵 + 알림

답변 없으면 카드 생성 안 하고
"오늘 브리핑 미발행" 알림만 운영자에게 전송.

장점: 퀄리티 기준 유지 (운영자 판단 없는 카드 안 나감)
단점: 바쁜 날 구독자에게 공백 발생

C

30분 대기 후 자동 초안

07:30 질문 → 08:00까지 답변 없으면
자동 초안 생성 + "초안으로 발행했어요" 알림.
운영자가 나중에 수정 원하면 재발행 가능.

장점: 공백 없음 + 퀄리티 수정 여지 남김
단점: 수정 재발행 흐름 추가 구현 필요

💡 추천: C안 — 공백도 막고 퀄리티도 지킵니다.
초안 카드에는 "⚠️ 자동생성" 워터마크를 달아 구독자도 구분 가능하게 할 수 있어요.
