## ⚠️ 알려진 한계·위험 (다음 사람이 봐야 할 것)
1. **틀 문장 유입은 남아 있다.** 실측에서 「이건 바로 OO」 틀이 레시피에 얹혀 "한국 천재를 돈방석에 앉힌 제품" 같은
   문장이 살아남았다(제가 category=None으로 스타일을 자동 선택한 탓도 있음 — 화면은 카테고리로 고른다).
   사실검사를 끈 대가. 뿌리는 `reference_스타일예시가_재료를_이긴다`·`reference_문장틀에_박힌_판매처…` — 스파인 승인 관리가 답.
2. `_shares_word`는 8·9번 같은 줄(폭신·부드러 같은 낱말이 겹치는 이야기 줄)은 못 잡는다. "오탐 0"이 존재 조건 — 깨지면 뺀다.
3. **`test_assembled_drafts` 2건은 `.env`(키)가 있으면 실제 모델을 호출해 어미가 흔들린다**(키 없이 16/16). 병합 게이트 스테이지는 `.env`가 없어 통과. 테스트 위생 문제, 미수정.
4. node 하네스 10건(test_app_scene·deco_preview·scene_lab·scene_masks·scene_play·scene_style_canary)은 origin/main에서도 실패하는 기존 플레이크(WinError 6).
5. A1 조립(`assemble_off='1'`로 이미 꺼짐)·B 픽업·②③ 플래너·env 6개는 **코드를 지우지 않았다**(5단계 "옛 코드 삭제"는 미완). 제작소 흐름에서만 안 탄다.
6. 오늘 오전 DB에 넣은 `script_claim_check=0`·`script_claim_fatal=0` 설정값은 더 이상 읽지 않는다(코드에서 제거). DB에 남아 있어도 무해.

## 검증 계획 (라이브 재반영 전 필수)
1. 배치 하네스: 최근 실제 mix_jobs N건 × 고른 스타일 2개를 **옛 코드 vs 새 코드**로 같은 재료·같은 키로 돌려
   안 개수 / 걸린 시간 / 장면 무관 비율(_shares_word + 사람 눈) / 주제 이탈 반려 수 / 틀 문장 유입 여부를 표로.
   N은 사장님 결정(모델 호출 비용). 추천 30건.
2. 카나리: 새 코드를 `_setting_gate("script_grounded_enabled")`처럼 **admin 전용**으로 다시 얹어 사장님 계정만
   며칠 실사용. (오늘 그 게이트를 '스위치=층'이라며 없앴는데, 그것은 정확히 이 용도의 카나리였다 — 검증 중엔 필요하다.)
3. 둘 다 통과하면 전체 켜기 → 며칠 뒤 옛 경로 삭제.

## ★영역 확정 (2026-09-16 저녁, 사장님) — 이 트랙 = **2단계 대본(오류·잘 쓰기)만**
