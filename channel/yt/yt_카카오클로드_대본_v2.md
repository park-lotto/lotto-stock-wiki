### 🎬 S6. STEP 2 — PlayMCP 카카오 연결 (1분 50초)

**씬 유형**: 리스트형 → 실화면 전환
**라벨**: STEP 2
**연출 포인트**: 중간에 "MCP가 뭔지 30초만 설명" 인서트 씬 삽입

겁먹을 필요 없어요. 30초만 들어보세요.

**[인서트 씬: MCP 개념 설명 — 임팩트형]**

(톤 살짝 바뀌며)

스마트폰 충전기 종류 기억하시죠?

예전엔 기기마다 다 다른 충전기 썼잖아요.

그런데 이제 USB-C 하나로 다 됩니다.

MCP가 그겁니다.

서비스마다 따로 코드 짜지 않고,

표준 방식 하나로 AI가 뭐든 연결할 수 있게 해주는 규격이에요.

**[화면 복귀 → PlayMCP 실화면]**

PlayMCP는 카카오톡, 네이버 같은 한국 서비스들을 MCP로 모아놓은 곳입니다.

구글에서 PlayMCP 검색하면 바로 나와요.

**[화면 단계별 실연]**
카카오 계정으로 로그인하시고...

여기서 카카오톡 나채팅방 MCP 추가합니다.

이게 Claude한테 내 카카오톡 연락처 알려주는 거예요.

추가하면 Claude 코워크로 다시 돌아와서...

설정 → 커넥터 → 플러스 → PlayMCP 검색 → 스위치 ON.

이렇게 하면 연결 끝입니다.

확인하고 싶으시면 "카카오톡 나에게 테스트 메시지 보내줘" 해보세요.

카톡에 오면 연결 성공입니다.

**[자막 바]** PlayMCP → 카카오톡 나채팅방 연결 완료
