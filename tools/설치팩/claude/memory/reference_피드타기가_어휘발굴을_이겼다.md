**어휘로는 장르 벽을 못 넘는다.** '숨겨진·비밀·정리·천재'는 어느 판에서나 쓴다.
사장님: "완전 방향 잘못짚었고 / 우리 썰체널들에서 피드타고 보는게 맞는거같은데"

## 피드 타기가 이긴다

유튜브 추천은 **같은 걸 보는 사람이 다음에 보는 것**이라 결이 가깝다.
첫 사이클 실측: 새 채널 89개 중 21개(24%)가 쇼핑 결. 어휘 발굴은 121개 중 6개(5%).

비용도 자릿수가 다르다 — 추천 수집은 `ytInitialData` 페이지 긁기라 **API 0 units**.
검증(업로드 25편)만 채널당 2 units. 검색은 1회에 100 units였다.

## ★그런데 멀리 나가면 샌다

사이클 202회까지 돌리자 통과 411개가 **DIY·시공·캠핑·주식·영화**로 새어나갔다.
아정당 인테리어 47.6만·철공방이 25/25로 통과했고, **아랍어 채널**까지 뚫고 들어왔다.

    씨앗에서 가까울 때만 정확하다. 멀어질수록 "옆 판"으로 흘러간다.
    → 등록 전에 사람이 본다. 자동 등록은 위험하다.
