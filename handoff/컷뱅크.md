  `_PAID_SITES` 숫자도 함께 올려야 한다.
- **`except Exception: pass`는 예산이 있다**(`test_silent_except_budget`). 로그 한 줄로 바꿔라.
- **같은 함수 스코프에서 변수명 재사용 → TDZ**로 함수가 통째로 죽는다(`node --check`는 통과한다).
  `test_produce_tdz_scan`이 잡아준다.
- **추출 캐시 때문에 B1이 안 탄다** — 같은 소재를 재실행하면 캐시를 쓴다(구간 수가 같으면 의심).
  검증할 땐 `Store.get_extract`를 프로세스 안에서만 무력화(DB는 건드리지 말 것).
- **배포는 새벽 2~6시 시간창** — 낮에는 `touch /home/ubuntu/DEPLOY_NOW`. 다만 그건 pull만 풀고

- 정적 파일(html/js)은 **재시작 없이** 새로고침만 하면 반영된다(`_NoCacheStaticFiles`).

### 두 모델 논의 체계 (`tools/discuss.py` · `docs/2모델_논의규약.md`)

클로드가 `codex exec`를 **직접 부른다**. 창 하나가 단체방이다.
사장님이 `@코덱스` / `@둘다`라고 하면 클로드가 중계한다.

```
py tools/discuss.py log  "<주제>" 클로드 "<내 답>"   # ★코덱스를 부르기 전에 먼저 봉인
py tools/discuss.py ask  "<주제>" "<질문>"
py tools/discuss.py show "<주제>"
```

**실제로 값을 했다**: 아스트라가 내 실수(위 "쪼개라")를 잡았고, 페이블이 내가 몰랐던
부품(`seg_thumbs` 캐시 1,339개)을 찾았고, 아스트라가 페이블 지적대로 `store.py`까지 고쳤다.

⚠️함정:
- **명령줄로 한글을 넘기면 cmd.exe가 cp949로 뭉갠다** → 질문을 UTF-8 파일에 쓰고 읽게 한다
- `-`(stdin)는 안 먹는다(무응답)
- codex는 **윈도우 프로그램**이라 `/tmp/...` 같은 리눅스 경로를 주면 못 찾고 `C:\Windows`를 뒤진다
- `codex` 실행파일은 npm 셸 래퍼라 `shutil.which`로 `.CMD`를 찾아야 한다
