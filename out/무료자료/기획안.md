## 0. 결론

| | 숏템메이커 키트 | 숏클메이커 키트 |
|---|---|---|
| 보는 사람 | 쇼핑쇼츠로 부업하려는 판매자·시니어 (편집 모름) | 클로드로 쇼츠 만들어 보다 지친 40·50·60대, 채널 여러 개 하려는 사람 |
| 이름 | **「쇼핑쇼츠 대본 공식 키트」** | **「해외 원본 찾기 + 클로드 지시문 키트」** |
| 전자책 | 터진 쇼핑쇼츠 대본의 틀 2가지(썰형·설명형) · 첫 줄 공식 · 연결어 · 쓰면 안 되는 말 | 재편집본에서 처음 찍은 원본까지 **손으로 찾는 6단계** · 함정 4개 · 같은 영상 판정 기준 · 권리 확인 |
| 프롬프트 | 챗GPT·클로드에 붙여넣는 대본 프롬프트 5종 | 클로드에게 "찾아줘" 대신 쓰는 지시문 7종 |
| 덤 | 업로드 전 점검표 1장 | 원본 찾기 기록장 1장 |
| 숏템/숏클로 넘어가는 다리 | "이 공식을 버튼으로 해 주는 게 숏템" | "이 6단계를 7분에, 자는 동안 해 주는 게 숏클" |

**왜 이 둘인가**: 영상 대본 표준의 설득 2단계("일반 해결책을 진짜 다 알려준다")를 **파일로 들고 가게** 한 것이다.
받은 사람은 손으로 해 보고 → 시간이 든다는 걸 직접 겪고 → 자동화(숏템·숏클)가 필요한 이유를 스스로 안다.
반대로 엔진 그 자체(숏클 검색어 목록 전체·판정 문턱·서버 지시서)는 **주지 않는다** — 방법은 다 주되 기계는 판다.

## 1. 받는 길 — 네이버 카페 '무료 자료실' (추천)

```
영상 CTA → 메이커스랩 카페(cafe.naver.com/makerslab7) 가입(바로 가입) → '무료 자료실' 게시판 → PDF 받기
```

- **왜 카페인가**: ① 우리가 이메일·전화번호를 따로 모으지 않는다(회원 데이터 승인 사안이 안 생김) ② 받는 순간 카페 회원 = 숏템·숏클 공지·후기를 계속 본다 ③ 카페는 이미 열려 있고 '새싹' 등급이 있다.
- 게시판 설정: '무료 자료실' 신설 · **읽기 = 새싹 이상**(가입해야 받음) · 쓰기 = 스탭.
- 글 2개: [숏템 키트] / [숏클 키트]. 첨부 = PDF + 프롬프트 txt(복사용).
- 재는 것: 글별 조회수 · 카페 신규 가입 수(일별) · 등업 신청 수. 영상 올린 날 기준 전후 비교.
- ⚠️ 카페 게시판 만들기·글 올리기는 **외부에 공개되는 일**이라 사장님 확인 뒤에 한다.

## 2. 영상별 CTA 문구

### 쇼츠 (말 + 끝 자막)
- 쇼츠는 설명·댓글 링크가 눌리지 않는다(유튜브 2023-08 변경. 업로드 때 지금도 그런지 확인). → **말로 검색어를 준다** + 채널 프로필 링크.
- 숏템 쇼츠 끝: "쇼핑쇼츠 대본 공식, 무료로 드려요. 네이버에 **메이커스랩 카페** 치세요."
- 숏클 쇼츠 끝: "원본 찾는 6단계, 무료 매뉴얼로 드립니다. 네이버 **메이커스랩 카페**."
- 끝 자막(1.5초): `무료 키트 ▶ 네이버 '메이커스랩 카페'`

### 롱폼 (두 번 건다)
1. **2단계(일반 해결책) 끝** — 첫 번째 CTA, 부담 없는 것: "지금 말씀드린 방법, 그대로 따라 하실 수 있게 키트로 정리해 뒀습니다. 고정 댓글 링크로 받아 가세요."
2. **7단계(마지막)** — 원래 CTA(신청서) **앞에** 한 줄: "아직 결정 전이시면 무료 키트부터 받아 보세요. 직접 해 보시면 왜 이걸 만들었는지 아실 겁니다."
- 고정 댓글: `📥 무료 키트(전자책+프롬프트): <카페 글 주소>` / `📝 신청서: <신청서 주소>` — 두 줄. 무료가 위.
- 설명란 첫 줄도 같은 두 줄.

### 3번째 영상(숏템)부터 바로 쓰는 묶음
| 영상 | 거는 키트 |
|---|---|
| 숏템메이커 영상(롱폼·쇼츠) | 숏템 키트 |
| 숏클메이커 영상(롱폼·쇼츠) | 숏클 키트 |
| 둘을 비교하는 영상 | 두 키트 모두(카페 글 하나에 둘 다 링크) |

## 3. 금지선 (영상 대본 표준과 같다)

- 금액·수익 약속 없음("한 달 얼마 벌었다" 금지) · 다른 채널·경쟁 제품 이름 없음 · 가짜 수치 없음 — 키트 안 숫자는 전부 우리 실측이거나 뺀다.
- 쇼핑 대본 예시에 **성분·효능·안전성·의학 주장 금지**(표시광고법). 광고·협찬 표시 안내 포함.
- 숏클 키트는 **원본 영상 권리 확인** 쪽을 반드시 넣는다(원본을 찾는 것과 써도 되는 것은 다르다).
- 벤치마킹 흔적(분석한 채널 이름·우리 내부 도구 이름) 넣지 않는다.
