## 품질 주의

`channel_styles.style='썰쇼핑'`은 영상이 아니라 채널 단위 이름표다. 그래서 한 채널이
올린 뉴스·예능·게임 영상도 원본 2,761건에 섞일 수 있다. 상위 200건의 현재 영상
카테고리는 `제품정체형 89 / 오용형 17 / 홈템 27 / 기타 65 / 레시피 1 / 장비템 1`이었다.
즉 원본 전체를 그대로 학습시키면 안 된다.

또한 유튜브 `caption`은 영상 제목이지 영상 화면에 실제로 뜨는 헤드카피와 항상 같지
않다. 제목 생성 규칙은 아래 세 층을 구분해서 만든다.

1. 유튜브 제목: 이번 CSV 원장
2. 첫 1~3초 말: 기존 히트작 200편 전체 대본
3. 화면 헤드카피: 기존 훅 프레임 및 추가 프레임 표본
