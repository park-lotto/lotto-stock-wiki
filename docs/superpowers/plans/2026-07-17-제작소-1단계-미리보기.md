# 제작소 1단계 영상 미리보기 게이트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 제작소 1단계에 0원짜리 영상 미리보기를 넣고, 그걸 봐야만 다음(유료 자막제거)으로 넘어가게 한다.

**Architecture:** 기존 `video_assemble.assemble()`은 이미 3토막(`_render_mix` → `clean_fn`(선택) → `_burn_captions`)이다. 미리보기는 `assemble(clean_fn=None, deco={})`로 부르면 **유료 VMake 단계만 빠진** 믹스+음성+기본자막이 나온다 — 새 파라미터 불필요. 상태는 기존 `mix_jobs.status` 한 줄기를 오염시키지 않도록 `preview_status`/`preview_path` 별도 컬럼으로 관리한다.

**Tech Stack:** Python 3 / FastAPI / SQLite(sqlite3) / pytest / ffmpeg / 순수 JS(빌드 없음)

## Global Constraints

- **스펙**: `docs/superpowers/specs/2026-07-17-제작소-1단계-미리보기-design.md` — 이 계획의 정본. 충돌 시 스펙이 이긴다.
- **트랙 폴더에서만 작업**: 모든 경로는 `.tracks/대본믹스통합/` 기준. main 폴더의 코드 파일은 단 하나도 건드리지 않는다.
- **`git add -A` 금지**: 트랙 폴더에도 `raw/` 크롤 데이터가 딸려온다(실측). 커밋은 **파일을 하나씩 지정**한다.
- **테스트 실행 조건**: 병합 게이트(`tools/merge_gate.py:75`)는 `pytest -q --tb=no -rf -p no:cacheprovider`로 **기본 캡처** 상태로 돌린다. `-s`로 통과시키면 게이트에서 터진다. 검증은 **게이트와 같은 조건**으로 할 것.
- **기준선**: `10 failed / 731 passed`. 실패 10건은 `test_apify_client`(6)·`test_edit_plan_build`(1)·`test_mix_pipeline`(1)·`test_mix_render_flow`(2)로 이 작업과 무관. **"전부 green"이 아니라 "실패가 늘지 않았나"**로 판정한다.
- **pytest 안에서 실 ffmpeg 호출 금지**: 이 저장소는 pytest 기본 캡처가 fd 0을 무효화해 `subprocess.run`이 죽는다(장면라이브러리 트랙 실측). 이 계획의 테스트는 **`assemble`을 가짜화**하고 실 ffmpeg를 부르지 않는다. 실 렌더 확인은 Task 6 라이브 grounding에서 한다.
- **뮤테이션 필수**: 이 저장소는 "통과하는데 결함을 못 잡는 테스트"가 반복해서 나왔다. 각 태스크의 뮤테이션 단계를 건너뛰지 않는다.
- **뮤테이션 되돌릴 때 `git checkout --` 금지**: 미커밋 수정까지 날아간다(실사고 있음). 심은 문자열을 **정확히 역치환**하고 `md5sum`으로 대조한다.
- **범위 밖**: 꾸미기(`deco`) / 자막 스타일 편집 UI / `run_render` 변경 / "봤는지" 추적 / 미리보기 자동생성 / `_render_mix`에 `silent` 파라미터.
