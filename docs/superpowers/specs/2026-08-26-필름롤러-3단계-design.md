## 자르기 부품 (③) — 한 벌로 만든다

세 곳(①②④)이 **같은 부품**을 쓴다. 세 번 만들면 반드시 어긋난다(0순위-B).

```
filmroll(host, {videoId, from, to, mark, onCommit})
  - 원본 전체를 1초=1칸으로 깔고(확대하면 0.2초까지 촘촘)
  - 빨간선(현재위치) + 손잡이 끌기 = 스크러빙(미리보기 실시간 추종)
  - 손잡이 우클릭 2번 = 시작→끝 → 오렌지 박스
  - 박스는 여러 개 공존, 끌어 이동/양끝 조절/X 삭제
  - 담기 → onCommit(구간들)
```

데모(`scratchpad/filmdemo/conveyor.html`)에서 이미 실측 검증됨:
스크러빙 6/6 시각일치·그림 6종, 확대 1초→0.2초, 박스 이동/조절/삭제/담기.

### 데모에서 이미 밟은 함정 (반복 금지)

```
□ TDZ — const 선언보다 위에서 쓰면 스크립트가 통째로 죽는다(node --check는 통과시킨다)
□ CSS를 JS 블록 안에 넣으면 둘 다 죽는다(주석이 양쪽에 같으면 치환이 엉뚱한 데 꽂힌다)
□ span은 inline이라 width/height가 안 먹고 부모 pointer-events:none을 물려받는다
□ 썸네일 캐시키(cur|STEP|i)와 조회키가 어긋나면 '있는데 안 쓰인다' → thumbAt(초) 하나로
```

## ④ 임의 구간 담기 — 4곳을 짝으로

`add(sid)`(L2225)와 서버(`edit_plan.py:5089`)는 **모르는 id를 조용히 버린다**:
```python
if sid in seg_map and sid not in ids:   # ← seg_map에 없으면 사라진다
```
`seg_map`은 `job["extract"]`에서 **서버가 매번 새로 만든다**(`app.py:4604`).
→ 화면이 만든 조각을 함께 보내지 않으면 **화면엔 담겼는데 렌더엔 없다**(최악의 실패).

```
□ ① 화면    새 조각을 DATA.segments에 추가 + EXTRA에 기록
□ ② 저장    saveWork/loadWork에 extra 포함 (안 하면 새로고침에 증발)
□ ③ 전송    applyServer payload에 extra_segs
□ ④ 서버    apply_scene_lab이 seg_map에 병합(기존 것을 덮지 않는다)
```
⚠️ FIXLEN이 ②를 빼먹어 **새로고침하면 사라지는** 상태다 — 같은 실수 금지.

겹침: 지금은 같은 seg_id만 막는다(id가 다르면 못 막음).
→ 막지 않고 **표시만** 한다(`⚠ 2-1과 1.2초 겹침`). 일부러 겹쳐 쓸 수 있다.
