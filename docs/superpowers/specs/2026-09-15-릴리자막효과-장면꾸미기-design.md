# 릴리 자막효과를 장면꾸미기에 연결하는 설계

## 목표

`릴리자막프리셋` 트랙에서 실제로 재현한 릴리리아 자막 효과를 장면꾸미기의 영상 위 오버레이로 사용한다. 기존 상단 헤드카피와 본문 자막을 대체하지 않고, 선택한 장면의 감정이나 핵심 단어를 순간적으로 강조하는 별도 효과 층으로 추가한다.

## 사용자 경험

- 장면꾸미기 `효과` 탭에 `릴리 자막효과` 영역을 둔다.
- 전체 146종을 용도별 분류와 검색으로 탐색할 수 있게 한다.
- 각 카드는 정지 썸네일이 아니라 실제 움직임을 짧게 반복 재생한다.
- 카드를 누르면 현재 장면 미리보기 위에 즉시 합성한다.
- 기본 적용 범위는 `현재 장면만`이다. 사용자가 명시적으로 선택할 때만 다른 장면이나 전체 장면으로 복사한다.
- 문구는 현재 장면 자막이나 사용자가 입력한 강조 문구를 사용한다.
- 원본 갤러리의 검은 배경, 출처 설명, 에디션 번호는 결과 영상에 넣지 않는다. 투명한 글자·도형·움직임만 사용한다.

## 구조

### 1. 프리셋 원장

`릴리자막프리셋` 트랙의 재현 프리셋 정의를 하나의 원장으로 사용한다. 장면꾸미기 쪽에 색상만 흉내 낸 별도 프리셋을 다시 작성하지 않는다. 각 항목은 고유 ID, 표시 이름, 용도 분류, 기본 문구, 렌더 컴포넌트, 기본 위치와 크기를 가진다.

### 2. 장면별 저장값

장면 스타일 데이터에 다음 값만 추가한다.

- 선택한 릴리 효과 ID
- 표시 문구
- 위치와 크기
- 시작 시점과 지속 시간
- 현재 장면/복사 범위

기존 헤드카피, 본문 자막, 워터마크, 미디어 효과 값과 분리해 저장한다. 장면을 닫거나 새로고침한 뒤에도 같은 효과가 복원되어야 한다.

### 3. 미리보기와 최종 렌더

미리보기와 최종 영상은 같은 프리셋 ID와 같은 파라미터를 읽는다. 브라우저용으로 비슷하게 흉내 낸 별도 CSS 정의를 만들지 않는다. 가능한 효과는 기존 릴리 Remotion 컴포넌트를 공용 렌더 경로로 사용하고, 미리보기 카드와 최종 합성의 차이를 자동 비교한다.

### 4. 첫 화면 구성

- 추천 효과를 먼저 보여주되 전체 146종은 모두 접근 가능하게 한다.
- 분류 예: 감정 강조, 말하는 자막, 이름표·로워서드, 뉴스·정보, 타이핑, 연애·예능, 심플.
- 선택한 카드에는 적용 중 표시와 `현재 장면만` 범위를 명확히 보인다.
- 효과 제거와 원래대로 되돌리기를 같은 영역에 둔다.

## 오류 처리

- 프리셋 미디어나 폰트가 없으면 조용히 다른 모양으로 대체하지 않고 해당 카드를 `사용 불가`로 표시한다.
- 지원하지 않는 모션이나 렌더 필드는 저장하지 않는다.
- 프리셋 로딩 실패가 기존 장면꾸미기 저장과 렌더를 막지 않게 효과 층만 비활성화한다.
- 정적 색상 변형 8종은 릴리 원본 재현이 아니므로 가져오지 않는다.

## 검증 기준

1. 제공된 예시처럼 기존 상단 제목은 유지되고 릴리 효과만 영상 영역에 투명하게 뜬다.
2. 카드에서 본 움직임·폰트·색·외곽선이 장면 미리보기와 최종 MP4에서 동일하다.
3. 현재 장면 적용, 다른 장면 복사, 제거, 저장, 닫기, 재열기, 새로고침이 모두 유지된다.
4. 릴리 프리셋 146종의 카드가 누락 없이 열리고, 미디어·폰트 누락을 검사한다.
5. 실제 작업 데이터로 짧은 MP4를 렌더해 원본 헤드카피·본문 자막·워터마크와 겹침이 없는지 눈으로 확인한다.

## 제외 범위

- 릴리 원본 MOGRT 자체를 브라우저에서 직접 실행하는 기능
- 자동으로 모든 장면에 서로 다른 효과를 배정하는 AI 추천
- 기존 헤드카피·본문 템플릿의 재디자인
- 릴리와 무관한 효과 라이브러리 정리
