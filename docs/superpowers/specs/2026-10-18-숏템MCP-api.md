# 숏템 MCP — 서버 ↔ 고객 PC API 계약 (2026-10-18, 관제 234)

설계 본문: `2026-10-18-숏템MCP-design.md`. 이 문서는 **두 쪽이 같이 지키는 모양**만 정한다. 바꾸면 두 쪽(서버 `shopping_shorts/claude_portal.py`, PC `shortem_client/server/`) 테스트를 같이 고친다.

## 0. 공통

- 기준 주소: `SHORTEM_BASE` (기본 `https://shoppingshorts.duckdns.org`, 개발 `http://127.0.0.1:8849`).
- 고객 PC → 서버 요청 헤더(전 라우트 공통):
  - `Authorization: Bearer <라이선스 키>`  — `SHORTEM-L1.<cid>.<exp_unix>.<kv>.<sig>` (sig = HMAC-SHA256(secret, f"{cid}|{exp}|{kv}") hex 앞 32자)
  - `X-Shortem-Device: <기기 지문 64 hex>` — sha256(machine_id + "|" + os_user)
  - `X-Shortem-Engine: <엔진 버전 semver>` (예 `1.0.0`)
  - `X-Shortem-Device-Name: <사람이 읽는 이름, 40자 이하>` (license 때만 필수)
- 응답은 전부 JSON. 실패 모양 하나: `{"ok": false, "code": "<영문 코드>", "msg": "<고객용 한국어 한 문장>", "retry_after"?: 초}`
  - HTTP: 401 키 없음·위조·만료 · 403 회수·정지·기기 미등록·엔진 낮음·목록 밖 · 409 다른 기기 작업 중 · 429 속도 제한 · 503 스위치 꺼짐.
  - code 목록: `no_key` `bad_key` `expired` `revoked` `suspended` `device_unknown` `device_limit` `engine_old` `busy_other_device` `lease_lost` `not_in_plan` `not_entitled` `rate_limited` `disabled` `bad_request`.
- 쿠키 없이 온다 — 미들웨어 공개 경로 접두사 `/api/claude/` (로그인 세션이 필요한 고객 페이지용 라우트는 `/api/claude/me/…`, 라우트가 세션을 직접 검사).

## 1. GET /api/claude/license

라이선스 확인 + 이 기기 등록(빈 칸이 있으면 자동 등록, 2대 차면 거절).

200:
```json
{"ok": true, "cid": 12, "plan": "claude", "expires": 1793000000,
 "device": {"id": "<지문 앞 12>", "name": "사무실 PC", "slot": 1, "registered_now": false},
 "devices_used": 1, "devices_max": 2,
 "entitled_presets": ["sseolpulda/A_흰바탕창/창아래_검정"],
 "profiles": [{"profile_id": "cp_…", "name": "내 채널 · 썰", "preset_id": "…", "version": 3}],
 "min_engine": "1.0.0", "min_installer": "1.0.0", "server_time": 1760000000}
```
거절: `device_limit`(403, msg에 "마이페이지에서 기기 교체"), `revoked`/`expired`/`bad_key`/`suspended`/`engine_old`.
`revoked` 를 받으면 PC는 `~/.shortem/cache` 를 비운다.

## 2. POST /api/claude/lease

body: `{"action": "acquire"|"heartbeat"|"release", "job_id": "<job id>", "lease_id"?: "...", "step_name"?: "장면 계획"}`

- acquire 200: `{"ok": true, "lease_id": "ls_…", "ttl": 180, "heartbeat_every": 60}`
  - 같은 기기·같은 job 재취득 = 같은 lease 갱신(멱등).
  - 다른 기기가 활성 lease 보유 → 409 `busy_other_device`, msg "다른 기기(<이름>)에서 작업 중입니다 — 끝나거나 3분 뒤 다시 시도하세요", `retry_after`.
- heartbeat 200: `{"ok": true, "ttl": 180}` / lease 없음·강제 해제됨 → 409 `lease_lost`.
- release 200: `{"ok": true}` (없는 lease 도 ok — 멱등).
- step_name 은 고정 9개 이름 중 하나만 받는다(그 밖이면 `bad_request`).

## 3. GET /api/claude/assets?profile=<profile_id>&job=<job_id>[&lease=<lease_id>][&extra=<kind:id,…>]

`assets_for(cid, profile_id, job)` 결과. 유효 lease 필수(job 일치).

200:
```json
{"ok": true, "job": "j_…", "profile_version": 3, "expires": 1760021600,
 "bundle": { "preset_id": "…", "profile_version": 3, "license": {"cid": 12, "issued": 1760000000, "mark": "<12 hex>"},
             "frame": {…축약…}, "rules": {…}, "options": {…합본…} },
 "assets": [{"id": "font:JalnanGothic", "kind": "font", "sha256": "…", "size": 123, "name": "JalnanGothic.ttf", "url": "<서명 URL 6h>"}]}
```
- `assets` 는 bundle 이 **참조하는 것만**(자산 수 = 참조 수). kinds: `font` `sfx` `bgm` `template` `meme`.
- `extra`: script 단계 뒤 대본 신호어가 고른 구체 짤·효과음(`meme:<id>`, `sfx:<팩>/<파일>`) — 프로필이 허용한 풀 안만, 밖이면 `not_in_plan`.
- 서명 URL: `GET /api/claude/blob/<asset_token>` (HMAC, 만료 6h, 1 URL 1 파일, Range 허용 — 원본 다운로드 경로). 저장소 = 서버 디스크 `CLAUDE_STORE_DIR/assets/<sha256>` (객체 저장소 R2/S3 붙이면 URL 만 바뀐다).

## 4. GET /api/claude/pack/<asset_id>?job=<job_id>

이번 job 의 `assets_for` 목록 안 자산만 서명 URL 재발급: `{"ok": true, "asset": {id,kind,sha256,size,name,url}}`. 목록 밖 → 403 `not_in_plan`(탐지 A5).

## 5. POST /api/claude/feedback

body: `{"kind": "request"|"bug", "text": "≤2000자", "job_id"?: "..."}` → `{"ok": true, "id": 31}`.

## 6. 견본(페이지 전용, 로그인 세션) — GET /api/claude/me/preview/<kind>/<id>?t=<10분 토큰>

- 원본 아님. `CLAUDE_STORE_DIR/preview/<kind>/<id>.<ext>` 만 읽는다. Range 헤더 있으면 403. 세션 쿠키·토큰 둘 다 필요.
- 토큰: `GET /api/claude/me/preview_token` → `{"t": "...", "exp": …}` (세션 cid 묶음, 10분).

## 7. 고객 페이지용(로그인 세션) — /api/claude/me/*

- `GET /api/claude/me/home` → 프리셋 카드·팩 목록(견본 id 만)·내 프로필·라이선스 상태·기기·설치팩.
- `POST /api/claude/me/profile` body `{profile_id?, name, preset_id, options}` → 저장(version+1). 옵션 값은 자산 id 만(검증).
- `POST /api/claude/me/license/issue` → 새 키(kv+1, 옛 키 즉시 무효). 키 원문은 이 응답에서 **한 번만**.
- `POST /api/claude/me/device/remove` `{device_id}` · `POST /api/claude/me/lease/force_release`.
