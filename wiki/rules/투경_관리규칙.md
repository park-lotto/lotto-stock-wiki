# 투자경고 종목 관리 규칙

> 마지막 업데이트: 2026-06-04

## 운영 원칙

1. **관리 종목만 추적** — `pipeline/투경_관리.json`에 등록된 종목만 해제 예측 대상
2. **신규 투경 → 반드시 사용자에게 확인** — 자동으로 추가하지 않음
3. **불필요한 종목은 텔레그램에서 제외** — 관리 외 종목은 "신규" 섹션에만 노출

## 파일 위치

| 파일 | 역할 |
|------|------|
| `pipeline/투경_관리.json` | 관리 종목 목록 (이름/코드/지정일/유형) |
| `raw/투경/투경현황.json` | 전체 활성 투경 종목 (KIND 실패 시 폴백) |
| `raw/투경/투경_{날짜}.json` | 일별 크롤링 결과 |

## 매일 텔레그램 메시지 구조

```
📋 투경 관리 현황 — {날짜}

✅ 관리 종목 (N종목)      ← 등록된 관리 종목만 (비관리 종목 표시 안 함)
  • 종목명 | 지정일

🎉 해제 (N종목)           ← 관리 종목이 투경 목록에서 빠진 경우
  • 종목명

🆕 오늘 신규 투경 (N종목) — 관리 추가하시겠어요?  ← 오늘 지정일인 것만
  • 종목명 | 지정일
→ Claude에게 '투경 관리에 {종목명} 추가해줘' 라고 말하세요
```

**핵심 원칙**: 이미 알고 있던 비관리 종목은 절대 반복 노출 안 함. 오늘 날짜에 새로 지정된 종목만 질문.

## 신규 종목 추가 절차

1. 텔레그램 🆕 섹션 확인 (오늘 지정일 종목만 표시됨)
2. 관심 있으면 Claude에게 `"투경 관리에 {종목명} 추가해줘"` 요청
3. Claude가 `pipeline/투경_관리.json`에 추가
