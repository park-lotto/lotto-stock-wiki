# TTS속도UI

## 완료

- 장면 편집의 선택한 멘트 칸에만 `속도 0.8×~1.4×` 선택기를 표시했다. 1.0× 기본 칸은 선택하지 않으면 숨겨 화면 밀도를 유지한다.
- `sync_speed` 하나를 음성 재합성, 브라우저 미리보기, 최종 FFmpeg 렌더, 캡컷 draft가 함께 읽게 했다.
- 속도 변경 뒤 성우·톤을 다시 골라도 배속이 풀리거나 중복으로 곱해지지 않게 칸별 음성 설정을 보존한다.
- 속도 변경 시 기존 완성본 연결과 VMake 청소조각 캐시를 무효화한다.
- 이미 배속이 적용된 청소조각을 캡컷으로 보낼 때는 `sync_speed`를 제거해 이중 가속을 막는다.
- 마지막 비트의 1초 여운이 빠른 장면을 다시 슬로모션으로 만드는 문제를 실제 MP4 프레임 검사에서 발견해 수정했다.

## 검증

- 로컬 실제 장면 편집 화면 F22에서 선택 칸만 작은 속도 선택기가 보이고 기본 칸은 숨는 것을 브라우저로 확인했다.
- 1.4× 실제 FFmpeg 렌더에서 출력 0.6초가 원본 약 0.84초 프레임까지 진행하는 것을 색상 프레임으로 확인했다.
- 캡컷 draft 영상 소재에 `speed=1.2`가 기록되고 오디오는 재합성본 1.0×로 유지되는 것을 검사했다.
- 관련 테스트 93개 통과.
