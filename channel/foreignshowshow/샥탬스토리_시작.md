3. `git status --short` — **공유 워크트리**(얜샷템 하이브리드·현장썰·썰템쇼 세션이 동시에 씀). 내 파일만 경로 지정 add. `add -A`·stash·checkout·reset 금지.

## 1. 확정 규칙 (사장님 10-18)
- **브랜드 = 샥탬스토리**(장부 `channel/브랜드.json` foreignshowshow). 스타일 = **현장썰**(한국어 나레 + 영어 원음 번역 자막 + 제품) — 강점은 `channel/스타일.json` 현장썰.strengths 에 **항목만 추가**(파일 다시 읽고, 통째 덮어쓰기 금지).
- **순서: 먼저 벤치 그대로 칼카피(방송 원음 위주) → 뒤에 얜샷템처럼 하이브리드로 변형.** 그대로 = 제목 띠·빨간 원·화살표·돈 이모지 같은 것도 우리 식으로 바꾸지 않는다. 바꾸는 건 로고 자리의 우리 브랜드뿐. 다른 점이 생기면 전부 보고(공통 §0-1 8번).
- 판독은 클로드 눈으로(제미나이 판독 금지, 받아쓰기만 무료 키 — 공용 풀 `py tools/calcopy/pull_pool_keys.py`, 10-18 161개). 사람 이름은 화면 글자(자막·이름표)로 확인된 것만, 얼굴 짐작은 '불명'(공통 §0-1 4·10·11번).
- 칼카피 세션끼리 공유: 문서·장부를 바꾸거나 새 사실을 알면 관련 세션에 SendMessage, 받으면 문서 자리 고치고 회신(공통 §0-1 7번). 현장썰 흐름 대조는 `channel/스타일분석/현장썰/쇼핑흐름_1차.md`.
- 벤치 공식 6박자: 0~3초 결말 반응(투자자+빨간 원) → 시연 → 기존 불편 → 숫자 → 지분 경쟁 → 방송 후 결과. 나레 반말 전언체(~는데/~다고), 벤치 나레 연속 3어절 베끼기 금지, 숫자는 출처 있는 것만.
- **역할 나누기**(공통 `tools/calcopy/담당_공통규칙.md`·`지시문_템플릿.md`): 이 세션 = 페이블(지휘·판정만). 손작업 = sonnet, 대본·수리 = opus 담당 에이전트. 담당은 계획 시트까지 → 페이블 OK → TTS 1회 → 렌더. 검수 = `tools/calcopy/검수_매뉴얼.md`.
- **빠르게(얜샷템 하이브리드 세션 도구, 고치지 말고 부르기만 — 수정은 handoff 끝 '엔진 요청')**: 후보는 통째 받지 말고 거른 뒤 고른 것만 1080p(`tools/calcopy/hybrid/screen.py` 방식) · 받아쓰기는 서버 키 풀 `hybrid/server_ai.py asr`(2모델 교차) · 렌더 뒤 `hybrid/checks.py` B표 초안 · 하이브리드판 렌더는 `hybrid/render_jaemi.py`·`render_itssum.py`.
- 동시 담당이 많을 때 무거운 프로세스(ffmpeg·yt-dlp·분석)는 담당당 한 번에 하나. `python -c pass` 3초 넘으면 멈춤.
