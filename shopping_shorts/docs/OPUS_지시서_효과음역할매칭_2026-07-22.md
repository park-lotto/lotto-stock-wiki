## 0. 이 문서를 받은 Opus에게 (작업 규칙)

1. **트랙 격리 필수** (CLAUDE.md): `py tools/track.py start 장면라이브러리` (기존 트랙 폴더 없음 — 새로 만든다. 트랙명이 활성기능과 겹치는지 `track.py list`로 확인 후). 편집은 전부 `.tracks/장면라이브러리/` 절대경로, git은 전부 `-C`. **main 폴더 코드 파일은 하나도 건드리지 마라.**
2. **writing-plans → TDD 구현**: 스펙을 받아 `superpowers:writing-plans`로 태스크 계획을 만들고, `superpowers:subagent-driven-development`(또는 executing-plans)로 태스크 단위 진행. 테스트 먼저.
3. **서브에이전트 보고를 그대로 믿지 마라** — 이 트랙에서 "이탈 없음" 거짓보고 실사고 있었음(handoff 교훈). 컨트롤러가 직접 프로브로 검증.
4. **파일 수정은 Edit 툴로만** — Python 스크립트로 통째 재작성 금지(CRLF 오염, handoff 교훈).
5. **ffmpeg subprocess는 `stdin=subprocess.DEVNULL`** — 없으면 Windows에서 WinError 6로 죽는다(scene_assets.py 관례).
6. **완료 판정 = 실측**: 렌더는 실제 ffmpeg 산출물을 ffprobe로, 라우트는 실제 요청으로. 합성 fixture 통과 ≠ 완료.
7. 끝나면 `py tools/track.py finish 장면라이브러리` — 게이트(문법→import→pytest, "실패가 늘지 않았나" 기준) 통과 시 main 병합 → 3분 내 라이브.

## 1. 구현 요약 (상세는 스펙)

- `scene_match.py`에 `match_sfx`(순수함수) 추가 — `_ROLE_FALLBACK`·`_pick_role_asset` 재사용, Gemini 0회, **중복 허용**(클립 역할패스와 유일한 차이), `beat["sfx"] = {asset_id, match_type:"role", position:"first"|"last"}`.
- `mix_pipeline.run_mix_job`에 삽입 1줄 (기존 `match_scene_assets` 바로 뒤).
- `video_assemble._burn_captions` 확장 — position→초 오프셋은 캡션과 **같은 함수**로 계산(`_caption_segments`/`_caption_durations` 재사용, 중복 계산 금지), BGM 전용 amix 블록을 다중트랙(`나레이션+bg+sfx*`)으로 일반화, `adelay=<ms>:all=1` + 고정 `volume`(deco `sfx_volume`, 기본 60).
- `app.py` — sfx/overlay 업로드·커밋에 role 통제어휘(`scene_assets._ROLES`) 검증 추가.
- `scene_library.html` — sfx 업로드 폼 role 드롭다운.
- `produce.html` — 검수판 🔊 배지 + 빼기 토글(클립 토글 패턴 재사용).

## 2. 함정 미리 알림 (스펙 §4·§10)

- sfx만 있고 BGM 없을 때도 `filter_complex` 경로를 타야 함(현재 video_assemble.py:1086 분기가 단순복사로 빠짐) — `has_sfx`를 분기 조건에 추가.
- `-ar`/`-ac` 사전 규격 고정은 **이번엔 불필요**(amix 방식이라). 옛 설계문서의 그 경고는 concat -c copy 얘기 — 헷갈리지 말 것.
- sfx가 비트보다 길면 다음 비트로 흘러넘침 — v1 알려진 한계, 고치지 말고 그대로 둔다(스펙 §4.3).
- 실 재료 grounding 필수: 사장님께 실제 효과음 파일 몇 개 받아 라이브러리에 담고, 실 대본으로 렌더해 귀로 확인(sfx_volume 기본값 60 튜닝 포함).
