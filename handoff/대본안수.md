# 대본안수 (2026-08-31)

## 무엇을·왜
사장님 제보: 픽업영상 대본 + 스타일 1개를 골랐는데 **A안 하나만** 나옴.

원인(서버로그 실측, shopping-shorts journalctl):
- 같은 shortcode에 두 요청이 12초 간격으로 `200 OK` / `502 Bad Gateway`
- 502 직전 `[insta_facts] 추출 실패: 429 RESOURCE_EXHAUSTED` (Gemini 쿼터)
- `produce.html` s2Generate가 두 요청을 `Promise.all`로 **동시** 발사 → 같은 키를 겹쳐 때림
- 화면은 `_good`(성공분)만 모아 `ok:true`, 경고 조건이 `S2.picked.length` 기준이라
  픽업이 죽은 경우 `1 < 1` = 거짓 → **아무 말 없이 1안**

## 고친 것 (커밋 ad5eae619, main 병합됨)
`shopping_shorts/static/produce.html` s2Generate:
1. 요청을 900ms 간격 **순차** 발사, 429/502면 2.5초 뒤 **1회 재시도**

   서버 error 문구를 함께 노란 힌트로 표시

검증: `node --check`로 JS 문법 통과. **실브라우저 동작 확인은 미실시**(배포 후 필요).
