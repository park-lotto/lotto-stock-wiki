# 숏템메이커 시작 안내 (상세판)

처음 오신 분이 **가입 → 라이브 시청 → 키 등록 → 담기 설치 → (선택) 캡컷 → 첫 영상**까지 가는 길을 순서대로 적었습니다. 한 단계씩 따라 하시면 됩니다. 설치는 PC에서 하고, 휴대폰으로는 설치가 안 됩니다.

## 0. 미리 준비할 것
| 준비물 | 왜 필요한가 |
|---|---|
| 유튜브 또는 인스타그램 채널 | 숏템메이커는 제작 프로그램입니다. 채널 개설은 직접 하셔야 합니다 |
| 구글(지메일) 계정 | 로그인과 제미나이 키 발급에 같이 씁니다 |
| PC + 크롬 또는 엣지 | 담기 프로그램과 캡컷 보내기는 크롬·엣지에서만 됩니다 |

## 1. 사이트 가입
1. **https://shoppingshorts.duckdns.org** 접속
2. **구글로 로그인** (새 비밀번호를 만들지 않습니다. 쓰시던 구글 계정으로 들어갑니다)
3. 처음 로그인하면 **이름 · 전화번호 · 성별 · 연령대** 입력 화면이 뜹니다. 승인 안내에 필요하니 정확히 적어 주세요.
4. 입력 후 **"승인 대기중"** 화면이 보입니다. 관리자가 확인하고 열어 드립니다.
5. 승인되면 같은 주소로 다시 로그인하면 바로 제작 화면이 열립니다.

주의: 구글 계정이 두 개인 분은 **한 계정으로만** 가입하세요. 다른 계정으로 로그인하면 담아둔 영상·키가 안 보입니다.

## 2. 숏템메이커 유튜브 채널 라이브 시청 (필수)
- 숏템메이커 유튜브 채널의 **최근 영상 몇 개는 반드시 시청**하고 시작하세요. 사용법(담기 → 대본 → 장면 → 완성)과 **업데이트되는 내용**을 라이브로 계속 올립니다.
- 라이브 링크: **https://www.youtube.com/live/B3brg_sG_PA?si=Ub3snEkLZfB7xmTj**
- 영상을 보고 나서 아래 3~5단계를 하시면 훨씬 수월합니다. 기능이 바뀌면 새 라이브로 알려 드리니 채널을 구독해 두고 최근 영상을 확인해 주세요.

## 3. API 키 발급과 등록
숏템메이커 이용료와 **별도**로, 각 서비스에 직접 가입해 키를 받는 부분입니다. 아래 **다섯 가지는 모두 등록**해야 제작이 끝까지 됩니다.

### 어디서 보나
- 그림으로 된 단계별 매뉴얼: shoppingshorts.duckdns.org/api_manual.html

### 무엇을 받나 — 전부 필수
| 서비스 | 쓰는 곳 | 비용 | 필수 여부 |
|---|---|---|---|
| 구글 제미나이 | 대본 뽑기 · 영상 분석 · 썸네일 | 무료 | **필수** (1개만, 공용) |
| 일레븐랩스 | AI 목소리 | 유료(본인 결제) | 목소리 둘 중 하나 **필수** |
| 타입캐스트 | 한국 성우 목소리(필재·김건·박창수·용식 등) | API 요금제 유료(본인 결제) | 목소리 둘 중 하나 **필수** |
| VMake | 원본 영상 자막 지우기 | 유료(본인 결제) | **필수** |
| SerpApi | 비슷한 영상 찾기(파워검색) | 월 250회 무료 | **필수** |
| 유튜브 | 유튜브 영상 정보 가져오기 | 무료 | **필수** (1개만, 공용) |

### 발급하는 곳
| 서비스 | 발급 페이지 | 키 모양 |
|---|---|---|
| 구글 제미나이 | aistudio.google.com/apikey → 「API 키 만들기」 | `AIza…` 한 줄 |
| 일레븐랩스 | elevenlabs.io → 왼쪽 아래 내 사진 → API Keys → Create → **오른쪽 권한(Permissions) 전부 허용** → Create | `sk_…` 한 줄 (한 번만 보여줌) |
| 타입캐스트 | typecast.ai 로그인 → **typecast.ai/pricing/api 에서 API 요금제(Lite) 결제** → API 키 만들기 | `__plt…` 한 줄 (한 번만 보여줌) |
| VMake | vmake.ai/developers → Dashboard → API key 에서 **API Key**와 **Secret Access Key** 두 개 복사 | 설정의 **자막 지우기 칸 두 개**에 각각 붙여넣기(윗칸 API Key · 아랫칸 Secret Access Key). 콜론으로 합치지 않습니다 |
| SerpApi | serpapi.com/manage-api-key (전화번호 인증) | 영문·숫자 긴 한 줄 |
| 유튜브 | 구글 클라우드에서 YouTube Data API v3 사용설정 → API 키 만들기 | `AIza…` 한 줄 |

### 타입캐스트에서 가장 많이 틀리는 것
- 타입캐스트는 요금제가 **두 가지**입니다. 홈페이지의 Pro($29) 같은 것은 **에디터 요금제**라 결제해도 숏템메이커에서는 안 됩니다.
- 반드시 **typecast.ai/pricing/api** 에서 **API 요금제(Lite $15/월)** 를 결제하세요.
- 결제 안 된 무료 계정으로 키를 넣으면 "비정상 활동이 감지되었습니다(UNUSUAL_ACTIVITY_DETECTED)"가 뜹니다. API 요금제 결제 후 다시 확인을 누르면 풀립니다.
- 타입캐스트 성우는 **본인 타입캐스트 키가 있어야만** 쓸 수 있습니다. 키 없이 고르면 안내문과 함께 막힙니다. 등록 전까지는 일레븐랩스 성우를 골라 주세요.

### 등록하는 법
1. 화면 오른쪽 위 사람 아이콘 → **마이페이지 → 🔑 내 키 등록**
2. 해당 서비스 칸에 붙여넣고 **저장**. 앞뒤 공백·줄바꿈이 끼면 "키가 틀렸습니다"가 뜹니다.
   - VMake는 칸이 **두 개**입니다. 윗칸 API Key, 아랫칸 Secret Access Key를 따로 넣습니다. 합쳐 넣지 마세요.
   - 일레븐랩스 키는 만들 때 **오른쪽 권한을 전부 허용**해야 목소리 생성이 됩니다.
3. 저장하면 그 자리에서 키가 맞는지 확인해 **● 정상**으로 표시됩니다. 틀리면 이유를 알려줍니다.
4. 제미나이는 예비로 2~3개 넣어 두시면 하나가 멈춰도 이어집니다(서로 다른 프로젝트에서 만든 키).

주의: 키는 본인 요금이 나가는 열쇠입니다. 단톡방·화면공유에 노출하지 마세요. 노출됐으면 그 사이트에서 폐기하고 새로 받으세요.

## 4. 담기 프로그램 설치 (필수)
유튜브·틱톡·인스타·샤오홍슈·도우인에서 마음에 든 영상을 클릭 한 번으로 담는 크롬 확장프로그램입니다. 이게 있어야 소재를 모읍니다.

1. PC 크롬(또는 엣지)에서 **shoppingshorts.duckdns.org/grab** 접속
2. 설치 파일을 받아 **압축을 풉니다**
3. 크롬 주소창에 `chrome://extensions` 입력
4. 오른쪽 위 **개발자 모드** 켜기
5. 압축 푼 **폴더**를 그 화면에 끌어다 놓기

- zip 파일이 아니라 **압축을 푼 폴더**를 넣어야 합니다.
- 텀퍼몽키 같은 다른 프로그램은 필요 없습니다.
- 설치 후 유튜브·인스타 영상 화면에 **📥 담기** 버튼이 보이면 성공입니다.

## 5. 캡컷 연동 (원하시는 분만)
- 완성 영상을 캡컷에서 더 다듬고 싶은 분만 합니다. 숏템메이커에서 바로 받거나 QR로 폰에 보내실 분은 이 단계를 건너뛰세요.
- 한 장 안내(3단계): **shoppingshorts.duckdns.org/capcut_easy.html**
- 처음 두 번만 따라 하시면 그 뒤로는 **보내기 한 번**으로 캡컷에 들어갑니다.
- 캡컷 보내기도 크롬·엣지에서만 됩니다.

## 6. 첫 영상 만들기
1. 유튜브·인스타에서 마음에 든 영상에서 **📥 담기**
2. 제작소에서 담긴 영상으로 대본 → 장면 → 목소리 → 완성
3. 완성본은 바로 받거나 QR로 폰에 보내거나, 캡컷으로 보냅니다

## 7. 이용 한도와 무료 범위
- 렌즈로 찾기 하루 10번 · 영상 만들기 하루 10편. 남은 횟수는 마이페이지 → 내 계정에서 보입니다.
- 영상 찾기 · 즐겨찾기 · 내보내기는 무료입니다.
- SerpApi 키를 등록하면 렌즈 횟수가 키 1개당 10번씩 늘어납니다.

## 8. 수익화에 필요한 계정 (나중에)
- 쿠팡파트너스: 8단계에서 **본인 계정의 추적 링크**를 넣어야 수수료가 붙습니다.
- 인포크링크: 프로필에 거는 링크인비오 서비스입니다.
