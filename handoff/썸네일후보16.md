# 3차 (2026-08-27) — 12장(6×2) + 미리보기 엘리베이터

## 사장님 요청
> "썸네일을 스크롤 내릴때마다 따라서 움직일수있게 엘리베이터같이"
> "이만큼만 썸네일 12개들어가게 하고 위쪽까지 썸네일 움직이게" (화면에 직접 범위를 그어 주셨다)

## ★★ 이번 세션 최대 발견 — sticky가 이 페이지에서 **처음부터 죽어 있었다**

뿌리는 `.main{overflow:auto}` 한 줄이다.

```
position:sticky는 **가장 가까운 스크롤 조상**을 기준으로 붙는다.
.main에 overflow:auto가 있으면 그 자리를 .main이 차지한다.
그런데 .main은 높이 제한이 없어 **실제로는 스크롤되지 않는다**
  (실측: main.scrollHeight == main.clientHeight == 2756).
→ 기준은 잡혔는데 그 기준이 움직이지 않으니 sticky가 **아무 일도 안 한다**.
   에러도 경고도 없다. 그냥 조용히 안 붙는다.
```

즉 이 페이지의 `.previewSlot` **3곳이 전부 무력**이었다:
- 0단계 꾸미기 미러 (1449행 `.previewSlot decoMirror`)
- 4단계 믹스 미리보기 (2170행 `#mixPreviewPanel.previewSlot`)
- 7단계 썸네일 미리보기 (이번에 붙인 것)

주석에는 "sticky·상단고정 규약을 공유한다"고 적혀 있었지만 **실제로는 셋 다 안 붙고 있었다.**
주석이 선언한 계약을 아무도 검사하지 않은 전형적인 사례
(메모리 `reference_prompt_says_but_nobody_checks`와 같은 모양).

### 고친 방법
```css
/* 전 */ .main{flex:1;padding:24px 32px;overflow:auto}
/* 후 */ .main{flex:1;min-width:0;padding:24px 32px}
```
`min-width:0`은 `admin.html`이 이미 쓰는 패턴 — flex 자식이 내용 최소폭 때문에 사이드바를
밀지 않게 한다(overflow를 뺐으니 이게 가로 넘침 방어를 대신한다).
**실측: 가로 스크롤 안 생김**(문서폭 1905 == 창폭 1905).

⚠️ 다른 페이지(collection·discover·find·index·library·outreach·scene_library·produce_intro)도
   같은 `.main{overflow:auto}`를 쓴다. **거기 sticky를 붙일 일이 생기면 같은 함정을 밟는다.**

## 나머지
- `GRID_FRAMES_DEFAULT = 12` (10 → 16 → 12). `.thumbFrameGrid` 6열(반응형 4/3/2).
  한 칸 191px(16장 때 181px). ★장수를 바꾸면 열 수도 같이 봐야 한다.
- **"위쪽까지"** — 프레임 고르개를 **편집 칼럼 안으로** 옮겼다. 종전엔 flex 줄 **밖 위쪽**이라
  sticky를 걸어도 프레임을 고르는 동안엔 결과가 안 보였다(sticky는 제 부모 안에서만 산다).
- 생성 결과(갤러리)도 같은 칼럼 **맨 아래**로 옮겼다 — 밖에 두면 거기 도달한 순간
  미리보기가 같이 사라진다.

```

"얼린고기"                     248px
"얼린고기 보관은 이렇게 하세요"   135px   ← 3.1배 차이
```

**사장님 지시**: "1로 해주고 작으면 각자 크기조정으로"
→ 처음 잡은 크기를 그 레이어 기준으로 **계속 쓴다. 자동으로 도로 줄이지 않는다.**

- `THUMB_FIT_HOLD = WeakMap(레이어 → {ratio})`
  ★WeakMap인 이유: 레이어 객체는 **그대로 서버에 저장된다**(썸네일 meta). L에 필드를
  심으면 저장 데이터가 오염되고, 인덱스로 담으면 순서가 바뀔 때 어긋난다.
- 비율(size/W)로 담는다 — 미리보기(270)와 저장(1080)이 같은 그림이어야 한다.
- 슬라이더 몫(scale)은 **빼고 담고 쓸 때 다시 곱한다**(두 번 곱하면 커진다).
- 빈 칸에선 안 잡는다(0으로 굳는다). 배지·스티커·도형 제외(글자 레이어만).

**결과**: 타이핑 422/422/422/364/364, 손 뗀 뒤에도 **364 유지**(종전엔 175로 도로 축소).
