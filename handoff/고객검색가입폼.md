  `sdw` 같은 입력에 무관한 고객이 우수수 걸린다. 칸을 합쳐 검색하면 그렇게 된다.

### ② 가입할 때 이름·전화 받기

**진짜 원인은 가입폼이 아니라 구글 로그인이었다.** 폼엔 이미 이름·전화 칸이
있었는데(필수가 아니었을 뿐), `get_or_create_by_google`이 email만 넘겨서
구글 가입은 이름·전화가 **아예 안 들어온다** → 179명 대부분이 빈칸이었다.

- 새 컬럼 `customers.welcome_due` (기본 0)
  - 구글 신규가입 / 아이디 가입을 빈칸으로 낸 경우에만 1
  - ★**기본이 0이라 기존 고객은 화면이 안 바뀐다**(갑자기 안 붙잡힌다)
- `/welcome` — 이름·전화 입력 화면(전화 자동 하이픈). 미들웨어가 대기실보다 **먼저** 보낸다
  - ⚠️ `/welcome`·`/api/welcome`은 **pending 게이트도 통과**시켜야 한다.
    안 그러면 위에서 /welcome으로 보내놓고 아래 pending이 대기실 HTML을 돌려줘
    **입력칸이 영영 안 보인다**(실측으로 잡음)
- 아이디 가입폼: 이름·전화 `required` + **서버에서도 검증**(required는 브라우저 힌트일 뿐)
- 저장은 관리자 '정보수정'과 **같은 `update_customer_info` 재사용**(0순위-B)

## 2026-08-24 (2차) — 성별·연령대 추가 + 기존 고객 백필

사장님 지시: "다음 접속시 띄워서 채워줘. 성별도" + "연령대도".
받는 것: **이름·전화·성별(남/여)·연령대(20~50대·기타)** — 넷 다 필수.

### 백필 — 기존 179명도 대상이 됐다

판정을 `welcome_due` 플래그가 아니라 **실제로 비었는가**(`_welcome_missing`)로 바꿨다.

- 비어 있는 칸이 하나라도 있으면 다음 접속 때 한 번 물어본다
- 이름·전화가 이미 있는 분은 **그 값이 미리 채워져** 나온다(다시 안 친다)
- 다 채우면 자연히 안 뜬다 — 플래그가 아니라 **상태**라 갇힐 일이 없다

### ★게이트 순서 — 이 작업에서 제일 중요한 것

마무리 게이트는 **모든 접근권한 판정 뒤**에 있어야 한다.
앞에 뒀더니 이 303 리다이렉트가 관리자게이트·유료게이트보다 먼저 떠서
**무관한 테스트 36건**이 403 대신 303을 받았다(막혀야 할 사람이 안 막힌 것처럼 보임).
여기까지 왔다 = 원래 들어갈 수 있는 사람이고 정보만 덜 낸 것 — 그때만 붙잡는다.

### ★화면 이동(GET 문서)만 붙잡는다 — API는 안 막는다

API까지 막으면 **이미 열려 있던 화면이 갑자기 오류를 뱉는다**.
사람은 다음 화면 이동 때 입력하면 된다.
판정은 `Sec-Fetch-Mode: navigate` (실측: 크롬이 실제로 보낸다.
TestClient는 안 보내므로 **테스트에 헤더를 직접 붙여야** 실제와 같은 조건이 된다).

### 그 밖에

- 목록에 없는 값은 서버가 반려한다 — `required`는 브라우저 힌트일 뿐 curl로 뚫린다
- 가입폼에서도 성별·연령을 받는다 → 가입 직후 `/welcome`으로 또 끌려가지 않는다
- 관리자 고객표에 성별·연령 열 + 검색 대상 포함(`여성 30대`로 추려진다)
- 선택지는 `_GENDER_OPTS`/`_AGE_OPTS` **한 곳**만 본다(화면·검증·가입폼 공용, 0순위-B)

### 함정 기록 (실측으로 두 번 틀린 것)

- ★**알약 레이아웃에 `nth-child` 번호를 세지 마라** — input+label 쌍이라 한 칸
  어긋나 엉뚱한 알약(50대)이 넓어졌다. `auto-fit`도 안 된다 — 브라우저가 4칸으로
  잡아 '기타'만 홀로 아랫줄에 남는다. **5칸 명시**가 답(760/380/330px 전부 1줄 확인)
- 관리자표 성별칸이 눌려 `여 성`/`40 대`로 글자가 쪼개졌다 → `nowrap`+최소폭.
  칸 번호(nth-child) 대신 **클래스**를 달았다(열이 늘면 번호는 통째로 어긋난다)
- 픽스처가 새 필수값을 안 내면 **무관해 보이는 테스트가 깨진다**(3건). 검증을 무르지
  말고 픽스처를 고쳐라
