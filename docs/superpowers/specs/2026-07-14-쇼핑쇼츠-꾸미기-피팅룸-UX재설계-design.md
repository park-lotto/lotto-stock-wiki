# 쇼핑쇼츠 꾸미기(5단계) — "피팅룸" UX 재설계

**날짜**: 2026-07-14
**상태**: 설계 승인됨, 구현 대기
**관련**: `shopping_shorts/static/produce.html`(step5 패널 = `data-step="4"`), 선행 `2026-07-14-쇼핑쇼츠-꾸미기-레퍼런스반영-design.md`(강조단어·프리셋)

## 1. 배경·문제

사용자가 현재 꾸미기 페이지 스크린샷 4장으로 불만을 명확히 전달:
1. **버튼 벽**: 완성스타일 19개 + 헤드카피 프리셋 11개 + 자막 프리셋 5개가 전부 펼쳐져 "뭘 눌러야 할지 모르겠고 어수선."
2. **완성본을 못 봄**: 추상적 버튼·슬라이더 대신 "직접 옷 피팅해보는 것처럼" 실제 장면 위에 완성본이 얹힌 걸 보면서 고르고 싶다(레퍼런스 랭킹 카드의 실썸네일+자막 느낌).
3. **터치 과다**: 폰트/색/크기/위치/외곽선/박스/자막스타일 슬라이더가 다 노출. "최적 샘플 하나를 기본으로 두고 최소한의 터치, 세부는 고급으로 감춰라."

핵심 철학: **딸깍 원클릭** — 진입하면 이미 완성돼 있고, 원할 때만 손댄다.

## 2. 현재 구조 (변경 대상)

`produce.html` step5 패널(`data-step="4"`, line 169~)이 위→아래로 전부 펼침:
- 🎯 완성 스타일 19버튼(`#fullPresets`, `renderFullPresets()` line 481, `applyFullPreset(i)`)
- 🎯 강조 단어(`#highlightRuleList`)
- 헤드카피 문구 input + 폰트/색/굵기/크기(slider)/세로·가로위치(slider)/정렬/외곽선/배경박스
- 🖱️ 실시간 미리보기: `#hcPreview`(340px 9:16), `#hcPreviewBg`(실장면 img), `#hcPreviewText`. `실장면 배경` 체크박스(`#sceneBg`, `toggleSceneBg()` line 624)가 `/api/produce/mix/poster/{MIX_JOB}`에서 프레임을 로드. **기본 꺼짐(흰 배경).**
- 💬 자막 스타일(폰트/색/크기/위치/외곽선/박스/효과)

재사용 자산: `FULL_PRESETS`(19종, 각 `{name,chip,hc,cap,extra?}`), `applyFullPreset`, `updateHC`, `fontCss()`, `PREVIEW_W=340/VIDEO_W=1080` 스케일, poster 엔드포인트, 강조단어 UI.

## 3. 새 레이아웃 — "피팅룸"

step5 패널을 좌우 2열(모바일은 세로 스택)로:

```
┌── 좌: 🪞 피팅 미러 ────────┬── 우: 최소 컨트롤 ──────────────┐
│ #hcPreview 확대(≈380px)   │ [헤드카피 문구 input]           │
│ · 실장면 배경 기본 ON      │                                │
│ · 기본 스타일 자동 적용    │ 스타일 고르기(가로 필름스트립)   │
│ · 글자 드래그 위치이동 유지 │ [카드][카드][카드][카드][카드]  │
│                          │  ↑각 카드=실장면 poster+그스타일 │
│                          │  [+ 더보기](나머지 14 펼침)     │
│                          │ 🎯 강조 단어(간단 행)            │
│                          │ ▸ ✏️ 직접 다듬기(고급) [details] │
└──────────────────────────┴────────────────────────────────┘
```

노출: **문구 입력 + 스타일 카드 + 강조단어**만. 나머지 전부 접힘.

## 4. 컴포넌트 상세

### 4-1. 진입 자동 완성 — `applyDefaultStyleOnEntry()`
- step5 패널이 처음 표시될 때(패널 전환 훅 또는 `MIX_JOB` 준비 시) 1회:
  - 아직 사용자가 스타일을 고르지 않았으면(플래그 `STYLE_TOUCHED=false`) 기본 프리셋 자동 적용: **`applyFullPreset(DEFAULT_STYLE_IDX)`**. 기본값 = **"임팩트 옐로"**(레퍼런스 빅채널 흰+노랑 톤). `FULL_PRESETS`에서 name으로 인덱스 조회(순서 바뀌어도 안전).
  - `MIX_JOB`이 있으면(2단계 매칭 완료) 실장면 배경 자동 ON: `#sceneBg.checked=true; toggleSceneBg()`. 실패(poster 없음)하면 기존 `toggleSceneBg`의 onerror 폴백(흰 배경)에 맡김 — 에러 alert는 자동진입 경로에선 억제(조용히 흰배경 유지).
- 사용자가 카드/슬라이더를 건드리면 `STYLE_TOUCHED=true` → 재진입해도 덮어쓰지 않음.

### 4-2. 스타일 카드 필름스트립 — `renderStyleCards()`
- `#fullPresets`(기존 19버튼 컨테이너)를 카드 스트립으로 교체.
- **대표 5장**: `FEATURED = ['모던 화이트','임팩트 옐로','옐로 2톤 A','네온 글로우 화이트','레드 강조']`(name 배열; 인덱스는 name 조회). 나머지 14장은 `[+ 더보기]` 토글로 펼침(`MORE_OPEN` 상태).
- **각 카드 = 실장면 위 그 스타일**(사용자 선택 방식):
  - 카드 = 작은 9:16 박스(≈84×150px). 배경 = poster 이미지(`/api/produce/mix/poster/{MIX_JOB}`, `MIX_JOB` 있을 때만; 없으면 스타일 chip색 그라데이션 폴백). 모든 카드가 **같은 poster** 1장 공유(스타일만 다름).
  - 카드 안 텍스트 = 사용자가 입력한 헤드카피 문구(있으면), 없으면 샘플 `"이거 실화?"`. 그 프리셋 `hc`의 font/color/size(카드 스케일로 축소)/outline을 CSS로 렌더 — `updateHC` 프리뷰와 동일 기법(`fontCss`, textShadow 외곽선, box 배경). 2톤 프리셋(`extra` 有)은 2줄로 근사 표시.
  - 하단 라벨 = 프리셋 name(작게).
  - 현재 선택 카드 = 테두리 강조(`outline:2px var(--accent2)`).
- 탭 → `applyFullPreset(idx)` + `STYLE_TOUCHED=true` + 미러 갱신(applyFullPreset이 이미 updateHC/updateCaption 호출) + 카드 선택표시 갱신.
- 문구 입력이 바뀌면 카드 텍스트도 갱신(디바운스 불필요, 가벼움) — `updateHC` 끝 또는 문구 oninput에서 `renderStyleCards()` 재호출(단, poster 재요청은 하지 않도록 캐시된 poster URL 재사용).

### 4-3. 고급 접기 — `<details>✏️ 직접 다듬기`
- 기존 헤드카피 세부(폰트picker/색/굵기/크기slider/세로·가로위치slider/정렬/외곽선/배경박스) + 헤드카피 프리셋 11버튼(`#hcPresets`) + 자막 스타일 블록 전체 + 내 프리셋 저장(`#myPresets`)을 하나의 `<details>`(기본 접힘)로 이동.
- `<summary>✏️ 직접 다듬기 — 폰트·크기·위치·자막·내 프리셋 ▾</summary>` 스타일은 코드에 이미 있는 `고급 ▾ <details>`(line 154) 패턴 재사용.
- 접힌 상태에서도 미러는 현재 스타일을 그대로 보여줌(값은 STATE에 있음). 펼쳐서 조정 시 실시간 반영(기존 updateHC/updateCaption 그대로).

### 4-4. 유지(변경 없음)
- `updateHC`/`updateCaption`/`applyFullPreset`/`applyConfig`/강조단어 함수/드래그(`bindHCDrag`)/자막·강조 렌더 — 로직 그대로. 이동/재배치만.
- 렌더 파이프라인(`video_assemble.py`)·서버 무변경.

## 5. 데이터/상태
- 신규 전역: `STYLE_TOUCHED`(bool), `MORE_OPEN`(bool), `DEFAULT_STYLE_NAME='임팩트 옐로'`, `FEATURED`(name 배열), `POSTER_URL_CACHE`(문자열|null).
- 기존 `STATE.headcopy/captionStyle/deco` 구조 불변.

## 6. 엣지 케이스·에러 처리
- **poster 없음(2단계 매칭 전 step5 접근)**: 카드·미러 배경은 chip 그라데이션/흰배경 폴백. 자동 sceneBg는 조용히 스킵(alert 없음). 사용자가 수동 실장면 배경 켜면 기존 경로(매칭 필요 alert) 유지.
- **문구 미입력**: 카드는 샘플 텍스트, 미러 텍스트는 빈 상태(기존 동작). 렌더 시 헤드카피 없으면 안 굽는 기존 로직 유지.
- **FEATURED name이 FULL_PRESETS에 없을 때**: 조회 실패 name은 건너뛰고 로그 없이 스킵(안전).
- **재진입**: `STYLE_TOUCHED=true`면 기본 재적용 안 함(사용자 선택 보존).

## 7. 테스트/검증(브라우저 실렌더 grounding)
- step5 진입 시: 기본 스타일 적용됨 + (job 있으면) 실장면 배경 ON + 미러에 완성본 표시.
- 카드 5장이 poster(또는 폴백) 위에 각 스타일 텍스트로 렌더됨. 탭 시 미러 스타일 변경 + 선택 표시 이동.
- "더보기" 클릭 시 나머지 14장 표시.
- "직접 다듬기" 기본 접힘 → 펼치면 모든 슬라이더/자막/내프리셋 존재, 조정 시 미러 실시간 반영.
- 문구 입력 시 카드·미러 텍스트 갱신.
- 회귀: 기존 mix/settings 저장 payload(headcopy/caption_style/deco) 동일, 최종 렌더 정상.

## 8. 범위 밖
- 카드에 자막(캡션) 미리보기까지 얹기(자막은 비트별 동적이라 카드엔 헤드카피만). 
- poster 여러 프레임 중 선택(현재 단일 프레임 유지).
- 완성스타일 자동추천(카테고리 기반 자동선택)은 이번 범위 아님(사용자가 고르는 "피팅" 유지).
- `video_assemble.py`/서버 변경 없음.
