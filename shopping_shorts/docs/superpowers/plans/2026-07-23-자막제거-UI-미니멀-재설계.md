# 자막제거 2단계 UI 미니멀 프리미엄 재설계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 영상제작소 2단계(자막제거) 화면에서 "VMake" 이름을 완전히 없애고, 최대한 동적인 "잘 만든 프로그램" 느낌의 미니멀 프리미엄 UI로 교체한다.

**Architecture:** 순수 표시층 교체 — 백엔드 로직·라우트·과금·폴링 무변경. `static/produce.html`의 2단계 마크업/CSS/상태렌더 JS를 갈아끼우고, 사용자에게 노출되는 백엔드 에러 문구 3파일의 "VMake" 문자열만 "AI 자막 제거"로 바꾼다. 모션은 전부 CSS 키프레임(라이브러리 무추가)이며 `prefers-reduced-motion`을 존중한다.

**Tech Stack:** 바닐라 HTML/CSS/JS(기존 produce.html 인라인), pytest(문자열 존재 검사 회귀 테스트), FastAPI(백엔드 문구).

**작업 폴더:** `.tracks/자막제거UI재설계` — 모든 편집은 이 트랙 폴더 절대경로로. git은 `git -C .tracks/자막제거UI재설계`.

**참조 스펙:** `shopping_shorts/docs/superpowers/specs/2026-07-23-자막제거-UI-미니멀-재설계-design.md`

SRC = Path(__file__).resolve().parents[1]


def test_vmake_client_user_strings_have_no_vendor_name():
    txt = (SRC / "vmake_client.py").read_text(encoding="utf-8")
    # raise/예외로 사용자에게 닿는 문구에 "VMake"가 없어야 한다(주석은 무관하지만

    # 새 브랜드명이 최소 한 번은 등장

        if "raise RuntimeError(" in l and "자막 제거가 켜져" in l:
