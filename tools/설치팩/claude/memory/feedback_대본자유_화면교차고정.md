믹스 대본·화면의 우선순위 기준 (2026-08-03 사장님 확정):

- **대본**: 두 영상의 멘트를 섞든, 한 영상 것만 쓰든 **상관없다**. 어차피 우리가 각색해서
  원본과 다른 내용으로 보이게 만드는 게 본체다. "원본 두 개를 다 반영해야 한다"는 제약을
  대본에 걸지 마라.
- **화면(영상 소스)**: 지금 규칙(두 컷씩 교차, 3연속 금지, 시간순 불변식)대로 **반드시 섞는다.
  이 기준은 흔들리면 안 된다.**

**Why:** 시청자가 "베낀 영상"으로 인식하는 건 화면 패턴(한 영상이 통으로 나오는 것)이지
대사 출처가 아니다. 대사는 각색이 가리고, 화면은 교차만이 가린다.

**How to apply:** 대본 품질 개선(약한 소스 멘트 비중 축소 등)을 할 때 대사 쪽은 자유롭게
설계해도 되지만, 화면 교차 로직(keep_order·두 컷 묶기·첫 장면 차별화)은 건드리지 말 것.
