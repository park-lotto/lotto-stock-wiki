# 장면꾸미기 기존 탭 통합

- 관리자 카나리의 템플릿 선택에 `템플릿 없이`, `기존 스타일`, `썰쇼핑형 20`, `전장면 고정형 20` 네 갈래를 배치했다.
- `템플릿 없이`는 기존 장면꾸미기의 직접 다듬기만, `기존 스타일`은 기존 완성 스타일·내 프리셋을 그대로 보여준다. 기존 DOM과 저장 함수를 재사용해 같은 설정을 새 코드에 복제하지 않았다.
- 새 두 템플릿 탭은 계속 격리 LAB 복사본에만 저장한다. 기존 두 탭으로 나갈 때는 현재 원본 작업 저장 화면임을 노란 안내문으로 명시하고, 새 탭으로 돌아오면 LAB iframe을 다시 사용한다.
- 새 편집기 → LAB → 제작소, 제작소 → LAB → 새 편집기 양방향 메시지를 분리했다. 관련 테스트 23개와 로컬 Chrome 네 탭 노출을 확인했다.
