# 핸드오프 — 레퍼런스추적 (URL로 원본/유사 영상 역추적)

날짜: 2026-07-19 (회사PC) · 트랙 `레퍼런스추적` · 브랜치 `track/레퍼런스추적`

## 무엇을 만들었나
레퍼런스 랭킹 페이지(`index.html`, shoppingshorts.duckdns.org) 맨 위 "➕ 레퍼런스 채널 등록" **바로 아래**에
**"🔗 URL로 레퍼런스 추적"** 위젯 신설. 링크 붙여넣기 → 구글렌즈(SerpApi)로 원본/유사 영상 → 결과는
기존 `renderLens` 재활용(담기 공짜). 채널 등록·수집·랭킹 경로를 안 거침.

## 완료·라이브 (origin/main)
- 백엔드 `POST /api/lens/trace_url` (`app.py`) — URL→대표이미지→`search_similar_videos`. 월 100회 가드 재사용.
- 프런트 위젯 + `traceByUrl()` (`index.html`, 슬라이스 마커 `TRACE-START/END`).
- **유튜브 봇차단 수정**: 서버(데이터센터 IP) yt-dlp가 유튜브 다운로드 막힘 → 유튜브는 **다운로드 없이
  공개 썸네일**(`i.ytimg.com`)을 렌즈에 직행(`_lens_image_for_url`). 비유튜브는 download_any 중간프레임,
  실패 시 oEmbed 썸네일 폴백.
