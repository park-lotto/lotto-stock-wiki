# 담기썸네일 — 제작소 씨앗 카드 썸네일이 안 뜨는 문제 (2026-09-21, 사장님 PC)

## 증상
제작소 2단계 씨앗 카드 5장 중 4장이 회색 필름 아이콘(사장님 제보 "썸네일이 안보임").
work=e285b3705796 / job=13d4cab55fba

## 진짜 원인 — /api/thumb도 화이트리스트도 아니었다
DB 실측: `mix_basket.thumbnail`이 **담길 때부터 빈 값**. 5건 중 4건 NULL이고
화면에 그림이 뜬 1건(reviewnara0728)만 값 보유 — **화면과 DB가 정확히 일치**.
이름·캡션·조회수·팔로워도 함께 비어 있었다.

뿌리는 `media_download._ig_cookies_file()`의 한 줄:
```python
_cands += [str(p) for p in Path(_d).glob("*.json")]   # ★최상위만 본다
```
살아있는 계정 11개는 08-09 풀 분리로 `ig_sessions/reference/`(하위 폴더)에 있는데
이 glob은 하위 폴더를 못 본다. 최상위엔 **8/9자 낡은 세션 하나**만 남아 있어서
"가장 최근 갱신"이 6주 묵은 죽은 계정으로 뽑혔고, 인스타가 로그인 페이지로
리다이렉트("exceeded the rate-limit")해 메타 수집이 전부 실패했다.

수집기(`channel_archive.session_slots`)는 하위 폴더를 제대로 봐서 멀쩡했다 —
**같은 판단("어느 세션을 쓰나")이 두 군데 다르게 적힌 것**이 사고의 형태다(0순위-B).

## 고친 것 (커밋 24205def3 · 2b24272e3, main 병합 e413e8266)
- `_ig_cookies_file()`이 `channel_archive.session_slots(pool="reference")`를 **빌려 쓴다**
  (직접 glob 금지 — 다시 갈라지면 같은 사고).
- `session_alive`로 죽은 세션을 거른다(10분 캐시). mtime만 보면 죽은 최신을 또 집는다.
  판정이 전부 실패하면 후보 전체로 되돌려 무쿠키 회귀를 막는다.
- 테스트 3개: `shopping_shorts/tests/test_ig_cookies_uses_pool.py`
- 복구 도구: `tools/backfill_grab_thumbs.py`

## ⏭ 남은 일
- **과거분 복구가 아직 남았다.** 오늘치(`--days 0`)만 반영했다(작업 1개·바구니 46건).
  최근 7일 기준 **바구니 168건 · 작업 60개**가 여러 고객에 걸쳐 남아 있다:
  ```

  sudo -E python3 -u tools/backfill_grab_thumbs.py --days 7 --dry-run    # 먼저 본다
  sudo -E python3 -u tools/backfill_grab_thumbs.py --days 7 --sleep 1.5  # 반영
  ```

  ⚠️ 인스타 레이트리밋 — `--sleep`을 줄이지 마라.

  썸네일이 못 뜨고 있다는 뜻 — `fetch_thumb_bytes` 보관함이 제작소 경로에도
  걸려 있는지 따로 봐야 한다.
