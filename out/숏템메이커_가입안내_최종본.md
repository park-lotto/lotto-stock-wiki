# 숏템메이커 — 가입 후 준비 안내 (최종본)

> 2026-08-25 기준 · 웹 정본: **shoppingshorts.duckdns.org/setup**
> 이 문서는 위 페이지와 같은 내용입니다. 단톡방·카톡에 그대로 붙여 쓰셔도 됩니다.

숏템메이커는 **제작 프로그램**입니다. 채널 자체는 미리 준비돼 있어야 합니다.
준비할 것은 크게 **세 가지**이고, ①②는 필수, ③은 원하는 분만 하시면 됩니다.

| | 무엇 | 필수 여부 |
|---|---|---|
| ① | 채널 개설 + API 키 발급 | 채널 = 필수 / 키 = 선택 |
| ② | 📥 담기 확장프로그램 설치 | **필수** |
| ③ | 캡컷 연동 | 선택 |

**공통 준비물**: PC + **크롬 또는 엣지**. 담기 확장프로그램과 캡컷 보내기는 크롬·엣지에서만 동작합니다. 휴대폰이나 다른 브라우저로는 설치가 안 됩니다.

---

## ① 채널 개설 + API 키 발급

### 1-1. 미리 해두셔야 하는 것

- **유튜브 또는 인스타그램 채널 개설** — 개설 방법 자체는 제공되지 않습니다
- **채널 기본 운영 준비** — 프로필·채널명 등 기본 세팅
- **구글 계정** — 숏템메이커 로그인과 제미나이 키 발급에 함께 씁니다

### 1-2. 가입과 첫 로그인

1. 신청하신 **구글 계정**으로 `shoppingshorts.duckdns.org` 로그인
2. **가입 즉시 체험이 자동으로 시작되고 포인트 50P가 함께 들어갑니다** (따로 요청 불필요)
3. 잔액은 **👤 마이페이지**에서 확인 — 0P로 보이면 단톡방·카톡으로 알려주세요

### 1-3. API 키 — 안 받으셔도 됩니다

키를 등록하면 그 작업은 **포인트가 안 깎입니다.** 등록하지 않아도 **포인트 차감 방식**으로 그대로 쓰실 수 있습니다. 5개를 다 하실 필요 없고, 쓰실 기능만 하시면 됩니다.

**갈래가 두 개입니다.**

- **㉠ 키 1개만 내면 무료로 쓰는 것 — 구글 제미나이 · 유튜브**
  1개만 등록해 주시면 공용 키 묶음에 들어가고, 대신 **묶음 전체를 포인트 없이** 쓰시게 됩니다. 여러 개 만드실 필요 없고, 모자라면 운영자가 채웁니다.
- **㉡ 내 키로 직접 쓰는 것 — VMake · ElevenLabs · SerpApi**
  등록하신 키로 작업이 돌아가고 요금은 **본인 계정에서** 나갑니다.

| 서비스 | 어디에 쓰나 | 비용 | 방식 |
|---|---|---|---|
| 구글 제미나이 | 대본 뽑기 · 영상 분석 · 썸네일 | 무료 | 1개만 · 공용 |
| 유튜브 | 유튜브 영상 정보 가져오기 | 무료 | 1개만 · 공용 |
| VMake | 원본 영상의 자막 지우기 | 월 14,000원 수준 | 내 키 |
| ElevenLabs | 영상에 넣을 AI 목소리(TTS) | 월 22달러 수준 | 내 키 |
| SerpApi | 비슷한 영상 찾기(파워검색) | 월 250회 무료 | 내 키 |

실제로 돈이 나가는 건 **ElevenLabs와 VMake 둘뿐**이고, 둘 다 쓰신다고 가정하면 **월 4만원 안팎**입니다. 결제는 각 서비스에 직접 하십니다. 자막 제거를 안 쓰시면 VMake 비용은 나가지 않습니다.

**등록 위치**: 👤 마이페이지 → 🔑 내 키 등록
**발급 방법(그림 매뉴얼)**: `shoppingshorts.duckdns.org/api_manual.html`

⚠️ **VMake 키는 값이 두 개입니다.** 앱키와 시크릿을 `앱키:시크릿` 형태로 **가운데 콜론을 넣어 한 줄**로 붙여넣으세요. 띄어쓰기가 들어가면 "키가 틀렸습니다"가 뜹니다.
⚠️ **SerpApi는 검색 1번에 3회가 소모됩니다**(한국어·영어·중국어 각각 검색). 무료 250회 = 실제 검색 약 83번. 키를 등록하셔도 서버 보호를 위한 **하루 10번** 제한은 그대로입니다.

## ② 📥 담기 확장프로그램 (필수)

유튜브·틱톡·인스타·샤오홍슈·도우인에서 마음에 든 영상을 **클릭 한 번으로 담는** 기능입니다. 이게 있어야 소재를 모읍니다.

**설치 — `shoppingshorts.duckdns.org/grab` 에서 2단계**

1. 설치 파일을 받아 **압축을 풉니다**
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기 → **압축 푼 폴더를 끌어다 놓기**

⚠️ zip 파일이 아니라 **압축을 푼 폴더**를 끌어다 놓아야 합니다.
⚠️ 텀퍼몽키 같은 다른 프로그램은 필요 없습니다.

## ③ 캡컷 연동 (선택)

완성본을 **캡컷에서 더 다듬고 싶은 분만** 하시면 됩니다. 숏템메이커에서 완성 영상을 바로 받거나 QR로 폰에 보내실 거면 건너뛰세요.

1. **캡컷 PC 버전을 깔고 — 한 번 켜서 로그인**
   로그인을 안 하면 캡컷이 설정 파일을 만들지 않아 다음 단계에서 *"설정 파일을 찾지 못했습니다"*가 뜹니다.
2. **자동 설정 파일을 한 번만 더블클릭**
   받는 곳 두 군데: ① 제작소에서 영상 매칭이 끝나면 아래 **📤 내보내기** 줄의 **⚙ 캡컷 자동설정(최초 1회)** 버튼 ② `shoppingshorts.duckdns.org/capcut_manual.html`(그림 안내)의 **⚙ 자동설정 파일 받기** 버튼
   이 파일이 하는 일은 둘뿐입니다 — `C:\capcutproject\CapCut Drafts` 폴더를 만들고, 캡컷의 **프로젝트 저장 위치**를 그 폴더로 바꿉니다. 기존 설정은 `.bak`으로 백업합니다.
   ⚠️ **캡컷을 완전히 끈 상태에서** 실행하세요. 켜져 있으면 멈춥니다(캡컷이 종료할 때 설정을 되돌리기 때문).
3. **숏템메이커에서 보내기 → 폴더 한 번 허용**
   크롬·엣지로 열고 완성 단계에서 **캡컷으로 보내기** → 폴더를 물어보면 위에서 만든 `CapCut Drafts`를 고르고 **허용**. 처음 한 번만 하면 됩니다.
4. **캡컷을 껐다 켜면 프로젝트가 보입니다**

**안 될 때**

| 증상 | 해결 |
|---|---|
| "Chrome 또는 Edge에서만 됩니다" | 크롬·엣지로 열거나, 대신 **캡컷용 ZIP**을 받으세요 |
| "설정 파일을 찾지 못했습니다" | 캡컷을 한 번 켜서 **로그인**부터 (1번) |
| "캡컷이 켜져 있습니다" | 캡컷을 완전히 끄고 다시 더블클릭 (2번) |
| 보냈다는데 캡컷에 안 보여요 | 캡컷을 껐다가 다시 켜세요 (4번) |

## 포인트 — 무엇에 얼마가 드나

키를 등록하지 않은 작업은 포인트로 차감됩니다. **1P = 100원**이고 마진 없이 원가 그대로입니다.

| 작업 | 차감 |
|---|---|
| 🎬 자막 지우기 | 5P |
| 🎞️ 영상 제작 (1편 완성) | 3P |
| 🔊 목소리 만들기 | 1P |
| 🔎 렌즈로 찾기 | 0.1P |
| 📝 대본 뽑기 | 0.1P |

영상 찾기 · 즐겨찾기 · 내보내기는 **무료**입니다. 작업이 실패하면 포인트는 자동으로 돌려드립니다.

**하루 사용량 상한**(pro 기준) — 영상 만들기 10편 / 렌즈 10회 / 대본 200건

## 수익화에 필요한 계정

- **쿠팡파트너스** — 8단계에서 **파트너스 추적 링크**를 넣는 칸이 있습니다. 이걸 넣어야 수수료가 붙습니다. 반드시 **본인 계정에서 직접 만든 링크**를 쓰세요(남의 링크를 쓰면 수수료가 그쪽으로 갑니다).
- **인포크링크** — 프로필에 거는 링크인비오 서비스. 9단계에서 붙여넣을 문구를 만들어 드리고, 등록은 직접 하셔야 합니다.

## 제공되지 않는 것

숏템메이커는 제작 프로그램이지 입문 강의가 아닙니다.

- ✕ 유튜브·인스타그램 **채널 개설 방법**
- ✕ 각 플랫폼의 **기본 사용법·운영 방법**
- ✕ 쇼핑 채널 세팅을 **처음부터 대신해드리는 서비스**
- ✕ 쇼핑쇼츠 **수익화 전반에 대한 기초 강의**

프로그램 **사용방법 교육영상**과 **제작 노하우**는 별도로 제공됩니다.

## 첫날 순서 요약

1. 신청하신 구글 계정으로 `shoppingshorts.duckdns.org` 로그인 → **가입 즉시 체험 + 50P 자동**
2. PC 크롬에서 `/grab` 들어가 **담기 확장프로그램 설치**
3. 마이페이지에서 포인트 잔액 확인(0P로 보이면 알려주세요)
4. (선택) VMake·SerpApi 키 발급해 등록 / (선택) 캡컷 연동
5. 유튜브·인스타에서 마음에 든 영상 **📥 담기** → 제작소에서 첫 영상 만들기

> 외부 서비스의 요금제·무료 사용량·API 정책은 각 제공업체 정책에 따라 변경될 수 있습니다. 막히는 곳이 있으면 단톡방에 물어봐 주세요.
