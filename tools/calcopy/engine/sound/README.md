# 칼카피 소리 도구 — 주인 한 벌 (10-20, 관제 097)
벤치 채널의 효과음·BGM·나레 판별(제미나이 없이 신호로). 처음 starpickroom/_tools 에서 만들어 세 채널에 사본으로 퍼졌던 것을 여기 한 벌로 모았다.
채널 폴더의 같은 이름 파일은 이걸 부르는 연결 파일뿐이다 — **고치는 건 여기서만.**
- sfx_fp(라이브러리·특징, 스펙트럼 지문 대조는 보정 실패로 폐기) · sfx_ncc(파형 상호상관) · sfx_events(고립 솟음) · sfx_rules · sfx_table
- voice_fp(우리 목소리 견본 대비 화자 유사도) · narr_report · bgm_fp(크로마 대조 — 곡 식별 신뢰 낮음)
- 한계(보정 실측): 효과음 되찾기 −6dB 3/8 · BGM 1위 6곡 — '일치 없음'은 '확인 불가'로 적는다.
