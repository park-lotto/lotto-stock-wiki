## 0. 원칙 (어기면 다시 한다)
1. **판독 = 클로드 눈.** 제미나이 판독 금지(사장님 10-18 "제미나이 쓰지 말고") — 화자 번호·효과 판독이 자주 틀렸다(키치잇 Cs-Ka '혹사시킨 거야'를 나레로 묶음). 받아쓰기만 기계(스피치매틱스·위스퍼).
2. **0.5초 시트만 보고 끝내지 않는다.** 자막·그림이 바뀌는 지점마다 **0.1초 띠**로 찾고 원본 프레임을 확대해 본다. 애니메이션은 시작·중간·끝 3프레임 이상.
3. **숫자는 실측만**(픽셀·초·LUFS·글자/초). 못 잰 건 "미측정"으로 적고 왜 못 쟀는지 적는다. 확인 범위를 문서 첫머리에 적는다.
4. **사람 이름은 화면 글자로 확인된 것만.** 얼굴로 짐작한 이름은 '불명'.
5. **★장면별 배치까지 센다(사장님 10-19 강한 규칙).** '무슨 효과가 있나' 목록으로 끝내지 말고, 편·초·대사·박자 역할마다 어떤 자막 모양/등장/강조색/스티커/효과음이 붙었는지 줄마다 적고 → **붙는 조건 규칙 + 빈도**(예: 나레 훅 첫 덩어리=팝 n/m)를 뽑는다. **꾸밈이 없는 줄·구간도 기록**한다(없는 것도 스타일).
6. **층을 가른다.** 그 채널이 얹은 층 vs 원본 영상에 이미 박혀 있던 층(글꼴·자리·외곽선이 다르다).
7. **이미 분석한 건 다시 안 한다** — `py tools/find_work.py <채널>` 과 `channel/<slug>/` 부터 본다.
8. 엔진 한계로 보고하지 않는다 — 자막은 '자막팩에 넣을 것'(`자막팩_보강안`), 엔진 결함은 '엔진 요청'으로 적는다.

## 2. 줄판독 칸 (편마다 `줄판독/<id>.json`)
```
{"id","dur","fps","size","title_lines":[{"text","colors":[{"word","hex"}]}],"source_label",
 "layout":{"title_y","window":[x0,y0,x1,y1],"source_y","logo_y","watermark"},
 "lines":[{"t0","t1","speaker":"나레|원음:<화면 글자로 확인된 이름>|제3자|불명","text":"화면 글 그대로",
   "layer":"<채널>|원본박힘","role":"훅|고조|공개|증거|반전|끝 …","enter":"typing|instant|pop|…","type_cps",
   "y":[y0,y1],"fill_hex","outline","glow","emph":[{"word","hex","outline"}],
   "sticker":[{"what","x","y","w","t_in","t_out","anim"}],"sfx":"종류·자리(근거) 또는 null",
   "scene":"얼굴|손·제품 근접|과정|기타","cut_at":[초]}],
 "beats":"훅(0~?초) → … → 끝","narr_share":"나레 줄/전체, 나레 초/전체","notes":["확인 못 한 것"]}
```
- 꾸밈 없는 줄도 `enter:"instant"`, `emph:[]`, `sticker:[]`, `sfx:null` 로 **빠짐없이** 적는다(빈도 계산의 분모).
- 색은 확대 크롭 픽셀 중앙값 hex · 타이핑 속도 = 글자 수 ÷ (첫~끝 글자 시각, 0.1초 띠).
- 나레/원음 가르기 = 입 모양(얼굴 컷) + 말꼴(전언 '~다는데') + 자동자막 시각 + 음높이 보조.

## 3. 스타일분석.md 꼴 (견본 `channel/kitchit/스타일분석.md`)
첫머리: 벤치 채널(ID·구독)·표본 편 수·원본/뜯기 경로·**판독 방법과 확인 범위** → 편 표(편·인물·조회·길이·LUFS·컷 수·중앙·출처 줄)
→ §1 자막(모양·등장·강조색·글꼴 크기·**줄 역할별 배치 규칙과 빈도**) → §2 틀(픽셀 좌표) → §3 스토리 박자(편마다 N/O 흐름) → §4 장면·소리(컷 길이·BGM·효과음 규칙·LUFS·목소리)
→ §5 우리 기존 판과 다른 점 → §6 프리셋·자막팩.
숫자 층이 필요하면(채널 50편) 기준표 10층을 쓴다: L 화면 배치 · S 자막 · H 헤드라인 · T 시간·컷 · A 소리 · W 대본 언어 · K 후킹·구조 · M 소재 · C 채널 단위 · V 터지는 지점(상위↔하위 같은 자 비교) + 정정·미측정 목록.
