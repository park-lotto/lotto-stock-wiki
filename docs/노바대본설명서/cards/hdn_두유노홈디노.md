## 1. 역할과 핵심 원리
**'어떤 불편을 겪던 누군가가 그걸 이렇게 해결해 버렸대요'**로 여는 존댓말 전언·체험담. 숨기는 것 = 어떻게 해결했나(원리). 붙잡는 것 = 흥미 이야기(유래·권위) + 우리 집·공간이 어떻게 바뀌었나. 숫자로 증명하지 않고 **'내가/주변이 봤다'로 증명**(설명서.md: 근거 방식 체험담 43.1% · 수치 3.4%).

**최우선 원칙**
1. 첫 문장 = 시작 공식 한 사건: [주체] + [계기·감정어 하나] + [해결해 버렸대요] (hook_formula.json, 사장님 2026-10-16)
2. 원리·속성 다음엔 '나에게 생긴 변화'로 넘긴다 — 공간·분위기(소구 71.4%)
3. 결과 비유 1개 이상(맹물과 원액·편의점 vs 바리스타)
4. 단어는 오버하지 말고 재미있게 — 센 감정어(빡친·열받은·짜증) 한 편 1회 이하
5. ★근거 규칙(모순 해소): 끝 줄은 '결과 과장' 칸 — 근거에 사회 반응 사실이 있으면 '~사이에서 난리래요', 없으면 '나·가족·공간의 변화 과장'으로 쓴다(창작 허용). 사회 반응 낱말(난리·품절·대란·사이에서)은 근거 번호가 있을 때만

## 2. 재료 확보 (쓰기 전에 채운다)
| 재료 | 쓰일 칸 | 근거 규칙 |
|---|---|---|
| 참고 있던 불편 1개 ← 가장 중요 | 상황·불편 칸 | 화면 근거(장면 설명) 또는 f번호. 없으면 제품군 단위 불편(관점 재료)으로만 — 수치·피해액 금지 |
| 화면에 보이는 사용 동작·결과 1~2개 | 사용 동작·결과 칸 | 장면 목록에 있는 것만(P3 원칙: 제품이 무엇을 하는지는 화면 설명에서만 읽는다) |
| 화제 근거 또는 관점 재료 | 추천인·사회 반응 칸 | 실제 화제·판매처는 f번호 필수. 없으면 6절 가공 장치 중 근거 불필요 장치만 |
| 최강 셀링포인트 1개 (뒤로 아낀다) | 심지어 칸(뒤쪽) | f번호 필수 — 제품 사실이므로 |
| 등장 인물(가족·지인·전문가 지인) | 훅·추천인 칸 | 창작 허용(체험담 장치). 단 그 인물이 말한 제품 사실은 f번호 필수 |

- ★근거 번호(f1…)를 재료마다 달아 넘긴다. 근거 없는 재료는 6절 '근거 필요=아니오' 장치로만 쓴다.
- 재료가 비면 비었다고 검수에 적는다(노바 1단계). 지어내서 채우지 않는다.
