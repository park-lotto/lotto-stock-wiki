# 영상제작소 대본·영상믹스 단계 통합 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 영상제작소의 분리된 "1·대본"·"2·영상" 단계를 하나의 "제작소"(좌 영상풀·우 결과) 화면으로 합치고, 대본 뽑기에서 도서관의 생성/디벨롭 기능을 그대로 쓰며, 제작소에서도 위키에 저장해 학습에 반영할 수 있게 한다.

**Architecture:** 백엔드는 URL 기반 위키 저장 라우트 1개만 신설(`/api/produce/save_to_wiki`)하고, 나머지 대본 생성·디벨롭·믹스 로직은 전부 기존 것 재사용. 프론트(`produce.html`)에서 두 단계 패널을 좌우 2단 한 패널로 병합하고, 도서관 생성 모달을 이식해 📝뽑기에 연결한다.

**Tech Stack:** FastAPI(Python), 순수 HTML/JS(produce.html 단일 파일), SQLite(reference.db), pytest.

**설계 근거:** `docs/superpowers/specs/2026-07-15-쇼핑쇼츠-영상제작소-대본믹스-통합-design.md`

```python
@app.post("/api/produce/save_to_wiki")
def api_produce_save_to_wiki(request: Request, body: dict, background_tasks: BackgroundTasks):
    """제작소에서 확정한 대본을 URL 기반으로 위키(도서관)에 저장 — 학습 반영용 다리.
    load_last_run()에 의존하는 /api/wiki/save와 달리, 클라이언트가 확정한 script_text를
    그대로 쓰고 URL로 영상만 영구보관(실패해도 대본·구조는 저장). category 필수 전달로
    element_stats NULL 누수 방지."""
    url = (body.get("url") or "").strip()
    script_text = (body.get("script_text") or "").strip()
    if not url or not script_text:
        return JSONResponse(status_code=422, content={"ok": False, "error": "url·script_text 필요"})
    code = (body.get("shortcode") or "").strip() or hashlib.sha1(url.encode()).hexdigest()[:12]
    category = (body.get("category") or "").strip() or None
    store = Store(DB_PATH)

    # 구조: 클라이언트가 넘겼으면 재사용, 없으면 분석
    structure = body.get("structure")
    if not structure:
        structure = analyze_structure(script_text)

    script = {"full_text": script_text, "segments": body.get("segments") or []}
    store.save_script(code, script, category=category)

    # 영상 영구보관(도서관 인라인 재생용) — 실패해도 대본·구조는 저장한다.
    hashed = hashlib.sha1(code.encode()).hexdigest()[:16]
    media_target = _WIKI_MEDIA_DIR / f"{hashed}.mp4"
    if not media_target.exists():
        work_dir = _FIND_TMP_DIR / hashed
        try:
            video_path, _ = download_any(url, str(work_dir))
            if video_path and Path(video_path).exists():
                _WIKI_MEDIA_DIR.mkdir(parents=True, exist_ok=True)
                shutil.copy(str(video_path), str(media_target))
        except Exception:
            pass  # 영상 보관 실패 무해

    item = {
        "shortcode": code,
        "name": body.get("name") or "",
        "category": category,
        "source_url": url,
        "video_url": body.get("video_url") or url,
        "caption": body.get("caption") or "",
        "followers": body.get("followers") or 0,
        "comments": body.get("comments") or 0,
        "density": body.get("density") or 0,
    }
    store.save_to_wiki(item, script, structure, customer_id=_cid(request))
    store.save_extract_structure(code, structure)
    background_tasks.add_task(_relearn_category, DB_PATH, category)
    return {"ok": True, "shortcode": code, "structure": structure,
            "has_video": media_target.exists()}
```
