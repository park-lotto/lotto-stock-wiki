Claude 자체 판단(예측·추천)을 브리핑에 쓰면 팩트 기반이 아니라 오류가 많다.

**Why:** "수주하면 10% 간다" 같은 말은 DB에 없는 Claude가 만들어낸 추측. 이상하고 틀림.

**How to apply:**
- 브리핑 코멘트 = 소스(애널리스트·리포트·텔레)가 한 말 직접 인용 + 출처+날짜 표기
- Claude 추론이 필요할 때는 "Claude 추론" 레이블 명시 후 팩트 근거와 함께 작성
- 브리핑 구조: 타임라인(날짜별 이벤트) + 개별 모멘텀(종목별 팩트 카드)
- 각 팩트 뒤 반드시 "출처 · 날짜" 표기 필수
