## 핵심 원칙
이슈가 들어왔을 때 즉시 관련 종목이 뽑혀야 한다. 그러려면 각 종목 파일에 3가지가 있어야 한다:
1. **사업 방향** (회사가 어디로 가는가)
2. **뉴스 반응 패턴** (어떤 뉴스에 얼마나 반응하는가)
3. **밸류체인 포지션** (앞 종목이 뜨면 왜 이 종목이 따라오는가, 시차는)

## 후발주 분류 2종 (2026-05-29 발견)

| 유형 | 작동 조건 | 대표 사례 |
|------|---------|---------|
| **공급망형** | 수요 증가 → 공급망 수혜 직결 | 심텍·대덕전자·이수페타시스 (삼성전기 뜨면 AI서버 기판 수요↑) |
| **밸류에이션 갭형** | 대장주 급등 → 덜 오른 동업종으로 자금 이동 | 삼화콘덴서 (삼성전기 420% 급등 후 수일 만에 2배) |

갭형은 실적이 나빠도 뜬다. 갭이 클수록 더 강하게 반응.

## MLCC 체인 연쇄 시차 (실제 데이터)
```
삼성전기 (당일 +4.5%)
  → 이수페타시스 (다음날 +5.2%) ← 가장 강한 반응
  → 대덕전자 (다음날 +4.1%)
  → 심텍 (다음날 +3.8%)
  → 코리아써키트 (2~3일 +7%)
  → 삼화콘덴서 (수일, 갭 플레이, 2배 가능)
```

## HBM 체인 연쇄 시차 (실제 데이터)
```
SK하이닉스 (당일 +5.0%)
```

## 섹터 리서치 Q10 프레임워크
- Q1~Q7: 기존 (섹터 전체 구조)
- Q8: 뉴스 트리거 × 주가 반응 패턴
- Q9: 지금 주도 종목 × 왜 강한가
- Q10: 꼬리에 꼬리 연쇄 구조

스크립트: `scripts/gemini_semiconductor_q10.py`
다음: `scripts/gemini_robot_q10.py` (로봇+현대차, 미작성)

## 반복 질문 원칙 (꼬리에 꼬리) — [[feedback_iterative_research]]
Q10이 끝이 아니다. 각 Q의 답변에서 새 Q가 나온다.
- 오늘 발견: CPU 추론 시대 → 오픈엣지 더 파야 함 → Q11 가능
- 오늘 발견: 갭 플레이 패턴 → 다른 섹터에도 같은 패턴 → Q12 가능
- 오늘 발견: 피지컬 AI → 현대오토에버·LG CNS 데이터 없음 → Phase 2 필요
답변 후 항상: "이 답변에서 더 파야 할 게 있는가?"

## 채우기 우선순위
Phase 1 (완료): 반도체 Q10
Phase 2 (예정): 로봇+현대차 Q10
Phase 3: 방산·조선

**Why:** 데이터 없는 섹터는 이슈가 와도 연결 못 함. 젠슨황 방한에서 자동차/피지컬AI 섹터 데이터 없어서 틀린 것.
