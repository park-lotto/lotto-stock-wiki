## 2026-08-18 (회사PC) — 제작소 5단계 TTS음성 UI 재배치

### 사장님 지적

1. **"복잡해서 뭐부터 할지 모름"**
2. **"정렬이 엉망임"**

대상은 `produce.html`의 **5단계 TTS음성**(`section.panel[data-step="2"]`).
⚠️ `data-step`은 옛 번호 그대로다 — 표시번호 5 = `data-step="2"`
(9단계 개편이 `ORB_TO_PANEL`만 재배열했다, 메모리 `project_제작소_9단계개편`).

### 실측한 문제 (브라우저, 성우 14명 상태)

| # | 문제 | 실측 |
|---|---|---|
| ① | 좌측 안내문이 **폭 1226px인데 높이 47px** | 아래 **세로 381px 빈 구멍** (안내문 끝 266 ↔ 미리보기 시작 647) |
| ② | 좌우 칸 끝이 안 맞음 | 성우카드 633px vs 좌측 266px = **367px 어긋남** |
| ③ | 첫 화면 선택지 5갈래 | 정작 할 일("들어보고 다음")이 맨 아래 |
| ④ | 완성 미리보기 대기 상태 | 오른쪽 **1357px(86%)** 통째로 빔 |

### 고친 방식 — 순서·폭만. **id는 하나도 안 지웠다**

전 id가 JS에서 실제로 쓰인다(사전에 grep으로 전수 확인: voiceUI·voiceHint·
voiceControls·presetCards·ttsBeats·noVoice·openVoiceTune·speedBtns·silenceBtns·
paceMode·voicePreview 등 11개 + 고급 슬라이더 4개). **하나라도 지우면 기능이 죽는다.**

```
① #ttsBeats(완성본 듣기)  → 맨 위 주인공으로 이동
② 🎙 목소리 바꾸기        → 접힌 채 그 아래 + summary에 지금 성우 표시
③ ⚙ 그 밖 설정            → 자막없이·발음교정을 묶어 첫 화면에서 뺌
④ voiceUI 순서 뒤집기     → [성우카드 | 설정]  (먼저 할 일이 왼쪽)
⑤ ★안내문을 두 칸 위 한 줄로 빼냄
⑥ 대기 화면을 [프레임 | 안내] 2단으로 → 빈 86% 제거
⑦ 44px 터치타깃          → paceMode 19→44, advBoost 20→44, 고급 요약 18→44
```

**★⑤가 핵심 교훈**: ④(좌우 뒤집기)만으로는 **367px 어긋남이 그대로 남았다**(실측).
안내문이 오른쪽 칸 안에 있는 한, 그 칸이 폭 1226px을 잡은 채 높이는 47px뿐이라
420px짜리 성우카드와 계속 어긋난다. **한 줄짜리 안내를 큰 칸에 넣지 마라** —
칸 밖 한 줄로 빼야 두 칸이 각자 내용만큼만 자리를 먹는다.

**★⑥에서 두 벌 방지**: `renderTtsBeats`의 `if(!MIX_JOB)` 분기도 HTML 초기값과
**같은 틀**로 맞췄다. 여기만 옛 모양으로 두면 "처음 열었을 때"와 "함수가 다시 그린 뒤"가
다르게 보인다(0순위-B: 같은 판단 두 벌 금지).

### 신설한 것 — `#curVoiceName` / `syncCurVoiceName()`

접힌 `🎙 목소리 바꾸기` 줄에 **"— 지금: 지민 · 안정"** 을 띄운다. 펼치지 않고도
무슨 성우로 만들어졌는지 알 수 있어야 "뭐부터 할지 모름"이 준다.
이름을 정하는 곳은 **함수 하나**뿐이고 `pickPreset`(고를 때)·`loadTtsBeats`(처음 뜰 때)가
같이 부른다 — 두 군데서 각자 문자열을 만들면 반드시 어긋난다.

### 로컬 검증하는 법 (다음 세션이 반복할 때)

로컬 DB엔 프리셋이 없어(`/api/voice-presets`가 `{ok,groups:[]}`) 카드가 안 뜬다.
브라우저 콘솔에서 `VOICE_GROUPS`에 목업을 넣고 `renderPresetCards()`를 부르면 재현된다.
⚠️ 패널은 `display`가 아니라 **`.panel.show` 클래스**로 열린다(inline style로는 안 열림).
