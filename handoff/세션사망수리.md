### 세션은 '만료'가 아니라 인스타가 **회수**한 것
```
HTTP/2 302
set-cookie: sessionid=deleted; expires=Thu, 01-Jan-1970 …
```
쿠키 만료일은 **2027-08-06**. 파일도 쿠키(sessionid·ds_user_id·csrftoken)도 멀쩡했다.
→ **파일만 봐선 절대 모른다. 인스타에 물어봐야 안다.**

### 왜 43%인가 — 라운드로빈이라 채널 탓이 아니다
`instagram_playwright.py:505` `slots[(i-1) % 7]` → 3/7이 자동으로 죽은 세션에 배정.
3/7=42.9% ≈ 실측 ok 47/110=42.7%.

**결정적 실험** — 같은 채널 `chae2home`, 슬롯만 바꿈:
```
slot0/4/5 (죽은 세션) → nodes=0   unknown
slot1/2/3/6(산 세션)  → nodes=10  ok
```
어제 실패한 다른 채널 6개도 산 슬롯으로 돌리니 **6/6 전부 12건씩** 수확. **죽은 채널 0개.**

### ★진짜 근본원인 — 0번 계정만 서버 맨 IP로 나갔다
`_detail_context()`가 `slots[0]` **고정**인데 프록시가 `elif`라 도달 불가:
```python
if session_path:  ctx_kw["storage_state"] = …   # 여기 들어오면
elif config.INSTAGRAM_PROXY:                     # ★영원히 안 옴 (게다가 미설정)
```
| 경로 | 계정 | 출구 IP |
|---|---|---|
| 채널수집 `:505` | 7개 순환 | 한국 가정회선 kr-11~ |
| 발굴 `:368` | 7개 순환 | 한국 가정회선 |
| **상세조회 `:216`** | **0번 고정** | **43.200.48.69 (AWS)** |

`_detail_context` 사용처 **5곳**(app.py×2·duration_backfill·media_download·backfill_channel_category).
길이백필만 매일 **119·125·118건** — 전부 0번 계정 + 데이터센터 IP.
→ 인스타 눈엔 "한 계정이 서버에서 하루 수백 건". 0번이 먼저 죽은 건 필연.

### ⚠️ 하마터면 전멸시킬 뻔했다 (사장님이 "악화 아닌지 체크" 지시 → 발견)
처음 계획은 "`:216`에 로테이션 붙이기"였다. 그대로 했으면:
```
지금  : 0번만 서버IP로 오염     → 1개 죽음, 6개 안전
수정후: 7개가 서버IP를 돌려씀   → ★전부 같은 오염에 노출 = 전멸
```
계정 재고 7개뿐 + 재로그인은 사장님 손 필요 → 전멸하면 수집이 통째로 멈춘다.
**로테이션보다 짝 맞추기가 먼저**다.

## 고친 것

### ① 계정↔프록시를 짝으로 (`instagram_playwright.py`)
슬롯 프록시를 **독립 `if`**로 빼 세션 분기에 안 먹히게. 계정을 고르면 그 짝 출구도 함께.
```
실측: 서버직결 43.200.48.69 → kr-12 169.213.158.140 (한국 가정회선)
```
`INSTAGRAM_PROXY` 폴백은 풀이 빌 때만 쓰는 옛 경로라 `elif`로 남겼다(동작 불변).

### ② 세션 생사 감시 (`channel_archive.py`)
- `session_alive(path)` — 쿠키 유무가 아니라 **인스타에 물어서** 판정(200=산 것/302=죽은 것).
  판정 불가(네트워크 오류)는 **True** — 멀쩡한 계정을 우리 손으로 빼는 게 더 위험.
- `live_slots(slots)` → `[(원래인덱스, path), …]`
  ★**인덱스 보존이 핵심**. 죽은 걸 지우면 뒤가 당겨져 `slot_proxy(index)`의 출구가
  통째로 재배치 → 계정↔IP 1:1이 깨진다(2026-08-05: IP 같으면 몇 시간 만에 warning).
  전멸 판정 시엔 **원본 폴백**(2026-08-06 랭킹 공백 사고 방지).

라이브 실측: `살아있는 인덱스 [1,2,3,6]` — 수동 curl과 일치. 인덱스 안 당겨짐.

## 함정
- **`unknown`을 "채널이 없다"로 읽지 마라.** 나머지 통이다. 이걸로 오독한 게 **세 번째**
  (08-09 · 08-17 · 이번). 이번엔 세션이 죽은 것이었다.
- **쿠키가 있다 ≠ 세션이 살아있다.** 만료일 2027년인데 인스타가 회수했다. 물어봐야 안다.
- **로테이션을 붙이기 전에 프록시부터.** 계정만 돌리고 IP가 같으면 전멸한다.
- 죽은 세션 파일을 **지우지 마라** — 인덱스가 당겨져 계정↔IP가 재배치된다. `live_slots`로 거를 것.
