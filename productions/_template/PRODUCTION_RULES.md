# 영상 제작 원칙 (Production Rules)
> 모든 씬 제작 전 반드시 이 원칙을 확인하고 통과해야 한다.

---

## R1. 가독성 — 텍스트 크기 최소값

| 용도 | 최소 크기 | 이유 |
|------|-----------|------|
| 자막 | 36px | 유튜브 시청 시 가독성 기준 |
| 패널 본문 | 18px | 카드 내 설명 텍스트 |
| 패널 타이틀 | 28px | 섹션 제목 |
| 수치/강조 | 48px | 임팩트 데이터 |
| 라벨/캡션 | **16px** | 절대 이 이하 금지 (11~14px 사용 불가) |
| 스텝 번호 | 60px | 단계 표시 |

**위반 즉시 수정. 작은 글씨는 없다.**

---

## R2. 요소 충돌 금지 — 겹침 방지

- **PiP 영역**: 우하단 PiP 위치를 먼저 계산하고, 모든 오버레이는 그 영역을 침범하지 않는다.
- **자막 영역**: 하단 subtitle zone에 다른 요소 진입 금지.
- **패널 간 충돌**: 좌측 패널 + 우측 패널 + PiP 세 요소가 동시에 등장할 때 겹치지 않는지 수치 계산 필수.
- **로고 + 텍스트**: 로고 옆 텍스트가 로고를 침범하지 않도록 gap 최소 12px.

**배치 전 항상 픽셀 좌표로 계산해서 확인.**

---

## R3. 이미지/로고 비율 보존

- 모든 이미지는 `object-fit: contain` 또는 `object-fit: cover` 명시.
- 고정 width+height 동시 지정 시 반드시 원본 비율 계산 확인.
- SVG 로고는 viewBox 유지, 임의 크기 지정 금지.
- **찌그러짐/잘림 0 허용.**

---

## R4. 안전 영역 (Safe Zone)

```
┌────────────────────────────────┐
│  ← 32px 여백 →              ← 32px 여백 →  │   ← 좌우 패널 시작점
│                                │
│   [콘텐츠 안전 영역]            │
│                                │
│          [PiP 금지 구역]        │   ← PiP 좌표 기준 + 20px 버퍼
│  [자막 금지 구역 ───────────]  │   ← 하단 16% + 20px 버퍼
└────────────────────────────────┘
```

- 좌우 최소 여백: 32px
- 상단 최소 여백: 24px
- PiP 버퍼: PiP 경계에서 20px 이상 떨어지기
- 자막 버퍼: subtitle 영역 위 20px 이상

---

## R5. 동시 등장 요소 한도

한 프레임에 동시에 보여야 하는 오버레이 요소:
- 최대 3개 패널 (STEP 배지 + 좌측 패널 + 우측 패널)
- 자막 항상 포함
- PiP 항상 포함

총 5개 요소. 이 이상이면 일부를 순차 등장으로 전환.

---

## R6. 색상 대비

- 배경 위 텍스트: 명도 대비 최소 4.5:1
- 어두운 카드(배경 rgba 0.05~0.10) 위 흰 텍스트: 항상 통과
- 강조색 위 검정 텍스트: 배경이 밝은 색일 때만 허용

---

## 점검 체크리스트 (제작 전 필수)

```
□ 모든 텍스트 크기 ≥ 최소값 확인
□ PiP 좌표 계산 → 우측 패널과 겹침 없음
□ 자막 영역과 다른 요소 겹침 없음
□ 이미지/로고 비율 보존 확인
□ 동시 등장 요소 ≤ 5개
□ 색상 대비 통과
□ 좌우 여백 최소 32px
```
