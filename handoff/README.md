# handoff — 트랙별 인수인계

한 PC에서 여러 Claude 세션이 같은 워킹트리로 동시에 작업한다.
`NEXT_SESSION.md` 한 장에 전부 적으면 세션끼리 덮어쓴다(2026-07-15 실사고).

## 규칙

1. **자기 트랙 파일만 수정한다.** `handoff/<트랙>.md`
2. 남의 트랙 파일은 **읽기만**. 고칠 게 보이면 그 트랙 파일에 메모를 남기지 말고 사용자에게 보고.
3. 새 트랙은 새 파일을 만든다. 기존 파일에 얹지 않는다.
4. 커밋할 때 `git add handoff/<내트랙>.md` — `git add -A` 금지.

## 트랙 찾기 — 아래 표 말고 이걸 쓰세요

```
py tools/find_work.py <주제어>      # 관련 기록을 전부 훑어 최신순으로
py tools/find_work.py --list        # 핸드오프 전체 (최근 갱신순)
```

⛔ **아래 표는 썩었습니다** — 12개만 적혀 있는데 실제 파일은 68개입니다.
손 관리 목록은 반드시 뒤처지므로, 찾을 땐 항상 위 도구를 쓰세요(CLAUDE.md 0순위-A2).
표는 옛 기록으로만 남겨둡니다.
