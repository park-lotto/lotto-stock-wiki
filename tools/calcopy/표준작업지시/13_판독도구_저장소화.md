# 13 판독 도구 저장소화 — scratchpad `capseg·cutdet·px·segsheet·build_lr` → `tools/calcopy/engine/readline_tools/` (표준 §11 ⑫)

## 목표
06 워커들이 줄판독에 쓰는 도구가 scratchpad(세션 임시 폴더)에만 있다 — 다음 세션·다른 PC·회원 PC 가 재현 못 한다(잇템로그 mk_v3 와 같은 사고). 저장소 모듈로 옮기고 `kal_analyze frames` 가 부르게 한다.

## 실측 배경
- 오푸스 보고(06 잇템로그·방구석, 10-25): 자막 띠 분할 `capseg` · 컷 검출 `cutdet` · 픽셀 실측 `px` · 구간 시트 `segsheet` · 줄판독 뼈대 생성 `build_lr` 가 scratchpad 에 있고 커밋 02d991b8c(방구석 6편 strict 0·sfx_events) 가 그 결과물이다.
- 저장소 쪽 기존 자리: `kal_analyze.frames_cmd`(2fps 시트·0.1초 띠, 571~) · `skeleton`(183~) · `channel/starpickroom/_tools/sheets.py`(text_mask 견본) · `engine/sound/*`.

## 만질 파일(독점)
`tools/calcopy/engine/readline_tools/`(새 폴더: `capseg.py`·`cutdet.py`·`px.py`·`segsheet.py`·`build_lr.py`·`README.md`) · `shopping_shorts/tests/test_readline_tools.py`(새) · `tools/calcopy/engine/kal_analyze.py` 는 **04 커밋 뒤** `frames_cmd`/`skeleton` 에서 호출하는 줄만(04 와 겹치므로 04 끝난 뒤 한 줄) · `tools/calcopy/지시문_템플릿.md`·`담당_공통규칙.md`(도구 경로 줄)
## 안 만질 파일
줄판독 데이터(06) · 판 파일 · 렌더러.

## 순서
1. scratchpad 원본을 그대로 옮기되 머리말에 '어디서 왔나·무엇을 재나·입력/출력 꼴' + `PYTHONUTF8=1` 명령 한 줄. 경로 상수(C:/숏템_칼카피 등)는 인자/환경변수로.
2. 각 도구 시험 1개: 방구석 6편 중 1편(캐시 src)으로 돌려 커밋된 줄판독 값(컷 시각·자막 띠 y·픽셀 hex)과 **같은 값**이 나온다(재현성).
3. `kal_analyze frames` → `readline_tools.segsheet/capseg` 호출(04 뒤) · `skeleton` → `build_lr`.
4. 06 워커 지시문·공통규칙에 "도구 = `tools/calcopy/engine/readline_tools/` 만, scratchpad 도구 금지" 한 줄.

## 합격 검사
1. 재현: 방구석 1편 재실행 값 == 커밋된 줄판독(컷 시각 ±1프레임·y ±2px·hex 같음).
2. scratchpad 참조 0: `grep -rn "scratchpad" tools/calcopy/engine/readline_tools` 0건 · 지시문에 경로 있음.
3. `kal.py --from frames` 가 새 경로로 돌아 `kal/frames_<id>/strips/` 생성(연결 뒤).
