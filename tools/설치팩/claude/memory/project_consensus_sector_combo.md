# 주도업종 + 컨센상향 교집합 전략

**출처**: 태린이아빠 텔레그램 (2026-06-02 오전 8:30)
**Why:** "상향한것 + 주도업종 교집합을 찾으면" → 핵심 매수 종목 압축

## 핵심 공식
```
컨센 상향 (TP_Up / Rating_Up)
    ×
주도업종 필터
    =
탑픽 후보
```

## 2026년 6월 말 기준 주도업종
태린이아빠 확인:
- **반도체 + 기판** (SK하이닉스, 삼성전자, LG이노텍, 두산테스나 등)
- **자동차** (현대차, 기아)
- **로봇** (레인보우로보틱스 등)

## 데이터 소스
| 데이터 | 파일 | 시트 |
|--------|------|------|
| 컨센 상향 | 추정이익변경.xlsm | TP_Up, Rating_Up |
| 주도업종 | 직접 설정 or 수급오실레이터 섹터 | - |
| ETF 비중 증가 | 액티브ETF관리.xlsx | 섹터별 시트 |

## 구현 예정
```python
# viz_card.py 또는 별도 스크립트
컨센상향_종목 = parse_추정이익변경()['TP_Up']
주도업종_필터 = ['반도체', '기판', '자동차', '로봇']
교집합 = [종목 for 종목 in 컨센상향_종목 if 종목.sector in 주도업종_필터]
# → 탑픽 카드뉴스로 출력
```

## viz_card.py 연동 방향
- 추정이익 카드뉴스에 "주도업종 해당 여부" 뱃지 추가
- 또는 별도 "주도업종 컨센상향" 카드뉴스 생성

**How to apply:** "주도업종 컨센", "교집합", "상향종목 필터" 언급 시 이 메모리 참조
