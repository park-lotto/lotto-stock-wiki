## 핵심 논리 체계 (이번 세션 개발)

### 1단계: 재료 강도 레벨 구분
- 직접 지분투자 (비상장) → 상장 주가 직접 연결 없음
- 저리대출 → 약한 호재. "기업이 돈 빌린 것"
- 저리대출이 진짜 호재가 되는 조건: **"이 대출 없었으면 못 했을 사업을 이제 할 수 있게 됐다"**

### 2단계: 주가 상승 인과관계 검증
- 날짜 + 종목 + 상승 이유 검색으로 반드시 확인
- 순환매인가 / 개별 호재인가 / 시장 편승인가 구분
- 주성엔지니어링 사례: 60% 급등이 국민성장펀드가 아닌 ALG 자체 호재였음

### 3단계: 악재 동시 검토
- 뉴스 단독 금지. 긍정 재료와 동시에 "XX 악재", "XX 주가 하락 이유" 검색
- SK바이오사이언스: 직접 확정 3,000억 받았지만 1Q26 영업손실 445억·인력 이탈 11% → 1군 불가

### 4단계: 1군/2군 분류
- 1군: 여론 多 + 재료와 주가 인과관계 명확 + 현재 유지
- 2군: 직접 확정 있지만 주가 미반응 / 간접 기대주
- 빠져나갈 구멍: 2군은 반드시 "기대치" 표현으로 조건부 제시

### 5단계: 날짜 필터
- 현시점 날짜 기준으로 데이터 전수 필터링
- 맞지 않으면 무조건 제외

## 국민성장펀드 최종 결론 (2026-05-31 기준)

**1군: 엘앤에프**
- 자회사 엘앤에프플러스 2,200억 12년 저리대출 직접 확정 (5/28)
- LFP 공장 = 이 대출 없었으면 못 했을 사업 → 진짜 호재 조건 충족
- 5/27 +13%, 현재 168,000원 유지
- 삼성SDI + SK온 공급 협약 자체 스토리까지 3중 재료

**2군: 에코프로비엠**
- 개별 직접 확정 없음
- 코스닥 시총 1위 → 자금 유입 최전선
- 6/15 실제 집행 시작 시 자동 수혜 구조
- 표현 주의: "직접 수혜가 아닌 자금 유입 최전선 종목"

**제외:**
- SK바이오사이언스: 내부 악재 (적자 3배, 인력 이탈)
- 에이디테크놀로지: 공시 없음
