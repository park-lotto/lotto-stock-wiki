# 화자일관성

2026-08-23 대본 화자 — 사장님 제보 "친구네 갔다가 남편턱이 달라졌다하고 저도
해봤다는게 말이되는건지". ★범인은 **규칙이 없어서가 아니라 판정이 없어서**였다.
헌장(_STORY_RULES_CORE)에 "훅에서 등장시킨 인물이 결말에서 회수돼야 하고 중간에
다른 인물로 갈아타지 마라"가 이미 정확히 적혀 있었는데, 게이트 검사 12종에
`화자|주어|인칭` grep이 0건 — 지켰는지 보는 판정이 없어 어겨도 미검출이고
재작성 루프가 안 걸렸다(판정축_하나면_교정이_통째로죽는다와 같은 모양).
라이브 실증: 깨진 대본이 게이트 6개 검사를 전부 통과했다.
헛짚은 것 2건: ①"틀 조립 탓" 틀림 — 조립은 08-21에 이미 껐다(assemble_off=1 실측).
**08-22 핸드오프의 "생성기는 멀쩡" 전제가 깨졌다** ②정규식 판정은 라이브 27개에서
오탐 2건(멀쩡한 다이소 대본) → 폐기하고 LLM 판정으로.
고친 것: check(speaker_judge=) 신설 + 재작성 루프 배선 + 실패작을 프롬프트 예시로
박음("하지 마라" 한 줄론 안 막힌다) + prior_verdict(재단 후 재검사에서 판정이
조용히 사라지던 것을 앞 판정 물려주기로, 두 번째 유료 호출 없이).
★fail-open이 핵심 — _call_json은 키 소진 시 {}를 주는데 그때 FAIL로 잡으면
키 마른 날 대본이 통째로 막힌다. 판정 불가 = 통과.
검증: 제보 대본 FAIL·고친 대본 통과·오탐 3/3 통과·테스트 9건 신설·관련 537건 통과.
전체 pytest는 기준선 2실패 → 1실패(늘지 않음). 커밋 67f09fc24.
⏭ 사장님 육안 확인 / 판정 비용(대본당 LLM 1콜 증가) 관측 / "인과 다리"도 같은 구멍.
