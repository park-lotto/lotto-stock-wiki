# 아침 브리핑 시스템 — 설계 스펙

> 작성일: 2026-06-06
> 목적: 매일 아침 운영자 판단이 담긴 브리핑 카드를 자동 생성·배포

---

## 핵심 철학

정보는 누구나 모을 수 있다. 좋은 정보를 고르기 어렵고, 정리하기는 더 어렵고, 인사이트로 뽑기는 제일 어렵다.
이 시스템은 Claude가 정보 수집·정리를 하고, 운영자가 판단을 더해 인사이트 카드로 만드는 구조다.

**기존 카드의 문제**: 정보 나열 → 누가 쓴지 모르는 분위기
**새 카드의 목표**: 운영자 판단 + 근거 → "로또의 주식" 색깔이 느껴지는 카드

---

## 전체 흐름

```
07:00~07:30  자동 정보 수집
     │
     ▼
07:30        텔레그램 봇 → 운영자에게 2단계 질문
     │         1단계: 오늘 핵심 주제 3~5개 제시 → 번호 선택
     │         2단계: 선택 주제의 판단 분기점 A/B 질문
     │
     ▼
07:30~08:00  운영자 텔레그램 답변
     │         예: "1" → "일시 조정. AI 가이던스 상향인데 네트워킹만 부진 부각된 것"
     │
     ▼
08:00 이전   카드 자동 생성 + PNG 캡처 + 텔레그램 채널 push
```

**답변 없을 때 (08:00까지 무응답):**
- 자동 초안 카드 생성 + "⚠️ 자동생성" 워터마크 표시
- 운영자에게 "초안으로 발행했어요" 알림
- 운영자가 수정 원하면 텔레그램으로 재발행 요청 가능

---

## 컴포넌트 구성

### 1. 정보 수집 모듈 (`scripts/briefing/collect.py`)
- 입력: 텔레그램 채널 ingest 결과 + 리포트 + 뉴스 (기존 파이프라인 활용)
- 출력: 오늘의 핵심 이슈 3~5개 (섹터명 + 이슈 요약 1줄 + 판단 분기점)
- 실행: 매일 07:00 Task Scheduler

### 2. 텔레그램 봇 (`scripts/briefing/bot.py`)
- 신규 봇 생성 (기존 봇과 분리)
- 양방향 소통: 질문 전송 + 답변 수신
- 1단계 질문 → 운영자 답변 → 2단계 질문 → 운영자 답변 → 카드 생성 트리거
- 08:00 타임아웃 시 자동 초안 생성 트리거

### 3. 카드 생성 모듈 (`scripts/briefing/card_gen.py`)
- 입력: 수집된 데이터 + 운영자 판단 + 판단 근거
- 출력: `out/briefing_아침_YYYYMMDD.html`
- TODAY'S 인사이트 블록: 운영자 판단 + 근거 1~2줄 (구어체, ~해요 말투)
- 자동생성 시: 워터마크 "⚠️ 자동생성" 표시

### 4. PNG 캡처 + 전송 (`scripts/briefing/publish.py`)
- Playwright로 HTML → PNG 자동 캡처
- 텔레그램 채널 자동 push
- 전송 완료 후 운영자에게 확인 알림

## 카드 구조 변경

### TODAY'S 인사이트 블록 (핵심 변경)

```
기존:
┌─────────────────────────────────┐
│ ⚡ TODAY'S 인사이트              │
│ 반도체 섹터는 브로드컴 실적 미달로 │
│ 단기 조정 가능성이 있습니다.      │
└─────────────────────────────────┘

새 구조:
┌─────────────────────────────────┐
│ ⚡ TODAY'S 인사이트  [일시조정✓] │  ← 운영자 판단 배지
│ 브로드컴 쇼크, 저는 일시 조정으로 │  ← 운영자 말투
│ 봐요. AI 가이던스는 상향인데      │  ← 판단 근거 포함
│ 네트워킹 부진만 부각된 거라서요.  │
└─────────────────────────────────┘
```

### 판단 배지 규칙
| 판단 | 배지 색상 | 예시 |
|------|---------|------|
| 강세/상승 | 민트 `#00e5c6` | `[일시조정 ✓]` `[추가상승 ✓]` |
| 주의/혼조 | 옐로 `#ffe500` | `[관망 ⚠]` `[변동주의 ⚠]` |
| 약세/하락 | 레드 `#ff2244` | `[추세전환 ✗]` `[비중축소 ✗]` |

## 텔레그램 봇 메시지 포맷

### 1단계 질문 (07:30 전송)
```
📊 STOCK BRAIN 오늘의 브리핑 질문 (1/2)

오늘 핵심 이슈 정리됐어요.
어느 섹터에 집중할까요?

① 반도체 — 브로드컴 쇼크 여파 + 피에스케이 상한가
② 조선 — CPSP D-30 카운트다운 임박
③ 로봇 — 시선AI 수주 + 유온로보틱스 1.5조

번호로 답해주세요 (예: 1)
⏰ 08:00까지 미답변 시 자동 초안 발행
```

### 2단계 질문 (1단계 답변 수신 후 즉시 전송)
```
📊 STOCK BRAIN 오늘의 브리핑 질문 (2/2)

반도체 선택하셨군요.
판단을 알려주세요:

A. 일시 조정 — 곧 반등 가능
B. 추세 전환 — 비중 줄이는 게 맞다

판단 + 이유 한 줄만요.
예: "A. AI 가이던스는 상향인데 네트워킹만 부진 부각"
```

## 단계적 구현 순서

1. **Phase 1**: 텔레그램 봇 양방향 질문-답변 (bot.py)
2. **Phase 2**: 카드 생성 연동 (card_gen.py) — 운영자 판단 반영
3. **Phase 3**: PNG 자동 캡처 + 채널 전송 (publish.py)
4. **Phase 4**: 자동 초안 생성 + 재발행 흐름
