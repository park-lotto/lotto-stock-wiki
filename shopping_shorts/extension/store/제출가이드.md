## 1단계 — 개발자 등록 ($5, 1회)

1. https://chrome.google.com/webstore/devconsole 접속
2. 사장님 구글 계정으로 로그인
3. **개발자 등록비 $5 결제** (평생 1회, 카드 필요)
4. 개발자 이름 입력 → 이게 스토어에 "게시자"로 표시됩니다
   - 추천: `로또의 주식인사이트` 또는 `숏템박스`

### 간단한 설명 (132자 이내)
```
유튜브·틱톡·인스타그램·샤오홍슈·도우인 영상에 '담기' 버튼을 추가해, 마음에 든 영상을 내 모음집에 클릭 한 번으로 저장합니다.
```

### 자세한 설명
```
영상을 찾다가 "이거 나중에 참고해야지" 싶을 때, 주소를 복사해 어딘가에 붙여넣는 번거로움 없이 버튼 하나로 모아두세요.

■ 이렇게 동작합니다
설치하면 아래 사이트의 영상 화면에 '📥 담기' 버튼이 자동으로 나타납니다.
버튼을 누르면 그 영상이 내 모음집(숏템박스)에 저장됩니다.

■ 지원 사이트
· 유튜브
· 틱톡
· 인스타그램
· 샤오홍슈(RedNote)
· 도우인

■ 인스타그램 추가 기능
· 🔍 렌즈 — 지금 보고 있는 장면으로 비슷한 영상 찾기
· 📌 채널등록 — 이 계정을 내 추적 목록에 추가
· ⏱ 시크바 — 원하는 장면으로 이동, 등록일 확인

■ 이용 안내
저장 기능을 쓰려면 숏템박스(shoppingshorts.duckdns.org) 계정이 필요합니다.
버튼은 위에 적힌 사이트에서만 나타나며, 다른 사이트에서는 아무 동작도 하지 않습니다.
```

## 5단계 — 개인정보 보호 (★심사에서 제일 잘 막히는 곳)

### 단일 목적 (Single purpose)
```
사용자가 보고 있는 동영상 페이지의 주소를 사용자 본인의 숏템박스 모음집에 저장하는 것, 단 하나의 목적을 위한 확장입니다.
```

### 권한 사유 — host permission (`shoppingshorts.duckdns.org`)
```
사용자가 '담기' 버튼을 눌렀을 때 해당 영상의 주소를 사용자 본인의 계정으로 저장하기 위해, 서비스 서버(shoppingshorts.duckdns.org)와만 통신합니다. 이 확장은 그 외 어떤 도메인과도 통신하지 않습니다.
```

### 권한 사유 — content script (유튜브·틱톡 등)
```
지원 사이트의 영상 페이지에 '담기' 버튼을 화면에 표시하고, 사용자가 버튼을 눌렀을 때 현재 페이지의 주소·제목·썸네일을 읽기 위해 필요합니다. 페이지의 다른 내용을 수집하거나 변경하지 않습니다.
```

### 원격 코드 사용
```
아니요 (No) — 모든 코드가 확장 패키지에 포함되어 있습니다.
```
※ 이건 사실입니다. 실제로 원격 로드를 전부 제거했습니다.

### 데이터 사용 — 체크할 항목
- ☑ **웹사이트 콘텐츠** (사용자가 담기를 누른 영상의 URL·제목·썸네일)
- ☐ 개인 식별 정보 / 건강 / 금융 / 인증 정보 / 위치 / 개인 통신 — **전부 체크 안 함**

### 데이터 사용 관련 3개 동의 항목 — **전부 체크**
- ☑ 승인된 사용 사례를 위해서만 데이터를 사용합니다
- ☑ 제3자에게 데이터를 판매/양도하지 않습니다
- ☑ 신용도 평가나 대출 목적으로 사용하지 않습니다

### 개인정보처리방침 URL
```
https://shoppingshorts.duckdns.org/privacy
```
※ 이 페이지에 **확장프로그램 전용 섹션(5번)을 새로 추가해뒀습니다** — 수집 항목·통신
대상·원격코드 미사용·제3자 미판매를 명시했습니다. 심사관이 실제로 열어보는 페이지입니다.

⚠️ **한 가지만 사장님이 채워주셔야 합니다.** 이 페이지 맨 아래 사업자정보가 지금
`(준비 중)`으로 비어 있습니다(상호·대표자·문의처). 심사관이 "연락처 없음"을 문제 삼는
경우가 있으니, **최소한 문의 이메일이라도** 채우시길 권합니다.
→ 채우는 곳: 관리자 화면(admin) → 사업자정보 설정(`biz_*`). 값을 넣으면 즉시 반영됩니다.

## 6단계 — 게시

**[검토를 위해 제출]** 클릭 → 끝.

- 심사 기간: 보통 **수일 ~ 2주**
- 결과는 사장님 구글 계정 메일로 옵니다
- 통과하면 스토어 링크가 나오고, 그 링크만 사용자에게 주면 **클릭 한 번**으로 설치됩니다
