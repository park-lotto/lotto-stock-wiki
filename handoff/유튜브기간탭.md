```
1. reel_history 가 인스타 전용 — platform 컬럼이 아예 없었다.

   지나간 수집분의 제목·썸네일·조회수가 하나도 안 남았다.
2. app.py:840  if platform != "instagram": return {"items": []}
   → 유튜브로 기간탭을 누르면 **빈 목록**이 돌아왔다.
```

## 고친 것 (A안 — 코드, 크롤 0)
- `reel_history`에 `platform` 컬럼 + 인덱스. 기존 DB는 `ALTER`로 자동 마이그레이션(기본값 instagram)
- `save_last_run_platform`도 `_record_history` 호출 → **유튜브 수집이 히스토리에 쌓인다**
- `hits_since(platform=...)` 필터 / `app.py`의 인스타 전용 차단 해제
- 테스트 3건 신규(`test_youtube_history.py`) + 기존 계약 테스트 갱신(`test_reference_span.py`)

## 과거 복원 (B안 — `scripts/backfill_youtube_history.py`) ⏭ 아직 안 돌림
`platform_snapshots`의 video_id를 50개씩 묶어 `videos.list(part=snippet,statistics)`로
제목·조회수를 받아 `reel_history`에 넣는다.
```
비용: 호출당 1유닛(50편 묶음) → 45,387편 = 약 908유닛
      하루 무료 10,000유닛의 9%. 요금은 0원.
썸네일: API 없이 video_id로 만든다 (i.ytimg.com/vi/<id>/hqdefault.jpg)
실행:  python -m scripts.backfill_youtube_history --days 30 --limit 2000   # 맛보기
       python -m scripts.backfill_youtube_history --days 30                # 전체
```
### ★함정 (여기서 한 번 밟았다)
`store._record_history`를 쓰면 **안 된다.** 그 함수는 `first_seen`·`last_seen`을 같은 값으로
넣고 끝에서 "last_seen이 30일보다 오래된 행 삭제"를 돌린다 → **옛 날짜로 넣는 순간
그 자리에서 지워진다**(넣었는데 0건이 되는 조용한 실패).
그래서 백필은 `first_seen=그때 수집일 / last_seen=지금`으로 갈라 직접 INSERT 한다.

### 30일 천장
`reel_history`는 30일 롤링 정리가 있다. 60일치를 넣어도 30일 넘은 건 다음 수집 때 지워진다.
'이번 주·이번 달'에는 충분하지만 **'역대 명예의전당'은 별개**다 —
그건 `channel_archive`(208,659행)가 담당하는데 이쪽도 인스타 전용이다(`archive=1` 분기).

### main에 들어간 것 (배포 완료)

### ⚠️ 서버는 아직 옛 코드다
`auto_deploy.sh`가 **"배포 대기(시간창 2~6시 밖)"** 로 미룬다(고객 사용 중 재시작 회피).
```

```
그래서 **백필은 배포 뒤에** 돌려야 한다 — `reel_history.platform` 컬럼이 서버 코드의
마이그레이션으로 생기기 때문이다(지금 서버 DB엔 아직 없다).

### 왜 조회수 기준인가 (실측)
```
댓글 중앙값     인스타 60   /   유튜브 1
유튜브에 인스타 문턱(500/1000)을 그대로 대면 → 이번주 48편 · 이번달 27편 = 빈 화면
조회수 분포     P90 7만 · P95 20만 · 최대 796만
                10만+ 754편(상위 8.2%) · 30만+ 325(3.5%) · 50만+ 196(2.1%) · 100만+ 72(0.8%)
```

### 밟은 함정 (다시 밟지 마라)
1. **`.vbadge` 이름은 이미 쓰이고 있다** — 썸네일 위 영상길이 뱃지, `position:absolute`.
   같은 이름을 쓰니 조회수 뱃지가 카드 밖으로 튀어나갔다(실측 x=1828, 카드는 x=306).
   → `.viewbadge`로 갈랐다. **새 CSS 클래스는 만들기 전에 grep부터.**
2. **조회수 줄에 뱃지를 붙이면 라벨 '조회수'가 두 줄로 깨진다**(폭 부족). 순번 줄 한 곳만.
3. **`store._record_history`로 옛 날짜를 넣으면 그 자리에서 지워진다**(30일 정리가 같이 돈다).
4. **`except: pass`를 늘리면 게이트가 막는다**(test_silent_except_budget). 예산을 올리지 말고 로그를 찍어라.
