# 해외HOT 자막 없는 썸네일 우선 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 해외HOT 목록에서 썸네일에 자막이 없는 영상(`text_level="none"`)이 맨 위로 오게 한다.

**Architecture:** 파이프라인 모양은 그대로 두고 두 가지만 바꾼다 — (1) 썸네일 자막 판정을 "수집순 앞 15개"에서 "생존자 전부"로 넓히되 SQLite 캐시로 재판정을 막고, (2) 피드 정렬 키를 `score` 단독에서 `(자막등급, -score)`로 바꾼다. 프론트는 서버가 준 배열 순서를 그대로 그리므로 화면 코드는 건드리지 않는다.

**Tech Stack:** Python 3.12 / SQLite (`shopping_shorts.store.Store`) / Gemini Vision (`video_analysis.text_level_vision`) / pytest

**설계문서:** `docs/superpowers/specs/2026-07-29-해외HOT-자막없는썸네일우선-design.md`

## Global Constraints

- **작업 폴더는 `.tracks/해외HOT` 하나뿐이다.** main 폴더(`C:\Users\TheRose\Desktop\로또의 주식\shopping_shorts\...`)의 파일은 하나도 건드리지 않는다. 흡수 사고의 원인이 된다.
- `ranking.py`의 `sort_by`는 **수정 금지** — 유튜브·인스타 랭킹이 함께 쓰는 공용 함수다. 해외HOT 정렬은 `overseas_hot_jobs._merge_rotate`에서만 한다.
- `overseas_funnel`은 **순수함수 모듈**이다. I/O(DB·네트워크)를 넣지 않는다.
- 판정 실패·썸네일 없음은 캐시에 저장하지 않는다(다음 수집에서 재시도되게).
- `text_level` 값은 `"none"` | `"light"` | `"heavy"` 셋뿐이다(`video_analysis._TEXT_LEVEL_SCHEMA` enum).
- 테스트는 `shopping_shorts/tests/` 아래에 둔다(`tests/` 아님).
- 전체 pytest 스위트는 기준선 실패 13건이 이미 있다. 게이트 기준은 "**실패가 늘지 않았나**"다.

```python
    def save_thumb_text_level(self, shortcode, level):
        """썸네일 자막등급('none'|'light'|'heavy') 저장. 같은 shortcode는 덮어쓴다."""
        with self._conn() as c:
            c.execute(
                "INSERT INTO thumb_text_level(shortcode, level, created_at) "
                "VALUES(?,?,?) ON CONFLICT(shortcode) DO UPDATE SET "
                "level=excluded.level, created_at=excluded.created_at",
                (shortcode, level, datetime.now(timezone.utc).isoformat()))

    def get_thumb_text_level(self, shortcode):
        """저장된 자막등급. 판정된 적 없으면 None."""
        with self._conn() as c:
            row = c.execute(
                "SELECT level FROM thumb_text_level WHERE shortcode=?", (shortcode,)
            ).fetchone()
            return row[0] if row else None
```

> 주의: `self._conn()`·`datetime` import는 `store.py`에 이미 있다. `save_vision_tags`가 쓰는 방식을 그대로 따를 것 — 다르면 그 파일의 실제 패턴에 맞춘다.

```python
def _annotate_text_level(items, store):
    """생존자 **전부**의 썸네일을 봐서 text_level(자막 오버레이 정도)을 매긴다.

    2026-07-29 변경: 예전엔 앞 cap(=15)개만 봤는데, 이 시점의 items는 아직
    score가 없어(build_overseas_items 전) '상위'가 아니라 그냥 수집순 앞 15개였다.
    판정 안 된 항목은 자막 여부를 모르니 정렬에서 줄을 세울 수 없어 상한을 없앴다.
    대신 shortcode 캐시로 재판정을 막아 Gemini 쿼터를 지킨다 — 피드는 _merge_rotate로
    유지되므로 매 수집에서 새로 들어온 것만 실제로 비전을 탄다.

    판정 실패·썸네일 없음은 text_level을 안 붙이고 캐시에도 안 남긴다
    (overseas_funnel.passes_caption_clutter가 통과시켜 과필터를 막고, 다음 수집에서 재시도)."""
    judged = cached = 0
    for it in items:
        sc = it.get("shortcode")
        hit = store.get_thumb_text_level(sc) if sc else None
        if hit:
            it["text_level"] = hit
            cached += 1
            continue
        img = video_analysis.fetch_thumb_bytes(it.get("thumbnail"))
        if not img:
            continue
        level = video_analysis.text_level_vision(img).get("text_level")
        if level:
            it["text_level"] = level
            judged += 1
            if sc:
                store.save_thumb_text_level(sc, level)
    _JOB["phase"] = f"자막판정 신규{judged}·캐시{cached}"
    return items
```
