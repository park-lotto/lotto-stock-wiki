# 장면꾸미기 UI·정밀 템플릿 디자인 시스템

## 2026-09-10 · 썰쇼핑형 보정 및 전장면 고정형 20종

- 기존 20종은 `썰쇼핑형`, 새 20종은 `전장면 고정형`으로 분리했다. 고정형은 `final_styles.json`에서 훅·본문의 상단 구조가 동일한 20종을 골라 단일 `frame`으로 만들었으며, 1~12장 이동 중 프레임은 유지되고 자막만 장면별로 바뀐다.
- 고정형 20종은 레퍼런스의 실제 제목 문구·줄 수·색·좌표를 편집 레이어 초기값으로 재현한다. 선택 즉시 원본과 같은 조판을 보이고 각 줄을 수정해도 해당 프리셋의 스타일이 유지된다.
- 고정형의 줄 내부 다중 강조색도 프리셋별 단어 규칙으로 분리했다. 리뷰어컵은 1줄 분홍/흰색, 2줄 노랑/청록과 기울기를 재현했고, 20종의 투톤·3줄·2줄 래핑·부분 색상을 각각 정의했다.
- 공가미·썰카12의 `top_band`를 채널명으로 오판하던 분기를 제거했다. 방구석꿀템처럼 실제 `channel_box`가 있는 프리셋만 채널 입력을 표시하고 기본값은 `숏템메이커`다.
- 살림킹왕짱 제목을 덜 투박한 투톤으로, 썰카12를 TmonMonsori 굵은 외곽선으로, 공가미 강조색을 청록으로 보정했다.
- 제목별 `− / + / ↑ / ↓ / ↺`, 자막 위치 3단계, 흰색·강조·배경 색 팔레트, localStorage 기반 `현재 설정 저장`을 연결했다.
- 위·아래 이동 간격은 클릭당 0.5%로 세밀화했고 글자 크기 상한은 200%로 확장했다.
- 제목 위치를 옮길 때 원본 글자를 덮던 패치까지 함께 이동해 뒤 글자가 드러나던 문제를 수정했다. 원래 자리의 지움 패치는 고정하고 새 글자와 새 배경만 이동한다.
- `tools/qa_scene_style_ui.js`에서 썰쇼핑형 20종/40화면을, `tools/qa_continuous20_ui.js`에서 고정형 20종의 전 장면 동일성·위치·저장·넘침을 검사해 각각 실패 0건을 확인했다.

## 2026-09-10 · 장면 이동·자막 위치·프리셋 복원

- 미리보기 아래를 `이전 / 현재 장면·전체 장면 / 다음`의 단일 장면 이동기로 정리했다.
- 1장은 훅, 2~12장은 본문으로 연결하고 처음·마지막에서는 이동 버튼이 비활성화된다.
- 현재 장면 표시 아래에 `줄바꿈 기준 자동 장면 분리` 안내를 고정했다.
- 자막 문구는 읽기 전용이며 장면마다 `위 / 가운데 / 아래` 위치만 독립적으로 선택한다.
- 채널명·훅 제목에는 크기 `−/+`와 `↺` 프리셋 복원을 제공한다. `↺`는 문구와 크기를 원래 프리셋 값·100%로 함께 되돌린다.
- 채널명이 길어지면 실측 글자 폭에 맞춰 채널 배경 박스도 함께 늘어난다.
- `tools/qa_scene_navigation.js`로 1→12→1 장면 이동, 경계 비활성화, 자막 위치 3단 이동·원복, 자막 읽기 전용, 채널 박스 확장, 채널·제목 복원을 실제 브라우저에서 검증했다.
- 1920px 기준 3단 비율을 `422 / 998 / 499px`로 조정하고, 프리셋 목록을 3열에서 2열로 바꿔 훅·본문 썸네일을 각각 `80×143px`까지 키웠다. 중앙 영상은 `321×570px`이며 아래 장면 이동기도 한 화면 안에 남는다.
- 일부 프리셋의 채널명·제목이 원본 측정값보다 큰 실제 폰트 메트릭 때문에 잘리던 문제를 실측 맞춤으로 수정했다. `tools/qa_all_preset_layout.js`로 20개 프리셋 × 훅/본문 40화면을 검사해 가로·세로 잘림 0건을 확인했다.

  - `README.md`: 제작·대조·게시 게이트와 사용자 UI 원칙.

- JSON Schema 자체 검사와 예시 데이터 검증을 통과했다.
- 크롬에서 4개 시안 전환, 이미지 로드, 가로 넘침을 확인했다.

- 제공된 이븐쇼핑 캡처 2장을 `out/template_refs/`에 원본 해시와 함께 고정하고 `out/even-pair-precision-lab.html` 정밀 복제 작업판을 추가했다.

- A 시안의 `숏템 기본형`을 360×640 원본 기준 전용 템플릿으로 교체했다. 훅 배경 `rgb(43,39,29)`, 강조 `rgb(255,229,0)`, 본문 상단 `rgb(255,233,168)`과 띠 그라데이션·그림자·실측 Y 좌표를 CSS에 고정하고 `TmonMonsori.ttf`를 직접 로드한다.
- 기본 문구 상태에서는 원본 프레임을 그대로 표시해 서브픽셀까지 동일하게 보존하고, 사용자가 입력하는 순간 실측 편집 레이어로 전환한다. 크롬에서 문구 수정, 다른 프리셋 전환, 숏템 복귀, 훅/본문 전환을 실제 클릭해 확인했다.
- 문구 편집 패널을 프레임별 필드 구성으로 변경했다. 숏템 본문은 실제 구성대로 `채널명 · 훅 제목 · 현재 장면 자막` 3개만 표시하며, 훅에서는 `채널명 · 훅 제목 1 · 훅 제목 2 · 보조 제목`을 표시한다. 채널명은 상단과 프로필 옆 이름에 동시에 반영되고 글자 수 표시도 입력값을 따라간다.

## 2026-09-10 · 재부팅 후 복구 및 편집 깨짐 수정

- A 시안의 기존 3단 편집기 구조를 유지한 채 `숏템 기본형`을 첫 번째·기본 선택으로 고정하고, 새벽에 수집한 20개 훅+본문 카드를 같은 목록에 연결했다.
- `숏템 기본형`은 범용 이미지 덧씌우기를 쓰지 않고 기존 전용 DOM/CSS 편집 레이어로 분기해 원본 디자인을 보존한다.
- 문구가 길어질 때 잘리거나 겹치던 문제를 자동 글자 크기 맞춤으로 수정했다. 16자 테스트 문구를 실제 입력해 가로 영역 293px 안에 맞는 것을 브라우저 렌더로 확인했다.
- 현재 초정밀 수동 좌표 완료·연결 대상은 `활용정점`, `살림킹왕짱`, `썰카12`, `방구석꿀템`이며 나머지는 계속 원본 대조가 필요하다.
- 템플릿 왕복 시 이전 정밀 이미지 레이어가 `hidden`보다 강한 CSS 때문에 남던 문제를 수정했다. 다른 템플릿에서 `숏템 기본형`으로 돌아와도 훅/본문 원본이 정상 복귀한다.
- 모든 문구 필드 라벨에 독립 `− / +` 크기 버튼과 퍼센트 표시를 추가했다. 크기는 `프리셋 + 훅/본문 + 필드` 단위로 분리된다.
- `tools/qa_scene_style_ui.js`로 20개 프리셋의 훅/본문 40화면을 검사한다. 채널명 단독 변경 격리, 모든 표시 필드 변경, 글자 크기 버튼, 가로 넘침, 원본 전환, 숏템 복귀, 이미지 로드, 런타임 오류를 검사했으며 최종 실패 0건이다.
- 원본 프레임에서 편집 레이어로 전환할 때 모든 문구를 한꺼번에 다시 그려 수정하지 않은 글자까지 달라지던 문제를 제거했다. 이제 변경한 필드의 배경 패치와 글자만 생성하고 나머지는 원본 픽셀을 유지한다.
- 숏템 훅/본문도 360×640 원본 기준 전용 좌표를 추가해 같은 필드 단위 편집 방식을 사용한다. 20개·40화면의 모든 표시 필드를 각각 하나씩 단독 수정해 다른 필드 레이어가 생성되지 않는 것까지 자동검사했다.
- 사용자가 지적한 핵심은 원본 래스터 보존이 아니라 `수정 전/후 편집 글자 스타일 동일`이다. 따라서 처음부터 편집 레이어를 표시하도록 전환했고, 자동 글자 축소를 제거했다. 긴 문구는 사용자가 `−/+`로 조절한다.
- `숏템 기본형` 훅은 TmonMonsori 원본 굵기 400, 51.81px 표시 크기, 자간 -2.70px, 외곽선 3.11px, 그림자 3.43px로 교정했다. `이케아도 놀랄` → `이케아도 놀랄1` 변경 전후 계산 스타일과 좌표가 완전히 동일함을 확인했다.

## 2026-09-10 폰트·훅 모션 보강

- 공식 배포 한글 제목 폰트 4종(잘난체2, 잘난고딕, 가석체, Stylish)을 추가하고 20개 고정형 프리셋의 성격에 맞춰 재배정했다.
