# Higgsfield API 내부 시험 생성

## 완료

- 관리자 전용 `/admin/higgsfield` 시험실을 추가했다.
- Seedance 2.0 image-to-video를 5초·720p·무음으로 고정하고 동시 1건만 허용했다.
- Open Higgsfield API Key ID/Secret을 서버 환경변수 또는 기존 암호화 키 저장소로 연결한다.
- 공급자 비동기 상태를 폴링하고 결과 영상을 서버에 내려받은 뒤 관리자에게 제공한다.
- 공개 HTTPS 입력만 허용하고 내부망·비공식 상태 URL을 거절한다.
- 현재는 관리자 내부 검증이라 고객 포인트는 차감하지 않고 예상 10P만 표시한다.

## 확인

- `py_compile` 통과.
- Higgsfield 어댑터·관리자 라우트 테스트 12개 통과.
- 인라인 JavaScript 문법 검사 통과.
- 로컬 서버에서 `/admin/higgsfield`와 설정 API가 200으로 열리고 키 미등록 상태·모델·가격·버튼 상태가 화면에 표시되는 것을 확인했다.

## 다음

- Open Higgsfield API 잔액 충전 및 Key ID/Secret 발급 후 시험실에서 암호화 연결한다.
- 공개 상품 이미지 한 장으로 최초 유료 생성 1건을 실행해 실제 원가·대기시간·품질을 기록한다.
- 서면 사용 허가와 실측이 끝나기 전에는 고객 포인트 차감을 열지 않는다.
