## 어떻게 모았나 (재현)

1. 유튜브 Data API는 쿼터 소진 → **`yt-dlp ytsearch30:`**(쿼터 0). 검색어 **67개**(한글 38 + 영문 18 + 예능 전용 11) → 고유 1,417편
2. 제목 키워드(배포·무료·템플릿·프리셋·팩·소스…) + 조회 1천↑ → 809편 설명란 수집. ★일반 `yt-dlp -j`는 150건쯤에서 **로그인 확인(봇 차단)**, watch 페이지 curl은 **캡차** → `--extractor-args youtube:player_client=android` 로 우회(실측 OK)
3. 설명란에서 링크(drive·blog·tistory·notion·mega…)와 라이선스 문구 추출 → 링크 있는 509편이 카탈로그
4. 상업OK 문구 + 구글드라이브 링크 = 89팩을 `gdown`으로 다운로드(`--no-cookies`, 폴더는 `--folder`) → **20팩 성공 후 구글이 "접근 과다"로 차단**(성공했던 링크도 실패) → 중단
5. `build_library.py`: zip 해제(중첩·cp949 파일명) → ffprobe로 알파·해상도 → 카테고리 폴더로 이동 + pack.json/library.json

## 2026-09-13 새벽 3차 — 뷰어 전수 점검·개선 (사장님 "깨진 것 다시 점검" 지시)

- 여는 방식: `file://` → **로컬 http 런처**(`research/effect_packs/open_library.ps1`, 바탕화면 `효과팩 라이브러리.lnk`). file://은 크롬 확장·플레이라이트가 못 다뤄 검수 불가 + 재생 편차. ★런처 .ps1은 **UTF-8 BOM**으로 저장해야 한글 경로가 안 깨진다(BOM 없으면 PowerShell 5.1이 ANSI로 읽음). 영문 정션 `Desktop\effect_packs` → 실제 폴더.
- 전수 점검 도구 `tools/effect_packs/audit.py`(ffprobe/PIL) + 브라우저 JS 전수(이미지 303·영상 228·오디오 56·크게보기 228 전부 OK).
- 뷰어(`viewer.py`) 개선: 자막 템플릿(mogrt)은 내장 thumb.mp4/thumb.png에서 **글자 영역만 PIL bbox 합집합으로 크롭**해 480×240 칸에(ffmpeg cropdetect는 어두운 얇은 자막에서 음수 폭 → 폐기) · 포스터는 6개 시점 중 내용 최다 프레임 · 화면에 보이면 자동재생 · 클릭=라이트박스(원본 전체 화면 1280×720, 컨트롤) · "정지형"/"빈 화면" 배지 · 유튜브 커버.
- ★실사고: 미리보기 480×135(홀수 높이) → libx264 실패 → 0바이트 50개(브라우저 재생 오류). 크기는 항상 짝수.
- zip 비번: `tools/effect_packs/zip_passwords.json`("*" 목록, 전 zip에 순서대로 시도). 릴리리아 10편 해제(8019·0011·4512·2816·1213·1215·1219·1214·1217·3080). 남은 릴리리아 5편(#10·#24·#28·#23·#13) + Freeticon 7 + 조PD 1.
- 남은 빈 썸네일 2개는 제작자 미리보기 자체가 빈 화면/극저휘도(f8X ver9, w0IR ver1) → "빈 화면" 배지.
- 사장님 최종 목표: **자막 폰트뿐 아니라 효과까지 프리셋으로 묶어** 제품에서 고르게(폰트 라이브러리처럼). 다음 단계는 이 라이브러리를 `deco_frame.PRESETS`·모션 자산 규격으로 잇는 어댑터.
