# 브리프 — 해외원본형 원본 찾기 (회원 흐름 flow.py 해외원본형 · 우리 PC 원본찾기 공용, 관제 263 지시서 08)

이 글은 서버 지시서(`tools/calcopy/hybrid/flow.py` 해외원본형 origin 단계)가 판독 질문에 그대로 붙인다. 판단 함수는 따로 있다 —
같은 영상 판정 지시문 = `origin_find.JUDGE_PROMPT` · 원본 고르기 = `origin_find.pick_origins` · 한국/해외 가르기 = `origin_find.is_korean`.
이 글에 그 규칙을 다시 적지 않는다(두 벌 금지) — 여기는 **회원 Claude 가 사진을 볼 때 놓치기 쉬운 것**만.

## 1. 소재(벤치) 읽기
- 한국 재편집 = 한국어 자막·나레·한글 제목. 해외 원본 = 출연자 본인이 올린 외국어 영상. 둘 다 받는다(해외 원본 주소를 바로 주면 그것이 첫 원본).
- 모음 편(한국 쇼츠 한 편에 외국인 여럿)은 원본이 여럿이다 — 렌즈 장면 4장(15·35·55·75%)이 서로 다른 원본을 가리킨다(01b §4·§6).
- 제품이 화면에 안 나오면(말로만) 만들지 않는다 — is_shopping false.

## 2. 같은 영상 판정(렌즈 후보 썸네일 시트)
- 같은 사람·같은 장소·같은 순간의 **같은 촬영분**만 같다. 자막·띠·잘림·확대·좌우반전이 달라도 같은 촬영분이면 같다.
- 같은 제품을 다른 사람이 쓴 영상, 같은 출연자의 다른 영상은 **다르다**(01b §5 BGT 사고 — 같은 마술사 다른 무대).
- 썸네일이 비었거나 작아 판단이 안 되면 넣지 않는다(미판정 — '다르다'로 단정하지 않는다).
- 원본 = 같은 영상 중 해외 채널마다 **가장 먼저** 올린 것. 한국 재편집보다 늦게 올린 해외 계정은 퍼 간 쪽(엔진이 날짜로 거른다).

## 3. 같은 제품 다른 해외 반응(원본이 1개뿐일 때 2~3개로)
- 같은 제품(포장·색·모양)을 **다른 해외 사람**이 처음 써 보고 반응하는 쇼츠. 한국 채널 재편집·리뷰 모음은 고르지 않는다.
- 제품이 또렷하고 반응(놀람·감탄)이 큰 것 · 박힌 자막·워터마크가 적은 것 · 이미 고른 원본과 같은 촬영분이 아닌 것.
- 화면에 다른 제품(비슷한 다른 브랜드)이 섞이면 뒤로(10-24 ep13: 세럼·튜브·노란 캡슐 구간은 다른 제품이라 안 씀).

## 4. 박힌 글자
- 원본에 덧씌운 자막·제목 띠·워터마크는 샷 판독(text 상자)에 빠짐없이 적는다 — 회원 VMake 키가 있으면 지우고(`vmake_clean`), 없으면 엔진이 흐린다(`rules.text_blur_all`). 잘라서 피하지 않는다(확대 1.0, 사장님 10-22).
- 화면 속 제품 포장 글자·출연자 옷 글자는 박힌 글자가 아니다.
