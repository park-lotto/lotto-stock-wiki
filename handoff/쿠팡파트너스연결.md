### 결론부터
- 파트너스 오픈API는 **최종 승인된 회원만** 발급. 최종 승인은 **실제 판매 실적**이 나야 넘어간다
  (자료마다 "판매금액 15만원" 등 — 현재 기준은 파트너스 대시보드에서 직접 확인 필요).
  키 유효기간 **180일**이라 승인 후에도 만료 관리가 따로 필요하다.
  → **지금은 자동 상품검색·딥링크 생성을 못 한다. 수동 흐름으로 먼저 붙였다.**
- **쿠팡 링크는 영상 픽셀에 안 들어간다.** 그래서 "썸네일 다음"에 단계를 새로 만들지 않았다.
  상품 *확정*만 앞단(매칭 검토)에서 하고, *링크*는 7단계 SEO 설명란·8단계 인포크 등록에서 꺼내 쓴다.
- 인포크링크(링크인바이오)가 최종 목적지 — 영상 설명란엔 인포크 프로필 링크 하나만 넣고
  상품은 인포크 안에서 관리하는 구조.

## 2026-07-29 (집) — 상품 자동검색(크롤) 추가, 라이브 병합

### 결론부터
- **크롤은 되는데, 되는 IP가 정해져 있다.** 쿠팡(Akamai)은 **데이터센터 IP와 헤드리스를
  둘 다 막는다.** 실측 결과:

  | 경로 | 결과 |
  |---|---|
  | httpx / curl_cffi(chrome124 위장) | 403 (홈페이지조차) |
  | Playwright **헤드리스**, 로컬 | 403 |
  | Playwright **헤드풀 + channel="chrome"**, 로컬(주거용 IP) | **200 · 상품 58건** |
  | 서버(AWS) 직결, xvfb + 헤드풀 chrome | 403 |
  | 서버 + Webshare `YTDLP_PROXY`(데이터센터 플랜) | 403 |

  → 유튜브 쇼츠·Reddit과 같은 패턴(memory `reference_youtube_shorts_datacenter_block`).
  **서버에서 돌리려면 주거용(residential) 프록시가 반드시 필요하다.**
- 사장님 선택 = 주거용 프록시 구입. 그래서 코드는 `COUPANG_PROXY` 한 줄로 꽂히게 해두고,
  **기본은 꺼둔 채** 병합했다(`COUPANG_SEARCH_ENABLED=0`) — 프록시 검증 전에 켜지면
  화면에 매번 실패 배너가 뜬다. 즉 이 병합만으로 라이브 동작은 안 바뀐다.

### 넣은 것
| 파일 | 내용 |
|---|---|
| `coupang_search.py` (신규) | 헤드풀 크롬으로 검색 → 카드 추출(JS) → `parse_items`(순수)로 정규화. URL은 `coupang_partners.parse_product_url`로 추적값 제거 |
| `config.py` | `COUPANG_PROXY` · `COUPANG_SEARCH_ENABLED`(기본 0) · `COUPANG_SEARCH_LIMIT`(24) · `COUPANG_SEARCH_TIMEOUT_MS` |
| `app.py` | `GET /api/coupang/search?q=` |
| `produce.html` | 상품 확정 폼에 `🔎 쿠팡에서 상품 찾기` + 결과 카드 그리드. **카드 클릭 = 확정** |
| 테스트 | `test_coupang_search.py` 12건 + 엔드포인트 2건 (쿠팡 관련 합계 36 passed) |

### 검증한 것 (실측)
- 로컬 라이브 API: `실리콘 집게` → **5.4초 / 19건**, 가격·평점·썸네일·광고표시까지
- 실브라우저 그라운딩(produce.html, Playwright): 카드 19개 렌더·썸네일 실제 로드,
  카드 클릭 시 `cpUrl`·`cpName` 자동입력 확인, pageerror 0

### 함정 (다음 사람이 밟지 말 것)
- ⚠️ `/api/coupang/search`는 **`async def`가 아니라 `def`**다. 안에서 Playwright **sync**
  API를 쓰므로 이벤트 루프 스레드에서 돌면 죽는다(FastAPI가 def 핸들러를 워커 스레드로 돌린다).
- ⚠️ `headless=False`가 필수다. 서버에선 **`xvfb-run`**으로 가상 디스플레이를 붙여야 한다
  (서버에 `xvfb-run`·Google Chrome 150 설치 확인됨). 단 **서버 RAM이 1GB**라 헤드풀 크롬이
  빠듯하다 — 실제 켤 때 메모리부터 관측할 것.
- ⚠️ 클래스명이 해시 붙은 CSS 모듈(`ProductUnit_productUnit__Qd6sv`)이라 **접두사 매칭**으로
  잡았다. 배포마다 해시가 바뀌므로 완전일치로 바꾸지 마라.
- ⚠️ 가격은 `PriceArea`가 "정가\n할인율\n판매가"로 쌓아 보낸다 — **마지막 '원'**이 판매가다.
