# 브리프 — 해외원본형 대본·재료 (회원 흐름 flow.py 해외원본형 script 단계 · 우리 PC 잇템로그 제작 공용, 관제 263 지시서 08)

서버 지시서가 대본 질문에 이 글을 붙인다. **박자·줄 수·어미·훅 꼴·끝 줄 꼴은 판(`styles.py brief <판>`)이 정한다** — 이 글은 판이 안 정하는,
해외 원본을 재료로 쓸 때의 공통 규칙만(판과 어긋나면 판이 이긴다). 옛 자리: scratchpad `mk_v3_*.py`(10-22~24 잇템로그 v3 13편 손 대본) → `tools/calcopy/ititemlog_make.py`.

## 대본(대본.json)
- 원음 줄(kind orig) = 원본 출연자 **본인의 말·반응**만. src = 원본 파일 이름, spans = 그 파일 초(해외 쇼츠는 통째로 받아 파일 0초 = 원본 0초).
  caps_rel = 한국어 번역 자막(반말·감탄 — '세상에·말도 안 돼'), 원문 뜻을 넘지 않는다. said = 원문 그대로.
- 나레(kind tts) = 판 brief 그대로. 사실은 원본 출연자가 말한 것·화면에 보이는 것·조사.md 사실(f번호)만 — 효능 단정·금액·질병 금지.
- 다른 해외 원본으로 넘어갈 때 나레가 다리를 놓는다('다른 외국인도 ~'). 원본 출연자를 한국인·유명인으로 꾸미지 않는다.
- 제품 이름: 같은 제품(exact)이면 이름을 말해도 된다. 비슷한 제품(alt)이면 원본 제품 이름을 쿠팡 제품처럼 말하지 않는다(rules.PRODUCT_TALK_FOREIGN).
- 받아쓰기 뭉개짐: 빠른 영문 약어(PDRN 등)는 목소리에서 빼고 자막에만(10-24 ep13 '알은'으로 들림).

## 재료(재료.json)
- 원본별 **시간순**(훅만 결과 먼저 — 판 v2) · 같은 장면 재사용 0 · 확대 1.0(세로 원본은 폭 전체 × 창 비율 높이) — 재료 초안(materials_draft)이 이 셋을 지킨 구간표를 준다. 그 안에서 줄마다 고른다.
- 박힌 글자: 지운 파일(clean)은 그대로 쓰고, 안 지운 파일의 글자 샷은 엔진이 재료.blur 를 채운다 — crop 을 좁혀 피하지 않는다.
- 끝 줄 화면은 앞에서 안 쓴 새 장면(판 v2 upgrades). 다른 제품(비슷한 다른 브랜드)·원본 밖 사람 얼굴 구간은 쓰지 않는다.
- see 칸 = 그 컷에 실제로 보이는 것(그 줄 대사의 동작·상태가 보여야 한다 — 장면↔대사, 표준 §12-3).

## 근거.md
'| 줄 | 말 | 근거 |' — 줄마다 한 줄(원본 id·초 · 사실 번호 · URL). 원본 URL 은 src_urls 에도.
