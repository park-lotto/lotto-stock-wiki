사용자는 가이드라인(기술 제약, 색상 시스템)만 제공하고, 씬의 레이아웃·구성·연출은 Claude가 매번 독창적으로 발명하기를 원한다.

**Why:** "나는 최소한의 가이드라인을 줄 뿐, 너에게 독창성과 창의성을 부여하는 것이다."

**How to apply:**
- 기술 제약 (WebkitBackgroundClip 금지, 색상 팔레트, 폰트) 은 준수
- 씬 레이아웃은 고정 템플릿에서 고르지 않음
- 매 씬 "이 내용을 가장 강하게 전달하는 시각 언어가 뭔가?" 에서 출발해 형식을 발명
- A~J 같은 유형 목록은 참고용일 뿐, 선택지 메뉴가 아님
- 이전 영상과 비슷한 씬 구성이 나오면 스스로 다른 방법을 찾음
