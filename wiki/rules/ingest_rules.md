## ⛔ 절대 금지 — 위키에 반영하지 않는 것

**목적: 양질의 구조적 인사이트만 누적. 하루짜리 노이즈는 위키를 오염시킨다.**

다음 내용은 출처(텔레그램·블로그·뉴스 무관)와 상관없이 **위키에 절대 기록하지 않는다:**

| 금지 유형 | 예시 |
|---------|------|
| 당일 주가 등락% | "삼성전자 오늘 -6%", "브로드컴 -12.6% 급락" |
| 당일 지수 등락% | "필라델피아반도체 +1.39%", "코스피 -0.8%" |
| 미국 종목 당일 등락 | "마블 +3.73%", "인텔 +4.43%", "릴리 신고가" |
| 외환·원자재 당일 가격 | "WTI 96달러", "달러 1,531원" |
| 단순 상한가/급등 언급 | "OO 오늘 상한가", "XX 장중 10% 급등" |

**반영해야 하는 것 (구조적 정보):**

| 반영 유형 | 예시 |
|---------|------|
| 리포트 TP 변경 | "KB증권 TP 200만원으로 상향 (기존 150만)" |
| 실적·수주·계약 이벤트 | "삼성중공업 FLNG 4.3조 수주 확정" |
| 섹터 방향성 변화 | "기관 수급 3총사: 반도체·피지컬AI·전력 확인" |
| 수급 빈집 종목 | "한미약품 수급빈집 포착" |
| 구조적 리스크/이슈 | "덕산하이메탈 공정위 담합 수사 개시" |
| 일정·트리거 이벤트 | "ADA학회 6/5~8 GLP-1 데이터 발표" |
| 증권사 투자전략 변화 | "하나증권 무선통신장비주 주도주 선언" |

## 수급오실레이터 일일 Ingest

**파일**: `raw/supply/{날짜}_수급오실레이터.xlsm`

### 시트 구조
```
수급오실레이터 시트:
  C7: 오실레이터 절대값
  C8: 오실레이터 일변화
  C12: 통계 (상위10% / 상위25% / 평균 / 하위25% / 하위10% / 현재)
```

### 빈집 등급 판정
```
현재값 < 하위10% → A 완전빈집 → 탑픽 2점
현재값 < 하위25% → B 반빈집   → 탑픽 2점
현재값 < 상위25% → C 정상     → 탑픽 0점
현재값 ≥ 상위25% → D 과매수   → 탑픽 0점
```

### 체크리스트
```
□ 1. xlsm 열기 (COM Excel, AutomationSecurity=1)
□ 2. 통계값 읽기 (상위10%/25%/평균/하위25%/10%)
□ 3. 관심 종목 컬럼 찾아 최신 C8값 추출
□ 4. 빈집 등급 판정
□ 5. 5일 방향 계산 (최근5일 평균 vs 오늘)
□ 6. stock/ 수급흐름 섹션에 새 행 추가
□ 7. 탑픽 스코어 재계산 + 콜아웃 업데이트
□ 8. log.md 기록
```

## 유동성 xlsm 일일 Ingest

**파일**: `raw/market/YYYYMMDD_유동성.xlsm`
**스크립트**: `raw/market/extract_유동성.ps1`
**출력**: `raw/market/YYYYMMDD_유동성_요약.md`

### 핵심 시트
| 시트 | 핵심 컬럼 | 탑픽 연결 |
|------|---------|---------|
| 유동성 컨셉 | C18=통합순위 | 수급빈집(0~2점) |
| 2027년 컨센 신고가 | C3=신고가여부(0=신고가) | 리포트신고가(+1점) |
| 가속화모멘텀 | C3=모멘텀스코어 | 주도섹터 확인 |

### 통합순위 → 빈집 등급
```
총 2,574종목. 순위 높을수록 = 빈집
A 완전빈집: 통합순위 ≥ 2,317 → 탑픽 2점
B 반빈집:   통합순위 ≥ 1,931 → 탑픽 2점
C 정상:     644~1,930         → 탑픽 0점
D 과매수:   ≤ 643             → 탑픽 0점
```

### /ingest raw/market/YYYYMMDD_유동성_요약.md 체크리스트
```
□ 1. 수급빈집 섹션 → stock/ 수급흐름 테이블 새 행 추가
□ 2. 탑픽 수급빈집 항목 업데이트 (A/B→✅ 2점, C/D→❌ 0점)
□ 3. 신고가 섹션 → stock/ 리포트신고가 ✅ 변경
□ 4. 주도섹터 → L5 섹터 index.md 오늘의 한줄 업데이트
□ 5. 탑픽 등급 재계산 (7~9점=🔴 / 5~6점=탑픽후보 / 3~4점=🟠 / 1~2점=🟡)
□ 6. log.md 기록
```

## 수출 데이터 모니터링

### 발표 주기별 처리
| 발표일 | 처리 방침 |
|-------|---------|
| 매월 1일 | ✅ 정식 업데이트 |
| 매월 11일 | 👁 방향성 확인만 |
| 매월 21일 | 👁 강한 신호(±30%p↑)만 메모 |
| 매월 15일 | ✅ 확정치로 잠정치 대비 수정 |

### 신호 등급
| 등급 | 조건 |
|------|------|
| 🔴 강력 | 판가YoY 부호 전환 / 물량YoY ±30%p 급변 |
| 🟠 중간 | 물량YoY > +50% 신규 / 판가YoY > ±20% / 전체≠미국향 괴리 |
| 🟡 약함 | 방향 유지, ±5~15%p 변화 |
| — | ±5%p 이내 |

### 신호별 업데이트 연쇄
| 신호 | export_monitor | sector/ | stock/ |
|------|:--------------:|:-------:|:------:|
| 🔴 강력 | ✅ | ✅ 즉시 | ✅ 즉시 |
| 🟠 중간 | ✅ | ✅ | — |
| 🟡 약함 | ✅ | — | — |

### 데이터 읽기 3대 원칙
1. **전체 ≠ 미국향**: 미국향 시트 반드시 별도 확인
2. **YoY ≠ 판가수준**: 절대값이 역대 고점이면 여전히 강세
3. **부분 데이터 보정**: 11일·21일은 일평균으로 비교

### 섹터-시트 연결
| 섹터 | 관련 시트 번호 |
|------|-------------|

| sector_PCB기판소재 | 21(PCB), 22(CCL), 25(솔더볼), 24(광섬유) |

## 일정·수주잔고·투경관리 Ingest

**파일**: `raw/일정 및 수주잔고.xlsx`

### 시트별 처리

**투경관리**
```
□ 경고예고·경고중 목록 읽기
□ 신규/해제 변화 탐지 → stock/ 최신 이벤트에 ⚠️/🔴/✅ 추가
□ 투경관리.md 업데이트
□ 투경 지정 종목: 탑픽 스코어 -1 페널티
```

**수주잔고**
```
□ col26(1Q26) vs col25(4Q25) QoQ 변화율 계산
□ 역대 최고 여부 판단
□ 🔴 신호 → stock/ 수주잔고 흐름 섹션 + 어닝서프(#3) ✅
□ 수주잔고_모니터.md 업데이트

신호: 역대최고·QoQ+50%↑ → 🔴 / QoQ+10~50% → 🟠 / ±10% → 🟡 / -30%↓ → ⚠️
```

**25년말~26년 이벤트**
```
□ 종목명 탐지 → D-? 계산
□ D-30 이내 → stock/ 일정 섹션 추가
□ 지난 것 → stock/ 최신 이벤트에 완료 행 추가
```

## 태린이 파이프라인 자동 ingest (ingest_excel.py)

> 업데이트: 2026-06-02 | `python scripts/ingest_excel.py` 한 번으로 전체 실행

### 파일별 파서 · 컬럼 · 텔레

#### 수급오실레이터 (700 / 700-1400 / 업종)
- EMA MACD 오실레이터 = (외인+기관 순매수) / 시가총액 → EMA12 - EMA26 - Signal
- **수급 상태 4분류**:
  | 상태 | 조건 | 의미 |
  |------|------|------|
  | 🔴 수급 바닥 턴중 | 빈집(하위25%) + trend=↑재진입 | 진입 타이밍 |
  | 🟡 수급 바닥 하락중 | 빈집(하위25%) + trend=↓빈집심화 or 횡보 | 대기 |
  | ⚪ 수급 꽉참 상승중 | 상위25% + trend=↑재진입 | 추격 위험 |
  | 🔵 수급 꽉참 턴중 | 상위25% + trend=↓빈집심화 | 매도 검토 |
- 업종 오실레이터: 양수 높음 = "수급 유입 중 업종" (강하다 X), 음수 낮음 = "업종 빈집"

#### 컨센움직임서프쇼크.xlsx
- **마지막 업데이트 확인**: `1개월 컨센 1개월일 변화` 시트 → "Last Update" 셀
- **실제 컬럼 구조 (0-based, 검증 완료)**:

  컨센상향/하향:
  ```
  r[1]=종목코드  r[2]=종목명  r[3]=업종
  r[4]=1M수익률  r[5]=3M수익률  r[6]=2026OP(십억)
  r[14]=컨센변화율(정렬기준)  r[16]=30일전컨센변화율
  ```
  서프라이즈/쇼크:
  ```
  r[1]=종목코드  r[2]=종목명  r[3]=업종
  r[4]=1M수익률  r[5]=3M수익률  r[7]=1Q실제발표
  r[11]=어닝서프율(정렬기준)  r[12]=컨센변화
  ```
- 기준일: 컨센상향/하향=6/1 기준 1개월 변화 / 서프·쇼크=1Q 실적(4월 발표)

#### 한국ETF상대강도.xlsx
- 파일 오래되면(10일 초과) → 소라티노ETF상대강도 파일로 자동 폴백
- Mansfield RS 60/120/250일 계산 → norm_RS_avg 기준 정렬

#### 투자아이디어정리.xlsx
- B열(r[1])에 데이터, 앞에 `'` prefix(Excel 텍스트 강제) → _clean()으로 제거
- 현재 분기 + 다음 분기 트리거만 추출
- 시트명 = 섹터/종목명

### 컨센 종합 탑픽 스코어링 (10점 만점)

| 조건 | 점수 | 파서 |
|------|------|------|
| 수급 빈집 A (하위10%) | +2 | parse_수급오실레이터() |
| 수급 빈집 B (하위25%) | +1 | parse_수급오실레이터() |
