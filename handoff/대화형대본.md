# 대화형대본 — 나레이션 + 인물1 / 인물1↔인물2 대화로 쓰는 쇼핑 대본 (전달 2026-10-05, TheRose PC)

> **소유 트랙**: 대화형대본 — 이 파일은 이 트랙 세션만 수정한다.
> 상태: 관제 카드 128 · 트랙 track/대화형대본 (2026-10-05 개시). 별개 트랙: 원음살리기(`handoff/원음살리기.md`).

## 흐름 (2026-10-05 사장님과)
1. "효과음 팩에 음성 효과음(이게 뭔 개소리야 같은) 있나?" → 없음. 팩21개 × 7칸 전부 타격음(`shopping_shorts/assets/sfx_packs/`)
2. "나레이션 + 다른 성우의 짧은 대사, 티키타카" 구상 → 리액션 꽂기 샘플 제작
3. 사장님 판정: **"리액션은 하면 안 될 것 같고, 언니 대사도 억지스럽다. 지금 대본 구성이 이런 쪽이 아니라 너무 어색하다."**
   → 리액션 꽂기 **폐기**. 대본을 처음부터 대화 구조로 써야 한다.

## 실측 (히트 쇼츠 말소리 있는 35편, 제미니 2회 판정 — 직접 듣진 않음)
| 형식 | 편수 |
|---|---|
| 한 목소리 | 19 |
| TTS 나레이션 + 리액션 목소리 | 4 (다이소 형 이거 해 줘 dCn16ZJGSqs 334만 등) |
| 원본 인물 원음 + 나레이션 | 3 (→ 원음살리기 트랙) |
| 실제 사람 대화(묻고 답하기) | 3 (청담샵 -hESnHg-Kug 278만 · 장윤주 YDFC0LmrW0Y 161만 · 샤워커튼 nn6wY-SC_lY 181만) |
| 기타 | 6 |

- 잘 되는 대화형의 공통점: **묻는 사람 = 시청자 대리(불편·의심) / 답하는 사람 = 정보를 쥔 사람(제품)**. 질문이 훅, 답에서 제품이 나온다. 리액션 전용 목소리 없음.
- 자연스러움 기준: "그 대사를 나레이션으로 바꿔 말하면 힘이 빠지나?" — 빠지면 인물 대사가 맞다("이거 산 뒤로 요거트 한 번도 안 샀어"). 안 빠지면 억지("매일?").
- ⚠️ 히트 대화형 3편은 **전부 실제 사람 녹음**. TTS 두 목소리 쇼핑 대화형이 잘 되는지는 미확인.

## 착수 시 정할 두 줄 (0순위-C) — 제안
- **주인 함수**: 칸별 화자는 대본 작가(`shopping_shorts/story_writer.py`)가 `beat["speaker"]`로 정하고, 목소리 고르기는 칸별 합성 한 곳이 `speaker→preset`으로 읽는다. 시간표(`video_assemble._beat_timeline`)·자막·캡컷은 칸 구조 그대로라 손 안 댐.
  ⚠️ 통째합성(`tts_joined.synthesize_joined`, 관제 049)은 한 목소리 전제 — 화자가 바뀌는 칸에서 끊어 합성해야 함. 미검증.
- **결과물 검사**: 완성 영상에서 칸마다 지정 화자 목소리인지(제미니 화자 판정) + 렌더·캡컷·미리보기 세 길 칸 길이 일치.
