주가가 올랐다고 해서 해당 재료 때문이라고 단정하면 안 된다.

**검증 순서:**
1. 해당 날짜 + 종목명으로 검색 → 상승 배경 실명 확인
2. 다른 이유 배제 체크리스트:
   - 섹터 전반 순환매인가?
   - 개별 호재(공급계약·임상·수주)가 따로 있었나?
   - 시장 전체 분위기(코스닥 급등일)에 편승한 것인가?
   - 외국인/기관 수급이 이 재료 때문에 들어왔나?
3. "국민성장펀드 때문에 올랐다"고 말하려면 → 그날 뉴스에서 해당 종목이 국민성장펀드 수혜주로 직접 언급됐는지 확인

**Why:** 영상에서 "이 종목이 국민성장펀드 때문에 올랐다"고 했다가 실제론 다른 이유였으면 신뢰도 0. 시청자도 검색하면 바로 반박 가능.

**How to apply:** 1군 후보 선정 시 무조건 "날짜+종목+상승이유" 검색으로 인과관계 검증. 인과관계 불명확하면 1군 탈락, 2군으로 내리거나 제외.

**논리 구조 (사고 흐름):**
재료 발표 확인 → 해당일 주가 반응 확인 → 상승 배경 검색(인과관계) → 악재 검토 → 현재 유지 여부 → 1군/2군 분류
