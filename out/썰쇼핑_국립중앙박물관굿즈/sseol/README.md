# 썰쇼핑 — 간식·제품 썰 쇼츠 프리셋

1080x1920 · 30fps · 약 45초. 참고 채널 최신 5편을 픽셀 단위로 재서 맞춘 화면 틀.
목소리 기본값: 타입캐스트 **제롬**.

## 화면 틀 (실측값, tools/render.py 상단 상수)
| 요소 | 값 |
|---|---|
| 헤더 | y 0~217 남색 (16,49,115), 아래 끝 y 218~221 선 4줄. 채널명 앞·뒤 반 / 가운데 아이콘 칸 x 454~625 |
| 제목 | 페이퍼로지 7Bold, 최대 80px · 폭 992px 넘으면 줄임, 가운데 y≈324, 검정 |
| 구분선 | y 432~436, x 30~1050, 회색 |
| 자막 | 페이퍼로지 6SemiBold 60.3px 검정, 1줄 기준선 y 539 / 2줄 y 610. 카드당 최대 2줄: 1줄 → 말에 맞춰 2줄이 아래 쌓임 → 다음 카드에서 통째로 교체. 문장부호 표시 안 함 |
| 영상 칸 | y 670~1549 (1080x880), 가운데 기준 꽉 채움, 컷은 그냥 끊김. 아래 y 1550~1919 흰 여백 |
| 인트로 | 제목 낭독 동안. 위쪽 y 0~435 를 62% 밝기로 + 훅 2줄(페이퍼로지 9Black, 1줄 흰색 105px · 2줄 하늘색 (0,166,238) 110px, 검정 테두리 8px, 그림자 오른쪽 10·아래 12) + 영상 y 436~바닥 + 흰 상자 x 78~1000·y 592~740 안에 제목(7Bold 최대 70px) |
| 끝 | 구독 유도 없이 마지막 말 뒤 약 0.4초에 끝 |

헤더 채널명·아이콘은 **내 채널 것**을 쓴다(참고 채널의 로고·마스코트는 그 채널 상표라 넣지 않는다):
`config.json` 의 `channel_name`(2글자면 아이콘 양옆 한 글자씩), `header_icon_path`(내 로고 PNG, 비우면 기본 아이스바).

## 설치
볼케이노 MCP 의 `sseol_seed` 단계가 이 폴더에 전용 가상환경(`.venv`)을 만들고 requirements(numpy · opencv-python · pillow · yt-dlp)를 깐다.
따로 필요한 것: ffmpeg/ffprobe(PATH) · agy(구글 Antigravity CLI, 로그인) · 열쇠 `~/.volcano/keys/typecast` · `~/.volcano/keys/speechmatics`.
점검: `python preset.py status`

## 제작 순서 (한 편 = 음성 1번 + 정렬 1번 + 렌더 1번)
```
projects/<이름>/script.json 작성                    (examples/chaltteok 참고)
python preset.py tts    projects/<이름>              → narration.wav, timing.json
python preset.py media  yt ...  / python preset.py aiimg ...  → 소재 (줄마다)
python preset.py review projects/<이름>              → review.json (굽기 전 판정: 작은 미리보기를 agy 가 한 번 · 판정은 코드)
python preset.py render projects/<이름>              → out.mp4   (review 통과여야 굽는다 · --still 3 : 한 장 미리보기)
python preset.py check  projects/<이름>              → sseol_check.json (렌더 뒤는 프로그램 측정만 — 완성본을 agy 에 보이지 않는다)
```

## script.json
```json
{"title": "공장 짓자마자 인기 식은 과자",
 "hook": ["공장 짓자마자", "인기 식은 과자"],
 "intro_media": {"path": "cands/g4/v03.mp4", "start": 16, "audio": true},
 "cards": [{"lines": ["일본 파트너 가루비는", "인기가 금방 식는다며 말렸지만"],
            "media": [{"path": "media/ai/ai01.jpg"}, {"path": "media/ai/ai02.jpg"}],
            "sfx": [{"name": "boing_1", "at": 0.9}]}]}
```
- `title` 상단 고정 제목·인트로 흰 상자 / `hook` 인트로 큰 글씨 2줄
- `cards[].lines` 1~2줄, 한 줄 4~12자
- `cards[].media` **줄 수만큼 목록** — 원본은 자막 줄마다 컷이 바뀐다(44초 41컷). 항목: `{"path", "start", "crop": [x0,y0,x1,y1], "audio": true, "motion": "zoom_in|zoom_out|none"}`
  - 컷 움직임(원본 그림 7컷·영상 8컷 프레임별 실측, 모든 컷 공통): 등장 1.063→1.025→1.002→1.0배로 튕겨 자리 잡고, 컷이 이어지는 동안 자막 줄이 바뀌면 1.006→1.056→1.093→1.117→1.121→1.122배 «툭» 밀고 들어감. 그 밖엔 멈춤. 확대 기준은 칸 가운데
  - `focus: [가로, 세로]`(0~1, crop 뒤 기준): 인물·행위 중심이 칸 가운데에 오게 자른다(원본은 피사체가 가로 50%·세로 45~50%). agy 가 장면마다 피사체 위치를 준다
  - 컷은 카드당 1개가 기본(원본 29카드 중 21), 같은 인물 그림 연속·몽타주만 목록으로 나눈다
  - 뉴스·자막이 박힌 영상은 `crop` 으로 자막 띠를 잘라낸다(뉴스는 보통 `[0,0.12,1,0.75]`)
- `cards[].sfx` 효과음 `{"name", "at": 카드 시작부터 초}`

## 장면 구성 (원본 찰떡파이 편 41컷 agy 판정: 실촬영 25 · 옛 광고/방송 9 · 생성형 실사풍 그림 7 · 실제 사진 0)
- 실촬영 영상·옛 광고/방송: `preset.py media yt` 로 받고 **agy 가 영상을 직접 보고** 줄마다 구간을 고른다. 고르기 지시에 **영상마다 길이(초)를 적고 «시작 < 길이-2»** 를 박는다(안 그러면 agy 가 길이를 넘는 시각을 고른다 — 10-08 실제 10곳)
- 생성형 재연 그림(화면 시간 약 20%, 원본 찰떡파이 20%·공장화재 18%): 실제 영상이 있을 수 없는 사건 장면(인물의 결정·다툼·도망·허탈)에 `preset.py aiimg` 로 실사풍 그림. 같은 인물은 같은 외모 문구 + 참고그림으로 2~4컷 이어 그린다. 생성 뒤 agy 가 글자·손·인물 일치를 본다
- 실제 사진(검색 사진)은 쓰지 않는다
- 효과음: 결정적인 줄(놀람·충돌·폭락·반전) 약 4줄에 1개

## 대본 (원본 5편 받아쓰기 기준)
- **문장이 끝나는 줄(음슴체 ~함·~음·~됨 등) 끝에 마침표를 찍는다** — 그래야 억양이 떨어지고 끊어 읽힌다. 화면 자막에선 지워짐
- 쉼은 `preset.py tts` 가 원본 실측값으로 맞춘다: 문장 끝 0.11초 · 그 밖 줄 경계 0.06초
- 약 330~360음절, 40~50초, 초당 8.0음절 (`target_syllables_per_sec`)
- 음슴체 반말: "~함", "~해버림", "~였음", "~인데", 끝은 "~있다고" / "~가더라"
- 흐름: 제목 낭독 → 배경(연도·숫자) → 갈등·빌런 → "이때 … 진짜 레전드인데" 반전 → 대비 → 결말 → 현재 상황
- 인터넷 말: 레전드·빡친·본좌·근본·찐·떡상. 사실은 출처로 확인

## 소리 (원본: 배경음악이 끝까지 깔림 + 영상 클립 자체 소리 + 편집 효과음)
- 내레이션: 문장 사이 쉼 0.08초, 속도 보정, −13 LUFS
- 클립 자체 소리: `preset.py media clip` 이 소리를 남긴다. 카드 media 에 `"audio": true` (음량 `audio_db`, 기본 `clip_db` −10dB)
- 효과음: 카드에 `"sfx": [{"name": "hit_2", "at": 0.1}]` — `assets/sfx/` 24개(hit 쿵·boing 띠용·pop 뿅·ding 띵·swoosh 휙·click 딸깍·fail·drum), 기본 `sfx_db` −4dB. 원본은 도장·법봉·돌·놀람 같은 결정적 장면에만 얹는다
- 배경음악: `bgm`(파일 경로, 비우면 없음) · `bgm_db`(기본 −18dB)
- 음량 기본값(−10/−4/−18dB)은 원본에서 잰 값이 아니다 — 귀로 맞출 것
- 소리 섞기는 렌더 때 ffmpeg 한 번 (`final_audio.wav`)
- 효과음 위치는 `"line": 줄번호`(0부터)로 적으면 음성을 다시 만들어도 그 줄이 나올 때 울린다

## 렌더가 멈추는 경우 (반쪽 파일은 남기지 않음)
- 소재 시작 초가 영상 길이를 넘을 때 / 한 컷에서 0.2초 넘게 한 색 빈 화면(흰 전환·검은 화면)이 나올 때 — 그 컷을 알려준다

## 알아둘 점
- 검색해 가져온 이미지·영상은 남의 저작물. 업로드 책임은 사용자에게 있음.
