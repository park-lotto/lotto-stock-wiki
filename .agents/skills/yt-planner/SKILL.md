# yt-planner — 씬 구성 & 기획서 작성

## 명령어

- `/기획` / "기획서 써줘" / "씬 짜줘"
- yt-content-research 완료 후 자동 진입

---

## 입력값 (yt-content-research 결과)

```
주제: {키워드}
각도: {패턴 + 훅 방향}
레퍼런스: {벤치마킹 영상 1개}
wiki 데이터: {있는 것 목록}
```

---

## STEP 1 — 이슈 타이밍 체크 ⚡

**가장 먼저 확인.** 이슈는 타이밍이 전부.

| 상태 | 기준 | 판단 |
|------|------|------|
| 🔴 지금 당장 | 이슈 발생 당일~다음날 | 오늘 업로드 필수 |
| 🟠 아직 살아있음 | 이슈 후 2~3일, 후속 재료 있음 | 내일까지 업로드 |
| 🟡 식어가는 중 | 이슈 후 4~7일, 검색량 감소 중 | 각도 변경 검토 |
| ⚫ 이미 식었음 | 일주일 이상, 후속 재료 없음 | 다른 소재로 변경 |

**판단 방법**:
```
WebSearch: "{주제} 주식 오늘" → 오늘 뉴스 있으면 살아있음
WebSearch: "{주제} 유튜브 방금" → 최신 영상 조회수 확인
```

⚫ 이미 식었으면 → yt-content-research 재실행, 이슈를 **다음 재료의 배경**으로만 쓰거나 폐기.

---

## STEP 2 — 제목 3개 작성

선택된 패턴 공식 적용:

| 패턴 | 공식 |
|------|------|
| 경고+기대 | "{기대감} 뜬다! 그런데 {경고}!??" |
| FOMO | "{숫자/비교} {대상}, 지금 안 사면 후회합니다" |
| 비밀 공개 | "아무도 모르는 {숨겨진 것}, {대상} 히든카드" |
| 속보 즉각성 | "방금 {이벤트} 끝났습니다. {행동} 하세요" |

**필수 요소 체크**:
- [ ] 숫자 포함 (조회수 +30% 효과)
- [ ] 시간 압박 단어 (지금 / 오늘 / 임박 / 방금)
- [ ] 행동 촉구 or 결론 암시
- [ ] 30자 이내

---

## STEP 3 — 씬 구조 (8분 기준)

```
씬1  훅        (0:00~0:25 / 25초)   → 레퍼런스 패턴 그대로 적용
씬2  공감       (0:25~1:10 / 45초)   → "나도 그래" 유발
씬3  선언       (1:10~1:45 / 35초)   → 해결책 한 줄 선언
씬4  데모/증명  (1:45~5:40 / ~4분)   → 실화면 + 실제 데이터
씬5  클라이맥스 (5:40~6:40 / 60초)   → 개념 전환 문장
씬6  자각       (6:40~7:20 / 40초)   → "이러면 시간/돈 절약"
씬7  여운       (7:20~7:50 / 30초)   → 다음 편 클릭 욕구
씬8  CTA        (7:50~8:20 / 30초)   → 댓글 키워드 + 서비스
```

**씬4 데모 화면 유형 결정**:
- 실화면 촬영 필요 → 체크리스트 작성
- Remotion 컴포넌트 → 기존 것 재사용 or 신규 파악
- 스크린샷/캡처 → 어떤 데이터 화면인지 명시
- wiki 데이터 시각화 → calc_oscillator.py 실행 필요 여부

---

## STEP 4 — 기획 검수 (9항목 / 7점 이상)

```
□ 제목에 숫자 + 시간압박 있는가?
□ 첫 10초 훅이 "나도 그래"를 유발하는가?
□ 씬 흐름이 공감→문제→해결→증명→CTA인가?
□ 핵심 메시지 1줄로 압축되는가?
□ 채널 방향(수급빈집/대장주/단기스윙)과 일치하는가?
□ 영상 길이 7~10분 범위인가?
□ 댓글/공유할 이유가 있는가?
□ 다음 편 궁금증이 심어지는가?
□ 경쟁 영상 대비 차별점이 명확한가?
```

7점 미만 → 각도 재검토.
