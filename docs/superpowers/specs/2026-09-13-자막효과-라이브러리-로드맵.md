# 자막·효과 라이브러리 로드맵 — 유료급 풀세트

작성 2026-09-13. 목표: 숏츠 제작 시 적재적소에 골라 쓰는 유료급 자막·효과 라이브러리.

## 왜 이 계획인가 (실측 근거)

- 실제 볼케이노 뇌전구 숏츠 1편 = **25~32컷 / 35~40초**, 컷마다 자막 1개, 밈 4~5개. (handoff/볼케이노* 실측)
- 그런데 지금 실제 자막 스타일은 **WHITE 나레 / RED PUNCH 2종만 반복**한다. → 단조롭다.
- 라이브러리의 목적: 이 단조로움을 **컷 성격에 맞는 다양성**으로 바꾼다.
- 릴리(by.Lily) 한 작가 팩만 **13에디션 139버전**(실측). 유료 마켓엔 이런 작가가 여럿 → 프로급은 수백 종이 정상.

## "계속 만들 수 있나?" — 답: 값만 바꿔 파생된다

컴포넌트 1개 = 스타일 1개가 아니라 **파생 틀**이다. props(색·문구·정렬·애니·아이콘)만 바꾸면 계열이 무한히 나온다.

| 컴포넌트 | 파생 축 | 1개당 파생 배수(보수적) |
|---|---|---|
| LilySub(프리셋 기반) | 프리셋 12종 × 강조 | 12+ |
| LilyDeco | 단어·색·애니 3종·외곽선 | 20+ |
| LilyNews | variant 5종 × 색 | 15+ |
| LilyHealing | variant 3 × 색·문구 | 10+ |
| LilyLower | variant 2 × 색·이름 | 12+ |

→ **컴포넌트 20개로도 이미 수백 종을 뽑을 능력**은 있다. 병목은 "만들 수 있나"가 아니라 **"어떤 걸 골라 대표 샘플로 등록하고 품질 검증하느냐"**다. 그래서 아래는 "무엇을 채우나"의 계획이다.

## 단계별 진행 순서 (우선순위 = 실제 사용 빈도)

1. **P1 — 실사용 즉시 (가장 자주 쓰는 것부터)**: 말하는자막 보강, 감정강조 보강, 로워서드 보강. 뇌전구·인물형·정보형 숏츠가 바로 다양해진다.
2. **P2 — 신규 필수 카테고리**: 타이틀/오프닝, 구독/CTA, 수치/카운트. 채널 완성도를 올린다.
3. **P3 — 밈·질문·전환**: 밈컷 보강, 질문/인터뷰(최대 갭), 전환자막.
4. **P4 — 테마·말풍선·나머지 색 변형**: 시즌 세트, 대화 연출, 각 에디션 잔여 변형.

## 지속 생산·품질 규칙 (매 배치 고정)

1. **원본을 눈으로 읽고 재현** — 샘플 이미지/영상 대조 없이 만들지 않는다. (memory: 디자인복제는_영상을읽혀라)
2. **검정 full-frame으로 원본과 1:1 대조** 후에만 "됐다".
3. **자막 y대역 PIL 실측** 후 크롭(추측 크롭 금지).
4. **브라우저 실측**(readyState·에러0)까지 봐야 완료.
5. **동시 렌더 금지**(포트·render_tmp 충돌) — 순차.
6. **main 폴더는 매 배치 복구**, 트랙에만 커밋(흡수 방지).
7. 카드에 **원본 출처(#에디션) + 카테고리** 표기 유지.

## 부록: 프로 숏츠 자막 배치 규칙 (2026-09-15 조사, 8건 검색 확인)

우리 구조("기본 스타일 1개 고정 + 특정 장면 효과 + 전체대사 자동/포인트 수동")가 한국 프로 편집 관행과 **정확히 일치**함을 확인.

### 배치 정석 (효과를 넣는 타이밍)
- **기본 자막**: 하단~중앙 고정, 흰/검 고대비 + 외곽선, 폰트 1종, 최대 2줄 — 상시. (일관성=브랜딩)
- **첫 3초 훅**: 상단 큰 두꺼운 폰트
- **감정 절정(놀람·반전·웃음)**: 팝단어·강조형
- **핵심 키워드·수치**: 색/크기 강조, 표시시간 연장
- **화자 표기**: 로워서드, 안전영역 위쪽

### 콘텐츠 유형별 효과 밀도
- 정보성: 절제·위계(제목>본문), 밈 남발 금지
- 예능성: 화려·리액션, 팝·밈 적극
- 감성 브이로그: 통일·최소, 절정에만 은은하게

### 자동화 가드레일 (필수 — 초보 실수 방지)
1. **안전영역 강제** — 쇼츠 하단 UI/댓글/해시태그에 안 가리게 (1순위 민원)
2. **줄수/글자수 상한** — 4줄 이상 금지, 한 줄도 짧게
3. **효과 발동 빈도 상한** — 강조 남발 = 강조 소멸
4. **고대비·최소크기 보장** — 외곽선/그림자, 최소 글자 크기
