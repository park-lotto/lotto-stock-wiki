> 사장님 설계(2026-08-17): *"처음에 영상을 추출할 때 이미 정보를 뽑잖아. 그럼 그때 뒤에서
> 물건템이면 쿠팡 상세랑 리뷰까지 추출하는 게 어떤가. 그럼 대본 뽑을 때 시간이 절약되잖아.

## 왜 이 구조인가 — 실측이 길을 정했다

**서버는 쿠팡을 못 긁는다.** 2026-08-17 직접 확인:

| 경로 | 결과 |
|---|---|
| 서버 직결 (AWS 서울 = **한국 IP**, `ipinfo.io/country` → KR) | **403** |
| 서버 + 독일 주거용 프록시 (기존 기록) | 403 |
| 사장님 PC + 헤드풀 Chrome | 200 |

한국 IP인데도 막힌다 → **IP가 아니라 브라우저 지문**을 본다. `product_facts.collect_raw`가
Playwright로 실제 Chrome 창을 띄우는 이유다. 그래서 **기존 릴레이**(사장님 PC가 서버에
롱폴링으로 일감을 물어가는 구조, `scripts/coupang_relay_client.py`)를 그대로 쓴다.

## 무엇을 만들었나

| 조각 | 파일 | 내용 |
|---|---|---|
| 안 기다리는 일감 | `coupang_relay.py` | `_Job`에 `kind`·`payload`·`on_done` + `submit_async()`. 기존 검색은 `kind` 기본값이 `search`라 **회귀 0** |
| 1단계 자동 큐잉 | `app.py` `_queue_product_prefetch` | 자동적재 끝에서 호출. **홈템·기타만**(레시피·뷰티 제외) |
| 릴레이가 수집·분석 | `scripts/coupang_relay_client.py` `handle_detail` | 검색 → 1위 상품 → 상세·리뷰 → 제미니 분석까지 **PC에서** 하고 결론 JSON만 전송 |
| 2단계가 사용 | `app.py` `_prefetched_facts_for_job` | job에 상품이 없으면 1단계 선수집분을 캐시에서 꺼낸다 |

### ★검색어를 어디서 얻나 — 3단계를 기다릴 필요가 없었다

지금까지 상품은 3단계 편집안의 `affiliate_target`에서 왔다. 그런데 **1단계 태깅이 이미
`source_brief.product`(이 영상이 파는 제품 이름)를 뽑고 있다**(`script_extract.py:92`).
그걸 검색어로 쓰면 1단계에서 바로 시작할 수 있다.

### 캐시 키

- `product_prefetch_<shortcode>` = `queued`|`done`|`empty` (같은 영상 두 번 안 긁는다)
- `product_facts_<shortcode>` = `{"facts": {...}, "product": {...}}`

## 이 작업에서 잡힌 진짜 버그 2건

1. **`app.py`에 `import json`이 아예 없었다.** `NameError`가 `except Exception`에 삼켜져
   **조용히 빈 값**이 나오고 있었다 — 테스트가 잡았다. 지금 추가함.
2. **릴레이가 윈도우 콘솔에서 시작하자마자 죽었다.** cp949가 안내문의 `—`를 못 찍어
   첫 `print`에서 `UnicodeEncodeError`(exit 1). 사장님이 켜도 똑같이 죽는 상태였다.
   → 출력 스트림을 UTF-8로 돌리고 못 찍는 글자는 `replace`. (특수문자를 빼는 건 답이 아니다
   — 상품명·리뷰에 어떤 글자가 올지 모른다)

## ⏭ 남은 것

1. **끝단 실측 미완** — 홈템 영상을 1단계에서 담아 큐잉→수집→2단계 재료 도착까지 한 번에 확인해야 한다.
   (서버 프로세스 내부 큐라 밖에서 일감을 못 넣는다 — 실제 담기로만 검증된다)
2. **릴레이가 켜져 있어야 한다.** 꺼져 있으면 큐에 남아 대기(아무것도 안 깨짐).
   토큰은 로컬 `.env`에 복사해 뒀다(`COUPANG_RELAY_TOKEN`, gitignore).
   실행: `py scripts/coupang_relay_client.py`
3. **고객이 쓸 때는 이 구조가 안 통한다** — 릴레이는 사장님 PC다. 고객 대상 서비스로 가려면
   한국 출구(주거용 프록시)나 다른 방법이 필요하다. 지금은 사장님 전용으로 둔다.
4. 2단계 화면에 "상품 재료 준비됨/받는 중" 표시 — 재료가 실제로 들어오는 걸 확인한 뒤에 붙인다.
