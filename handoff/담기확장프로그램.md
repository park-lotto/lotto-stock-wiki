처음엔 유저스크립트 로더처럼 **서버에서 로직을 받아 실행**하게 만들었다. 유튜브에서
📥가 아예 안 떴고, 원인을 세 번 잘못 짚었다. 실측으로 확인된 차단 벽:

| 시도 | 결과 |
|---|---|
| 페이지 월드 `<script src="우리도메인">` | ❌ 유튜브 CSP `script-src`에 우리 도메인 없음 |
| 페이지 월드 Blob URL `<script>` | ❌ 유튜브 CSP는 `blob:`도 차단 |
| 격리 월드에서 `eval(받아온 코드)` | ❌ **확장 CSP가 `unsafe-eval` 금지** |
| + 유튜브는 Trusted Types까지 켜져 있어 `script.src` 문자열 대입 자체가 차단 | |

→ **확장에 로직을 동봉하는 것이 크롬이 허용하는 유일한 길.**
   MV3 '원격 코드 금지' 정책과도 맞아 웹스토어 심사에도 유리하다.
   ⚠️ "격리 월드는 페이지 CSP를 안 탄다"는 맞지만, **확장 자신의 CSP가 eval을 막는다**.
   이걸 몰라서 한 바퀴 더 돌았다.

## 2026-08-17 (회사PC) — ★도우인 카드담기 안 되던 진짜 원인 = **확장 자신의 CSP** · world:"MAIN"으로 해결

### 증상
사장님: "도우인에 담기가 없어졌다. 샤오·틱톡·인스타는 버튼 있다."
우측 하단 플로팅 `📥 담기`만 있고 **카드별 버튼이 하나도 없음**. 재설치해도 그대로.
"잘되다가 왜 그러냐, 회사PC는 잘되던데."

### ★원인 (사장님 콘솔 실측으로 확정)
```
grab_logic.js:716 Executing inline script violates the following Content Security Policy
directive 'script-src 'self' 'wasm-unsafe-eval' 'inline-speculation-rules'
http://localhost:* http://127.0.0.1:* chrome-extension://9adf66a6-.../'.
The action has been blocked.        ← addDouyinCardBtns @ grab_logic.js:716
```
**막은 주체는 도우인이 아니라 확장 자신의 CSP다.** `localhost`·`chrome-extension:`이
소스로 들어간 CSP는 도우인이 보낼 수 없다 = 크롬 확장 기본 CSP(`unsafe-inline` 없음).

격리월드(콘텐츠 스크립트) 코드가 **스스로 만든 `<script>`**는 확장 CSP 검사를 받아 차단된다.
→ 메인월드 도달 실패 → fiber 못 읽음 → 카드버튼 0개
→ `syncFloat()`(grab_logic.js:500)이 "카드버튼 있으면 플로팅 숨김" 규칙이라 **플로팅만 남음**.

**도우인만 안 되는 이유**: 샤오·틱톡·인스타는 DOM만 써서 주입이 필요 없다.
도우인만 `<a href>`·`data-id`가 없어 React fiber를 읽어야 하고, 그래서 유일하게 주입을 쓴다.

**회사PC가 되던 이유**: 유저스크립트(텀퍼몽키) 경로는 확장 CSP를 안 타서 주입이 통과한다.
확장으로 옮긴 PC만 막힌다. (즉 코드는 한 줄도 안 바뀌었고 **설치 방식이 바뀐 것**이 원인)

### ⚠️조사 중 내가 틀린 것 2가지 (같은 함정 반복 금지)
1. **도우인 CSP `strict-dynamic`을 원인으로 지목했다 → 틀렸다.**
   헤더에 `strict-dynamic`이 있는 걸 보고 결과를 추측했다. 실제로 같은 페이지에서
   nonce 없는 인라인을 시험하니 **실행됐다**(`inlineRan: true`). 도우인 CSP는 무관.
2. **내 테스트가 조건을 다르게 만들었다.** 나는 코드를 `javascript_tool`로 **페이지 월드**에
   붙여넣어 20/20 성공을 봤다 — 페이지 월드는 확장 CSP를 안 탄다. 사장님 확장은 격리월드.
   **"한쪽은 되는데 한쪽은 안 된다"면 실행 환경이 같은지부터 확인할 것.**

### 해결 (커밋 이 세션)
`world: "MAIN"` 콘텐츠 스크립트 = **크롬이 직접** 메인월드에 넣어준다 → 확장 CSP의
인라인 검사를 **아예 타지 않는다**. MV3 정식 기능(Chrome 111+, 실측 환경 Chrome 151),
번들 동봉이라 원격코드 아님 = 웹스토어 심사 무관. 추가 권한도 필요 없다.
