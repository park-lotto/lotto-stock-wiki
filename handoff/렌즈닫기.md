# 렌즈 오버레이 ✕ 닫기 (인스타에서 안 닫힘)

**날짜**: 2026-09-22 · **트랙**: `렌즈닫기` · 커밋 `fea474e30`

## 무엇을
사장님 제보: 인스타 화면 안 「🔍 원본·유사 레퍼런스」 오버레이에서 ✕가 안 닫힌다.

## 원인 (`shopping_shorts/userscript/grab_logic.js` `_lensOverlay`)
✕ 버튼만 인라인 `onclick='…remove()'`에 기대고 있었다. 인스타 페이지 CSP('unsafe-inline' 없음)가
인라인 핸들러 실행을 막는다. 같은 오버레이의 「담기」는 `onclick='void(0)'` + addEventListener라 정상,
배경 클릭 닫기도 JS로 묶여 있어 그것만 됐다.

## 고침
✕에 `id='ss-lens-x'`를 주고 `_lensOverlay` 안에서 addEventListener로 묶음. `grab_logic.js`는 서버가
요청마다 파일에서 읽어 주므로(`app.py _serve_grab_logic`, max-age 60초) 배포 뒤 새로고침이면 반영.

## 검증(로컬, 실제 크로미움 + 인스타식 CSP `script-src 'nonce-…'`)
전: ✕ 클릭 뒤 오버레이 남음 · 콘솔 `Executing inline event handler violates … Content Security Policy` 1건
후: 닫힘 · CSP 오류 0건. 파일 내 다른 인라인 onclick 잔존 없음(grep).

## 기각한 가설
- 다른 요소가 ✕를 덮음 → 패널 position:relative, 겹치는 요소 없음
- 배경 클릭 핸들러가 이벤트를 삼킴 → `e.target === o` 검사만 함
