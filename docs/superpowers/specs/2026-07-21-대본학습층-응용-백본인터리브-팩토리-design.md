# 대본 학습층 — 응용: 백본-인터리브 + 차별화 엔진 + 팩토리 큐 (설계)

작성: 2026-07-21 (Opus 4.8) · 검토: 페이블 5 반영 · **분리 근거: 코어 스펙 A9**
전제 스펙(선행): `2026-07-21-대본학습층-부품은행-스파인라이브러리-design.md` (코어) — 부품은행+스파인이 이 응용의 토대.

> **착수 게이트(하드)**: **A7 스파이크 통과 필수** — 실제 잘된 영상 2~3세트로 행위단위 태깅 → 서브 풀이 앵커 행위를
> 얼마나 커버하는지 실측. 커버율이 낮으면 이 응용 전체의 전제(행위 스왑)가 흔들린다. 스파이크 산출물 = **F1 행위 액션 사전 v1 + 커버율 리포트**.
> **A8(화면 재사용 리스크)은 사장님 결정으로 수용됨** — 게이트에서 제거.

## 0. 목표

L2 능력(코어)만으로 **L3 데모락트에 저비용 근접** + **하루 수십 개 winner를 팩토리처럼 찍어내되 잘된 영상과 다를 바 없이.**
싱크 사다리(L1 무매칭 / L2 앵커싱크=코어 / L3 데모락트)는 코어 스펙 §8-1 참조.

## 1. 입력 계약

- **최소 2개**: **메인=백본**(구조·과정순서·싱크 앵커) / **서브 ≥1=같은 제품 풀**(b-roll + best-of-N 스왑용).
- 팩토리: 일일 랭킹 = 작업 큐. 사장님 동작 = **메인+서브 던지기 → 추천안 승인.** 나머지 자동.

## 2. 백본-인터리브 (D10 강화)

잘된 영상 1개를 백본으로 물려받아 **싱크를 "상속"**(백본 나레이션은 이미 백본 화면과 맞음).
1. 백본을 잘게 쪼개 **논리적 과정 순서를 스파인으로 고정**(재배열 금지).
2. **앵커 비트 = 백본은 순서·논리·싱크 앵커만**, 실제 화면은 §3 best-of-N.
3. **자유 비트·전환 = 서브 b-roll 삽입**(다양성·길이·중복회피).
4. **나레이션 = 백본 차용 후 코어 L2 변주** — 부품은행이 스타일만 바꾸고 각 비트 행위는 스파인에 고정(코어 D9).
- 레시피 동일: 단계 순서 유지, 같은 요리 b-roll 삽입, 결과물·앵커 컷은 같은 요리 소스(연속성).
- 배선: `edit_plan.build_scene_first_plan`에 **`backbone_source` 옵션** 추가(그 소스=원순서 스파인, 나머지 same-product=자유비트 insert/스왑 풀). 앵커/자유 분류(2트랙, 있음) 재사용.

## 3. 비트별 베스트 장면 (D13)

- 백본은 **스파인(비트·순서·싱크)만** 정하고, **각 비트 화면은 전 소스 풀(메인+서브들)에서 품질로 골라 채운다**(1번 순서 + 2·3번이 더 좋으면 스왑, 1+2+3 조합 가능).
- 배선: `build_scene_first_plan`의 `primary/alternates`를 **전 소스 풀에서 품질 랭크**하도록 확장(현재 fit + 신규 scene_quality 점수). 백본 클립 우선권 없음.
- 연속성: best-of-N 후보는 **같은 요리/제품 풀** 한정(D10 강화) + 조명·세팅 매칭(§4).
- 차별화 1층(화면 스왑)과 **동일 엔진** — best-of-N이 곧 화면 차별화를 겸함.
- **[A7 의존]** 행위 매칭은 F1 행위 액션 사전(통제어휘 `당기다·붓다·바르다…`) 위에서 돈다.

## 4. 차별화 엔진 (D11 — "독창성 품질 게이트")

> A6·A8 반영: 목적을 "탐지 회피"가 아니라 **독창성 품질**로 자리매김. 화면 재사용은 사장님 결정(리스크 수용)하에 진행.

- **1층 화면**: 앵커 행위를 풀(서브)의 같은 행위 클립으로 스왑(§3 best-of-N과 동일) + 풀에 없는 행위만 백본 클립 + **시각변형**(크롭·리프레임·속도램프·좌우반전·색보정·오버레이).
- **2층 나레이션**: ①화자 POV 전환(남편→아내→지인 선물→후기) ②훅 교체(후킹 은행) ③등장인물 스왑(스파인) ④비트 재분할 + 부품은행 골격 재조립.
- **3층 구조**: 과정 순서 고정, **진입만 변주**(결과-먼저 콜드오픈 ↔ 문제-먼저), 훅·CTA 프레이밍 교체.
- **차별화 게이트(측정·강제)** [A6]: `score = 화면중첩%(pHash 우선) + n-gram중첩 + 훅유사도 + POV동일 + 진입동일`. 임계 미달이면 변형 자동 증량. **임계 초기치는 스파이크로 실측**(지금 숫자 박지 말 것).
- **[F3] 자기중복 방지 — 변주 계열 관리**: 차별화는 원본 대비만이 아니라 **우리 영상끼리**도 봐야 한다. `pattern_source↔발행물` 매핑으로 **계열(series) 테이블**: 같은 백본/스파인 발행 이력 추적 → 다음 변주는 **미사용 POV·훅·진입 자동 배정**. 게이트에 "vs 우리 최근 발행물" 축 추가.
- **연속성(이질감 방지)**: 서브 클립을 조명·세팅 태그로 골라 끼우고 안 맞으면 색보정 통일(장면 인벤토리에 조명/세팅 태그 추가).

## 5. 팩토리 큐 (D12)

- **일일 랭킹 = 작업 큐**, 항목마다 **[만들기]** 버튼.
- **[F2] 소스 프리웜**: 랭킹 오른 순간 백그라운드로 다운로드·scene_cut·행위태깅·구조분석까지 → 클릭 시점엔 조립만. `daily_batch`/`discover_jobs` 패턴 재사용, 상위 N개만.
- **[F6] 잡 상태머신 + 아침 신호등**: `mix_jobs` 확장 — 단계별 상태·실패사유·자동재시도(상한). 대시보드에 완료(초록)/사람개입(노랑=게이트 탈락·빨간불)/실패(빨강). 사장님 아침 동선 = 노랑만.
- 부품은행이 미리 배워놔서 think-free. 처리량 병목 = 서브 풀 확보 + 연속성 매칭(최소 2개 계약이 흡수).

## 6. 폐루프 정밀화

- **[F7] 변주 계열 = 공짜 A/B**: F3 계열 데이터로 같은 제품·스파인·훅만 다른 발행물이 자연 A/B가 된다. 성과 회수 시 계열 내 비교 → 부품 perf_score를 상관이 아니라 **준실험**으로 갱신. 코어 Phase 3 폐루프에 병합.

## 8. 신규 vs 재활용

- **재활용**: `build_scene_first_plan`(backbone_source 옵션 추가), 2트랙 앵커/자유 분류, EDL·렌더, `mix_jobs`·`daily_batch`·`discover_jobs`, `outreach`(허가 소스 표시 선택).
- **신규**: backbone_source 배선, best-of-N scene_quality 랭크, F1 행위 액션 사전, 차별화 게이트(pHash+n-gram+POV/진입 유사도), F3 계열 테이블, F2 프리웜, F6 상태머신·신호등, F7 계열 A/B 회수.
