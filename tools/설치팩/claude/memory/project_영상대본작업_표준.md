사장님이 2026-08-19에 확정: **"영상제작 대본작업 하자"고 하면 즉흥으로 짜지 말고
`channel/strategy/영상제작_대본작업_표준.md` 를 열어 그대로 한다.** CLAUDE.md에도 트리거 박음.

**Why:** 숏템하우스 2편을 만들며 방향이 4번 바뀌었다(비교콘텐츠→1편업그레이드→녹화위주→7단계설득구조).
매번 대본을 다시 쓰느라 시간이 갔다. 다음 편부터 같은 왕복을 하지 않으려고 표준으로 고정한 것.

**How to apply:**
- 골격은 **설득구조 7단계**: 문제인식 → 일반해결책(★진짜로 다 알려준다=가치 선지급) → 한계 →
  방향(범주만) → **대안배제(승부처)** → 내 아이템 → CTA.
  1~5단계는 3분 안에 끊고 **6단계에 절반 이상**을 몰아준다. 페인은 짧고 구체적으로 치고 빠진다.
- **관통 키워드 하나**를 정해 3번 회수한다(2편은 "왕복": 3단계 문제→5단계 배제근거→6단계 해소).
- 산출물 3종 세트 + 바탕화면 복사. 직전 편 파일이 템플릿 원본.
  수정모드 html = contenteditable + localStorage + **수정본 뽑기**(바뀐 곳만 추출) + charset 필수.
  녹화콜시트 html = 타이머 + 구간 목표시간 + 랩타임 + `필수`컷 표시.
- **금지선(예외 없음)**: 금액 언급 · 결제내역 제작(위조) · 경쟁제품 화면·이름 · 가짜지표 · 미동의 후기.
  대안배제는 **지목 안 하고 구조만 지적**하는 쪽이 더 세다.
- 기능 자랑은 반드시 `git log --since=<직전편>`으로 실측(1편→2편 사이 1,138커밋이었다).
  기억·핸드오프로 쓰면 없는 기능을 자랑한다.
- 녹화는 화면 조작만(말 안 함), 음성은 사후 일레븐랩스 별도 → [[reference_local_tts_silent_mock_trap]]
- HTML은 **브라우저에서 실제로 열어 검증**. 2편 때 charset 누락으로 한글이 전부 깨진 걸 그렇게 발견했다.
- 썸네일이 먼저 있으면 **썸네일이 대본을 정한다**. 약속 회수표를 대본 상단에 박는다.
  썸네일에 실제 아닌 수치가 있으면 **영상 안에서 그 숫자를 주장하지 않는다.**
