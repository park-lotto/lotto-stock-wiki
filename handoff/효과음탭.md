# 효과음탭 — 3단계 효과음 조절(횟수·크기·소리 묶음·칸별) 사용자 선택 (관제 059, 2026-10-01 사장님 PC)

사장님: "영상대본믹스에서 효과음 탭을 구성하고 4개를 다 만들어서 구성해보자 사용자 선택"

## 주인 함수 · 결과물 검사 (0순위-C)
- 주인: `shopping_shorts/sfx_pack.py` — `settings_of(deco)`가 값의 뜻·허용 범위를 정하고, `resolve()`가 팩 dict에
  density/level/mute_beats를 실어 `events()`가 적용한다. 화면(produce.html)·설정 API(app.py)는 저장·표시만.
  렌더·미리보기·캡컷은 종전처럼 `_resolve_sfx_paths → sfx_events_for → sfx_pack.events` 한 길이라 손대지 않았다.
- 검사: `tools/sfx_bench/ui_check.py` ⑤(실브라우저: 네 값 저장·새로고침 유지·렌더 resolve가 같은 값) + `test_sfx_pack.py` 6건 추가.

## 값 (deco 안)
| 키 | 값 | 뜻 |
|---|---|---|
| sfx_density | low / normal / high | 적게=칸 첫 줄만 · 보통=자막 줄마다 1발(긴 줄 2발, 지금) · 많이=1.4초 넘는 줄도 2발 |
| sfx_level | low / normal / high | -3dB / 0 / +3dB (PACK_GAIN_DB 위에) |
| sfx_pack | off / auto / "7" | 끔 / 회원 배정(팩21_사장님) / 전체 팩 번호(list_packs 순서, 1부터) |
| sfx_mute_beats | [beat_idx…] | 이 칸은 효과음 없음(사람이 고른 효과음은 그대로) |

## 한 것
- sfx_pack: `settings_of`·`pack_label`·`DENSITY_MAX_SILENCE`·`LEVEL_DB`, `plan_events(density=)`, `events()`가 level·mute 적용.
- app.py: `/api/produce/mix/settings`가 네 값 저장(모르는 값→보통, 바뀌면 미리보기 폐기, 통째 저장 시 보존) ·
  `/api/produce/mix/sfx_pack/{job}`에 packs·pack_no·density·level·mute_beats·beats(칸별 타점 수)·timeline_ready ·
  `/api/produce/sfx_pack/sound/{no}/{slot}` 미리듣기 wav.
- produce.html: 3단계 효과음 바 → 「⚙ 효과음 조절」 탭(횟수 3단·크기 3단·소리 묶음 select+▶7개·칸별 체크).
- 캡처: ui_check `sfx_tab.png`. 테스트 47건 통과(효과음 관련 5파일).
