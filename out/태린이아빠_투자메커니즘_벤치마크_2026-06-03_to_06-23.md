## 2. 핵심 데이터 7종 — "매일 같은 7개 지표" (★벤치마크 핵심)

태린이아빠가 **매일 빠짐없이** 재측정하는 데이터. 각각의 용도가 명확히 분리돼 있다.

| # | 데이터 | 정체 | 무엇을 판단하나 | 해석 규칙 |
|---|--------|------|----------------|----------|
| **1** | **피어앤그리드 오실레이터** (한·미, 자작) | 시장 과열/과매도 수급 지표 | **현금비중 타이밍** | 과열권→현금 확보 / 과매도권→재매수 / "과매도 후 과매수 = 손바뀜 = 새 지지선" |
| **2** | **소라티노(Sortino) 순위** | 변동성조정 모멘텀, ETF·섹터 단위 | **주도업종 판별** | 10주선·20일선·10일선 **3구간 동시 상위**여야 진짜 주도 |
| **3** | **상대강도(RS)** | 절대·상대 강도 순위 | 주도업종 보강 | **RS 70 이상**만 생존 섹터로 인정 |
| **4** | **투자자별 수급** | 사모·투신·연금 × 시총대비/금액대비 | **주도업종 자금 확인** | 3주체 **공통 매수 섹터 = 교집합**이 진짜 주도 |
| **5** | **52주(250일) 신고가 리스트** | 국내·미국·일본 | **매수 후보 1차 필터** | "**오랜만에 군집 신고가 = 들이대는 시점**" |
| **6** | **거래대금 강도 오실레이터** | 종목별 거래대금 위치 | **진입/이탈 타이밍** | **하단 = 매수 적기 / 상단 = 과열 매도** |
| **7** | **컨센서스/추정이익** | EPS·매출·목표가 상·하향 | **펀더멘털 검증** | "**27년 추정이익 상향 = 찐(진짜 재료)**", 목표가 하향은 경계 |

**보조 지표** (필요할 때만):
- **수출데이터** — 매월 **1·11·21일 발표(확정 15일)**. "기둥이 아니라 보조 확률 보강용". RS·모멘텀 강한 섹터에서만 품목별 판가/물량 확인.
- **업종쏠림지수** — 극단→반등 / 하락구간 = "대충 사도 먹는, 매매 편한 시장"
- **이격도** (30일 vs 247거래일 퍼센타일, 자작 코드) — 과열 룸 점검
- **수급 빈집** (수급 오실레이터) — 자금이 빠져나가 비어있는 종목 = 선점 대상

> **벤치마크 포인트 ②**: 지표가 7개뿐이고 **역할이 안 겹친다**. 오실레이터=현금타이밍 / 소라티노=주도업종 / 신고가=종목후보 / 컨센=펀더검증. 우리도 "지표 백화점" 대신 **역할별 1개씩** 골라야 한다. (우리 자산: 오실레이터.xlsm·유동성.xlsm·수급빈집 → 이미 비슷한 무기를 갖고 있음)

## 3. 의사결정 3대 공식 (★그대로 복제 가능)

### 공식 A — 주도업종 확정 (Triangulation)
```
소라티노(10주·20일·10일 동시 상위)
   ∩ 투자자별 수급(사모·투신·연금 공통 매수)
   ∩ "조정 후 가장 먼저 신고가 간 섹터"
= 1티어 주도업종
```
- 한 지표 단독으로 안 믿는다. **3개가 겹치는 것만** 채택 → 매일 저녁(슬롯④)에 "교집합" 멘트로 결론.
- 기간 전체 결론: **반도체가 압도적 1티어**(18일 내내). 2티어 = 피지컬AI·전력(변압기/ESS)·네트워크(광통신·삼성전기). 후순위로 은행·조선이 6월 중순 신규 진입.

### 공식 B — 종목 매수 트리거
```
52주(250일) 신고가
   ∩ 주도업종
   ∩ 수급 빈집(국장) / 거래대금 강도 하단(미장)
   ∩ 컨센 상향(추정이익 신고가)
= 신규 매수/교체
```
- **신규 발굴이 아니라 "교체"가 기본 단위**. (예: 네패스아크→LS일렉, 한솔아이원스→현대오토에버, 샌디스크→엔테그리스)
- 비중 규칙: **한 종목 4~5%(최대 10%), 동일비중 ~20종목**. 단 전닉(삼성전자·SK하이닉스)은 시총비중이 커서 보유비중을 시총비중에 맞춰 고비중 허용.

### 공식 C — 매도 5규칙 (22:49, 6/18 명문화)
```
① 10일선 이탈 → 정리 (특히 오실레이터 과열이 꺾일 때)
② 주봉 신고가 후 음봉 → 정리
③ 거래대금 강도 충분히 상승(과열) → 정리
④ 오실레이터 과매도권에선 10일선 깨도 보유 (예외)
⑤ 최고가 대비 -2.5 ATR → 비중 절반 축소, 10일선 이탈 시 잔량 정리
```

### 공식 D — 현금비중 = 오실레이터의 함수
```
피어앤그리드 과열 → 꺾임 확인 → 단계적 현금 확보
   코스닥 10일선 이탈 → 현금 15~20%
   코스피 10일선 이탈 → 현금 30%
   MDD -15% → 분할 재매수 시작 (상승장에선 -15%가 공격 구간)
   오실레이터 바닥 + 3일선 회복 → 현금 소진(풀비중)
```
- **실측 사례 (6/23)**: 코스닥·코스피 동반 10일선 이탈 → 하루 만에 현금 **15%→56%**로 계단식 확대(20%→37%→42%→52%→56%). "고점대비 -10% 이내만 관리 가능"이 멘탈 기준선.
- **반대 사례 (6/8→6/13)**: 서킷브레이커(MDD-15%) 급락 → 현금 30% 방어 → 오실레이터 반등+이벤트 소멸 확인 → **풀비중 100% 복귀**. 규칙이 양방향으로 일관 작동.

> **벤치마크 포인트 ③**: 핵심 철학 = **"종목 연구보다 도망치는 로직(현금 조절) + 주도업종 압축이 우선"**. "위기엔 가장 센 것(반도체)으로 도망친다 + 현금". 매수보다 **매도·현금 규칙이 훨씬 정교**하다.

## 4. 시장을 보는 사고체계 (해석 프레임)

1. **미장 먼저, 국장은 미장의 그림자** — 매일 새벽 미국 소라티노/신고가로 글로벌 주도업종을 먼저 확정하고, "그 중 한국에 영향 줄 섹터"로 국장 주도업종을 역산.
2. **피어(peer) 선행 추적** — 일본 Taiyo Yuden·TEL, 네덜란드 BESI, 미국 마이크론의 신고가/실적을 **국내 삼성전기·한미반도체·전닉의 선행 신호**로 사용.
3. **뉴스 → 밸류체인 나비효과 연역** — 어떤 테크 뉴스든(인텔 18A, 퀄컴 40개 설계, 딥시크 MoE) "→ 메모리/D램 전공정 장비 수요 증가"로 인과 체인 연결. (제미나이·GPT를 1차 해석기로 활용)
4. **이벤트 캘린더 관리** — 매일 "내일 일정"(수출데이터·선옵만기·실적·물가·IPO) 명시 → "우려 이벤트 하나씩 소멸 = 주도업종 부각" 시나리오로 연결.
5. **순환매 대응** — 오실레이터 변곡 근방의 순환매는 잦고 연속성 낮음 → 과열권 순환매는 비동참, 바닥에서 올라오는 순환매만 동참.
6. **선행 로테이션 사고** — "반도체 강하면 소비재 약세"(자작 연구). 7월 DRAM 판가 YoY 둔화 시 자금이 소비재(라면·화장품)·방산으로 이동할 가능성을 미리 셋팅.
7. **자가 벤치마킹** — 본인 수익률을 코스피·코덱스모멘텀·타임폴리오 ETF와 비교. 졌으면 반성하고 다음 편입 후보로 학습("감이 아닌 데이터로 극복").

## 6. 운영자(로또의 주식) 벤치마킹 액션 — "내가 따라하려면"

### 즉시 복제 가능 (우리가 이미 가진 무기)
- ✅ **오실레이터.xlsm** → 태린이의 "피어앤그리드 오실레이터" 역할 (현금비중 타이밍)
- ✅ **수급빈집 데이터** → "수급 오실레이터(빈집)" 역할 (종목 선점)
- ✅ **태린이 파일 13개 파서 + 업종오실레이터** → 소라티노·RS·투자자별 수급·컨센 이미 파싱 중
- ✅ **daily_scenario.py / 카드뉴스** → 슬롯①(장전)·슬롯④(저녁) 고정 발신 포맷에 대응

### 따라할 루틴 설계
1. **고정 2슬롯 발신**: 아침 브리핑(06~07시) = 미장복기+오실레이터+주도업종 / 저녁 정리(18~19시) = 투자자별 수급 교집합 → 주도업종 1티어 발표.
2. **주도업종은 Triangulation으로만 확정**: 소라티노 3구간 ∩ 사모/투신/연금 공통 ∩ "먼저 신고가 간 섹터". 단일 지표 콜 금지.
3. **종목은 발굴이 아니라 교체 테이블로**: 52주신고가 ∩ 주도업종 ∩ 수급빈집 ∩ 컨센상향 → 과열 종목과 1:1 교체.
