> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 유튜브 레퍼런스 랭킹에서 연예·이슈 클립을 걷어내고 살림·제품 소재만 남긴다.

**Tech Stack:** Python 3 / FastAPI / SQLite (`shopping_shorts/store.py`) / 순수 JS 프론트(`shopping_shorts/static/index.html`) / pytest

```python
"""채널별 '쇼핑 소재 적합도' 계산 (2026-07-29).

왜: 유튜브 랭킹에 연예·이슈 클립 채널이 섞여 들어와 짜깁기 쇼핑쇼츠 소재를 못 찾는다.
실측(2026-07-29): 채널 715개 중 285개는 홈템·레시피·가전만 내고, 164개는 전부 '기타'.
사람이 지울 채널을 고를 수 있게 이 비율을 관리 보드에 보여준다.

뷰티를 분자에서 뺀 이유: 메이크업 실촬영은 짜깁기 소재로 쓰지 않는다(설계 확정).
"""

GOOD_CATEGORIES = {"홈템", "레시피", "가전"}


def channel_fitness(items):
    """랭킹 items → {채널명: {total, good, other, fitness}}.

    items는 last_run 캐시의 항목 형식(name/username/category 키를 가짐)을 그대로 받는다.
    """
    acc = {}
    for it in items:
        ch = it.get("name") or it.get("username") or "?"
        cat = it.get("category")
        row = acc.setdefault(ch, {"total": 0, "good": 0, "other": 0})
        row["total"] += 1
        if cat in GOOD_CATEGORIES:
            row["good"] += 1
        if cat == "기타":
            row["other"] += 1
    for row in acc.values():
        row["fitness"] = row["good"] / row["total"] if row["total"] else 0.0
    return acc
```

async function purgeLowFitness(rows){
  const targets = rows.filter(r => (r.fitness||0) === 0 && (r.total||0) >= 3);
  if(!targets.length){ alert('적합도 0%인 채널이 없습니다.'); return; }
  const names = targets.slice(0,10).map(r=>r.channel).join(', ');
  if(!confirm(`적합도 0% 채널 ${targets.length}개를 등록목록에서 지웁니다.\n예: ${names}${targets.length>10?' …':''}\n\n계속할까요?`)) return;
  let done=0;
  for(const r of targets){
    if(!r.seed_url) continue;   // 시드로 등록돼 있지 않은 채널은 지울 게 없다
    await fetch('/api/seeds',{method:'DELETE',headers:{'Content-Type':'application/json'},
      body:JSON.stringify({platform:'youtube', value:r.seed_url})});
    done++;
  }

## Task 5: 누락된 좋은 채널 등록 (T4보다 먼저 켤 것)

**Files:**

**Interfaces:**

- Produces: 없음 (1회성 운영 스크립트)

**왜 필요한가:** 랭킹에 등장하는 채널은 715개인데 시드에 등록된 건 464개뿐이다. 적합도 높은 미등록 채널을 먼저 넣지 않고 키워드 경로를 끄면 **수집량이 급감한다.**

- [ ] **Step 1: 스크립트 작성**

```python
"""적합도 높은 미등록 유튜브 채널을 시드로 등록한다 (1회성, 2026-07-29).

★ seed_only 플래그를 켜기 '전에' 반드시 먼저 돌려야 한다.
안 그러면 키워드로만 잡히던 좋은 채널들이 통째로 빠져 수집량이 급감한다.

사용: python -m scripts.register_good_youtube_channels [--dry-run]
"""
import sys
from shopping_shorts.store import Store
from shopping_shorts.config import DB_PATH
from shopping_shorts.channel_fitness import channel_fitness

MIN_FITNESS = 1.0    # 100%짜리만 자동 등록한다(애매한 건 사람이 본다)
MIN_TOTAL = 3        # 표본 3건 이상


def main(dry_run=False):
    store = Store(DB_PATH)
    cached = store.load_last_run_platform("youtube") or {}
    items = cached.get("items") or []
    if not items:
        print("[중단] 캐시가 비어 있다. 수집이 먼저 돌아야 한다.")
        return 1

    registered = {s["value"] for s in store.list_seeds("youtube")}
    # 채널 URL은 items의 channel_id에서 만든다. 없으면 등록할 수 없다.
    url_by_channel = {}
    for it in items:
        ch = it.get("name") or it.get("username") or "?"
        cid = it.get("channel_id")
        if cid and ch not in url_by_channel:
            url_by_channel[ch] = f"https://www.youtube.com/channel/{cid}"

    fit = channel_fitness(items)
    added = skipped_no_id = 0
    for ch, f in sorted(fit.items(), key=lambda kv: -kv[1]["total"]):
        if f["fitness"] < MIN_FITNESS or f["total"] < MIN_TOTAL:
            continue
        url = url_by_channel.get(ch)
        if not url:
            skipped_no_id += 1
            continue
        if url in registered:
            continue
        print(f"{'[dry]' if dry_run else '[등록]'} {ch}  적합도100%  영상{f['total']}건  {url}")
        if not dry_run:
            store.add_seed("youtube", "account", url)
        added += 1

    print(f"\n등록 {added}개 / 채널ID 없어 건너뜀 {skipped_no_id}개 / 기존 시드 {len(registered)}개")
    return 0


if __name__ == "__main__":
    sys.exit(main(dry_run="--dry-run" in sys.argv))
```
