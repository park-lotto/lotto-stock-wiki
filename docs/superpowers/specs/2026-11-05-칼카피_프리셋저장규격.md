## 1. 원칙

1. **정본은 JSON, 한 사실은 한 곳.** `frame.json`(틀)·`manifest.json`(그 밖 전부)·`defaults.json`. md 는 생성물(`manifest_sha`). 새 정본 파일을 만들지 않는다 — 고정/편마다는 `manifest.variables`·`variable_stats`(주인 `preset_save.merge`), 머리표는 `manifest` 에 칸 추가.
2. **frame.json 값 구조는 바꾸지 않는다.** 렌더·`per_video`·`preview_request.preset_defaults`·`preset_brief` 가 평평한 값을 읽는다. 출처는 `manifest.provenance[자리] = {src, how}`.
3. **출처 꼬리표는 도구가 적는다**(사람이 적으면 참인지 못 잰다): `preset_save`→실측 · `fix_value(why)`→손 · `fill_defaults`→기본값 · 글꼴 판별 점수 < 0.5 →미확인.
4. **바꾸기는 version + history.** `fix_value` 는 why·who 를 history 에 자동으로 적는다. 확정(`frozen_at`) 뒤에는 version 을 올리지 않는 변경과 why 없는 변경을 `preset_save` 가 거절한다(J81 의 진짜 막 = "누가 시켰나"). 폴더는 그대로, 판은 배포 zip 이름에만(`<이름>_v2.zip`).
5. **모르는 칸·없는 자산은 멈춘다.** 엔진이 모르는 키, 창고에 없는 글꼴, 키 없음 → 실패. 대체는 사람이 고르고 history 에 기록(J17·J78).
6. **형식만 복제.** 벤치 채널명·실제 제목 문구·로고·징글·영상·대사는 넣지 않는다(J10). 검사가 채널명 문자열을 frame·defaults 에서 찾는다.
7. **공통 것은 엔진 한 곳을 부른다.** 글꼴 = `fontmatch` 창고 · 금지 파일·글자 = `engine_bundle.forbidden/SECRETS`·`benchmark_pack.check` · 판독·대조 지시문 = 서버 지시서(`hybrid/flow_bench.py`) — 프리셋엔 id 만.
8. **1판은 숏폼 전용.** 롱폼은 §6.

## 2. 폴더 구성 (★ 필수 · ◇ 조건부 필수 · ○ 선택)

```
channel/<slug>/preset/<스타일>/       ← 경로 그대로(참조하는 곳이 많다). 판은 manifest.version
  frame.json        ★ 틀(평평한 값 — 지금 그대로)
  manifest.json     ★ 그 밖 전부. 지금 칸 + 2판에서 더하는 칸:
                       version · format("숏폼") · engine(엔진 판) · frozen_at
                       fonts: [{name, sha256, license, in_store}]   ← 파일은 창고, 여기엔 목록
                       required_assets · secrets_from: ["env:TYPECAST_API_KEY", "~/.volcano/keys/typecast"]
                       provenance{자리:{src,how}} · history[{v, when, who, why, changed}]
                       confidence("low" = 벤치 n<3) · accepted_unknown[{path, who, when}]
                       checks{validate:{…}, final:{…}}  ← 수치: 색±·좌표±·LUFS±·길이± (공통 실행기가 읽음)
                       reference{final_sha256, sheet}   ← 기준 완성본(이 프리셋 합격본)
  defaults.json     ★ 편마다 기본값 + _from(근거 파일:줄) — 지금 그대로
  sources/<편>.json ★ 벤치 편마다 잰 **수치·좌표만** (남의 자막 글·대사 원문은 넣지 않는다 — 1판 모순 해소)
  job.template.json ★ 편마다 넣을 입력 꼴(소재·제목·대사·--set)
  requirements.txt  ★ 파이썬 꾸러미 판 고정(엔진 공통이면 엔진 판 한 줄)
  reference/        ★ 기준 완성본 프레임 시트 jpg · 벤치 측정 json (영상 파일 자체는 넣지 않는다 — 저작권)
  tests/            ◇ 잡도리가 있으면 필수 — 잡도리마다 test_id 하나(오프라인)
  잡도리.md         ◇ 우리 보관본에만(원문 전부·test_id). 회원 묶음엔 '바뀐 규칙' 줄만(반출 금지)
  assets/fonts/     ◇ 창고에 없는 글꼴만 + LICENSE. 시스템 글꼴(맑은 고딕 등)은 넣지 말고 doctor 실패
  assets/{sfx,bgm,logo}/ ○ 우리 브랜드만
  SHA256.json       ★ 폴더 전체 파일 해시(생성) — 손댄 파일 잡기
  ── 생성물(손으로 쓰지 않음, manifest_sha 표식) ──
  프리셋.md         ★ 고정/편마다·출처·필요 자산·history 요약
  CLAUDE.md         ★ 이 프리셋으로 만들 때 지킬 것(강의 '냉장고 메모')
  README.md         ○ (프리셋.md 한 절로 대신 가능)
  changelog.md      ○ v2 부터, history 에서 생성
```

넣지 않는 것: 받은 원본 영상·중간 렌더·캐시 · 키(.env) · 남의 영상·대사·자막 원문 · 벤치 로고·징글 · **내 PC 절대경로**(회원 2226 SHA256SUMS 에 맥 경로가 샌 실제 사례).

## 3. 저장 절차 (강의 4-1~4-6 + 회원 잡도리)

| 단계 | 하는 일 | 끝났다의 기준(검사로) |
|---|---|---|
| S1 칼카피 1편 | 연습장에서 벤치 1편을 따라 만든다 | 결과 영상 |
| S2 잡도리 | 벤치와 나란히 대조하며 고친다. 다그친 원문은 바로 잡도리.md 에(test_id 칸 비워 둠) | 대조 표 |
| S3 고정/편마다 | 벤치 편을 같은 자로 재서 `preset_save.merge` (n<3 이면 confidence: low) | manifest.variables·variable_stats |
| S4 정본 쓰기 | frame·manifest·defaults — 꼬리표는 도구가 | 미확인 칸 = 0 또는 accepted_unknown |
| S5 관문 굳히기 | checks(validate·final) 수치, 잡도리마다 test_id 시험 | 시험 통과 · 잡도리마다 test_id 있음 |
| S6 다른 소재 재현 | 연습에 안 쓴 소재 1편으로 만들어 벤치와 대조 | checks.final 수치 합격 + 벤치 상위 10편 중앙값 이상 |
| S7 생성·묶기 | 프리셋.md·CLAUDE.md·SHA256.json 생성 → zip(같은 내용 = 같은 zip) | manifest_sha·SHA256 일치 |

## 6. 열린 것

- 회원 PC 프리셋 묶음(benchmark_pack)과 이 규격을 같은 꼴로 맞추는 순서.
