뉴스 기사 단독으로 종목 판단 금지. 수혜 재료가 있더라도 반드시 아래 4가지 교차 확인.

1. **악재 검토** — 내부 리스크, 부채, 소송, 임상 실패, 경영진 이슈 등
2. **주가 실제 반응** — 재료 발표 후 주가가 실제로 어떻게 움직였나 (선반영·무반응·역반응)
3. **날짜 필터** — 현시점 날짜와 맞지 않는 데이터 무조건 제외
4. **재료 강도** — "수혜 예상" vs "직접 투자 확정" 레벨 구분 필수

**Why:** 표면 기사만 보면 좋아 보이는 종목도 내부 악재나 선반영으로 실제 주가와 괴리. 시청자에게 잘못된 판단 유도 방지.

**How to apply:** 종목 분석 시 긍정 재료와 동시에 반드시 부정 요인 검색. "XX 악재", "XX 주가 하락 이유", "XX 리스크" 별도 검색.
