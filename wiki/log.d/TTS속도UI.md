# TTS속도UI

- 장면 편집 멘트 칸에 선택 시만 보이는 음성·장면 통합 속도(0.8~1.4×)를 추가했다.
- `sync_speed`를 미리보기·TTS·최종 렌더·캡컷의 공용 값으로 연결하고, 여운으로 배속이 풀리던 최종 렌더 오류와 캡컷 이중 가속을 막았다.
- 최신 main의 구절 맞춤·수동 컷·미리보기 합본을 보존해 통합했고, 실제 UI 확인·FFmpeg 프레임 검사·관련 테스트 127개를 통과했다.
- 배포 전체검사에서 발견된 단독 JS 실행 의존성과 미지정 TTS 속도 주입을 제거하고 관련 회귀 검사 15개를 재통과했다.
- 라이브 작업 `fdbdf33c16cb`에서 기본 음성 1.6이 상대배속 계산에서 빠져 1.4×가 절대 1.4로 느려진 것을 확인했다. 실제 기본 음성을 기준으로 곱하고 잘못 저장된 첫 배포 값도 복구하도록 수정했다.
- 라이브 작업 `616ee19b6187`에서 배속을 왕복할 때마다 TTS를 재합성해 억양이 달라진 원인을 제거했다. 기준 음성을 고정하고 배속본만 파생해 1.0× 복귀 시 원음이 정확히 돌아오게 했다.
- 자막제거 완성본 조각을 캡컷으로 보낼 때 MIX 배속이 `1.0×`로 사라지던 경로를 수정했다. 조각을 역변환한 뒤 캡컷 speed material에 원래 0.8~1.4×를 기록해 결과 길이와 편집 가능성을 함께 보존한다.
