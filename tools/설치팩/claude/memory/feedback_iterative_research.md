데이터 수집은 한 번으로 끝내지 않는다. 답변이 나오면 그 답변에서 새로운 질문을 뽑아서 더 깊이 파고든다.

**Why:** 오늘 세션에서 이 원칙이 반복 확인됨:
- 젠슨황 방한 → 왜 오냐 → 피지컬 AI → 수혜주는 → LG CNS·현대오토에버 → 왜 못 잡았냐 → 데이터 없어서
- 삼성전기 후발주 → 심텍·대덕 → 삼화콘덴서 왜 빠졌냐 → 갭 플레이 몰랐음 → 2배 급등 사례
- CPU 부각 → 왜 → 에이전틱 AI → 추론 시대 → 오픈엣지 → 더 파야 함

매번 답변 후 "그렇다면 더 깊이 파야 할 것"이 드러남.

**How to apply:**
1. 제미나이 Q10 구조 자체가 꼬리 물기 방식. Q1 답변이 Q2 방향을 결정.
2. 답변에서 "아직 모르는 것"이 나오면 그게 다음 질문이 된다.
3. 한 사이클이 끝나면 "이 답변에서 더 파야 할 게 있는가?" 반드시 체크.
4. 위키에 쌓인 데이터도 "이 데이터가 연결 안 된 게 있는가?"로 계속 확장.

**구체적 발전 방향:**
- Q10 이후 Q11~Q15로 계속 확장 가능 (각 답변이 새 Q 생성)
- 예: Q10 꼬리체인 → Q11 갭 플레이 패턴 → Q12 추론 AI 수혜 → Q13 CPU 관련주...
- 섹터 연구가 끝나는 게 아니라 계속 깊어지는 구조

**가장 중요한 원칙:**
"답변이 나왔으면 그게 끝이 아니다. 그 답변에서 무엇을 더 알아야 하는지를 찾는 것이 진짜 작업이다."
