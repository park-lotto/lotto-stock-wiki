### ⚠️ 이번에 밟은 함정 (다음에 반복 금지)
- **심볼릭 링크로 오버레이 만들지 마라.** `ln -s` 후 `cp -f`가 링크를 따라가
  **라이브 서버 파일을 오염**시켰다(`M instagram_playwright.py`). 즉시
  `git checkout --`로 되돌렸지만, 방치했으면 `auto_deploy.sh`가 pull 실패로
  **전 서비스 배포가 조용히 멈춘다**(CLAUDE.md 9번 사고와 동일).
- **PYTHONPATH 오버레이는 설치본에 밀린다.** `__file__`을 찍어 어느 파일이 실제로
  로드됐는지 **매번 확인**할 것 — 안 하면 "라이브인데 성공했다"는 가짜 green이 난다
  (이번에 실제로 두 번 속았다).
- `finish` 게이트는 **pytest rc=2로 스킵**됐다(기존 이슈). 게이트 통과 ≠ 테스트 통과 —
  직접 실측으로 검증할 것.
