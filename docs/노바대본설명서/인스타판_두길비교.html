  2. 숏템 클로드형: 같은 지침서·같은 근거를 Claude가 쓴다(클로드 코드 작업 흐름). 버텍스 Claude는 이 프로젝트 사용 한도 0(429) — 숏템메이커 안에서 Claude로 쓰려면 GCP 콘솔에서 한도 신청 필요
