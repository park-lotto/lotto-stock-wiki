# 댓글효과

## 목적

숏템메이커 장면꾸미기에 편집 가능한 댓글 카드 효과 2종을 추가했다.

## 구현

- `shopping_shorts/comment_card.py`: `dark_social`, `premium_pop` 투명 PNG 렌더, 한글 단어 줄바꿈, 프로필 폴백, 버전 캐시.
- `shopping_shorts/app.py`: 스타일 목록, 미리보기 PNG, 작업별 프로필 사진 업로드 API.
- `shopping_shorts/mix_pipeline.py`: `deco.comment_card` 정규화와 동적 PNG 생성.
- `shopping_shorts/video_assemble.py`: 기존 모션 레이어 배관으로 아래 등장·감속·페이드 입출력. 무한 이미지 입력은 `shortest=1`로 원본 영상 길이에서 종료.
- `shopping_shorts/static/produce.html`: `장면꾸미기 > 효과 > 댓글 카드`, 스타일 2종, 작성자·시간·댓글·좋아요·시작·길이·크기, 사진 업로드, 드래그, 삭제, 저장·복원.

## 검증

- 전용·관련 테스트 29개 통과.
- Playwright 실제 화면에서 두 스타일 선택, 서버 PNG 미리보기, 드래그(`x=62`, `y=66.9`), 삭제, 재선택 확인.
- 1080×1920 5초 MP4를 두 스타일로 실제 합성. 등장 전·중·고정 프레임 육안 검수.
- ffprobe: 출력 video 1080×1920 + audio 스트림 확인.

## 주의·다음

- 실제 YouTube API 댓글 수집과 댓글 여러 개 순환은 1차 범위에서 제외했다.
- 새 `댓글효과` 트랙 생성이 `.git` 쓰기 권한으로 막혀 깨끗한 기존 `장면꾸미기재편` 트랙을 사용했다.
- 현재 권한 정책에서 `.git` 작성이 막혀 커밋·`track.py finish`는 하지 못했다. 파일은 트랙 폴더에 보존되어 있다.
