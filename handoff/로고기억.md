# 로고기억 — 장면꾸미기 로고 자동 최종기억 (관제 131)

2026-10-05 · PC CH · 사장님 "장면꾸미기에 로고 넣는 것 자동 최종기억으로, 프리셋 등록도 마찬가지"

## 착수 전 두 줄 (0순위-C)
- 주인 함수: `out/precision20-ui.js` 로고 기억 블록(`rememberedLogo`·`rememberLogo`·`noteLogo`·`freshEffects`) 한 곳. 꾸밈 패널·연결부는 이걸 부르기만 한다.
- 결과물 검사: `tools/scene_font_research/check_logo_memory.py` — 제작소처럼 iframe 으로 편집기를 열어 ①~⑦, 그 스냅샷 그대로 서버 검증→렌더·캡컷 레이어→썸네일 한 장→최종 합성 mp4(⑧).

## 왜 (라이브 실측 10-05)
- 로고 든 작업 4건 전부 **전 장면·같은 자리**. 고객 412는 작업 3건(10-04~05)마다 같은 로고를 손으로 다시 넣었다(자리 2,2 / 2,2 / 1,2).
- 고치기 전: 새 작업은 `effects:{}` 로 시작(scene-style-connect.js) → 로고 0장면. 내 프리셋은 로고를 담지도, 적용 때 얹지도 않았다(applyTaste 가 effects 를 안 건드림) — 065 안내문 "내 프리셋에 저장하면 다음 작업에도 그대로"는 사실이 아니었다.

## 한 것
- 기억 = 마지막에 손댄 로고 항목 하나(그림·자리·크기·투명도) → localStorage `scene_style_logo` (워터마크와 같은 방식, 이 브라우저).
  - 넣기·옮기기·크기 바꾸기 = 저장 버튼 없이 기억. 한 장면에서만 지우면 유지, 어느 장면에도 안 남으면 잊는다.
  - 저장본 없는 새 작업 = 그 로고를 **전 장면**에. 저장본 있는 작업은 안 건드린다.
- 내 프리셋 등록 = `snap.logo` 로 담김. 적용 = 전 장면에 얹음. 로고 없는 프리셋(옛 프리셋 포함)은 지금 로고를 안 건드린다.
- 로고 칸 안내문 교체. 스크립트 버전 ui 243 · connect 64 · decorations 70.

## 검사 결과 (로컬)
- 고친 코드: 18항목 전부 통과. 고치기 전 코드: 8건 실패(②③⑤⑥⑦) — 검사가 실제로 잡는다.
- ⑧ 렌더·캡컷 레이어 7/7장 로고(분홍 점 6561, 로고 없는 스냅샷 0) · 썸네일 한 장 6561 · 완성 영상 7장면 6165~6481.
- 기존 `check_my_presets.py` 전부 통과.

## 2차 (10-05 밤, 사장님 "로고 칸에서 전 장면에 할지 이 장면에만 할지 선택")
- 로고 칸에 범위 버튼 [모든 장면](기본) / [이 장면만]. 판단 주인 = `precision20-ui.js` `logoScope`·`spreadLogos`(effect() 안에서 부른다), 꾸밈 패널은 버튼만.
- 모든 장면: 넣기·옮기기·크기·지우기가 전 장면에 같이 간다(로고만 — 다른 장면의 확대·스티커는 그대로). 버튼을 누르면 보던 장면의 로고가 곧바로 전 장면에.
- 이 장면만: 보는 장면만. 이 범위로 쓴 뒤의 새 작업엔 자동으로 안 넣는다(어느 장면인지 정할 수 없다). 범위 선택도 브라우저에 기억(`scene_style_logo_scope`).
- 검사 ⑨ 7항목 추가. 버전 ui 244 · decorations 71 · css 67.

## ⏭ 남은 것
- 라이브 실측(배포 뒤): 관리자로 로고 올리기 → 적용 → 새 작업 열어 전 장면 로고 확인 → 렌더·캡컷. `py tools/live_admin.py` 사용.
- 알아둘 것: 기억은 브라우저 단위다(다른 PC엔 안 따라감, 한 브라우저에서 계정을 바꾸면 앞 계정 로고가 새 작업에 보인다 — 내 프리셋·워터마크 기억과 같은 성질). 계정 단위로 옮기려면 회원 데이터라 사장님 승인 카드가 따로 필요.
