# 빈집 + 주도 — 채널 시그니처 매매 원리

> 작성일: 2026-05-29 | 채널 핵심 자산 (시그니처 철학)
> **이 파일은 모든 영상·콘텐츠·종목 분석의 사상적 기반이다.**
> 영상 기획·대본 작성·종목 추천 시 항상 이 4가지 Rule을 동시 적용한다.

---

## 한 줄로

> **좋은 종목 찾기는 누구나 한다. 진짜 차별화는 수급이 빈 그날 들어가는 것이다.**
> 단, **주도 종목**이 아니면 빈집은 영원히 빈집으로 남는 함정이 된다.

---

## Rule 1 — 종목 분석 < 타이밍

```
종목 정보는 평준화됐다 (뉴스·텔레방·유튜브 다 같음)
        ↓
누구나 같은 종목을 알게 된다
        ↓
차별화 포인트가 사라진다
        ↓
"어디 종목 들었어요?"가 아니라
"언제 들어갔어요?"가 진짜 질문
```

**채널 메시지 반복 패턴**: `종목 < 타이밍`을 영상당 4회 박는다.
1. 훅 (오프닝 결론 선공개)
2. 권위 시퀀스 직전 (이유 들어가기 전 1회)
3. 클리프행어 직후 결론 (감정 피크에서 1회)
4. 마무리 (요약에서 1회)

같은 메시지를 표현만 바꿔서 4번. 시청자 머리에 박힐 때까지.

## Rule 2 — 빈집의 작동 원리 (욕조 비유)

### 직관 비유

```
┌─────────────────────┐         ┌─────────────────────┐
│                     │         │ ░░░░░░░░░░░░░░░░░░ │
│                     │         │ ░░░░░░░░░░░░░░░░░░ │
│      빈 욕조        │         │      가득 찬 욕조   │
│                     │         │ ░░░░░░░░░░░░░░░░░░ │
└─────────────────────┘         └─────────────────────┘
   물 한 컵 부으면                 물 한 컵 부으면
   ↑ 수위 급상승                   → 옆으로 넘침
   (적은 매수 → 큰 주가 변화)      (매도 출회 = 주가 벽)
```

### 메커니즘 (왜 이게 작동하는가)

| 단계 | 빈집 종목 | 가득 찬 종목 |
|------|---------|------------|
| 매수 주체 | 외인·기관 빠진 상태 → 들어오는 매수만 신규 | 이미 외인·기관 보유 → 추가 매수 미미 |
| 매도 출회 | **매도 벽 없음** → 호가 위로 쉽게 뚫림 | 차익실현 매도 출회 → 호가 막힘 |
| 가격 탄력 | 적은 거래량으로 큰 폭 상승 | 거래량 많아도 횡보·하락 |
| 정렬 시 | 신규 매수 = 100% 추세 매수 | 신규 매수 = 차익실현 매도와 충돌 |

### 핵심 인사이트

```
좋은 종목은 결국 외인·기관이 다시 채우러 온다.
빈집은 일시적 상태일 뿐, 영원하지 않다.
→ "채우러 들어오는 첫날"을 잡아야 한다.
→ 그게 5일 방향이 ↓에서 ↑로 꺾이는 그 날.
```

### 빈집을 측정하는 두 시스템

| 시스템 | 측정 | 빈집 등급 | 의미 |
|-------|------|---------|------|
| 유동성 통합순위 (현재 수준) | 통합순위 ≥ 2,317 | A 완전빈집 (하위10%) | 욕조 거의 비어있음 |
| 유동성 통합순위 (현재 수준) | 통합순위 ≥ 1,931 | B 반빈집 (하위25%) | 욕조 절반 비어있음 |
| 수급오실레이터 (변화 방향) | 5일방향 ↓ | 심화 중 | 욕조 계속 비워지는 중 |
| 수급오실레이터 (변화 방향) | 5일방향 → | 횡보 | 변화 없음 |
| 수급오실레이터 (변화 방향) | 5일방향 ↑ | **재진입 초기** | **물 들어오는 첫날** ← 진입 트리거 |

> 두 시스템 동시 확인 — 통합순위 A/B + 오실레이터 ↑전환 = 🔴 강력 신호

## Rule 3 — 신고가 vs 눌림 둘 다 OK

> **표면 가격 위치는 조건이 아니다.**

| 표면 모습 | 가능한 수급 상태 | 진입 가능? |
|---------|-------------|---------|
| 신고가 + 외인·기관 빠진 빈집 | 개인 주도 급등 + 외인·기관 미참여 | ✅ 가능 (외인 들어올 자리 있음) |
| 신고가 + 외인·기관 가득 | 외인·기관 주도 강세 추세 | ❌ 추격 (탄력 제한) |
| 눌림 + 외인·기관 빠진 빈집 | 패닉 셀링 → 재진입 대기 | ✅ 가능 (전형적 빈집) |
| 눌림 + 외인·기관 가득 | 추세 약화 + 매물 부담 | ❌ 함정 (더 빠질 수 있음) |

### 통상적 오해 vs 우리 원칙

```
오해: "신고가는 너무 비싸 / 눌림은 안전"
       ↓ (가격 표면만 봄)
       ↓
원칙: "신고가든 눌림이든 빈집이면 가능 / 가득 차면 추격"
       ↓ (수급 본질을 봄)
       ↓
       어떤 표면이든 수급오실레이터가 모든 걸 말해준다.
```

## Rule 4 — 주도 종목이 아니면 빈집은 함정 ⚠️ (가장 중요)

### 함정 메커니즘

```
빈집 + 비주도 종목
        ↓
외인·기관이 돌아올 이유 없음
        ↓
영원히 빈집으로 남음
        ↓
"왜 빈집인데 안 오르지?" → 함정에 갇힘
```

### 주도 여부를 먼저 확인하라

종목 후보가 떴을 때 순서:
```
1. 주도 섹터인가? (테마·매크로·실적 모멘텀 살아있는가)
        ↓ NO → 컷
2. 주도 종목인가? (섹터 내 1티어인가)
        ↓ NO → 2티어로 빠짐, 신중
3. 그제서야 빈집 확인
        ↓ NO → 추격, 신중
        ↓ YES → 🔴 진입 자리
```

### 빈집 × 주도 매트릭스

|              | 주도 ✅                      | 주도 ❌                          |
|--------------|----------------------------|--------------------------------|
| **빈집 ✅**  | 🔴 **진입 자리** (시그니처) | ⚠️ **함정** (영원히 빈집)        |
| **빈집 ❌**  | 🟠 추격 자리 (탄력 제한)    | 🟡 관심 외 (왜 보고 있나)         |

> **시그니처는 🔴 한 칸만**. 나머지 3칸은 다 거르거나 거르고 봐야 함.

### 주도 종목 판단 기준 (7가지 중 3개 이상)

1. 그룹·계열 핵심사 (대장 1~3사 내)
2. 섹터 내 시총·점유율 1~3위
3. 핵심 신사업 메가트렌드 직접 노출 (AI·SDV·로봇 등)
4. 해외 페어 종목 다중 (글로벌 비교 자산)
5. 증권사 동시 명시 (같은 주 3사+ 리포트)
6. 그룹 신사업의 코어 (인접 자회사·관계사 중심축)
7. 정량 모멘텀 (수주잔고·기관 추정 매수 50억+)

> **현대모비스 사례**: 7가지 중 7가지 모두 충족 — 시그니처 표본.

## 통합 진입 트리거 (실전 체크리스트)

종목을 진입 자리로 판단하려면 **모두 충족**해야 한다.

```
□ STEP 1 — 주도 확인 (Rule 4)
    □ 주도 섹터 (테마 살아있음)
    □ 주도 종목 (위 7가지 중 3개 이상)
        ↓ 미충족 시 → 즉시 컷, 다음 종목으로

□ STEP 2 — 빈집 확인 (Rule 2)
    □ 유동성 통합순위: A 완전빈집 or B 반빈집
    □ 수급오실레이터: 하위 25% 이하
        ↓ 미충족 시 → 추격 영역, 보류

□ STEP 3 — 타이밍 확인 (Rule 1)
    □ 5일방향이 ↓에서 ↑로 막 꺾인 그 날
    □ 신호 정렬 4개 (수급·외국인·리포트·일정) 동시 시점
        ↓ 미충족 시 → 대기, 다음 정렬 기다림
        ↓ 충족 시   → 🔴 진입 자리, 그날 검토

□ STEP 4 — 표면 무관 (Rule 3)
    □ 신고가든 눌림이든 진입 자리는 진입 자리
```

| 체크 항목 | 현대모비스 |
|---------|----------|
| **STEP 1 — 주도 확인** | ✅ |
|  - 주도 섹터 | ✅ 자동차부품(대형) + 전장·ADAS 동시 코어 |
|  - 주도 종목 | ✅ 7가지 모두 충족 — 그룹 핵심 3사·SDV·해외페어 4중·증권사 3사 동시·BD코어·다올 45억 추정 매수 |
| **STEP 2 — 빈집 확인** | ✅ |
|  - 유동성 통합순위 | ✅ B 반빈집 (하위 21%) |
|  - 수급오실레이터 | ✅ -0.000352 하위 21% |
| **STEP 3 — 타이밍 확인** | ✅ |
|  - 5일방향 전환 | ✅ ↓에서 ↑로 꺾인 그 날 = 2026-05-27 |
|  - 신호 정렬 | ✅ 수급·외국인·리포트·일정 4개 정렬 동일 시점 |
| **결론** | 🔴 **진입 자리 — 그날** (2026-05-27) |

> 표면은 신고가도 눌림도 아닌 횡보 구간 — Rule 3에 따라 표면 무관.

## 콘텐츠·영상 적용 가이드

### 영상에 박는 우선순위

```
1순위 (절대 필수): Rule 1 "종목 < 타이밍" 4회 반복
2순위 (시그니처): Rule 4 "빈집 + 주도" 매트릭스 보여주기
3순위 (메커니즘): Rule 2 욕조 비유 (시각화에 최적)
4순위 (오해 정정): Rule 3 신고가 vs 눌림 둘 다 OK
```

### 비유는 욕조로 통일

- 모든 영상·콘텐츠에서 **욕조 비유** 사용
- 다른 비유 (그릇·탱크·창고) 금지 — 채널 시그니처 일관성
- 욕조 비주얼: 빈 욕조 ↔ 가득 찬 욕조 대비
- 강조 단어: "빈집" "수위" "물 한 컵"

### 메시지 4회 반복 패턴 예시

| 위치 | 표현 (같은 메시지·다른 표현) |
|------|--------------------------|
| 1회 (훅) | "진짜 어려운 건 종목이 아니라 타이밍입니다" |
| 2회 (권위 시퀀스 직전) | "좋은 종목인 건 다들 알아요. 문제는 언제 들어가느냐죠" |
| 3회 (클리프행어 직후) | "그날 잡는 게 진짜입니다" |
| 4회 (마무리) | "종목 찾기보다 타이밍이 본질이에요" |

> 다른 표현이지만 같은 본질 → 시청자 무의식에 박힘.
