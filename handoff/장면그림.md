프레임은 새로 안 받는다 — `work/seg_thumbs/{seg_id}.jpg` 캐시 재사용.
`store.py:195·205`가 계획을 읽을 때마다 `_fill`을 다시 도는 허점까지 반영해 저장 출구에서 검증.

계약: 화면 교체 없음(표시만) · `screen_verify_enabled` 기본 **OFF** · visual_verb=False 제외 ·
그림 없으면 텍스트 폴백(회귀 0) · 두 판정을 `screen_verify.jsonl`에 남겨 대조 가능.

```
즉 **텍스트 판정은 태깅이 틀리면 같이 틀린다**(자기 글자를 자기가 채점). 이 작업이 노린 바가
실제로 재현됐다.

## ★함정 — 이미지 경로와 텍스트 경로가 **다른 키풀**을 쓴다

```
텍스트 판정: _vault_call        → key_vault
이미지 판정: sv.image_call      → frame_script._call_with_key_rotation → comment_gen 키풀
```
`comment_gen` 키풀이 비면 `_call_with_key_rotation`이 **로그 한 줄 없이 return None** →
이미지 판정만 조용히 0이 되고 화면엔 종전(텍스트) 판정만 남는다.
로컬 PC에서 처음 돌렸을 때 정확히 이 모양이었다(로컬 `SHORTS_GEMINI_KEYS` 0개, `image: null` 17/17).
서버는 14개 살아있어 정상 동작. **"그림 판정이 안 보인다"는 제보가 오면 키풀부터 확인하라.**

## 2026-09-10 (4) — 자동 교체 구현 + 실측 (사장님 "답을 알고 두 번 수동으로 하는 거야?")

**만든 것**: 어긋난 칸이 나오면 후보를 사진으로 훑어 **맞는 첫 장으로 바꾼다.**
- 후보 순서(싼 것부터): ①대본이 지목한 alternates → ②**같은 영상의 이웃 컷** → ③나머지
- 이미 다른 칸이 쓰는 장면은 뺀다 · edge(첫·끝 컷)는 종전대로 제외(`non_edge_segs`)
- 원본을 `auto_swap.from`에 남기고 화면에 **"🔄 자동으로 바꿨습니다 · ↩ 원래대로"** 표시
- 스위치 `screen_verify_autofix`(검증 스위치와 **따로** — 검증만 켜고 교체는 끌 수 있다)
- 못 찾으면 종전대로 빨간불(회귀 0)

**실측(서버 격리본, 실키)**: 어긋남이 있던 job 21건

```

### 남은 한계 (알고 넘어간다)
- **화면 자막까지 맞추지는 못한다.** CTA 칸은 자막 없는 컷이 이상적인데 그 기준은 아직 없다.
- 사진 1장만 본다 — 그 순간에만 안 보이는 물건이면 억울하게 바뀔 수 있다. 그래서 되돌리기가 있다.
- 09-08 낱말겹침 기각 계보를 지킨다: **사장님 손이 늘었는지**로 검증해야 한다(`scene_swaps` 대조).
