v2에서 바뀐 것
· 사장님이 새로 쓴 데모 대본(레퍼런스 랭킹 → 최종 렌더)을 **TTS용으로 정리**했다.
  오타·띄어쓰기 교정 / 문장 끊기 / 감정 태그 / <break> / 챕터 분할.
· 데모를 **한 덩어리에서 12챕터로 쪼갰다.** 이유: 한 번에 7분을 생성하면 톤이 흘러내리고
  중간에 끊기면 처음부터 다시 뽑아야 한다. 챕터로 나누면 그 챕터만 다시 뽑는다.
· 낡은 표현 교체: "렌즈 검색" → **"숏템파워검색"**(2026-07-30 실제 버튼명, 화면과 일치).
· 옛 [S5-1](소재찾기)은 새 데모 대본과 내용이 겹쳐 폐기하고, 그 도입 질문만 [S5-0]으로 살렸다.

사용법
· 모델 = Eleven v3 / 안정성 = 견고한(Robust) / 음성 = 전 씬 하나로 통일
· **▼▼▼ ~ ▲▲▲ 사이만 복사**해서 붙여넣는다. ※줄은 지시문이니 붙여넣지 말 것.
· 챕터 블록은 통째로 한 번에 생성. 느리면 뽑은 뒤 1.1~1.15배 가속(태그를 지우기보다 안전).

★TTS 발음 주의 (읽어보고 이상하면 아래처럼 한글로 바꿔서 다시 뽑는다)
· TTS  → 티티에스      · CTA → 씨티에이      · AI → 에이아이
· 물결표(~)는 오독이 잦아 전부 "…에서 …"로 풀어 썼다 (예: 1분에서 2분 정도)
· 숫자는 그대로 뒀다. 어색하게 읽으면 한글로("3개"→"세 개") 바꾼다.

※ 아직 비어 있는 것: 링크를 **어디에** 두는지 확정(유튜브 고정 댓글 / 프로필 링크 / 둘 다).
  "고정 댓글"로 썼으니 그렇게 두면 원고 수정 없이 그대로 쓸 수 있다.

  맡는 내용→맞는 내용 / 깔끔하지 지워진→깔끔하게 지워진 / 필요없이→필요 없이

태그 사용 요약
  [impressed] 감탄 / [excited] 들뜸 / [determined] 결의 / [whispers] 귓속말 / [lowered] 낮게
  [calm] 차분 / [serious] 진지 / [disappointed] 실망 / [knowing] 알고 있다는 듯 / [curious] 의아함
  [clear] 명료 / [confident] 확신 / [tired] 지침 / [warm] 따뜻함 / [relaxed] 여유
  [amazed] 경탄 / [emphatic] 못박기 / [sincere] 진심 / [urgent] 급함

감정 설계 원칙
  1. 앞을 담백하게 → 뒤가 산다. S5-11 [amazed]가 정점이므로 S5-6~10은 일부러 낮게 깔았다.
  2. 페인 구간(S2)은 세게 읽으면 안 된다.
  3. 밀어내는 화법(S6)은 낮고 차분하게.
  4. [sincere]는 두 번만(S5-끝, S7). 남발하면 진심이 연기로 들린다.
  5. 태그보다 **끊기**가 더 자연스럽다 — 짧은 문장·<break>·… 를 먼저 쓴다.
