## 유튜브 채널기반 수집 (틱톡 계정시드 미러) — 2026-07-25 ✅ 병합·라이브

레퍼런스 랭킹 유튜브가 **키워드 시드 검색만** 하고 `/refs`에 등록한 **채널(kind=account) 시드는
저장만 되고 수집 안 되던** 문제를 해결. 틱톡 Phase 1(무료 계정시드)과 같은 채널기반 모델을 얹음.
인스타 레퍼런스와 **동일한 카드·3열 지표(속도/가속/참여율)·전체 섞어 랭킹**. **비용 0원**(Data API 쿼터만,
채널당 ~2–3 units). 유튜브는 키워드검색도 무료라 **채널+키워드 두 경로를 함께** 자동 수집.
