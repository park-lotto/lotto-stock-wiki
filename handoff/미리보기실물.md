## 2026-08-23 — 3번 1단계: 재생 자막에 실제 스타일 (커밋 `fdb995cf2`)

**원인**: 재생 자막 `#subbox`가 CSS에 **흰색 17px·bottom 64px 고정**.
자막 꾸미기를 아무리 해도 재생 화면엔 안 보였다 → 렌더를 돌려야만 결과를 알 수 있었다.

**고침**: `applyPlaySubStyle(box)` 공용 함수. `tickSub`가 그릴 때마다 호출.
- ★규칙을 새로 안 만든다 — `updateCaption`이 정한 `STATE.captionStyle`을 그대로 읽는다(0순위-B)
- 함수 없는 화면(scene_lab 단독)은 `typeof`로 걸러 조용히 넘어간다

### ★내가 낸 버그 2건(둘 다 실측으로 잡음)
1. **`window.STATE`는 항상 undefined** — `STATE`는 최상위 `const`라 window에 안 붙는다.
   (`MIX_JOB`·`WORK_ID`에서 **이미 두 번 밟은 함정**) → `typeof STATE`로 교체.
2. 재생기가 안 열렸을 때 `clientWidth=0` → 배율 0 → 글씨 사라짐. 0이면 `PREVIEW_W`로 폴백.
