**이모티콘+그래픽 움직임 비중 높이기** — 텍스트와 이모지/그래픽을 균형 있게. 이모지가 보조가 아니라 비주얼 중심 역할.

**Why:** 사용자가 "글자보다 이모티콘+그래픽이미지 움직임 선호"라고 명시. 단, 완전히 이모지만 쓰면 너무 극단적이라 NG.

**How to apply (균형 기준):**
- 이모지는 80~130px 수준 (200px+ 전체 화면 점령은 과도함)
- 카드/레이아웃 안에서 이모지(60~80px) + 텍스트(36~60px) 함께 사용
- 이모지는 elastic scale, float, wobble 등 움직임 필수
- 배경에 작은 이모지 파티클(opacity 0.06~0.10) 흘러다니기 OK
- 텍스트도 Remotion 가이드 방식 유지 (X슬라이드, letterSpacing 등)
- 이모지와 텍스트 조합 비율: 이모지 40% : 텍스트 60% 느낌
- "이모지만" 또는 "텍스트만" 둘 다 NG — 항상 혼합

**자막바 필수** — 모든 AG 시리즈 씬(Whisper 싱크 포함)에 하단 자막바 필수.

**Why:** 사용자가 "자막 넣어야 해"라고 명시 요청. 음성 싱크 씬에는 항상 자막이 있어야 함.

**How to apply:**
- 하단 16% 고정 자막바 영역
- Whisper 세그먼트 기반으로 현재 말하는 텍스트 표시
- 세그먼트 전환 시 페이드인/아웃 처리
- fontSize 40px, fontWeight 700, color C.textPrimary
- 자막 없는 구간(세그먼트 사이 공백)은 바 영역 비워둠
