# 핸드오프 — 인포크링크 등록 모달 (트랙 `인포크모달`)

> 사장님 질문(2026-08-18): *"인포크링크 페이지를 붙여서 관리하게 할 수 있나? 인스타는 꼭 필요한 건데"*

---

## ✅ 2026-08-18 회사PC — 9단계에서 인포크에 바로 등록 (라이브)

### 결론부터 — 붙일 수 있다. 막는 게 하나도 없었다

처음엔 "링크인바이오 서비스는 대개 iframe을 막는다"고 추정했는데 **실측하니 전부 틀렸다.**
사장님이 *"해봐야 가능한지 알 수 있는 거야?"* 라고 짚어준 게 맞았다 — 헤더 한 번 찍으면 되는 일이었다.

| 검사 | 결과 |
|---|---|
| `X-Frame-Options` 헤더 (`/`, `/user/login`) | **없음** |
| `Content-Security-Policy` 헤더 | **없음** |
| HTML `<meta>` CSP | **없음** |
| 프레임버스팅 JS (`top!=self`·`frameElement`) | **0건** |
| iframe 안 실제 렌더 | **436 엘리먼트** (로그인 폼 정상) |
| **세션 쿠키 유지** (사장님 계정 실로그인) | **유지됨** — 관리화면·블록편집까지 정상 |

`SameSite=Lax`로 쿠키가 막힐 가능성이 마지막 변수였는데, 실제로 로그인해보니 안 막혔다.

구조: `link.inpock.co.kr` = Express + CloudFront, 관리화면 `/admin`,
미로그인 시 `307` → `/user/login?redirect=%2Fadmin`. (`www.inpock.co.kr`은 Framer 홍보사이트, 별개)

### 어디에 붙였나 — 9단계(최종렌더), 기존 `#inpockBox` 자리

사장님이 *"8단계가 SEO인가? 쿠파스도 거기 붙이기로 했는데"* 라고 물어 확인한 결과:

- **화면상 8단계 = SEO 맞다.** 다만 **인포크 박스는 9단계(최종렌더)에 있다**(`data-step=6`).
- 8단계로 옮기지 않은 이유: ①인포크는 "다 만든 뒤 마지막에 올리는 곳"이라 영상이 렌더돼야
  올릴 게 생긴다 ②8단계 SEO는 *설명란 텍스트를 만드는 곳*이라 성격이 다르다(거기엔 이미
  `🛒 쿠팡 링크 + 고지문구 붙이기`가 있다) ③`final_link`를 꺼내는 코드가 두 벌이 된다(0순위-B).

**쿠팡이 이미 붙어 있는 자리(참고)**: 1단계 선수집 큐잉 → 2단계 대본 재료 → 3단계 상품 확정 UI
→ 8단계 SEO 고지문구 → 9단계 인포크 등록. 즉 인포크는 이 흐름의 **마지막 조각**이라 충돌이 없다.

### 넣은 것

| 파일 | 내용 |
|---|---|
| `static/produce.html` | `#inpockModal`(`.gen-bg`+`.gen-box-wide`) · `inpockModalOpen/Close` · `inpockCopyChecked` · `#inpockBox` 버튼 교체 |
| `tests/test_produce_inpock_modal.py` (신규) | 9건 |

- 모달은 **`pmModal`의 `.gen-bg`/`.gen-box`/`.open` 규약을 그대로** 따랐다(새 규약 안 만듦).
  인포크 관리화면이 좌측메뉴+편집+미리보기 3단이라 760px에선 눌려 **`.gen-box-wide`(1440px)
  변형만 얹었다** — `.gen-box` 자체는 안 건드렸다.
- 새 탭으로 나가던 `인포크링크 열기 ↗`는 **제거**했다. 남겨두면 '창 옮겨 다니기'가 그대로다.

### 검증한 것 (실측, 로컬 :8901 + Playwright)

```
링크 없음 → 모달 안 열림 + "3단계(영상대본MIX)에서 지정하세요" 안내
링크 있음 → 열림, src=link.inpock.co.kr/admin, 인포크 436 엘리먼트 렌더

닫기 후 src 유지 · 재열기 정상 · 우리 코드발 JS 에러 0건
pytest 33 passed (신규 9 + 기존 쿠팡·인포크 24, 회귀 0)
```

### 함정 (다음 사람이 밟지 말 것)

- ⚠️ **패널 제목의 번호는 이미 자동이다 — 고치지 마라.** HTML에 `7 · SEO해시테크`라 적혀
  있지만 `syncPanelTitles()`가 `renderSteps()`마다 `STEP_LABELS`에서 채워 **화면엔 8이 뜬다**
  (실측: 9개 중 8개가 HTML 초기값과 다르고 전부 런타임에 교정됨). 손으로 고치면 두 벌이 된다.
  *이번에 "번호가 틀렸으니 고치자"고 했다가 실측하고 취소했다.*
- ⚠️ **복사 성공을 가정하지 마라.** `clipboard`는 비보안 컨텍스트·권한 거부에서 **조용히**
  실패한다. 실패했는데 "복사됨"이라 띄우면 빈 클립보드로 붙여넣게 된다 →
  `inpockCopyChecked`가 성공/실패를 갈라 돌려주고 `execCommand`로 한 번 더 시도한다.
- ⚠️ **`final_link`는 상품이 있어도 빌 수 있다.** `url`·`partner_url`이 둘 다 비면 빈 문자열
  (`coupang_partners.final_link`) → 버튼은 그려지고 링크만 없다. 검증 중 발견해 가드를 넣었다.
- ⚠️ **닫을 때 `frame.src`를 비우지 마라.** 비우면 다시 열 때마다 재로그인 흐름을 탄다.
- ⚠️ `iframe`에 `src`를 마크업으로 박지 마라 — 제작소를 열 때마다 인포크를 부른다.
- ⚠️ **이 기능은 인포크가 프레임을 안 막는다는 전제 위에 있다.** 저쪽이 나중에
  `X-Frame-Options`를 걸면 모달이 빈 화면이 된다. 그때는 Playwright 자동등록(아래 ⏭2)로 간다.

### 인스타와의 관계 (사장님 "인스타는 꼭 필요한 건데")

내 인스타 프로필 링크는 **인포크 하나**이므로, 영상마다 생기는 쿠팡 상품은 전부 인포크 안에
쌓여야 한다. 그래서 이 등록 단계가 인스타 수익화의 목줄이다. 영상 설명란·고정댓글에는
인포크 프로필 링크 하나만 넣는 구조(`refreshInpock` 안내문에 그대로 적혀 있다).
