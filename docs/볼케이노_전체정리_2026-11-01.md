## 2. 볼케이노가 돌아가는 구조 **[실측]**

### 2-1. 전체 흐름

```
setup (env_probe → 키·도구 확인)
  → start (소재 지정. 대부분 서버는 안 받고 다음 단계로 넘김)
  → assets ① reserve (빈 폴더 예약, nonce)
  → assets ② save    (작업 고정 영수증 저장)
  → assets ③ 팩 내려받기 (runner·pipeline·fonts, sha256·파일 수 대조) + 출입증
  → 실행기 volcano_drive.py --step env
      → <preset>_seed (사전 점검, 전용 .venv)
      → <preset>_make → <preset>_check (사람=Claude 차례, rc 3 정지)
  → Claude가 팩 문서대로 제작
  → --step <preset>_check 재개 (서버가 완성본 재판정)
  → <preset>_deliver
```

- 서버는 **대본·영상을 만들지 않는다.** 규칙 문서와 고정 코드를 내려주고, 이 PC의 Claude가 만든다. 서버는 마지막에 결과를 다시 판정한다.
- 호출마다 `next_payload`를 그대로 되돌려 보내고, 빠진 칸(`next_payload_missing`)만 채운다.
- 썰쇼핑은 작업 고정 단계 없이 바로 팩을 줬다. 프리셋마다 경로가 다르다.
- 회원 화면: 예능픽은 `127.0.0.1` 로컬 화면이 자동으로 뜨고, 소재(링크·검색어)·배경색·글씨색·목소리·배속을 고른다.

| 썰쇼핑 | 없으면 Claude가 "개발 비화·짝퉁·대란·몰락·역전" 제품을 고름. 영상은 카드마다 검색 | 기사 2곳 이상 + 유튜브 |
| 인스타그램 쇼핑 | [A] 소스 폴더 또는 [B] 벤치 링크(TikHub) | 사용자 제공, 샤오홍슈 등 |

- **소재는 저절로 바뀌지 않는다.** 입력값으로 만든다. 다만 Claude·agy의 구간 선택은 실행마다 달라질 수 있다.
- 이번 예능픽 소재는 볼케이노 지정이 아니다. 내가 피식대학 채널 목록을 조회해 236초·371만 회 영상을 골랐다.
- **인스타형의 채널별 순번 [실측]:** 후보를 재미 순위로 고르지 않고, 채널 핸들·영상 ID로 순서를 돌린다. 같은 링크라도 채널마다 다른 대목이 된다. 이번: 3번(상) → 2번(중) → 1번(중).
- 볼케이노 서버는 소재 금지를 약하게 막는다. MBC 공식 영상이 `start`를 통과했고, 렌더 전 검사는 차단 채널 목록·방송사 표기·`source_reviews` 칸 채움을 본다. 제작 주체를 직접 확인하지 않는다.

### 6-1. 예능픽 **[실측·팩]**

**뼈대**

### 6-3. 썰쇼핑 **[팩]**

**뼈대**
- 약 45초, 330~360음절, 말 속도 8.0음절/초.
- 제목 14~17자 도발형, 훅은 제목 두 줄(둘째 줄 강조색).
- 카드 1~2줄, 줄당 4~12자, 카드당 컷 1개 기본(29카드 중 21개가 1컷).
- 흐름: 배경(연도·숫자) → 갈등 → "근데/이때 … 진짜 레전드인데" 반전 → 대비 → 결말 → 현재.
- 말투 음슴체 반말(~함·~해버림·~였음), 끝은 ~있다고/~가더라.
- 문장 끝 줄에 마침표(읽기 끊김용, 자막에선 삭제). 받침 자동 판단 금지.
- 사실은 기사·공식 자료 2곳 이상, `SOURCES.md`.
- 실촬영 + 재연 그림 20~30%. 재연은 실제 영상이 있을 수 없는 장면만, 검색 사진 금지. 같은 인물은 앞 그림을 참고로.
- 같은 구간 두 번 금지, 뉴스 띠는 crop, 컷마다 `focus`.
- 효과음 약 4줄에 1개(결정적인 줄).
- 쉼: 음슴체 끝 0.11초, 그 밖 0.06초. 컷 움직임: 등장 1.063→1.0, 줄 바뀜 1.0→1.122, 이동·회전 0.

**결**: Paperlogy, Do Hyeon, 제롬 목소리, 효과음 파일, 채널 아이콘.

**이븐쇼핑형 메모**: 메모리의 "천재 떼돈 정체 → 논란 → 이건 바로 → 심지어 → 충격 포인트" 흐름과 다르다. 비교 대상으로 볼 것.

### 6-4. 인스타형 예능프리셋 **[팩]**

**뼈대: 고르기**
- 사건 하나. "누가 무엇을 해서 누가 어떻게 됐다" 한 줄, 앞뒤 몰라도 이해, 화면에 보임. 셋 다 충족.
- 신호: 제작진 개입, 1~2초 화자 교대 3회+, 질문-단답, 메타 발언, 갑을 전복, Freeze & Crash.
- 거름: 한 사람 4초+ 독백, 룰 설명, 맥락 대명사.
- 30초 배분: 0~3 도발 / 4~9 상황 / 10~21 가열 / 22~27 클라이맥스 / 28~30 결말.

**뼈대: 컷**
- 원속도 1.0. 슬로·구간 배속·정지·느린 확대 금지. 전체 1.1배만 게이트 뒤 마지막에.
- 말 사이 0.3초 초과 틈 자름. 첫 단어 앞 0.10초, 끝 단어 뒤 0.15초, 영상 끝만 0.45~0.8초.
- 숏 3초 이내(최대 5초). 이음새 사이 0.4초 미만 숏 금지. 소리 크로스페이드 4프레임.
- 점검치: 평균 컷 1.2~2.0초, 분당 35~50컷, 무음 2% 이하.
- 자를 때 컷을 통째로 빼지 않고 앞뒤를 깎는다. 30초에 13~20번.
- 말 없는 사건은 `protect`, 게임은 원인→전략→실행→결과.

**뼈대: 자막**
- 대사 카드 한 카드 한 사람, 16자 안팎, 시작은 실제 말 시작(0.4초 초과 어긋남·0.7초 미만 막음).
- 기호 `?` `!`만. 욕은 첫 글자만 순화(소리는 원음).
- 원본 자막과 우리 카드 공존 금지. 아래 자막은 크롭, 얼굴 옆 말풍선은 그걸로 대체.
- 하단 설명: 줄당 2.8초↑, 근거가 나온 뒤 표시, 대사 반복 금지, 노출 25~90%.
- 하단 한 줄의 일은 하나: 상황 압축, 속마음, 반전·아이러니, 별명, 대사 밖 맥락.
- 예능 말투는 커뮤니티체(음슴체, ㅋㅋ·ㄷㄷ은 절반 이하). 영화는 인과 서술(`~다`는 마지막 줄만).
- 효과음 4초당 1개 이상, 같은 소리 3번까지, 말소리보다 10dB 아래.

**뼈대: 후킹·제목**
- 후킹 TTS 한 문장, 결말 숨긴 `~데`, 쉼표 금지, 끝에서 답하는 질문을 연다. 그동안 원음 0.1배, 대사 카드 없음.
- 후킹 자리 = 이야기 밖의 한 숏. 그 밑에 이야기 대사 금지.
- 최근 3편과 후킹 틀이 같으면 막음(`hook_history.json`).
- 화면 제목 2줄 각 7~11자, 종결형 금지, 둘째 줄은 명사로, 결말 숨김.
- 유튜브 제목(895편 실측): 실명 2명+ → 사건 → ㅋㅋㅋ → 감상, 30~36자, 따옴표 금지.

**뼈대: 게이트·보고**
- 예외는 넷뿐: 숏 3초, 끝 여운, 원본부터 잘린 이마, 대사·사건 숏 반쪽 자막. 사유 필수, 효과음·음량·싱크는 못 넘김.
- 코드 수치: 숏 3.0초(후킹 밑 첫 숏 5.0), 음량 I -16~-11.5·TP -0.5 이하, 끝 여운 0.30, 카드 0.70, 싱크 0.40. 얼굴 처짐·이마 잘림은 자동 면제로 보고만 한다(`final_check.py:548`). 소재 길이는 40.0~49.5초, 41초 미만이면 채우기 조각으로 44초에 맞춘다(`tight_source.py:201`).
- 지킬 순서: 결말·펀치라인·사건 > 반쪽 자막 없음 > 3초·여운·얼굴 위치.
- 게이트를 피하려고 대사·사건을 빼지 않는다. 미리 줄이는 것도 금지.
- 어긴 것을 한 번에 전부 출력. 재작업 ③은 한 번까지.
- 도구 호출 40번 안쪽, 렌더 겹치지 않기, 목표 30분.

**결**: A2Z, Jua, Paperlogy, Pretendard, 온글잎 오케이티콘체, 로고 링 색, 제목 색, vivid·색온도 -10, 효과음 세트, 하단 문구.

### 6-5. 인스타그램 쇼핑 **[팩]**

**뼈대**
- 10~30초. 시작 전 `준비확인.py`, ❌ 있으면 시작 안 함.
- 대본: 의미 덩어리 3~4개, 덩어리 끝에서만 닫고 안에서는 끝음을 이음. 줄마다 끊기·초단문 연속·끝까지 한 문장 금지.
- 소스 하나로 4유형 동시 제작(낯선 점·인물 사건·질문·고민). 첫 문장은 4편 동일, 둘째 덩어리부터 갈림. 헤드라인은 편마다 다름.
- 첫 문장은 시청자가 겪어 본 순간으로. 벤치 문장 복사 금지.
- 첫 장면은 킬포인트, 앞 3~4초에 가장 강한 장면.
- 자막: 12자 안팎 최대 16자, 0.6초 미만 금지, 카드 빈틈 없이 연속, 초당 12자, 카드 7초 이하, 가운데 한 줄.
- `cards.py`가 형태소 분석(kiwipiepy)으로 경계 검사: 조사·어미 분리 금지, 꾸밈-받음 분리 금지, 숫자+단위·고유명사 분리 금지.
- 낭독은 한글, 자막만 원래 표기("에스라인"/"S라인").
- 장면 전환 = 절 경계 프레임. 절마다 뜻이 보이는 장면. 단 소구점 선행이 우선.
- 같은 소스 구간 두 번 금지. 합성 전에 가장 짧은 필수 장면 길이부터 잰다.
- 배율 유형별 100~130%, 컷 안 고정, 느린 줌 금지.
- 색: 원본 + 블랙 +20 고정 곡선, 벤치 색 따라가기 금지.

**결**: 서툰이야기, Dongle, 남자 살림 20년차 화자, CTA "나도", [광고] 표시, BGM.

**쓰면 안 되는 것**: 이 팩 문서에는 "일화·성능·기간 다 지어낸다"는 규칙이 있다. 광고에서 허위 경험·수치는 법적 위험이 크다. **우리는 가져오지 않는다.** 기본틀 쪽 규칙("허구 경험·미확인 수치 금지")을 따른다.

## 8. 우리가 필요한 것 (우선순위)

### A. 바로 효과가 큰 것

1. **굽기 전 판정 관문**
   - 완성본과 같은 그림·시각의 작은 미리보기(소리 없음 또는 저용량)를 만든다.
   - AI가 컷마다 원본 자막·로고·장면 불일치·검은 화면·멈춤을 본다. 판정 합격 여부는 코드가 낸다.
   - 판정 결과를 저장하고, **판정 뒤 대본·타이밍·소재가 바뀌면 렌더를 거부**한다.
   - 구현 근거: 썰쇼핑 컷 지문 = sha256{종류, 소재 경로·크기·mtime, 자막 줄, 제목, 8fps 프레임 수, 줄 바뀜 위치}. 컷 번호·절대 시각은 뺀다 [코드].
   - 왜: 예능픽 렌더 3회 중 2회가 끝까지 구운 뒤 실패했다. 우리 회원 길의 전체 재실행 문제(10-29~30 회당 20~66분)와 같은 종류다.

2. **컷별 지문으로 바뀐 컷만 재검수**
   - 컷마다 입력 해시를 저장한다. 통과한 컷은 다시 묻지 않고, 고친 것이 없으면 호출하지 않는다.
   - 답이 없던 컷만 한 번 더 묻는다. 단계 재현 금지 규칙을 코드로 강제하는 장치다.

3. **게이트는 어긴 것을 한 번에 전부 출력**
   - 하나 고치고 재렌더하는 패턴을 막는다(인스타형 기록: 13판·81분).

4. **필수 도구·조건은 `setup`에서 확인 (볼케이노의 약점)**
   - AGY 없음은 팩을 다 받은 뒤 `_make`에서야 나왔다. 한글 경로는 아예 경고가 없었다.
   - 우리는 시작 전 한 번에: 필수 CLI, 로그인 상태, 키, 경로 문자, 디스크, 글꼴.

5. **영상을 직접 보는 AI 호출 경로**
   - Claude는 프레임만 본다. 영상+소리 판단은 Gemini 계열로 분리한다.
   - 구독 CLI를 쓰되 API 키는 환경에서 제거한다. 지적은 파형·프레임으로 재확인한다.
   - 먼저 시험할 것: 같은 영상으로 Claude 프레임 판정과 agy 판정을 비교해 어느 쪽이 실제 결함을 잡는지 측정.

### B. 구조로 가져올 것

6. **작업 고정 영수증**: 편마다 코드·규칙 지문 저장. "회원 길 = PC와 같다"를 판별 대조로 증명하는 근거.
7. **단계 저장·재개**: `next_payload` + `--step` 방식. 실패 지점부터 이어 가기.
8. **역할 경계**: 판단은 AI, 렌더·검증은 고정 코드. "눈·경험은 같게, 엔진은 가둔다"와 같은 구조.
9. **재렌더는 새 출력 폴더, 합격 이관 금지**.
10. **서버 재판정**: 결과 JSON과 파일 해시를 서버가 다시 잰다.
11. **예외는 증명으로만**: 임계값을 낮추지 않고 사유 + 픽셀 대조(`reviewed_source_motion`), 또는 정해진 갈래만 사유와 함께(`--accept-gate "갈래: 까닭"`).
12. **재작업 상한**: 검수 지적으로 인한 재작업은 한 번까지, 뒤집히는 지적은 재서 맞을 때만.
13. **도구 호출 예산**: 한 편 40번 안쪽, 측정 스크립트 손으로 안 짜기.

### C. 콘텐츠 규칙으로 가져올 것

14. 채널별 순번으로 같은 소재도 다른 대목(회원끼리 겹침 방지).
15. 최근 3편과 후킹·제목 틀 중복 금지(`hook_history.json`).
16. "처음 보는 사람이 모를 것"을 AI가 뽑아 `context.json`에 적고, 설명이 없으면 도구가 멈춤.
17. 사건 기준 3가지와 신호·거름 목록.
18. 자동 신호로 재미를 고르지 말 것: 표면 신호 13개가 AUC 0.6을 못 넘겼다는 기록. 영상을 보는 AI는 실제 채택 구간을 맞혔다.
19. 형태소 기반 자막 경계 검사(kiwipiepy).
20. 낭독문과 자막 표기 분리("에스라인"/"S라인").
21. 하단 설명 "한 줄의 일은 하나" 5가지와 커뮤니티체 변환표.
22. 효과음 밀도 기준(4초당 1개, 같은 소리 3번까지, 말소리 -10dB).
23. 규칙마다 왜 생겼는지 남기는 `검증기록.md` 방식.
24. 썰쇼핑 쉼 수치(0.11초/0.06초)와 컷 움직임 배율 표.

| `assets` 응답마다 같은 코드 3만 자 반복 | 응답 축소, 구독 한도 절약 |
| 청구액 미측정 | 호출별 원가 기록 |
| 자막 싱크 근거가 자기 신고 | 실제 음성으로 대조 |
| 프리셋마다 경로가 달라 멈춤 지점이 다름 | 공통 관문 하나 |
