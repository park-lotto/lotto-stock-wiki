# 15 효과 밀도·말속도 — 벤치 상위 편 목표(targets) (표준 §12-2·§12-4 · 03·05·07 뒤, 14 와 병렬)

## 목표
업그레이드 판에서 효과음·꾸밈 밀도와 말속도 편차가 **벤치 상위 편(조회 상위 50%) 의 좋은 쪽 사분위**를 목표값으로 계획 단계에서 맞춰진다. ep13 실측(sfx.rate 0 vs 0.034~0.067 · 나레 꾸밈 0 vs 0.056~0.231 · cps 편차 0.163 vs 0.113) 을 뒤집는다. 0발이 조용히 나가는 일(⑮) 재발 방지.

## 실측 배경(10-25)
- `placement.place`: 본보기 편 1개(`reference`) 비율 또는 `counted` 전체 합계 — 상위 편 구분 없음 · `rules.sfx` 없으면 sfx `[]`(경고 없음) · `rules.enter` 고정값이면 그대로.
- `upgrade_table.top()`(05) 가 상위 50% 편 id 를 낸다(`C:/숏템_칼카피/<slug>/top.json views`) · `counted.videos[*]` 에 편별 slots·stickers·sfx 수가 있다.
- 말속도: `render_itssum` 줄별 cps 표·`CPS_LINE_TOL`(⑤) · 대본 검사 `script_audit` 규칙 종류에 cps 편차 없음(`tts_chars`·`est_length` 만).
- 판 칸 주인 = 07(⑭). 상위 편 목표 파일 = 14 가 만드는 `_kal/상위편_목표.json`(여기선 칸 추가).

## 만질 파일(독점)
`tools/calcopy/hybrid/placement.py`(`place` 에 `targets` 모드 — 03 끝났음) · `tools/calcopy/hybrid/script_audit.py`(규칙 `tts_cps_spread` 추가) · `tools/calcopy/hybrid/render_itssum.py`(타입캐스트 줄별 ±8% 미세 보정 — `CPS_LINE_TOL` 옆, 미나 고정 배속 불변) · `tools/calcopy/hybrid/thumb_rule.py`(훅 targets 읽기 한 줄) · `channel/<slug>/_kal/상위편_목표.json`(밀도·cps·훅 **칸 추가만**) · `shopping_shorts/tests/test_placement_targets_top.py`(새)
## 안 만질 파일
판 파일 `targets` 값(07) · `material_fit.py`(14) · `quality_gate.py`.

## 설계
1. `placement.count` 결과에 `top:{ids, slots, stickers, sfx, p75, max}`(상위 50% 편 묶음 집계 — `upgrade_table.top()` 과 같은 선정 함수 import) 추가 · `상위편_목표.json` 에 `density{fx_rate_narr, fx_rate_orig, sfx_rate, sticker_rate: {p75, max}}` 기록.
2. `place(rows, style, seed, targets=None)`: `style.targets.density` 가 있으면(업그레이드 판) 목표 밀도 = p75, 상한 = max — **종류·조건·자리 규칙은 1차 그대로**, 개수만 목표로 채운다(조건 맞는 덩어리가 모자라면 그 수까지만 + 로그). `rules.sfx`·`rules.enter` 가 없으면 `log` 에 **경고**(⚠ 0발) 와 `check_place` 항목 ×(조용히 0 금지).
3. `script_audit` 규칙 `{"kind":"tts_cps_spread","max":0.11,"cps":8.6}` — 줄별 예상 cps(글자 ÷ (글자/cps_target)) 의 변동계수 ≤ max; 벤치 상위 p25 를 07 이 `targets.speech.spread` 에 적고 audit 이 읽는다. 걸리면 어느 줄을 몇 자 늘리거나 줄일지 제안.
4. `render_itssum`: 타입캐스트 목소리만 줄별 atempo 미세 보정 ±8%(상한 1.25 안)로 cps 편차를 `targets.speech.spread` 쪽으로 — 미나(fixed_tempo) 는 손대지 않음. render_info 표에 보정 전·후.
5. 훅: `상위편_목표.json hook{first_cut_sec_p50, face_or_object_frac, first_fx_t}` → `thumb_rule.FIND_ORDER` 가 참고(판정 규칙 변경 아님 — 추천 순서만).

## 합격 검사(사보타주 먼저)
1. 사보타주: `rules.sfx` 없는 판으로 `plan` → 로그 ⚠ + `check_place` × (고치기 전엔 0발 조용히 통과였음을 확인).
2. ep13 v2: 배치 뒤 sfx.rate·fx.rate.나레 가 상위편 p75 ±20%p 안이고 max 를 넘지 않음 · 1차 판(잇템로그판)으로 돌리면 **값이 바뀌지 않는다**(targets 없음 = 옛 동작, 자막표 diff 0).
3. `tts_cps_spread`: 편차 큰 대본 픽스처 → 실패+제안 줄 / 고른 대본 → 통과. ep13 대본 수정 뒤 `render_info` cps 편차 ≤ 벤치 상위 p25(0.113 근처 — 실측 값으로).
4. `upgrade_table`(05) 재실행: 효과 밀도·cps 축 `better:true`, `worse_n 0`.
5. 미나 판(키치잇판)에서 줄별 atempo 가 1.35 그대로(회귀).
